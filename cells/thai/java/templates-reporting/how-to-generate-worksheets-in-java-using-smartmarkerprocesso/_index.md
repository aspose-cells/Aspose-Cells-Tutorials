# วิธีสร้าง worksheets ใน Java ด้วย SmartMarkerProcessor

หากคุณต้องการ **how to generate worksheets** ในไฟล์ Excel คำแนะนำนี้จะแสดงวิธีแก้ปัญหาที่สมบูรณ์และพร้อมใช้งาน ตั้งแต่ประโยคแรกสองประโยคคุณจะเข้าใจวิธีสร้าง worksheets และ dynamic excel sheets จากคอลเลกชันของอ็อบเจ็กต์ และคุณจะได้ตัวอย่างโค้ดที่ทำงานซึ่งอัตโนมัติการสร้าง excel ด้วยการเรียกเมธอดเดียว

การสร้าง worksheets แยกสำหรับแต่ละพนักงาน, โครงการ, หรือเอนทิตี้อื่น ๆ เป็นความต้องการทั่วไปเมื่อคุณต้อง **populate excel workbook** ข้อมูลโดยโปรแกรมมิง คำแนะนำนี้จะพาคุณผ่านทุกขั้นตอน — ตั้งแต่การตั้งค่าเทมเพลตจนถึงการประมวลผลรายการและบันทึกไฟล์สุดท้าย — เพื่อให้คุณสามารถนำเทคนิคนี้ไปใช้ได้ทันทีในแอปพลิเคชัน Java ของคุณ

## สิ่งที่คุณจะได้ทำ

* สร้าง master worksheet ที่แสดงข้อมูลระดับสูง.  
* สร้าง **multiple sheets from list** data, แต่ละชีทจะถูกตั้งชื่ออัตโนมัติ.  
* **Automate excel creation** โดยไม่ต้องเพิ่มแถวหรือคอลัมน์ด้วยตนเอง.  
* **Populate excel workbook** ด้วยโครงสร้างข้อมูลที่ซับซ้อน (objects, maps, arrays).  

ข้อกำหนดเบื้องต้น:

* ติดตั้ง Java 8 หรือใหม่กว่า.  
* Maven (หรือเครื่องมือสร้างอื่น) เพื่อเพิ่มไลบรารี Aspose.Cells for Java.  
* ความเข้าใจพื้นฐานเกี่ยวกับ Java collections.  

> **Pro tip:** ไวยากรณ์ SmartMarker (`${EmployeeMaster}`) ทำงานกับคอลเลกชันประเภทใดก็ได้ที่ implements `java.util.Collection`. ใช้เพื่อให้เทมเพลตของคุณสะอาดและดูแลได้ง่าย.

## วิธีสร้าง worksheets ด้วย SmartMarkerProcessor

ส่วนนี้มีโค้ดหลักที่ทำให้ **how to generate worksheets** ง่ายดาย เราจะอธิบายว่าทำไมแต่ละบรรทัดจึงสำคัญ ไม่ใช่แค่ทำอะไร

### ขั้นตอน 1: เพิ่ม dependency ของ Aspose.Cells

หากคุณใช้ Maven ให้ใส่ส่วนต่อไปนี้ในไฟล์ `pom.xml` ของคุณ ไลบรารีนี้ให้คลาส `SmartMarkerProcessor` ที่ใช้ตลอดคู่มือ

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **Why:** Aspose.Cells จัดการ I/O ของไฟล์ Excel, การแยกวิเคราะห์ Smart Marker, และการจัดการชีทภายใน ทำให้คุณมุ่งเน้นที่ข้อมูลแทนการดำเนินการไฟล์ระดับต่ำ

### ขั้นตอน 2: เตรียมเทมเพลต Excel

สร้างไฟล์ Excel ชื่อ `EmployeeTemplate.xlsx` ที่มีเซลล์เดียวซึ่งมี placeholder ของ Smart Marker:

| A |
|---|
| `${EmployeeMaster}` |

เมื่อ processor ทำงาน มันจะแทนที่ placeholder นี้ด้วย **detail sheet** ที่มีหนึ่งแถวต่อพนักงานหนึ่งคน

> **Why:** placeholder บอก processor ว่าจะใส่ข้อมูลที่ไหน การใช้เทมเพลตแยกทำให้การจัดรูปแบบ (ฟอนต์, เส้นขอบ, ความกว้างคอลัมน์) ของคุณคงที่

### ขั้นตอน 3: กำหนดโมเดลข้อมูล

ด้านล่างเป็นคลาส `Employee` ขั้นต่ำและเมธอดช่วยเหลือที่สร้างรายการพนักงาน รายการนี้จะใช้เพื่อสาธิต **multiple sheets from list**.

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **Why:** วัตถุ Java ธรรมดา (POJO) จะแมปโดยตรงกับฟิลด์ของ Smart Marker (`firstName`, `lastName`, `department`). สิ่งนี้ทำให้การ **populate excel workbook** ง่ายและปลอดภัยต่อประเภท

### ขั้นตอน 4: ตั้งค่า SmartMarkerProcessor

ตอนนี้เราจะเชื่อมทุกอย่าง together. processor จะอ่านเทมเพลต, แทนที่ marker, และสร้างชีทใหม่ชื่อ `EmployeeDetail`.

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

**คำอธิบายของบรรทัดสำคัญ**

| Line | Reason |
|------|--------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | โหลดเทมเพลตที่มี placeholder ของ Smart Marker อยู่แล้ว. |
| `data.put("EmployeeMaster", employees);` | ผูกรายการ Java กับ marker `${EmployeeMaster}`. |
| `processor.setDetailSheetNewName("EmployeeDetail");` | ตั้งชื่อชีทที่สร้างใหม่ให้มีความหมายแทนค่าเริ่มต้น `Sheet1`. |
| `processor.process(wb, data);` | **How to generate worksheets** – processor อ่าน marker, สร้างชีทใหม่, และเติมแถวสำหรับแต่ละ `Employee`. |
| `wb.save("EmployeesReport.xlsx");` | บันทึก **dynamic excel sheets** ลงดิสก์. |

### ขั้นตอน 5: ตรวจสอบผลลัพธ์

เปิดไฟล์ `EmployeesReport.xlsx` คุณควรเห็น worksheets สองชีท:

1. **Sheet1** – เทมเพลตต้นฉบับ (สามารถซ่อนหรือเอาออกได้)  
2. **EmployeeDetail** – **dynamic excel sheet** ที่มีคอลัมน์ `firstName`, `lastName`, `department` และหนึ่งแถวต่อพนักงานหนึ่งคน

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **Why this matters:** ไฟล์ตอนนี้มี **multiple sheets from list** โดยไม่ต้องวนลูปหรือระบุเซลล์ด้วยตนเอง Engine ของ Smart Marker จะดูแลการสร้างแถว, การแปลงข้อมูล, และการสืบทอดการจัดรูปแบบ

### ขั้นตอน 6: จัดการกรณีขอบ

#### รายการข้อมูลว่าง

หาก `employees` ว่าง processor ยังสร้างชีท `EmployeeDetail` แต่จะปล่อยให้ว่างเปล่า คุณสามารถป้องกันไม่ให้เพิ่มชีทได้โดยตรวจสอบขนาดของคอลเลกชันก่อนประมวลผล:

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### รายการขนาดใหญ่มาก

สำหรับแถวหลายพันแถว ให้พิจารณาเพิ่มการจัดสรรหน่วยความจำ (`-Xmx2g`) หรือใช้ `processor.setAutoFitRows(false)` เพื่อเร่งการประมวลผล

#### การตั้งชื่อชีทแบบกำหนดเองต่อกลุ่ม

หากคุณต้องการชีทแยกสำหรับแต่ละแผนก คุณสามารถใช้ **multiple detail sheets**:

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

placeholder `${department}` จะถูกดึงจากแต่ละอ็อบเจ็กต์ `Employee` ทำให้สร้างชีทเช่น `Dept_Sales`, `Dept_Marketing` เป็นต้น
