# สร้างแผ่นรายละเอียดใน Java ด้วย Aspose.Cells smart markers

หากคุณต้อง **create detail sheets** ในแอปพลิเคชัน Java คำแนะนำนี้จะแสดงวิธีทำด้วย Aspose.Cells smart markers คุณจะได้เห็นตัวอย่างที่ทำงานได้เต็มรูปแบบซึ่ง **java create worksheets**, ดึง **sheet name from field**, และ **process data source** เพียงไม่กี่บรรทัดของโค้ด

คู่มือครอบคลุมทุกอย่างตั้งแต่การตั้งค่าโครงการจนถึงการบันทึกเวิร์กบุ๊กสุดท้าย เพื่อให้คุณสามารถคัดลอก‑วางโซลูชันนี้ลงในโปรเจกต์ของคุณและปรับใช้ได้ทันที ไม่ต้องอ้างอิงเอกสารภายนอก—ทุกอย่างที่คุณต้องการอยู่ที่นี่

## สิ่งที่คุณจะได้เรียนรู้

* วิธี **use smart markers** เพื่อทำสำเนาแผ่นเทมเพลตสำหรับแต่ละแถวในชุดข้อมูลหลัก  
* วิธีตั้งชื่อแผ่นใหม่แบบไดนามิกตามค่าฟิลด์ (เช่น `Order_123`)  
* วิธีส่งคอลเลกชัน Java เป็น **process data source** ให้กับเครื่องยนต์ smart marker  
* เคล็ดลับการจัดการกรณีขอบเช่น ข้อมูลว่าง, อักขระพิเศษในชื่อแผ่น, และการพิจารณาประสิทธิภาพสำหรับชุดข้อมูลขนาดใหญ่

### ข้อกำหนดเบื้องต้น

| ความต้องการ | เหตุผล |
|-------------|--------|
| Java 8 หรือสูงกว่า | Aspose.Cells for Java รองรับ Java 8+ |
| ระบบสร้าง Maven หรือ Gradle | ช่วยให้ง่ายต่อการเพิ่ม dependency ของ Aspose.Cells |
| ความรู้พื้นฐานเกี่ยวกับคอลเลกชัน Java | จำเป็นสำหรับการสร้างแหล่งข้อมูลให้กับ smart markers |
| ไฟล์เทมเพลต Excel (`Template.xlsx`) ที่มี smart marker ตัวแทนในเซลล์ **A1** | เทมเพลตเป็นตัวขับเคลื่อนการสร้างแผ่นรายละเอียด |

> **Pro tip:** เก็บไฟล์เทมเพลตเวิร์กบุ๊กไว้ในโฟลเดอร์ `resources` ของโปรเจกต์เพื่อให้รวมอยู่ในไฟล์ JAR ของคุณ

## ขั้นตอนที่ 1: เพิ่ม Aspose.Cells ไปยังโปรเจกต์ของคุณ (java create worksheets)

หากคุณใช้ **Maven** ให้เพิ่ม dependency ต่อไปนี้ใน `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

สำหรับ **Gradle** ให้ใส่บรรทัดนี้ใน `build.gradle`:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

บรรทัดเหล่านี้ทำให้ API **java create worksheets** พร้อมใช้งานในขั้นตอนคอมไพล์

## ขั้นตอนที่ 2: โหลดเวิร์กบุ๊กเทมเพลต

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*ทำไมจึงสำคัญ:* วัตถุ `Workbook` เป็นจุดเริ่มต้นสำหรับการทำงานกับ Excel ทั้งหมด การโหลดเทมเพลตทำให้คุณเริ่มต้นด้วยโครงร่างและการจัดรูปแบบที่กำหนดไว้ล่วงหน้า

## ขั้นตอนที่ 3: แทรก smart marker ที่สร้างแผ่นใหม่ต่อแต่ละแถวหลัก (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

ไวยากรณ์ `${Orders:DetailSheetNewName=Order_${OrderId}}` คือหัวใจของ **use smart markers** ซึ่งทำสามอย่าง:

1. วนซ้ำคอลเลกชัน `Orders`  
2. สร้าง **new worksheet** สำหรับแต่ละรายการ  
3. ตั้ง **sheet name from field** `OrderId` (โดยเพิ่มคำนำหน้า `Order_`)

## ขั้นตอนที่ 4: เตรียมแหล่งข้อมูล (process data source)

ด้านล่างเป็นตัวอย่างขั้นต่ำที่ใช้ `List<Map<String, Object>>` แทนที่ด้วยแหล่งข้อมูลจริงของคุณ—แถวฐานข้อมูล, การแปลง JSON ฯลฯ

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*ทำไมจึงสำคัญ:* ขั้นตอน **process data source** จะผูกคอลเลกชัน Java ของคุณกับเครื่องยนต์ smart marker คีย์ (`"Orders"`) ต้องตรงกับชื่อ smart marker อย่างแม่นยำ

## ขั้นตอนที่ 5: ประมวลผล smart markers (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

เมื่อเรียก `process` Aspose.Cells จะอ่านคอลเลกชัน `Orders` คัดลอกแผ่นเทมเพลตสำหรับแต่ละรายการ และเปลี่ยนชื่อแผ่นตามฟิลด์ `OrderId` นี่คือหัวใจของการใช้ **process data source**

## ขั้นตอนที่ 6: บันทึกเวิร์กบุ๊กพร้อมแผ่นรายละเอียดที่ทำซ้ำ

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

หลังจากรันเสร็จ คุณจะพบไฟล์ `DuplicatedDetailSheets.xlsx` ที่มี:

* `Sheet1` – เทมเพลตต้นฉบับ (ไม่เปลี่ยนแปลง)  
* `Order_101` – แผ่นรายละเอียดสำหรับออเดอร์แรก  
* `Order_102` – แผ่นรายละเอียดสำหรับออเดอร์ที่สอง

### ผลลัพธ์ที่คาดหวัง (ส่วนหนึ่ง)

| ชื่อแผ่น | A1 (smart marker) | เนื้อหาที่ได้ |
|----------|-------------------|-------------------|
| Order_101 | `${Orders:...}`   | เติมข้อมูลจาก `order1` |
| Order_102 | `${Orders:...}`   | เติมข้อมูลจาก `order2` |

เปิดไฟล์ใน Excel เพื่อตรวจสอบว่าแต่ละแผ่นมีชื่อถูกต้องและมีข้อมูลแถวที่สอดคล้องกัน

## การจัดการความแตกต่างและกรณีขอบทั่วไป

### แหล่งข้อมูลว่าง

หาก `orders` ว่าง เครื่องประมวลผล smart marker จะ **ไม่สร้าง worksheet ใหม่** เพื่อหลีกเลี่ยงเวิร์กบุ๊กเปล่า ให้เพิ่มการตรวจสอบ:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### อักขระพิเศษในชื่อแผ่น

ชื่อแผ่น Excel ไม่สามารถมี `\ / ? * [ ] :` ได้ ทำความสะอาดฟิลด์ก่อนใช้งาน:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### ชุดข้อมูลขนาดใหญ่

สำหรับแถวหลายพันรายการ ควรเพิ่มขนาด heap ของ JVM (`-Xmx2g`) และเรียก `workbook.calculateFormula()` หลังจากสร้างแผ่นทั้งหมดเสร็จเพื่อเพิ่มประสิทธิภาพ
