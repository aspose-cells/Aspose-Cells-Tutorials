# วิธีเปลี่ยนทิศทางของติ๊กบนแผนภูมิใน Java ด้วย Aspose.Cells

## วิธีเปลี่ยนทิศทางของติ๊กบนแผนภูมิใน Java
เพื่อแก้ไขทิศทางของป้ายกำกับติ๊ก คุณต้องโหลดเวิร์กบุ๊กเป้าหมาย ดึงแผนภูมิที่ต้องการ เข้าถึงแกนหมวดหมู่ของมัน และเรียก `setTickLabelDirection` พร้อมกับ `ChartTextDirectionType` ที่ต้องการ ลำดับขั้นตอนนี้ทำได้เพียงไม่กี่บรรทัดของโค้ด Java ทำให้การรวมเข้ากับกระบวนการอัตโนมัติที่มีอยู่เป็นเรื่องง่าย

1. โหลดเวิร์กบุ๊กที่มีแผนภูมิที่คุณต้องการแก้ไข.  
2. ดึงแผ่นงานและอ็อบเจ็กต์แผนภูมิตามดัชนีของมัน.  
3. เข้าถึงแกนหมวดหมู่ (`getCategoryAxis()`) และเรียก `setTickLabelDirection` พร้อมกับ `ChartTextDirectionType` ที่ต้องการ.  
4. บันทึกเวิร์กบุ๊กเป็นไฟล์ใหม่.

## คู่มือการใช้งาน

### การโหลดเวิร์กบุ๊กและแผนภูมิ
คลาส `Workbook` แทนไฟล์ Excel ทั้งไฟล์ในหน่วยความจำ คลาส `Worksheet` ให้คุณเข้าถึงแผ่นงานแต่ละแผ่น และคลาส `Chart` แทนแผนภูมิเฉพาะหนึ่ง.
```java
Workbook workbook = new Workbook("input.xlsx");               // 1️⃣ Load file
Worksheet sheet = workbook.getWorksheets().get(0);            // 2️⃣ First sheet
Chart chart = sheet.getCharts().get(0);                       // 3️⃣ First chart on the sheet
```

### การเปลี่ยนทิศทางของป้ายกำกับติ๊ก
`ChartAxis` ควบคุมคุณสมบัติเกี่ยวกับแกนทั้งหมด `ChartTextDirectionType` เป็น enumeration ที่กำหนดทิศทาง.
```java
ChartAxis categoryAxis = chart.getCategoryAxis();            // Access category axis
categoryAxis.setTickLabelDirection(ChartTextDirectionType.HORIZONTAL); // 4️⃣ Set direction
```

- `ChartTextDirectionType.HORIZONTAL` → ป้ายกำกับอ่านจากซ้ายไปขวา.  
- `ChartTextDirectionType.VERTICAL` → ป้ายกำกับอ่านจากบนลงล่าง.  
- `ChartTextDirectionType.ROTATED_45` → ป้ายกำกับหมุน 45° (มีในเวอร์ชันใหม่)

### การบันทึกเวิร์กบุ๊ก
หลังจากปรับแกนแล้ว ให้บันทึกการเปลี่ยนแปลง:
```java
workbook.save("output.xlsx", SaveFormat.XLSX);
```

**Q: ฉันสามารถหมุนป้ายกำกับติ๊กเป็นมุมใดก็ได้หรือไม่?**  
A: Aspose.Cells ปัจจุบันรองรับค่า enum ที่กำหนดไว้ล่วงหน้า (แนวนอน, แนวตั้ง, 45°). สำหรับมุมที่กำหนดเองคุณสามารถผสมการหมุนกับ `setTickLabelAlignment`.

A: ใช่. โหลดเวิร์กบุ๊กด้วย `new Workbook("file.xlsx", new LoadOptions(LoadFormat.XLSX) {{ setPassword("pwd"); }})`.

**Q: มีขีดจำกัดจำนวนแผนภูมิที่ฉันสามารถแก้ไขในเวิร์กบุ๊กหนึ่งได้หรือไม่?**

**Q: ฉันจะใช้ใบอนุญาตชั่วคราวในโปรแกรมอย่างไร?**

**Q: การเปลี่ยนทิศทางของติ๊กจะส่งผลต่อชุดข้อมูลที่มีอยู่หรือไม่?**  
A: ไม่. การดำเนินการนี้เปลี่ยนเฉพาะการแสดงผลของป้ายกำกับแกน; ค่าข้อมูลยังคงไม่เปลี่ยนแปลง.
