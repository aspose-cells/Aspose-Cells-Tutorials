# นำเข้าอ็อบเจ็กต์แบบกำหนดเองเข้าสู่ Excel ด้วย Aspose.Cells – คู่มือ Java

หากคุณต้องการ **นำเข้าอ็อบเจ็กต์แบบกำหนดเอง** ไปยังแผ่นงาน Excel คู่มือนี้จะพาคุณผ่านกระบวนการทั้งหมดโดยใช้ Aspose.Cells for Java คุณจะได้เห็นวิธี **นำเข้าข้อมูลไปยัง Excel** การใช้สไตล์หัวข้อแบบหนา และการสร้างไฟล์ `.xlsx` ที่พร้อมแชร์

การส่งออกข้อมูลแบบตารางจาก Java มักต้องเขียนเซลล์ทีละเซลล์ด้วยตนเอง ซึ่งทำให้เกิดข้อผิดพลาดและบำรุงรักษายาก โดยการใช้ API `importCustomObjects` คุณจะหลีกเลี่ยงโค้ดที่ซ้ำซ้อน รักษาโมเดลข้อมูลของคุณไว้ครบถ้วน และได้การควบคุมสไตล์อย่างละเอียด

ในบทแนะนำนี้คุณจะได้ทำ:

* สร้างรายการของอ็อบเจ็กต์ Java `Map` ที่จำลองตารางข้อมูลทั่วไป
* สร้างสไตล์หัวข้อที่สามารถนำกลับมาใช้ใหม่ได้ (ฟอนต์หนา) ด้วย Aspose.Cells
* นำเข้าอ็อบเจ็กต์แบบกำหนดเองเข้าสู่แผ่นงานพร้อมใช้สไตล์อาร์เรย์
* บันทึกเวิร์กบุ๊กลงดิสก์และตรวจสอบผลลัพธ์

ข้อกำหนดเบื้องต้นเพียงแค่สภาพแวดล้อมการพัฒนา Java (แนะนำ JDK 8+) และไลบรารี Aspose.Cells for Java

## สิ่งที่คุณต้องมี

| ข้อกำหนด | เหตุผล |
|-----------|--------|
| JDK 8 หรือใหม่กว่า | จำเป็นสำหรับการคอมไพล์และรันโค้ด Java |
| Aspose.Cells for Java (เวอร์ชันล่าสุด) | ให้บริการคลาส `Workbook`, `Worksheet` และ API การนำเข้า |
| IDE หรือเครื่องมือ build (เช่น Maven, Gradle) | ช่วยจัดการ dependencies และการรันโปรเจกต์ |
| สิทธิ์การเขียนในโฟลเดอร์สำหรับไฟล์ผลลัพธ์ | เวิร์กบุ๊กจะถูกบันทึกเป็น `ImportWithStyle.xlsx` |

เพิ่ม dependency ของ Aspose.Cells ลงใน `pom.xml` หากคุณใช้ Maven:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## ขั้นตอนที่ 1: เตรียมอ็อบเจ็กต์แบบกำหนดเองสำหรับการนำเข้า

ขั้นตอนแรกคือการสร้างคอลเลกชันที่แทนแถวที่คุณต้องการใส่ลงใน Excel ตัวอย่างนี้ใช้ `List<Map<String,Object>>` โดยแต่ละ `Map` ทำหน้าที่เป็นแถวที่มีชื่อคอลัมน์เป็นคีย์

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**ทำไมจึงสำคัญ:**  
`importCustomObjects` ต้องการอาร์เรย์ของอ็อบเจ็กต์ การใช้ `Map` ทำให้คุณรักษาชื่อคอลัมน์ไว้ ทำให้ Aspose.Cells สามารถแมปคีย์ไปยังเซลล์ได้โดยอัตโนมัติ วิธีนี้คล้ายกับ `DataTable` ใน .NET หรือ `ResultSet` จาก JDBC ทำให้โค้ดนำกลับไปใช้ใหม่ได้ง่ายในหลายโปรเจกต์

---

## ขั้นตอนที่ 2: กำหนดสไตล์หัวข้อเพื่อใช้ในการนำเข้า

แถวหัวข้อที่ชัดเจนช่วยเพิ่มความอ่านง่าย Aspose.Cells ให้คุณสร้างอ็อบเจ็กต์ `Style` ตั้งค่าให้ฟอนต์เป็นหนา และส่งผ่านอาร์เรย์ `ImportTableOptions`

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**ทำไมจึงสำคัญ:**  
หากคุณละเว้นอาร์เรย์สไตล์ แถวหัวข้อจะใช้ฟอนต์เริ่มต้นซึ่งอาจไม่โดดเด่น การเตรียมสไตล์ไว้ครั้งเดียวช่วยลดการเรียกใช้ซ้ำสำหรับแต่ละแถวและทำให้โลจิกการนำเข้าเรียบง่ายขึ้น

---

## ขั้นตอนที่ 3: นำเข้าอ็อบเจ็กต์แบบกำหนดเองพร้อมอาร์เรย์สไตล์

ตอนนี้คุณรวมข้อมูลและสไตล์เข้าด้วยกัน แล้วเรียก `importCustomObjects` วิธีนี้จะวางข้อมูลเริ่มจากมุมบน‑ซ้าย (แถว 0, คอลัมน์ 0) และใช้สไตล์หัวข้อโดยอัตโนมัติ

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**ทำไมจึงสำคัญ:**  
`importCustomObjects` จะวิเคราะห์แต่ละ `Map` สร้างคอลัมน์ตามคีย์ (`Name`, `Score`) แล้วเขียนค่าลงในเซลล์ที่ตรงกัน `ImportTableOptions` บอก Aspose.Cells ให้ใช้ `styleArray` สำหรับแถวแรก ทำให้คุณได้หัวข้อหนาโดยไม่ต้องเขียนโค้ดเพิ่มเติม

---

## ขั้นตอนที่ 4: บันทึกเวิร์กบุ๊กและตรวจสอบผลลัพธ์

สุดท้ายให้เขียนเวิร์กบุ๊กลงไฟล์ ไฟล์ Excel ที่สร้างขึ้นจะมีแถวหัวข้อที่มีสไตล์ตามที่กำหนดและตามด้วยแถวข้อมูล

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**ผลลัพธ์ที่คาดหวัง:**  

| **Name** | **Score** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

เซลล์หัวข้อ (`Name`, `Score`) จะปรากฏเป็นฟอนต์หนา ตรงกับสไตล์ที่กำหนดในขั้นตอนที่ 2

---

## ความแตกต่างทั่วไปและกรณีขอบ

| สถานการณ์ | การปรับแนะนำ |
|-----------|--------------|
| **ลำดับคอลัมน์ที่แตกต่าง** | ตรวจสอบให้แน่ใจว่าคีย์ใน `Map` ถูกใส่ตามลำดับที่ต้องการ หรือใช้ POJO ที่มีฟิลด์ที่กำหนดด้วย annotation และอาร์เรย์ `PropertyDescriptor` |
| **ชุดข้อมูลขนาดใหญ่ (>10 000 แถว)** | เพิ่มค่า `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` เพื่อหลีกเลี่ยง `OutOfMemoryError` |
| **รูปแบบตัวเลขแบบกำหนดเอง** | เพิ่ม `Style` ตัวที่สองใน `styleArray` สำหรับแถวข้อมูล เช่น ตั้ง `NumberFormat` เป็น `"0"` สำหรับคะแนนเป็นจำนวนเต็ม |
| **หลายแผ่นงาน** | เรียก `importCustomObjects` บนแต่ละแผ่นงานเป้าหมาย ปรับแถว/คอลัมน์เริ่มต้นตามต้องการ |
| **ข้อความหัวข้อเฉพาะโลคัล** | เติมแถวหัวข้อด้วยตนเองก่อนการนำเข้า แล้วใช้สไตล์กับช่วงทั้งหมดโดยใช้ `Cells.applyStyle` |

## เคล็ดลับระดับมืออาชีพสำหรับการส่งออก Java ไปยัง Excel อย่างมั่นคง

* **ใช้เวิร์กบุ๊กชั่วคราวซ้ำ** – การสร้าง `Workbook` ใหม่สำหรับแต่ละสไตล์เพิ่มภาระงาน ควรใช้อินสแตนซ์เดียวหากต้องการหลายสไตล์ |
* **ตรวจสอบข้อมูลก่อนนำเข้า** – ค่าที่เป็น `null` ใน `Map` จะกลายเป็นเซลล์ว่าง คุณสามารถแทนที่ด้วยค่าเริ่มต้นได้โดยการพรี‑โปรเซสรายการ |
* **ปิดทรัพยากร** – แม้ว่า Aspose.Cells จะจัดการหน่วยความจำภายในแล้ว แต่การเรียก `workbook.dispose()` หลังบันทึกจะปล่อยทรัพยากรเนทีฟอย่างรวดเร็ว |
* **ตั้งค่า `Workbook.setForceFullCalculation(true)`** หากเวิร์กบุ๊กของคุณมีสูตรที่ต้องคำนวณก่อนบันทึก |
