# วิธีสร้าง Excel workbook ใน Java ด้วยข้อมูล JSON

หากคุณต้องการ **create Excel workbook java** นักพัฒนามักเผชิญความท้าทายในการโหลดข้อมูล JSON ลงในสเปรดชีต คู่มือฉบับนี้จะแสดงวิธี **populate Excel from JSON** รวมถึงวิธี **convert JSON array excel** และ **populate workbook from json** อย่างเป็นระบบและทำซ้ำได้ง่าย

การทำงานกับ JSON เป็นเรื่องปกติเมื่อบริการให้ข้อมูลผ่าน REST APIs และ Excel ยังคงเป็นรูปแบบหลักสำหรับการรายงานและการวิเคราะห์ เมื่อจบบทเรียนนี้คุณจะมีโปรแกรม Java ที่สามารถทำงานได้จริงซึ่ง:

* สร้าง Excel workbook ใหม่,
* อ่าน JSON array (หรือโครงสร้าง JSON ใด ๆ) แล้วเขียนค่าลงในเซลล์,
* บันทึกไฟล์ลงดิสก์พร้อมใช้ต่อในกระบวนการต่อไป

ไม่ต้องใช้เครื่องมือภายนอกเพิ่มเติม นอกจากไลบรารี Aspose.Cells for Java ซึ่งให้ `SmartMarkerProcessor` ที่ใช้ในโค้ดตัวอย่าง

## Prerequisites

ก่อนเริ่มทำโปรเจกต์ ตรวจสอบว่าคุณมี:

| Prerequisite | Reason |
|--------------|--------|
| Java Development Kit (JDK) ≥ 8 | จำเป็นสำหรับคอมไพล์และรันตัวอย่าง |
| Maven หรือ Gradle (optional) | ช่วยจัดการ dependency ได้ง่ายขึ้น |
| Aspose.Cells for Java (v23.10 หรือใหม่กว่า) | มีคลาส `Workbook` และ `SmartMarkerProcessor` |
| ความรู้พื้นฐานเกี่ยวกับ JSON และ Java I/O | ช่วยให้เข้าใจการไหลของข้อมูล |

หากคุณไม่ต้องการใช้เครื่องมือสร้าง โปรเจกต์ สามารถดาวน์โหลด Aspose.Cells JAR จาก [Aspose website](https://products.aspose.com/cells/java/) แล้วเพิ่มลงใน classpath ของโปรเจกต์ด้วยตนเอง

## Step 1: Set up the project and add the Aspose.Cells dependency

### Maven users

เพิ่ม dependency ต่อไปนี้ในไฟล์ `pom.xml` ของคุณ:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Gradle users

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

หากคุณไม่ได้ใช้เครื่องมือสร้างใด ๆ ให้วาง JAR ที่ดาวน์โหลดไว้ในโฟลเดอร์ `libs/` แล้วใส่ไว้ใน classpath ขณะคอมไพล์:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## Step 2: Create a new workbook and configure the SmartMarker processor

`SmartMarkerProcessor` ทำให้การแมปค่า JSON ไปยังเซลล์ Excel ง่ายขึ้น โดยการเรียก `setArrayAsSingle(true)` เราบอกให้ตัวประมวลผลถือ JSON array ทั้งหมดเป็นค่าเดียว ซึ่งมีประโยชน์เมื่อคุณต้องการให้แต่ละองค์ประกอบอยู่ในเซลล์ของแถวเดียวกัน

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**Why this matters:**  
การสร้าง workbook ล่วงหน้าจะให้พื้นที่ทำงานที่สะอาด การตั้งค่า `setArrayAsSingle(true)` ป้องกันไม่ให้ตัวประมวลผลแปลง array ให้เป็นสตริงเดียว (เช่น `["A","B","C"]`) และทำให้คุณควบคุมการจัดวางได้ด้วยตนเอง

## Step 3: Define the JSON data you want to insert

สำหรับบทเรียนนี้เราจะใช้ JSON array ง่าย ๆ แต่แนวทางเดียวกันใช้ได้กับอ็อบเจ็กต์, nested arrays หรือโครงสร้างที่ซับซ้อน

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**Tip:** หาก JSON ของคุณมาจากไฟล์หรือ endpoint ของ REST ให้แทนสตริงลิเทรัลด้วย `String` ที่อ่านจากแหล่งนั้น เช่น `Files.readString(Paths.get("data.json"))`

## Step 4: Process the workbook with the JSON data

ต่อไปเราจะให้ `SmartMarkerProcessor` แมป JSON array ไปยัง worksheet แรก พฤติกรรมเริ่มต้นจะเขียนแต่ละองค์ประกอบลงในเซลล์ต่อเนื่องโดยเริ่มที่ `A1`

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

เบื้องหลัง Aspose.Cells จะทำการพาร์ส JSON, สร้างตารางข้อมูลชั่วคราว, แล้วเขียนค่าเหล่านั้นลงใน worksheet เนื่องจากเราได้ตั้งค่า `ArrayAsSingle` เป็น `true` องค์ประกอบของ array จะถูกจัดวางในแนวนอนบนแถวแรก

## Step 5: Save the workbook to a file

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

เมื่อรันโปรแกรม คุณควรเห็นไฟล์ชื่อ **CreatedFromJson.xlsx** ในไดเรกทอรีทำงานของคุณ การเปิดไฟล์ด้วย Excel (หรือโปรแกรมดูที่รองรับ) จะได้ผลลัพธ์ดังนี้:

| A | B | C |
|---|---|---|
| A | B | C | *(ค่าปรากฏในเซลล์ A1, B1, C1)*

### Expected output

```
Workbook saved to CreatedFromJson.xlsx
```

และแผ่น Excel จะมีลักษณะดังนี้:

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## Step 6: Handling more complex JSON structures (optional)

### 6.1 Populating a workbook from a JSON object

หาก JSON ของคุณเป็นอ็อบเจ็กต์แทน array คุณยังสามารถใช้ `SmartMarkerProcessor` ได้ ตัวอย่างเช่น:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

ตัวประมวลผลจะสร้าง named ranges (`title`, `month`, `values`) ที่คุณสามารถอ้างอิงในเทมเพลต Excel ด้วย Smart Markers เช่น `&=title` และ `&=values`

### 6.2 Converting a nested JSON array to a vertical list

บางครั้งคุณต้องการให้ array เติมลงในคอลัมน์แทนแถว ให้ตั้งค่าเซลล์เริ่มต้นด้วยตนเองก่อนทำการประมวลผล:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

ค่าที่เป็น **A**, **B**, **C** จะปรากฏในเซลล์ A2, A3, A4 ตามลำดับ

## Common pitfalls and how to avoid them

| Issue | Cause | Fix |
|-------|-------|-----|
| **Array written as a single string** | `setArrayAsSingle(false)` (ค่าเริ่มต้น) | เรียก `processor.setArrayAsSingle(true)` |
| **File not found when saving** | เส้นทางไม่ถูกต้องหรือไม่มีสิทธิ์เขียน | ใช้เส้นทางเต็มหรือให้แน่ใจว่าโฟลเดอร์มีอยู่ |
| **JSON parsing error** | สตริง JSON ผิดรูปแบบ | ตรวจสอบ JSON ด้วยเครื่องมือหรือใช้ไลบรารีเช่น Jackson เพื่อสร้างสตริง |
| **Cells overwritten unintentionally** | ประมวลผล worksheet เดียวหลายครั้งโดยไม่รีเซ็ตเซลล์เริ่มต้น | เรียก `processor.setStartCell("A1")` ก่อนแต่ละการเรียก `process` |

## Pro tip: reuse the workbook as a template

แทนที่จะสร้าง workbook ว่างใหม่ทุกครั้ง คุณสามารถโหลดเทมเพลตที่ออกแบบไว้ล่วงหน้า ซึ่งอาจมีหัวตาราง, สูตร, หรือสไตล์แล้ว:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

วิธีนี้ผสานความสวยงามของไฟล์ Excel ที่ทำด้วยมือกับการทำงานอัตโนมัติของ **populate workbook from json**
