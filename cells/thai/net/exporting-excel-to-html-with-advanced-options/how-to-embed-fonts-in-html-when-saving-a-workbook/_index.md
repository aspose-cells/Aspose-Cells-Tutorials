# วิธีฝังฟอนต์ใน HTML เมื่อบันทึกเวิร์กบุ๊ก

หากคุณต้องการ **วิธีฝังฟอนต์ใน HTML** ขณะส่งออกสเปรดชีต, บทแนะนำนี้จะแสดงวิธีแก้ปัญหาที่สมบูรณ์พร้อมใช้งาน ไม่ว่าคุณจะสร้างพอร์ทัลรายงานหรือมุมมองการวิเคราะห์ฝั่งไคลเอนต์ การฝังฟอนต์จะทำให้ HTML ที่แสดงผลตรงกับเวิร์กบุ๊กต้นฉบับอย่างแม่นยำ ไม่ขึ้นกับฟอนต์ที่ติดตั้งบนเครื่องของผู้ชม

คุณจะได้เรียนรู้วิธีที่ดีที่สุดในการ **บันทึกเวิร์กบุ๊กเป็น HTML** ด้วย Aspose.Cells, ดูข้อผิดพลาดทั่วไป, และรับเคล็ดลับในการจัดการเวิร์กบุ๊กขนาดใหญ่หรือไฟล์ฟอนต์แบบกำหนดเอง ไม่จำเป็นต้องอ้างอิงเอกสารภายนอก—ทุกอย่างที่คุณต้องการอยู่ในคู่มือนี้

## ข้อกำหนดเบื้องต้น

- .NET 6.0 หรือใหม่กว่า (โค้ดยังทำงานได้กับ .NET Framework 4.7+)
- ใบอนุญาต Aspose.Cells for .NET ที่ถูกต้อง (หรือคุณสามารถใช้โหมดประเมินผลฟรี)
- ความรู้พื้นฐานของ C# และ IDE เช่น Visual Studio 2022
- ไฟล์ฟอนต์ TrueType (.ttf) หรือ OpenType (.otf) ที่คุณต้องการฝัง (ต้องสามารถเข้าถึงได้จากกระบวนการที่กำลังทำงาน)

## ขั้นตอนที่ 1: ตั้งค่าโปรเจกต์และนำเข้า Aspose.Cells

สร้างแอปพลิเคชันคอนโซลใหม่และเพิ่มแพคเกจ NuGet ของ Aspose.Cells:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

จากนั้นเปิด **Program.cs** และเพิ่มคำสั่ง `using` ที่จำเป็น:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **เคล็ดลับ:** วางฟอนต์ที่กำหนดเองของคุณในโฟลเดอร์ชื่อ `fonts` ภายในรูทของโปรเจกต์ ซึ่งทำให้โซลูชันพกพาได้และอ้างอิงได้ง่ายในภายหลัง.

## ขั้นตอนที่ 2: สร้างหรือโหลดเวิร์กบุ๊ก

เพื่อการสาธิต เราจะสร้างเวิร์กบุ๊กง่าย ๆ พร้อมเซลล์ที่มีสไตล์บางส่วน:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **ทำไมเรื่องนี้สำคัญ:** หากคุณละเว้นสไตล์ที่กำหนดเอง HTML ที่ส่งออกจะกลับไปใช้ฟอนต์เริ่มต้นของเบราว์เซอร์ ทำให้วัตถุประสงค์ของ **วิธีฝังฟอนต์ใน HTML** สูญเสียไป

## ขั้นตอนที่ 3: กำหนดค่า `HtmlSaveOptions` เพื่อฝังฟอนต์

หัวใจของ **วิธีฝังฟอนต์ใน HTML** อยู่ในคลาส `HtmlSaveOptions` การตั้งค่า `EmbedFonts = true` จะบอก Aspose.Cells ให้ฝังฟอนต์ TrueType/OpenType ที่อ้างอิงไว้โดยตรงลงใน HTML ที่สร้างขึ้นเป็น Data URI ที่เข้ารหัสเป็น Base64

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### วิธีการทำงานของการฝังฟอนต์

เมื่อ `EmbedFonts` เป็น `true` Aspose.Cells จะสแกนการกำหนดสไตล์ของเวิร์กบุ๊ก, ค้นหาไฟล์ฟอนต์ที่สอดคล้องบนระบบ (หรือในโฟลเดอร์ `fonts` ที่คุณเพิ่ม), อ่านข้อมูลไบนารีของไฟล์เหล่านั้น, และแทรกบล็อก `<style>` ที่คล้ายกับ:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

เนื่องจากข้อมูลฟอนต์ถูกเข้ารหัสโดยตรงใน HTML หน้าเว็บจึงแสดงผลได้อย่างถูกต้องแม้บนเครื่องที่ไม่ได้ติดตั้งฟอนต์นั้น

## ขั้นตอนที่ 4: บันทึกเวิร์กบุ๊กเป็น HTML

ตอนนี้คุณสามารถ **บันทึกเวิร์กบุ๊กเป็น HTML** ด้วยตัวเลือกที่กำหนดไว้แล้ว เลือกไดเรกทอรีที่แอปพลิเคชันสามารถเขียนได้ (เช่น `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

การรันโปรแกรมจะสร้างไฟล์ `report.html` เพียงไฟล์เดียว เปิดไฟล์นี้ในเบราว์เซอร์สมัยใหม่ใดก็ได้ คุณจะเห็นหัวข้อ “Quarterly Sales” แสดงด้วยฟอนต์ **Pacifico** แม้ว่าฟอนต์นั้นจะไม่ได้ติดตั้งบนระบบปฏิบัติการของคุณ

### ผลลัพธ์ที่คาดหวัง

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

แอตทริบิวต์ `src:` มีสตริง Base64 ยาว—นี่คือข้อมูลฟอนต์ที่ฝังไว้ซึ่งทำให้ **วิธีฝังฟอนต์ใน HTML** ทำงานได้

## ขั้นตอนที่ 5: ตรวจสอบการฝังฟอนต์และแก้ไขปัญหา

1. **เปิดไฟล์ HTML ใน Chrome หรือ Edge.** หากฟอนต์ที่กำหนดเองปรากฏ การฝังฟอนต์สำเร็จ.  
2. **ตรวจสอบซอร์สของหน้า.** มองหา rule `@font-face` ที่สร้างโดย Aspose.Cells.  
3. **ปัญหาทั่วไป:**  
   - *ไฟล์ฟอนต์หาย:* ตรวจสอบให้แน่ใจว่าไฟล์ฟอนต์สามารถเข้าถึงได้ คุณสามารถเพิ่มโฟลเดอร์ไปยังเส้นทางค้นหาโดยชัดเจน:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *ขนาด HTML ใหญ่:* การฝังฟอนต์หลายตัวอาจทำให้ไฟล์บวม ใช้ `ExportToSingleFile = false` เพื่อเก็บฟอนต์เป็นไฟล์ `.ttf` แยกในโฟลเดอร์ resources.  

   - *รูปแบบฟอนต์ที่ไม่รองรับ:* Aspose.Cells ฝังได้เฉพาะ TrueType (`.ttf`) และ OpenType (`.otf`) เท่านั้น ให้แปลงรูปแบบอื่นก่อนฝัง.

## ตัวอย่างทำงานเต็มรูปแบบ

ด้านล่างเป็นโปรแกรมเต็มที่คุณสามารถคัดลอก, วาง, และรันได้โดยไม่ต้องแก้ไข (ยกเว้นบรรทัดใบอนุญาตที่เป็นตัวเลือก).

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

การรันโปรแกรมนี้จะสร้าง `output/report.html` เปิดไฟล์นั้นและคุณจะเห็นฟอนต์ **Pacifico** แสดงอย่างถูกต้อง—แสดงให้เห็น **วิธีฝังฟอนต์ใน HTML** ขณะ **บันทึกเวิร์กบุ๊กเป็น HTML**.

## คำถามที่พบบ่อย

| คำถาม | คำตอบ |
|----------|--------|
| *ฉันสามารถฝังเฉพาะฟอนต์ที่ต้องการได้หรือไม่?* | ได้. ตั้งค่า `htmlOpt.EmbedAllFonts = false` (มีในเวอร์ชันใหม่) และใช้ `htmlOpt.FontsToEmbed` เพื่อระบุชื่อฟอนต์ที่ต้องการฝัง. |
| *ถ้าต้องการฝังฟอนต์สำหรับหลายแผ่นงานล่ะ?* | ตั้งค่า `ExportActiveWorksheetOnly = false` เพื่อให้ทุกแผ่นงานถูกส่งออก และ Aspose.Cells จะฝังฟอนต์ที่ใช้ในทั้งเวิร์กบุ๊ก. |
| *ฟอนต์ที่ฝังไว้จะทำงานบนเบราว์เซอร์มือถือหรือไม่?* | เบราว์เซอร์มือถือสมัยใหม่รองรับฟอนต์ที่เข้ารหัสเป็น Base64 ดังนั้นฟอนต์ที่ฝังจะเรนเดอร์ได้อย่างถูกต้องตราบใดที่รูปแบบฟอนต์ได้รับการสนับสนุน (TTF หรือ OTF). |
| *ไฟล์ HTML จะใหญ่ขนาดไหนได้บ้าง?* | การฝังฟอนต์ TrueType ขนาด 200 KB จะเพิ่มขนาดไฟล์ HTML ประมาณเท่าเดิม (Base64 เพิ่ม ~33 % ของขนาด). หากมีหลายฟอนต์ ควรพิจารณาส่งออกเป็นโฟลเดอร์ (`ExportToSingleFile = false`) เพื่อให้ไฟล์ HTML มีขนาดเบา. |
