# วิธีฝังฟอนต์เมื่อบันทึก Excel เป็น HTML ด้วย C#

การฝังฟอนต์เมื่อบันทึกเวิร์กบุ๊ก Excel เป็น HTML เป็นความต้องการทั่วไปเพื่อรักษลักษณะการแสดงผลที่ตรงกันของสเปรดชีตของคุณบนเบราว์เซอร์ต่าง ๆ หากคุณต้องการส่งออก Excel เป็น HTML พร้อมคงฟอนต์เดิมไว้ คำแนะนำนี้จะแสดงวิธีแก้ไขที่สมบูรณ์พร้อมรันได้ทันที

คุณจะได้เรียนรู้วิธี **export Excel to HTML**, **convert Excel to HTML** พร้อมฝังฟอนต์ และหลีกเลี่ยงปัญหา “missing‑font” ที่ทำให้การจัดวางเสียหายบนเครื่องของผู้ใช้ ไม่ต้องใช้เครื่องมือภายนอก—เพียงแค่ไลบรารี Aspose.Cells และบรรทัดโค้ด C# ไม่กี่บรรทัด

## ข้อกำหนดเบื้องต้น

ก่อนเริ่มทำงาน โปรดตรวจสอบว่าคุณมี:

* .NET 6.0 (หรือใหม่กว่า) ที่ติดตั้งแล้ว  
* สำเนา **Aspose.Cells for .NET** ที่มีลิขสิทธิ์ – เวอร์ชันทดลองฟรีสามารถใช้ทดสอบได้  
* IDE เช่น Visual Studio 2022 หรือ VS Code  

หากคุณมีทั้งหมดนี้แล้ว สามารถข้ามไปยังขั้นตอนโค้ดได้ทันที

## ขั้นตอนที่ 1: สร้างเวิร์กบุ๊กและเพิ่มข้อมูลตัวอย่าง

ก่อนอื่นเราจะสร้างเวิร์กบุ๊กขนาดเล็กเพื่อให้คุณเห็นผลของการฝังฟอนต์ โค้ดด้านล่างจะสร้างแผ่นงาน เขียนข้อมูลในเซลล์บางส่วน และกำหนดฟอนต์แบบกำหนดเอง

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### ทำไมต้องเพิ่มฟอนต์แบบกำหนดเอง

การฝังฟอนต์มีความสำคัญเมื่อเวิร์กบุ๊กใช้ฟอนต์ที่อาจไม่มีอยู่บนอุปกรณ์ของผู้ใช้ โดยการตั้งค่า **Arial** (หรือฟอนต์อื่น) อย่างชัดเจน เราสามารถตรวจสอบได้ว่าเอาต์พุต HTML จริง ๆ มีข้อมูลฟอนต์อยู่หรือไม่

## ขั้นตอนที่ 2: กำหนดค่า HTML Save Options เพื่อฝังฟอนต์

Aspose.Cells มีคลาส `HtmlSaveOptions` การตั้งค่า `EmbedFonts = true` จะบอกไลบรารีให้ฝังไฟล์ฟอนต์ที่จำเป็นโดยตรงลงใน HTML ที่สร้างขึ้นเป็น Data URI ที่เข้ารหัสเป็น Base64

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### สิ่งที่ “embed fonts in html” ทำจริง ๆ

เมื่อ `EmbedFonts` เป็น true, Aspose.Cells จะดึงไฟล์ฟอนต์จากระบบ (หรือจากคอลเลกชันฟอนต์ที่ฝังอยู่ในเวิร์กบุ๊ก) แล้วแปลงเป็นสตริง **Base64** สตริงเหล่านี้จะถูกใส่ไว้ในบล็อก `<style>` ด้วย `@font-face` HTML ที่ได้จึงสามารถเปิดได้บนอุปกรณ์ใด ๆ โดยไม่ต้องติดตั้งฟอนต์ต้นฉบับ

## ขั้นตอนที่ 3: บันทึกเวิร์กบุ๊กเป็น HTML พร้อมฝังฟอนต์

ต่อไปเราจะเขียนเวิร์กบุ๊กลงดิสก์ ไฟล์จะบรรจุข้อมูลฟอนต์ไว้ ดังนั้นการเปิดไฟล์ในเบราว์เซอร์สมัยใหม่ใดก็จะแสดงตัวอักษรที่ตรงกับไฟล์ Excel ดั้งเดิม

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### ผลลัพธ์ที่คาดหวัง

* `embedded.html` อยู่ในโฟลเดอร์ `output`  
* การเปิดไฟล์ใน Chrome, Edge หรือ Firefox จะแสดงแผ่นงานพร้อมข้อความ **Arial** แม้ว่าคอมพิวเตอร์ของเบราว์เซอร์จะไม่มี Arial  
* การตรวจสอบซอร์ส HTML จะพบบล็อก `<style>` ที่มีกฎ `@font-face` พร้อมการประกาศ `src: url(data:font/ttf;base64,…)` ยาว – นั่นคือฟอนต์ที่ฝังไว้  

## ขั้นตอนที่ 4: ตรวจสอบว่า HTML ทำงานบนเครื่องอื่น (ไม่บังคับ)

เพื่อให้แน่ใจว่าการฝังสำเร็จ:

1. คัดลอก `output/embedded.html` ไปยังคอมพิวเตอร์เครื่องอื่น (หรือเครื่องเสมือน) ที่ **ไม่มี** ฟอนต์ที่กำหนดไว้ติดตั้ง  
2. เปิดไฟล์ในเบราว์เซอร์  
3. การจัดวางและการพิมพ์ควรตรงกับมุมมอง Excel ดั้งเดิม  

หากฟอนต์ถอยกลับไปเป็นฟอนต์ทั่วไป ให้ตรวจสอบว่าไฟล์ฟอนต์สามารถเข้าถึงได้บนเครื่องที่ทำการสร้างและคุณมีสิทธิ์อ่านไฟล์นั้นหรือไม่

## คำถามทั่วไปและกรณีขอบ

### การฝังฟอนต์ทำให้ไฟล์ใหญ่ขึ้นหรือไม่?

ใช่ การฝังฟอนต์ TrueType หรือ OpenType สามารถเพิ่ม **หลายสิบกิโลไบต์** ให้กับไฟล์ HTML สำหรับเวิร์กบุ๊กขนาดใหญ่ที่มีฟอนต์หลายแบบ ควรพิจารณา:

* การทำ subset ฟอนต์ (เฉพาะอักขระที่ใช้) – Aspose.Cells ทำโดยอัตโนมัติสำหรับฟอนต์ทั่วไปส่วนใหญ่  
* ใช้ `ExportEmbeddedImages = false` หากไม่ต้องการฝังรูปภาพ  

### หากต้องการฝังเฉพาะฟอนต์บางตัวจะทำอย่างไร?

`HtmlSaveOptions` ไม่ได้เปิดให้กำหนด whitelist โดยตรง แต่คุณสามารถควบคุมฟอนต์ที่ปรากฏได้โดย **จำกัดฟอนต์ที่ใช้ในเวิร์กบุ๊ก** ก่อนเรียก `Save` ลบการกำหนดฟอนต์ที่ไม่จำเป็นหรือเปลี่ยนเป็นฟอนต์เว็บ‑เซฟมาตรฐาน  

### สามารถฝังฟอนต์เมื่อแปลงเป็นรูปแบบอื่น (เช่น PDF) ได้หรือไม่?

คุณสมบัติ `EmbedFonts` มีอยู่ใน `PdfSaveOptions` ด้วย แนวคิดเดียวกัน: ฝังข้อมูลฟอนต์เพื่อให้ PDF แสดงผลได้อย่างถูกต้องบนโปรแกรมอ่านใด ๆ  

## ตัวอย่างเต็มที่สามารถรันได้

ด้านล่างเป็นโปรแกรมสมบัติที่คุณสามารถคัดลอก‑วางลงในโปรเจกต์คอนโซลใหม่ได้

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

การรันโปรแกรมจะสร้าง **ไฟล์ HTML ที่บรรจุฟอนต์ Arial** ทำให้มั่นใจว่าการแสดงผลจะเหมือนเดิมไม่ว่าที่ใดก็ตามที่เปิดไฟล์

## สรุป

คุณได้เรียนรู้ **วิธีฝังฟอนต์เมื่อบันทึก Excel เป็น HTML** ด้วย C# โดยตั้งค่า `HtmlSaveOptions.EmbedFonts = true` คุณสามารถ **export Excel to HTML** และ **convert Excel to HTML** ได้อย่างมั่นใจโดยไม่ต้องกังวลเรื่องฟอนต์หายบนเครื่องผู้ใช้ เทคนิคนี้จำเป็นสำหรับการรายงานบนเว็บ, แดชบอร์ดที่ส่งอีเมลได้, หรือสถานการณ์ใด ๆ ที่คุณต้องการแชร์เนื้อหาจาก Excel ในรูปแบบ HTML

### ขั้นตอนต่อไป

* **ฝังรูปภาพ** อย่างเลือกสรรโดยสลับ `ExportEmbeddedImages`

ลองทดลองใช้ฟอนต์ต่าง ๆ, แผ่นงานขนาดใหญ่, หรือเวิร์กบุ๊กหลายแผ่น ฟลัก `EmbedFonts` ทำงานในทุกรูปแบบเอาต์พุตที่รองรับ ให้คุณควบคุมการฝังฟอนต์ได้อย่างสม่ำเสมอในทุกที่ที่ต้องการ Happy coding!
