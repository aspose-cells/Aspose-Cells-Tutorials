# วิธีส่งออกตาราง Pivot เป็นภาพโดยใช้ Aspose.Cells ใน C#

หากคุณต้องการ **how to export pivot** ข้อมูลเป็นรูปภาพที่พกพาได้ Aspose.Cells ทำให้กระบวนการนี้ง่ายดาย คู่มือนี้จะแสดงให้คุณเห็นอย่างชัดเจนว่าการส่งออกตาราง Pivot เป็นไฟล์ PNG ทำได้อย่างไร เพื่อให้คุณสามารถฝังภาพเหล่านี้ในรายงาน อีเมล หรือเอกสารโดยไม่ต้องใช้ Excel บนเครื่องเป้าหมาย

การส่งออก Pivot เป็นภาพช่วยขจัดปัญหาการจัดรูปแบบที่ขึ้นกับเวอร์ชันและทำให้ผู้มีส่วนได้ส่วนเสียที่ไม่ใช่เทคนิคสามารถดูการวิเคราะห์ได้ทันที เราจะครอบคลุมทุกอย่างตั้งแต่การตั้งค่าโครงการจนถึงการเรนเดอร์ **export pivot table image** สุดท้าย และเรายังจะอธิบายวิธี **save pivot as image** เพื่อการใช้ซ้ำในอนาคต

## วิธีส่งออกตาราง Pivot เป็นภาพด้วย Aspose.Cells

ด้านล่างเป็นตัวอย่างที่สมบูรณ์และสามารถรันได้ ซึ่งโหลด workbook, รีเฟรช pivot, ตั้งค่าตัวเลือกภาพ และเขียนไฟล์ผลลัพธ์ แต่ละขั้นตอนมีคำอธิบายสั้น ๆ เพื่อให้คุณเข้าใจ *ทำไม* โค้ดถึงเขียนเช่นนั้น ไม่ใช่แค่ *อะไร* ที่มันทำ

### 1. ตั้งค่าสภาพแวดล้อม Aspose.Cells

1. ติดตั้งแพ็กเกจ NuGet:

   ```bash
   dotnet add package Aspose.Cells
   ```

2. เพิ่ม `using` directives ที่จำเป็นที่ส่วนหัวของไฟล์ C# ของคุณ:

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **Pro tip:** ตั้งค่าเป้าหมายเป็น .NET 6 หรือใหม่กว่าเพื่อรับประโยชน์จากการปรับปรุงประสิทธิภาพล่าสุดใน Aspose.Cells.

### 2. โหลด workbook และค้นหาตาราง pivot

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*Why this matters:* คลาส `Workbook` จะทำการแยกไฟล์ XLSX และให้คุณเข้าถึง worksheets ทั้งหมด การเลือก worksheet ที่ถูกต้องเป็นสิ่งสำคัญเนื่องจาก workbook อาจมีหลาย pivot.

### 3. รีเฟรชตาราง pivot เพื่อดึงข้อมูลต้นทางล่าสุด

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

การรีเฟรชรับประกันว่าการเปลี่ยนแปลงใด ๆ ที่ทำกับช่วงข้อมูลต้นทางหลังจากไฟล์ถูกบันทึกจะสะท้อนในภาพที่เรนเดอร์ หากข้ามขั้นตอนนี้อาจทำให้ได้ภาพที่ล้าสมัยหรือไม่แม่นยำ

### 4. ตั้งค่าตัวเลือกการส่งออกภาพ (export pivot table image)

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

อ็อบเจ็กต์ `ImageOrPrintOptions` ให้คุณควบคุมรูปแบบ ความละเอียด และรายละเอียดการเรนเดอร์อื่น ๆ PNG เป็นตัวเลือกที่นิยมที่สุดสำหรับกราฟิกที่คมชัดและเข้ากันได้กับเว็บ แต่คุณสามารถเปลี่ยนเป็น `ImageFormat.Jpeg` หากขนาดไฟล์เป็นข้อกังวล

### 5. เรนเดอร์และ **save pivot as image**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

`RenderToImage` ทำหน้าที่หลัก: มันวาด pivot ให้เหมือนกับที่แสดงใน Excel และเขียนข้อมูล PNG แบบไบนารีลงดิสก์ เมธอดนี้คืนค่า `void` ดังนั้นคุณสามารถมั่นใจได้ว่าไฟล์จะมีอยู่หลังจากการเรียกเสร็จสมบูรณ์โดยไม่ต้องตรวจสอบเพิ่มเติม

#### ผลลัพธ์ที่คาดหวัง

หลังจากโปรแกรมทำงาน คุณจะพบไฟล์ `Pivot.png` ในโฟลเดอร์ที่ระบุ การเปิดไฟล์ควรแสดงภาพสแนปช็อตที่ตรงกับตาราง pivot ดั้งเดิม รวมถึงหัวคอลัมน์ ผลรวมแถว และการจัดรูปแบบใด ๆ ที่ได้กำหนดไว้

### 6. ความแตกต่างทั่วไปและกรณีขอบ

| Scenario | Adjustment |
|----------|------------|
| **Large pivots** (หลายแถว/หลายคอลัมน์) | เพิ่ม `HorizontalResolution` และ `VerticalResolution` เป็น 300 dpi เพื่อให้ผลลัพธ์คมชัดขึ้น. |
| **Custom styling** (สีพื้นหลัง, ฟอนต์) | ตรวจสอบให้แน่ใจว่าการกำหนดสไตล์ของ workbook ถูกโหลดก่อนเรียก `Refresh()`. |
| **Multiple pivots** ในแผ่นเดียว | วนลูปผ่าน `worksheet.PivotTables` และเรียก `RenderToImage` สำหรับแต่ละรายการโดยใช้ชื่อไฟล์ที่แตกต่างกัน. |
| **Export to JPEG** แทน PNG | เปลี่ยนเป็น `ImageFormat = ImageFormat.Jpeg` และอาจตั้งค่า `Quality` บนอ็อบเจ็กต์ `JpegSaveOptions`. |

ความแตกต่างเหล่านี้ทำให้คุณสามารถ **export pivot table image** ในรูปแบบที่ระบบปลายทางของคุณคาดหวังได้อย่างแม่นยำ

## โค้ดเต็มสำหรับคัดลอก‑วางอย่างรวดเร็ว

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

การรันโปรแกรมจะสร้างไฟล์ PNG ตามที่แสดงด้านบน เสร็จสิ้นกระบวนการ **save pivot as image** ภายในไม่กี่นาที

## สรุป

ตอนนี้คุณรู้แล้วว่า **how to export pivot** ตารางเป็นไฟล์ภาพโดยใช้ Aspose.Cells ใน C# คู่มือนี้ได้พาคุณผ่านการตั้งค่าห้องสมุด การโหลด workbook การรีเฟรช pivot การตั้งค่าตัวเลือก PNG และสุดท้ายการเรนเดอร์ **export pivot table image** พร้อมกับแสดงวิธี **save pivot as image** เพื่อการใช้ซ้ำในภายหลัง

ขั้นตอนต่อไปที่คุณอาจสำรวจ:

* **Batch export** – วนซ้ำผ่านตาราง pivot ทั้งหมดใน workbook และสร้างรายงาน PDF ที่ฝัง PNG แต่ละไฟล์.
* **Apply custom themes** – ปรับเปลี่ยนคอลเลกชันสไตล์ของ workbook ก่อนการเรนเดอร์เพื่อให้ตรงกับแบรนด์ขององค์กร.
* **Integrate with ASP.NET Core** – สร้าง PNG แบบเรียลไทม์และส่งกลับเป็นการตอบสนอง HTTP สำหรับแดชบอร์ดเว็บ.

อย่าลังเลที่จะทดลองกับรูปแบบภาพ ความละเอียด และสถานการณ์อัตโนมัติต่าง ๆ ขอให้สนุกกับการเขียนโค้ด!
