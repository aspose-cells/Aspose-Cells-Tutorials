# วิธีส่งออกข้อมูลไปยัง Excel ด้วยเทมเพลต C# – คู่มือขั้นตอนโดยละเอียด

หากคุณต้องการ **export data to Excel** จากแอปพลิเคชัน .NET คู่มือนี้จะแสดงวิธีแก้ไขแบบครบวงจรที่ทำงานตั้งแต่ต้นจนจบ โดยการโหลดเทมเพลต Excel ที่มีแท็ก Smart Marker อยู่แล้ว คุณสามารถ **automate Excel generation** และสร้าง **employee report Excel** ที่ดูเป็นมืออาชีพโดยไม่ต้องเขียนโค้ดแบบเซลล์ต่อเซลล์

คุณจะได้เรียนรู้วิธี:

* โหลดเทมเพลต Excel (`load excel template`) ที่กำหนดรูปแบบไว้
* ป้อนรายการอ็อบเจ็กต์พนักงานเข้าไปในเทมเพลต
* สร้างไฟล์เวิร์กบุ๊กขั้นสุดท้ายและบันทึกเป็น `output.xlsx`

โค้ดที่จำเป็นทั้งหมดรวมไว้แล้ว คุณสามารถคัดลอก วาง และรันได้ทันที

## Prerequisites

* .NET 6.0 หรือใหม่กว่า (โค้ดนี้ยังทำงานกับ .NET Framework 4.7+)
* แพคเกจ NuGet **Aspose.Cells for .NET** – ให้บริการ `Workbook`, `SmartMarkerProcessor` และการสนับสนุน Smart Marker
* โฟลเดอร์ชื่อ `YOUR_DIRECTORY` ที่มีไฟล์ `template.xlsx` เทมเพลตควรมีแท็ก Smart Marker เช่น `&=EmployeeList.Name` อยู่ในเซลล์ที่ต้องการให้แสดงข้อมูล

> **Pro tip:** เก็บเทมเพลตไว้ในโฟลเดอร์โปรเจกต์เดียวกันและตั้งค่า *Copy to Output Directory* เป็น *Copy always* เพื่อให้เส้นทางถูกต้องขณะดีบัก

## Full source code

```csharp
using System;
using System.Collections.Generic;
using Aspose.Cells;

namespace ExcelExportDemo
{
    // Simple POCO that represents an employee record
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Step 1: Load the Excel template that contains Smart Marker tags
            string templatePath = @"YOUR_DIRECTORY\template.xlsx";
            Workbook wb = new Workbook(templatePath);

            // Step 2: Prepare a data source – a list of employee objects
            List<Employee> employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Step 3: Create a SmartMarkerProcessor instance
            SmartMarkerProcessor sp = new SmartMarkerProcessor();

            // Step 4: Apply the employee data to the workbook using the processor
            // The tag &amp;=EmployeeList.Name in the template will be replaced with each employee's name,
            // and &amp;=EmployeeList.Position will be replaced with the corresponding position.
            sp.Process(wb, employeeList);

            // Step 5: Save the populated workbook
            string outputPath = @"YOUR_DIRECTORY\output.xlsx";
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

### What the code does

| ขั้นตอน | เหตุผลสำคัญ | บรรทัดสำคัญ |
|------|----------------|-------------|
| **โหลดเทมเพลต Excel** | การใช้เลเอาต์ที่ออกแบบไว้ล่วงหน้าช่วยประหยัดเวลาและรับประกันการจัดรูปแบบที่สม่ำเสมอ | `Workbook wb = new Workbook(templatePath);` |
| **เตรียมแหล่งข้อมูล** | Smart Markers ทำงานกับคอลเลกชัน `IEnumerable` ใดก็ได้; ในที่นี้เราใช้รายการ `Employee` | `List<Employee> employeeList = …` |
| **สร้างโปรเซสเซอร์** | `SmartMarkerProcessor` จะวิเคราะห์เทมเพลต ค้นหาแท็ก และใส่ข้อมูล | `SmartMarkerProcessor sp = new SmartMarkerProcessor();` |
| **ประมวลผลข้อมูล** | โปรเซสเซอร์จะแทนที่แต่ละแท็ก Smart Marker ด้วยค่าคุณสมบัติตรงกัน | `sp.Process(wb, employeeList);` |
| **บันทึกเวิร์กบุ๊ก** | ไฟล์สุดท้ายสามารถส่งให้ผู้ใช้ เก็บบนเซิร์ฟเวอร์ หรือแนบเป็นอีเมล | `wb.Save(outputPath);` |

ผลลัพธ์คือไฟล์ **employee report Excel** ที่แต่ละแถวมีชื่อและตำแหน่งของพนักงานตรงตามที่แท็กถูกวางไว้ในเทมเพลตต้นฉบับ

## Load an Excel template

เมื่อคุณ `load excel template` ด้วย `new Workbook(path)` Aspose.Cells จะอ่านเวิร์กบุ๊กทั้งหมดรวมถึงสไตล์ สูตร และตัวแทน Smart Marker วิธีนี้ดีกว่าการสร้างเวิร์กบุ๊กจากศูนย์ เพราะ:

* **การควบคุมการออกแบบ** – นักออกแบบสามารถจัดรูปแบบหัวตาราง เพิ่มโลโก้บริษัท และตั้งความกว้างของคอลัมน์โดยไม่ต้องแก้โค้ด
* **เวอร์ชัน** – การอัปเดตเทมเพลตไม่ต้องคอมไพล์แอปพลิเคชันใหม่
* **การแปลภาษา** – สามารถเก็บไฟล์เทมเพลตแยกตามภาษาต่าง ๆ ได้

หากคุณต้องการโซลูชัน .NET แบบบริสุทธิ์โดยไม่ใช้ไลบรารีของบุคคลที่สาม คุณอาจใช้ **ClosedXML** หรือ **EPPlus** แต่ไลบรารีเหล่านั้นไม่มีการสนับสนุน Smart Marker ในตัว ทำให้ต้องเขียนลูปคัดลอกข้อมูลเซลล์ต่อเซลล์เอง

## Automate Excel generation with Smart Markers

Smart Markers คือตัวแทนที่มีรูปแบบ `&=Collection.Property` เมื่อโปรเซสเซอร์ทำงาน:

* จะวนลูปผ่านคอลเลกชัน (`employeeList` ในตัวอย่างของเรา)
* สำหรับแต่ละรายการ จะเขียนค่าคุณสมบัติเข้าในเซลล์ที่สอดคล้องกัน
* ระบบจะขยายแถวหรือคอลัมน์โดยอัตโนมัติตามความจำเป็น

กลไกนี้ **automates Excel generation** และขจัดตรรกะการวนลูปด้วยตนเอง รูปแบบเดียวกันทำงานได้กับข้อมูลรูปแบบใด ๆ เช่น คำสั่งซื้อ ใบแจ้งหนี้ รายการสินค้าคงคลัง เป็นต้น

### Common variations

| รูปแบบ | วิธีทำ |
|-----------|------------------|
| **หลายคอลเลกชัน** | เพิ่มรายการอื่น ๆ (เช่น `List<Department>`) แล้วอ้างอิงด้วยแท็กต่าง ๆ เช่น `&=DepartmentList.Name` |
| **คอลเลกชันซ้อน** | ใช้โนเทชันแบบจุด: `&=EmployeeList.Projects.ProjectName` โดยที่ `Projects` เป็นคอลเลกชันภายใน `Employee` |
| **การจัดรูปแบบตามเงื่อนไข** | ใส่กฎการจัดรูปแบบตามเงื่อนไขในเทมเพลต; โปรเซสเซอร์จะคงกฎนั้นไว้สำหรับแถวที่สร้างขึ้น |

## Create an employee report Excel

คำว่า **employee report Excel** แสดงถึงกรณีการใช้งานธุรกิจทั่วไป: ผู้จัดการต้องการรายการพนักงานที่พิมพ์ได้ โดยการฝังแท็ก Smart Marker ลงในเทมเพลตโดยตรง คุณจะได้:

* แถวหัวตารางที่มีฟอนต์หนาและสีพื้นหลัง
* คอลัมน์ที่ปรับขนาดอัตโนมัติตามข้อมูล
* แถวสรุปเพิ่มเติม (เช่น จำนวนพนักงาน) ที่สามารถคำนวณด้วยสูตร Excel มาตรฐาน

หากต้องการเพิ่มแถวสรุป เพียงวางสูตรเช่น `=COUNTA(A2:A100)` ในเทมเพลต; โปรเซสเซอร์จะไม่ทำลายสูตรนั้น

## Generate Excel template C# – best practices

เมื่อคุณ **generate Excel template C#** ควรปฏิบัติตามแนวทางต่อไปนี้:

1. **Separate concerns** – แยกการโหลดเทมเพลต การเตรียมข้อมูล และการประมวลผลออกเป็นเมธอดต่างหาก ทำให้การทดสอบหน่วยง่ายขึ้น
2. **Validate input** – ตรวจสอบให้แน่ใจว่าไฟล์เทมเพลตมีอยู่และคอลเลกชันข้อมูลไม่เป็น `null` ก่อนเรียก `Process`
3. **Dispose resources** – แม้ Aspose.Cells จะจัดการหน่วยความจำเอง แต่ควรใส่ `Workbook` ในบล็อก `using` หากทำงานกับไฟล์ขนาดใหญ่
4. **Handle exceptions** – ใช้ `try‑catch` รอบ `sp.Process` เพื่อจับข้อผิดพลาดเช่นชื่อแท็กไม่ตรงกัน

```csharp
static Workbook LoadTemplate(string path)
{
    if (!File.Exists(path))
        throw new FileNotFoundException($"Template not found: {path}");
    return new Workbook(path);
}
```

## Troubleshooting common issues

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
|---------|--------------|-----|
| ไม่มีข้อมูลปรากฏหลังการประมวลผล | แท็ก Smart Marker พิมพ์ผิดหรือวางอยู่ในเซลล์ที่รวมกัน | ตรวจสอบว่าแท็กเป็นรูปแบบ `&=Collection.Property` อย่างถูกต้องและไม่ได้อยู่ในเซลล์ที่รวมกัน |
| ไฟล์ผลลัพธ์ว่างหรือเสียหาย | เวิร์กบุ๊กถูกบันทึกก่อนการประมวลผลเสร็จ | ตรวจสอบให้ `sp.Process` ทำงาน **ก่อน** `wb.Save` |
| รายการพนักงานขนาดใหญ่ทำให้การสร้างช้าลง | ใช้เวอร์ชันฟรีของ Aspose.Cells ที่มีข้อจำกัดด้านประสิทธิภาพ | อัปเกรดเป็นเวอร์ชันลิขสิทธิ์หรือประมวลผลข้อมูลเป็นชุด |
| เส้นทางเทมเพลตไม่ถูกต้อง | เส้นทางสัมพันธ์ถูกแปลงเป็นโฟลเดอร์อื่นขณะรัน | ใช้ `Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "template.xlsx")` หรือกำหนดคุณสมบัติ *Copy to Output Directory* ของไฟล์ |

## Complete example recap

ด้านล่างเป็นโปรแกรมทั้งหมดในบล็อกเดียวเพื่อคัดลอก‑วางอย่างรวดเร็ว:

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Load the template
            string templatePath = Path.Combine("YOUR_DIRECTORY", "template.xlsx");
            Workbook wb = new Workbook(templatePath);

            // Prepare data
            var employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Process Smart Markers
            var sp = new SmartMarkerProcessor();
            sp.Process(wb, employeeList);

            // Save the result
            string outputPath = Path.Combine("YOUR_DIRECTORY", "output.xlsx");
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

การรันโปรแกรมนี้จะสร้างไฟล์ **employee report Excel** ที่สามารถส่งอีเมล พิมพ์ หรือประมวลผลต่อได้
