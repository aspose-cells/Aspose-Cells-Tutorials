# วิธีสร้าง Excel workbook C# พร้อมการจัดรูปแบบแบบกำหนดเองและบันทึกเป็น XLSX

หากคุณต้องการ **สร้าง Excel workbook C#** ที่นำเข้าข้อมูล, ใช้รูปแบบตัวเลขแบบกำหนดเอง, และเปลี่ยนสีฟอนต์ของเซลล์, บทเรียนนี้จะแสดงให้คุณเห็นขั้นตอนอย่างละเอียด คุณจะได้ตัวอย่างที่พร้อมรันซึ่งสร้างไฟล์ `StyleArrayImport.xlsx` ที่มีการจัดรูปแบบภายในไม่กี่วินาที

การทำงานกับ Excel จาก C# มักต้องทำขั้นตอนซ้ำ ๆ ด้วยมือ—กำหนดรูปแบบ, ใส่สี, และจำต้องบันทึกไฟล์อย่างถูกต้อง จนกระทั่งจบคู่มือคุณจะสามารถทำงานเหล่านี้โดยอัตโนมัติทั้งหมด เพื่อให้คุณโฟกัสที่ข้อมูลแทน UI

คุณจะได้เรียนรู้วิธี:

* นำเข้า `DataTable` ไปยัง worksheet,
* ใช้ `StyleArray` เพื่อ **ใช้รูปแบบตัวเลขแบบกำหนดเอง** และ **เปลี่ยนสีฟอนต์ของเซลล์**,
* **บันทึก workbook เป็น XLSX** ด้วยการเรียกเมธอดเดียว,
* และตรวจสอบว่า **format imported data excel** ปรากฏตามที่ต้องการ

ข้อกำหนดเดียวที่ต้องมีคือการอ้างอิงไลบรารี **Aspose.Cells for .NET** (หรือ API ที่เข้ากันได้ซึ่งให้คลาส `Workbook`, `Worksheet`, และ `StyleArray`) โค้ดนี้ทำงานบน .NET 6+ แต่เวอร์ชันก่อนหน้าก็ใช้ได้ด้วยการปรับเล็กน้อย

## ขั้นตอนที่ 1: เตรียม DataTable ตัวอย่าง

ก่อนอื่นให้สร้าง `DataTable` ที่จำลองข้อมูลที่คุณมักจะดึงจากฐานข้อมูลหรือแหล่งอื่น ตารางนี้มีคอลัมน์ **Name** (string) และคอลัมน์ **Amount** (decimal) ที่เราจะจัดรูปแบบในขั้นตอนต่อไป

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**ทำไมจึงสำคัญ:** การใช้ `DataTable` ทำให้ตรรกะการนำเข้าแยกจากแหล่งข้อมูล ซึ่งเป็นแพทเทิร์นทั่วไปเมื่อสร้างรายงานจากฐานข้อมูล, ไฟล์ CSV, หรือ API

## ขั้นตอนที่ 2: กำหนด StyleArray เพื่อ **ใช้รูปแบบตัวเลขแบบกำหนดเอง** และ **เปลี่ยนสีฟอนต์ของเซลล์**

`StyleArray` ช่วยให้คุณรวมคำสั่งการจัดรูปแบบที่จะถูกนำไปใช้กับทุกเซลล์ที่นำเข้าจาก `DataTable` ในตัวอย่างนี้เราจะ:

* ตั้งค่า `Number` เป็น `#,##0.00` – รูปแบบบัญชีทั่วไปที่มีคั่นหลักพัน,
* ตั้งค่า `FontColor` เป็น `Color.Blue` – ทำให้ตัวเลขโดดเด่น

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**ทำไมต้องใช้ StyleArray?** การใช้สไตล์ขณะนำเข้าช่วยหลีกเลี่ยงการทำรอบที่สองบน worksheet ซึ่งทำให้ประสิทธิภาพดีขึ้นสำหรับชุดข้อมูลขนาดใหญ่

---

## ขั้นตอนที่ 3: **สร้าง Excel workbook C#** – สร้างอินสแตนซ์ Workbook และรับ Worksheet แรก

ตอนนี้เราจะสร้าง workbook ว่างและรับอ้างอิงไปยัง worksheet แรก (index 0) Worksheet นี้จะเป็นที่รับข้อมูลที่เรานำเข้า

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**คำอธิบาย:** `Workbook` แทนไฟล์ Excel ทั้งไฟล์, ส่วน `Worksheet` แทนแท็บเดียว ค่าเริ่มต้นของ workbook มีแผ่นเดียว ซึ่งเพียงพอสำหรับรายงานง่าย ๆ ส่วนใหญ่

## ขั้นตอนที่ 4: นำเข้า DataTable ด้วย **StyleArray** เพื่อ **จัดรูปแบบข้อมูลที่นำเข้าใน Excel**

เมธอด `ImportDataTable` คัดลอกแถวและคอลัมน์ของตารางไปยัง worksheet เริ่มที่เซลล์ `A1` (แถว 0, คอลัมน์ 0) อาร์กิวเมนต์ `true` บอกเมธอดให้รวมหัวคอลัมน์ด้วย เนื่องจากเราผ่าน `styleArray` ทุกเซลล์ที่นำเข้าจะได้รับรูปแบบตัวเลขและสีฟอนต์ที่กำหนด

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**สิ่งที่เกิดขึ้นเบื้องหลัง:** Aspose.Cells จะวนลูปแต่ละแถว, เขียนค่า, แล้วใช้สไตล์ที่กำหนดใน `styleArray` ตัวเลขจะแสดงด้วยคอมม่าและทศนิยมสองตำแหน่ง, ข้อความจะแสดงเป็นสีน้ำเงิน

## ขั้นตอนที่ 5: **บันทึก workbook เป็น XLSX** – เขียนไฟล์ลงดิสก์

สุดท้ายให้บันทึก workbook ไปเป็นไฟล์ `.xlsx` คุณสามารถเปลี่ยนพาธเป็นไดเรกทอรีที่เขียนได้บนเครื่องของคุณ

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**การตรวจสอบผลลัพธ์:** เปิดไฟล์ที่สร้างใน Excel คุณควรเห็นสามแถวของข้อมูล, คอลัมน์ **Amount** ถูกจัดรูปแบบด้วยคอมม่า, มีทศนิยมสองตำแหน่ง, และแสดงด้วยฟอนต์สีน้ำเงิน สิ่งนี้ยืนยันว่าขั้นตอน **format imported data excel** สำเร็จ

## ตัวอย่างทำงานเต็มรูปแบบ

คัดลอกบล็อกทั้งหมดด้านล่างไปยังโปรเจกต์คอนโซลใหม่และรัน ไม่ต้องเขียนโค้ดเพิ่มเติม

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**ผลลัพธ์ที่คาดว่าจะเห็นในคอนโซล:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

เปิดไฟล์และตรวจสอบว่าคอลัมน์ **Amount** แสดงค่าเช่น `1,234.56` ในฟอนต์สีน้ำเงิน

## คำถามที่พบบ่อย & กรณีขอบ

| คำถาม | คำตอบ |
|----------|--------|
| *ฉันสามารถใช้รูปแบบต่าง ๆ กับคอลัมน์แต่ละคอลัมน์ได้หรือไม่?* | ได้ หลังจากนำเข้าแล้วให้ดึงออบเจ็กต์ `Style` ของคอลัมน์ (`worksheet.Cells.Columns[1].Style`) แล้วตั้งค่า `Number` หรือ `FontColor` ที่ต้องการ |
| *ถ้าต้องการจัดรูปแบบวันที่แทนตัวเลขจะทำอย่างไร?* | ตั้งค่า `styleArray.Number = "mm-dd-yyyy"` และอาจตั้งค่า `styleArray.FontColor` สำหรับเซลล์วันที่ |
| *สีฟอนต์สีน้ำเงินมองเห็นได้ในธีม Excel สีเข้มหรือไม่?* | สีน้ำเงินอาจอ่านยากบนพื้นหลังสีเข้ม ใช้เฉดสีอ่อนกว่า (`Color.LightBlue`) หรือสีที่ตัดกัน (`Color.Black`) |
| *ฉันจะนำเข้า DataTable ขนาดใหญ่มาก (หลายแสนแถว) อย่างไร?* | ใช้ `ImportDataTable` กับ overload `ImportDataTableOptions` เพื่อสตรีมข้อมูล, หรือแยกการนำเข้าเป็นหลาย worksheet เพื่อไม่เกินขีดจำกัดแถวของ Excel (1,048,576 แถว) |
| *ฉันสามารถส่งออกเป็น CSV แทน XLSX ได้หรือไม่?* | แทนที่ `SaveFormat.Xlsx` ด้วย `SaveFormat.Csv` อย่างไรก็ตามข้อมูลการจัดรูปแบบ (รูปแบบตัวเลข, สีฟอนต์) จะหายไปเนื่องจาก CSV เป็นรูปแบบข้อความธรรมดา |

## เคล็ดลับสำหรับการใช้งานใน Production

* **Pro tip:** แคชออบเจ็กต์ `Style` หากต้องใช้การจัดรูปแบบเดียวกันกับหลาย worksheet; การสร้าง `StyleArray` ใหม่สำหรับแต่ละการนำเข้าจะเพิ่มภาระ |
* **ระวังความแตกต่างของวัฒนธรรม:** รูปแบบ `Number` `#,##0.00` ใช้วัฒนธรรม invariant หากต้องการคั่นตามท้องถิ่นให้ใช้ `NumberFormatInfo` หรือให้ Excel จัดการตามการตั้งค่าภูมิภาคของผู้ใช้ |
* **การจัดการข้อผิดพลาด:** ครอบเมธอด `Save` ด้วยบล็อก try‑catch เพื่อจัดการข้อยกเว้น I/O (เช่น สิทธิ์ไม่เพียงพอหรือไฟล์ถูกล็อก) |
