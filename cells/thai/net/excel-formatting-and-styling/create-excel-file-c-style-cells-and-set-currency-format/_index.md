# สร้างไฟล์ excel c# – จัดรูปแบบเซลล์และตั้งค่ารูปแบบสกุลเงิน

หากคุณต้องการ **create excel file c#** ที่ดูเป็นมืออาชีพ คู่มือนี้จะแสดงให้คุณเห็นอย่างละเอียดว่า จะจัดรูปแบบเซลล์ excel อย่างไรและตั้งค่าคอลัมน์เป็นสกุลเงินอย่างไร คุณจะได้เห็นตัวอย่างครบวงจรตั้งแต่ต้นจนจบที่นำเข้า `DataTable` ใส่หัวตารางเป็นตัวหนา และตั้งค่ารูปแบบตัวเลข `$#,##0.00` สำหรับคอลัมน์ราคา

บทเรียนนี้ครอบคลุมทุกอย่างที่คุณต้องการ: แพคเกจ NuGet ที่จำเป็น, โค้ดเต็ม, คำอธิบายว่าทำไมแต่ละส่วนจึงสำคัญ, และเคล็ดลับการจัดการกรณีขอบเช่น แถวว่างหรือโลคัลที่ต่างกัน เมื่อเสร็จสิ้นคุณจะสามารถสร้างไฟล์ `.xlsx` ที่มีคอลัมน์ราคาที่จัดรูปแบบอย่างสวยงามได้ด้วยเพียงไม่กี่บรรทัดของ C#

## ข้อกำหนดเบื้องต้น

- .NET 6.0 หรือใหม่กว่า (โค้ดนี้ยังทำงานกับ .NET Framework 4.6+)
- Visual Studio 2022 หรือโปรแกรมแก้ไข C# ใด ๆ ที่คุณชอบ
- ไลบรารี **Aspose.Cells for .NET** หรือ **GemBox.Spreadsheet** (ทั้งสองรองรับ `ImportTableOptions`). ตัวอย่างด้านล่างใช้ **Aspose.Cells** เพราะมีคุณสมบัติ `StyleArray` ที่ง่ายต่อการใช้งาน
- ความรู้พื้นฐานเกี่ยวกับคอลเลกชันของ C# และ `DataTable`

> **Pro tip:** หากคุณต้องการทางเลือกฟรี ให้เปลี่ยน `Aspose.Cells` เป็น `GemBox.Spreadsheet`. API สำหรับการนำเข้า `DataTable` พร้อมสไตล์นั้นเกือบจะเหมือนกัน; เพียงเปลี่ยนชื่อเนมสเปซและชื่อแพคเกจ NuGet

## ขั้นตอนที่ 1: ติดตั้งไลบรารี Excel

เปิด NuGet Package Manager แล้วติดตั้งไลบรารี:

```bash
dotnet add package Aspose.Cells
```

> **ทำไมต้องทำขั้นตอนนี้?** ไลบรารีจะให้คลาส `Workbook`, `Worksheet`, `Style` และ `ImportTableOptions` ที่ใช้ในขั้นตอนต่อไป หากไม่มีคุณจะต้องเขียนรูปแบบ Office Open XML ด้วยตนเอง ซึ่งเสี่ยงต่อข้อผิดพลาดสูง

## ขั้นตอนที่ 2: สร้าง DataTable พร้อมข้อมูลตัวอย่าง

`DataTable` เป็นวิธีที่สะดวกในการเก็บข้อมูลแบบตารางก่อนส่งออกเป็น Excel ในตัวอย่างนี้เรามีสองคอลัมน์: *Product* และ *Price*

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Explanation:**  
> - `Columns.Add("Price", typeof(double))` บอกตารางให้ถือค่าราคาเป็นตัวเลข ซึ่งจำเป็นสำหรับการจัดรูปแบบตัวเลขในภายหลัง  
> - การเพิ่มแถวไม่กี่แถวทำให้เรามีข้อมูลเพื่อทดสอบขั้นตอน **format column currency**

## ขั้นตอนที่ 3: กำหนดสไตล์ที่ต้องการใช้

เราจะสร้างอาเรย์ของอ็อบเจ็กต์ `Style` ที่สอดคล้องกับลำดับคอลัมน์ รายการแรกใช้สไตล์สำหรับแถวหัวตาราง, รายการที่สองปล่อยคอลัมน์ *Product* ไว้ตามค่าเริ่มต้น, และรายการที่สามจะใส่รูปแบบตัวเลขสกุลเงิน

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### ทำไมต้องใช้ **style array**?

`ImportTableOptions.StyleArray` จะแมปแต่ละคอลัมน์กับ `Style` นี่เป็นวิธีที่มีประสิทธิภาพที่สุดในการ **add number format** และ **style excel cells** ในการนำเข้าครั้งเดียว ลดการทำงานรอบที่สองบนเวิร์กชีต

## ขั้นตอนที่ 4: ตั้งค่าตัวเลือกการนำเข้า

ตอนนี้เราจะผูกอาเรย์สไตล์เข้ากับการนำเข้า `ImportTableOptions` ยังช่วยให้คุณควบคุมได้ว่าขั้นแรกจะถือเป็นหัวตารางหรือไม่

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Note:** `IsFieldNameShown` มีค่าเริ่มต้นเป็น `true` แต่การตั้งค่าอย่างชัดเจนทำให้เจตนาชัดเจนต่อผู้อ่านในอนาคต

## ขั้นตอนที่ 5: สร้างเวิร์กบุ๊ก, นำเข้าตาราง, และบันทึก

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### ผลลัพธ์ที่คาดหวัง

เมื่อคุณเปิดไฟล์ `DataTableWithStyles.xlsx`:

- แถวแรก (หัวตาราง) จะเป็น **bold**  
- คอลัมน์ *Price* จะแสดงค่าเป็น **$1.20**, **$3.50**, **$0.75**  
- คอลัมน์ *Product* จะคงฟอนต์เริ่มต้นไว้

คุณได้ **created an excel file c#** ที่มีคอลัมน์สกุลเงินที่จัดรูปแบบและหัวตารางที่สไตล์แล้วอย่างสำเร็จ

## ขั้นตอนที่ 6: การจัดการความแปรผันและกรณีขอบทั่วไป

### a. โลคัลต่างหรือสัญลักษณ์สกุลเงินกำหนดเอง

หากต้องการยูโรหรือสกุลเงินอื่น ให้เปลี่ยนรูปแบบในตัว `164` เป็นสตริงรูปแบบที่กำหนดเอง:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. เพิ่มคอลัมน์เพิ่มเติมในภายหลัง

เมื่อคุณเพิ่มคอลัมน์ใหม่ ให้ขยายอาเรย์ `columnStyles` ให้สอดคล้อง ใช้ `null` สำหรับคอลัมน์ที่ต้องการคงสไตล์เริ่มต้นไว้

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. DataTable ว่าง

หาก `DataTable` ไม่มีแถว Aspose.Cells จะยังคงสร้างแถวหัวตาราง แต่เวิร์กบุ๊กจะมีเพียงแถวเดียวเท่านั้น เพื่อหลีกเลี่ยงไฟล์ว่าง ให้ตรวจสอบจำนวนแถวก่อนทำการนำเข้า:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. ใช้ `GemBox.Spreadsheet` แทน Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

ตรรกะยังคงเหมือนเดิม แสดงให้เห็นว่าบทเรียนนี้ **format column currency** ไม่ขึ้นกับไลบรารีที่ใช้

## ขั้นตอนที่ 7: ตรวจสอบไฟล์ด้วยโปรแกรม (ทางเลือก)

คุณสามารถเปิดเวิร์กบุ๊กที่สร้างขึ้นและตรวจสอบว่ารูปแบบตัวเลขถูกนำไปใช้อย่างถูกต้อง – มีประโยชน์สำหรับการทดสอบหน่วย

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```

## สรุป

บทเรียนนี้แสดงวิธี **create excel file c#**, **style excel cells**, และ **set currency format** ให้กับคอลัมน์เฉพาะโดยใช้ตัวอย่างสั้น ๆ ครบวงจร คุณได้เรียนรู้:

1. วิธีสร้าง `DataTable` ที่มีข้อมูลเชิงตัวเลข  
2. วิธีกำหนด **style array** ที่ทำให้หัวตารางเป็นตัวหนาและ **add number format** ให้คอลัมน์ราคา  
3. วิธีนำเข้าตารางด้วย `ImportTableOptions` และบันทึกเวิร์กบุ๊ก  
4. วิธีปรับโซลูชันให้รองรับโลคัลต่าง ๆ, คอลัมน์เพิ่ม, DataTable ว่าง, และไลบรารีทางเลือก

จากนี้คุณสามารถสำรวจการจัดรูปแบบขั้นสูงเพิ่มเติม – การจัดรูปแบบตามเงื่อนไข, เส้นขอบเซลล์, หรือการปรับขนาดคอลัมน์อัตโนมัติ ทดลองใช้คุณสมบัติ `Style` เพื่อเปลี่ยนฟอนต์, สีพื้นหลัง, หรือการจัดแนว และคุณจะมีโซลูชันการส่งออก Excel ที่ครบถ้วนสำหรับแอปพลิเคชัน C# ใด ๆ

**ขั้นตอนต่อไป:**  

- เรียนรู้วิธี **format column currency** ตามโลคัลของผู้ใช้ (`CultureInfo`)  
- เพิ่ม **data validation** (รายการดรอป‑ดาวน์) ให้กับเวิร์กชีต  
- ใช้ **Excel tables** (`ListObject`) เพื่อการกรองและจัดเรียงที่ดียิ่งขึ้นในไฟล์ที่สร้างขึ้น  

ขอให้เขียนโค้ดอย่างสนุกและเพลิดเพลินกับการสร้างรายงาน Excel ที่ดูเป็นมืออาชีพโดยตรงจาก C#!
