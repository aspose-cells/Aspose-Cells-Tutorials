# वर्कबुक को सेव करते समय HTML में फ़ॉन्ट एम्बेड कैसे करें

यदि आपको स्प्रेडशीट निर्यात करते समय **HTML में फ़ॉन्ट एम्बेड करने** की आवश्यकता है, तो यह ट्यूटोरियल आपको एक पूर्ण, तैयार‑चलाने योग्य समाधान दिखाता है। चाहे आप रिपोर्टिंग पोर्टल बना रहे हों या क्लाइंट‑साइड एनालिटिक्स व्यू, फ़ॉन्ट एम्बेड करने से यह सुनिश्चित होता है कि उत्पन्न HTML मूल वर्कबुक जैसा ही दिखे, चाहे दर्शक के सिस्टम में फ़ॉन्ट इंस्टॉल हों या न हों।

आप Aspose.Cells का उपयोग करके **वर्कबुक को HTML के रूप में सेव करने** का सबसे अच्छा तरीका सीखेंगे, सामान्य समस्याओं को देखेंगे, और बड़े वर्कबुक या कस्टम फ़ॉन्ट फ़ाइलों को संभालने के टिप्स प्राप्त करेंगे। कोई बाहरी दस्तावेज़ीकरण आवश्यक नहीं है—आपको जो कुछ भी चाहिए वह इस गाइड में ही है।

## आवश्यकताएँ

- .NET 6.0 या बाद का संस्करण (कोड .NET Framework 4.7+ के साथ भी काम करता है)
- एक वैध Aspose.Cells for .NET लाइसेंस (या आप मुफ्त इवैल्यूएशन मोड का उपयोग कर सकते हैं)
- बुनियादी C# ज्ञान और Visual Studio 2022 जैसे IDE
- वे TrueType (.ttf) या OpenType (.otf) फ़ॉन्ट फ़ाइलें जिन्हें आप एम्बेड करना चाहते हैं (उनका एक्सेस चल रहे प्रोसेस को होना चाहिए)

## चरण 1: प्रोजेक्ट सेट अप करें और Aspose.Cells इम्पोर्ट करें

एक नया कंसोल एप्लिकेशन बनाएं और Aspose.Cells NuGet पैकेज जोड़ें:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

फिर **Program.cs** खोलें और आवश्यक `using` निर्देश जोड़ें:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **प्रो टिप:** अपने कस्टम फ़ॉन्ट को प्रोजेक्ट रूट के अंदर `fonts` नामक फ़ोल्डर में रखें। इससे समाधान पोर्टेबल रहता है और बाद में उन्हें रेफ़रेंस करना आसान हो जाता है।

## चरण 2: वर्कबुक बनाएं या लोड करें

प्रदर्शन के लिए, हम कुछ स्टाइल किए हुए सेल्स के साथ एक सरल वर्कबुक बनाएंगे:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **यह क्यों महत्वपूर्ण है:** यदि आप कस्टम स्टाइल को छोड़ देते हैं, तो निर्यात किया गया HTML ब्राउज़र के डिफ़ॉल्ट फ़ॉन्ट पर वापस आ जाएगा, जिससे **HTML में फ़ॉन्ट एम्बेड करने** का उद्देश्य विफल हो जाता है।

## चरण 3: फ़ॉन्ट एम्बेड करने के लिए `HtmlSaveOptions` कॉन्फ़िगर करें

**HTML में फ़ॉन्ट एम्बेड करने** का मूल `HtmlSaveOptions` क्लास में है। `EmbedFonts = true` सेट करने से Aspose.Cells को निर्देश मिलता है कि वह सभी संदर्भित TrueType/OpenType फ़ॉन्ट को सीधे उत्पन्न HTML में Base64‑एन्कोडेड डेटा URI के रूप में एम्बेड करे।

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### एम्बेडिंग कैसे काम करती है

जब `EmbedFonts` `true` होता है, तो Aspose.Cells वर्कबुक की स्टाइल परिभाषाओं को स्कैन करता है, सिस्टम पर (या आपके द्वारा जोड़े गए `fonts` फ़ोल्डर में) संबंधित फ़ॉन्ट फ़ाइलों को ढूँढता है, उनका बाइनरी डेटा पढ़ता है, और एक `<style>` ब्लॉक इस प्रकार इंजेक्ट करता है:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

क्योंकि फ़ॉन्ट डेटा सीधे HTML में एन्कोड किया गया है, पेज उन मशीनों पर भी सही ढंग से रेंडर होता है जहाँ फ़ॉन्ट इंस्टॉल नहीं है।

## चरण 4: वर्कबुक को HTML के रूप में सेव करें

अब आप कॉन्फ़िगर किए गए विकल्पों के साथ **वर्कबुक को HTML के रूप में सेव** कर सकते हैं। ऐसा डायरेक्टरी चुनें जहाँ एप्लिकेशन लिख सके (उदाहरण के लिए, `output`)।

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

प्रोग्राम चलाने पर एक ही `report.html` फ़ाइल बनती है। इसे किसी भी आधुनिक ब्राउज़र में खोलें और आप “Quarterly Sales” हेडर को **Pacifico** फ़ॉन्ट के साथ रेंडर होते देखेंगे, भले ही आपके OS में वह फ़ॉन्ट इंस्टॉल न हो।

### अपेक्षित आउटपुट

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

`src:` एट्रिब्यूट में एक लंबा Base64 स्ट्रिंग होता है—यह एम्बेडेड फ़ॉन्ट डेटा है जो **HTML में फ़ॉन्ट एम्बेड करने** को सक्षम बनाता है।

## चरण 5: फ़ॉन्ट एम्बेडिंग को सत्यापित करें और समस्याओं का निवारण करें

1. **Chrome या Edge में HTML फ़ाइल खोलें।** यदि कस्टम फ़ॉन्ट दिखाई देता है, तो एम्बेडिंग सफल रही।  
2. **पेज सोर्स को inspect करें।** Aspose.Cells द्वारा जेनरेट किए गए `@font-face` नियम को देखें।  
3. **सामान्य समस्याएँ:**  
   - *फ़ॉन्ट फ़ाइल गायब:* सुनिश्चित करें कि फ़ॉन्ट फ़ाइल पहुँच योग्य है। आप सर्च पाथ में स्पष्ट रूप से एक फ़ोल्डर जोड़ सकते हैं:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *बड़ी HTML साइज:* कई फ़ॉन्ट एम्बेड करने से फ़ाइल का आकार बढ़ सकता है। फ़ॉन्ट को अलग `.ttf` फ़ाइलों के रूप में एक रिसोर्सेज फ़ोल्डर में रखने के लिए `ExportToSingleFile = false` उपयोग करें।  
   - *असमर्थित फ़ॉन्ट फ़ॉर्मेट:* Aspose.Cells केवल TrueType (`.ttf`) और OpenType (`.otf`) को एम्बेड करता है। एम्बेड करने से पहले अन्य फ़ॉर्मेट को परिवर्तित करें।

## पूर्ण कार्यशील उदाहरण

नीचे पूरा प्रोग्राम दिया गया है जिसे आप बिना किसी संशोधन के (वैकल्पिक लाइसेंस लाइन को छोड़कर) कॉपी, पेस्ट और चला सकते हैं।

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

इस प्रोग्राम को चलाने से `output/report.html` बनता है। फ़ाइल खोलें, और आप **Pacifico** फ़ॉन्ट को सही ढंग से रेंडर होते देखेंगे—जो **HTML में फ़ॉन्ट एम्बेड करने** को **वर्कबुक को HTML के रूप में सेव करने** के दौरान दर्शाता है।

## अक्सर पूछे जाने वाले प्रश्न

| प्रश्न | उत्तर |
|----------|--------|
| *क्या मैं केवल विशिष्ट फ़ॉन्ट एम्बेड कर सकता हूँ?* | हाँ। `htmlOpt.EmbedAllFonts = false` सेट करें (नए संस्करणों में उपलब्ध) और `htmlOpt.FontsToEmbed` का उपयोग करके सटीक फ़ॉन्ट नामों की सूची दें। |
| *यदि मुझे कई वर्कशीट्स के लिए फ़ॉन्ट एम्बेड करने की आवश्यकता हो तो क्या करें?* | `ExportActiveWorksheetOnly = false` सेट करें ताकि हर वर्कशीट एक्सपोर्ट हो, और Aspose.Cells पूरे वर्कबुक में उपयोग किए गए फ़ॉन्ट को एम्बेड करेगा। |
| *क्या एम्बेडेड फ़ॉन्ट मोबाइल ब्राउज़रों पर काम करेंगे?* | आधुनिक मोबाइल ब्राउज़र Base64‑एन्कोडेड फ़ॉन्ट को सपोर्ट करते हैं, इसलिए एम्बेडेड फ़ॉन्ट सही ढंग से रेंडर होते हैं जब तक फ़ॉन्ट फ़ॉर्मेट समर्थित हो (TTF या OTF)। |
| *HTML फ़ाइल कितना बड़ा हो सकता है?* | 200 KB TrueType फ़ॉन्ट एम्बेड करने से HTML आकार में लगभग वही मात्रा जुड़ती है (Base64 ~33 % ओवरहेड जोड़ता है)। कई फ़ॉन्ट्स के लिए, HTML को हल्का रखने हेतु फ़ोल्डर में एक्सपोर्ट करने पर विचार करें (`ExportToSingleFile = false`)। |
