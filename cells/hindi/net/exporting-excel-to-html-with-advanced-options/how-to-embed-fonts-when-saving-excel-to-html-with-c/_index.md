# Excel को HTML में सेव करते समय फ़ॉन्ट एम्बेड कैसे करें (C#)

Excel वर्कबुक को HTML में सेव करते समय फ़ॉन्ट एम्बेड करना एक सामान्य आवश्यकता है ताकि आपके स्प्रेडशीट का लुक सभी ब्राउज़र में समान रहे। यदि आपको Excel को HTML में एक्सपोर्ट करते समय मूल फ़ॉन्ट बनाए रखने हैं, तो यह गाइड एक पूर्ण, तैयार‑चलाने योग्य समाधान दिखाता है।

आप सीखेंगे **Excel को HTML में एक्सपोर्ट** करना, **फ़ॉन्ट एम्बेड के साथ Excel को HTML में कनवर्ट** करना, और क्लाइंट मशीनों पर लेआउट टूटने वाली सामान्य “फ़ॉन्ट‑मिसिंग” समस्या से बचना। कोई बाहरी टूल आवश्यक नहीं—सिर्फ Aspose.Cells लाइब्रेरी और कुछ लाइनें C# की।

## Prerequisites

शुरू करने से पहले सुनिश्चित करें कि आपके पास है:

* .NET 6.0 (या बाद का) इंस्टॉल हो।
* **Aspose.Cells for .NET** की लाइसेंस्ड कॉपी – परीक्षण हेतु फ्री ट्रायल चल सकता है।
* Visual Studio 2022 या VS Code जैसा IDE।

यदि ये सब आपके पास है, तो सीधे कोड की ओर बढ़ें।

## Step 1: Create a workbook and add sample data

पहले हम एक छोटा वर्कबुक बनाते हैं ताकि आप एम्बेडेड फ़ॉन्ट का प्रभाव देख सकें। नीचे दिया गया कोड एक वर्कशीट बनाता है, कुछ सेल्स लिखता है, और एक कस्टम फ़ॉन्ट लागू करता है।

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### Why we add a custom font

फ़ॉन्ट एम्बेड तभी मायने रखता है जब वर्कबुक ऐसे फ़ॉन्ट उपयोग करता है जो क्लाइंट डिवाइस पर मौजूद नहीं हो सकते। **Arial** (या कोई अन्य फ़ॉन्ट) को स्पष्ट रूप से सेट करके हम यह सत्यापित कर सकते हैं कि HTML आउटपुट में वास्तव में फ़ॉन्ट डेटा शामिल है।

## Step 2: Configure HTML save options to embed fonts

Aspose.Cells `HtmlSaveOptions` क्लास प्रदान करता है। `EmbedFonts = true` सेट करने से लाइब्रेरी आवश्यक फ़ॉन्ट फ़ाइलों को सीधे जनरेटेड HTML में Base64‑एन्कोडेड डेटा URI के रूप में एम्बेड करती है।

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### What “embed fonts in html” really does

जब `EmbedFonts` true होता है, तो Aspose.Cells सिस्टम (या वर्कबुक के एम्बेडेड फ़ॉन्ट कलेक्शन) से फ़ॉन्ट फ़ाइलें निकालता है और उन्हें **Base64** स्ट्रिंग्स में बदल देता है। ये स्ट्रिंग्स फिर `<style>` ब्लॉक के अंदर `@font-face` के साथ रखी जाती हैं। परिणामस्वरूप HTML को किसी भी डिवाइस पर खोलने पर मूल फ़ॉन्ट इंस्टॉल किए बिना सही रूप में दिखेगा।

## Step 3: Save the workbook as HTML with embedded fonts

अब हम वर्कबुक को डिस्क पर लिखते हैं। फ़ाइल में फ़ॉन्ट डेटा होगा, इसलिए इसे किसी भी आधुनिक ब्राउज़र में खोलने पर टाइपोग्राफी मूल Excel फ़ाइल जैसी ही दिखेगी।

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### Expected result

* `embedded.html` `output` फ़ोल्डर में स्थित है।
* Chrome, Edge, या Firefox में फ़ाइल खोलने पर वर्कशीट **Arial** टेक्स्ट के साथ दिखेगी, भले ही ब्राउज़र वाले मशीन में Arial न हो।
* HTML सोर्स को देखेंगे तो `<style>` ब्लॉक में `@font-face` नियम के साथ एक लंबा `src: url(data:font/ttf;base64,…)` डिक्लेरेशन मिलेगा – यही एम्बेडेड फ़ॉन्ट है।

## Step 4: Verify the HTML works on another machine (optional)

एंबेडिंग सफल हुई है यह पूरी तरह से सुनिश्चित करने के लिए:

1. `output/embedded.html` को किसी अलग कंप्यूटर (या वर्चुअल मशीन) पर कॉपी करें जहाँ कस्टम फ़ॉन्ट इंस्टॉल न हो।
2. ब्राउज़र में फ़ाइल खोलें।
3. लेआउट और टाइपोग्राफी मूल Excel व्यू के समान दिखनी चाहिए।

यदि फ़ॉन्ट सामान्य फ़ॉन्ट में बदल जाता है, तो जांचें कि फ़ॉन्ट फ़ाइल बिल्ड मशीन पर एक्सेसिबल है और पढ़ने की अनुमति है।

## Common questions and edge cases

### Does embedding increase file size?

हां। TrueType या OpenType फ़ॉन्ट को एम्बेड करने से HTML फ़ाइल में **दसियों किलोबाइट** जोड़ सकते हैं। बड़े वर्कबुक में कई यूनिक फ़ॉन्ट होने पर विचार करें:

* फ़ॉन्ट को सबसेट करें (सिर्फ उपयोग किए गए कैरेक्टर) – Aspose.Cells अधिकांश सामान्य फ़ॉन्ट के लिए यह स्वचालित करता है।
* यदि इमेजेज की जरूरत नहीं है तो `ExportEmbeddedImages = false` उपयोग करें।

### What if I need to embed only specific fonts?

`HtmlSaveOptions` सीधे कोई व्हाइटलिस्ट प्रदान नहीं करता, लेकिन आप `Save` कॉल करने से पहले वर्कबुक में उपयोग किए गए फ़ॉन्ट को **सीमित** करके यह नियंत्रित कर सकते हैं। अनावश्यक फ़ॉन्ट असाइनमेंट हटाएँ या उन्हें स्टैंडर्ड वेब‑सेफ़ फ़ॉन्ट से बदलें।

### Can I embed fonts when converting to other formats (e.g., PDF)?

`PdfSaveOptions` में भी वही `EmbedFonts` प्रॉपर्टी मौजूद है। सिद्धांत समान है: फ़ॉन्ट डेटा एम्बेड किया जाता है ताकि PDF किसी भी व्यूअर में सही ढंग से रेंडर हो।

## Full, runnable example

नीचे पूरा प्रोग्राम दिया गया है जिसे आप नई कंसोल प्रोजेक्ट में कॉपी‑पेस्ट कर सकते हैं।

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

प्रोग्राम चलाने पर **HTML फ़ाइल बनती है जिसमें एम्बेडेड Arial फ़ॉन्ट होता है**, जिससे फ़ाइल को जहाँ भी खोला जाए, विज़ुअल फ़िडेलिटी सुनिश्चित रहती है।
