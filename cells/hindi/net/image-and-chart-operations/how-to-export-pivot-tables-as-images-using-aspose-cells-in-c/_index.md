# Aspose.Cells में C# का उपयोग करके पिवट टेबल को इमेज के रूप में एक्सपोर्ट कैसे करें

यदि आपको पिवट डेटा को एक पोर्टेबल चित्र में **how to export pivot** एक्सपोर्ट करने की आवश्यकता है, तो Aspose.Cells प्रक्रिया को सरल बनाता है। यह ट्यूटोरियल आपको दिखाता है कि पिवट टेबल को PNG फ़ाइलों के रूप में कैसे एक्सपोर्ट किया जाए, ताकि आप उन्हें रिपोर्ट, ईमेल या दस्तावेज़ों में एम्बेड कर सकें बिना लक्ष्य मशीन पर Excel की आवश्यकता के।

पिवट को इमेज के रूप में एक्सपोर्ट करने से संस्करण‑विशिष्ट फ़ॉर्मेटिंग समस्याएँ समाप्त हो जाती हैं और गैर‑तकनीकी हितधारकों को विश्लेषण तुरंत देखने की सुविधा मिलती है। हम प्रोजेक्ट सेटअप से लेकर अंतिम **export pivot table image** रेंडर करने तक सब कुछ कवर करेंगे, और साथ ही भविष्य में पुनः उपयोग के लिए **save pivot as image** कैसे किया जाए, यह भी समझाएंगे।

## Aspose.Cells के साथ पिवट टेबल को इमेज के रूप में एक्सपोर्ट कैसे करें

नीचे पूरा, चलाने योग्य उदाहरण दिया गया है जो एक वर्कबुक लोड करता है, पिवट को रिफ्रेश करता है, इमेज विकल्प कॉन्फ़िगर करता है, और आउटपुट फ़ाइल लिखता है। प्रत्येक चरण में एक संक्षिप्त तर्क शामिल है ताकि आप समझ सकें कि कोड *क्यों* उस तरह लिखा गया है, न कि केवल *क्या* करता है।

### 1. Aspose.Cells पर्यावरण सेट अप करें

1. NuGet पैकेज इंस्टॉल करें:

   ```bash
   dotnet add package Aspose.Cells
   ```

2. अपने C# फ़ाइल के शीर्ष पर आवश्यक `using` निर्देश जोड़ें:

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **Pro tip:** नवीनतम प्रदर्शन सुधारों का लाभ उठाने के लिए .NET 6 या उसके बाद के संस्करण को टार्गेट करें।

### 2. वर्कबुक लोड करें और पिवट टेबल खोजें

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*Why this matters:* `Workbook` क्लास XLSX फ़ाइल को पार्स करती है और आपको सभी वर्कशीट्स तक पहुँच देती है। सही वर्कशीट का चयन आवश्यक है क्योंकि एक वर्कबुक में कई पिवट हो सकते हैं।

### 3. नवीनतम स्रोत डेटा को कैप्चर करने के लिए पिवट टेबल को रिफ्रेश करें

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

रिफ्रेश करने से यह सुनिश्चित होता है कि फ़ाइल सहेजने के बाद स्रोत रेंज में किए गए किसी भी परिवर्तन को रेंडर की गई इमेज में दर्शाया जाए। इस चरण को छोड़ने से पुरानी या गलत विज़ुअल्स उत्पन्न हो सकते हैं।

### 4. इमेज एक्सपोर्ट विकल्प कॉन्फ़िगर करें (export pivot table image)

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

`ImageOrPrintOptions` ऑब्जेक्ट आपको फ़ॉर्मेट, रिज़ॉल्यूशन और अन्य रेंडरिंग विवरणों को नियंत्रित करने देता है। PNG तीक्ष्ण, वेब‑अनुकूल ग्राफ़िक्स के लिए सबसे सामान्य विकल्प है, लेकिन यदि फ़ाइल आकार की चिंता है तो आप `ImageFormat.Jpeg` पर स्विच कर सकते हैं।

### 5. रेंडर करें और **save pivot as image**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

`RenderToImage` भारी काम करता है: यह पिवट को ठीक उसी तरह ड्रॉ करता है जैसा कि Excel में दिखता है और बाइनरी PNG डेटा को डिस्क पर लिखता है। यह मेथड `void` रिटर्न करता है, इसलिए आप सुरक्षित रूप से मान सकते हैं कि कॉल समाप्त होने के बाद फ़ाइल मौजूद है और अतिरिक्त जांच की आवश्यकता नहीं है।

#### अपेक्षित परिणाम

प्रोग्राम चलने के बाद, आपको निर्दिष्ट फ़ोल्डर में `Pivot.png` मिलेगा। फ़ाइल खोलने पर मूल पिवट टेबल का एक सटीक स्नैपशॉट दिखना चाहिए, जिसमें कॉलम हेडर, रो टोटल और लागू फ़ॉर्मेटिंग शामिल हैं।

### 6. सामान्य विविधताएँ और किनारी मामलों

| परिदृश्य | समायोजन |
|----------|------------|
| **Large pivots** (बहुत सारी पंक्तियाँ/स्तंभ) | `HorizontalResolution` और `VerticalResolution` को 300 dpi तक बढ़ाएँ ताकि आउटपुट स्पष्ट हो। |
| **Custom styling** (पृष्ठभूमि रंग, फ़ॉन्ट) | `Refresh()` कॉल करने से पहले सुनिश्चित करें कि वर्कबुक की स्टाइल परिभाषाएँ लोड हो चुकी हैं। |
| **Multiple pivots** (एक शीट में) | `worksheet.PivotTables` पर लूप करें और प्रत्येक के लिए `RenderToImage` कॉल करें, अलग-अलग फ़ाइल नामों का उपयोग करके। |
| **Export to JPEG** (PNG के बजाय) | `ImageFormat = ImageFormat.Jpeg` बदलें और वैकल्पिक रूप से `JpegSaveOptions` ऑब्जेक्ट पर `Quality` सेट करें। |

ये विविधताएँ आपको **export pivot table image** को ठीक उसी फ़ॉर्मेट में एक्सपोर्ट करने देती हैं जो आपका डाउनस्ट्रीम सिस्टम अपेक्षित करता है।

## त्वरित कॉपी‑पेस्ट के लिए पूर्ण स्रोत कोड

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

प्रोग्राम चलाने से ऊपर दिखाए गए PNG फ़ाइल बनती है, जिससे **save pivot as image** वर्कफ़्लो एक मिनट से कम समय में पूरा हो जाता है।

## निष्कर्ष

अब आप जानते हैं कि Aspose.Cells में C# का उपयोग करके **how to export pivot** टेबल को इमेज फ़ाइलों में कैसे एक्सपोर्ट किया जाता है। यह गाइड आपको लाइब्रेरी सेट अप करने, वर्कबुक लोड करने, पिवट को रिफ्रेश करने, PNG विकल्प कॉन्फ़िगर करने, और अंत में **export pivot table image** रेंडर करने तक ले गया, साथ ही बाद में पुनः उपयोग के लिए **save pivot as image** कैसे किया जाए भी दिखाया।

आप अगले चरणों में यह खोज सकते हैं:

* **Batch export** – वर्कबुक में सभी पिवट टेबल्स पर इटररेट करें और एक PDF रिपोर्ट बनाएं जो प्रत्येक PNG को एम्बेड करे।
* **Apply custom themes** – रेंडर करने से पहले वर्कबुक की स्टाइल कलेक्शन को संशोधित करें ताकि कॉरपोरेट ब्रांडिंग से मेल खाए।
* **Integrate with ASP.NET Core** – PNG को ऑन‑द‑फ्लाई जनरेट करें और वेब डैशबोर्ड के लिए HTTP रिस्पॉन्स के रूप में रिटर्न करें।

विभिन्न इमेज फ़ॉर्मेट, रिज़ॉल्यूशन और ऑटोमेशन परिदृश्यों के साथ प्रयोग करने में संकोच न करें। कोडिंग का आनंद लें!
