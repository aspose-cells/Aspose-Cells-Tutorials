# कैसे बनाएं Excel workbook C# कस्टम फ़ॉर्मेटिंग के साथ और सहेजें XLSX

यदि आपको **Excel workbook C#** बनाना है जो डेटा इम्पोर्ट करता है, कस्टम नंबर फ़ॉर्मेट लागू करता है, और सेल फ़ॉन्ट रंग बदलता है, तो यह ट्यूटोरियल आपको ठीक‑ठीक दिखाएगा। आप एक तैयार‑चलाने‑योग्य उदाहरण प्राप्त करेंगे जो कुछ ही सेकंड में एक स्टाइल्ड `StyleArrayImport.xlsx` फ़ाइल बनाता है।

C# से Excel के साथ काम करना अक्सर दोहरावदार मैनुअल चरणों में शामिल होता है—फ़ॉर्मेट परिभाषित करना, रंग लागू करना, और फ़ाइल को सही ढंग से सहेजना याद रखना। इस गाइड के अंत तक आप इन सभी कार्यों को ऑटोमेट कर लेंगे, ताकि आप UI के बजाय डेटा पर ध्यान केंद्रित कर सकें।

आप सीखेंगे कैसे:

* `DataTable` को एक वर्कशीट में इम्पोर्ट करें,
* `StyleArray` का उपयोग करके **कस्टम नंबर फ़ॉर्मेट लागू करें** और **सेल फ़ॉन्ट रंग बदलें**,
* **वर्कबुक को XLSX के रूप में सहेजें** एक ही मेथड कॉल से,
* और सत्यापित करें कि **format imported data excel** बिल्कुल इच्छित रूप में दिख रहा है।

एकमात्र पूर्वापेक्षा है **Aspose.Cells for .NET** लाइब्रेरी (या कोई भी संगत API जो `Workbook`, `Worksheet`, और `StyleArray` प्रदान करती हो) का रेफ़रेंस होना। कोड .NET 6+ को टार्गेट करता है, लेकिन छोटे समायोजनों के साथ पहले के संस्करण भी काम करेंगे।

## चरण 1: नमूना DataTable तैयार करें

सबसे पहले, एक `DataTable` बनाएं जो उस डेटा की नकल करता है जिसे आप सामान्यतः डेटाबेस या किसी अन्य स्रोत से प्राप्त करेंगे। टेबल में एक **Name** कॉलम (string) और एक **Amount** कॉलम (decimal) शामिल है जिसे हम बाद में फ़ॉर्मेट करेंगे।

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**यह क्यों महत्वपूर्ण है:** `DataTable` का उपयोग करने से आप इम्पोर्ट लॉजिक को डेटा स्रोत से स्वतंत्र रख सकते हैं, जो डेटाबेस, CSV फ़ाइलों या APIs से रिपोर्ट जेनरेट करते समय एक सामान्य पैटर्न है।

## चरण 2: **कस्टम नंबर फ़ॉर्मेट लागू करने** और **सेल फ़ॉन्ट रंग बदलने** के लिए StyleArray परिभाषित करें

`StyleArray` आपको फ़ॉर्मेटिंग निर्देशों को बंडल करने देता है जो `DataTable` से इम्पोर्ट किए गए प्रत्येक सेल पर लागू होंगे। इस उदाहरण में हम:

* `Number` को `#,##0.00` सेट करते हैं – हजारों सेपरेटर वाला एक सामान्य अकाउंटिंग फ़ॉर्मेट,
* `FontColor` को `Color.Blue` सेट करते हैं – जिससे नंबर उभर कर दिखें।

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**StyleArray क्यों उपयोग करें?** इम्पोर्ट समय पर स्टाइल लागू करने से वर्कशीट पर दूसरा पास नहीं करना पड़ता, जिससे बड़े डेटा सेट के लिए प्रदर्शन बेहतर होता है।

## चरण 3: **Excel workbook C#** बनाएं – Workbook इंस्टैंशिएट करें और पहला Worksheet प्राप्त करें

अब हम एक खाली वर्कबुक बनाते हैं और पहले Worksheet (इंडेक्स 0) का रेफ़रेंस प्राप्त करते हैं। यह Worksheet हमारे इम्पोर्ट किए गए डेटा का गंतव्य बन जाएगा।

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**व्याख्या:** `Workbook` पूरी Excel फ़ाइल का प्रतिनिधित्व करता है, जबकि `Worksheet` एकल टैब को दर्शाता है। डिफ़ॉल्ट वर्कबुक में एक शीट होती है, जो अधिकांश साधारण रिपोर्टों के लिए पर्याप्त है।

## चरण 4: **StyleArray** का उपयोग करके **format imported data excel** इम्पोर्ट करें

`ImportDataTable` मेथड टेबल की पंक्तियों और कॉलम को Worksheet में `A1` (पंक्ति 0, कॉलम 0) से शुरू करके कॉपी करता है। `true` आर्ग्यूमेंट मेथड को कॉलम हेडर शामिल करने के लिए कहता है। क्योंकि हम `styleArray` पास करते हैं, प्रत्येक इम्पोर्टेड सेल को कस्टम नंबर फ़ॉर्मेट और फ़ॉन्ट रंग मिल जाता है।

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**पर्दे के पीछे क्या होता है:** Aspose.Cells प्रत्येक पंक्ति पर इटररेट करता है, मान लिखता है, और फिर `styleArray` में परिभाषित स्टाइल लागू करता है। नंबर कॉमा और दो दशमलव स्थानों के साथ दिखते हैं, और टेक्स्ट नीले रंग में रेंडर होता है।

## चरण 5: **वर्कबुक को XLSX के रूप में सहेजें** – फ़ाइल को डिस्क पर लिखें

अंत में, वर्कबुक को एक `.xlsx` फ़ाइल में सहेजें। आप पथ को अपनी मशीन की किसी भी लिखने योग्य डायरेक्टरी में बदल सकते हैं।

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**परिणाम सत्यापन:** उत्पन्न फ़ाइल को Excel में खोलें। आपको डेटा की तीन पंक्तियाँ दिखनी चाहिए, जहाँ **Amount** कॉलम कॉमा, दो दशमलव स्थान, और नीले फ़ॉन्ट में फ़ॉर्मेट किया गया है। यह पुष्टि करता है कि **format imported data excel** चरण सफल रहा।

## पूर्ण कार्यशील उदाहरण

नीचे पूरे ब्लॉक को एक नए कंसोल प्रोजेक्ट में कॉपी करें और चलाएँ। अतिरिक्त कोड की आवश्यकता नहीं है।

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**कंसोल में अपेक्षित आउटपुट:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

फ़ाइल खोलें और सत्यापित करें कि **Amount** कॉलम में `1,234.56` जैसी वैल्यूज़ नीले फ़ॉन्ट में दिख रही हैं।

## सामान्य प्रश्न एवं किनारे के मामलों

| प्रश्न | उत्तर |
|----------|--------|
| *क्या मैं व्यक्तिगत कॉलमों पर अलग-अलग फ़ॉर्मेट लागू कर सकता हूँ?* | हाँ। इम्पोर्ट के बाद, कॉलम की `Style` ऑब्जेक्ट (`worksheet.Cells.Columns[1].Style`) प्राप्त करें और अलग `Number` या `FontColor` सेट करें। |
| *यदि मुझे नंबरों के बजाय डेट्स फ़ॉर्मेट करने की जरूरत है तो?* | `styleArray.Number = "mm-dd-yyyy"` सेट करें और वैकल्पिक रूप से डेट सेल्स के लिए `styleArray.FontColor` सेट करें। |
| *क्या नीला फ़ॉन्ट डार्क Excel थीम पर दिखाई देता है?* | डार्क बैकग्राउंड पर नीला पढ़ना मुश्किल हो सकता है। हल्का शेड (`Color.LightBlue`) या कंट्रास्टिंग रंग (`Color.Black`) उपयोग करें। |
| *मैं बहुत बड़ी DataTable (सैकड़ों हज़ार पंक्तियों) को कैसे इम्पोर्ट करूँ?* | `ImportDataTable` को `ImportDataTableOptions` ओवरलोड के साथ उपयोग करके डेटा स्ट्रीम करें, या कई Worksheet में विभाजित करें ताकि Excel की पंक्ति सीमा (1,048,576 पंक्तियाँ) से बाहर न जाएँ। |
| *क्या मैं XLSX के बजाय CSV एक्सपोर्ट कर सकता हूँ?* | `SaveFormat.Xlsx` को `SaveFormat.Csv` से बदलें। ध्यान दें कि CSV एक प्लेन‑टेक्स्ट फ़ॉर्मेट है, इसलिए फ़ॉर्मेटिंग जानकारी (नंबर फ़ॉर्मेट, फ़ॉन्ट रंग) खो जाएगी। |

## प्रोडक्शन उपयोग के टिप्स

* **Pro tip:** यदि आपको कई Worksheet पर समान फ़ॉर्मेट लागू करना है तो `Style` ऑब्जेक्ट को कैश करें; प्रत्येक इम्पोर्ट के लिए नया `StyleArray` बनाना ओवरहेड जोड़ता है।
* **संस्कृति अंतर पर ध्यान दें:** `Number` पैटर्न `#,##0.00` इनवेरिएंट कल्चर का पालन करता है। यदि आपको लोकल‑स्पेसिफिक सेपरेटर चाहिए तो `NumberFormatInfo` उपयोग करें या उपयोगकर्ता की रीजनल सेटिंग्स के आधार पर Excel को संभालने दें।
* **एरर हैंडलिंग:** `Save` कॉल को try‑catch ब्लॉक में रखें ताकि I/O एक्सेप्शन (जैसे अपर्याप्त परमिशन या लॉक्ड फ़ाइल) को संभाला जा सके।
