# Excel फ़ाइल बनाएं c# – सेल्स को स्टाइल करें और मुद्रा फ़ॉर्मेट सेट करें

यदि आपको **create excel file c#** पेशेवर दिखनी चाहिए, तो यह गाइड आपको बिल्कुल बताता है कि Excel सेल्स को कैसे स्टाइल करें और किसी कॉलम को मुद्रा के रूप में फ़ॉर्मेट करें। आप एक पूर्ण, एंड‑टू‑एंड उदाहरण देखेंगे जो एक `DataTable` को इम्पोर्ट करता है, बोल्ड हेडर लागू करता है, और प्राइस कॉलम के लिए `$#,##0.00` नंबर फ़ॉर्मेट सेट करता है।

ट्यूटोरियल में वह सब कुछ कवर किया गया है जिसकी आपको ज़रूरत है: आवश्यक NuGet पैकेज, पूरा सोर्स कोड, यह समझाने के लिए कि हर भाग क्यों महत्वपूर्ण है, और खाली रो या विभिन्न लोकेल जैसे एज केस को संभालने के टिप्स। अंत तक आप कुछ ही C# लाइनों में एक `.xlsx` फ़ाइल जेनरेट कर पाएँगे जिसमें प्राइस कॉलम सुंदरता से फ़ॉर्मेट किया गया हो।

## Prerequisites

- .NET 6.0 या बाद का (कोड .NET Framework 4.6+ के साथ भी काम करता है)
- Visual Studio 2022 या कोई भी C# एडिटर जो आप पसंद करते हैं
- **Aspose.Cells for .NET** या **GemBox.Spreadsheet** लाइब्रेरी (दोनों `ImportTableOptions` को सपोर्ट करते हैं)। नीचे का उदाहरण **Aspose.Cells** का उपयोग करता है क्योंकि यह एक सरल `StyleArray` प्रॉपर्टी प्रदान करता है।
- C# कलेक्शन्स और `DataTable` का बेसिक ज्ञान

> **Pro tip:** यदि आप एक फ्री विकल्प चाहते हैं, तो `Aspose.Cells` को `GemBox.Spreadsheet` से बदल दें। `DataTable` को स्टाइल के साथ इम्पोर्ट करने के लिए API लगभग समान है; केवल नेमस्पेस और NuGet पैकेज नाम बदलें।

## Step 1: Install the Excel library

NuGet Package Manager खोलें और लाइब्रेरी इंस्टॉल करें:

```bash
dotnet add package Aspose.Cells
```

> **Why this step?** लाइब्रेरी `Workbook`, `Worksheet`, `Style`, और `ImportTableOptions` क्लासेज़ प्रदान करती है जो बाद में उपयोग होते हैं। इसके बिना आपको Office Open XML फ़ॉर्मेट को मैन्युअली लिखना पड़ेगा, जो त्रुटिप्रवण है।

## Step 2: Create a DataTable with sample data

`DataTable` एक्सेल में एक्सपोर्ट करने से पहले टैब्युलर डेटा रखने का एक सुविधाजनक तरीका है। इस उदाहरण में हमारे पास दो कॉलम हैं: *Product* और *Price*।

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Explanation:**  
> - `Columns.Add("Price", typeof(double))` टेबल को बताता है कि प्राइस वैल्यूज़ को नंबर के रूप में ट्रीट किया जाए, जो बाद में नंबर फ़ॉर्मेटिंग के लिए आवश्यक है।  
> - कुछ रो जोड़ने से हमें **format column currency** स्टेप को वेरिफ़ाई करने के लिए डेटा मिल जाता है।

## Step 3: Define the styles you want to apply

हम `Style` ऑब्जेक्ट्स की एक एरे बनाएँगे जो कॉलम ऑर्डर से मेल खाती हो। पहला एंट्री हेडर रो को स्टाइल करेगा, दूसरा *Product* कॉलम को जैसा है वैसा ही रखेगा, और तीसरा एक मुद्रा नंबर फ़ॉर्मेट लागू करेगा।

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### Why use a **style array**?

`ImportTableOptions.StyleArray` प्रत्येक कॉलम को एक `Style` से मैप करता है। यह **add number format** और **style excel cells** को एक ही इम्पोर्ट ऑपरेशन में करने का सबसे इफ़िशिएंट तरीका है, जिससे वर्कशीट पर दूसरा पास नहीं करना पड़ता।

## Step 4: Configure import options

अब हम स्टाइल एरे को इम्पोर्ट ऑपरेशन से बाइंड करते हैं। `ImportTableOptions` ऑब्जेक्ट यह भी नियंत्रित करता है कि क्या पहली रो को हेडर माना जाए।

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Note:** `IsFieldNameShown` डिफ़ॉल्ट रूप से `true` होता है, लेकिन इसे स्पष्ट रूप से सेट करने से भविष्य के रीडर्स के लिए इरादा स्पष्ट हो जाता है।

## Step 5: Create a workbook, import the table, and save

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### Expected result

जब आप `DataTableWithStyles.xlsx` खोलेंगे:

- पहली रो (हेडर) **बोल्ड** होगी।
- *Price* कॉलम में वैल्यूज़ **$1.20**, **$3.50**, **$0.75** के रूप में दिखेंगी।
- *Product* कॉलम डिफ़ॉल्ट फ़ॉन्ट को ही रखेगा।

आपने सफलतापूर्वक **create excel file c#** को एक फ़ॉर्मेटेड करंसी कॉलम और स्टाइल्ड हेडर सेल्स के साथ बनाया है।

## Step 6: Handling common variations and edge cases

### a. Different locale or custom currency symbol

यदि आपको यूरो या कोई अन्य मुद्रा चाहिए, तो बिल्ट‑इन फ़ॉर्मेट `164` को एक कस्टम फ़ॉर्मेट स्ट्रिंग से बदल दें:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. Adding more columns later

जब आप अतिरिक्त कॉलम जोड़ें, तो `columnStyles` एरे को उसी अनुसार एक्सटेंड करें। उन कॉलम्स के लिए `null` उपयोग करें जिनकी डिफ़ॉल्ट स्टाइल रखनी है।

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. Empty DataTable

यदि `DataTable` में कोई रो नहीं है, तो Aspose.Cells अभी भी हेडर रो बनाता है। हालांकि, वर्कबुक में केवल एक रो ही रहेगा। खाली फ़ाइल से बचने के लिए इम्पोर्ट करने से पहले रो काउंट चेक करें:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Using `GemBox.Spreadsheet` instead of Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

लॉजिक बिल्कुल समान रहता है, जिससे यह दिखता है कि ट्यूटोरियल **format column currency** लाइब्रेरी-एग्नॉस्टिक है।

## Step 7: Verify the file programmatically (optional)

आप जेनरेटेड वर्कबुक को खोल सकते हैं और यह एसेर्ट कर सकते हैं कि नंबर फ़ॉर्मेट सही ढंग से लागू हुआ है—यह यूनिट टेस्ट्स के लिए उपयोगी है।

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```

## Conclusion

इस ट्यूटोरियल ने दिखाया कि कैसे **create excel file c#**, **style excel cells**, और किसी विशिष्ट कॉलम के लिए **set currency format** को एक संक्षिप्त, एंड‑टू‑एंड उदाहरण के साथ लागू किया जाता है। आपने सीखा:

1. कैसे एक `DataTable` को न्यूमेरिक डेटा के साथ बनाया जाए।  
2. कैसे एक **style array** परिभाषित किया जाए जो हेडर को बोल्ड करे और प्राइस कॉलम के लिए **add number format** सेट करे।  
3. कैसे `ImportTableOptions` के साथ टेबल को इम्पोर्ट किया जाए और वर्कबुक को सेव किया जाए।  
4. कैसे समाधान को विभिन्न लोकेल, अतिरिक्त कॉलम, खाली डेटा, और वैकल्पिक लाइब्रेरीज़ के लिए अनुकूलित किया जाए।

अब आप अधिक एडवांस्ड स्टाइलिंग—कंडीशनल फ़ॉर्मेटिंग, सेल बॉर्डर्स, या ऑटो‑साइज़िंग कॉलम्स—की खोज कर सकते हैं। `Style` ऑब्जेक्ट के साथ फ़ॉन्ट, बैकग्राउंड कलर, या अलाइनमेंट बदलें, और आपके पास किसी भी C# एप्लिकेशन के लिए एक फुल‑फ़ीचर Excel एक्सपोर्ट सॉल्यूशन होगा।
