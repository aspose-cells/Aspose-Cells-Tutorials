# जावा में Aspose.Cells का उपयोग करके चार्ट टिक दिशा कैसे बदलें

## परिचय

चार्ट टिक दिशा बदलना एक्सेल चार्ट की पठनीयता सुधारने का एक सामान्य तरीका है, विशेष रूप से जब लंबी श्रेणी नाम या घनी डेटा सेटों से निपटना हो। इस गाइड में आप **चार्ट टिक दिशा कैसे बदलें** सीखेंगे Aspose.Cells for Java के साथ, लाइब्रेरी स्थापित करने से लेकर अंतिम वर्कबुक सहेजने तक। हम यह भी कवर करेंगे कि वित्तीय रिपोर्ट, वैज्ञानिक विज़ुअलाइज़ेशन और व्यावसायिक डैशबोर्ड के लिए उचित लेबल घुमाव क्यों महत्वपूर्ण है।

## त्वरित उत्तर
- **कौन सी लाइब्रेरी चार्ट लेबल घुमाव को संभालती है?** Aspose.Cells for Java.  
- **कौन सा Maven आर्टिफैक्ट यह कार्यक्षमता जोड़ता है?** `com.aspose:aspose-cells`.  
- **क्या मैं लेबल कोण को वर्टिकल सेट कर सकता हूँ?** हाँ, `ChartTextDirectionType.VERTICAL` का उपयोग करें।  
- **उत्पादन उपयोग के लिए क्या लाइसेंस चाहिए?** एक स्थायी लाइसेंस आवश्यक है; मूल्यांकन के लिए एक अस्थायी लाइसेंस काम करता है।  
- **क्या API Java 8 और उसके बाद के संस्करणों के साथ संगत है?** हाँ, यह Java 8‑21 को सपोर्ट करता है।

## चार्ट टिक दिशा बदलना क्या है?
**चार्ट टिक दिशा बदलना** का अर्थ है श्रेणी‑अक्ष टिक लेबलों (जैसे, क्षैतिज, लंबवत, या घुमाए हुए) की अभिविन्यास को समायोजित करना ताकि वे चार्ट क्षेत्र में बेहतर फिट हों। यह ऑपरेशन Aspose.Cells में `ChartAxis` ऑब्जेक्ट की `setTickLabelDirection` मेथड के माध्यम से किया जाता है।

## जावा में चार्ट टिक दिशा कैसे बदलें?
टिक‑लेबल अभिविन्यास को संशोधित करने के लिए आपको लक्ष्य वर्कबुक लोड करनी होगी, विशिष्ट चार्ट प्राप्त करना होगा, उसकी श्रेणी अक्ष तक पहुंचना होगा, और इच्छित `ChartTextDirectionType` के साथ `setTickLabelDirection` को कॉल करना होगा। यह क्रम केवल कुछ लाइनों के जावा कोड में किया जा सकता है, जिससे इसे मौजूदा ऑटोमेशन वर्कफ़्लो में एकीकृत करना आसान हो जाता है।

1. वह वर्कबुक लोड करें जिसमें वह चार्ट हो जिसे आप संशोधित करना चाहते हैं।  
2. वर्कशीट और उसके इंडेक्स द्वारा चार्ट ऑब्जेक्ट प्राप्त करें।  
3. श्रेणी अक्ष (`getCategoryAxis()`) तक पहुंचें और इच्छित `ChartTextDirectionType` के साथ `setTickLabelDirection` को कॉल करें।  
4. वर्कबुक को नई फ़ाइल में सहेजें।

## कार्यान्वयन गाइड

### वर्कबुक और चार्ट लोड करना
`Workbook` क्लास मेमोरी में पूरी एक्सेल फ़ाइल का प्रतिनिधित्व करता है। `Worksheet` क्लास आपको व्यक्तिगत शीट्स तक पहुंच देती है, और `Chart` क्लास एक विशिष्ट चार्ट का प्रतिनिधित्व करता है।

```java
Workbook workbook = new Workbook("input.xlsx");               // 1️⃣ Load file
Worksheet sheet = workbook.getWorksheets().get(0);            // 2️⃣ First sheet
Chart chart = sheet.getCharts().get(0);                       // 3️⃣ First chart on the sheet
```

### टिक लेबल दिशा बदलना
`ChartAxis` सभी अक्ष‑संबंधित गुणों को नियंत्रित करता है। `ChartTextDirectionType` एक एन्यूमरेशन है जो अभिविन्यास को परिभाषित करता है।

```java
ChartAxis categoryAxis = chart.getCategoryAxis();            // Access category axis
categoryAxis.setTickLabelDirection(ChartTextDirectionType.HORIZONTAL); // 4️⃣ Set direction
```

- `ChartTextDirectionType.HORIZONTAL` → लेबल बाएँ‑से‑दाएँ पढ़े जाते हैं।  
- `ChartTextDirectionType.VERTICAL` → लेबल ऊपर‑से‑नीचे पढ़े जाते हैं।  
- `ChartTextDirectionType.ROTATED_45` → लेबल 45° घुमाए जाते हैं (नए संस्करणों में उपलब्ध)।

### वर्कबुक सहेजना
अक्ष को समायोजित करने के बाद, परिवर्तन को स्थायी बनाएं:

```java
workbook.save("output.xlsx", SaveFormat.XLSX);
```
