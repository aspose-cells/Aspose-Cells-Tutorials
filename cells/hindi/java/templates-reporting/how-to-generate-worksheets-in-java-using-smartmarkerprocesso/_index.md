# Java में SmartMarkerProcessor का उपयोग करके वर्कशीट्स कैसे जेनरेट करें

यदि आपको **वर्कशीट्स जेनरेट करने** की आवश्यकता है, तो यह गाइड एक पूर्ण, तैयार‑से‑चलाने वाला समाधान दिखाता है। पहले दो वाक्यों के अंत तक आप समझ जाएंगे कि ऑब्जेक्ट्स के संग्रह से वर्कशीट्स और डायनामिक एक्सेल शीट्स कैसे जेनरेट करें, और आपके पास एक कार्यशील कोड उदाहरण होगा जो एक ही मेथड कॉल से एक्सेल निर्माण को ऑटोमेट करता है।

प्रत्येक कर्मचारी, प्रोजेक्ट, या किसी अन्य इकाई के लिए अलग-अलग वर्कशीट बनाना आम आवश्यकता है जब आपको **एक्सेल वर्कबुक** डेटा प्रोग्रामेटिकली **पॉप्युलेट** करना हो। यह ट्यूटोरियल सभी चरणों—टेम्पलेट सेटअप से लेकर सूची प्रोसेसिंग और अंतिम फ़ाइल सहेजने तक—को कवर करता है, ताकि आप तुरंत इस तकनीक को अपने Java एप्लिकेशन में लागू कर सकें।

## आप क्या हासिल करेंगे

* एक मास्टर वर्कशीट जेनरेट करेंगे जो उच्च‑स्तरीय जानकारी सूचीबद्ध करेगी।  
* **सूची डेटा से कई शीट्स** बनाएं, प्रत्येक शीट का नाम स्वचालित रूप से निर्धारित होगा।  
* **एक्सेल निर्माण को ऑटोमेट** करें बिना मैन्युअली पंक्तियों या कॉलम्स जोड़ें।  
* **एक्सेल वर्कबुक** को समृद्ध डेटा संरचनाओं (ऑब्जेक्ट्स, मैप्स, एरेज़) के साथ **पॉप्युलेट** करें।  

पूर्वापेक्षाएँ:

* Java 8 या नया स्थापित हो।  
* Maven (या कोई अन्य बिल्ड टूल) ताकि Aspose.Cells for Java लाइब्रेरी जोड़ सकें।  
* Java कलेक्शन्स की बुनियादी समझ।  

> **Pro tip:** SmartMarker सिंटैक्स (`${EmployeeMaster}`) किसी भी कलेक्शन टाइप के साथ काम करता है जो `java.util.Collection` को इम्प्लीमेंट करता है। इसे उपयोग करके अपने टेम्पलेट्स को साफ़ और मेंटेन करने योग्य रखें।

## SmartMarkerProcessor के साथ वर्कशीट्स कैसे जेनरेट करें

यह सेक्शन वह कोर कोड दिखाता है जो **वर्कशीट्स जेनरेट करने** को आसान बनाता है। हम समझाएंगे कि प्रत्येक लाइन क्यों महत्वपूर्ण है, सिर्फ यह नहीं कि वह क्या करती है।

### Step 1: Aspose.Cells डिपेंडेंसी जोड़ें

यदि आप Maven उपयोग कर रहे हैं, तो अपने `pom.xml` में नीचे दिया गया कोड शामिल करें। लाइब्रेरी `SmartMarkerProcessor` क्लास प्रदान करती है जिसका उपयोग इस गाइड में किया गया है।

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **Why:** Aspose.Cells एक्सेल फ़ाइल I/O, Smart Marker पार्सिंग, और शीट मैनेजमेंट को आंतरिक रूप से संभालता है, जिससे आप डेटा पर ध्यान केंद्रित कर सकते हैं न कि लो‑लेवल फ़ाइल ऑपरेशन्स पर।

### Step 2: एक्सेल टेम्पलेट तैयार करें

`EmployeeTemplate.xlsx` नाम की एक एक्सेल फ़ाइल बनाएं जिसमें एक ही सेल में Smart Marker प्लेसहोल्डर हो:

| A |
|---|
| `${EmployeeMaster}` |

जब प्रोसेसर चलाया जाएगा, तो यह प्लेसहोल्डर को **डिटेल शीट** से बदल देगा जिसमें प्रत्येक कर्मचारी के लिए एक पंक्ति होगी।

> **Why:** प्लेसहोल्डर प्रोसेसर को बताता है कि डेटा कहां इंजेक्ट करना है। एक अलग टेम्पलेट उपयोग करने से आपका फॉर्मेटिंग (फ़ॉन्ट, बॉर्डर, कॉलम चौड़ाई) बरकरार रहता है।

### Step 3: डेटा मॉडल परिभाषित करें

नीचे एक न्यूनतम `Employee` क्लास और एक हेल्पर मेथड दिया गया है जो कर्मचारियों की सूची बनाता है। यह सूची **सूची से कई शीट्स** को प्रदर्शित करने के लिए उपयोग होगी।

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **Why:** एक साधा Java ऑब्जेक्ट (POJO) सीधे Smart Marker फ़ील्ड्स (`firstName`, `lastName`, `department`) से मैप होता है। यह **एक्सेल वर्कबुक पॉप्युलेट** को सरल और टाइप‑सेफ़ बनाता है।

### Step 4: SmartMarkerProcessor सेट अप करें

अब हम सब कुछ जोड़ते हैं। प्रोसेसर टेम्पलेट पढ़ेगा, मार्कर को बदल देगा, और `EmployeeDetail` नाम की नई शीट बनाएगा।

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

**मुख्य लाइनों की व्याख्या**

| पंक्ति | कारण |
|------|--------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | वह टेम्पलेट लोड करता है जिसमें पहले से Smart Marker प्लेसहोल्डर मौजूद है। |
| `data.put("EmployeeMaster", employees);` | Java सूची को मार्कर `${EmployeeMaster}` से बाइंड करता है। |
| `processor.setDetailSheetNewName("EmployeeDetail");` | जेनरेट की गई शीट को डिफ़ॉल्ट `Sheet1` की बजाय एक अर्थपूर्ण नाम देता है। |
| `processor.process(wb, data);` | **वर्कशीट्स जेनरेट करने** – प्रोसेसर मार्कर पढ़ता है, नई शीट बनाता है, और प्रत्येक `Employee` के लिए पंक्तियाँ भरता है। |
| `wb.save("EmployeesReport.xlsx");` | **डायनामिक एक्सेल शीट्स** को डिस्क पर सहेजता है। |

### Step 5: आउटपुट की जाँच करें

`EmployeesReport.xlsx` खोलें। आपको दो वर्कशीट्स दिखनी चाहिए:

1. **Sheet1** – मूल टेम्पलेट (इसे छिपाया या हटाया जा सकता है)।  
2. **EmployeeDetail** – एक **डायनामिक एक्सेल शीट** जिसमें कॉलम `firstName`, `lastName`, `department` और प्रत्येक कर्मचारी के लिए एक पंक्ति होगी।

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **Why this matters:** फ़ाइल अब **सूची से कई शीट्स** बिना किसी मैन्युअल लूप या सेल एड्रेसिंग के रखती है। Smart Marker इंजन पंक्तियों के निर्माण, डेटा रूपांतरण, और फॉर्मेटिंग इनहेरिटेंस का ध्यान रखता है।

### Step 6: एज केस संभालें

#### Empty data list

यदि `employees` खाली है, तो प्रोसेसर अभी भी `EmployeeDetail` शीट बनाता है लेकिन उसे खाली छोड़ देता है। आप प्रोसेसिंग से पहले कलेक्शन साइज चेक करके शीट जोड़ने से बच सकते हैं:

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### Very large lists

हजारों पंक्तियों के लिए मेमोरी एलोकेशन (`-Xmx2g`) बढ़ाने या `processor.setAutoFitRows(false)` उपयोग करने पर प्रोसेसिंग तेज़ हो सकती है।

#### Custom sheet naming per group

यदि आपको प्रत्येक विभाग के लिए अलग शीट चाहिए, तो आप **कई डिटेल शीट्स** का उपयोग कर सकते हैं:

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

प्लेसहोल्डर `${department}` प्रत्येक `Employee` ऑब्जेक्ट से लिया जाता है, जिससे `Dept_Sales`, `Dept_Marketing` आदि जैसी शीट्स बनती हैं।
