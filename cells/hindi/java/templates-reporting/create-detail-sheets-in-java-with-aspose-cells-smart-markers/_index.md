# Create detail sheets in Java with Aspose.Cells smart markers

यदि आपको **Java एप्लिकेशन में detail sheets बनानी हों**, तो यह ट्यूटोरियल Aspose.Cells smart markers के साथ इसे करने का तरीका दिखाता है। आप एक पूर्ण, चलाने योग्य उदाहरण देखेंगे जो **java create worksheets** करता है, **sheet name from field** को निकालता है, और कुछ ही पंक्तियों के कोड में **process data source** को प्रोसेस करता है।

यह गाइड प्रोजेक्ट सेटअप से लेकर अंतिम वर्कबुक को सेव करने तक सब कुछ कवर करता है, ताकि आप समाधान को अपने प्रोजेक्ट में कॉपी‑पेस्ट कर तुरंत अनुकूलित कर सकें। कोई बाहरी दस्तावेज़ीकरण आवश्यक नहीं—आपको जो चाहिए वह सब यहाँ है।

## What you’ll learn

* **smart markers** का उपयोग करके मास्टर डेटा सेट की प्रत्येक पंक्ति के लिए एक टेम्पलेट वर्कशीट को डुप्लिकेट कैसे करें।  
* प्रत्येक नई शीट का नाम फ़ील्ड वैल्यू (जैसे `Order_123`) के आधार पर डायनामिक रूप से कैसे सेट करें।  
* Java कलेक्शन को **process data source** के रूप में smart marker इंजन को कैसे फीड करें।  
* खाली डेटा, शीट नामों में विशेष अक्षर, और बड़े डेटा सेट के लिए प्रदर्शन संबंधी विचारों जैसे एज केस को कैसे संभालें।

### Prerequisites

| Requirement | Reason |
|-------------|--------|
| Java 8 or higher | Aspose.Cells for Java supports Java 8+. |
| Maven or Gradle build system | Simplifies adding the Aspose.Cells dependency. |
| Basic knowledge of Java collections | Needed to build the data source for the smart markers. |
| A template Excel file (`Template.xlsx`) with a placeholder smart marker in cell **A1** | The template drives the detail‑sheet generation. |

> **Pro tip:** Keep the template workbook in the project’s `resources` folder so it’s packaged with your JAR.

## Step 1: Add Aspose.Cells to your project (java create worksheets)

If you use **Maven**, add the following dependency to `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

For **Gradle**, place this line in `build.gradle`:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

These lines make the **java create worksheets** APIs available at compile time.

## Step 2: Load the template workbook

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*Why this matters:* The `Workbook` object is the entry point for all Excel operations. Loading the template ensures you start with the correct layout and any pre‑defined formatting.

## Step 3: Insert a smart marker that creates a new sheet per master row (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

The `${Orders:DetailSheetNewName=Order_${OrderId}}` syntax is the core of **use smart markers**. It does three things:

1. Iterates over the `Orders` collection.  
2. Creates a **new worksheet** for each element.  
3. Sets the **sheet name from field** `OrderId` (prefixed with `Order_`).

## Step 4: Prepare the data source (process data source)

Below is a minimal example using a `List<Map<String, Object>>`. Replace it with your real data source—database rows, JSON deserialization, etc.

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*Why this matters:* The **process data source** step binds your Java collection to the smart marker engine. The key (`"Orders"`) must match the smart marker name exactly.

## Step 5: Process the smart markers (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

When `process` runs, Aspose.Cells reads the `Orders` collection, clones the template worksheet for each entry, and renames each sheet according to the `OrderId` field. This is the heart of **process data source** usage.

## Step 6: Save the workbook with duplicated detail sheets

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

After execution, you’ll find `DuplicatedDetailSheets.xlsx` containing:

* `Sheet1` – the original template (unchanged).  
* `Order_101` – detail sheet for the first order.  
* `Order_102` – detail sheet for the second order.

### Expected output (excerpt)

| Sheet name | A1 (smart marker) | Resulting content |
|------------|-------------------|-------------------|
| Order_101  | `${Orders:...}`   | Populated with data from `order1` |
| Order_102  | `${Orders:...}`   | Populated with data from `order2` |

Open the file in Excel to verify that each sheet is correctly named and contains the data rows.

## Handling common variations and edge cases

### Empty data source

If `orders` is empty, the smart marker processor creates **no new worksheets**. To avoid an empty workbook, add a guard:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### Special characters in sheet names

Excel sheet names cannot contain `\ / ? * [ ] :`. Clean the field before using it:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### Large data sets

For thousands of rows, consider increasing the JVM heap (`-Xmx2g`) and calling `workbook.calculateFormula()` only after all sheets are generated to improve performance.
