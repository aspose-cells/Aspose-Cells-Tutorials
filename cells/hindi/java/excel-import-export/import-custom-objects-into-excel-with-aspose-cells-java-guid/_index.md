# Import custom objects into Excel with Aspose.Cells – Java guide

यदि आपको **कस्टम ऑब्जेक्ट्स** को Excel वर्कशीट में इम्पोर्ट करने की आवश्यकता है, तो यह गाइड Aspose.Cells for Java का उपयोग करके पूरी प्रक्रिया को दिखाता है। आप देखेंगे कि **डेटा को Excel में इम्पोर्ट** कैसे किया जाता है, बोल्ड हेडर स्टाइल कैसे लागू किया जाता है, और तैयार‑से‑शेयर `.xlsx` फ़ाइल कैसे जेनरेट की जाती है।

Java से टेबलर डेटा एक्सपोर्ट करना अक्सर मैन्युअल सेल‑बाय‑सेल लिखने की आवश्यकता पड़ती है, जो त्रुटिप्रवण और रखरखाव में कठिन होती है। `importCustomObjects` API का उपयोग करके आप बायलरप्लेट कोड से बचते हैं, अपना डेटा मॉडल अपरिवर्तित रखते हैं, और स्टाइलिंग पर सूक्ष्म नियंत्रण प्राप्त करते हैं।

इस ट्यूटोरियल में आप करेंगे:

* Java `Map` ऑब्जेक्ट्स की एक लिस्ट बनाएँगे जो सामान्य डेटा टेबल की नकल करती है।
* Aspose.Cells के साथ एक पुन: उपयोग योग्य हेडर स्टाइल (बोल्ड फ़ॉन्ट) बनाएँगे।
* कस्टम ऑब्जेक्ट्स को वर्कशीट में इम्पोर्ट करेंगे और स्टाइल एरे लागू करेंगे।
* वर्कबुक को डिस्क पर सेव करेंगे और परिणाम की पुष्टि करेंगे।

एकमात्र पूर्वापेक्षा एक Java डेवलपमेंट एनवायरनमेंट (JDK 8+ अनुशंसित) और Aspose.Cells for Java लाइब्रेरी है।

## Step 1: Prepare the custom objects to import

पहला चरण वह कलेक्शन बनाना है जो उन पंक्तियों का प्रतिनिधित्व करता है जिन्हें आप Excel में रखना चाहते हैं। इस उदाहरण में हम `List<Map<String,Object>>` का उपयोग करते हैं जहाँ प्रत्येक मैप एक पंक्ति की तरह कार्य करता है और कॉलम नाम कुंजियों के रूप में होते हैं।

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Why this matters:**  
`importCustomObjects` को ऑब्जेक्ट्स का एरे चाहिए। `Map` का उपयोग करके आप कॉलम नाम संरक्षित रखते हैं, जिससे Aspose.Cells उन्हें स्वचालित रूप से सेल्स से मैप कर सकता है। यह दृष्टिकोण .NET के `DataTable` या JDBC के `ResultSet` के समान है, जिससे कोड विभिन्न प्रोजेक्ट्स में पुन: उपयोग योग्य बनता है।

---

## Step 2: Define a header style to apply on import

एक स्पष्ट हेडर पंक्ति पठनीयता को बढ़ाती है। Aspose.Cells आपको `Style` ऑब्जेक्ट बनाने, उसका फ़ॉन्ट बोल्ड सेट करने, और इसे `ImportTableOptions` एरे के माध्यम से पास करने की अनुमति देता है।

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Why this matters:**  
यदि आप स्टाइल एरे को छोड़ देते हैं तो हेडर डिफ़ॉल्ट फ़ॉन्ट में दिखेगा, जो प्रमुख नहीं होगा। एक बार स्टाइल तैयार करके आप प्रत्येक पंक्ति के लिए दोहराव वाले कॉल्स से बचते हैं और इम्पोर्ट लॉजिक साफ़ रहता है।

---

## Step 3: Import the custom objects with the style array

अब आप डेटा और स्टाइल को मिलाते हैं, फिर `importCustomObjects` को कॉल करते हैं। यह मेथड डेटा को टॉप‑लेफ़्ट कॉर्नर (row 0, column 0) से शुरू करता है और हेडर स्टाइल को स्वचालित रूप से लागू करता है।

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Why this matters:**  
`importCustomObjects` प्रत्येक मैप को पार्स करता है, कुंजियों (`Name`, `Score`) के आधार पर कॉलम बनाता है, और मानों को उपयुक्त सेल्स में लिखता है। `ImportTableOptions` ऑब्जेक्ट Aspose.Cells को बताता है कि पहले रो के लिए `styleArray` का उपयोग किया जाए, जिससे अतिरिक्त कोड के बिना बोल्ड हेडर मिल जाता है।

---

## Step 4: Save the workbook and verify the output

अंत में, वर्कबुक को फ़ाइल में लिखें। जेनरेट की गई Excel फ़ाइल में स्टाइल्ड हेडर रो के बाद डेटा रो होते हैं।

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Expected result:**  

| **Name** | **Score** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

हेडर सेल्स (`Name`, `Score`) बोल्ड फ़ॉन्ट में दिखेंगे, जो चरण 2 में परिभाषित स्टाइल से मेल खाता है।

## Common variations and edge cases

| Situation | Recommended adjustment |
|-----------|------------------------|
| **Different column order** | सुनिश्चित करें कि `Map` कुंजियों को इच्छित क्रम में डाला गया है, या एनोटेटेड फ़ील्ड्स वाले कस्टम POJO और `PropertyDescriptor` एरे का उपयोग करें। |
| **Large data sets (>10 000 rows)** | `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` को बढ़ाएँ ताकि `OutOfMemoryError` से बचा जा सके। |
| **Custom number formats** | डेटा रो के लिए `styleArray` में दूसरा `Style` जोड़ें, उदाहरण के लिए `NumberFormat` को `"0"` सेट करें ताकि पूर्णांक स्कोर सही फ़ॉर्मेट में दिखें। |
| **Multiple worksheets** | प्रत्येक लक्ष्य वर्कशीट पर `importCustomObjects` कॉल करें, और आवश्यकतानुसार स्टार्ट रो/कॉलम समायोजित करें। |
| **Locale‑specific header text** | इम्पोर्ट से पहले हेडर रो को मैन्युअली भरें, फिर `Cells.applyStyle` का उपयोग करके पूरे रेंज पर स्टाइल लागू करें। |

## Pro tips for a robust Java export to Excel

* **Reuse the temporary workbook** – प्रत्येक स्टाइल के लिए नया `Workbook` बनाने से ओवरहेड बढ़ता है। यदि कई स्टाइल्स की आवश्यकता हो तो एक ही इंस्टेंस रखें।  
* **Validate data before import** – मैप में `null` मान खाली सेल बनाते हैं; आप लिस्ट को प्री‑प्रोसेस करके डिफ़ॉल्ट वैल्यूज़ सेट कर सकते हैं।  
* **Close resources** – यद्यपि Aspose.Cells आंतरिक रूप से मेमोरी मैनेज करता है, `workbook.dispose()` को स्पष्ट रूप से कॉल करने से नेटिव रिसोर्सेज तुरंत मुक्त होते हैं।  
* **Set `Workbook.setForceFullCalculation(true)`** यदि आपकी वर्कबुक में फ़ॉर्मूले हैं जिन्हें सेव करने से पहले मूल्यांकन करना आवश्यक है।
