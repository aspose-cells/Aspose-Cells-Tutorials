# Java में JSON डेटा के साथ Excel वर्कबुक कैसे बनाएं

यदि आपको **create Excel workbook java** की आवश्यकता है, तो डेवलपर्स अक्सर JSON डेटा को स्प्रेडशीट में लोड करने की चुनौती का सामना करते हैं। यह गाइड आपको दिखाता है कि **populate Excel from JSON** कैसे किया जाता है, जिसमें **convert JSON array excel** और **populate workbook from json** को साफ़ और दोहराने योग्य तरीके से शामिल किया गया है।

जब सेवाएँ REST APIs के माध्यम से डेटा उजागर करती हैं, तो JSON के साथ काम करना सामान्य है, और रिपोर्टिंग और विश्लेषण के लिए Excel अभी भी प्रमुख फ़ॉर्मेट बना रहता है। इस ट्यूटोरियल के अंत तक आपके पास एक चलाने योग्य Java प्रोग्राम होगा जो:

* एक नई Excel वर्कबुक बनाता है,
* एक JSON array (या कोई भी JSON संरचना) पढ़ता है और उसके मानों को सेल्स में लिखता है,
* फ़ाइल को डिस्क पर सहेजता है, जिससे आगे की प्रोसेसिंग के लिए तैयार हो जाता है।

Aspose.Cells for Java लाइब्रेरी के अलावा कोई बाहरी टूल आवश्यक नहीं है, जो नमूना कोड में उपयोग किए गए `SmartMarkerProcessor` को प्रदान करती है।

## पूर्वापेक्षाएँ

शुरू करने से पहले, सुनिश्चित करें कि आपके पास है:

| पूर्वापेक्षा | कारण |
|--------------|--------|
| Java Development Kit (JDK) ≥ 8 | उदाहरण को संकलित और चलाने के लिए आवश्यक है |
| Maven or Gradle (optional) | निर्भरता प्रबंधन को सरल बनाता है |
| Aspose.Cells for Java (v23.10 or later) | `Workbook` और `SmartMarkerProcessor` क्लासेस प्रदान करता है |
| Basic knowledge of JSON and Java I/O | डेटा प्रवाह को समझने में मदद करता है |

यदि आप बिल्ड टूल का उपयोग नहीं करना चाहते हैं, तो आप Aspose.Cells JAR को [Aspose वेबसाइट](https://products.aspose.com/cells/java/) से डाउनलोड कर सकते हैं और इसे मैन्युअल रूप से अपने प्रोजेक्ट के क्लासपाथ में जोड़ सकते हैं।

## चरण 1: प्रोजेक्ट सेट अप करें और Aspose.Cells निर्भरता जोड़ें

### Maven उपयोगकर्ता

Add the following dependency to your `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Gradle उपयोगकर्ता

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

If you are not using a build tool, place the downloaded JAR in the `libs/` folder and include it on the classpath when compiling:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## चरण 2: नई वर्कबुक बनाएं और SmartMarker प्रोसेसर को कॉन्फ़िगर करें

`SmartMarkerProcessor` JSON मानों को Excel सेल्स में मैप करने को सरल बनाता है। `setArrayAsSingle(true)` को कॉल करके हम प्रोसेसर को बताते हैं कि पूरी JSON array को एकल मान के रूप में माना जाए, जो तब उपयोगी होता है जब आप चाहते हैं कि प्रत्येक तत्व एक पंक्ति में अपने स्वयं के सेल में हो।

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**यह क्यों महत्वपूर्ण है:**  
वर्कबुक को पहले से बनाना आपको एक साफ़ कैनवास देता है। `setArrayAsSingle(true)` को कॉन्फ़िगर करने से प्रोसेसर को array को एकल स्ट्रिंग (जैसे `["A","B","C"]`) में फ्लैटन करने से रोका जाता है और इसके बजाय आप लेआउट को मैन्युअल रूप से नियंत्रित कर सकते हैं।

## चरण 3: वह JSON डेटा परिभाषित करें जिसे आप सम्मिलित करना चाहते हैं

इस ट्यूटोरियल के लिए हम एक सरल JSON array का उपयोग करते हैं, लेकिन यही तरीका ऑब्जेक्ट्स, नेस्टेड arrays, या जटिल संरचनाओं के साथ भी काम करता है।

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**टिप:** यदि आपका JSON फ़ाइल या REST endpoint से आता है, तो लिटरल स्ट्रिंग को स्रोत से पढ़ी गई `String` से बदलें, उदाहरण के लिए `Files.readString(Paths.get("data.json"))`।

## चरण 4: JSON डेटा के साथ वर्कबुक प्रोसेस करें

अब हम `SmartMarkerProcessor` को JSON array को पहले worksheet पर मैप करने देते हैं। डिफ़ॉल्ट व्यवहार प्रत्येक तत्व को क्रमिक सेल्स में `A1` से शुरू करके लिखता है।

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

पर्दे के पीछे, Aspose.Cells JSON को पार्स करता है, एक अस्थायी डेटा टेबल बनाता है, और मानों को worksheet में लिखता है। क्योंकि हमने `ArrayAsSingle` को `true` सेट किया है, array के तत्व पहली पंक्ति में क्षैतिज रूप से रखे जाते हैं।

## चरण 5: वर्कबुक को फ़ाइल में सहेजें

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

जब आप प्रोग्राम चलाते हैं, तो आपके कार्य निर्देशिका में **CreatedFromJson.xlsx** नाम की फ़ाइल दिखाई देगी। इसे Excel (या किसी भी संगत व्यूअर) से खोलने पर यह दिखेगा:

| A | B | C |
|---|---|---|
| A | B | C | *(मान सेल्स A1, B1, C1 में दिखाई देते हैं)*

## चरण 6: अधिक जटिल JSON संरचनाओं को संभालना (वैकल्पिक)

### 6.1 JSON ऑब्जेक्ट से वर्कबुक को पॉपुलेट करना

यदि आपका JSON array के बजाय एक ऑब्जेक्ट है, तो आप अभी भी `SmartMarkerProcessor` का उपयोग कर सकते हैं। उदाहरण के लिए:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

प्रोसेसर named ranges (`title`, `month`, `values`) बनाएगा जिन्हें आप अपने Excel टेम्पलेट में Smart Markers जैसे `&=title` और `&=values` का उपयोग करके संदर्भित कर सकते हैं।

### 6.2 नेस्टेड JSON array को वर्टिकल सूची में बदलना

कभी-कभी आपको array को पंक्ति के बजाय कॉलम में भरना पड़ता है। प्रोसेसिंग से पहले प्रारंभिक सेल को मैन्युअल रूप से सेट करें:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

अब मान **A**, **B**, **C** क्रमशः सेल्स A2, A3, A4 में दिखाई देते हैं।

## सामान्य समस्याएँ और उन्हें कैसे टालें

| समस्या | कारण | समाधान |
|-------|-------|-----|
| **Array written as a single string** | `setArrayAsSingle(false)` (default) | Call `processor.setArrayAsSingle(true)` |
| **File not found when saving** | अमान्य पथ या लिखने की अनुमति नहीं होना | एक पूर्ण पथ का उपयोग करें या सुनिश्चित करें कि डायरेक्टरी मौजूद है |
| **JSON parsing error** | गलत स्वरूपित JSON स्ट्रिंग | JSON को किसी टूल से वैलिडेट करें या Jackson जैसी लाइब्रेरी का उपयोग करके स्ट्रिंग जनरेट करें |
| **Cells overwritten unintentionally** | स्टार्ट सेल को रीसेट किए बिना एक ही worksheet को कई बार प्रोसेस करना | Call `processor.setStartCell("A1")` before each `process` call |

## प्रो टिप: वर्कबुक को टेम्पलेट के रूप में पुन: उपयोग करें

हर बार एक खाली वर्कबुक से शुरू करने के बजाय, आप एक पूर्व-डिज़ाइन किया हुआ टेम्पलेट लोड कर सकते हैं जिसमें पहले से हेडर, फ़ॉर्मूले या स्टाइलिंग मौजूद हों:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

यह तरीका हाथ से तैयार किए गए Excel फ़ाइल की दृश्य परिष्कार को **populate workbook from json** की ऑटोमेशन के साथ मिलाता है।
