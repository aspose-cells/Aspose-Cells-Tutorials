# Как экспортировать данные в Excel с помощью шаблона C# – пошаговое руководство

Если вам нужно **экспортировать данные в Excel** из .NET‑приложения, это руководство показывает полное решение, работающее от начала до конца. Загрузив шаблон Excel, уже содержащий теги Smart Marker, вы можете **автоматизировать генерацию Excel** и создать аккуратный **employee report Excel** без написания кода построчно‑по‑ячейкам.

Вы увидите, как:

* Загрузить шаблон Excel (`load excel template`), определяющий макет.  
* Передать список объектов сотрудника в шаблон.  
* Сгенерировать окончательную книгу и сохранить её как `output.xlsx`.

Весь необходимый код включён, так что вы можете скопировать, вставить и сразу выполнить его.

## Предварительные требования

* .NET 6.0 или новее (код также работает с .NET Framework 4.7+).  
* Пакет NuGet **Aspose.Cells for .NET** — он предоставляет `Workbook`, `SmartMarkerProcessor` и поддержку Smart Marker.  
* Папка с именем `YOUR_DIRECTORY`, содержащая `template.xlsx`. Шаблон должен иметь теги Smart Marker, например `&=EmployeeList.Name`, в ячейках, где должны появиться данные.

> **Совет:** Держите шаблон в той же папке проекта и установите свойство *Copy to Output Directory* в значение *Copy always*, чтобы путь корректно разрешался во время отладки.

## Полный исходный код

```csharp
using System;
using System.Collections.Generic;
using Aspose.Cells;

namespace ExcelExportDemo
{
    // Simple POCO that represents an employee record
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Step 1: Load the Excel template that contains Smart Marker tags
            string templatePath = @"YOUR_DIRECTORY\template.xlsx";
            Workbook wb = new Workbook(templatePath);

            // Step 2: Prepare a data source – a list of employee objects
            List<Employee> employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Step 3: Create a SmartMarkerProcessor instance
            SmartMarkerProcessor sp = new SmartMarkerProcessor();

            // Step 4: Apply the employee data to the workbook using the processor
            // The tag &amp;=EmployeeList.Name in the template will be replaced with each employee's name,
            // and &amp;=EmployeeList.Position will be replaced with the corresponding position.
            sp.Process(wb, employeeList);

            // Step 5: Save the populated workbook
            string outputPath = @"YOUR_DIRECTORY\output.xlsx";
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

### Что делает код

| Шаг | Почему это важно | Ключевая строка(и) |
|------|-------------------|--------------------|
| **Загрузка шаблона Excel** | Повторное использование заранее разработанного макета экономит время и гарантирует единообразный стиль. | `Workbook wb = new Workbook(templatePath);` |
| **Подготовка источника данных** | Smart Markers работают с любой коллекцией `IEnumerable`; здесь мы используем список `Employee`. | `List<Employee> employeeList = …` |
| **Создание процессора** | `SmartMarkerProcessor` разбирает шаблон, находит теги и вставляет данные. | `SmartMarkerProcessor sp = new SmartMarkerProcessor();` |
| **Обработка данных** | Процессор заменяет каждый тег Smart Marker соответствующим значением свойства. | `sp.Process(wb, employeeList);` |
| **Сохранение книги** | Итоговый файл можно отправить пользователю, сохранить на сервере или вложить в письмо. | `wb.Save(outputPath);` |

В результате получается файл **employee report Excel**, где каждая строка содержит имя и должность сотрудника, точно в тех местах, где теги были размещены в оригинальном шаблоне.

## Загрузка шаблона Excel

Когда вы `load excel template` с помощью `new Workbook(path)`, Aspose.Cells считывает всю книгу — включая стили, формулы и заполнители Smart Marker. Такой подход предпочтительнее создания книги с нуля, потому что:

* **Контроль дизайна** — Дизайнеры могут форматировать заголовки, добавлять логотипы компании и задавать ширину столбцов без изменения кода.  
* **Версионирование** — Обновление шаблона не требует перекомпиляции приложения.  
* **Локализация** — Можно хранить отдельные файлы шаблонов для разных языков.

Если вы предпочитаете чистое .NET‑решение без сторонних библиотек, можно использовать **ClosedXML** или **EPPlus**, но они не имеют встроенной поддержки Smart Marker, что означает необходимость писать циклы, копирующие данные ячейка за ячейкой.

## Автоматизация генерации Excel с помощью Smart Markers

Smart Markers — это заполнители, выглядящие как `&=Collection.Property`. Когда процессор запускается:

* Он перебирает коллекцию (`employeeList` в нашем примере).  
* Для каждого элемента записывает значение свойства в соответствующую ячейку.  
* Автоматически расширяет строки или столбцы по мере необходимости.

Этот механизм **автоматизирует генерацию Excel** и устраняет необходимость ручной итерации. Та же схема работает с любыми типами данных — заказы, счета, списки инвентаря и т.д.

### Распространённые варианты

| Вариант | Как реализовать |
|-----------|------------------|
| **Несколько коллекций** | Добавьте дополнительные списки (например, `List<Department>`) и ссылаться на них с помощью разных тегов, например `&=DepartmentList.Name`. |
| **Вложенные коллекции** | Используйте точечную нотацию: `&=EmployeeList.Projects.ProjectName`, где `Projects` — свойство‑коллекция внутри `Employee`. |
| **Условное форматирование** | Разместите правило условного форматирования Excel в шаблоне; процессор сохранит его для сгенерированных строк. |

## Создание отчёта Excel о сотрудниках

Термин **employee report Excel** обозначает типичный бизнес‑случай: менеджер хочет распечатываемый список сотрудников. Внедрив теги Smart Marker непосредственно в шаблон, вы получаете:

* Строку заголовка с полужирным шрифтом и фоновым цветом.  
* Автоматически подгоняемые столбцы по данным.  
* При желании строки итогов (например, количество сотрудников), которые можно вычислить стандартными формулами Excel.

Если нужно добавить строку итогов, просто разместите формулу вроде `=COUNTA(A2:A100)` в шаблоне; процессор её не изменит.

## Генерация шаблона Excel C# — лучшие практики

При написании кода **generate Excel template C#** учитывайте следующие рекомендации:

1. **Разделяйте ответственности** — Держите загрузку шаблона, подготовку данных и их обработку в отдельных методах. Это упрощает модульное тестирование.  
2. **Проверяйте ввод** — Убедитесь, что файл шаблона существует, а коллекция данных не null перед вызовом `Process`.  
3. **Освобождайте ресурсы** — Хотя Aspose.Cells управляет памятью, оберните `Workbook` в блок `using`, если работаете с большими файлами.  
4. **Обрабатывайте исключения** — Перехватывайте `Exception` вокруг `sp.Process`, чтобы выявлять проблемы, такие как несоответствие имён тегов.  

```csharp
static Workbook LoadTemplate(string path)
{
    if (!File.Exists(path))
        throw new FileNotFoundException($"Template not found: {path}");
    return new Workbook(path);
}
```

## Ожидаемый результат

После запуска программы откройте `output.xlsx`. Вы должны увидеть лист, выглядящий так (упрощённый вид):

| Имя | Должность |
|-----------|------------|
| John Doe  | Developer  |
| Jane Smith| Manager    |

Всё форматирование из `template.xlsx` — например, фон заголовка, ширина столбцов и любые изображения логотипов — остаётся неизменным.

## Устранение распространённых проблем

| Симптом | Возможная причина | Решение |
|---------|-------------------|----------|
| No data appears after processing | Теги Smart Marker написаны с ошибкой или находятся в объединённых ячейках. | Убедитесь, что теги точно соответствуют синтаксису `&=Collection.Property` и не находятся внутри объединённых областей. |
| Output file is empty or corrupted | Книга была сохранена до завершения обработки. | Убедитесь, что `sp.Process` выполняется **до** `wb.Save`. |
| Large employee list slows down generation | Использование бесплатной версии Aspose.Cells может иметь ограничения производительности. | Обновите до лицензированной версии или обрабатывайте данные пакетами. |
| Template path is wrong | Относительный путь разрешается в другую папку во время выполнения. | Используйте `Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "template.xlsx")` или установите свойство файла `Copy to Output Directory`. |

## Полный обзор примера

Ниже приведена вся программа в одном блоке для быстрого копирования‑вставки:

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Load the template
            string templatePath = Path.Combine("YOUR_DIRECTORY", "template.xlsx");
            Workbook wb = new Workbook(templatePath);

            // Prepare data
            var employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Process Smart Markers
            var sp = new SmartMarkerProcessor();
            sp.Process(wb, employeeList);

            // Save the result
            string outputPath = Path.Combine("YOUR_DIRECTORY", "output.xlsx");
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

Запуск этой программы создаёт файл **employee report Excel**, который можно отправить по электронной почте, распечатать или дальше обрабатывать.

## Следующие шаги

* **Добавить диаграммы** — Разместите заполнитель диаграммы в шаблоне; процессор сохранит связь диаграммы с сгенерированными данными.  
* **Экспорт в другие форматы** — Aspose.Cells может сохранять напрямую в PDF, CSV или HTML (`wb.Save("report.pdf")`).  
* **Интеграция с ASP.NET Core** — Возвратите сгенерированную книгу как загрузку файла в действии контроллера.

Не стесняйтесь экспериментировать с дополнительными коллекциями, условным форматированием или динамическими формулами, чтобы удовлетворить потребности вашего проекта. Приятного кодинга!
