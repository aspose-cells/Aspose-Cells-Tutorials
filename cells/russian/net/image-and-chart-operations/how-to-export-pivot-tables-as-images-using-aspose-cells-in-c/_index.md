# Как экспортировать сводные таблицы в виде изображений с помощью Aspose.Cells в C#

Если вам нужно **how to export pivot** данные в переносимый рисунок, Aspose.Cells делает процесс простым. Этот учебник показывает, как экспортировать сводные таблицы в файлы PNG, чтобы вы могли вставлять их в отчёты, электронные письма или документацию без необходимости наличия Excel на целевой машине.

Экспорт сводной таблицы в виде изображения устраняет проблемы форматирования, зависящие от версии, и позволяет нетехническим заинтересованным сторонам мгновенно просматривать анализ. Мы рассмотрим всё от настройки проекта до рендеринга окончательного **export pivot table image**, а также объясним, как **save pivot as image** для будущего повторного использования.

## Как экспортировать сводные таблицы в виде изображений с Aspose.Cells

Ниже представлен полный, готовый к выполнению пример, который загружает книгу, обновляет сводную таблицу, настраивает параметры изображения и записывает выходной файл. Каждый шаг включает краткое обоснование, чтобы вы понимали *почему* код написан именно так, а не только *что* он делает.

### 1. Настройка среды Aspose.Cells

1. Установите пакет NuGet:

   ```bash
   dotnet add package Aspose.Cells
   ```

2. Добавьте необходимые директивы `using` в начало вашего C# файла:

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **Pro tip:** Нацельтесь на .NET 6 или новее, чтобы воспользоваться последними улучшениями производительности в Aspose.Cells.

### 2. Загрузка книги и поиск сводной таблицы

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*Почему это важно:* Класс `Workbook` разбирает файл XLSX и предоставляет доступ ко всем листам. Выбор правильного листа имеет решающее значение, поскольку книга может содержать несколько сводных таблиц.

### 3. Обновление сводной таблицы для захвата последних исходных данных

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

Обновление гарантирует, что любые изменения, внесённые в исходный диапазон после сохранения файла, отразятся в отрисованном изображении. Пропуск этого шага может привести к устаревшим или неточным визуализациям.

### 4. Настройка параметров экспорта изображения (export pivot table image)

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

Объект `ImageOrPrintOptions` позволяет управлять форматом, разрешением и другими деталями рендеринга. PNG — самый распространённый выбор для чёткой, совместимой с веб‑графикой, но при необходимости уменьшения размера файла можно переключиться на `ImageFormat.Jpeg`.

### 5. Рендеринг и **save pivot as image**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

`RenderToImage` выполняет основную работу: он рисует сводную таблицу точно так же, как она выглядит в Excel, и записывает бинарные данные PNG на диск. Метод возвращает `void`, поэтому вы можете с уверенностью предположить, что файл существует после завершения вызова, без необходимости дополнительных проверок.

После выполнения программы вы найдете `Pivot.png` в указанной папке. Открытие файла должно показать точную копию оригинальной сводной таблицы, включая заголовки столбцов, итоги строк и любое применённое форматирование.

### 6. Распространённые варианты и граничные случаи

| Сценарий | Корректировка |
|----------|------------|
| **Large pivots** (many rows/columns) | Увеличьте `HorizontalResolution` и `VerticalResolution` до 300 dpi для более чёткого вывода. |
| **Custom styling** (background colors, fonts) | Убедитесь, что определения стилей книги загружены перед вызовом `Refresh()`. |
| **Multiple pivots** in one sheet | Пройдитесь по `worksheet.PivotTables` и вызовите `RenderToImage` для каждой, используя разные имена файлов. |
| **Export to JPEG** instead of PNG | Измените `ImageFormat = ImageFormat.Jpeg` и при желании задайте `Quality` в объекте `JpegSaveOptions`. |

Эти варианты позволяют вам **export pivot table image** в точном формате, ожидаемом вашей downstream системой.

## Полный исходный код для быстрого копирования

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

Запуск программы создаёт PNG‑файл, показанный выше, завершая процесс **save pivot as image** менее чем за минуту.
