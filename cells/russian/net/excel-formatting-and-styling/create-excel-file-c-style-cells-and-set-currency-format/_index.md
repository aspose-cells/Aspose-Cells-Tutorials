# Создать Excel файл c# – стилизация ячеек и установка формата валюты

Если вам нужно **создать Excel файл c#**, который выглядит профессионально, это руководство покажет, как именно стилизовать ячейки Excel и задать формат валюты для столбца. Вы увидите полный пример от начала до конца, который импортирует `DataTable`, применяет жирный заголовок и задаёт числовой формат `$#,##0.00` для столбца цены.

В руководстве покрыты все необходимые детали: требуемые пакеты NuGet, полный исходный код, объяснения, почему каждый элемент важен, и советы по работе с особенностями, такими как пустые строки или разные локали. К концу вы сможете генерировать файл `.xlsx` с красиво отформатированным столбцом цены всего в несколько строк C#.

## Предварительные требования

- .NET 6.0 или новее (код также работает с .NET Framework 4.6+)
- Visual Studio 2022 или любой другой редактор C#
- Библиотека **Aspose.Cells for .NET** или **GemBox.Spreadsheet** (обе поддерживают `ImportTableOptions`). В примере ниже используется **Aspose.Cells**, потому что она предоставляет простое свойство `StyleArray`.
- Базовые знания о коллекциях C# и `DataTable`

> **Pro tip:** Если вы предпочитаете бесплатную альтернативу, замените `Aspose.Cells` на `GemBox.Spreadsheet`. API для импорта `DataTable` со стилями почти идентично; просто измените пространство имён и название пакета NuGet.

## Шаг 1: Установить библиотеку Excel

Откройте менеджер пакетов NuGet и установите библиотеку:

```bash
dotnet add package Aspose.Cells
```

> **Почему этот шаг?** Библиотека предоставляет классы `Workbook`, `Worksheet`, `Style` и `ImportTableOptions`, которые используются дальше. Без неё вам пришлось бы писать формат Office Open XML вручную, что подвержено ошибкам.

## Шаг 2: Создать DataTable с примерными данными

`DataTable` — удобный способ хранить табличные данные перед экспортом в Excel. В этом примере у нас два столбца: *Product* и *Price*.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Объяснение:**  
> - `Columns.Add("Price", typeof(double))` указывает таблице рассматривать значения цены как числа, что необходимо для последующего форматирования.  
> - Добавление нескольких строк даёт данные для проверки шага **format column currency**.

## Шаг 3: Определить стили, которые нужно применить

Мы создадим массив объектов `Style`, соответствующий порядку столбцов. Первый элемент стилизует строку заголовка, второй оставляет столбец *Product* без изменений, а третий задаёт числовой формат валюты.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### Почему использовать **style array**?

`ImportTableOptions.StyleArray` сопоставляет каждый столбец со `Style`. Это самый эффективный способ **add number format** и **style excel cells** за одну операцию импорта, избегая второго прохода по листу.

## Шаг 4: Настроить параметры импорта

Теперь привязываем массив стилей к операции импорта. Объект `ImportTableOptions` также позволяет управлять тем, будет ли первая строка рассматриваться как заголовок.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Примечание:** `IsFieldNameShown` по умолчанию `true`, но явное указание делает намерение ясным для будущих читателей.

## Шаг 5: Создать рабочую книгу, импортировать таблицу и сохранить

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### Ожидаемый результат

При открытии `DataTableWithStyles.xlsx`:

- Первая строка (заголовок) **жирная**.
- Столбец *Price* отображает значения как **$1.20**, **$3.50**, **$0.75**.
- Столбец *Product* сохраняет шрифт по умолчанию.

Вы успешно **создали Excel файл c#** с отформатированным столбцом валюты и стилизованными ячейками заголовка.

## Шаг 6: Обработка распространённых вариантов и граничных случаев

### a. Другая локаль или пользовательский символ валюты

Если нужна евро или другая валюта, замените встроенный формат `164` на пользовательскую строку формата:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. Добавление дополнительных столбцов позже

При добавлении новых столбцов расширьте массив `columnStyles` соответствующим образом. Для столбцов, которые должны сохранять стиль по умолчанию, используйте `null`.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. Пустой DataTable

Если в `DataTable` нет строк, Aspose.Cells всё равно создаёт строку заголовка. Однако рабочая книга будет содержать только одну строку. Чтобы избежать пустого файла, проверьте количество строк перед импортом:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Использование `GemBox.Spreadsheet` вместо Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

Логика остаётся идентичной, демонстрируя, что руководство **format column currency** независимо от выбранной библиотеки.

## Шаг 7: Программная проверка файла (необязательно)

Можно открыть сгенерированную рабочую книгу и убедиться, что числовой формат применён корректно — полезно для модульных тестов.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```
