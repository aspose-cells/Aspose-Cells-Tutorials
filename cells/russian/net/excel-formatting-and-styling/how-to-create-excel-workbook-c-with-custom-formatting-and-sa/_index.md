# Как создать Excel‑книгу C# с пользовательским форматированием и сохранить как XLSX

Если вам нужно **создать Excel‑книгу C#**, которая импортирует данные, применяет пользовательский числовой формат и меняет цвет шрифта ячейки, этот учебник покажет, как это сделать. Вы получите готовый к запуску пример, который за секунды создаст стилизованный файл `StyleArrayImport.xlsx`.

Работа с Excel из C# часто требует повторяющихся ручных действий — определения форматов, применения цветов и правильного сохранения файла. К концу этого руководства вы автоматизируете все эти задачи, чтобы сосредоточиться на данных, а не на пользовательском интерфейсе.

Вы узнаете, как:

* импортировать `DataTable` в лист,
* использовать `StyleArray` для **применения пользовательского числового формата** и **изменения цвета шрифта ячейки**,
* **сохранить книгу как XLSX** одним вызовом метода,
* и убедиться, что **format imported data excel** выглядит точно так, как задумано.

Единственное требование — наличие ссылки на библиотеку **Aspose.Cells for .NET** (или любой совместимый API, предоставляющий `Workbook`, `Worksheet` и `StyleArray`). Код рассчитан на .NET 6+, но более ранние версии работают с небольшими изменениями.

## Step 1: Prepare the sample DataTable

Сначала создайте `DataTable`, имитирующую данные, которые обычно получаете из базы данных или другого источника. Таблица содержит столбец **Name** (string) и столбец **Amount** (decimal), который мы отформатируем позже.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Почему это важно:** Использование `DataTable` позволяет держать логику импорта независимой от источника данных, что является распространённым шаблоном при генерации отчётов из баз данных, CSV‑файлов или API.

## Step 2: Define a StyleArray to **apply custom number format** and **change cell font color**

`StyleArray` позволяет собрать инструкции форматирования, которые будут применяться к каждой ячейке, импортируемой из `DataTable`. В этом примере мы:

* задаём `Number` как `#,##0.00` — типичный бухгалтерский формат с разделителями тысяч,
* задаём `FontColor` как `Color.Blue` — чтобы числа выделялись.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**Зачем нужен StyleArray?** Применение стиля во время импорта избавляет от второго прохода по листу, что повышает производительность при работе с большими наборами данных.

---

## Step 3: **Create Excel workbook C#** – instantiate Workbook and get the first Worksheet

Теперь создаём пустую книгу и получаем ссылку на первый лист (индекс 0). Этот лист будет назначен получателем наших импортированных данных.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Пояснение:** `Workbook` представляет весь файл Excel, а `Worksheet` — отдельную вкладку. По умолчанию книга содержит один лист, чего достаточно для большинства простых отчётов.

---

## Step 4: Import the DataTable using the **StyleArray** to **format imported data excel**

Метод `ImportDataTable` копирует строки и столбцы таблицы в лист, начиная с ячейки `A1` (строка 0, столбец 0). Параметр `true` указывает включить заголовки столбцов. Поскольку мы передаём `styleArray`, каждая импортированная ячейка получает пользовательский числовой формат и цвет шрифта.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**Что происходит под капотом:** Aspose.Cells проходит по каждой строке, записывает значение, а затем применяет стиль, определённый в `styleArray`. Числа отображаются с запятыми и двумя знаками после запятой, а текст — синим цветом.

---

## Step 5: **Save workbook as XLSX** – write the file to disk

Наконец, сохраняем книгу в файл формата `.xlsx`. При желании измените путь на любой доступный каталог на вашем компьютере.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Проверка результата:** Откройте сгенерированный файл в Excel. Вы должны увидеть три строки данных, столбец **Amount** отформатирован с запятыми, двумя десятичными знаками и отображается синим шрифтом. Это подтверждает успешное выполнение шага **format imported data excel**.

## Full Working Example

Скопируйте весь блок ниже в новый консольный проект и запустите его. Дополнительный код не требуется.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Ожидаемый вывод в консоли:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

Откройте файл и убедитесь, что столбец **Amount** показывает значения вроде `1,234.56` синим шрифтом.

## Common Questions & Edge Cases

| Вопрос | Ответ |
|--------|-------|
| *Можно ли применить разные форматы к отдельным столбцам?* | Да. После импорта получите объект `Style` столбца (`worksheet.Cells.Columns[1].Style`) и задайте иной `Number` или `FontColor`. |
| *Что делать, если нужно форматировать даты вместо чисел?* | Установите `styleArray.Number = "mm-dd-yyyy"` и при необходимости `styleArray.FontColor` для ячеек дат. |
| *Виден ли синий шрифт на тёмных темах Excel?* | Синий может быть плохо читаем на тёмном фоне. Используйте более светлый оттенок (`Color.LightBlue`) или контрастный цвет (`Color.Black`). |
| *Как импортировать очень большую `DataTable` (сотни тысяч строк)?* | Используйте перегрузку `ImportDataTable` с параметром `ImportDataTableOptions` для потоковой передачи данных, либо разбейте импорт на несколько листов, чтобы не превысить ограничение Excel (1 048 576 строк). |
| *Можно ли экспортировать в CSV вместо XLSX?* | Замените `SaveFormat.Xlsx` на `SaveFormat.Csv`. Учтите, что информация о форматировании (числовой формат, цвет шрифта) теряется в CSV, так как это простой текстовый формат. |

## Tips for Production Use

* **Pro tip:** Кешируйте объект `Style`, если нужно применять одинаковое форматирование к множеству листов; создание нового `StyleArray` для каждого импорта добавляет накладные расходы.
* **Обратите внимание на культурные различия:** Шаблон `Number` `#,##0.00` соответствует инвариантной культуре. Если нужны локальные разделители, используйте `NumberFormatInfo` или позвольте Excel подобрать их согласно региональным настройкам пользователя.
* **Обработка ошибок:** Оберните вызов `Save` в блок `try‑catch`, чтобы перехватывать исключения ввода‑вывода (например, недостаточные права или заблокированные файлы).
