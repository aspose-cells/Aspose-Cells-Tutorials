# Как внедрять шрифты при сохранении Excel в HTML с помощью C#

Как внедрять шрифты при сохранении рабочей книги Excel в HTML — это распространённая потребность для сохранения точного внешнего вида ваших таблиц во всех браузерах. Если вам нужно экспортировать Excel в HTML, сохранив оригинальные шрифты, это руководство покажет готовое решение, готовое к запуску.

Вы узнаете, как **экспортировать Excel в HTML**, **конвертировать Excel в HTML** с внедрёнными шрифтами и избежать типичной проблемы «отсутствующего шрифта», которая ломает макет на клиентских машинах. Внешние инструменты не требуются — только библиотека Aspose.Cells и несколько строк кода на C#.

## Prerequisites

Перед началом убедитесь, что у вас есть:

* .NET 6.0 (или новее) установлен.
* Лицензированная копия **Aspose.Cells for .NET** — бесплатная пробная версия подходит для тестирования.
* IDE, например Visual Studio 2022 или VS Code.

Если всё уже готово, можете сразу переходить к коду.

## Step 1: Create a workbook and add sample data

Сначала мы создаём небольшую рабочую книгу, чтобы вы могли увидеть эффект внедрённых шрифтов. Приведённый ниже код создаёт лист, записывает несколько ячеек и применяет пользовательский шрифт.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### Why we add a custom font

Внедрение шрифтов имеет смысл только тогда, когда рабочая книга использует шрифты, которые могут отсутствовать на клиентском устройстве. Явно задав **Arial** (или любой другой шрифт), мы можем убедиться, что HTML‑вывод действительно содержит данные шрифта.

## Step 2: Configure HTML save options to embed fonts

Aspose.Cells предоставляет класс `HtmlSaveOptions`. Установка `EmbedFonts = true` сообщает библиотеке внедрять необходимые файлы шрифтов непосредственно в генерируемый HTML в виде Base64‑закодированных URI.

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### What “embed fonts in html” really does

Когда `EmbedFonts` равно `true`, Aspose.Cells извлекает файлы шрифтов из системы (или из встроенной коллекции шрифтов рабочей книги) и преобразует их в строки **Base64**. Эти строки затем помещаются в блок `<style>` с помощью правила `@font-face`. Полученный HTML можно открыть на любом устройстве без необходимости установки оригинального шрифта.

## Step 3: Save the workbook as HTML with embedded fonts

Теперь сохраняем рабочую книгу на диск. Файл будет содержать данные шрифта, поэтому открытие его в любом современном браузере покажет точно такой же набор типографики, как в оригинальном файле Excel.

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### Expected result

* `embedded.html` находится в папке `output`.
* Открытие файла в Chrome, Edge или Firefox отображает лист с текстом **Arial**, даже если на машине браузера Arial не установлен.
* При просмотре исходного кода HTML вы увидите блок `<style>`, содержащий правило `@font-face` с длинным объявлением `src: url(data:font/ttf;base64,…)` — это внедрённый шрифт.

## Step 4: Verify the HTML works on another machine (optional)

Чтобы быть полностью уверенным, что внедрение прошло успешно:

1. Скопируйте `output/embedded.html` на другой компьютер (или виртуальную машину), где **не** установлен пользовательский шрифт.
2. Откройте файл в браузере.
3. Макет и типографика должны соответствовать оригинальному виду в Excel.

Если шрифт переключается на общий, проверьте, что файл шрифта доступен на машине сборки и что у вас есть права на его чтение.

## Common questions and edge cases

### Does embedding increase file size?

Да. Внедрение TrueType или OpenType шрифта может добавить **десятки килобайт** к HTML‑файлу. Для больших книг с множеством уникальных шрифтов рассмотрите:

* Подборку шрифта (только используемые символы) — Aspose.Cells делает это автоматически для большинства распространённых шрифтов.
* Использование `ExportEmbeddedImages = false`, если вам не нужны встроенные изображения.

### What if I need to embed only specific fonts?

`HtmlSaveOptions` не предоставляет прямой «белый список», но вы можете контролировать, какие шрифты попадают в вывод, **ограничивая шрифты, используемые в рабочей книге**, перед вызовом `Save`. Удалите лишние назначения шрифтов или замените их стандартными веб‑безопасными шрифтами.

### Can I embed fonts when converting to other formats (e.g., PDF)?

То же свойство `EmbedFonts` существует в `PdfSaveOptions`. Принцип идентичен: данные шрифта внедряются, чтобы PDF корректно отображался в любом просмотрщике.

## Full, runnable example

Ниже приведена полная программа, которую можно скопировать и вставить в новый консольный проект.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

Запуск программы создаёт **HTML‑файл, содержащий внедрённый шрифт Arial**, гарантируя визуальное соответствие независимо от того, где файл открыт.

## Conclusion

Теперь вы знаете, **как внедрять шрифты при сохранении Excel в HTML** с помощью C#. Настроив `HtmlSaveOptions.EmbedFonts = true`, вы надёжно **экспортируете Excel в HTML** и **конвертируете Excel в HTML** без опасений по поводу отсутствия шрифтов на клиентской стороне. Эта техника незаменима для веб‑отчётности, дашбордов, пригодных для электронной почты, или любой ситуации, когда вы делитесь контентом, полученным из Excel, в виде HTML.

### What’s next?

* **Настройте CSS**, генерируемый Aspose.Cells, под стиль вашего сайта.  
* **Внедряйте изображения** выборочно, переключая `ExportEmbeddedImages`.  
* **Исследуйте другие форматы экспорта**, такие как PDF или SVG, при этом продолжая внедрять шрифты.  

Экспериментируйте с разными шрифтами, более крупными листами или книгами с несколькими листами. Флаг `EmbedFonts` работает во всех поддерживаемых форматах вывода, предоставляя единый контроль над внедрением шрифтов там, где это необходимо. Приятного кодинга!
