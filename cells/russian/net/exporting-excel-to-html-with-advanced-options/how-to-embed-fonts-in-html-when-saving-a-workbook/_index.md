# Как внедрять шрифты в HTML при сохранении книги

Если вам нужно **как внедрять шрифты в HTML** при экспорте таблицы, этот учебник покажет готовое решение, готовое к запуску. Независимо от того, создаёте ли вы портал отчётности или клиентскую аналитическую панель, внедрение шрифтов гарантирует, что отображаемый HTML будет точно соответствовать оригинальной книге, независимо от установленных у пользователя шрифтов.

Вы также узнаете лучший способ **сохранить книгу как HTML** с помощью Aspose.Cells, увидите типичные подводные камни и получите советы по работе с большими книгами или пользовательскими файлами шрифтов. Внешняя документация не требуется — всё, что нужно, содержится в этом руководстве.

## Требования

Прежде чем начать, убедитесь, что у вас есть:

- .NET 6.0 или новее (код также работает с .NET Framework 4.7+)
- Действительная лицензия Aspose.Cells for .NET (или вы можете использовать бесплатный режим оценки)
- Базовые знания C# и IDE, например Visual Studio 2022
- Файлы шрифтов TrueType (.ttf) или OpenType (.otf), которые вы хотите внедрить (они должны быть доступны процессу выполнения)

## Шаг 1: Настройка проекта и импорт Aspose.Cells

Создайте новое консольное приложение и добавьте пакет Aspose.Cells через NuGet:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

Затем откройте **Program.cs** и добавьте необходимые директивы `using`:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **Pro tip:** Поместите свои пользовательские шрифты в папку `fonts` в корне проекта. Это делает решение портативным и упрощает их последующее использование.

## Шаг 2: Создание или загрузка книги

Для демонстрации создадим простую книгу с несколькими стилизованными ячейками:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **Почему это важно:** Если пропустить пользовательский стиль, экспортированный HTML будет использовать шрифты браузера по умолчанию, что нивелирует цель **как внедрять шрифты в HTML**.

## Шаг 3: Настройка `HtmlSaveOptions` для внедрения шрифтов

Суть **как внедрять шрифты в HTML** заключается в классе `HtmlSaveOptions`. Установка `EmbedFonts = true` сообщает Aspose.Cells внедрять любые используемые TrueType/OpenType шрифты непосредственно в генерируемый HTML в виде Base64‑закодированных URI.

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### Как работает внедрение

Когда `EmbedFonts` установлен в `true`, Aspose.Cells сканирует определения стилей книги, находит соответствующие файлы шрифтов в системе (или в папке `fonts`, которую вы добавили), считывает их бинарные данные и вставляет блок `<style>` примерно такого вида:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

Поскольку данные шрифта закодированы прямо в HTML, страница корректно отображается даже на компьютерах, где шрифт не установлен.

## Шаг 4: Сохранение книги как HTML

Теперь вы можете **сохранить книгу как HTML** с настроенными параметрами. Выберите каталог, в который приложение имеет право записи (например, `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

Запуск программы создаёт один файл `report.html`. Откройте его в любом современном браузере, и вы увидите заголовок «Quarterly Sales», отрисованный шрифтом **Pacifico**, даже если этот шрифт не установлен в вашей ОС.

### Ожидаемый результат

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

Атрибут `src:` содержит длинную строку Base64 — это внедрённые данные шрифта, которые позволяют **как внедрять шрифты в HTML**.

## Шаг 5: Проверка внедрения шрифтов и устранение проблем

1. **Откройте HTML‑файл в Chrome или Edge.** Если пользовательский шрифт отображается, внедрение прошло успешно.  
2. **Просмотрите исходный код страницы.** Ищите правило `@font-face`, сгенерированное Aspose.Cells.  
3. **Распространённые проблемы:**  
   - *Отсутствует файл шрифта:* Убедитесь, что файл шрифта доступен. При необходимости явно добавьте папку в путь поиска:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *Большой размер HTML:* Внедрение множества шрифтов может увеличить файл. Используйте `ExportToSingleFile = false`, чтобы хранить шрифты отдельными файлами `.ttf` в папке ресурсов.

   - *Неподдерживаемый формат шрифта:* Aspose.Cells внедряет только TrueType (`.ttf`) и OpenType (`.otf`). Преобразуйте другие форматы перед внедрением.

## Полный рабочий пример

Ниже представлена полная программа, которую можно скопировать, вставить и запустить без изменений (за исключением необязательной строки лицензии).

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

Запуск этой программы создаёт `output/report.html`. Откройте файл, и вы увидите шрифт **Pacifico**, отрисованный корректно — демонстрируя **как внедрять шрифты в HTML** при **сохранении книги как HTML**.

## Часто задаваемые вопросы

| Question | Answer |
|----------|--------|
| *Can I embed only specific fonts?* | Yes. Set `htmlOpt.EmbedAllFonts = false` (available in newer versions) and use `htmlOpt.FontsToEmbed` to list the exact font names. |
| *What if I need to embed fonts for multiple worksheets?* | Set `ExportActiveWorksheetOnly = false` so every worksheet is exported, and Aspose.Cells will embed fonts used across the whole workbook. |
| *Will embedded fonts work on mobile browsers?* | Modern mobile browsers support Base64‑encoded fonts, so the embedded fonts render correctly as long as the font format is supported (TTF or OTF). |
| *How large can the HTML file become?* | Embedding a 200 KB TrueType font adds roughly the same amount to the HTML size (Base64 adds ~33 % overhead). For many fonts, consider exporting to a folder (`ExportToSingleFile = false`) to keep the HTML lightweight. |
