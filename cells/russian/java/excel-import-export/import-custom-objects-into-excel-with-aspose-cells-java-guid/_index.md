# Импорт пользовательских объектов в Excel с помощью Aspose.Cells – руководство для Java

Если вам нужно **импортировать пользовательские объекты** в лист Excel, это руководство проведёт вас через весь процесс с использованием Aspose.Cells для Java. Вы увидите, как **импортировать данные в Excel**, применить стиль жирного заголовка и создать готовый к распространению файл `.xlsx`.

Экспорт табличных данных из Java часто требует ручного построчного заполнения ячеек, что подвержено ошибкам и трудно поддерживается. Используя API `importCustomObjects`, вы избавляетесь от шаблонного кода, сохраняете целостность модели данных и получаете тонкую настройку стилей.

В этом уроке вы:

* Сформируете список Java‑объектов `Map`, имитирующий типичную таблицу данных.
* Создадите переиспользуемый стиль заголовка (жирный шрифт) с помощью Aspose.Cells.
* Импортируете пользовательские объекты в лист, применив массив стилей.
* Сохраните книгу на диск и проверите результат.

Единственное требование — наличие среды разработки Java (рекомендовано JDK 8+) и библиотеки Aspose.Cells для Java.

```xml
    <version>23.12</version> <!-- Use the latest stable version -->

```

## Шаг 1: Подготовьте пользовательские объекты для импорта

Первый шаг — создать коллекцию, представляющую строки, которые вы хотите поместить в Excel. В примере используется `List<Map<String,Object>>`, где каждая карта выступает как строка с именами столбцов в качестве ключей.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Почему это важно:**  
`importCustomObjects` ожидает массив объектов. Используя `Map`, вы сохраняете имена столбцов, позволяя Aspose.Cells автоматически сопоставлять их ячейкам. Такой подход аналогичен типичной `DataTable` в .NET или `ResultSet` из JDBC, делая код переиспользуемым в разных проектах.

---

## Шаг 2: Определите стиль заголовка для применения при импорте

Чёткая строка заголовка улучшает читаемость. Aspose.Cells позволяет создать объект `Style`, установить шрифт жирным и передать его через массив `ImportTableOptions`.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Почему это важно:**  
Если опустить массив стилей, заголовок будет отображён обычным шрифтом, который может не выделяться. Подготовив стиль один раз, вы избегаете повторных вызовов для каждой строки и сохраняете чистоту логики импорта.

---

## Шаг 3: Импортируйте пользовательские объекты с массивом стилей

Теперь объединяем данные и стиль, затем вызываем `importCustomObjects`. Метод размещает данные, начиная с верхнего‑левого угла (строка 0, столбец 0) и автоматически применяет стиль заголовка.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Почему это важно:**  
`importCustomObjects` разбирает каждую карту, создаёт столбцы на основе ключей (`Name`, `Score`) и записывает значения в соответствующие ячейки. Объект `ImportTableOptions` указывает Aspose.Cells использовать `styleArray` для первой строки, обеспечивая жирный заголовок без дополнительного кода.

---

## Шаг 4: Сохраните книгу и проверьте результат

Наконец, запишите книгу в файл. Сгенерированный Excel‑файл содержит стилизованную строку заголовка и последующие строки данных.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Ожидаемый результат:**  

| **Name** | **Score** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

Ячейки заголовка (`Name`, `Score`) отображаются жирным шрифтом, соответствующим стилю, определённому на Шаге 2.

## Распространённые варианты и граничные случаи

| Ситуация | Рекомендованная корректировка |
|----------|------------------------------|
| **Другой порядок столбцов** | Убедитесь, что ключи `Map` вставлены в нужном порядке, либо используйте пользовательский POJO с аннотированными полями и массивом `PropertyDescriptor`. |
| **Большие наборы данных (>10 000 строк)** | Увеличьте `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)`, чтобы избежать `OutOfMemoryError`. |
| **Пользовательские числовые форматы** | Добавьте второй `Style` в `styleArray` для строк данных, например, задайте `NumberFormat` как `"0"` для целых оценок. |
| **Несколько листов** | Вызывайте `importCustomObjects` для каждого целевого листа, корректируя начальную строку/столбец при необходимости. |
| **Локализованный текст заголовка** | Заполните строку заголовка вручную перед импортом, затем примените стиль ко всему диапазону с помощью `Cells.applyStyle`. |

## Полезные советы для надёжного экспорта Java в Excel

* **Повторно используйте временную книгу** — создание нового `Workbook` для каждого стиля добавляет накладные расходы. Держите один экземпляр, если нужны несколько стилей.  
* **Проверяйте данные перед импортом** — `null`‑значения в карте становятся пустыми ячейками; их можно заменить значениями по умолчанию, предварительно обработав список.  
* **Закрывайте ресурсы** — хотя Aspose.Cells управляет памятью внутренне, явный вызов `workbook.dispose()` после сохранения быстро освобождает нативные ресурсы.  
* **Установите `Workbook.setForceFullCalculation(true)`**, если в книге есть формулы, которые необходимо вычислить перед сохранением.
