# Как создать рабочую книгу Excel в Java с данными JSON

Если вам нужно **create Excel workbook java**, разработчики часто сталкиваются с задачей загрузки данных JSON в таблицу. Это руководство покажет, как **populate Excel from JSON**, включая то, как **convert JSON array excel** и **populate workbook from json** чистым и повторяемым способом.

Работа с JSON распространена, когда сервисы предоставляют данные через REST API, а Excel остаётся предпочтительным форматом для отчётности и анализа. К концу этого руководства у вас будет исполняемая Java‑программа, которая:

* создаёт новую рабочую книгу Excel,
* читает массив JSON (или любую структуру JSON) и записывает его значения в ячейки,
* сохраняет файл на диск, готовый для дальнейшей обработки.

Никакие внешние инструменты не требуются, кроме библиотеки Aspose.Cells for Java, которая предоставляет `SmartMarkerProcessor`, используемый в примерах кода.

## Требования

Прежде чем начать, убедитесь, что у вас есть:

| Требование | Причина |
|------------|---------|
| Java Development Kit (JDK) ≥ 8 | Требуется для компиляции и запуска примера |
| Maven or Gradle (optional) | Упрощает управление зависимостями |
| Aspose.Cells for Java (v23.10 or later) | Предоставляет классы `Workbook` и `SmartMarkerProcessor` |
| Basic knowledge of JSON and Java I/O | Помогает понять поток данных |

Если вы предпочитаете не использовать систему сборки, можете скачать JAR‑файл Aspose.Cells с [веб‑сайта Aspose](https://products.aspose.com/cells/java/) и добавить его в classpath вашего проекта вручную.

## Шаг 1: Настройте проект и добавьте зависимость Aspose.Cells

### Пользователи Maven

Добавьте следующую зависимость в ваш `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Пользователи Gradle

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

Если вы не используете систему сборки, поместите загруженный JAR в папку `libs/` и включите его в classpath при компиляции:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## Шаг 2: Создайте новую рабочую книгу и настройте процессор SmartMarker

`SmartMarkerProcessor` упрощает сопоставление значений JSON с ячейками Excel. Вызвав `setArrayAsSingle(true)`, мы указываем процессору рассматривать весь массив JSON как единое значение, что полезно, когда каждый элемент должен занимать отдельную ячейку в строке.

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**Почему это важно:**  
Создание рабочей книги заранее даёт чистый холст. Настройка `setArrayAsSingle(true)` предотвращает преобразование процессором массива в одну строку (например, `["A","B","C"]`) и позволяет вручную управлять расположением.

## Шаг 3: Определите JSON‑данные, которые нужно вставить

Для этого руководства мы используем простой массив JSON, но тот же подход работает с объектами, вложенными массивами или сложными структурами.

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**Подсказка:** Если ваш JSON поступает из файла или REST‑конечного пункта, замените строковый литерал на `String`, считанный из источника, например `Files.readString(Paths.get("data.json"))`.

## Шаг 4: Обработайте рабочую книгу с данными JSON

Теперь мы позволяем `SmartMarkerProcessor` сопоставить массив JSON с первым листом. По умолчанию каждый элемент записывается в последовательные ячейки, начиная с `A1`.

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

Внутри Aspose.Cells парсит JSON, создаёт временную таблицу данных и записывает значения на лист. Поскольку мы установили `ArrayAsSingle` в `true`, элементы массива размещаются горизонтально в первой строке.

## Шаг 5: Сохраните рабочую книгу в файл

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

При запуске программы вы должны увидеть файл с именем **CreatedFromJson.xlsx** в рабочем каталоге. Открыв его в Excel (или любом совместимом просмотрщике), вы увидите:

| A | B | C |
|---|---|---|
| A | B | C | *(значения находятся в ячейках A1, B1, C1)*

### Ожидаемый вывод

```
Workbook saved to CreatedFromJson.xlsx
```

И лист Excel выглядит так:

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## Шаг 6: Обработка более сложных структур JSON (необязательно)

### 6.1 Заполнение рабочей книги из JSON‑объекта

Если ваш JSON представляет собой объект, а не массив, вы всё равно можете использовать `SmartMarkerProcessor`. Например:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

Процессор создаст именованные диапазоны (`title`, `month`, `values`), которые можно использовать в шаблоне Excel с помощью Smart Markers, например `&=title` и `&=values`.

### 6.2 Преобразование вложенного массива JSON в вертикальный список

Иногда требуется, чтобы массив заполнял столбец, а не строку. Установите начальную ячейку вручную перед обработкой:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

Теперь значения **A**, **B**, **C** появляются в ячейках A2, A3, A4 соответственно.

## Распространённые подводные камни и как их избежать

| Проблема | Причина | Решение |
|----------|---------|---------|
| **Массив записан как одна строка** | `setArrayAsSingle(false)` (по умолчанию) | Вызовите `processor.setArrayAsSingle(true)` |
| **Файл не найден при сохранении** | Недопустимый путь или отсутствие прав записи | Используйте абсолютный путь или убедитесь, что каталог существует |
| **Ошибка разбора JSON** | Некорректная строка JSON | Проверьте JSON с помощью инструмента или используйте библиотеку, например Jackson, для генерации строки |
| **Ячейки перезаписаны непреднамеренно** | Обработка того же листа несколько раз без сброса начальной ячейки | Вызовите `processor.setStartCell("A1")` перед каждым вызовом `process` |

## Профессиональный совет: повторное использование рабочей книги как шаблона

Вместо создания новой пустой рабочей книги каждый раз, вы можете загрузить заранее подготовленный шаблон, который уже содержит заголовки, формулы или стили:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

Этот подход сочетает визуальную отделку вручную созданного Excel‑файла с автоматизацией **populate workbook from json**.
