# Создание листов деталей в Java с помощью умных маркеров Aspose.Cells

Если вам нужно **создавать листы деталей** в Java‑приложении, этот учебник покажет, как сделать это с помощью умных маркеров Aspose.Cells. Вы увидите полностью готовый, исполняемый пример, который **java create worksheets**, получает **sheet name from field** и **process data source** всего в нескольких строках кода.

Руководство охватывает всё — от настройки проекта до сохранения конечной книги, так что вы можете скопировать‑вставить решение в свой проект и сразу адаптировать его. Внешняя документация не требуется — всё, что нужно, находится здесь.

## Чего вы научитесь

* Как **использовать умные маркеры** для дублирования шаблонного листа для каждой строки в основной наборе данных.  
* Как динамически задавать имя каждого нового листа на основе значения поля (например, `Order_123`).  
* Как передать Java‑коллекцию в качестве **process data source** для движка умных маркеров.  
* Советы по обработке граничных случаев, таких как пустые данные, специальные символы в именах листов и вопросы производительности при больших наборах данных.

### Предварительные требования

| Требование | Причина |
|-------------|--------|
| Java 8 or higher | Aspose.Cells for Java supports Java 8+. |
| Maven or Gradle build system | Simplifies adding the Aspose.Cells dependency. |
| Basic knowledge of Java collections | Needed to build the data source for the smart markers. |
| A template Excel file (`Template.xlsx`) with a placeholder smart marker in cell **A1** | The template drives the detail‑sheet generation. |

> **Pro tip:** Храните шаблонную книгу в папке `resources` проекта, чтобы она была упакована вместе с вашим JAR.

## Шаг 1: Добавьте Aspose.Cells в ваш проект (java create worksheets)

Если вы используете **Maven**, добавьте следующую зависимость в `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

Для **Gradle** поместите эту строку в `build.gradle`:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

Эти строки делают API **java create worksheets** доступными во время компиляции.

## Шаг 2: Загрузите шаблонную книгу

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*Почему это важно:* Объект `Workbook` является точкой входа для всех операций с Excel. Загрузка шаблона гарантирует, что вы начинаете с правильного макета и любой предварительно заданной форматировки.

## Шаг 3: Вставьте умный маркер, который создает новый лист для каждой строки основного набора (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

Синтаксис `${Orders:DetailSheetNewName=Order_${OrderId}}` является ядром **use smart markers**. Он делает три вещи:

1. Перебирает коллекцию `Orders`.  
2. Создает **new worksheet** для каждого элемента.  
3. Устанавливает **sheet name from field** `OrderId` (с префиксом `Order_`).

## Шаг 4: Подготовьте источник данных (process data source)

Ниже приведен минимальный пример с использованием `List<Map<String, Object>>`. Замените его вашим реальным источником данных — строки из базы данных, десериализацию JSON и т.д.

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*Почему это важно:* Шаг **process data source** связывает вашу Java‑коллекцию с движком умных маркеров. Ключ (`"Orders"`) должен точно соответствовать имени умного маркера.

## Шаг 5: Обработайте умные маркеры (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

Когда вызывается `process`, Aspose.Cells читает коллекцию `Orders`, клонирует шаблонный лист для каждой записи и переименовывает каждый лист в соответствии с полем `OrderId`. Это суть использования **process data source**.

## Шаг 6: Сохраните книгу с дублированными листами деталей

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

После выполнения вы найдете `DuplicatedDetailSheets.xlsx`, содержащий:

* `Sheet1` — оригинальный шаблон (не изменён).  
* `Order_101` — лист деталей для первого заказа.  
* `Order_102` — лист деталей для второго заказа.

### Ожидаемый вывод (выдержка)

| Имя листа | A1 (умный маркер) | Полученное содержимое |
|------------|-------------------|-----------------------|
| Order_101  | `${Orders:...}`   | Populated with data from `order1` |
| Order_102  | `${Orders:...}`   | Populated with data from `order2` |

Откройте файл в Excel, чтобы убедиться, что каждый лист правильно назван и содержит строки данных.

## Обработка распространённых вариантов и граничных случаев

### Пустой источник данных

Если `orders` пуст, процессор умных маркеров **не создаёт новых листов**. Чтобы избежать пустой книги, добавьте проверку:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### Специальные символы в именах листов

Имена листов Excel не могут содержать `\ / ? * [ ] :`. Очистите поле перед использованием:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### Большие наборы данных

Для тысяч строк рассмотрите увеличение кучи JVM (`-Xmx2g`) и вызов `workbook.calculateFormula()` только после генерации всех листов, чтобы улучшить производительность.
