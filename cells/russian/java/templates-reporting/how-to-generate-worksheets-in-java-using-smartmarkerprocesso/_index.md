# Как генерировать листы в Java с помощью SmartMarkerProcessor

Если вам нужно **how to generate worksheets** в файле Excel, это руководство покажет вам полное, готовое к запуску решение. К концу первых двух предложений вы поймёте, как генерировать листы и динамические листы Excel из коллекции объектов, и у вас будет рабочий пример кода, который автоматизирует создание Excel одним вызовом метода.

Создание отдельных листов для каждого сотрудника, проекта или любой другой сущности — распространённое требование, когда нужно **populate excel workbook** данные программно. Это руководство проходит каждый шаг — от настройки шаблона до обработки списка и сохранения конечного файла — чтобы вы могли сразу применить технику в своих Java‑приложениях.

## Что вы получите

* Создать главный лист, в котором перечислена информация высокого уровня.  
* Создать **multiple sheets from list** данные, каждый лист автоматически именуется.  
* **Automate excel creation** без ручного добавления строк или столбцов.  
* **Populate excel workbook** с богатыми структурами данных (объекты, карты, массивы).  

Требования:

* Установлен Java 8 или новее.  
* Maven (или другой инструмент сборки) для добавления библиотеки Aspose.Cells for Java.  
* Базовое понимание коллекций Java.  

> **Pro tip:** Синтаксис SmartMarker (`${EmployeeMaster}`) работает с любым типом коллекции, реализующим `java.util.Collection`. Используйте его, чтобы ваши шаблоны оставались чистыми и поддерживаемыми.

## Как генерировать листы с помощью SmartMarkerProcessor

В этом разделе содержится основной код, который делает **how to generate worksheets** простым. Мы объясним, почему каждая строка важна, а не только что она делает.

### Шаг 1: Добавьте зависимость Aspose.Cells

Если вы используете Maven, включите следующее в ваш `pom.xml`. Библиотека предоставляет класс `SmartMarkerProcessor`, используемый в этом руководстве.

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **Why:** Aspose.Cells обрабатывает ввод‑вывод файлов Excel, разбор Smart Marker и управление листами внутри, позволяя вам сосредоточиться на данных, а не на низкоуровневых операциях с файлами.

### Шаг 2: Подготовьте шаблон Excel

Создайте файл Excel с именем `EmployeeTemplate.xlsx`, содержащий в одной ячейке плейсхолдер Smart Marker:

| A |
|---|
| `${EmployeeMaster}` |

Когда процессор выполнится, он заменит этот плейсхолдер на **detail sheet**, содержащий одну строку на каждого сотрудника.

> **Why:** Плейсхолдер указывает процессору, куда вставлять данные. Использование отдельного шаблона сохраняет ваше форматирование (шрифты, границы, ширину столбцов) нетронутым.

### Шаг 3: Определите модель данных

Ниже приведён минимальный класс `Employee` и вспомогательный метод, который формирует список сотрудников. Список будет использован для демонстрации **multiple sheets from list**.

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **Why:** Обычный объект Java (POJO) напрямую сопоставляется с полями Smart Marker (`firstName`, `lastName`, `department`). Это делает **populate excel workbook** простым и типобезопасным.

### Шаг 4: Настройте SmartMarkerProcessor

Теперь мы соединяем всё вместе. Процессор прочитает шаблон, заменит маркер и создаст новый лист с именем `EmployeeDetail`.

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

**Объяснение ключевых строк**

| Line | Reason |
|------|--------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | Загружает шаблон, который уже содержит плейсхолдер Smart Marker. |
| `data.put("EmployeeMaster", employees);` | Связывает Java‑список с маркером `${EmployeeMaster}`. |
| `processor.setDetailSheetNewName("EmployeeDetail");` | Присваивает сгенерированному листу осмысленное имя вместо значения по умолчанию `Sheet1`. |
| `processor.process(wb, data);` | **How to generate worksheets** — процессор читает маркер, создает новый лист и заполняет его строками для каждого `Employee`. |
| `wb.save("EmployeesReport.xlsx");` | Сохраняет **dynamic excel sheets** на диск. |

### Шаг 5: Проверьте результат

Откройте `EmployeesReport.xlsx`. Вы должны увидеть два листа:

1. **Sheet1** — оригинальный шаблон (может быть скрыт или удалён).  
2. **EmployeeDetail** — **dynamic excel sheet** с колонками `firstName`, `lastName`, `department` и одной строкой на каждого сотрудника.

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **Why this matters:** Файл теперь содержит **multiple sheets from list** без какого‑либо ручного перебора или адресации ячеек. Движок Smart Marker заботится о создании строк, преобразовании данных и наследовании форматирования.

### Шаг 6: Обработка граничных случаев

#### Пустой список данных

Если `employees` пуст, процессор всё равно создаст лист `EmployeeDetail`, но оставит его пустым. Вы можете предотвратить добавление листа, проверив размер коллекции перед обработкой:

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### Очень большие списки

Для тысяч строк рассмотрите увеличение выделения памяти (`-Xmx2g`) или использование `processor.setAutoFitRows(false)` для ускорения обработки.

#### Пользовательское именование листов по группам

Если вам нужен отдельный лист для каждого отдела, вы можете использовать **multiple detail sheets**:

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

Плейсхолдер `${department}` берётся из каждого объекта `Employee`, создавая листы вроде `Dept_Sales`, `Dept_Marketing` и т.д.
