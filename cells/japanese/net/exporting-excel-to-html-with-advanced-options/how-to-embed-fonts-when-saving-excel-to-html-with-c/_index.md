# Excel を HTML に保存する際にフォントを埋め込む方法（C#）

Excel ワークブックを HTML に保存する際にフォントを埋め込むことは、ブラウザ間でスプレッドシートの外観を正確に保つための一般的な要件です。元のフォントを保持したまま Excel を HTML にエクスポートする必要がある場合、このガイドでは完全で実行可能なソリューションを示します。

**export Excel to HTML**、**convert Excel to HTML**（フォント埋め込み）を学び、クライアントマシンでレイアウトが崩れる典型的な「missing‑font」問題を回避できます。外部ツールは不要で、Aspose.Cells ライブラリと数行の C# だけで実現できます。

## 前提条件

* .NET 6.0（以降）をインストール済み。
* **Aspose.Cells for .NET** のライセンス版 – 無料トライアルでもテスト可能です。
* Visual Studio 2022 や VS Code などの IDE。

これらがすでに揃っている場合は、すぐにコードへ進めます。

## 手順 1: ワークブックを作成しサンプルデータを追加

まず、小さなワークブックを生成し、フォント埋め込みの効果を確認できるようにします。以下のコードはワークシートを作成し、いくつかのセルに書き込み、カスタムフォントを適用します。

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### カスタムフォントを追加する理由

フォントを埋め込む必要があるのは、ワークブックがクライアントデバイスに存在しない可能性のあるフォントを使用している場合だけです。**Arial**（または他のフォント）を明示的に設定することで、HTML 出力に実際にフォントデータが含まれていることを確認できます。

## 手順 2: フォント埋め込みのために HTML 保存オプションを設定

Aspose.Cells は `HtmlSaveOptions` クラスを提供します。`EmbedFonts = true` を設定すると、必要なフォントファイルが Base64 エンコードされたデータ URI として生成された HTML に直接埋め込まれます。

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### 「HTML にフォントを埋め込む」実際の動作

`EmbedFonts` が true の場合、Aspose.Cells はシステム（またはワークブックの埋め込みフォントコレクション）からフォントファイルを抽出し、**Base64** 文字列に変換します。その文字列は `@font-face` を使用した `<style>` ブロック内に配置されます。結果として得られる HTML は、元のフォントがインストールされていなくても任意のデバイスで開くことができます。

## 手順 3: フォント埋め込みでワークブックを HTML として保存

ここでワークブックをディスクに書き出します。ファイルにはフォントデータが含まれるため、最新のブラウザで開くと元の Excel ファイルと同じタイポグラフィが表示されます。

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### 期待される結果

* `embedded.html` は `output` フォルダーに配置されます。
* Chrome、Edge、Firefox のいずれかでファイルを開くと、ブラウザのマシンに Arial がなくても **Arial** テキストでワークシートが表示されます。
* HTML ソースを検査すると、長い `src: url(data:font/ttf;base64,…)` 宣言を含む `@font-face` ルールが入った `<style>` ブロックが見つかります――これが埋め込まれたフォントです。

## 手順 4: 別のマシンで HTML が機能するか確認（オプション）

埋め込みが確実に成功したことを確認するには、次の手順を実行します：

1. `output/embedded.html` を、カスタムフォントがインストールされていない別のコンピュータ（または仮想マシン）にコピーします。
2. ブラウザでファイルを開きます。
3. レイアウトとタイポグラフィが元の Excel の表示と一致するはずです。

フォントが汎用フォントにフォールバックした場合は、ビルドマシンでフォントファイルにアクセスできるか、読み取り権限があるかを再確認してください。

## よくある質問とエッジケース

### 埋め込みはファイルサイズを増加させますか？

はい。TrueType または OpenType フォントを埋め込むと、HTML ファイルに **数十キロバイト** 程度が追加されます。多数のユニークフォントを使用する大規模なワークブックの場合、以下を検討してください：

* フォントのサブセット化（使用する文字だけ） – Aspose.Cells はほとんどの一般的なフォントで自動的に行います。
* 画像を埋め込む必要がない場合は `ExportEmbeddedImages = false` を使用します。

### 特定のフォントだけを埋め込みたい場合は？

`HtmlSaveOptions` には直接的なホワイトリスト機能はありませんが、`Save` を呼び出す前に **ワークブックで使用するフォントを制限** することで、埋め込まれるフォントを制御できます。不要なフォント割り当てを削除するか、標準的なウェブセーフフォントに置き換えてください。

### 他の形式（例: PDF）に変換する際にもフォントを埋め込めますか？

`PdfSaveOptions` でも同様の `EmbedFonts` プロパティが利用できます。概念は同じで、フォントデータが埋め込まれるため、PDF は任意のビューアで正しく表示されます。

## 完全な実行可能サンプル

以下は新しいコンソールプロジェクトにコピー＆ペーストできる完全なプログラムです。

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

プログラムを実行すると、**埋め込まれた Arial フォントを含む HTML ファイル** が生成され、ファイルが開かれる場所に関係なく視覚的な忠実度が保証されます。

## 結論

これで C# を使用して **Excel を HTML に保存する際にフォントを埋め込む方法** が分かりました。`HtmlSaveOptions.EmbedFonts = true` を設定すれば、クライアント側でフォントが欠如する心配なく、確実に **Excel を HTML にエクスポート** し、**Excel を HTML に変換** できます。この手法は、Web ベースのレポーティング、メール対応のダッシュボード、または Excel 由来のコンテンツを HTML で共有するあらゆるシナリオで不可欠です。

### 次にやることは？

* Aspose.Cells が生成する CSS をカスタマイズし、サイトのスタイルガイドに合わせる。  
* `ExportEmbeddedImages` を切り替えて画像を選択的に埋め込む。  
* フォント埋め込みを維持したまま、PDF や SVG など他のエクスポート形式も検討する。  

さまざまなフォントや大きなワークシート、複数シートのワークブックで自由に試してみてください。同じ `EmbedFonts` フラグはすべてのサポート対象出力形式で機能し、必要な場所ですべて一貫したフォント埋め込みの制御が可能です。コーディングを楽しんでください！
