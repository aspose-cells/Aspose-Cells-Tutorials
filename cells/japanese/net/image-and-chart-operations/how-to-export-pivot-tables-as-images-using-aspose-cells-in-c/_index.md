# C# で Aspose.Cells を使用してピボットテーブルを画像としてエクスポートする方法

If you need to **how to export pivot** data into a portable picture, Aspose.Cells makes the process straightforward. This tutorial shows you exactly how to export pivot tables as PNG files, so you can embed them in reports, emails, or documentation without requiring Excel on the target machine.

Exporting a pivot as an image eliminates version‑specific formatting issues and lets non‑technical stakeholders view the analysis instantly. We'll cover everything from project setup to rendering the final **export pivot table image**, and we’ll also explain how to **save pivot as image** for future reuse.

## Aspose.Cells を使用してピボットテーブルを画像としてエクスポートする方法

Below is the complete, runnable example that loads a workbook, refreshes the pivot, configures image options, and writes the output file. Each step includes a short rationale so you understand *why* the code is written that way, not just *what* it does.

### 1. Aspose.Cells 環境のセットアップ

1. NuGet パッケージをインストールします:

   ```bash
   dotnet add package Aspose.Cells
   ```

2. C# ファイルの先頭に必要な `using` ディレクティブを追加します:

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **Pro tip:** Aspose.Cells の最新パフォーマンス向上の恩恵を受けるには、.NET 6 以降をターゲットにしてください。

### 2. ワークブックをロードし、ピボットテーブルを見つける

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*Why this matters:* `Workbook` クラスは XLSX ファイルを解析し、すべてのワークシートへのアクセスを提供します。正しいワークシートを選択することは重要です。ワークブックには複数のピボットが含まれる可能性があるためです。

### 3. ピボットテーブルをリフレッシュして最新のソースデータを取得する

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

リフレッシュを行うことで、ファイル保存後にソース範囲に加えられた変更がレンダリングされた画像に反映されます。このステップを省略すると、古い情報や不正確なビジュアルが生成される可能性があります。

### 4. 画像エクスポートオプションの設定（export pivot table image）

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

`ImageOrPrintOptions` オブジェクトを使用すると、フォーマット、解像度、その他のレンダリング詳細を制御できます。PNG は鮮明でウェブ対応のグラフィックとして最も一般的な選択ですが、ファイルサイズが問題になる場合は `ImageFormat.Jpeg` に切り替えることも可能です。

### 5. レンダリングして **save pivot as image**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

`RenderToImage` は重い処理を実行します。Excel に表示されるピボットと同じように描画し、バイナリ PNG データをディスクに書き込みます。このメソッドは `void` を返すため、呼び出しが完了した後にファイルが存在すると安全に仮定でき、追加のチェックは不要です。

#### 期待される結果

After the program runs, you will find `Pivot.png` in the specified folder. Opening the file should display a faithful snapshot of the original pivot table, including column headers, row totals, and any applied formatting.

### 6. 一般的なバリエーションとエッジケース

| シナリオ | 調整 |
|----------|------------|
| **Large pivots**（多数の行/列） | 出力をより鮮明にするため、`HorizontalResolution` と `VerticalResolution` を 300 dpi に増やします。 |
| **Custom styling**（背景色、フォント） | `Refresh()` を呼び出す前に、ワークブックのスタイル定義がロードされていることを確認します。 |
| 1 つのシートに **Multiple pivots** | `worksheet.PivotTables` をループし、各ピボットに対して `RenderToImage` を呼び出し、ファイル名を個別に設定します。 |
| PNG の代わりに **Export to JPEG** | `ImageFormat = ImageFormat.Jpeg` に変更し、必要に応じて `JpegSaveOptions` オブジェクトの `Quality` を設定します。 |

These variations let you **export pivot table image** in the exact format your downstream system expects.

## クイックコピー＆ペースト用の完全ソースコード

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

Running the program produces the PNG file shown above, completing the **save pivot as image** workflow in under a minute.
