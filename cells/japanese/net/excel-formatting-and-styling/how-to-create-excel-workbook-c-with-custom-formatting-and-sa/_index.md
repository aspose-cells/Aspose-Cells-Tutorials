# カスタム書式設定でExcelブックをC#で作成しXLSXとして保存する方法

データをインポートし、カスタム数値書式を適用し、セルのフォント色を変更する **Excel workbook C#** を作成する必要がある場合、このチュートリアルで手順をすべて示します。数秒でスタイルが適用された `StyleArrayImport.xlsx` ファイルを生成する、実行可能なサンプルが手に入ります。

C# から Excel を操作する際は、書式の定義、色の適用、ファイルの保存を手作業で行うことが多く、手間がかかります。このガイドを最後まで読むと、これらの作業をすべて自動化でき、UI ではなくデータに集中できるようになります。

本記事で学べること：

* `DataTable` をワークシートにインポートする方法
* `StyleArray` を使用して **カスタム数値書式を適用** し、**セルのフォント色を変更** する方法
* **ワークブックを XLSX として保存** するワンライナー
* **format imported data excel** が意図した通りに表示されることを確認する方法

前提条件は **Aspose.Cells for .NET** ライブラリ（または `Workbook`、`Worksheet`、`StyleArray` を提供する互換 API）への参照だけです。コードは .NET 6+ を対象としていますが、少し調整すれば以前のバージョンでも動作します。

## 手順 1: サンプル DataTable を作成する

まず、データベースやその他のソースから取得するデータを模倣した `DataTable` を作成します。テーブルには **Name** 列（文字列）と、後で書式設定する **Amount** 列（decimal）が含まれます。

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**ポイント:** `DataTable` を使用すると、インポート ロジックをデータ ソースから切り離すことができ、データベース、CSV、API からのレポート作成時に一般的に用いられるパターンです。

## 手順 2: **カスタム数値書式を適用** し **セルのフォント色を変更** する StyleArray を定義する

`StyleArray` は、`DataTable` からインポートされるすべてのセルに適用される書式指示をまとめて保持できます。この例では次の設定を行います。

* `Number` を `#,##0.00` に設定 – 桁区切り付きの会計書式
* `FontColor` を `Color.Blue` に設定 – 数字を目立たせる

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**なぜ StyleArray を使うのか？** インポート時にスタイルを適用することで、ワークシートを二度走査する必要がなくなり、大量データのパフォーマンスが向上します。

---

## 手順 3: **Excel workbook C# を作成** – Workbook をインスタンス化し、最初の Worksheet を取得する

空のワークブックを作成し、最初のワークシート（インデックス 0）への参照を取得します。このワークシートがインポート データの格納先になります。

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**解説:** `Workbook` は Excel ファイル全体を表し、`Worksheet` は単一のタブを表します。デフォルトのワークブックはシートが 1 枚だけ含まれており、シンプルなレポートには十分です。

---

## 手順 4: **StyleArray** を使用して **format imported data excel** を実行する

`ImportDataTable` メソッドはテーブルの行と列をワークシートにコピーし、開始セルは `A1`（行 0、列 0）です。`true` 引数は列ヘッダーも含めることを指示します。`styleArray` を渡すことで、インポートされた各セルにカスタム数値書式とフォント色が適用されます。

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**内部で何が起きているか:** Aspose.Cells は各行を走査し、値を書き込み、その後 `styleArray` で定義されたスタイルを適用します。数値はカンマ区切りと小数点以下 2 桁で表示され、テキストは青色で描画されます。

---

## 手順 5: **Save workbook as XLSX** – ファイルをディスクに書き出す

最後に、ワークブックを `.xlsx` ファイルとして永続化します。パスは任意の書き込み可能ディレクトリに変更可能です。

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**結果の確認:** Excel で生成されたファイルを開きます。3 行のデータが表示され、**Amount** 列がカンマ区切り・小数点以下 2 桁の書式で青色フォントになっているはずです。これにより **format imported data excel** 手順が正常に完了したことが確認できます。

## 完全動作サンプル

以下のブロック全体を新しいコンソール プロジェクトにコピーし、実行してください。追加のコードは不要です。

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**コンソールへの期待出力:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

ファイルを開き、**Amount** 列に `1,234.56` のように青色フォントで表示されていることを確認してください。

## よくある質問とエッジケース

| 質問 | 回答 |
|------|------|
| *個別の列に異なる書式を適用できますか？* | はい。インポート後に対象列の `Style` オブジェクト（例: `worksheet.Cells.Columns[1].Style`）を取得し、別の `Number` や `FontColor` を設定します。 |
| *数値ではなく日付をフォーマットしたい場合は？* | `styleArray.Number = "mm-dd-yyyy"` とし、必要に応じて `styleArray.FontColor` で日付セルの色を指定します。 |
| *ダークテーマの Excel で青色フォントは見えにくくありませんか？* | ダーク背景では見えにくい可能性があります。`Color.LightBlue` やコントラストの高い `Color.Black` など、より明るい色を使用してください。 |
| *数十万行の非常に大きな DataTable をインポートするには？* | `ImportDataTable` の `ImportDataTableOptions` オーバーロードを使用してストリーミングインポートするか、行数制限（1,048,576 行）に合わせて複数シートに分割してください。 |
| *XLSX ではなく CSV にエクスポートしたい場合は？* | `SaveFormat.Xlsx` を `SaveFormat.Csv` に置き換えます。ただし、CSV はプレーンテキスト形式のため、数値書式やフォント色といった書式情報は失われます。 |

## 本番環境での活用ポイント

* **プロのコツ:** 多数のワークシートに同じ書式を適用する場合は、`Style` オブジェクトをキャッシュして再利用すると、毎回新しい `StyleArray` を作成するオーバーヘッドを削減できます。
* **文化圏の違いに注意:** `Number` パターン `#,##0.00` は不変カルチャに基づきます。ローカライズされた区切り文字が必要な場合は `NumberFormatInfo` を使用するか、ユーザーの地域設定に任せて Excel に自動調整させてください。
* **エラーハンドリング:** `Save` 呼び出しは try‑catch でラップし、I/O 例外（権限不足やファイルロックなど）に対処してください。
