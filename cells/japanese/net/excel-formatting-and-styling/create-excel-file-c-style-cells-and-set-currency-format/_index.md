# C#でExcelファイルを作成 – セルのスタイル設定と通貨形式の設定

プロフェッショナルな見た目の **create excel file c#** が必要な方へ。本ガイドでは、Excel のセルにスタイルを適用し、価格列を `$#,##0.00` の通貨形式に設定する方法をステップバイステップで解説します。`DataTable` をインポートし、ヘッダーを太字にし、価格列に数値書式を設定する完全なエンドツーエンドのサンプルをご覧いただけます。

本チュートリアルでは、必要な NuGet パッケージ、完全なソースコード、各要素が重要な理由の解説、空行やロケールの違いといったエッジケースへの対処法を網羅しています。最後まで読めば、数行の C# コードで、価格列がきれいにフォーマットされた `.xlsx` ファイルを生成できるようになります。

## 前提条件

- .NET 6.0 以降（.NET Framework 4.6+ でも動作します）
- Visual Studio 2022 またはお好みの C# エディタ
- **Aspose.Cells for .NET** または **GemBox.Spreadsheet** ライブラリ（どちらも `ImportTableOptions` をサポート）。以下の例は **Aspose.Cells** を使用しています。シンプルな `StyleArray` プロパティが利用できるためです。
- C# のコレクションと `DataTable` の基本知識

> **プロのコツ:** 無料の代替品を使いたい場合は、`Aspose.Cells` を `GemBox.Spreadsheet` に置き換えてください。`DataTable` のインポート時にスタイルを指定する API はほぼ同一です。名前空間と NuGet パッケージ名だけ変更すれば OK です。

## Step 1: Excel ライブラリをインストール

NuGet パッケージ マネージャーを開き、ライブラリをインストールします。

```bash
dotnet add package Aspose.Cells
```

> **なぜこのステップが必要か？** ライブラリは後で使用する `Workbook`、`Worksheet`、`Style`、`ImportTableOptions` クラスを提供します。これが無いと、Office Open XML 形式を手作業で記述しなければならず、ミスが起きやすくなります。

## Step 2: サンプルデータで DataTable を作成

`DataTable` は Excel へエクスポートする前に表形式データを保持する便利な手段です。この例では *Product* と *Price* の 2 列を用意します。

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **解説:**  
> - `Columns.Add("Price", typeof(double))` は、価格の値を数値として扱うことをテーブルに指示します。これにより、後で数値書式を適用できるようになります。  
> - 数行のデータを追加することで、**format column currency** のステップを検証できるようにしています。

## Step 3: 適用したいスタイルを定義

列の順序に合わせた `Style` オブジェクトの配列を作成します。最初の要素はヘッダー行のスタイル、2 番目は *Product* 列をそのままにし、3 番目は通貨の数値書式を適用します。

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### なぜ **style array** を使うのか？

`ImportTableOptions.StyleArray` は各列に対して `Style` をマッピングします。これにより、**add number format** と **style excel cells** を 1 回のインポート操作で実行でき、ワークシートを二度走査する必要がなくなります。

## Step 4: インポート オプションを設定

ここでスタイル配列をインポート操作にバインドします。`ImportTableOptions` オブジェクトは、最初の行をヘッダーとして扱うかどうかも制御できます。

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **注記:** `IsFieldNameShown` の既定値は `true` ですが、明示的に設定しておくと将来の読者に意図が伝わりやすくなります。

## Step 5: ワークブックを作成し、テーブルをインポートして保存

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### 期待される結果

`DataTableWithStyles.xlsx` を開くと:

- 1 行目（ヘッダー）が **太字** になる  
- *Price* 列の値が **$1.20**, **$3.50**, **$0.75** のように表示される  
- *Product* 列はデフォルトフォントのまま

これで **create an excel file c#** が完了し、通貨列がフォーマットされたヘッダー付きの Excel ファイルが生成されました。

## Step 6: 一般的なバリエーションとエッジケースの対処

### a. ロケールが異なる、またはカスタム通貨記号を使用したい場合

ユーロや別の通貨を使用する場合は、組み込み書式 `164` をカスタム書式文字列に置き換えます。

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. 後から列を追加したい場合

列を増やすときは、`columnStyles` 配列を同様に拡張します。デフォルトスタイルを維持したい列は `null` を指定してください。

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. 空の DataTable

`DataTable` に行が無い場合でも、Aspose.Cells はヘッダー行だけを作成します。ただし、ワークブックには 1 行しか含まれません。空ファイルを防ぐには、インポート前に行数をチェックしてください。

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Aspose.Cells の代わりに `GemBox.Spreadsheet` を使用する場合

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

ロジックは全く同じで、チュートリアルが **format column currency** に対してライブラリ非依存であることを示しています。

## Step 7: ファイルをプログラムで検証する（任意）

生成したワークブックを開き、数値書式が正しく適用されているかをアサートできます。単体テストに便利です。

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```
