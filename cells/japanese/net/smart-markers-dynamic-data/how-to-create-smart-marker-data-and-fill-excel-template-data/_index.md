# スマートマーカー データの作成と Excel テンプレート データの入力

Excel ワークブック用に **スマートマーカー データを作成** する必要がある場合、Aspose.Cells のスマートマーカーを使えば簡単です。このチュートリアルでは、C# の数行のコードで **Excel テンプレート データを入力** する方法を示します。

テンプレートに Smart Marker タグを埋め込み、データ ソースを提供し、プロセッサを実行して、結果のファイルを保存する方法を学びます。外部ツールは不要で、Aspose.Cells for .NET と基本的な C# プロジェクトだけで完了します。

## 必要なもの

- .NET 6.0 以降（コードは .NET Framework 4.7+ でも動作します）
- Aspose.Cells for .NET（NuGet パッケージ `Aspose.Cells`）
- `${Comment:fieldName}` のような Smart Marker タグを含む Excel ワークブック
- C# IDE（Visual Studio、Rider、または VS Code）

> **プロのコツ:** ワークブックをプロジェクトと同じフォルダーに置くか、絶対パスを使用してファイルが見つからないエラーを防ぎましょう。

## Aspose.Cells を使用したスマートマーカー データの作成方法

ソリューションの中心は `SmartMarkerProcessor` です。ワークシート内のタグをスキャンし、データ ソースから対応する値を取得して、シートに結果を書き戻します。

```csharp
using Aspose.Cells;
using System;

// 1️⃣ Load the workbook that contains Smart Marker tags.
Workbook workbook = new Workbook("Template.xlsx");

// 2️⃣ Get the worksheet where the tags reside.
Worksheet ws = workbook.Worksheets[0];

// 3️⃣ Prepare the data source that supplies values for the markers.
var dataSource = new[]
{
    new { fieldName = "Sample comment text generated by C#." }
};

// 4️⃣ Create a SmartMarkerProcessor instance.
SmartMarkerProcessor processor = new SmartMarkerProcessor();

// 5️⃣ Process the worksheet, replacing Smart Marker tags with data from the source.
processor.Process(ws, dataSource);

// 6️⃣ Save the populated workbook.
workbook.Save("Result.xlsx");
```

### 各行が重要な理由

1. **ワークブックの読み込み** は、プロセッサが操作する具体的なファイルを提供します。  
2. **ワークシートの選択** は、プロセッサが正しいシートをスキャンすることを保証します。インデックスまたは名前で任意のシートを対象にできます。  
3. **データ ソース** は匿名オブジェクトの配列です。各プロパティ名（`fieldName`）は `${Comment:fieldName}` 内のマーカー名と一致する必要があります。  
4. **`SmartMarkerProcessor`** はタグを解析し、置換を実行するエンジンです。  
5. **`Process`** は本格的な処理を行います。すべての `${...}` タグを読み取り、データ ソース内の対応するプロパティを検索し、セルに値を書き込みます。  
6. **ワークブックの保存** は、更新されたファイルをディスクに書き込み、以降の利用に備えます。

## Excel テンプレートを **Excel テンプレート データの入力** 用に準備する

1. 新しい Excel ワークブックを開きます。  
2. 動的コンテンツを入れたい任意のセルに、Smart Marker タグを入力します。例:  

   ```
   ${Comment:fieldName}
   ```

3. ファイルを `Template.xlsx` として保存します。  

タグの構文は `${<CollectionName>:<PropertyName>}` のパターンに従います。このシンプルな例ではコレクション名を省略し、`Process` に渡すデータ ソースがデフォルトコレクションとして使用されます。

> **エッジケース:** タグがデータ ソースに存在しないプロパティを参照している場合、Aspose.Cells はセルを変更せずに残します。プロパティ名が完全に一致しているか（大文字小文字も含め）必ず確認してください。

## **Aspose.Cells スマートマーカー** を使用するためのデータ ソース構築

配列、`List<T>`、`DataTable`、またはカスタムオブジェクトなど、任意の列挙可能コレクションを提供できます。テーブルスタイルのマーカーが使用されている場合、プロセッサはコレクションを反復し、各アイテムごとに行を繰り返します。

```csharp
// Example with a List<T>
var comments = new List<Comment>
{
    new Comment { fieldName = "First comment." },
    new Comment { fieldName = "Second comment." }
};

processor.Process(ws, comments);
```

```csharp
public class Comment
{
    public string fieldName { get; set; }
}
```

複数行を提供すると、Aspose.Cells はテンプレート領域を自動的に拡張してすべてのアイテムを収容します。これにより、レポートや請求書、データ駆動型テーブルの生成が容易になります。

## **Aspose.Cells スマートマーカー** を使用したワークシートの処理

`Process` メソッドは、以下のようなオプション設定を受け取ることができます。

- `SmartMarkerOptions`：空セルの処理方法を制御します。
- `DataSourceOptions`：別のコレクション名を指定します。

```csharp
SmartMarkerOptions options = new SmartMarkerOptions
{
    // Preserve empty cells as blanks instead of removing them.
    PreserveEmptyCells = true
};

processor.Process(ws, dataSource, options);
```

これらのオプションにより、**Excel テンプレート データの入力** 操作を細かく制御でき、出力がフォーマット要件に合致することが保証されます。

## 結果の保存と出力の検証

処理後、Aspose.Cells がサポートする任意の形式（XLSX、CSV、PDF など）でワークブックを保存できます。

```csharp
workbook.Save("Result.pdf", SaveFormat.Pdf);
```

`Result.xlsx`（または `Result.pdf`）を開き、`${Comment:fieldName}` プレースホルダーが **C# によって生成されたサンプルコメントテキスト** に置き換わっていることを確認してください。セルに元のタグが残っている場合は、データ ソースのプロパティ名を再確認してください。

## よくある落とし穴と回避方法

| 問題 | 原因 | 対策 |
|-------|-------|-----|
| タグが置換されない | プロパティ名の不一致（例: `fieldname` と `fieldName`） | 大文字小文字を含めた正確な一致を確保する |
| 行が複製されない | データ ソースが 1 つのオブジェクトしか含んでおらず、テンプレートがテーブルを想定している | 複数のアイテムを含むコレクションを提供する |
| 保存時にワークブックがクラッシュする | 古いバージョンの Aspose.Cells を使用している | 最新の NuGet パッケージにアップグレードする |
| 書式が失われる | プロセッサがセルのスタイルを上書きする | `SmartMarkerOptions.PreserveCellFormatting = true` を使用してスタイルを保持する |

## 完全な動作例

以下は、コピーして貼り付け、実行できる自己完結型のプログラムです。

```csharp
using Aspose.Cells;
using System;
using System.Collections.Generic;

namespace SmartMarkerDemo
{
    class Program
    {
        static void Main()
        {
            // Load the template that contains the Smart Marker tag ${Comment:fieldName}
            Workbook workbook = new Workbook("Template.xlsx");
            Worksheet ws = workbook.Worksheets[0];

            // Create a list of data objects – each object maps to the marker property.
            var data = new List<Comment>
            {
                new Comment { fieldName = "First generated comment." },
                new Comment { fieldName = "Second generated comment." },
                new Comment { fieldName = "Third generated comment." }
            };

            // Initialise the processor and run it.
            SmartMarkerProcessor processor = new SmartMarkerProcessor();
            processor.Process(ws, data);

            // Save the populated workbook.
            workbook.Save("Result.xlsx");
            Console.WriteLine("Smart marker processing complete. Check Result.xlsx.");
        }
    }

    public class Comment
    {
        public string fieldName { get; set; }
    }
}
```

**期待結果:** `Result.xlsx` では、元々 `${Comment:fieldName}` が入っていたセルが 3 行に展開され、`data` リストの対応するコメントテキストがそれぞれ入力されます。
