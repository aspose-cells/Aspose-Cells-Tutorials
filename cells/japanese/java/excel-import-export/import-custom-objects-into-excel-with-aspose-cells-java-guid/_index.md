# Aspose.Cells を使用した Excel へのカスタムオブジェクトのインポート – Java ガイド

Excel ワークシートに **カスタムオブジェクトをインポート** する必要がある場合、このガイドでは Aspose.Cells for Java を使用した完全な手順をご案内します。**Excel へのデータインポート** 方法、太字のヘッダー スタイルの適用、そして共有可能な `.xlsx` ファイルの生成方法が確認できます。

Java から表形式データをエクスポートする際、手動でセルごとに書き込むことが多く、エラーが発生しやすく保守が困難です。`importCustomObjects` API を活用すれば、定型コードを回避し、データモデルをそのまま保ちつつ、細かいスタイリング制御が可能になります。

このチュートリアルでは:

- 典型的なデータテーブルを模倣した Java の `Map` オブジェクトのリストを作成する。
- Aspose.Cells を使用して再利用可能なヘッダー スタイル（太字フォント）を作成する。
- スタイル配列を適用しながらカスタムオブジェクトをワークシートにインポートする。
- ワークブックをディスクに保存し、結果を検証する。

必要条件は、Java 開発環境（JDK 8 以上推奨）と Aspose.Cells for Java ライブラリだけです。

---

## 必要なもの

| 要件 | 理由 |
|------|------|
| JDK 8 以上 | Java コードのコンパイルと実行に必要です。 |
| Aspose.Cells for Java（最新バージョン） | `Workbook`、`Worksheet`、インポート API を提供します。 |
| IDE またはビルドツール（例: Maven、Gradle） | 依存関係の管理と実行を簡素化します。 |
| 出力ファイル用フォルダーへの書き込み権限 | ワークブックは `ImportWithStyle.xlsx` として保存されます。 |

Maven を使用する場合は、`pom.xml` に Aspose.Cells の依存関係を追加してください：

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## ステップ 1: インポートするカスタムオブジェクトの準備

最初のステップは、Excel に配置したい行を表すコレクションを作成することです。この例では、各マップが列名をキーとした行として機能する `List<Map<String,Object>>` を使用します。

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**なぜ重要か:**  
`importCustomObjects` はオブジェクトの配列を期待します。`Map` を使用することで列名が保持され、Aspose.Cells が自動的にセルへマッピングできます。このアプローチは .NET の典型的な `DataTable` や JDBC の `ResultSet` に似ており、プロジェクト間でコードを再利用しやすくなります。

---

## ステップ 2: インポート時に適用するヘッダー スタイルの定義

明確なヘッダー行は可読性を向上させます。Aspose.Cells では `Style` オブジェクトを作成し、フォントを太字に設定し、`ImportTableOptions` 配列を介して渡すことができます。

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**なぜ重要か:**  
スタイル配列を省略すると、ヘッダーはデフォルトフォントで表示され、目立たない可能性があります。スタイルを一度作成しておくことで、各行ごとの呼び出しを繰り返す必要がなくなり、インポートロジックがすっきりします。

---

## ステップ 3: スタイル配列を使用してカスタムオブジェクトをインポート

ここでデータとスタイルを組み合わせ、`importCustomObjects` を呼び出します。このメソッドはデータを左上隅（行 0、列 0）から配置し、ヘッダー スタイルを自動的に適用します。

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**なぜ重要か:**  
`importCustomObjects` は各マップを解析し、キー（`Name`、`Score`）に基づいて列を作成し、対応するセルに値を書き込みます。`ImportTableOptions` オブジェクトは、最初の行に `styleArray` を使用するよう Aspose.Cells に指示し、余分なコードなしで太字ヘッダーを実現します。

---

## ステップ 4: ワークブックを保存し、出力を確認

最後に、ワークブックをファイルに書き出します。生成された Excel ファイルには、スタイルが適用されたヘッダー行とデータ行が続きます。

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**期待される結果:**  

| **Name** | **Score** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

ヘッダーセル（`Name`、`Score`）は太字で表示され、ステップ 2 で定義したスタイルと一致します。

## 一般的なバリエーションとエッジケース

| 状況 | 推奨される調整 |
|-----------|------------------------|
| **列の順序が異なる** | `Map` のキーが希望する順序で挿入されていることを確認するか、アノテーション付きフィールドを持つカスタム POJO と `PropertyDescriptor` 配列を使用してください。 |
| **大規模データセット（>10 000 行）** | `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` を増やして `OutOfMemoryError` を回避します。 |
| **カスタム数値書式** | データ行用に `styleArray` に 2 番目の `Style` を追加し、例えば整数スコアの場合は `NumberFormat` を `"0"` に設定します。 |
| **複数のワークシート** | 必要に応じて開始行/列を調整し、各対象ワークシートで `importCustomObjects` を呼び出します。 |
| **ロケール固有のヘッダーテキスト** | インポート前にヘッダー行を手動で入力し、`Cells.applyStyle` を使用して範囲全体にスタイルを適用します。 |

---

## 堅牢な Java から Excel へのエクスポートのためのプロのコツ

- **一時的なワークブックを再利用する** – スタイルごとに新しい `Workbook` を作成するとオーバーヘッドが増えます。複数のスタイルが必要な場合は単一インスタンスを保持してください。  
- **インポート前にデータを検証する** – マップ内の null 値は空セルになります。リストを前処理してデフォルト値に置き換えることができます。  
- **リソースを閉じる** – Aspose.Cells は内部でメモリを管理しますが、保存後に明示的に `workbook.dispose()` を呼び出すことでネイティブリソースを速やかに解放できます。  
- **`Workbook.setForceFullCalculation(true)` を設定する** – 保存前に評価が必要な数式がワークブックに含まれる場合に使用します。
