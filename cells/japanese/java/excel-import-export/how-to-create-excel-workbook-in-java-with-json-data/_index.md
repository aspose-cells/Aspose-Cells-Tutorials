# JavaでJSONデータからExcelブックを作成する方法

If you need to **create Excel workbook java** developers often face the challenge of loading JSON data into a spreadsheet. This guide shows you how to **populate Excel from JSON**, including how to **convert JSON array excel** and **populate workbook from json** in a clean, repeatable way.

JSON を扱うことは、サービスが REST API を通じてデータを公開する際に一般的であり、Excel はレポートや分析のための定番フォーマットです。このチュートリアルの最後までに、以下を実行できる実行可能な Java プログラムが手に入ります。

* 新しい Excel ブックを作成する
* JSON 配列（または任意の JSON 構造）を読み取り、セルに書き込む
* ファイルをディスクに保存し、 downstream 処理に備える

外部ツールは不要で、サンプルコードで使用している `SmartMarkerProcessor` を提供する **Aspose.Cells for Java** ライブラリだけで完結します。

## 前提条件

開始する前に、以下を用意してください。

| 前提条件 | 理由 |
|--------------|--------|
| Java Development Kit (JDK) ≥ 8 | サンプルをコンパイル・実行するために必須 |
| Maven or Gradle (optional) | 依存関係管理を簡素化 |
| Aspose.Cells for Java (v23.10 or later) | `Workbook` と `SmartMarkerProcessor` クラスを提供 |
| Basic knowledge of JSON and Java I/O | データフローの理解に役立つ |

ビルドツールを使用しない場合は、[Aspose のウェブサイト](https://products.aspose.com/cells/java/) から Aspose.Cells JAR をダウンロードし、プロジェクトのクラスパスに手動で追加してください。

## ステップ 1: プロジェクトを設定し、Aspose.Cells の依存関係を追加する

### Maven ユーザー

`pom.xml` に以下の依存関係を追加します。

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Gradle ユーザー

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

ビルドツールを使用しない場合は、ダウンロードした JAR を `libs/` フォルダーに配置し、コンパイル時にクラスパスに含めます。

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## ステップ 2: 新しいブックを作成し、SmartMarker プロセッサを設定する

`SmartMarkerProcessor` は JSON の値を Excel のセルへマッピングする作業を簡素化します。`setArrayAsSingle(true)` を呼び出すことで、JSON 配列全体を単一の値として扱うよう指示し、各要素を行内の個別セルに配置できるようになります。

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**Why this matters:**  
ブックを最初に作成しておくことで、クリーンなキャンバスが得られます。`setArrayAsSingle(true)` を設定しないと、配列は `["A","B","C"]` のような単一文字列にフラット化されてしまい、レイアウトの制御が難しくなります。

## ステップ 3: 挿入したい JSON データを定義する

このチュートリアルではシンプルな JSON 配列を使用しますが、同じ手法でオブジェクトや入れ子配列、複雑な構造にも対応できます。

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**Tip:** JSON がファイルや REST エンドポイントから取得される場合は、リテラル文字列の代わりに `Files.readString(Paths.get("data.json"))` などで取得した `String` を使用してください。

## ステップ 4: JSON データでブックを処理する

ここで `SmartMarkerProcessor` に JSON 配列をマッピングさせ、最初のワークシートに書き込みます。デフォルトの動作では、要素が `A1` から始まる連続セルに配置されます。

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

内部では Aspose.Cells が JSON を解析し、一時的なデータテーブルを作成してワークシートに書き込みます。`ArrayAsSingle` を `true` に設定したため、配列要素は横方向に第一行に配置されます。

## ステップ 5: ブックをファイルに保存する

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

プログラムを実行すると、作業ディレクトリに **CreatedFromJson.xlsx** という名前のファイルが生成されます。Excel（または互換ビューア）で開くと以下のように表示されます。

| A | B | C |
|---|---|---|
| A | B | C | *(セル A1、B1、C1 に値が表示されます)*

### 期待される出力

```
Workbook saved to CreatedFromJson.xlsx
```

そして Excel シートは次のようになります。

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## ステップ 6: より複雑な JSON 構造の処理（オプション）

### 6.1 JSON オブジェクトからブックを埋め込む

JSON が配列ではなくオブジェクトの場合でも、`SmartMarkerProcessor` を利用できます。例：

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

プロセッサは名前付き範囲（`title`、`month`、`values`）を作成し、Excel テンプレート内で `&=title` や `&=values` といった Smart Marker を使用して参照できます。

### 6.2 入れ子 JSON 配列を縦リストに変換する

配列を行ではなく列に配置したい場合は、処理前に開始セルを手動で設定します。

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

これで **A**、**B**、**C** がそれぞれセル A2、A3、A4 に縦方向に配置されます。

## よくある落とし穴と回避方法

| 問題 | 原因 | 対策 |
|-------|-------|-----|
| **配列が単一文字列として書き込まれる** | `setArrayAsSingle(false)`（デフォルト） | `processor.setArrayAsSingle(true)` を呼び出す |
| **保存時にファイルが見つからない** | パスが無効、または書き込み権限がない | 絶対パスを使用するか、ディレクトリが存在することを確認 |
| **JSON 解析エラー** | JSON 文字列が不正 | ツールで JSON を検証するか、Jackson などのライブラリで文字列を生成 |
| **セルが意図せず上書きされる** | 同一シートを複数回処理し、開始セルをリセットしていない | 各 `process` 呼び出し前に `processor.setStartCell("A1")` を実行 |

## プロのコツ: テンプレートとしてブックを再利用する

毎回空のブックから始める代わりに、ヘッダーや数式、スタイルが事前に設定されたテンプレートをロードできます。

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

この方法により、手作りの Excel ファイルの見た目と、**populate workbook from json** の自動化を両立できます。
