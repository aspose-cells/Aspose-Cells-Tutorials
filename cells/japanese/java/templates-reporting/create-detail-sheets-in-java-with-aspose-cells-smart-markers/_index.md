# JavaでAspose.Cellsスマートマーカーを使用して詳細シートを作成する

Javaアプリケーションで**詳細シートを作成**する必要がある場合、このチュートリアルではAspose.Cellsスマートマーカーを使用した方法を示します。**java create worksheets**、**sheet name from field**、**process data source** を数行のコードで実行する完全な実行可能サンプルが確認できます。

このガイドはプロジェクトのセットアップから最終ワークブックの保存までを網羅しているので、ソリューションをコピー＆ペーストしてすぐに自分のプロジェクトに適用できます。外部ドキュメントは不要です—必要なものはすべてここにあります。

## 学習できること

* **use smart markers** を使用して、マスターデータセットの各行に対してテンプレートワークシートを複製する方法。  
* フィールド値（例: `Order_123`）に基づいて各新シートの名前を動的に設定する方法。  
* Java コレクションを **process data source** としてスマートマーカーエンジンに供給する方法。  
* 空データ、シート名の特殊文字、大規模データセットのパフォーマンス考慮事項など、エッジケースの取り扱いに関するヒント。

### 前提条件

| 要件 | 理由 |
|------|------|
| Java 8 or higher | Aspose.Cells for Java は Java 8+ をサポートしています。 |
| Maven or Gradle build system | Aspose.Cells の依存関係追加が簡単になります。 |
| Basic knowledge of Java collections | スマートマーカーのデータソースを構築するために必要です。 |
| A template Excel file (`Template.xlsx`) with a placeholder smart marker in cell **A1** | このテンプレートが詳細シートの生成を駆動します。 |

> **Pro tip:** テンプレートワークブックをプロジェクトの `resources` フォルダーに配置すると、JAR にパッケージされます。

## 手順 1: Aspose.Cells をプロジェクトに追加する (java create worksheets)

**Maven** を使用している場合、`pom.xml` に次の依存関係を追加します：

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

**Gradle** を使用している場合、`build.gradle` に次の行を配置します：

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

これらの行により、**java create worksheets** API がコンパイル時に利用可能になります。

## 手順 2: テンプレートワークブックを読み込む

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*Why this matters:* `Workbook` オブジェクトはすべての Excel 操作のエントリーポイントです。テンプレートを読み込むことで、正しいレイアウトと事前定義された書式設定で開始できます。

## 手順 3: マスタ行ごとに新しいシートを作成するスマートマーカーを挿入する (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

`${Orders:DetailSheetNewName=Order_${OrderId}}` 構文は **use smart markers** の核心です。次の 3 つのことを行います：

1. `Orders` コレクションを反復処理します。  
2. 各要素ごとに **new worksheet** を作成します。  
3. フィールド `OrderId`（`Order_` プレフィックス付き）から **sheet name from field** を設定します。

## 手順 4: データソースを準備する (process data source)

以下は `List<Map<String, Object>>` を使用した最小例です。実際のデータソース（データベース行、JSON デシリアライズなど）に置き換えてください。

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*Why this matters:* **process data source** ステップは Java コレクションをスマートマーカーエンジンにバインドします。キー（`"Orders"`）はスマートマーカー名と完全に一致する必要があります。

## 手順 5: スマートマーカーを処理する (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

`process` が実行されると、Aspose.Cells は `Orders` コレクションを読み取り、テンプレートワークシートを各エントリ用にクローンし、`OrderId` フィールドに従って各シートの名前を変更します。これが **process data source** の使用の核心です。

## 手順 6: 複製された詳細シートを含むワークブックを保存する

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

実行後、`DuplicatedDetailSheets.xlsx` には次のシートが含まれます：

* `Sheet1` – 元のテンプレート（変更なし）。  
* `Order_101` – 最初の注文の詳細シート。  
* `Order_102` – 2 番目の注文の詳細シート。

### 期待される出力（抜粋）

| シート名 | A1 (smart marker) | 結果の内容 |
|----------|-------------------|------------|
| Order_101 | `${Orders:...}`   | `order1` のデータで埋め込まれます |
| Order_102 | `${Orders:...}`   | `order2` のデータで埋め込まれます |

Excel でファイルを開き、各シートが正しく名前付けされデータ行が含まれていることを確認してください。

## 一般的なバリエーションとエッジケースの処理

### 空のデータソース

`orders` が空の場合、スマートマーカー処理は **new worksheets** を作成しません。空のワークブックを防ぐためにガードを追加します：

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### シート名の特殊文字

Excel のシート名には `\ / ? * [ ] :` を含めることはできません。使用する前にフィールドをクリーンアップしてください：

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### 大規模データセット

数千行の場合、JVM ヒープを増やす（例: `-Xmx2g`）ことと、すべてのシート生成後にのみ `workbook.calculateFormula()` を呼び出すことでパフォーマンスを向上させることを検討してください。
