# Hur man bäddar in typsnitt i HTML när man sparar en arbetsbok

Om du behöver **how to embed fonts in HTML** när du exporterar ett kalkylblad, visar den här handledningen en komplett, färdig‑att‑köra lösning. Oavsett om du bygger en rapportportal eller en klient‑sidig analysvy, garanterar inbäddning av typsnitt att den renderade HTML‑en ser exakt ut som den ursprungliga arbetsboken, oavsett vilka typsnitt som är installerade på betraktarens system.

Du kommer också att lära dig det bästa sättet att **save workbook as HTML** med Aspose.Cells, se vanliga fallgropar och få tips för att hantera stora arbetsböcker eller anpassade typsnittsfiler. Ingen extern dokumentation krävs—allt du behöver finns i den här guiden.

## Förutsättningar

- .NET 6.0 eller senare (koden fungerar också med .NET Framework 4.7+)
- En giltig Aspose.Cells för .NET-licens (eller så kan du använda gratis utvärderingsläge)
- Grundläggande C#-kunskaper och en IDE som Visual Studio 2022
- TrueType‑(.ttf) eller OpenType‑(.otf) typsnittsfilerna du vill bädda in (de måste vara åtkomliga för den körande processen)

## Steg 1: Ställ in projektet och importera Aspose.Cells

Skapa en ny konsolapplikation och lägg till Aspose.Cells NuGet‑paketet:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

Öppna sedan **Program.cs** och lägg till de nödvändiga `using`‑direktiven:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **Pro tip:** Placera dina anpassade typsnitt i en mapp som heter `fonts` i projektets rot. Detta gör lösningen portabel och gör det enkelt att referera till dem senare.

## Steg 2: Skapa eller ladda en arbetsbok

För demonstration skapar vi en enkel arbetsbok med några formaterade celler:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **Why this matters:** Om du hoppar över den anpassade stilen kommer den exporterade HTML‑en att falla tillbaka på webbläsarens standardtypsnitt, vilket undergräver syftet med **how to embed fonts in HTML**.

## Steg 3: Konfigurera `HtmlSaveOptions` för att bädda in typsnitt

Kärnan i **how to embed fonts in HTML** ligger i `HtmlSaveOptions`‑klassen. Genom att sätta `EmbedFonts = true` instrueras Aspose.Cells att bädda in alla refererade TrueType/OpenType‑typsnitt direkt i den genererade HTML‑en som Base64‑kodade data‑URI:er.

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### Så fungerar inbäddningen

När `EmbedFonts` är `true` skannar Aspose.Cells arbetsbokens stildefinitioner, hittar motsvarande typsnittsfiler på systemet (eller i `fonts`‑mappen du lade till), läser deras binära data och injicerar ett `<style>`‑block liknande:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

Eftersom typsnittsdata kodas direkt i HTML‑en renderas sidan korrekt även på maskiner som inte har typsnittet installerat.

## Steg 4: Spara arbetsboken som HTML

Nu kan du **save workbook as HTML** med de konfigurerade alternativen. Välj en katalog som applikationen kan skriva till (t.ex. `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

När programmet körs skapas en enda `report.html`‑fil. Öppna den i någon modern webbläsare så ser du rubriken “Quarterly Sales” renderad med **Pacifico**‑typsnittet, även om typsnittet inte är installerat på ditt OS.

### Förväntad output

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

`src:`‑attributet innehåller en lång Base64‑sträng—detta är de inbäddade typsnittsdata som möjliggör **how to embed fonts in HTML**.

## Steg 5: Verifiera typsnitts‑inbäddning och felsök

1. **Öppna HTML‑filen i Chrome eller Edge.** Om det anpassade typsnittet visas har inbäddningen lyckats.  
2. **Inspektera sidans källkod.** Leta efter `@font-face`‑regeln som genererats av Aspose.Cells.  
3. **Common issues:**  
   - *Missing font file:* Se till att typsnittsfilen är åtkomlig. Du kan explicit lägga till en mapp i sökvägen:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *Large HTML size:* Inbäddning av många typsnitt kan göra filen onödigt stor. Använd `ExportToSingleFile = false` för att hålla typsnitten som separata `.ttf`‑filer i en resurser‑mapp.

   - *Unsupported font format:* Aspose.Cells bäddar endast in TrueType (`.ttf`) och OpenType (`.otf`). Konvertera andra format innan inbäddning.

## Fullt fungerande exempel

Nedan är det kompletta programmet som du kan kopiera, klistra in och köra utan ändringar (förutom den valfria licensraden).

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

När du kör detta program skapas `output/report.html`. Öppna filen så ser du **Pacifico**‑typsnittet renderat korrekt—det demonstrerar **how to embed fonts in HTML** medan du **save workbook as HTML**.

## Vanliga frågor

| Fråga | Svar |
|----------|--------|
| *Kan jag bädda in bara specifika typsnitt?* | Ja. Ställ in `htmlOpt.EmbedAllFonts = false` (tillgängligt i nyare versioner) och använd `htmlOpt.FontsToEmbed` för att lista de exakta typsnittsnamnen. |
| *Vad händer om jag behöver bädda in typsnitt för flera arbetsblad?* | Ställ in `ExportActiveWorksheetOnly = false` så att varje arbetsblad exporteras, och Aspose.Cells kommer att bädda in typsnitt som används i hela arbetsboken. |
| *Fungerar inbäddade typsnitt i mobila webbläsare?* | Moderna mobila webbläsare stöder Base64‑kodade typsnitt, så de inbäddade typsnitten renderas korrekt så länge typsnittformatet stöds (TTF eller OTF). |
| *Hur stor kan HTML‑filen bli?* | Att bädda in ett 200 KB TrueType‑typsnitt lägger till ungefär samma mängd till HTML‑storleken (Base64 lägger till ~33 % overhead). För många typsnitt, överväg att exportera till en mapp (`ExportToSingleFile = false`) för att hålla HTML‑filen lätt. |
