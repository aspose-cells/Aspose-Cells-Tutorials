# Så bäddar du in typsnitt när du sparar Excel till HTML med C#

Att bädda in typsnitt när du sparar en Excel-arbetsbok till HTML är ett vanligt krav för att bevara det exakta utseendet på dina kalkylblad i olika webbläsare. Om du behöver exportera Excel till HTML samtidigt som du behåller de ursprungliga teckensnitten, visar den här guiden en komplett, färdig‑att‑köra lösning.

Du kommer att lära dig hur du **exporterar Excel till HTML**, **konverterar Excel till HTML** med inbäddade typsnitt, och undviker det vanliga problemet med “saknade‑typsnitt” som förstör layouten på klientdatorer. Inga externa verktyg krävs—bara Aspose.Cells‑biblioteket och några rader C#.

## Förutsättningar

* .NET 6.0 (eller senare) installerat.
* En licensierad kopia av **Aspose.Cells for .NET** – gratis provversion fungerar för testning.
* En IDE som Visual Studio 2022 eller VS Code.

Om du redan har detta kan du hoppa rakt in i koden.

## Steg 1: Skapa en arbetsbok och lägg till exempeldata

Först genererar vi en liten arbetsbok så att du kan se effekten av inbäddade typsnitt. Koden nedan skapar ett kalkylblad, skriver några celler och tillämpar ett anpassat typsnitt.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### Varför vi lägger till ett anpassat typsnitt

Att bädda in typsnitt är bara relevant när arbetsboken använder typsnitt som kanske inte finns på klientenheten. Genom att explicit ange **Arial** (eller något annat typsnitt) kan vi verifiera att HTML‑utdata verkligen innehåller typsnittsdata.

## Steg 2: Konfigurera HTML‑sparalternativ för att bädda in typsnitt

Aspose.Cells tillhandahåller klassen `HtmlSaveOptions`. Genom att sätta `EmbedFonts = true` instrueras biblioteket att bädda in de nödvändiga typsnittsfilerna direkt i den genererade HTML‑koden som Base64‑kodade data‑URI:er.

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### Vad “embed fonts in html” faktiskt gör

När `EmbedFonts` är true extraherar Aspose.Cells typsnittsfilerna från systemet (eller från arbetsbokens inbäddade typsnittssamling) och konverterar dem till **Base64**‑strängar. Dessa strängar placeras sedan i ett `<style>`‑block med `@font-face`. Den resulterande HTML‑filen kan öppnas på vilken enhet som helst utan att det ursprungliga typsnittet måste vara installerat.

## Steg 3: Spara arbetsboken som HTML med inbäddade typsnitt

Nu skriver vi arbetsboken till disk. Filen kommer att innehålla typsnittsdata, så att öppna den i någon modern webbläsare visar exakt samma typografi som den ursprungliga Excel‑filen.

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### Förväntat resultat

* `embedded.html` finns i mappen `output`.
* När du öppnar filen i Chrome, Edge eller Firefox visas kalkylbladet med **Arial**‑text, även om maskinen som kör webbläsaren saknar Arial.
* Genom att inspektera HTML‑källkoden ser du ett `<style>`‑block som innehåller en `@font-face`‑regel med en lång `src: url(data:font/ttf;base64,…)`‑deklaration – det är det inbäddade typsnittet.

## Steg 4: Verifiera att HTML fungerar på en annan maskin (valfritt)

För att vara helt säker på att inbäddningen lyckades:

1. Kopiera `output/embedded.html` till en annan dator (eller en virtuell maskin) som **inte** har det anpassade typsnittet installerat.
2. Öppna filen i en webbläsare.
3. Layouten och typografin bör matcha den ursprungliga Excel‑vyn.

Om typsnittet faller tillbaka till ett generiskt, dubbelkolla att typsnittsfilen är åtkomlig på byggmaskinen och att du har behörighet att läsa den.

## Vanliga frågor och edge‑cases

### Ökar inbäddning filstorleken?

Ja. Att bädda in ett TrueType‑ eller OpenType‑typsnitt kan lägga till **tiotals kilobyte** till HTML‑filen. För stora arbetsböcker med många unika typsnitt, överväg:

* Att skapa en delmängd av typsnittet (endast de tecken du använder) – Aspose.Cells gör detta automatiskt för de flesta vanliga typsnitt.
* Att använda `ExportEmbeddedImages = false` om du inte behöver inbäddade bilder.

### Vad om jag bara behöver bädda in specifika typsnitt?

`HtmlSaveOptions` erbjuder ingen direkt vitlista, men du kan kontrollera vilka typsnitt som inkluderas genom att **begränsa typsnitten som används i arbetsboken** innan du anropar `Save`. Ta bort onödiga typsnittstilldelningar eller ersätt dem med standard‑webbsäkra typsnitt.

### Kan jag bädda in typsnitt när jag konverterar till andra format (t.ex. PDF)?

Samma `EmbedFonts`‑egenskap finns på `PdfSaveOptions`. Konceptet är identiskt: typsnittsdata inbäddas så att PDF‑filen renderas korrekt i vilken visare som helst.

## Fullt, körbart exempel

Nedan är det kompletta programmet som du kan kopiera‑och‑klistra in i ett nytt konsolprojekt.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

När du kör programmet får du en **HTML‑fil som innehåller det inbäddade Arial‑typsnittet**, vilket garanterar visuell trohet oavsett var filen öppnas.

## Slutsats

Du vet nu **hur du bäddar in typsnitt när du sparar Excel till HTML** med C#. Genom att konfigurera `HtmlSaveOptions.EmbedFonts = true` kan du på ett pålitligt sätt **exportera Excel till HTML** och **konvertera Excel till HTML** utan att oroa dig för saknade typsnitt på klientsidan. Denna teknik är avgörande för webbaserad rapportering, e‑postvänliga instrumentpaneler eller vilket scenario som helst där du delar Excel‑baserat innehåll som HTML.

### Vad blir nästa steg?

* **Anpassa den CSS** som genereras av Aspose.Cells för att matcha din webbplats stilguide.  
* **Bädda in bilder** selektivt genom att växla `ExportEmbeddedImages`.  
* **Utforska andra exportformat** såsom PDF eller SVG samtidigt som du fortfarande bäddar in typsnitt.  

Känn dig fri att experimentera med olika typsnitt, större kalkylblad eller arbetsböcker med flera blad. Samma `EmbedFonts`‑flagga fungerar i alla stödda utdataformat och ger dig konsekvent kontroll över typsnitts­inbäddning där du än behöver det. Lycka till med kodningen!
