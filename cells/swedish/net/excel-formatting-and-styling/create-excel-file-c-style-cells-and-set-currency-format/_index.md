# Skapa excel‑fil c# – formatera celler och ange valutaformat

Om du behöver **create excel file c#** som ser professionell ut, visar den här guiden exakt hur du formaterar excel‑celler och formaterar en kolumn som valuta. Du får se ett komplett, end‑to‑end‑exempel som importerar en `DataTable`, applicerar en fet rubrik och sätter ett `$#,##0.00`‑talformat för pris‑kolumnen.

Handledningen täcker allt du behöver: nödvändiga NuGet‑paket, hela källkoden, förklaringar till varför varje del är viktig, och tips för att hantera kantfall såsom tomma rader eller olika språk. I slutet kommer du kunna generera en `.xlsx`‑fil med en snyggt formaterad pris‑kolumn på bara några rader C#.

## Förutsättningar

- .NET 6.0 eller senare (koden fungerar också med .NET Framework 4.6+)
- Visual Studio 2022 eller någon C#‑redigerare du föredrar
- Biblioteket **Aspose.Cells for .NET** eller **GemBox.Spreadsheet** (båda stödjer `ImportTableOptions`). Exemplet nedan använder **Aspose.Cells** eftersom det erbjuder en enkel `StyleArray`‑egenskap.
- Grundläggande kunskap om C#‑samlingar och `DataTable`

> **Pro tip:** Om du föredrar ett gratisalternativ, ersätt `Aspose.Cells` med `GemBox.Spreadsheet`. API‑et för att importera en `DataTable` med stilar är nästan identiskt; byt bara namnrymd och NuGet‑paketnamn.

## Steg 1: Installera Excel‑biblioteket

Öppna NuGet Package Manager och installera biblioteket:

```bash
dotnet add package Aspose.Cells
```

> **Varför detta steg?** Biblioteket tillhandahåller klasserna `Workbook`, `Worksheet`, `Style` och `ImportTableOptions` som används senare. Utan det skulle du behöva skriva Office Open XML‑formatet manuellt, vilket är felbenäget.

## Steg 2: Skapa en DataTable med exempeldata

En `DataTable` är ett bekvämt sätt att hålla tabulär data innan den exporteras till Excel. I detta exempel har vi två kolumner: *Product* och *Price*.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Förklaring:**  
> - `Columns.Add("Price", typeof(double))` talar om för tabellen att behandla prisvärdena som siffror, vilket krävs för talformatering senare.  
> - Att lägga till några rader ger oss data för att verifiera steget **format column currency**.

## Steg 3: Definiera de stilar du vill tillämpa

Vi kommer skapa en array av `Style`‑objekt som matchar kolumnordningen. Det första elementet formaterar rubrikraden, det andra lämnar *Product*-kolumnen orörd, och det tredje tillämpar ett valuta‑talformat.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### Varför använda en **style array**?

`ImportTableOptions.StyleArray` mappar varje kolumn till en `Style`. Detta är det mest effektiva sättet att **add number format** och **style excel cells** i en enda importoperation, vilket undviker ett andra pass över kalkylbladet.

## Steg 4: Konfigurera importalternativ

Nu binder vi stil‑arrayen till importoperationen. `ImportTableOptions`‑objektet låter dig också styra om den första raden behandlas som en rubrik.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Obs:** `IsFieldNameShown` är `true` som standard, men att sätta den explicit gör avsikten tydlig för framtida läsare.

## Steg 5: Skapa en arbetsbok, importera tabellen och spara

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### Förväntat resultat

När du öppnar `DataTableWithStyles.xlsx`:

- Den första raden (rubrik) är **fet**.
- *Price*-kolumnen visar värden som **$1.20**, **$3.50**, **$0.75**.
- *Product*-kolumnen behåller standardtypsnittet.

Du har framgångsrikt **created an excel file c#** med en formaterad valuta‑kolumn och stilade rubrikceller.

## Steg 6: Hantera vanliga variationer och kantfall

### a. Olika språk eller anpassad valutasymbol

Om du behöver Euro eller en annan valuta, ersätt det inbyggda formatet `164` med en anpassad formatsträng:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. Lägga till fler kolumner senare

När du lägger till extra kolumner, utöka `columnStyles`‑arrayen i enlighet med detta. Använd `null` för kolumner som ska behålla standardstilen.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. Tom DataTable

Om `DataTable`‑en saknar rader, skapar Aspose.Cells fortfarande rubrikraden. Arbetsboken kommer dock bara innehålla en rad. För att undvika en tom fil, kontrollera radantalet innan import:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Använda `GemBox.Spreadsheet` istället för Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

Logiken förblir identisk, vilket visar att handledningen är **format column currency** oberoende av det underliggande biblioteket.

## Steg 7: Verifiera filen programatiskt (valfritt)

Du kan öppna den genererade arbetsboken och påstå att talformatet har tillämpats korrekt – användbart för enhetstester.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```
