# Hur man skapar Excel-arbetsbok C# med anpassad formatering och sparar som XLSX

Om du behöver **create Excel workbook C#** som importerar data, tillämpar ett anpassat talformat och ändrar cellens teckensnittsfärg, visar den här handledningen exakt hur du gör. Du får ett färdigt exempel som producerar en formaterad `StyleArrayImport.xlsx`‑fil på några sekunder.

Att arbeta med Excel från C# innebär ofta repetitiva manuella steg—att definiera format, applicera färger och komma ihåg att spara filen korrekt. I slutet av den här guiden automatiserar du alla dessa uppgifter, så att du kan fokusera på data istället för UI.

Du kommer att lära dig hur du:

* importerar en `DataTable` till ett kalkylblad,
* använder en `StyleArray` för att **apply custom number format** och **change cell font color**,
* **save workbook as XLSX** med ett enda metodanrop,
* och verifierar att **format imported data excel** visas exakt som avsett.

Det enda förutsättningen är en referens till **Aspose.Cells for .NET**‑biblioteket (eller något kompatibelt API som tillhandahåller `Workbook`, `Worksheet` och `StyleArray`). Koden riktar sig mot .NET 6+, men tidigare versioner fungerar med mindre justeringar.

## Prerequisites

| Krav | Orsak |
|------|-------|
| .NET 6 SDK or later | Provides the runtime for the C# console app. |
| Aspose.Cells for .NET (NuGet package `Aspose.Cells`) | Supplies `Workbook`, `Worksheet`, and `StyleArray` classes used in the example. |
| Visual Studio 2022 (or any C# IDE) | Makes it easy to compile and run the sample. |
| Basic knowledge of `DataTable` manipulation | Needed to generate the source data set. |

Install the Aspose.Cells package with the following command:

```bash
dotnet add package Aspose.Cells
```

## Steg 1: Förbered exempel‑DataTable

Först skapar du en `DataTable` som efterliknar den data du normalt skulle hämta från en databas eller annan källa. Tabellen innehåller en **Name**‑kolumn (string) och en **Amount**‑kolumn (decimal) som vi kommer att formatera senare.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Why this matters:** Att använda en `DataTable` låter dig hålla importlogiken oberoende av datakällan, vilket är ett vanligt mönster när man genererar rapporter från databaser, CSV‑filer eller API:er.

## Steg 2: Definiera en StyleArray för att **apply custom number format** och **change cell font color**

`StyleArray` låter dig samla formateringsinstruktioner som kommer att tillämpas på varje cell som importeras från `DataTable`. I detta exempel:

* sätter vi `Number` till `#,##0.00` – ett typiskt bokföringsformat med tusentalsavgränsare,
* sätter vi `FontColor` till `Color.Blue` – vilket får siffrorna att sticka ut.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**Why use a StyleArray?** Att applicera en stil vid importtid undviker ett andra pass över kalkylbladet, vilket förbättrar prestandan för stora datamängder.

---

## Steg 3: **Create Excel workbook C#** – skapa Workbook och hämta det första Worksheet

Nu skapar vi en tom arbetsbok och får en referens till det första kalkylbladet (index 0). Detta kalkylblad blir destinationen för vår importerade data.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Explanation:** `Workbook` representerar hela Excel‑filen, medan `Worksheet` representerar en enskild flik. Standardarbetsboken innehåller ett blad, vilket räcker för de flesta enkla rapporter.

---

## Steg 4: Importera DataTable med **StyleArray** för att **format imported data excel**

`ImportDataTable`‑metoden kopierar tabellens rader och kolumner till kalkylbladet, med start i cell `A1` (rad 0, kolumn 0). Argumentet `true` talar om för metoden att inkludera kolumnrubriker. Eftersom vi skickar med `styleArray` får varje importerad cell det anpassade talformatet och teckensnittsfärgen.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**What happens under the hood:** Aspose.Cells itererar över varje rad, skriver värdet och applicerar sedan den stil som definierats i `styleArray`. Siffror visas med kommatecken och två decimaler, och texten renderas i blått.

## Steg 5: **Save workbook as XLSX** – skriv filen till disk

Till sist sparar vi arbetsboken till en `.xlsx`‑fil. Du kan ändra sökvägen till någon skrivbar katalog på din maskin.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Result verification:** Öppna den genererade filen i Excel. Du bör se de tre raderna med data, **Amount**‑kolumnen formaterad med kommatecken, två decimaler och visad i blått teckensnitt. Detta bekräftar att steget **format imported data excel** lyckades.

## Fullständigt fungerande exempel

Kopiera hela blocket nedan till ett nytt konsolprojekt och kör det. Ingen extra kod behövs.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Expected output in the console:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

Öppna filen och verifiera att **Amount**‑kolumnen visar värden som `1,234.56` i blått teckensnitt.

## Vanliga frågor & edge‑cases

| Fråga | Svar |
|-------|------|
| *Can I apply different formats to individual columns?* | Yes. After importing, retrieve the column’s `Style` object (`worksheet.Cells.Columns[1].Style`) and set a different `Number` or `FontColor`. |
| *What if I need to format dates instead of numbers?* | Set `styleArray.Number = "mm-dd-yyyy"` and optionally `styleArray.FontColor` for date cells. |
| *Is the blue font visible on dark Excel themes?* | Blue can be hard to read on dark backgrounds. Use a lighter shade (`Color.LightBlue`) or a contrasting color (`Color.Black`). |
| *How do I import a very large DataTable (hundreds of thousands of rows)?* | Use `ImportDataTable` with the `ImportDataTableOptions` overload to stream data, or split the import into multiple worksheets to stay within Excel’s row limit (1,048,576 rows). |
| *Can I export to CSV instead of XLSX?* | Replace `SaveFormat.Xlsx` with `SaveFormat.Csv`. Note that formatting information (number format, font color) is lost in CSV because it’s a plain‑text format. |

## Tips för produktionsanvändning

* **Pro tip:** Cache the `Style` object if you need to apply the same formatting to many worksheets; creating a new `StyleArray` for each import adds overhead.
* **Watch out for culture differences:** The `Number` pattern `#,##0.00` follows the invariant culture. If you need locale‑specific separators, use `NumberFormatInfo` or let Excel handle it based on the user’s regional settings.
* **Error handling:** Wrap the `Save` call in a try‑catch block to handle I/O exceptions (e.g., insufficient permissions or locked files).
