# Skapa detaljblad i Java med Aspose.Cells smart markers

Om du behöver **create detail sheets** i en Java‑applikation visar den här handledningen hur du gör det med Aspose.Cells smart markers. Du får se ett komplett, körbart exempel som **java create worksheets**, hämtar **sheet name from field**, och **process data source** på bara några rader kod.

Guiden täcker allt från projektuppsättning till att spara den färdiga arbetsboken, så att du kan kopiera‑klistra lösningen i ditt eget projekt och anpassa den omedelbart. Ingen extern dokumentation krävs—allt du behöver finns här.

## Vad du kommer att lära dig

* Hur du **use smart markers** för att duplicera ett mall‑arbetsblad för varje rad i ett huvuddatamängd.  
* Hur du dynamiskt sätter varje nytt bladnamn baserat på ett fältvärde (t.ex. `Order_123`).  
* Hur du matar en Java‑samling som **process data source** för smart‑marker‑motorn.  
* Tips för att hantera kantfall såsom tom data, specialtecken i bladnamn, och prestandaöverväganden för stora datamängder.

### Förutsättningar

| Krav | Orsak |
|-------------|--------|
| Java 8 eller högre | Aspose.Cells for Java stödjer Java 8+. |
| Maven eller Gradle byggsystem | Förenklar att lägga till Aspose.Cells‑beroendet. |
| Grundläggande kunskap om Java‑samlingar | Behövs för att bygga datakällan för smart markers. |
| En mall‑Excel‑fil (`Template.xlsx`) med en platshållar‑smart‑marker i cell **A1** | Mallen styr genereringen av detaljblad. |

> **Pro tip:** Behåll mall‑arbetsboken i projektets `resources`‑mapp så att den paketeras med din JAR.

## Steg 1: Lägg till Aspose.Cells i ditt projekt (java create worksheets)

Om du använder **Maven**, lägg till följande beroende i `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

För **Gradle**, placera den här raden i `build.gradle`:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

Dessa rader gör **java create worksheets**‑API:erna tillgängliga vid kompilering.

## Steg 2: Ladda mall‑arbetsboken

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*Varför detta är viktigt:* `Workbook`‑objektet är ingångspunkten för alla Excel‑operationer. Att ladda mallen säkerställer att du börjar med rätt layout och eventuell fördefinierad formatering.

## Steg 3: Infoga en smart marker som skapar ett nytt blad per huvudrad (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

Syntaxen `${Orders:DetailSheetNewName=Order_${OrderId}}` är kärnan i **use smart markers**. Den gör tre saker:

1. Itererar över `Orders`‑samlingen.  
2. Skapar ett **new worksheet** för varje element.  
3. Sätter **sheet name from field** `OrderId` (med prefixet `Order_`).

## Steg 4: Förbered datakällan (process data source)

Nedan är ett minimalt exempel som använder en `List<Map<String, Object>>`. Ersätt det med din verkliga datakälla—databasrader, JSON‑deserialisering, etc.

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*Varför detta är viktigt:* Steget **process data source** binder din Java‑samling till smart‑marker‑motorn. Nyckeln (`"Orders"`) måste exakt matcha smart‑marker‑namnet.

## Steg 5: Bearbeta smart markers (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

När `process` körs läser Aspose.Cells `Orders`‑samlingen, klonar mall‑arbetsbladet för varje post och byter namn på varje blad enligt fältet `OrderId`. Detta är kärnan i användning av **process data source**.

## Steg 6: Spara arbetsboken med duplicerade detaljblad

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

Efter körning hittar du `DuplicatedDetailSheets.xlsx` som innehåller:

* `Sheet1` – den ursprungliga mallen (oförändrad).  
* `Order_101` – detaljblad för den första ordern.  
* `Order_102` – detaljblad för den andra ordern.

### Förväntat resultat (utdrag)

| Bladnamn | A1 (smart marker) | Resulterande innehåll |
|----------|-------------------|-----------------------|
| Order_101  | `${Orders:...}`   | Fylld med data från `order1` |
| Order_102  | `${Orders:...}`   | Fylld med data från `order2` |

Öppna filen i Excel för att verifiera att varje blad har rätt namn och innehåller dataraderna.

## Hantera vanliga variationer och kantfall

### Tom datakälla

Om `orders` är tom skapar smart‑marker‑processorn **inga nya arbetsblad**. För att undvika en tom arbetsbok, lägg till en kontroll:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### Specialtecken i bladnamn

Excel‑bladnamn får inte innehålla `\ / ? * [ ] :`. Rensa fältet innan du använder det:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### Stora datamängder

För tusentals rader, överväg att öka JVM‑heapen (`-Xmx2g`) och anropa `workbook.calculateFormula()` först efter att alla blad har genererats för att förbättra prestandan.
