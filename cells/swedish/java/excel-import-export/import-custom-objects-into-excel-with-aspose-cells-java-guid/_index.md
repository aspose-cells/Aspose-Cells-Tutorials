# Importera anpassade objekt till Excel med Aspose.Cells – Java‑guide

Om du behöver **importera anpassade objekt** till ett Excel‑arbetsblad, guidar den här guiden dig genom hela processen med Aspose.Cells för Java. Du kommer att se hur du **importerar data till Excel**, använder en fet rubrikstil och genererar en färdig‑att‑dela `.xlsx`‑fil.

Att exportera tabulära data från Java innebär ofta manuella cell‑för‑cell‑skrivningar, vilket är felbenäget och svårt att underhålla. Genom att utnyttja `importCustomObjects`‑API:et undviker du boilerplate‑kod, behåller din datamodell intakt och får fin‑granulerad stilkontroll.

I den här handledningen kommer du att:

* Bygga en lista med Java `Map`‑objekt som efterliknar en typisk datatabell.
* Skapa en återanvändbar rubrikstil (fet teckensnitt) med Aspose.Cells.
* Importera de anpassade objekten till ett arbetsblad samtidigt som du tillämpar stil‑arrayen.
* Spara arbetsboken till disk och verifiera resultatet.

Det enda förutsättningen är en Java‑utvecklingsmiljö (JDK 8+ rekommenderas) och Aspose.Cells för Java‑biblioteket.

---

## Vad du behöver

| Krav | Orsak |
|------|-------|
| JDK 8 eller nyare | Krävs för att kompilera och köra Java‑koden. |
| Aspose.Cells for Java (senaste versionen) | Tillhandahåller `Workbook`, `Worksheet` och import‑API:er. |
| IDE eller byggverktyg (t.ex. Maven, Gradle) | Förenklar beroendehantering och körning. |
| Skrivbehörighet till en mapp för utdatafilen | Arbetsboken sparas som `ImportWithStyle.xlsx`. |

Lägg till Aspose.Cells‑beroendet i din `pom.xml` om du använder Maven:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## Steg 1: Förbered de anpassade objekten för import

Det första steget är att skapa en samling som representerar raderna du vill placera i Excel. I detta exempel använder vi en `List<Map<String,Object>>` där varje karta fungerar som en rad med kolumnnamn som nycklar.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Varför detta är viktigt:**  
`importCustomObjects` förväntar sig en array av objekt. Genom att använda en `Map` bevarar du kolumnnamnen, vilket gör att Aspose.Cells kan mappa dem automatiskt till celler. Detta tillvägagångssätt speglar en typisk `DataTable` i .NET eller ett `ResultSet` från JDBC, vilket gör koden återanvändbar i olika projekt.

---

## Steg 2: Definiera en rubrikstil att tillämpa vid import

En tydlig rubrikrad förbättrar läsbarheten. Aspose.Cells låter dig skapa ett `Style`‑objekt, sätta dess teckensnitt till fetstil och skicka det via en `ImportTableOptions`‑array.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Varför detta är viktigt:**  
Om du utelämnar stil‑arrayen visas rubriken i standardteckensnittet, vilket kanske inte framträder. Genom att förbereda stilen en gång undviker du repetitiva anrop för varje rad och håller importlogiken ren.

---

## Steg 3: Importera de anpassade objekten med stil‑arrayen

Nu kombinerar du data och stil och anropar `importCustomObjects`. Metoden placerar data med början i det övre‑vänstra hörnet (rad 0, kolumn 0) och tillämpar rubrikstilen automatiskt.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Varför detta är viktigt:**  
`importCustomObjects` analyserar varje karta, skapar kolumner baserat på nycklarna (`Name`, `Score`) och skriver värdena till rätt celler. `ImportTableOptions`‑objektet talar om för Aspose.Cells att använda `styleArray` för den första raden, så du får en fet rubrik utan extra kod.

---

## Steg 4: Spara arbetsboken och verifiera utdata

Slutligen skriver du arbetsboken till en fil. Den genererade Excel‑filen innehåller en stylad rubrikrad följd av dataraderna.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Förväntat resultat:**  

| **Namn** | **Poäng** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

Rubrikcellerna (`Namn`, `Poäng`) visas i fet stil, enligt den stil som definierades i steg 2.

## Vanliga variationer och kantfall

| Situation | Rekommenderad justering |
|-----------|--------------------------|
| **Olika kolumnordning** | Säkerställ att `Map`‑nycklarna infogas i önskad ordning, eller använd en anpassad POJO med annoterade fält och en `PropertyDescriptor`‑array. |
| **Stora datamängder (>10 000 rader)** | Öka `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` för att undvika `OutOfMemoryError`. |
| **Anpassade talformat** | Lägg till en andra `Style` i `styleArray` för dataraderna, t.ex. sätt `NumberFormat` till `"0"` för heltalsscore. |
| **Flera arbetsblad** | Anropa `importCustomObjects` på varje mål‑worksheet och justera start‑rad/kolumn efter behov. |
| **Locale‑specifik rubriktext** | Fyll i rubrikraden manuellt före import, applicera sedan stilen på hela området med `Cells.applyStyle`. |

---

## Pro‑tips för en robust Java‑export till Excel

* **Återanvänd den temporära arbetsboken** – Att skapa en ny `Workbook` för varje stil ger onödig overhead. Behåll en enda instans om du behöver flera stilar.  
* **Validera data före import** – Null‑värden i en karta blir tomma celler; du kan ersätta dem med standardvärden genom att förbehandla listan.  
* **Stäng resurser** – Även om Aspose.Cells hanterar minne internt, frigör du inhemska resurser omedelbart genom att explicit anropa `workbook.dispose()` efter sparning.  
* **Sätt `Workbook.setForceFullCalculation(true)`** om din arbetsbok innehåller formler som måste beräknas innan sparning.
