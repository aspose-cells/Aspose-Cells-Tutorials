# Hur man skapar Excel-arbetsbok i Java med JSON-data

Om du behöver **create Excel workbook java** utvecklare ofta möter utmaningen att ladda JSON-data i ett kalkylblad. Denna guide visar hur du **populate Excel from JSON**, inklusive hur du **convert JSON array excel** och **populate workbook from json** på ett rent, repeterbart sätt.

Att arbeta med JSON är vanligt när tjänster exponerar data via REST‑API:er, och Excel förblir det föredragna formatet för rapportering och analys. I slutet av den här handledningen har du ett körbart Java‑program som:

* skapar en ny Excel‑arbetsbok,
* läser en JSON‑array (eller någon JSON‑struktur) och skriver dess värden till celler,
* sparar filen till disk klar för vidare bearbetning.

Inga externa verktyg krävs utöver Aspose.Cells for Java‑biblioteket, som tillhandahåller `SmartMarkerProcessor` som används i exempel­koden.

## Förutsättningar

Innan du börjar, se till att du har:

| Prerequisite | Reason |
|--------------|--------|
| Java Development Kit (JDK) ≥ 8 | Krävs för att kompilera och köra exemplet |
| Maven or Gradle (optional) | Förenklar hantering av beroenden |
| Aspose.Cells for Java (v23.10 or later) | Tillhandahåller `Workbook` och `SmartMarkerProcessor`‑klasserna |
| Basic knowledge of JSON and Java I/O | Hjälper dig att förstå dataflödet |

Om du föredrar att inte använda ett byggverktyg kan du ladda ner Aspose.Cells‑JAR‑filen från [Aspose website](https://products.aspose.com/cells/java/) och lägga till den i ditt projekts classpath manuellt.

## Steg 1: Ställ in projektet och lägg till Aspose.Cells‑beroendet

### Maven‑användare

Lägg till följande beroende i din `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Gradle‑användare

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

Om du inte använder ett byggverktyg, placera den nedladdade JAR‑filen i `libs/`‑mappen och inkludera den på classpath när du kompilerar:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## Steg 2: Skapa en ny arbetsbok och konfigurera SmartMarker‑processorn

`SmartMarkerProcessor` förenklar mappning av JSON‑värden till Excel‑celler. Genom att anropa `setArrayAsSingle(true)` säger vi till processorn att behandla en hel JSON‑array som ett enda värde, vilket är användbart när du vill att varje element ska fylla sin egen cell i en rad.

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**Varför detta är viktigt:**  
Att skapa arbetsboken i förväg ger dig en ren canvas. Genom att konfigurera `setArrayAsSingle(true)` förhindras att processorn plattar till arrayen till en enda sträng (t.ex. `["A","B","C"]`) och du får istället kontroll över layouten manuellt.

## Steg 3: Definiera JSON‑data som du vill infoga

För den här handledningen använder vi en enkel JSON‑array, men samma metod fungerar med objekt, nästlade arrayer eller komplexa strukturer.

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**Tips:** Om din JSON kommer från en fil eller en REST‑endpoint, ersätt den bokstavliga strängen med en `String` som läses från källan, t.ex. `Files.readString(Paths.get("data.json"))`.

## Steg 4: Bearbeta arbetsboken med JSON‑data

Nu låter vi `SmartMarkerProcessor` mappa JSON‑arrayen på det första kalkylbladet. Standardbeteendet skriver varje element i på varandra följande celler med start i `A1`.

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

Bakom kulisserna parsar Aspose.Cells JSON‑en, skapar en temporär datatabell och skriver värdena till kalkylbladet. Eftersom vi har satt `ArrayAsSingle` till `true` placeras array‑elementen horisontellt över den första raden.

## Steg 5: Spara arbetsboken till en fil

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

När du kör programmet bör du se en fil med namnet **CreatedFromJson.xlsx** i din arbetskatalog. Att öppna den i Excel (eller någon kompatibel visare) visar:

| A | B | C |
|---|---|---|
| A | B | C | *(värdena visas i cellerna A1, B1, C1)*

### Förväntat resultat

```
Workbook saved to CreatedFromJson.xlsx
```

Och Excel‑bladet ser ut så här:

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## Steg 6: Hantera mer komplexa JSON‑strukturer (valfritt)

### 6.1 Fyll i en arbetsbok från ett JSON‑objekt

Om din JSON är ett objekt snarare än en array kan du fortfarande använda `SmartMarkerProcessor`. Till exempel:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

Processorn kommer att skapa namngivna områden (`title`, `month`, `values`) som du kan referera till i din Excel‑mall med Smart Markers som `&=title` och `&=values`.

### 6.2 Konvertera en nästlad JSON‑array till en vertikal lista

Ibland behöver du att arrayen fyller en kolumn istället för en rad. Ställ in startcellen manuellt innan bearbetning:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

Nu visas värdena **A**, **B**, **C** i cellerna A2, A3, A4 respektive.

## Vanliga fallgropar och hur du undviker dem

| Problem | Orsak | Lösning |
|---------|-------|---------|
| **Array skrivet som en enda sträng** | `setArrayAsSingle(false)` (standard) | Anropa `processor.setArrayAsSingle(true)` |
| **Fil ej hittad vid sparande** | Ogiltig sökväg eller saknade skrivbehörigheter | Använd en absolut sökväg eller säkerställ att katalogen finns |
| **JSON‑tolkningsfel** | Felaktig JSON‑sträng | Validera JSON med ett verktyg eller använd ett bibliotek som Jackson för att generera strängen |
| **Celler överskrivna oavsiktligt** | Bearbetar samma kalkylblad flera gånger utan att återställa startcellen | Anropa `processor.setStartCell("A1")` före varje `process`‑anrop |

## Pro‑tips: återanvänd arbetsboken som en mall

Istället för att börja från en tom arbetsbok varje gång kan du ladda en fördesignad mall som redan innehåller rubriker, formler eller formatering:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

Detta tillvägagångssätt kombinerar den visuella poleringen av en handgjord Excel‑fil med automatiseringen av **populate workbook from json**.
