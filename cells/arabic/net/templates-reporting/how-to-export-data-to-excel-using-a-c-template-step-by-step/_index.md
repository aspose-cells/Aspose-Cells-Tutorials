# كيفية تصدير البيانات إلى Excel باستخدام قالب C# – دليل خطوة‑بخطوة

إذا كنت بحاجة إلى **تصدير البيانات إلى Excel** من تطبيق .NET، يوضح هذا الدليل حلاً كاملاً يعمل من البداية إلى النهاية. من خلال تحميل قالب Excel يحتوي مسبقًا على علامات Smart Marker، يمكنك **أتمتة إنشاء Excel** وإنتاج **تقرير موظفين بصيغة Excel** مصقول دون كتابة أي شفرة خلية‑ب‑خلية.

ستتعرف على كيفية:

* تحميل قالب Excel (`تحميل قالب Excel`) الذي يحدد التخطيط.
* إمداد القالب بقائمة من كائنات الموظف.
* إنشاء المصنف النهائي وحفظه كـ `output.xlsx`.

جميع الشيفرات المطلوبة مضمَّنة، بحيث يمكنك نسخها ولصقها وتشغيلها فورًا.

## المتطلبات المسبقة

* .NET 6.0 أو أحدث (الشفرة تعمل أيضًا مع .NET Framework 4.7+).  
* حزمة NuGet **Aspose.Cells for .NET** – توفر `Workbook`، `SmartMarkerProcessor`، ودعم Smart Marker.  
* مجلد باسم `YOUR_DIRECTORY` يحتوي على `template.xlsx`. يجب أن يحتوي القالب على علامات Smart Marker مثل `&=EmployeeList.Name` في الخلايا التي تريد ظهور البيانات فيها.

> **نصيحة احترافية:** احتفظ بالقالب في نفس مجلد المشروع واضبط خاصية *Copy to Output Directory* إلى *Copy always* حتى يتم حل المسار بشكل صحيح أثناء التصحيح.

## الشيفرة المصدرية الكاملة

```csharp
using System;
using System.Collections.Generic;
using Aspose.Cells;

namespace ExcelExportDemo
{
    // Simple POCO that represents an employee record
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Step 1: Load the Excel template that contains Smart Marker tags
            string templatePath = @"YOUR_DIRECTORY\template.xlsx";
            Workbook wb = new Workbook(templatePath);

            // Step 2: Prepare a data source – a list of employee objects
            List<Employee> employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Step 3: Create a SmartMarkerProcessor instance
            SmartMarkerProcessor sp = new SmartMarkerProcessor();

            // Step 4: Apply the employee data to the workbook using the processor
            // The tag &amp;=EmployeeList.Name in the template will be replaced with each employee's name,
            // and &amp;=EmployeeList.Position will be replaced with the corresponding position.
            sp.Process(wb, employeeList);

            // Step 5: Save the populated workbook
            string outputPath = @"YOUR_DIRECTORY\output.xlsx";
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

### ما تقوم به الشيفرة

| الخطوة | لماذا يهم | السطر (السطر) الرئيسي |
|------|----------------|-------------|
| **تحميل قالب Excel** | إعادة استخدام تخطيط مُصمم مسبقًا يوفر الوقت ويضمن تنسيقًا موحدًا. | `Workbook wb = new Workbook(templatePath);` |
| **تحضير مصدر البيانات** | تعمل Smart Markers مع أي مجموعة `IEnumerable`؛ هنا نستخدم قائمة من `Employee`. | `List<Employee> employeeList = …` |
| **إنشاء المعالج** | `SmartMarkerProcessor` يحلل القالب، يجد العلامات، ويُدخل البيانات. | `SmartMarkerProcessor sp = new SmartMarkerProcessor();` |
| **معالجة البيانات** | يقوم المعالج باستبدال كل علامة Smart Marker بقيمة الخاصية المقابلة. | `sp.Process(wb, employeeList);` |
| **حفظ المصنف** | يمكن إرسال الملف النهائي إلى المستخدم، تخزينه على الخادم، أو إرفاقه برسالة بريد إلكتروني. | `wb.Save(outputPath);` |

النتيجة هي ملف **تقرير موظفين بصيغة Excel** حيث يحتوي كل صف على اسم الموظف وموقعه، تمامًا حيث وُضعت العلامات في القالب الأصلي.

## تحميل قالب Excel

عند `تحميل قالب Excel` باستخدام `new Workbook(path)`، تقوم Aspose.Cells بقراءة المصنف بالكامل—بما في ذلك الأنماط، الصيغ، وعلامات Smart Marker. هذا النهج مفضَّل على إنشاء مصنف من الصفر لأن:

* **التحكم في التصميم** – يمكن للمصممين تنسيق العناوين، إضافة شعارات الشركة، وتحديد عرض الأعمدة دون لمس الشيفرة.
* **الإصدار** – تحديث القالب لا يتطلب إعادة تجميع التطبيق.
* **التعريب** – يمكنك الاحتفاظ بملفات قوالب منفصلة للغات المختلفة.

إذا كنت تفضّل حلاً نقيًا في .NET بدون مكتبات طرف ثالث، يمكنك استخدام **ClosedXML** أو **EPPlus**، لكنهما يفتقران إلى دعم Smart Marker المدمج، مما يعني أنك ستحتاج إلى كتابة حلقات تنسخ البيانات خلية بخلية.

## أتمتة إنشاء Excel باستخدام Smart Markers

Smart Markers هي عناصر نائبة تشبه `&=Collection.Property`. عندما يعمل المعالج:

* يتكرر عبر المجموعة (`employeeList` في مثالنا).
* لكل عنصر، يكتب قيمة الخاصية في الخلية المقابلة.
* يوسّع الصفوف أو الأعمدة تلقائيًا حسب الحاجة.

هذه الآلية **تُؤتمت إنشاء Excel** وتُزيل الحاجة إلى منطق التكرار اليدوي. النمط نفسه يعمل مع أي شكل من أشكال البيانات—الطلبات، الفواتير، قوائم المخزون، إلخ.

### تنوعات شائعة

| التنوع | كيفية التنفيذ |
|-----------|------------------|
| **قوائم متعددة** | أضف قوائم إضافية (مثل `List<Department>`) وارجع إليها بعلامات مختلفة مثل `&=DepartmentList.Name`. |
| **قوائم متداخلة** | استخدم الصيغة النقطية: `&=EmployeeList.Projects.ProjectName` حيث `Projects` هي خاصية مجموعة داخل `Employee`. |
| **تنسيق شرطي** | ضع قاعدة تنسيق شرطي في القالب؛ سيحافظ المعالج عليها للصفوف المُولَّدة. |

## إنشاء تقرير موظفين بصيغة Excel

مصطلح **تقرير موظفين بصيغة Excel** يشير إلى حالة استخدام تجارية شائعة: يرغب المدير في قائمة قابلة للطباعة لأعضاء الفريق. من خلال تضمين علامات Smart Marker مباشرة في القالب، تحصل على:

* صف رأس يحتوي على خطوط غامقة ولون خلفية.
* أعمدة ذات حجم تلقائي بناءً على البيانات.
* صفوف إجمالية اختيارية (مثل عدد الموظفين) يمكنك حسابها باستخدام صيغ Excel القياسية.

إذا احتجت لإضافة صف إجمالي، ما عليك سوى وضع صيغة مثل `=COUNTA(A2:A100)` في القالب؛ لن يغيّرها المعالج.

## أفضل الممارسات لتوليد قالب Excel بـ C#

عند كتابة شفرة **توليد قالب Excel بـ C#**، احرص على اتباع الإرشادات التالية:

1. **فصل المسؤوليات** – احتفظ بتحميل القالب، تحضير البيانات، والمعالجة في طرق منفصلة. هذا يسهل اختبار الوحدات.
2. **التحقق من المدخلات** – تأكد من وجود ملف القالب وأن مجموعة البيانات ليست فارغة قبل استدعاء `Process`.
3. **تحرير الموارد** – رغم أن Aspose.Cells تدير الذاكرة، يمكنك وضع `Workbook` داخل كتلة `using` إذا كنت تتعامل مع ملفات كبيرة.
4. **معالجة الاستثناءات** – احرص على التقاط `Exception` حول `sp.Process` لتظهر المشكلات مثل عدم تطابق أسماء العلامات.

```csharp
static Workbook LoadTemplate(string path)
{
    if (!File.Exists(path))
        throw new FileNotFoundException($"Template not found: {path}");
    return new Workbook(path);
}
```

| John Doe  | Developer  |

جميع التنسيقات من `template.xlsx`—مثل لون خلفية العنوان، عرض الأعمدة، وأي صورة شعار—تبقى كما هي.

## استكشاف الأخطاء الشائعة وإصلاحها

| العَرَض | السبب المحتمل | الحل |
|---------|--------------|-----|
| لا تظهر بيانات بعد المعالجة | علامات Smart Marker مكتوبة بخطأ أو موضوعة في خلايا مدمجة. | تأكد من أن العلامات تتبع الصيغة الدقيقة `&=Collection.Property` ولا توجد داخل خلايا مدمجة. |
| ملف الإخراج فارغ أو معطوب | تم حفظ المصنف قبل اكتمال المعالجة. | تأكد من أن `sp.Process` يُنفَّذ **قبل** `wb.Save`. |
| قائمة الموظفين الكبيرة تبطئ عملية الإنشاء | النسخة المجانية من Aspose.Cells قد تكون لها حدود أداء. | ارتقِ إلى النسخة المرخصة أو عالج البيانات على دفعات. |
| مسار القالب غير صحيح | المسار النسبي يُحل إلى مجلد مختلف أثناء التشغيل. | استخدم `Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "template.xlsx")` أو اضبط خاصية `Copy to Output Directory` للملف. |

## ملخص المثال الكامل

فيما يلي البرنامج بالكامل في كتلة واحدة للنسخ السريع:

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Load the template
            string templatePath = Path.Combine("YOUR_DIRECTORY", "template.xlsx");
            Workbook wb = new Workbook(templatePath);

            // Prepare data
            var employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Process Smart Markers
            var sp = new SmartMarkerProcessor();
            sp.Process(wb, employeeList);

            // Save the result
            string outputPath = Path.Combine("YOUR_DIRECTORY", "output.xlsx");
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

تشغيل هذا البرنامج يُنشئ ملف **تقرير موظفين بصيغة Excel** يمكن إرساله بالبريد، طباعته، أو معالجته لاحقًا.
