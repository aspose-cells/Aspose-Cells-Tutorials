# كيفية تضمين الخطوط في HTML عند حفظ دفتر العمل

إذا كنت بحاجة إلى **how to embed fonts in HTML** أثناء تصدير جدول بيانات، فإن هذا الدليل يوضح لك حلاً كاملاً وجاهزًا للتنفيذ. سواءً كنت تبني بوابة تقارير أو عرض تحليلات على جانب العميل، فإن تضمين الخطوط يضمن أن HTML المُولَّد يبدو تمامًا مثل دفتر العمل الأصلي، بغض النظر عن الخطوط المثبتة لدى المشاهد.

سوف تتعلم أيضًا أفضل طريقة لـ **save workbook as HTML** باستخدام Aspose.Cells، وتطلع على المشكلات الشائعة، وتحصل على نصائح للتعامل مع دفاتر عمل كبيرة أو ملفات خطوط مخصصة. لا حاجة إلى أي وثائق خارجية—كل ما تحتاجه موجود في هذا الدليل.

## المتطلبات المسبقة

- .NET 6.0 أو أحدث (الكود يعمل أيضًا مع .NET Framework 4.7+)
- ترخيص صالح لـ Aspose.Cells for .NET (أو يمكنك استخدام وضع التقييم المجاني)
- معرفة أساسية بلغة C# وبيئة تطوير مثل Visual Studio 2022
- ملفات الخطوط TrueType (.ttf) أو OpenType (.otf) التي تريد تضمينها (يجب أن تكون متاحة للعملية الجارية)

## الخطوة 1: إعداد المشروع واستيراد Aspose.Cells

Create a new console application and add the Aspose.Cells NuGet package:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

ثم افتح **Program.cs** وأضف توجيهات `using` المطلوبة:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **نصيحة احترافية:** ضع خطوطك المخصصة في مجلد اسمه `fonts` داخل جذر المشروع. هذا يجعل الحل قابلًا للنقل ويسهل الإشارة إليه لاحقًا.

## الخطوة 2: إنشاء أو تحميل دفتر عمل

للتوضيح، سننشئ دفتر عمل بسيط يحتوي على بعض الخلايا ذات التنسيق:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **لماذا هذا مهم:** إذا تخطيت النمط المخصص، سيعود HTML المُصدَّر إلى خطوط المتصفح الافتراضية، مما يُبطل هدف **how to embed fonts in HTML**.

## الخطوة 3: تكوين `HtmlSaveOptions` لتضمين الخطوط

جوهر **how to embed fonts in HTML** يكمن في فئة `HtmlSaveOptions`. ضبط `EmbedFonts = true` يخبر Aspose.Cells بتضمين أي خطوط TrueType/OpenType مُشار إليها مباشرةً في HTML المُولَّد كعناوين URI مشفرة بـ Base64.

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### كيف يعمل التضمين

عند ضبط `EmbedFonts` إلى `true`، يقوم Aspose.Cells بمسح تعريفات الأنماط في دفتر العمل، ويحدد ملفات الخطوط المقابلة على النظام (أو في مجلد `fonts` الذي أضفته)، يقرأ بياناتها الثنائية، ويُدرج كتلة `<style>` مشابهة لـ:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

نظرًا لأن بيانات الخط مشفرة مباشرةً في HTML، فإن الصفحة تُظهر بشكل صحيح حتى على الأجهزة التي لا تتوفر فيها الخطوط المثبتة.

## الخطوة 4: حفظ دفتر العمل كـ HTML

الآن يمكنك **save workbook as HTML** باستخدام الخيارات المُكوَّنة. اختر دليلًا يمكن للتطبيق الكتابة فيه (مثال: `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

تشغيل البرنامج ينتج ملفًا واحدًا باسم `report.html`. افتحه في أي متصفح حديث وسترى عنوان “Quarterly Sales” مُظهرًا بخط **Pacifico**، حتى وإن لم يكن الخط مثبتًا على نظام التشغيل الخاص بك.

### النتيجة المتوقعة

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

خاصية `src:` تحتوي على سلسلة Base64 طويلة—هذه هي بيانات الخط المضمَّنة التي تمكّن **how to embed fonts in HTML**.

## الخطوة 5: التحقق من تضمين الخطوط واستكشاف الأخطاء

1. **افتح ملف HTML في Chrome أو Edge.** إذا ظهر الخط المخصص، فإن التضمين نجح.  
2. **افحص مصدر الصفحة.** ابحث عن قاعدة `@font-face` التي يولدها Aspose.Cells.  
3. **المشكلات الشائعة:**  
   - *ملف الخط مفقود:* تأكد من إمكانية الوصول إلى ملف الخط. يمكنك إضافة مجلد صراحةً إلى مسار البحث:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *حجم HTML كبير:* قد يؤدي تضمين العديد من الخطوط إلى زيادة حجم الملف. استخدم `ExportToSingleFile = false` للاحتفاظ بالخطوط كملفات `.ttf` منفصلة في مجلد الموارد.

   - *صيغة خط غير مدعومة:* Aspose.Cells يضمّن فقط خطوط TrueType (`.ttf`) و OpenType (`.otf`). قم بتحويل الصيغ الأخرى قبل التضمين.

## مثال كامل يعمل

فيما يلي البرنامج الكامل الذي يمكنك نسخه، لصقه، وتشغيله دون تعديل (باستثناء سطر الترخيص الاختياري).

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

تشغيل هذا البرنامج ينشئ `output/report.html`. افتح الملف، وسترى خط **Pacifico** يُعرض بشكل صحيح—مما يُظهر **how to embed fonts in HTML** أثناء **save workbook as HTML**.

## الأسئلة المتكررة

| السؤال | الجواب |
|----------|--------|
| *هل يمكنني تضمين خطوط محددة فقط؟* | نعم. اضبط `htmlOpt.EmbedAllFonts = false` (متاح في الإصدارات الأحدث) واستخدم `htmlOpt.FontsToEmbed` لتحديد أسماء الخطوط المطلوبة. |
| *ماذا لو احتجت لتضمين خطوط لعدة أوراق عمل؟* | اضبط `ExportActiveWorksheetOnly = false` ليتم تصدير جميع أوراق العمل، وسيقوم Aspose.Cells بتضمين الخطوط المستخدمة عبر دفتر العمل بأكمله. |
| *هل ستعمل الخطوط المضمَّنة على المتصفحات المحمولة؟* | متصفحات الهواتف الحديثة تدعم الخطوط المشفرة بـ Base64، لذا تُعرض الخطوط المضمَّنة بشكل صحيح طالما أن صيغة الخط مدعومة (TTF أو OTF). |
| *ما هو الحد الأقصى لحجم ملف HTML؟* | تضمين خط TrueType بحجم 200 KB يضيف تقريبًا نفس الحجم إلى ملف HTML (Base64 يضيف حوالي 33 % زيادة). إذا كان هناك العديد من الخطوط، فكر في التصدير إلى مجلد (`ExportToSingleFile = false`) للحفاظ على خفة HTML. |
