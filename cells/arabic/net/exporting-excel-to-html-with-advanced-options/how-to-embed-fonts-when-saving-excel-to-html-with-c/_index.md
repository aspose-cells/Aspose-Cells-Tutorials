# كيفية تضمين الخطوط عند حفظ Excel إلى HTML باستخدام C#

تعد طريقة تضمين الخطوط عند حفظ مصنف Excel إلى HTML مطلبًا شائعًا للحفاظ على المظهر الدقيق لجداول البيانات عبر المتصفحات. إذا كنت بحاجة إلى تصدير Excel إلى HTML مع الحفاظ على الخطوط الأصلية، فإن هذا الدليل يوضح لك حلًا كاملًا وجاهزًا للتنفيذ.

سوف تتعلم كيفية **تصدير Excel إلى HTML**، **تحويل Excel إلى HTML** مع خطوط مضمّنة، وتجنب مشكلة “الخط المفقود” التي تُفسد التخطيط على أجهزة العملاء. لا تحتاج إلى أدوات خارجية—فقط مكتبة Aspose.Cells وبعض أسطر C#.

## المتطلبات المسبقة

قبل أن تبدأ، تأكد من وجود ما يلي:

* .NET 6.0 (أو أحدث) مثبت.
* نسخة مرخصة من **Aspose.Cells for .NET** – النسخة التجريبية المجانية تعمل للاختبار.
* بيئة تطوير متكاملة مثل Visual Studio 2022 أو VS Code.

إذا كان لديك هذه المتطلبات، يمكنك القفز مباشرة إلى الكود.

## الخطوة 1: إنشاء مصنف وإضافة بيانات تجريبية

أولاً نقوم بإنشاء مصنف صغير لتتمكن من رؤية تأثير الخطوط المضمّنة. الكود أدناه ينشئ ورقة عمل، يكتب بضع خلايا، ويطبق خطًا مخصصًا.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### لماذا نضيف خطًا مخصصًا

تضمين الخطوط مهم فقط عندما يستخدم المصنف خطوطًا قد لا تكون موجودة على جهاز العميل. من خلال تعيين **Arial** (أو أي خط آخر) صراحةً، يمكننا التحقق من أن مخرجات HTML تحتوي فعلاً على بيانات الخط.

## الخطوة 2: تكوين خيارات حفظ HTML لتضمين الخطوط

توفر Aspose.Cells الفئة `HtmlSaveOptions`. ضبط `EmbedFonts = true` يخبر المكتبة بتضمين ملفات الخط المطلوبة مباشرةً في HTML المُولد كعناوين URI مشفّرة بـ Base64.

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### ما الذي يفعله “تضمين الخطوط في HTML” فعليًا

عند تعيين `EmbedFonts` إلى true، تقوم Aspose.Cells باستخراج ملفات الخط من النظام (أو من مجموعة الخطوط المضمّنة في المصنف) وتحويلها إلى سلاسل **Base64**. تُوضع تلك السلاسل داخل كتلة `<style>` باستخدام `@font-face`. يمكن فتح HTML الناتج على أي جهاز دون الحاجة إلى تثبيت الخط الأصلي.

## الخطوة 3: حفظ المصنف كـ HTML مع خطوط مضمّنة

الآن نكتب المصنف إلى القرص. سيحتوي الملف على بيانات الخط، لذا فإن فتحه في أي متصفح حديث يعرض نفس الطباعة تمامًا كما في ملف Excel الأصلي.

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### النتيجة المتوقعة

* `embedded.html` موجود في مجلد `output`.
* فتح الملف في Chrome أو Edge أو Firefox يعرض ورقة العمل بنص **Arial**، حتى إذا كان الجهاز لا يحتوي على Arial.
* فحص مصدر HTML يكشف عن كتلة `<style>` تحتوي على قاعدة `@font-face` مع تصريح طويل `src: url(data:font/ttf;base64,…)` – هذا هو الخط المضمّن.

## الخطوة 4: التحقق من عمل HTML على جهاز آخر (اختياري)

للتأكد تمامًا من نجاح التضمين:

1. انسخ `output/embedded.html` إلى جهاز كمبيوتر مختلف (أو آلة افتراضية) لا يحتوي على الخط المخصص مثبتًا.
2. افتح الملف في المتصفح.
3. يجب أن يتطابق التخطيط والطباعة مع عرض Excel الأصلي.

إذا عاد الخط إلى خط عام، فتأكد من أن ملف الخط قابل للوصول على جهاز البناء وأن لديك إذن القراءة.

## الأسئلة الشائعة والحالات الخاصة

### هل يزيد التضمين من حجم الملف؟

نعم. يمكن أن يضيف تضمين خط TrueType أو OpenType **عشرات الكيلوبايت** إلى ملف HTML. بالنسبة للمصنفات الكبيرة التي تحتوي على خطوط فريدة متعددة، ضع في اعتبارك:

* تقليل الخط (فقط الأحرف المستخدمة) – Aspose.Cells يقوم بذلك تلقائيًا لمعظم الخطوط الشائعة.
* استخدام `ExportEmbeddedImages = false` إذا لم تكن بحاجة إلى تضمين الصور.

### ماذا لو أردت تضمين خطوط محددة فقط؟

`HtmlSaveOptions` لا توفر قائمة بيضاء مباشرة، لكن يمكنك التحكم في الخطوط التي تظهر عن طريق **تقييد الخطوط المستخدمة في المصنف** قبل استدعاء `Save`. احذف تعيينات الخط غير الضرورية أو استبدلها بخطوط ويب آمنة قياسية.

### هل يمكنني تضمين الخطوط عند التحويل إلى صيغ أخرى (مثل PDF)؟

خاصية `EmbedFonts` نفسها موجودة في `PdfSaveOptions`. الفكرة هي نفسها: يتم تضمين بيانات الخط بحيث يتم عرض PDF بشكل صحيح على أي عارض.

## مثال كامل قابل للتنفيذ

فيما يلي البرنامج الكامل الذي يمكنك نسخه ولصقه في مشروع وحدة تحكم جديد.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

تشغيل البرنامج ينتج **ملف HTML يحتوي على خط Arial المضمّن**، مما يضمن الحفاظ على المظهر البصري أينما تم فتح الملف.

## الخلاصة

أنت الآن تعرف **كيفية تضمين الخطوط عند حفظ Excel إلى HTML** باستخدام C#. من خلال ضبط `HtmlSaveOptions.EmbedFonts = true`، يمكنك بثقة **تصدير Excel إلى HTML** و**تحويل Excel إلى HTML** دون القلق بشأن الخطوط المفقودة على جانب العميل. هذه التقنية أساسية للتقارير المستندة إلى الويب، ولوحات التحكم الصديقة للبريد الإلكتروني، أو أي سيناريو تتشارك فيه محتوى مستخرج من Excel كـ HTML.

### ما التالي؟

* **تخصيص CSS** الذي يولده Aspose.Cells ليتوافق مع دليل نمط موقعك.  
* **تضمين الصور** بشكل انتقائي عن طريق تبديل `ExportEmbeddedImages`.  
* **استكشاف صيغ تصدير أخرى** مثل PDF أو SVG مع الاستمرار في تضمين الخطوط.  

لا تتردد في تجربة خطوط مختلفة، أوراق عمل أكبر، أو مصنفات متعددة الأوراق. علم `EmbedFonts` يعمل عبر جميع صيغ الإخراج المدعومة، مما يمنحك تحكمًا ثابتًا في تضمين الخطوط أينما احتجت. برمجة سعيدة!
