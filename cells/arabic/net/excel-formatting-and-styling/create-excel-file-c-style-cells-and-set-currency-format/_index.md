# إنشاء ملف إكسل C# – تنسيق الخلايا وتعيين صيغة العملة

إذا كنت بحاجة إلى **إنشاء ملف إكسل C#** يبدو احترافيًا، فإن هذا الدليل يوضح لك بالضبط كيفية تنسيق خلايا إكسل وتعيين صيغة عملة لعمود. ستشاهد مثالًا كاملاً من البداية إلى النهاية يستورد `DataTable`، يضيف رأسًا غامقًا، ويضبط صيغة رقمية `$#,##0.00` لعمود السعر.

يغطي الدرس كل ما تحتاجه: حزم NuGet المطلوبة، الكود الكامل، شرح سبب أهمية كل جزء، ونصائح للتعامل مع الحالات الخاصة مثل الصفوف الفارغة أو اللغات المختلفة. بنهاية الدرس ستكون قادرًا على توليد ملف `.xlsx` بعمود سعر منسق بشكل جميل في بضع أسطر من C#.

## المتطلبات المسبقة

- .NET 6.0 أو أحدث (الكود يعمل أيضًا مع .NET Framework 4.6+)
- Visual Studio 2022 أو أي محرر C# تفضله
- مكتبة **Aspose.Cells for .NET** أو **GemBox.Spreadsheet** (كلاهما يدعم `ImportTableOptions`). المثال أدناه يستخدم **Aspose.Cells** لأنه يوفر خاصية `StyleArray` بسيطة.
- معرفة أساسية بمجموعات C# و`DataTable`

> **نصيحة احترافية:** إذا كنت تفضل بديلًا مجانيًا، استبدل `Aspose.Cells` بـ `GemBox.Spreadsheet`. واجهة برمجة التطبيقات لاستيراد `DataTable` مع الأنماط شبه متطابقة؛ فقط غيّر مساحة الاسم واسم حزمة NuGet.

## الخطوة 1: تثبيت مكتبة إكسل

افتح مدير حزم NuGet وقم بتثبيت المكتبة:

```bash
dotnet add package Aspose.Cells
```

> **لماذا هذه الخطوة؟** المكتبة توفر الفئات `Workbook`، `Worksheet`، `Style`، و`ImportTableOptions` المستخدمة لاحقًا. بدونها سيتعين عليك كتابة صيغة Office Open XML يدويًا، وهو أمر عرضة للأخطاء.

## الخطوة 2: إنشاء DataTable ببيانات تجريبية

`DataTable` طريقة مريحة لحفظ البيانات الجدولية قبل تصديرها إلى إكسل. في هذا المثال لدينا عمودان: *Product* و*Price*.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **شرح:**  
> - `Columns.Add("Price", typeof(double))` يُخبر الجدول بمعالجة قيم السعر كأرقام، وهو ضروري لتنسيق الأرقام لاحقًا.  
> - إضافة بعض الصفوف يمنحنا بيانات للتحقق من خطوة **تنسيق عمود العملة**.

## الخطوة 3: تعريف الأنماط التي تريد تطبيقها

سننشئ مصفوفة من كائنات `Style` تتطابق مع ترتيب الأعمدة. العنصر الأول ينسق صف الرأس، العنصر الثاني يترك عمود *Product* دون تعديل، والعنصر الثالث يطبق صيغة رقمية للعملة.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### لماذا نستخدم **مصفوفة الأنماط**؟

`ImportTableOptions.StyleArray` يربط كل عمود بـ `Style`. هذه هي الطريقة الأكثر كفاءة لإضافة **صيغة رقمية** و**تنسيق خلايا إكسل** في عملية استيراد واحدة، متجنبًا المرور الثاني على ورقة العمل.

## الخطوة 4: ضبط خيارات الاستيراد

الآن نربط مصفوفة الأنماط بعملية الاستيراد. كائن `ImportTableOptions` يتيح لك أيضًا التحكم فيما إذا كان الصف الأول يُعامل كرأس.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **ملاحظة:** `IsFieldNameShown` يساوي `true` افتراضيًا، لكن تعيينه صراحةً يجعل النية واضحة للقراء المستقبليين.

## الخطوة 5: إنشاء دفتر عمل، استيراد الجدول، وحفظه

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### النتيجة المتوقعة

عند فتح `DataTableWithStyles.xlsx`:

- الصف الأول (الرأس) **غامق**.
- عمود *Price* يعرض القيم كـ **$1.20**، **$3.50**، **$0.75**.
- عمود *Product* يحتفظ بالخط الافتراضي.

لقد نجحت في **إنشاء ملف إكسل C#** بعمود عملة منسق ورؤوس خلايا مُنسقة.

## الخطوة 6: التعامل مع المتغيرات الشائعة والحالات الخاصة

### أ. لغة مختلفة أو رمز عملة مخصص

إذا كنت تحتاج إلى يورو أو عملة أخرى، استبدل الصيغة المدمجة `164` بسلسلة صيغة مخصصة:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### ب. إضافة أعمدة أخرى لاحقًا

عند إضافة أعمدة إضافية، قم بتمديد مصفوفة `columnStyles` وفقًا لذلك. استخدم `null` للأعمدة التي يجب أن تحتفظ بالنمط الافتراضي.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### ج. DataTable فارغ

إذا كان `DataTable` لا يحتوي على صفوف، لا يزال Aspose.Cells ينشئ صف الرأس. ومع ذلك، سيحتوي دفتر العمل على صف واحد فقط. لتجنب ملف فارغ، تحقق من عدد الصفوف قبل الاستيراد:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### د. استخدام `GemBox.Spreadsheet` بدلاً من Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

المنطق يبقى هو نفسه، مما يُظهر أن الدرس **تنسيق عمود العملة** غير مرتبط بالمكتبة الأساسية.

## الخطوة 7: التحقق من الملف برمجيًا (اختياري)

يمكنك فتح دفتر العمل المُولد والتحقق من تطبيق صيغة الرقم بشكل صحيح—مفيد لاختبارات الوحدة.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```

## الخلاصة

أظهر هذا الدرس كيفية **إنشاء ملف إكسل C#**، **تنسيق خلايا إكسل**، وتعيين **صيغة عملة** لعمود محدد باستخدام مثال مختصر من البداية إلى النهاية. تعلمت:

1. كيفية بناء `DataTable` ببيانات رقمية.  
2. كيفية تعريف **مصفوفة الأنماط** التي تجعل الرأس غامقًا وتضيف **صيغة رقمية** لعمود السعر.  
3. كيفية استيراد الجدول باستخدام `ImportTableOptions` وحفظ دفتر العمل.  
4. كيفية تعديل الحل للغات مختلفة، أعمدة إضافية، بيانات فارغة، ومكتبات بديلة.

من هنا يمكنك استكشاف تنسيقات أكثر تقدمًا—التنسيق الشرطي، حدود الخلايا، أو تعديل عرض الأعمدة تلقائيًا. جرّب كائن `Style` لتغيير الخطوط، ألوان الخلفية، أو المحاذاة، وستحصل على حل تصدير إكسل كامل المميزات لأي تطبيق C#.

**الخطوات التالية:**  

- تعلم كيفية **تنسيق عمود العملة** بناءً على لغة المستخدم (`CultureInfo`).  
- إضافة **تحقق من البيانات** (قوائم منسدلة) إلى ورقة العمل.  
- استخدام **جداول إكسل** (`ListObject`) لتحسين الفلترة والفرز في الملف المُولد.  

نتمنى لك برمجة سعيدة، واستمتع بإنشاء تقارير إكسل مصقولة مباشرة من C#!
