# كيفية إنشاء مصنف Excel C# مع تنسيق مخصص وحفظه كملف XLSX

إذا كنت بحاجة إلى **إنشاء مصنف Excel C#** يستورد البيانات، ويطبق تنسيق رقم مخصص، ويغير لون خط الخلية، فإن هذا الدرس يوضح لك بالضبط كيفية القيام بذلك. ستحصل على مثال جاهز للتنفيذ ينتج ملف `StyleArrayImport.xlsx` منسق خلال ثوانٍ.

العمل مع Excel من خلال C# غالبًا ما يتضمن خطوات يدوية متكررة—تعريف التنسيقات، تطبيق الألوان، وتذكر حفظ الملف بشكل صحيح. بنهاية هذا الدليل ستتمكن من أتمتة جميع هذه المهام، لتتمكن من التركيز على البيانات بدلاً من واجهة المستخدم.

سوف تتعلم كيفية:

* استيراد `DataTable` إلى ورقة عمل،
* استخدام `StyleArray` **لتطبيق تنسيق رقم مخصص** و**تغيير لون خط الخلية**،
* **حفظ المصنف كملف XLSX** باستدعاء طريقة واحدة،
* والتحقق من أن **تنسيق البيانات المستوردة في Excel** يظهر تمامًا كما هو مقصود.

المتطلب الوحيد هو وجود إشارة إلى مكتبة **Aspose.Cells for .NET** (أو أي API متوافق يوفر الفئات `Workbook` و `Worksheet` و `StyleArray`). يستهدف الكود .NET 6+، لكن الإصدارات الأقدم تعمل مع تعديلات بسيطة.

## الخطوة 1: إعداد عينة `DataTable`

أولاً، أنشئ `DataTable` تحاكي البيانات التي عادةً ما تستخرجها من قاعدة بيانات أو مصدر آخر. يتضمن الجدول عمود **Name** (نص) وعمود **Amount** (رقم عشري) سنقوم بتنسيقه لاحقًا.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**لماذا هذا مهم:** استخدام `DataTable` يتيح لك إبقاء منطق الاستيراد مستقلاً عن مصدر البيانات، وهو نمط شائع عند إنشاء تقارير من قواعد بيانات أو ملفات CSV أو APIs.

## الخطوة 2: تعريف `StyleArray` **لتطبيق تنسيق رقم مخصص** و**تغيير لون خط الخلية**

`StyleArray` يتيح لك تجميع تعليمات التنسيق التي سيتم تطبيقها على كل خلية مستوردة من `DataTable`. في هذا المثال نقوم بـ:

* ضبط `Number` إلى `#,##0.00` – تنسيق محاسبي شائع مع فواصل الآلاف،
* ضبط `FontColor` إلى `Color.Blue` – لجعل الأرقام بارزة باللون الأزرق.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**لماذا نستخدم `StyleArray`؟** تطبيق النمط أثناء الاستيراد يجنب الحاجة إلى تمريرة ثانية على ورقة العمل، مما يحسن الأداء لمجموعات البيانات الكبيرة.

---

## الخطوة 3: **إنشاء مصنف Excel C#** – إنشاء كائن Workbook والحصول على أول Worksheet

الآن ننشئ مصنفًا فارغًا ونحصل على مرجع إلى أول ورقة عمل (المؤشر 0). تصبح هذه الورقة هي الوجهة لبياناتنا المستوردة.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**شرح:** `Workbook` يمثل ملف Excel بالكامل، بينما `Worksheet` يمثل تبويبًا واحدًا. يحتوي المصنف الافتراضي على ورقة واحدة، وهو كافٍ لمعظم التقارير البسيطة.

---

## الخطوة 4: استيراد `DataTable` باستخدام **StyleArray** **لتنسيق البيانات المستوردة في Excel**

طريقة `ImportDataTable` تنسخ صفوف وأعمدة الجدول إلى ورقة العمل، بدءًا من الخلية `A1` (الصف 0، العمود 0). الوسيط `true` يُخبر الطريقة بتضمين رؤوس الأعمدة. لأننا نمرر `styleArray`، كل خلية مستوردة تحصل على تنسيق الرقم المخصص ولون الخط.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**ما يحدث خلف الكواليس:** Aspose.Cells يتنقل عبر كل صف، يكتب القيمة، ثم يطبق النمط المحدد في `styleArray`. تظهر الأرقام بفواصل وعشرتيْن، والنص يُعرض باللون الأزرق.

## الخطوة 5: **حفظ المصنف كملف XLSX** – كتابة الملف إلى القرص

أخيرًا، احفظ المصنف إلى ملف `.xlsx`. يمكنك تغيير المسار إلى أي دليل قابل للكتابة على جهازك.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**التحقق من النتيجة:** افتح الملف المُنشأ في Excel. يجب أن ترى الثلاث صفوف من البيانات، وعمود **Amount** مُنسق بفواصل، وعشرتيْن، ومُظهر بالخط الأزرق. هذا يؤكد نجاح خطوة **تنسيق البيانات المستوردة في Excel**.

## مثال كامل يعمل

انسخ الكتلة الكاملة أدناه إلى مشروع console جديد وشغّله. لا تحتاج إلى أي كود إضافي.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**الناتج المتوقع في وحدة التحكم:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

افتح الملف وتحقق من أن عمود **Amount** يظهر قيمًا مثل `1,234.56` بالخط الأزرق.

## أسئلة شائعة وحالات خاصة

| السؤال | الجواب |
|--------|--------|
| *هل يمكنني تطبيق تنسيقات مختلفة على أعمدة فردية؟* | نعم. بعد الاستيراد، احصل على كائن `Style` للعمود (`worksheet.Cells.Columns[1].Style`) واضبط `Number` أو `FontColor` مختلفًا. |
| *ماذا لو احتجت لتنسيق تواريخ بدلاً من أرقام؟* | اضبط `styleArray.Number = "mm-dd-yyyy"` ويمكنك أيضًا ضبط `styleArray.FontColor` لخلايا التاريخ. |
| *هل الخط الأزرق واضح على سمات Excel الداكنة؟* | قد يكون اللون الأزرق صعب القراءة على الخلفيات الداكنة. استخدم درجة أفتح (`Color.LightBlue`) أو لونًا متباينًا (`Color.Black`). |
| *كيف يمكنني استيراد `DataTable` كبير جدًا (مئات الآلاف من الصفوف)؟* | استخدم `ImportDataTable` مع نسخة التحميل `ImportDataTableOptions` لتدفق البيانات، أو قسّم الاستيراد إلى عدة أوراق عمل للبقاء ضمن حد الصفوف في Excel (1,048,576 صف). |
| *هل يمكنني التصدير إلى CSV بدلاً من XLSX؟* | استبدل `SaveFormat.Xlsx` بـ `SaveFormat.Csv`. لاحظ أن معلومات التنسيق (تنسيق الرقم، لون الخط) تُفقد في CSV لأنه تنسيق نصي بسيط. |

## نصائح للاستخدام في بيئة الإنتاج

* **نصيحة احترافية:** خزن كائن `Style` في الذاكرة إذا كنت بحاجة لتطبيق نفس التنسيق على عدة أوراق عمل؛ إنشاء `StyleArray` جديد لكل استيراد يضيف عبئًا إضافيًا.
* **احذر اختلافات الثقافة:** نمط `Number` `#,##0.00` يتبع الثقافة الثابتة. إذا كنت تحتاج إلى فواصل خاصة بالمنطقة، استخدم `NumberFormatInfo` أو دع Excel يتعامل مع ذلك بناءً على إعدادات المستخدم الإقليمية.
* **معالجة الأخطاء:** ضع استدعاء `Save` داخل كتلة `try‑catch` للتعامل مع استثناءات الإدخال/الإخراج (مثل عدم كفاية الصلاحيات أو الملفات المقفلة).
