# كيفية تصدير جداول المحور كصور باستخدام Aspose.Cells في C#

إذا كنت بحاجة إلى **how to export pivot** البيانات إلى صورة محمولة، فإن Aspose.Cells يجعل العملية بسيطة. يوضح هذا الدليل بالضبط كيفية تصدير جداول المحور كملفات PNG، بحيث يمكنك تضمينها في التقارير أو رسائل البريد الإلكتروني أو الوثائق دون الحاجة إلى Excel على الجهاز المستهدف.

تصدير جدول محوري كصورة يزيل مشكلات التنسيق الخاصة بالإصدارات ويسمح لأصحاب المصلحة غير التقنيين برؤية التحليل فورًا. سنغطي كل شيء من إعداد المشروع إلى تصيير **export pivot table image** النهائي، وسنشرح أيضًا كيفية **save pivot as image** لإعادة الاستخدام في المستقبل.

## كيفية تصدير جداول المحور كصور باستخدام Aspose.Cells

فيما يلي المثال الكامل القابل للتنفيذ الذي يحمل مصنفًا، ويُحدث جدول المحور، ويُكوّن خيارات الصورة، ويكتب ملف الإخراج. يتضمن كل خطوة مبررًا قصيرًا لتفهم *لماذا* كُتبت الشيفرة بهذه الطريقة، وليس فقط *ماذا* تفعل.

### 1. إعداد بيئة Aspose.Cells

1. تثبيت حزمة NuGet:

   ```bash
   dotnet add package Aspose.Cells
   ```

2. إضافة توجيهات `using` المطلوبة في أعلى ملف C# الخاص بك:

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **نصيحة احترافية:** استهدف .NET 6 أو أحدث للاستفادة من أحدث تحسينات الأداء في Aspose.Cells.

### 2. تحميل المصنف وتحديد موقع جدول المحور

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*لماذا هذا مهم:* فئة `Workbook` تحلل ملف XLSX وتمنحك الوصول إلى جميع أوراق العمل. اختيار ورقة العمل الصحيحة أمر أساسي لأن المصنف قد يحتوي على جداول محورية متعددة.

### 3. تحديث جدول المحور لالتقاط أحدث بيانات المصدر

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

يضمن التحديث أن أي تغييرات تم إجراؤها على النطاق المصدر بعد حفظ الملف تُعكس في الصورة المُصدَّرة. قد يؤدي تخطي هذه الخطوة إلى صور قديمة أو غير دقيقة.

### 4. تكوين خيارات تصدير الصورة (export pivot table image)

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

كائن `ImageOrPrintOptions` يتيح لك التحكم في الصيغة، الدقة، وتفاصيل التصيير الأخرى. PNG هو الخيار الأكثر شيوعًا للرسومات الحادة والمتوافقة مع الويب، لكن يمكنك التحويل إلى `ImageFormat.Jpeg` إذا كان حجم الملف يمثل قلقًا.

### 5. تصيير و **save pivot as image**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

`RenderToImage` يقوم بالعمل الشاق: يرسم جدول المحور تمامًا كما يظهر في Excel ويكتب بيانات PNG الثنائية إلى القرص. تُعيد الطريقة `void`، لذا يمكنك الافتراض بأمان أن الملف موجود بعد إكمال الاستدعاء دون الحاجة إلى فحوصات إضافية.

### 6. الاختلافات الشائعة وحالات الحافة

| السيناريو | التعديل |
|----------|------------|
| **جداول محورية كبيرة** (العديد من الصفوف/الأعمدة) | زيادة `HorizontalResolution` و `VerticalResolution` إلى 300 dpi للحصول على مخرجات أوضح. |
| **تنسيق مخصص** (ألوان الخلفية، الخطوط) | تأكد من تحميل تعريفات الأنماط في المصنف قبل استدعاء `Refresh()`. |
| **جداول محورية متعددة** في ورقة واحدة | التكرار عبر `worksheet.PivotTables` واستدعاء `RenderToImage` لكل منها، باستخدام أسماء ملفات مميزة. |
| **تصدير إلى JPEG** بدلاً من PNG | تغيير `ImageFormat = ImageFormat.Jpeg` واختيارياً ضبط `Quality` على كائن `JpegSaveOptions`. |

تتيح لك هذه الاختلافات **export pivot table image** بالتنسيق الدقيق الذي يتوقعه نظامك اللاحق.

## الشيفرة الكاملة للنسخ السريع واللصق

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

تشغيل البرنامج ينتج ملف PNG المعروض أعلاه، مكتملاً سير عمل **save pivot as image** في أقل من دقيقة.
