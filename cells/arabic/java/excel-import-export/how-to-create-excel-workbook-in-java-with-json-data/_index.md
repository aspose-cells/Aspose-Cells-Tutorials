# كيفية إنشاء مصنف Excel في Java باستخدام بيانات JSON

إذا كنت بحاجة إلى **create Excel workbook java** غالبًا ما يواجه المطورون تحدي تحميل بيانات JSON إلى جدول بيانات. يوضح هذا الدليل كيفية **populate Excel from JSON**، بما في ذلك كيفية **convert JSON array excel** و **populate workbook from json** بطريقة نظيفة وقابلة للتكرار.

التعامل مع JSON شائع عندما تقوم الخدمات بتوفير البيانات عبر REST APIs، ولا يزال Excel هو الصيغة المفضلة للتقارير والتحليل. بنهاية هذا الدليل ستحصل على برنامج Java قابل للتنفيذ يقوم بـ:

* إنشاء مصنف Excel جديد،
* قراءة مصفوفة JSON (أو أي بنية JSON) وكتابة قيمها في الخلايا،
* حفظ الملف على القرص جاهزًا للمعالجة اللاحقة.

لا توجد أدوات خارجية مطلوبة بخلاف مكتبة Aspose.Cells for Java، التي توفر `SmartMarkerProcessor` المستخدم في مثال الشيفرة.

## المتطلبات المسبقة

| المتطلب | السبب |
|--------------|--------|
| Java Development Kit (JDK) ≥ 8 | مطلوب لتجميع وتشغيل المثال |
| Maven or Gradle (optional) | يبسط إدارة الاعتمادات |
| Aspose.Cells for Java (v23.10 or later) | يوفر فئات `Workbook` و `SmartMarkerProcessor` |
| Basic knowledge of JSON and Java I/O | يساعدك على فهم تدفق البيانات |

إذا كنت تفضل عدم استخدام أداة بناء، يمكنك تنزيل ملف JAR الخاص بـ Aspose.Cells من [موقع Aspose](https://products.aspose.com/cells/java/) وإضافته إلى مسار الفئة (classpath) لمشروعك يدويًا.

## الخطوة 1: إعداد المشروع وإضافة اعتماد Aspose.Cells

### مستخدمي Maven

أضف الاعتماد التالي إلى ملف `pom.xml` الخاص بك:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### مستخدمي Gradle

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

إذا لم تكن تستخدم أداة بناء، ضع ملف JAR الذي تم تنزيله في المجلد `libs/` وأدرجه في مسار الفئة عند التجميع:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## الخطوة 2: إنشاء مصنف جديد وتكوين معالج SmartMarker

`SmartMarkerProcessor` يبسط ربط قيم JSON بخلايا Excel. من خلال استدعاء `setArrayAsSingle(true)` نخبر المعالج بأن يتعامل مع مصفوفة JSON كاملة كقيمة واحدة، وهو مفيد عندما تريد أن يشغل كل عنصر خلية خاصة به في صف.

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**لماذا هذا مهم:**  
إنشاء المصنف مسبقًا يمنحك لوحة نظيفة. ضبط `setArrayAsSingle(true)` يمنع المعالج من تحويل المصفوفة إلى سلسلة واحدة (مثال: `["A","B","C"]`) ويسمح لك بالتحكم في التخطيط يدويًا.

## الخطوة 3: تعريف بيانات JSON التي تريد إدراجها

في هذا الدليل نستخدم مصفوفة JSON بسيطة، لكن نفس النهج يعمل مع الكائنات، المصفوفات المتداخلة، أو الهياكل المعقدة.

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**نصيحة:** إذا كان JSON الخاص بك يأتي من ملف أو نقطة نهاية REST، استبدل السلسلة الحرفية بـ `String` تُقرأ من المصدر، مثلًا `Files.readString(Paths.get("data.json"))`.

## الخطوة 4: معالجة المصنف ببيانات JSON

الآن نسمح لـ `SmartMarkerProcessor` بربط مصفوفة JSON بالورقة الأولى. السلوك الافتراضي يكتب كل عنصر في خلايا متتالية بدءًا من `A1`.

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

خلف الكواليس، تقوم Aspose.Cells بتحليل JSON، وإنشاء جدول بيانات مؤقت، وكتابة القيم في الورقة. لأننا ضبطنا `ArrayAsSingle` إلى `true`، يتم وضع عناصر المصفوفة أفقياً عبر الصف الأول.

## الخطوة 5: حفظ المصنف إلى ملف

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

عند تشغيل البرنامج، يجب أن ترى ملفًا باسم **CreatedFromJson.xlsx** في دليل العمل الخاص بك. فتحه باستخدام Excel (أو أي عارض متوافق) سيظهر:

| A | B | C |
|---|---|---|
| A | B | C | *(القيم تظهر في الخلايا A1 و B1 و C1)*

### النتيجة المتوقعة

```
Workbook saved to CreatedFromJson.xlsx
```

وستظهر ورقة Excel كما يلي:

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## الخطوة 6: معالجة هياكل JSON أكثر تعقيدًا (اختياري)

### 6.1 تعبئة مصنف من كائن JSON

إذا كان JSON الخاص بك كائنًا بدلاً من مصفوفة، يمكنك ما زال استخدام `SmartMarkerProcessor`. على سبيل المثال:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

سيقوم المعالج بإنشاء نطاقات مسماة (`title`, `month`, `values`) يمكنك الإشارة إليها في قالب Excel باستخدام Smart Markers مثل `&=title` و `&=values`.

### 6.2 تحويل مصفوفة JSON متداخلة إلى قائمة عمودية

أحيانًا تحتاج إلى أن تملأ المصفوفة عمودًا بدلاً من صف. اضبط الخلية الابتدائية يدويًا قبل المعالجة:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

الآن تظهر القيم **A**، **B**، **C** في الخلايا A2، A3، A4 على التوالي.

## الأخطاء الشائعة وكيفية تجنبها

| المشكلة | السبب | الحل |
|-------|-------|-----|
| **المصفوفة مكتوبة كسلسلة واحدة** | `setArrayAsSingle(false)` (الافتراضي) | استدعِ `processor.setArrayAsSingle(true)` |
| **الملف غير موجود عند الحفظ** | مسار غير صالح أو عدم وجود أذونات كتابة | استخدم مسارًا مطلقًا أو تأكد من وجود الدليل |
| **خطأ في تحليل JSON** | سلسلة JSON غير صالحة | تحقق من صحة JSON باستخدام أداة أو استخدم مكتبة مثل Jackson لتوليد السلسلة |
| **الخلايا تُستبدل عن غير قصد** | معالجة نفس الورقة عدة مرات دون إعادة تعيين الخلية الابتدائية | استدعِ `processor.setStartCell("A1")` قبل كل استدعاء `process` |

## نصيحة احترافية: إعادة استخدام المصنف كقالب

بدلاً من البدء بمصنف فارغ في كل مرة، يمكنك تحميل قالب مُصمم مسبقًا يحتوي بالفعل على رؤوس، صيغ، أو تنسيقات:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

هذا النهج يجمع بين اللمسة البصرية لملف Excel مُصمم يدويًا مع أتمتة **populate workbook from json**.
