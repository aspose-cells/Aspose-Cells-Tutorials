# استيراد الكائنات المخصصة إلى Excel باستخدام Aspose.Cells – دليل Java

إذا كنت بحاجة إلى **استيراد الكائنات المخصصة** إلى ورقة عمل Excel، يشرح لك هذا الدليل العملية الكاملة باستخدام Aspose.Cells for Java. سترى كيف **تستورد البيانات إلى Excel**، وتطبق نمط رأس غامق، وتولد ملف `.xlsx` جاهز للمشاركة.

تصدير البيانات الجدولية من Java غالبًا ما يتضمن كتابة الخلايا يدويًا خليةً بخلية، وهو أمر عرضة للأخطاء وصعب الصيانة. باستخدام واجهة برمجة التطبيقات `importCustomObjects` تتجنب كتابة الكود المتكرر، وتحافظ على نموذج البيانات الخاص بك، وتكتسب تحكمًا دقيقًا في التنسيق.

في هذا البرنامج التعليمي ستقوم بـ:

* بناء قائمة من كائنات Java `Map` تحاكي جدول بيانات نموذجي.
* إنشاء نمط رأس قابل لإعادة الاستخدام (خط غامق) باستخدام Aspose.Cells.
* استيراد الكائنات المخصصة إلى ورقة عمل مع تطبيق مصفوفة الأنماط.
* حفظ المصنف على القرص والتحقق من النتيجة.

المتطلب الوحيد هو بيئة تطوير Java (يوصى بـ JDK 8 أو أحدث) ومكتبة Aspose.Cells for Java.

| المتطلب | السبب |
|----------|--------|
| JDK 8 أو أحدث | مطلوب لتجميع وتشغيل كود Java. |
| Aspose.Cells for Java (أحدث إصدار) | يوفر الكائنات `Workbook` و `Worksheet` وواجهات الاستيراد. |

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## الخطوة 1: إعداد الكائنات المخصصة للاستيراد

الخطوة الأولى هي إنشاء مجموعة تمثل الصفوف التي تريد وضعها في Excel. في هذا المثال نستخدم `List<Map<String,Object>>` حيث كل خريطة تعمل كصف مع أسماء الأعمدة كمفاتيح.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**لماذا هذا مهم:**  
تتوقع `importCustomObjects` مصفوفة من الكائنات. باستخدام `Map` تحتفظ بأسماء الأعمدة، مما يسمح لـ Aspose.Cells بربطها تلقائيًا بالخلايا. هذا النهج يشبه `DataTable` في .NET أو `ResultSet` من JDBC، مما يجعل الكود قابلًا لإعادة الاستخدام عبر المشاريع.

---

## الخطوة 2: تعريف نمط رأس لتطبيقه عند الاستيراد

صف رأس واضح يحسن قابلية القراءة. يتيح لك Aspose.Cells إنشاء كائن `Style`، ضبط خطه إلى غامق، وتمريره عبر مصفوفة `ImportTableOptions`.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**لماذا هذا مهم:**  
إذا حذفت مصفوفة الأنماط، سيظهر الرأس بخط افتراضي قد لا يبرز. بإعداد النمط مرة واحدة، تتجنب استدعاءات متكررة لكل صف وتحافظ على نظافة منطق الاستيراد.

---

## الخطوة 3: استيراد الكائنات المخصصة مع مصفوفة الأنماط

الآن تجمع البيانات والنمط، ثم تستدعي `importCustomObjects`. تقوم الطريقة بوضع البيانات بدءًا من الزاوية العليا اليسرى (الصف 0، العمود 0) وتطبيق نمط الرأس تلقائيًا.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**لماذا هذا مهم:**  
تحلل `importCustomObjects` كل خريطة، وتُنشئ أعمدة بناءً على المفاتيح (`Name`, `Score`)، وتكتب القيم في الخلايا المناسبة. كائن `ImportTableOptions` يخبر Aspose.Cells باستخدام `styleArray` للصف الأول، مما يمنحك رأسًا غامقًا دون كود إضافي.

---

## الخطوة 4: حفظ المصنف والتحقق من النتيجة

أخيرًا، اكتب المصنف إلى ملف. يحتوي ملف Excel المُولد على صف رأس مُنسق يليه صفوف البيانات.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**النتيجة المتوقعة:**  

| **الاسم** | **النتيجة** |
|-----------|-------------|
| Alice     | 95          |
| Bob       | 82          |

تظهر خلايا الرأس (`الاسم`, `النتيجة`) بخط غامق، مطابقة للنمط المحدد في الخطوة 2.

## تنوعات شائعة وحالات حافة

| الحالة | التعديل الموصى به |
|-----------|------------------------|
| **ترتيب أعمدة مختلف** | تأكد من إدراج مفاتيح `Map` بالترتيب المطلوب، أو استخدم POJO مخصص مع حقول مُعَلَّمة ومصفوفة `PropertyDescriptor`. |
| **مجموعات بيانات كبيرة (>10 000 صف)** | زد قيمة `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` لتجنب `OutOfMemoryError`. |
| **تنسيقات أرقام مخصصة** | أضف `Style` ثانية في `styleArray` لصفوف البيانات، على سبيل المثال ضبط `NumberFormat` إلى `"0"` للنتائج الصحيحة. |
| **عدة أوراق عمل** | استدعِ `importCustomObjects` على كل ورقة هدف، مع تعديل صف/عمود البداية حسب الحاجة. |
| **نص رأس مخصص للمنطقة** | املأ صف الرأس يدويًا قبل الاستيراد، ثم طبّق النمط على النطاق بالكامل باستخدام `Cells.applyStyle`. |

## نصائح احترافية لتصدير Java قوي إلى Excel

* **إعادة استخدام المصنف المؤقت** – إنشاء `Workbook` جديد لكل نمط يضيف عبئًا. احتفظ بنسخة واحدة إذا كنت تحتاج إلى أنماط متعددة.  
* **تحقق من البيانات قبل الاستيراد** – القيم `null` في الخريطة تصبح خلايا فارغة؛ يمكنك استبدالها بقيم افتراضية عبر معالجة القائمة مسبقًا.  
* **إغلاق الموارد** – رغم أن Aspose.Cells يدير الذاكرة داخليًا، فإن استدعاء `workbook.dispose()` صراحةً بعد الحفظ يحرّر الموارد الأصلية بسرعة.  
* **ضبط `Workbook.setForceFullCalculation(true)`** إذا كان المصنف يحتوي على صيغ يجب تقييمها قبل الحفظ.
