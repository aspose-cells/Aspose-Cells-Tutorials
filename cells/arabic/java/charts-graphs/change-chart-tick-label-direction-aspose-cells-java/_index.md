# كيفية تغيير اتجاه علامات المحور في المخطط باستخدام Java و Aspose.Cells

## مقدمة

تغيير اتجاه علامات المحور في المخطط هو طريقة شائعة لتحسين قابلية قراءة مخططات Excel، خاصةً عند التعامل مع أسماء فئات طويلة أو مجموعات بيانات كثيفة. في هذا الدليل ستتعلم **كيفية تغيير اتجاه علامات المحور في المخطط** باستخدام Aspose.Cells للغة Java، بدءًا من تثبيت المكتبة وحتى حفظ المصنف النهائي. سنغطي أيضًا لماذا يعتبر تدوير التسميات بشكل صحيح مهمًا للتقارير المالية، والرسوم البيانية العلمية، ولوحات التحكم التجارية.

## إجابات سريعة
- **ما المكتبة التي تتعامل مع تدوير تسميات المخطط؟** Aspose.Cells for Java.
- **ما هو عنصر Maven الذي يضيف هذه الوظيفة؟** `com.aspose:aspose-cells`.
- **هل يمكنني ضبط زاوية التسمية لتكون عمودية؟** نعم، استخدم `ChartTextDirectionType.VERTICAL`.
- **هل أحتاج إلى ترخيص للاستخدام في الإنتاج؟** يلزم ترخيص دائم؛ الترخيص المؤقت يعمل للتقييم.
- **هل API متوافق مع Java 8 وما بعدها؟** نعم، يدعم Java 8‑21.

## ما هو تغيير اتجاه علامات المحور في المخطط؟
**تغيير اتجاه علامات المحور في المخطط** يشير إلى تعديل اتجاه تسميات علامات محور الفئة (مثلًا أفقي، عمودي، أو مائل) بحيث تتناسب بشكل أفضل داخل منطقة المخطط. يتم تنفيذ هذه العملية عبر طريقة `setTickLabelDirection` لكائن `ChartAxis` في Aspose.Cells.

## لماذا نستخدم Aspose.Cells للغة Java لتدوير تسميات المحور؟
تتعامل Aspose.Cells مع **أكثر من 150 تنسيق ملف**، ويمكنها معالجة مصنفات تحتوي على **أكثر من 500 ورقة عمل** دون تحميل الملف بالكامل إلى الذاكرة، وتقوم بتدوير التسميات في **أقل من 0.2 ثانية** لأحجام المخططات النموذجية. تجعل هذه القدرات الم quantified تجعلها خيارًا موثوقًا لأتمتة Excel على مستوى المؤسسات.

## كيف تغير اتجاه علامات المحور في المخطط باستخدام Java؟
لتعديل اتجاه تسميات العلامات، يجب تحميل المصنف المستهدف، استرجاع المخطط المحدد، الوصول إلى محور الفئة الخاص به، واستدعاء `setTickLabelDirection` مع `ChartTextDirectionType` المطلوب. يمكن تنفيذ هذه السلسلة في بضع أسطر فقط من كود Java، مما يجعل دمجها في سير عمل الأتمتة الحالي سهلًا.

1. حمّل المصنف الذي يحتوي على المخطط الذي تريد تعديله.  
2. استرجع ورقة العمل وكائن المخطط حسب فهرسه.  
3. وصول إلى محور الفئة (`getCategoryAxis()`) واستدعِ `setTickLabelDirection` مع `ChartTextDirectionType` المطلوب.  
4. احفظ المصنف إلى ملف جديد.

## دليل التنفيذ

### تحميل المصنف والمخطط
تمثل فئة `Workbook` ملف Excel كامل في الذاكرة. توفر فئة `Worksheet` الوصول إلى الأوراق الفردية، وتمثل فئة `Chart` مخططًا محددًا.

```java
Workbook workbook = new Workbook("input.xlsx");               // 1️⃣ Load file
Worksheet sheet = workbook.getWorksheets().get(0);            // 2️⃣ First sheet
Chart chart = sheet.getCharts().get(0);                       // 3️⃣ First chart on the sheet
```

### تغيير اتجاه تسميات العلامات
`ChartAxis` يتحكم في جميع خصائص المحور. `ChartTextDirectionType` هو تعداد يحدد الاتجاه.

```java
ChartAxis categoryAxis = chart.getCategoryAxis();            // Access category axis
categoryAxis.setTickLabelDirection(ChartTextDirectionType.HORIZONTAL); // 4️⃣ Set direction
```

- `ChartTextDirectionType.HORIZONTAL` → التسميات تُقرأ من اليسار إلى اليمين.  
- `ChartTextDirectionType.VERTICAL` → التسميات تُقرأ من الأعلى إلى الأسفل.  
- `ChartTextDirectionType.ROTATED_45` → التسميات مائلة بزاوية 45° (متوفرة في الإصدارات الأحدث).

### حفظ المصنف
بعد تعديل المحور، احفظ التغييرات:

```java
workbook.save("output.xlsx", SaveFormat.XLSX);
```

## المشكلات الشائعة والحلول
- **فهرس المخطط غير صحيح** – تحقق من وجود المخطط عن طريق فحص `sheet.getCharts().getCount()`.  
- **الترخيص غير مُطبق** – إذا رأيت علامة مائية، تأكد من تحميل ملف الترخيص قبل أي عملية على المصنف.  
- **اتجاه غير مدعوم** – بعض أنواع المخططات القديمة تدعم فقط التسميات الأفقية؛ قم بالترقية إلى أحدث إصدار من Aspose.Cells للوصول إلى جميع قيم التعداد.

## التطبيقات العملية
يبرز تغيير اتجاه تسميات العلامات في السيناريوهات التي تكون فيها المساحة محدودة:

1. **الخطوط الزمنية المالية** – التسميات الأفقية تحافظ على قابلية قراءة سلاسل التاريخ في المخططات الزمنية الكثيفة.  
2. **الرسوم العلمية** – التسميات العمودية توفر مساحة أفقية لأسماء المتغيرات الطويلة.  
3. **لوحات التحكم التجارية** – التسميات المائلة تمنع تداخل النص في مخططات الأعمدة متعددة الفئات.
