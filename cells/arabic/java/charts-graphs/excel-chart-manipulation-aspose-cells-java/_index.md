## كيفية استخراج معادلة خط الاتجاه java؟

حمّل دفتر العمل، احسب المخطط، واقرأ المعادلة في ثلاث خطوات فقط. أولاً، أنشئ كائن `Workbook` يشير إلى ملفك. بعد ذلك، استدعِ `chart.calculate()` لتحديث جميع حسابات المخطط، مما يضمن أن خطوط الاتجاه محدثة. أخيرًا، استدعِ `getTrendline().getEquation()` على السلسلة المطلوبة للحصول على نص الصيغة الدقيقة كما هو معروض في Excel.

### الوصول إلى دفتر عمل Excel ومعالجته

فئة `Workbook` تمثل ملف Excel كامل في الذاكرة. توفر طرقًا لفتح، حفظ، وتعديل دفاتر العمل دون تشغيل Excel.  
```java
import com.aspose.cells.Workbook;

String dataDir = "YOUR_DATA_DIRECTORY"; // Replace with actual directory path
Workbook workbook = new Workbook(dataDir + "/source.xlsx"); // Load the Excel file into a Workbook object
```  

### الوصول إلى ورقة العمل داخل دفتر العمل

فئة `Worksheet` تت对应 إلى ورقة واحدة داخل `Workbook`. يمكنك استرجاعها حسب الفهرس أو الاسم، ثم العمل مع صفوفها وأعمدتها ومخططاتها.  
```java
import com.aspose.cells.Worksheet;

Worksheet worksheet = workbook.getWorksheets().get(0); // Access the first worksheet in the workbook
```  

### الوصول إلى المخطط داخل ورقة العمل

فئة `Chart` هي نموذج كائن Aspose.Cells لأي مخطط على ورقة عمل. تمنحك تحكمًا كاملًا في السلاسل والمحاور وخطوط الاتجاه.  
```java
import com.aspose.cells.Chart;

Chart chart = worksheet.getCharts().get(0); // Access the first chart in the worksheet
```  

### حساب المخطط لتحديث نص معادلة خط الاتجاه

استدعاء `chart.calculate()` يجبر Aspose.Cells على إعادة حساب جميع بيانات المخطط، مما يضمن أن خطوط الاتجاه تعكس القيم الأخيرة قبل قراءة المعادلة.  
```java
chart.calculate(); // Calculate the chart to update its data and associated elements
```  

### الوصول إلى خط الاتجاه من السلسلة واسترجاع نص المعادلة

فئة `Trendline` تحتفظ بالصيغة والخصائص البصرية لخط الاتجاه. طريقة `getEquation()` تُعيد نص المعادلة، مثل “y = 2.5x + 3”.  
```java
import com.aspose.cells.Trendline;

Trendline trendLine = chart.getNSeries().get(0).getTrendLines().get(0); // Access the first trendline from the first series
String equationText = trendLine.getDataLabels().getText(); // Retrieve the Equation Text of the trendline
```
