# كيفية إنشاء أوراق عمل في Java باستخدام SmartMarkerProcessor

إذا كنت بحاجة إلى **كيفية إنشاء أوراق عمل** في ملف Excel، فإن هذا الدليل يوضح لك حلاً كاملاً وجاهزًا للتنفيذ. بحلول نهاية الجملتين الأوليين ستفهم كيفية إنشاء أوراق عمل و أوراق Excel ديناميكية من مجموعة من الكائنات، وستحصل على عينة كود تعمل تلقائيًا على إنشاء Excel باستدعاء طريقة واحدة.

إنشاء أوراق عمل منفصلة لكل موظف أو مشروع أو أي كيان آخر هو طلب شائع عندما تحتاج إلى **populate excel workbook** البيانات برمجيًا. يشرح هذا البرنامج التعليمي كل خطوة — من إعداد القالب إلى معالجة قائمة وحفظ الملف النهائي — حتى تتمكن من تطبيق التقنية فورًا في تطبيقات Java الخاصة بك.

## ما ستحققه

* إنشاء ورقة عمل رئيسية تُظهر معلومات عالية المستوى.  
* إنشاء بيانات **multiple sheets from list**، حيث يتم تسمية كل ورقة تلقائيًا.  
* **Automate excel creation** دون إضافة الصفوف أو الأعمدة يدويًا.  
* **Populate excel workbook** باستخدام هياكل بيانات غنية (كائنات، خرائط، مصفوفات).  

المتطلبات المسبقة:

* تثبيت Java 8 أو أحدث.  
* Maven (أو أداة بناء أخرى) لإضافة مكتبة Aspose.Cells for Java.  
* فهم أساسي لمجموعات Java.

> **Pro tip:** صيغة SmartMarker (`${EmployeeMaster}`) تعمل مع أي نوع مجموعة يطبق `java.util.Collection`. استخدمها للحفاظ على قوالبك نظيفة وقابلة للصيانة.

## كيفية إنشاء أوراق عمل باستخدام SmartMarkerProcessor

يتضمن هذا القسم الكود الأساسي الذي يجعل **how to generate worksheets** سهلًا. سنشرح لماذا كل سطر مهم، وليس فقط ما يفعله.

### الخطوة 1: إضافة تبعية Aspose.Cells

إذا كنت تستخدم Maven، أدرج ما يلي في ملف `pom.xml`. توفر المكتبة الفئة `SmartMarkerProcessor` المستخدمة طوال هذا الدليل.

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **لماذا:** تتعامل Aspose.Cells مع إدخال/إخراج ملفات Excel، وتحليل Smart Marker، وإدارة الأوراق داخليًا، مما يتيح لك التركيز على البيانات بدلاً من عمليات الملفات منخفضة المستوى.

### الخطوة 2: إعداد قالب Excel

أنشئ ملف Excel باسم `EmployeeTemplate.xlsx` يحتوي على خلية واحدة تحتوي على عنصر نائب Smart Marker:

| A |
|---|
| `${EmployeeMaster}` |

عند تشغيل المعالج، سيستبدل هذا العنصر النائب بـ **detail sheet** يحتوي على صف واحد لكل موظف.

> **لماذا:** يُخبر العنصر النائب المعالج بمكان إدخال البيانات. استخدام قالب منفصل يحافظ على تنسيقك (الخطوط، الحدود، عرض الأعمدة) دون تغيير.

### الخطوة 3: تعريف نموذج البيانات

فيما يلي فئة `Employee` الحد الأدنى وطريقة مساعدة تُنشئ قائمة من الموظفين. ستُستخدم القائمة لعرض **multiple sheets from list**.

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **لماذا:** كائن Java بسيط (POJO) يطابق مباشرةً حقول Smart Marker (`firstName`, `lastName`, `department`). هذا يجعل **populate excel workbook** سهلًا وآمنًا من حيث النوع.

### الخطوة 4: إعداد SmartMarkerProcessor

الآن نقوم بربط كل شيء معًا. سيقرأ المعالج القالب، يستبدل العلامة، وينشئ ورقة جديدة تسمى `EmployeeDetail`.

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

| السطر | السبب |
|------|--------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | يقوم بتحميل القالب الذي يحتوي بالفعل على عنصر نائب Smart Marker. |
| `data.put("EmployeeMaster", employees);` | يربط قائمة Java بالعلامة `${EmployeeMaster}`. |
| `processor.setDetailSheetNewName("EmployeeDetail");` | يعطي الورقة المُنشأة اسمًا ذا معنى بدلاً من الافتراضي `Sheet1`. |
| `processor.process(wb, data);` | **How to generate worksheets** – يقوم المعالج بقراءة العلامة، وإنشاء ورقة جديدة، وتعبئتها بالصفوف لكل `Employee`. |
| `wb.save("EmployeesReport.xlsx");` | يحفظ **dynamic excel sheets** على القرص. |

### الخطوة 5: التحقق من المخرجات

افتح `EmployeesReport.xlsx`. يجب أن ترى ورقتين عمل:

1. **Sheet1** – القالب الأصلي (يمكن إخفاؤه أو إزالته).  
2. **EmployeeDetail** – **dynamic excel sheet** يحتوي على أعمدة `firstName`, `lastName`, `department` وصف واحد لكل موظف.

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **لماذا هذا مهم:** يحتوي الملف الآن على **multiple sheets from list** دون أي تكرار يدوي أو تحديد خلايا. يتولى محرك Smart Marker إنشاء الصفوف، وتحويل البيانات، ووراثة التنسيق.

### الخطوة 6: معالجة الحالات الحدية

#### قائمة بيانات فارغة

إذا كانت `employees` فارغة، لا يزال المعالج ينشئ ورقة `EmployeeDetail` لكنه يتركها فارغة. يمكنك منع إضافة الورقة عن طريق فحص حجم المجموعة قبل المعالجة:

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### قوائم كبيرة جدًا

لآلاف الصفوف، فكر في زيادة تخصيص الذاكرة (`-Xmx2g`) أو استخدام `processor.setAutoFitRows(false)` لتسريع المعالجة.

#### تسمية أوراق مخصصة حسب المجموعة

إذا كنت بحاجة إلى ورقة منفصلة لكل قسم، يمكنك استخدام **multiple detail sheets**:

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

يتم أخذ العنصر النائب `${department}` من كل كائن `Employee`، مما ينتج أوراقًا مثل `Dept_Sales`، `Dept_Marketing`، إلخ.
