# إنشاء أوراق تفصيلية في Java باستخدام علامات Aspose.Cells الذكية

إذا كنت بحاجة إلى **إنشاء أوراق تفصيلية** في تطبيق Java، يوضح لك هذا الدليل كيفية القيام بذلك باستخدام علامات Aspose.Cells الذكية. سترى مثالًا كاملًا وقابلًا للتنفيذ يوضح **java create worksheets**، ويستخرج **sheet name from field**، و**process data source** في بضع أسطر من الشيفرة.

الدليل يغطي كل شيء من إعداد المشروع إلى حفظ ملف العمل النهائي، بحيث يمكنك نسخ‑لصق الحل في مشروعك الخاص وتعديله فورًا. لا حاجة إلى وثائق خارجية—كل ما تحتاجه موجود هنا.

## ما ستتعلمه

* كيفية **use smart markers** لتكرار ورقة عمل القالب لكل صف في مجموعة البيانات الرئيسية.  
* كيفية تعيين اسم كل ورقة جديدة ديناميكيًا بناءً على قيمة حقل (مثال: `Order_123`).  
* كيفية تغذية مجموعة Java كـ **process data source** لمحرك العلامات الذكية.  
* نصائح للتعامل مع الحالات الخاصة مثل البيانات الفارغة، الأحرف الخاصة في أسماء الأوراق، واعتبارات الأداء لمجموعات البيانات الكبيرة.

### المتطلبات المسبقة

| المتطلب | السبب |
|-------------|--------|
| Java 8 أو أعلى | Aspose.Cells for Java يدعم Java 8+. |
| نظام بناء Maven أو Gradle | يبسط إضافة تبعية Aspose.Cells. |
| معرفة أساسية بمجموعات Java | مطلوب لبناء مصدر البيانات للعلامات الذكية. |
| ملف Excel قالب (`Template.xlsx`) يحتوي على علامة ذكية نائبة في الخلية **A1** | القالب يدفع عملية إنشاء الأوراق التفصيلية. |

> **Pro tip:** احتفظ بملف العمل القالب في مجلد `resources` الخاص بالمشروع حتى يتم تضمينه مع ملف JAR الخاص بك.

## الخطوة 1: إضافة Aspose.Cells إلى مشروعك (java create worksheets)

إذا كنت تستخدم **Maven**، أضف التبعية التالية إلى `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

بالنسبة إلى **Gradle**، ضع هذا السطر في `build.gradle`:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

هذه الأسطر تجعل واجهات برمجة التطبيقات **java create worksheets** متاحة أثناء التجميع.

## الخطوة 2: تحميل ملف العمل القالب

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*لماذا هذا مهم:* كائن `Workbook` هو نقطة الدخول لجميع عمليات Excel. تحميل القالب يضمن أن تبدأ بالتخطيط الصحيح وأي تنسيق مسبق التعريف.

## الخطوة 3: إدراج علامة ذكية تنشئ ورقة جديدة لكل صف رئيسي (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

الصيغة `${Orders:DetailSheetNewName=Order_${OrderId}}` هي جوهر **use smart markers**. تقوم بثلاثة أشياء:

1. تتكرر عبر مجموعة `Orders`.  
2. تنشئ **new worksheet** لكل عنصر.  
3. تحدد **sheet name from field** `OrderId` (مسبوقة بـ `Order_`).

## الخطوة 4: إعداد مصدر البيانات (process data source)

فيما يلي مثال بسيط يستخدم `List<Map<String, Object>>`. استبدله بمصدر البيانات الحقيقي الخاص بك—صفوف قاعدة البيانات، تحويل JSON، إلخ.

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*لماذا هذا مهم:* خطوة **process data source** تربط مجموعة Java الخاصة بك بمحرك العلامات الذكية. المفتاح (`"Orders"`) يجب أن يطابق اسم العلامة الذكية تمامًا.

## الخطوة 5: معالجة العلامات الذكية (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

عند تشغيل `process`، تقوم Aspose.Cells بقراءة مجموعة `Orders`، وتستنسخ ورقة العمل القالب لكل إدخال، وتعيد تسمية كل ورقة وفقًا لحقل `OrderId`. هذا هو جوهر استخدام **process data source**.

## الخطوة 6: حفظ ملف العمل مع أوراق تفصيلية مكررة

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

بعد التنفيذ، ستجد `DuplicatedDetailSheets.xlsx` يحتوي على:

* `Sheet1` – القالب الأصلي (بدون تغيير).  
* `Order_101` – ورقة تفصيلية للطلب الأول.  
* `Order_102` – ورقة تفصيلية للطلب الثاني.

### النتيجة المتوقعة (مقتطف)

| اسم الورقة | A1 (smart marker) | المحتوى الناتج |
|------------|-------------------|-------------------|
| Order_101  | `${Orders:...}`   | مملوء بالبيانات من `order1` |
| Order_102  | `${Orders:...}`   | مملوء بالبيانات من `order2` |

افتح الملف في Excel للتحقق من أن كل ورقة مسماة بشكل صحيح وتحتوي على صفوف البيانات.

## التعامل مع التغييرات الشائعة وحالات الحافة

### مصدر بيانات فارغ

إذا كانت `orders` فارغة، فإن معالج العلامة الذكية لا ينشئ **أي أوراق عمل جديدة**. لتجنب ملف عمل فارغ، أضف شرطًا:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### أحرف خاصة في أسماء الأوراق

أسماء أوراق Excel لا يمكن أن تحتوي على `\ / ? * [ ] :`. نظف الحقل قبل استخدامه:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### مجموعات بيانات كبيرة

لآلاف الصفوف، فكر في زيادة حجم الذاكرة المخصصة للـ JVM (`-Xmx2g`) واستدعاء `workbook.calculateFormula()` فقط بعد إنشاء جميع الأوراق لتحسين الأداء.
