# Comment intégrer des polices dans le HTML lors de l’enregistrement d’un classeur

Si vous devez **comment intégrer des polices dans le HTML** lors de l’exportation d’une feuille de calcul, ce tutoriel vous propose une solution complète, prête à l’emploi. Que vous construisiez un portail de reporting ou une vue analytique côté client, l’intégration des polices garantit que le HTML rendu ressemble exactement au classeur original, quel que soit les polices installées chez le lecteur.

Vous apprendrez également la meilleure façon de **enregistrer le classeur au format HTML** avec Aspose.Cells, découvrirez les pièges courants et obtiendrez des conseils pour gérer de gros classeurs ou des fichiers de polices personnalisés. Aucune documentation externe n’est requise — tout ce dont vous avez besoin se trouve dans ce guide.

## Prérequis

- .NET 6.0 ou ultérieur (le code fonctionne également avec .NET Framework 4.7+)
- Une licence valide d’Aspose.Cells pour .NET (ou vous pouvez utiliser le mode d’évaluation gratuit)
- Connaissances de base en C# et un IDE tel que Visual Studio 2022
- Les fichiers de polices TrueType (.ttf) ou OpenType (.otf) que vous souhaitez intégrer (ils doivent être accessibles au processus en cours d’exécution)

## Étape 1 : Configurer le projet et importer Aspose.Cells

Créez une nouvelle application console et ajoutez le package NuGet Aspose.Cells :

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

Ensuite, ouvrez **Program.cs** et ajoutez les directives `using` requises :

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **Conseil :** Placez vos polices personnalisées dans un dossier nommé `fonts` à la racine du projet. Cela rend la solution portable et facilite leur référence ultérieure.

## Étape 2 : Créer ou charger un classeur

À titre d’exemple, nous créerons un classeur simple avec quelques cellules formatées :

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **Pourquoi c’est important :** Si vous omettez le style personnalisé, le HTML exporté reviendra aux polices par défaut du navigateur, contrecarrant ainsi le but de **comment intégrer des polices dans le HTML**.

## Étape 3 : Configurer `HtmlSaveOptions` pour intégrer les polices

Le cœur de **comment intégrer des polices dans le HTML** réside dans la classe `HtmlSaveOptions`. Définir `EmbedFonts = true` indique à Aspose.Cells d’intégrer toutes les polices TrueType/OpenType référencées directement dans le HTML généré sous forme d’URIs de données encodées en Base64.

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### Fonctionnement de l’intégration

Lorsque `EmbedFonts` est `true`, Aspose.Cells analyse les définitions de style du classeur, localise les fichiers de police correspondants sur le système (ou dans le dossier `fonts` que vous avez ajouté), lit leurs données binaires et injecte un bloc `<style>` similaire à :

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

Comme les données de la police sont encodées directement dans le HTML, la page s’affiche correctement même sur des machines qui n’ont pas la police installée.

## Étape 4 : Enregistrer le classeur au format HTML

Vous pouvez maintenant **enregistrer le classeur au format HTML** avec les options configurées. Choisissez un répertoire dans lequel l’application peut écrire (par ex., `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

L’exécution du programme génère un seul fichier `report.html`. Ouvrez-le dans n’importe quel navigateur moderne et vous verrez l’en-tête « Quarterly Sales » rendu avec la police **Pacifico**, même si la police n’est pas installée sur votre système d’exploitation.

### Résultat attendu

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

L’attribut `src:` contient une longue chaîne Base64 — c’est la donnée de police intégrée qui permet **comment intégrer des polices dans le HTML**.

## Étape 5 : Vérifier l’intégration des polices et résoudre les problèmes

1. **Ouvrez le fichier HTML dans Chrome ou Edge.** Si la police personnalisée apparaît, l’intégration a réussi.  
2. **Inspectez le code source de la page.** Recherchez la règle `@font-face` générée par Aspose.Cells.  
3. **Problèmes courants :**  
   - *Fichier de police manquant :* Assurez‑vous que le fichier de police est accessible. Vous pouvez ajouter explicitement un dossier au chemin de recherche :

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *Taille HTML importante :* L’intégration de nombreuses polices peut alourdir le fichier. Utilisez `ExportToSingleFile = false` pour conserver les polices comme fichiers `.ttf` séparés dans un dossier de ressources.

   - *Format de police non pris en charge :* Aspose.Cells n’intègre que les polices TrueType (`.ttf`) et OpenType (`.otf`). Convertissez les autres formats avant l’intégration.

## Exemple complet fonctionnel

Voici le programme complet que vous pouvez copier, coller et exécuter sans modifications (à l’exception de la ligne de licence facultative).

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

L’exécution de ce programme crée `output/report.html`. Ouvrez le fichier, et vous verrez la police **Pacifico** correctement rendue—démontrant **comment intégrer des polices dans le HTML** lors de **l’enregistrement du classeur au format HTML**.

## Questions fréquemment posées

| Question | Réponse |
|----------|--------|
| *Puis-je intégrer uniquement des polices spécifiques ?* | Oui. Définissez `htmlOpt.EmbedAllFonts = false` (disponible dans les versions récentes) et utilisez `htmlOpt.FontsToEmbed` pour lister les noms exacts des polices. |
| *Et si je dois intégrer des polices pour plusieurs feuilles de calcul ?* | Définissez `ExportActiveWorksheetOnly = false` afin que chaque feuille soit exportée, et Aspose.Cells intégrera les polices utilisées dans l’ensemble du classeur. |
| *Les polices intégrées fonctionneront‑elles sur les navigateurs mobiles ?* | Les navigateurs mobiles modernes prennent en charge les polices encodées en Base64, de sorte que les polices intégrées s’affichent correctement tant que le format de police est pris en charge (TTF ou OTF). |
| *Quelle taille peut atteindre le fichier HTML ?* | Intégrer une police TrueType de 200 KB ajoute approximativement la même quantité à la taille du HTML (Base64 ajoute ~33 % de surcharge). Pour de nombreuses polices, envisagez d’exporter vers un dossier (`ExportToSingleFile = false`) afin de garder le HTML léger. |
