# Comment intégrer des polices lors de l’enregistrement d’Excel en HTML avec C#

Intégrer des polices lors de l’enregistrement d’un classeur Excel en HTML est une exigence courante pour préserver l’aspect exact de vos feuilles de calcul sur les navigateurs. Si vous devez exporter Excel vers HTML tout en conservant les polices d’origine, ce guide vous présente une solution complète, prête à l’emploi.

Vous apprendrez comment **exporter Excel en HTML**, **convertir Excel en HTML** avec des polices intégrées, et éviter le problème typique de « police manquante » qui casse la mise en page sur les machines clientes. Aucun outil externe n’est requis — il suffit de la bibliothèque Aspose.Cells et de quelques lignes de C#.

## Prérequis

* .NET 6.0 (ou version ultérieure) installé.
* Une copie sous licence de **Aspose.Cells for .NET** – l’essai gratuit suffit pour les tests.
* Un IDE tel que Visual Studio 2022 ou VS Code.

Si vous avez déjà tout cela, vous pouvez passer directement au code.

## Étape 1 : Créer un classeur et ajouter des données d’exemple

Tout d’abord, nous générons un petit classeur afin que vous puissiez voir l’effet des polices intégrées. Le code ci‑dessous crée une feuille de calcul, écrit quelques cellules et applique une police personnalisée.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### Pourquoi ajouter une police personnalisée

L’intégration de polices n’est pertinente que lorsque le classeur utilise des polices qui pourraient ne pas être présentes sur le dispositif client. En définissant explicitement **Arial** (ou toute autre police) nous pouvons vérifier que la sortie HTML contient réellement les données de la police.

## Étape 2 : Configurer les options d’enregistrement HTML pour intégrer les polices

Aspose.Cells fournit la classe `HtmlSaveOptions`. Définir `EmbedFonts = true` indique à la bibliothèque d’intégrer les fichiers de police requis directement dans le HTML généré sous forme d’URI de données encodées en Base64.

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### Ce que fait réellement « intégrer des polices dans le HTML »

Lorsque `EmbedFonts` est vrai, Aspose.Cells extrait les fichiers de police du système (ou de la collection de polices intégrées du classeur) et les convertit en chaînes **Base64**. Ces chaînes sont ensuite placées dans un bloc `<style>` à l’aide de `@font-face`. Le HTML résultant peut être ouvert sur n’importe quel dispositif sans nécessiter l’installation de la police d’origine.

## Étape 3 : Enregistrer le classeur en HTML avec les polices intégrées

Nous écrivons maintenant le classeur sur le disque. Le fichier contiendra les données de la police, de sorte qu’en l’ouvrant dans n’importe quel navigateur moderne, la typographie sera exactement la même que celle du fichier Excel d’origine.

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### Résultat attendu

* `embedded.html` se trouve dans le dossier `output`.
* Ouvrir le fichier dans Chrome, Edge ou Firefox affiche la feuille de calcul avec du texte **Arial**, même si la machine du navigateur ne possède pas Arial.
* L’inspection du code source HTML révèle un bloc `<style>` contenant une règle `@font-face` avec une longue déclaration `src: url(data:font/ttf;base64,…)` – il s’agit de la police intégrée.

## Étape 4 : Vérifier que le HTML fonctionne sur une autre machine (optionnel)

Pour être absolument certain que l’intégration a réussi :

1. Copiez `output/embedded.html` sur un autre ordinateur (ou une machine virtuelle) qui **n’a pas** la police personnalisée installée.
2. Ouvrez le fichier dans un navigateur.
3. La mise en page et la typographie doivent correspondre à la vue Excel originale.

Si la police revient à une police générique, vérifiez que le fichier de police est accessible sur la machine de construction et que vous avez la permission de le lire.

## Questions fréquentes et cas particuliers

### L’intégration augmente‑t‑elle la taille du fichier ?

Oui. Intégrer une police TrueType ou OpenType peut ajouter **des dizaines de kilooctets** au fichier HTML. Pour de gros classeurs contenant de nombreuses polices uniques, envisagez :

* Sous‑ensembler la police (seuls les caractères que vous utilisez) – Aspose.Cells le fait automatiquement pour la plupart des polices courantes.
* Utiliser `ExportEmbeddedImages = false` si vous n’avez pas besoin d’images intégrées.

### Et si je dois intégrer uniquement des polices spécifiques ?

`HtmlSaveOptions` n’expose pas de liste blanche directe, mais vous pouvez contrôler les polices présentes en **limitant les polices utilisées dans le classeur** avant d’appeler `Save`. Supprimez les affectations de police inutiles ou remplacez‑les par des polices web‑safe standard.

### Puis‑je intégrer des polices lors de la conversion vers d’autres formats (p. ex., PDF) ?

La même propriété `EmbedFonts` existe sur `PdfSaveOptions`. Le concept est identique : les données de la police sont intégrées afin que le PDF s’affiche correctement sur n’importe quel lecteur.

## Exemple complet et exécutable

Voici le programme complet que vous pouvez copier‑coller dans un nouveau projet console.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

L’exécution du programme génère un **fichier HTML contenant la police Arial intégrée**, garantissant la fidélité visuelle où que le fichier soit ouvert.

## Conclusion

Vous savez maintenant **comment intégrer des polices lors de l’enregistrement d’Excel en HTML** avec C#. En configurant `HtmlSaveOptions.EmbedFonts = true`, vous pouvez de façon fiable **exporter Excel en HTML** et **convertir Excel en HTML** sans vous soucier des polices manquantes côté client. Cette technique est essentielle pour les rapports web, les tableaux de bord adaptés aux e‑mails, ou tout scénario où vous partagez du contenu dérivé d’Excel sous forme HTML.

### Et après ?

* **Personnalisez le CSS** généré par Aspose.Cells pour qu’il corresponde au guide de style de votre site.  
* **Intégrez les images** sélectivement en basculant `ExportEmbeddedImages`.  
* **Explorez d’autres formats d’exportation** comme PDF ou SVG tout en intégrant les polices.  

N’hésitez pas à expérimenter avec différentes polices, des feuilles de calcul plus grandes ou des classeurs multi‑feuilles. Le même drapeau `EmbedFonts` fonctionne avec tous les formats de sortie pris en charge, vous offrant un contrôle cohérent sur l’intégration des polices où que vous en ayez besoin. Bon codage !
