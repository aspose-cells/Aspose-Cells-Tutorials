# Comment exporter des tableaux croisés dynamiques en images avec Aspose.Cells en C#

Si vous devez **exporter des pivots** data into a portable picture, Aspose.Cells makes the process straightforward. This tutorial shows you exactly how to export pivot tables as PNG files, so you can embed them in reports, emails, or documentation without requiring Excel on the target machine.

Exporter un tableau croisé dynamique en image élimine les problèmes de formatage spécifiques aux versions et permet aux parties prenantes non techniques de visualiser l'analyse instantanément. Nous couvrirons tout, de la configuration du projet au rendu de l'**image du tableau croisé dynamique exporté**, et nous expliquerons également comment **enregistrer le tableau croisé dynamique en image** pour une réutilisation future.

## Comment exporter des tableaux croisés dynamiques en images avec Aspose.Cells

Voici l'exemple complet et exécutable qui charge un classeur, rafraîchit le tableau croisé dynamique, configure les options d'image et écrit le fichier de sortie. Chaque étape inclut une courte justification afin que vous compreniez *pourquoi* le code est écrit ainsi, et pas seulement *ce que* fait le code.

### 1. Configurer l'environnement Aspose.Cells

1. Installez le package NuGet :

   ```bash
   dotnet add package Aspose.Cells
   ```

2. Ajoutez les directives `using` requises en haut de votre fichier C# :

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **Astuce :** Ciblez .NET 6 ou une version ultérieure pour profiter des dernières améliorations de performances d'Aspose.Cells.

### 2. Charger le classeur et localiser le tableau croisé dynamique

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*Pourquoi c'est important :* La classe `Workbook` analyse le fichier XLSX et vous donne accès à toutes les feuilles de calcul. Sélectionner la bonne feuille est essentiel car un classeur peut contenir plusieurs tableaux croisés dynamiques.

### 3. Rafraîchir le tableau croisé dynamique pour capturer les dernières données source

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

Le rafraîchissement garantit que toutes les modifications apportées à la plage source après l'enregistrement du fichier sont reflétées dans l'image rendue. Ignorer cette étape peut produire des visuels obsolètes ou inexacts.

### 4. Configurer les options d'exportation d'image (exporter le tableau croisé dynamique en image)

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

L'objet `ImageOrPrintOptions` vous permet de contrôler le format, la résolution et d'autres détails de rendu. PNG est le choix le plus courant pour des graphiques nets et compatibles web, mais vous pouvez passer à `ImageFormat.Jpeg` si la taille du fichier est un problème.

### 5. Rendre et **enregistrer le tableau croisé dynamique en image**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

`RenderToImage` effectue le travail lourd : il dessine le tableau croisé dynamique exactement comme il apparaît dans Excel et écrit les données PNG binaires sur le disque. La méthode renvoie `void`, vous pouvez donc supposer en toute sécurité que le fichier existe après l'exécution de l'appel, sans nécessiter de vérifications supplémentaires.

#### Résultat attendu

Après l'exécution du programme, vous trouverez `Pivot.png` dans le dossier spécifié. L'ouverture du fichier doit afficher un instantané fidèle du tableau croisé dynamique original, incluant les en‑têtes de colonne, les totaux de ligne et tout formatage appliqué.

### 6. Variantes courantes et cas limites

| Scenario | Adjustment |
|----------|------------|
| **Pivots volumineux** (de nombreuses lignes/colonnes) | Augmentez `HorizontalResolution` et `VerticalResolution` à 300 dpi pour une sortie plus nette. |
| **Style personnalisé** (couleurs d'arrière‑plan, polices) | Assurez‑vous que les définitions de style du classeur sont chargées avant d'appeler `Refresh()`. |
| **Multiples pivots** dans une même feuille | Parcourez `worksheet.PivotTables` et appelez `RenderToImage` pour chacun, en utilisant des noms de fichiers distincts. |
| **Exportation en JPEG** au lieu de PNG | Modifiez `ImageFormat = ImageFormat.Jpeg` et, éventuellement, définissez `Quality` sur un objet `JpegSaveOptions`. |

Ces variantes vous permettent d'**exporter le tableau croisé dynamique en image** dans le format exact attendu par votre système en aval.

## Code source complet pour copier‑coller rapidement

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

L'exécution du programme génère le fichier PNG affiché ci‑dessus, complétant le flux de travail **enregistrer le tableau croisé dynamique en image** en moins d'une minute.
