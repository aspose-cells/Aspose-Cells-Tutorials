# Comment créer un classeur Excel C# avec un formatage personnalisé et l’enregistrer en XLSX

Si vous devez **créer un classeur Excel C#** qui importe des données, applique un format numérique personnalisé et modifie la couleur de police des cellules, ce tutoriel vous montre exactement comment procéder. Vous obtiendrez un exemple prêt à l’exécution qui génère un fichier `StyleArrayImport.xlsx` formaté en quelques secondes.

Travailler avec Excel depuis C# implique souvent des étapes manuelles répétitives — définir des formats, appliquer des couleurs et se souvenir d’enregistrer correctement le fichier. À la fin de ce guide, vous automatiserez toutes ces tâches, afin de pouvoir vous concentrer sur les données plutôt que sur l’interface utilisateur.

Vous apprendrez à :

* importer un `DataTable` dans une feuille de calcul,
* utiliser un `StyleArray` pour **appliquer un format numérique personnalisé** et **modifier la couleur de police de la cellule**,
* **enregistrer le classeur au format XLSX** avec un seul appel de méthode,
* et vérifier que le **format des données importées dans Excel** apparaît exactement comme prévu.

Le seul prérequis est une référence à la bibliothèque **Aspose.Cells for .NET** (ou toute API compatible qui fournit `Workbook`, `Worksheet` et `StyleArray`). Le code cible .NET 6+, mais les versions antérieures fonctionnent avec de légers ajustements.

| Exigence | Raison |
|----------|--------|
| .NET 6 SDK ou version ultérieure | Fournit le runtime pour l’application console C#. |

Installez le package Aspose.Cells avec la commande suivante :

```bash
dotnet add package Aspose.Cells
```

## Étape 1 : Préparer le DataTable d'exemple

Tout d'abord, créez un `DataTable` qui imite les données que vous récupérez habituellement depuis une base de données ou une autre source. Le tableau comprend une colonne **Name** (string) et une colonne **Amount** (decimal) que nous formaterons plus tard.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Pourquoi c’est important :** Utiliser un `DataTable` vous permet de garder la logique d’importation indépendante de la source de données, ce qui est une pratique courante lors de la génération de rapports à partir de bases de données, de fichiers CSV ou d’API.

## Étape 2 : Définir un StyleArray pour **appliquer un format numérique personnalisé** et **modifier la couleur de police de la cellule**

`StyleArray` vous permet de regrouper les instructions de formatage qui seront appliquées à chaque cellule importée depuis le `DataTable`. Dans cet exemple nous :

* définissons `Number` à `#,##0.00` – un format comptable typique avec séparateur de milliers,
* définissons `FontColor` à `Color.Blue` – pour faire ressortir les nombres.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**Pourquoi utiliser un StyleArray ?** Appliquer un style lors de l’importation évite un second passage sur la feuille de calcul, ce qui améliore les performances pour les grands ensembles de données.

---

## Étape 3 : **Créer un classeur Excel C#** – instancier Workbook et obtenir la première Worksheet

Nous créons maintenant un classeur vide et obtenons une référence à la première feuille de calcul (index 0). Cette feuille devient la destination de nos données importées.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Explication :** `Workbook` représente le fichier Excel complet, tandis que `Worksheet` représente un onglet unique. Le classeur par défaut contient une feuille, ce qui suffit pour la plupart des rapports simples.

---

## Étape 4 : Importer le DataTable en utilisant le **StyleArray** pour **formater les données importées dans Excel**

La méthode `ImportDataTable` copie les lignes et colonnes du tableau dans la feuille de calcul, en commençant à la cellule `A1` (ligne 0, colonne 0). L’argument `true` indique à la méthode d’inclure les en‑têtes de colonne. Parce que nous transmettons `styleArray`, chaque cellule importée reçoit le format numérique personnalisé et la couleur de police.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**Ce qui se passe en coulisses :** Aspose.Cells parcourt chaque ligne, écrit la valeur, puis applique le style défini dans `styleArray`. Les nombres apparaissent avec des virgules et deux décimales, et le texte est affiché en bleu.

---

## Étape 5 : **Enregistrer le classeur au format XLSX** – écrire le fichier sur le disque

Enfin, persistez le classeur dans un fichier `.xlsx`. Vous pouvez modifier le chemin vers n’importe quel répertoire accessible en écriture sur votre machine.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Vérification du résultat :** Ouvrez le fichier généré dans Excel. Vous devez voir les trois lignes de données, la colonne **Amount** formatée avec des virgules, deux décimales et affichée en police bleue. Cela confirme que l’étape **format des données importées dans Excel** a réussi.

## Exemple complet fonctionnel

Copiez le bloc complet ci‑dessous dans un nouveau projet console et exécutez‑le. Aucun code supplémentaire n’est requis.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Sortie attendue dans la console :**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

Ouvrez le fichier et vérifiez que la colonne **Amount** affiche des valeurs comme `1,234.56` en police bleue.

## Questions fréquentes et cas particuliers

| Question | Réponse |
|----------|--------|
| *Puis‑je appliquer des formats différents à des colonnes individuelles ?* | Oui. Après l’importation, récupérez l’objet `Style` de la colonne (`worksheet.Cells.Columns[1].Style`) et définissez un `Number` ou `FontColor` différent. |
| *Et si je dois formater des dates au lieu de nombres ?* | Définissez `styleArray.Number = "mm-dd-yyyy"` et éventuellement `styleArray.FontColor` pour les cellules de date. |
| *La police bleue est‑elle visible sur les thèmes sombres d’Excel ?* | Le bleu peut être difficile à lire sur des fonds sombres. Utilisez une teinte plus claire (`Color.LightBlue`) ou une couleur contrastante (`Color.Black`). |
| *Comment importer un DataTable très volumineux (des centaines de milliers de lignes) ?* | Utilisez `ImportDataTable` avec la surcharge `ImportDataTableOptions` pour diffuser les données, ou divisez l’importation en plusieurs feuilles afin de rester dans la limite de lignes d’Excel (1 048 576 lignes). |
| *Puis‑je exporter en CSV au lieu de XLSX ?* | Remplacez `SaveFormat.Xlsx` par `SaveFormat.Csv`. Notez que les informations de formatage (format numérique, couleur de police) sont perdues en CSV car il s’agit d’un format texte brut. |

## Conseils pour l’utilisation en production

* **Astuce :** Mettez en cache l’objet `Style` si vous devez appliquer le même formatage à de nombreuses feuilles ; créer un nouveau `StyleArray` pour chaque importation ajoute une surcharge.  
* **Attention aux différences culturelles :** Le modèle `Number` `#,##0.00` suit la culture invariante. Si vous avez besoin de séparateurs spécifiques à une locale, utilisez `NumberFormatInfo` ou laissez Excel le gérer en fonction des paramètres régionaux de l’utilisateur.  
* **Gestion des erreurs :** Enveloppez l’appel `Save` dans un bloc `try‑catch` pour gérer les exceptions d’E/S (par ex., permissions insuffisantes ou fichiers verrouillés).
