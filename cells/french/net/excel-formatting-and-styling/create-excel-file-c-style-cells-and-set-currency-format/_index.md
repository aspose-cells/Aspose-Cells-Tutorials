# Créer un fichier Excel c# – styliser les cellules et définir le format monétaire

Si vous devez **créer un fichier Excel c#** qui ait un aspect professionnel, ce guide vous montre exactement comment styliser les cellules Excel et formater une colonne en monnaie. Vous verrez un exemple complet, de bout en bout, qui importe un `DataTable`, applique un en‑tête en gras, et définit un format numérique `$#,##0.00` pour la colonne prix.

Le tutoriel couvre tout ce dont vous avez besoin : les packages NuGet requis, le code source complet, les explications sur l’importance de chaque élément, et des astuces pour gérer les cas limites comme les lignes vides ou les paramètres régionaux différents. À la fin, vous serez capable de générer un fichier `.xlsx` avec une colonne prix joliment formatée en quelques lignes de C#.

## Prérequis

- .NET 6.0 ou ultérieur (le code fonctionne également avec .NET Framework 4.6+)
- Visual Studio 2022 ou tout éditeur C# de votre choix
- La bibliothèque **Aspose.Cells for .NET** ou **GemBox.Spreadsheet** (les deux supportent `ImportTableOptions`). L’exemple ci‑dessous utilise **Aspose.Cells** car il fournit une propriété simple `StyleArray`.
- Connaissances de base des collections C# et de `DataTable`

> **Astuce pro :** Si vous préférez une alternative gratuite, remplacez `Aspose.Cells` par `GemBox.Spreadsheet`. L’API pour importer un `DataTable` avec styles est presque identique ; il suffit de changer l’espace de noms et le nom du package NuGet.

## Étape 1 : Installer la bibliothèque Excel

Ouvrez le Gestionnaire de packages NuGet et installez la bibliothèque :

```bash
dotnet add package Aspose.Cells
```

> **Pourquoi cette étape ?** La bibliothèque fournit les classes `Workbook`, `Worksheet`, `Style` et `ImportTableOptions` utilisées plus tard. Sans elle, vous devriez écrire manuellement le format Office Open XML, ce qui est source d’erreurs.

## Étape 2 : Créer un DataTable avec des données d'exemple

Un `DataTable` est un moyen pratique de contenir des données tabulaires avant de les exporter vers Excel. Dans cet exemple, nous avons deux colonnes : *Product* et *Price*.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Explication :**  
> - `Columns.Add("Price", typeof(double))` indique à la table de traiter les valeurs de prix comme des nombres, ce qui est nécessaire pour le formatage numérique ultérieur.  
> - Ajouter quelques lignes nous donne des données pour vérifier l’étape **format column currency**.

## Étape 3 : Définir les styles à appliquer

Nous allons créer un tableau d’objets `Style` qui correspond à l’ordre des colonnes. La première entrée stylise la ligne d’en‑tête, la deuxième laisse la colonne *Product* intacte, et la troisième applique un format numérique monétaire.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### Pourquoi utiliser un **style array** ?

`ImportTableOptions.StyleArray` associe chaque colonne à un `Style`. C’est la façon la plus efficace d’**add number format** et de **style excel cells** en une seule opération d’importation, évitant ainsi un second passage sur la feuille de calcul.

## Étape 4 : Configurer les options d'importation

Nous liasons maintenant le tableau de styles à l’opération d’importation. L’objet `ImportTableOptions` vous permet également de contrôler si la première ligne est traitée comme un en‑tête.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Note :** `IsFieldNameShown` vaut `true` par défaut, mais le définir explicitement rend l’intention claire pour les futurs lecteurs.

## Étape 5 : Créer un classeur, importer le tableau et enregistrer

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### Résultat attendu

Lorsque vous ouvrez `DataTableWithStyles.xlsx` :

- La première ligne (en‑tête) est en **gras**.
- La colonne *Price* affiche les valeurs sous la forme **$1.20**, **$3.50**, **$0.75**.
- La colonne *Product* conserve la police par défaut.

Vous avez réussi à **créer un fichier Excel c#** avec une colonne monétaire formatée et des cellules d’en‑tête stylisées.

## Étape 6 : Gestion des variations courantes et des cas limites

### a. Locale différente ou symbole monétaire personnalisé

Si vous avez besoin d’un euro ou d’une autre monnaie, remplacez le format intégré `164` par une chaîne de format personnalisée :

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. Ajouter d’autres colonnes plus tard

Lorsque vous ajoutez des colonnes supplémentaires, étendez le tableau `columnStyles` en conséquence. Utilisez `null` pour les colonnes qui doivent conserver le style par défaut.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. DataTable vide

Si le `DataTable` n’a aucune ligne, Aspose.Cells crée quand même la ligne d’en‑tête. Cependant, le classeur ne contiendra qu’une seule ligne. Pour éviter un fichier vide, vérifiez le nombre de lignes avant d’importer :

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Utiliser `GemBox.Spreadsheet` à la place d’Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

La logique reste identique, démontrant que le tutoriel est **format column currency** indépendant de la bibliothèque sous‑jacente.

## Étape 7 : Vérifier le fichier de façon programmatique (optionnel)

Vous pouvez ouvrir le classeur généré et vérifier que le format numérique a été appliqué correctement — utile pour les tests unitaires.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```
