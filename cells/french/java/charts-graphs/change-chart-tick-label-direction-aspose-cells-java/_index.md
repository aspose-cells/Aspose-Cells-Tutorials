# Comment changer la direction des repères du graphique en Java avec Aspose.Cells

## Introduction

Modifier la direction des repères du graphique est un moyen courant d'améliorer la lisibilité des graphiques Excel, surtout lorsqu'il s'agit de noms de catégories longs ou d'ensembles de données denses. Dans ce guide, vous apprendrez **comment changer la direction des repères du graphique** avec Aspose.Cells pour Java, depuis l'installation de la bibliothèque jusqu'à l'enregistrement du classeur final. Nous aborderons également pourquoi une rotation correcte des étiquettes est importante pour les rapports financiers, les visualisations scientifiques et les tableaux de bord d'entreprise.

## Réponses rapides

- **What library handles chart label rotation?** Aspose.Cells for Java.  
- **Which Maven artifact adds the functionality?** `com.aspose:aspose-cells`.  
- **Can I set the label angle to vertical?** Yes, use `ChartTextDirectionType.VERTICAL`.  
- **Do I need a license for production use?** A permanent license is required; a temporary license works for evaluation.  
- **Is the API compatible with Java 8 and later?** Yes, it supports Java 8‑21.

## Pourquoi utiliser Aspose.Cells pour Java pour faire pivoter les tick labels ?

Aspose.Cells traite **plus de 150 formats de fichiers**, peut gérer des classeurs avec **plus de 500 feuilles** sans charger le fichier complet en mémoire, et effectue les rotations d'étiquettes en **moins de 0,2 seconde** pour des tailles de graphiques typiques. Ces capacités quantifiées en font un choix fiable pour l'automatisation Excel de niveau entreprise.

## Prérequis

- **Aspose.Cells for Java** version 25.3 ou plus récente.  
- Un kit de développement Java 8+ et votre IDE préféré (IntelliJ IDEA, Eclipse, etc.).  
- Maven ou Gradle pour la gestion des dépendances.  
- Une licence Aspose.Cells temporaire ou permanente (voir la section licence ci‑dessous).

## Configuration d'Aspose.Cells pour Java

Pour commencer, ajoutez la dépendance Aspose.Cells à votre fichier de construction.

**Maven**  
```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>25.3</version>
    <classifier>jdk17</classifier>
</dependency>
```

**Gradle**  
```gradle
implementation 'com.aspose:aspose-cells:25.3:jdk17'
```

La classe `Workbook` est le point d'entrée pour toutes les opérations Excel. Après avoir ajouté la bibliothèque, vous pouvez créer une instance de classeur comme suit :

Workbook workbook = new Workbook("input.xlsx");

## Comment changer la direction des repères du graphique en Java ?

Pour modifier l'orientation des tick‑labels, vous devez charger le classeur cible, récupérer le graphique spécifique, accéder à son axe de catégorie, et invoquer `setTickLabelDirection` avec le `ChartTextDirectionType` souhaité. Cette séquence peut être réalisée en quelques lignes de code Java, ce qui la rend simple à intégrer dans des flux d'automatisation existants.

1. Chargez le classeur qui contient le graphique que vous souhaitez modifier.  
2. Récupérez la feuille de calcul et l'objet graphique par son index.  
3. Accédez à l'axe de catégorie (`getCategoryAxis()`) et appelez `setTickLabelDirection` avec le `ChartTextDirectionType` souhaité.  
4. Enregistrez le classeur dans un nouveau fichier.

## Guide d'implémentation

### Chargement du classeur et du graphique

La classe `Workbook` représente un fichier Excel complet en mémoire. La classe `Worksheet` vous donne accès aux feuilles individuelles, et la classe `Chart` représente un graphique spécifique.

```java
Workbook workbook = new Workbook("input.xlsx");               // 1️⃣ Load file
Worksheet sheet = workbook.getWorksheets().get(0);            // 2️⃣ First sheet
Chart chart = sheet.getCharts().get(0);                       // 3️⃣ First chart on the sheet
```

### Modification de la direction du tick label

`ChartAxis` contrôle toutes les propriétés liées aux axes. `ChartTextDirectionType` est une énumération qui définit l'orientation.

```java
ChartAxis categoryAxis = chart.getCategoryAxis();            // Access category axis
categoryAxis.setTickLabelDirection(ChartTextDirectionType.HORIZONTAL); // 4️⃣ Set direction
```

- `ChartTextDirectionType.HORIZONTAL` → les étiquettes s'affichent de gauche à droite.  
- `ChartTextDirectionType.VERTICAL` → les étiquettes s'affichent de haut en bas.  
- `ChartTextDirectionType.ROTATED_45` → les étiquettes sont pivotées de 45° (disponible dans les versions récentes).

### Enregistrement du classeur

Après avoir ajusté l'axe, enregistrez les modifications :

```java
workbook.save("output.xlsx", SaveFormat.XLSX);
```

## Problèmes courants et solutions

- **Incorrect chart index** – Vérifiez que le graphique existe en contrôlant `sheet.getCharts().getCount()`.  
- **License not applied** – Si vous voyez un filigrane, assurez-vous que le fichier de licence est chargé avant toute opération sur le classeur.  
- **Unsupported direction** – Certains types de graphiques plus anciens ne prennent en charge que les étiquettes horizontales ; mettez à jour vers la dernière version d'Aspose.Cells pour accéder à toutes les valeurs d'énumération.

## Applications pratiques

Modifier la direction des tick labels est utile dans les scénarios où l'espace est limité :

1. **Financial timelines** – Les étiquettes horizontales maintiennent la lisibilité des dates sur les graphiques de séries temporelles denses.  
2. **Scientific plots** – Les étiquettes verticales libèrent de l'espace horizontal pour des noms de variables plus longs.  
3. **Business dashboards** – Les étiquettes pivotées évitent le chevauchement du texte dans les graphiques à barres multi‑catégories.

## Considérations de performance

Lors du traitement de classeurs contenant **des centaines de graphiques**, suivez ces meilleures pratiques :

- Chargez le classeur une fois et réutilisez la même instance `Workbook`.  
- Appliquez les changements d'étiquettes dans une boucle, puis appelez `workbook.save` une seule fois pour minimiser les I/O.  
- Utilisez le drapeau `setCalculateFormula` uniquement lorsque vous devez recalculer les formules après les modifications.

## Questions fréquentes

**Q : Puis-je faire pivoter les tick labels à un angle arbitraire ?**  
R : Aspose.Cells prend actuellement en charge les valeurs d'énumération prédéfinies (horizontal, vertical, 45°). Pour des angles personnalisés, vous pouvez combiner la rotation avec `setTickLabelAlignment`.

**Q : L'API fonctionne‑t‑elle avec des fichiers Excel protégés par mot de passe ?**  
R : Oui. Chargez le classeur avec `new Workbook("file.xlsx", new LoadOptions(LoadFormat.XLSX) {{ setPassword("pwd"); }})`.

**Q : Existe‑t‑il une limite au nombre de graphiques que je peux modifier dans un classeur ?**  
R : Aucun plafond strict ; les performances dépendent de la mémoire disponible. Le traitement d'un classeur contenant 1 000 graphiques se termine généralement en moins de 30 secondes sur un serveur standard.

**Q : Comment appliquer une licence temporaire par programme ?**  
R : La classe `License` charge et applique votre fichier de licence Aspose.Cells à l'exécution. Créez un objet `License` et appelez `setLicense("Aspose.Total.Java.lic")` avant toute opération Aspose.Cells.

**Q : Le changement de direction des tick labels affectera‑t‑il les séries de données existantes ?**  
R : Non. L'opération ne modifie que le rendu des étiquettes d'axe ; les valeurs de données restent inchangées.
