# Comment générer des feuilles de calcul en Java avec SmartMarkerProcessor

Si vous avez besoin de **how to generate worksheets** dans un fichier Excel, ce guide vous présente une solution complète, prête à l'emploi. À la fin des deux premières phrases, vous comprendrez comment générer des feuilles de calcul et des feuilles Excel dynamiques à partir d'une collection d'objets, et vous disposerez d'un exemple de code fonctionnel qui automatise la création d'Excel avec un seul appel de méthode.

Créer des feuilles de calcul séparées pour chaque employé, projet ou toute autre entité est une exigence courante lorsque vous devez **populate excel workbook** des données de manière programmatique. Ce tutoriel parcourt chaque étape — de la configuration du modèle à la traitement d'une liste et à l'enregistrement du fichier final — afin que vous puissiez appliquer immédiatement la technique dans vos propres applications Java.

## Ce que vous allez réaliser

* Générer une feuille de calcul principale qui répertorie les informations de haut niveau.  
* Créer **multiple sheets from list** à partir des données, chaque feuille étant nommée automatiquement.  
* **Automate excel creation** sans ajouter manuellement des lignes ou des colonnes.  
* **Populate excel workbook** avec des structures de données riches (objets, cartes, tableaux).  

Prérequis :

* Java 8 ou version supérieure installé.  
* Maven (ou un autre outil de construction) pour ajouter la bibliothèque Aspose.Cells for Java.  
* Une compréhension de base des collections Java.  

> **Conseil pro :** La syntaxe SmartMarker (`${EmployeeMaster}`) fonctionne avec tout type de collection qui implémente `java.util.Collection`. Utilisez‑la pour garder vos modèles propres et faciles à maintenir.

## Comment générer des feuilles de calcul avec SmartMarkerProcessor

Cette section contient le code principal qui rend **how to generate worksheets** sans effort. Nous expliquerons pourquoi chaque ligne est importante, pas seulement ce qu'elle fait.

### Étape 1 : Ajouter la dépendance Aspose.Cells

Si vous utilisez Maven, incluez ce qui suit dans votre `pom.xml`. La bibliothèque fournit la classe `SmartMarkerProcessor` utilisée tout au long de ce guide.

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **Pourquoi :** Aspose.Cells gère les entrées/sorties de fichiers Excel, l'analyse des Smart Markers et la gestion des feuilles en interne, vous permettant de vous concentrer sur les données plutôt que sur les opérations de fichiers de bas niveau.

### Étape 2 : Préparer le modèle Excel

Créez un fichier Excel nommé `EmployeeTemplate.xlsx` contenant une seule cellule avec le placeholder Smart Marker :

| A |
|---|
| `${EmployeeMaster}` |

Lorsque le processeur s'exécute, il remplacera ce placeholder par une **detail sheet** contenant une ligne par employé.

> **Pourquoi :** Le placeholder indique au processeur où injecter les données. Utiliser un modèle séparé conserve votre mise en forme (polices, bordures, largeurs de colonnes) intacte.

### Étape 3 : Définir le modèle de données

Ci‑dessous se trouve une classe `Employee` minimale et une méthode d'aide qui construit une liste d'employés. La liste sera utilisée pour démontrer **multiple sheets from list**.

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **Pourquoi :** Un objet Java simple (POJO) correspond directement aux champs du Smart Marker (`firstName`, `lastName`, `department`). Cela rend **populate excel workbook** simple et sûr du point de vue du typage.

### Étape 4 : Configurer le SmartMarkerProcessor

Nous allons maintenant tout assembler. Le processeur lira le modèle, remplacera le marqueur et créera une nouvelle feuille appelée `EmployeeDetail`.

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

**Explication des lignes clés**

| Line | Reason |
|------|--------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | Charge le modèle qui contient déjà le placeholder Smart Marker. |
| `data.put("EmployeeMaster", employees);` | Lie la liste Java au marqueur `${EmployeeMaster}`. |
| `processor.setDetailSheetNewName("EmployeeDetail");` | Donne à la feuille générée un nom significatif au lieu du `Sheet1` par défaut. |
| `processor.process(wb, data);` | **How to generate worksheets** – le processeur lit le marqueur, crée une nouvelle feuille et la remplit avec des lignes pour chaque `Employee`. |
| `wb.save("EmployeesReport.xlsx");` | Enregistre les **dynamic excel sheets** sur le disque. |

### Étape 5 : Vérifier le résultat

Ouvrez `EmployeesReport.xlsx`. Vous devriez voir deux feuilles de calcul :

1. **Sheet1** – le modèle original (peut être masqué ou supprimé).  
2. **EmployeeDetail** – une **dynamic excel sheet** avec les colonnes `firstName`, `lastName`, `department` et une ligne par employé.

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **Pourquoi c'est important :** Le fichier contient maintenant **multiple sheets from list** sans aucune boucle manuelle ni adressage de cellules. Le moteur Smart Marker se charge de la création des lignes, de la conversion des données et de l'héritage du formatage.

### Étape 6 : Gérer les cas limites

#### Liste de données vide

Si `employees` est vide, le processeur crée toujours la feuille `EmployeeDetail` mais la laisse vide. Vous pouvez empêcher l'ajout de la feuille en vérifiant la taille de la collection avant le traitement :

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### Listes très volumineuses

Pour des milliers de lignes, envisagez d'augmenter l'allocation de mémoire (`-Xmx2g`) ou d'utiliser `processor.setAutoFitRows(false)` pour accélérer le traitement.

#### Nomination personnalisée des feuilles par groupe

Si vous avez besoin d'une feuille séparée pour chaque département, vous pouvez utiliser **multiple detail sheets** :

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

Le placeholder `${department}` est extrait de chaque objet `Employee`, produisant des feuilles comme `Dept_Sales`, `Dept_Marketing`, etc.
