# Importer des objets personnalisés dans Excel avec Aspose.Cells – guide Java

Si vous devez **importer des objets personnalisés** dans une feuille de calcul Excel, ce guide vous accompagne pas à pas dans le processus complet à l’aide d’Aspose.Cells pour Java. Vous verrez comment **importer des données vers Excel**, appliquer un style d’en‑tête en gras et générer un fichier `.xlsx` prêt à être partagé.

L’exportation de données tabulaires depuis Java implique souvent des écritures manuelles cellule par cellule, ce qui est source d’erreurs et difficile à maintenir. En exploitant l’API `importCustomObjects`, vous évitez le code répétitif, conservez votre modèle de données intact et bénéficiez d’un contrôle fin du style.

Dans ce tutoriel, vous allez :

* Construire une liste d’objets Java `Map` qui imite un tableau de données typique.  
* Créer un style d’en‑tête réutilisable (police en gras) avec Aspose.Cells.  
* Importer les objets personnalisés dans une feuille de calcul tout en appliquant le tableau de styles.  
* Enregistrer le classeur sur le disque et vérifier le résultat.

Le seul prérequis est un environnement de développement Java (JDK 8+ recommandé) et la bibliothèque Aspose.Cells pour Java.

---

## Ce dont vous avez besoin

| Exigence | Raison |
|----------|--------|
| JDK 8 ou version ultérieure | Nécessaire pour compiler et exécuter le code Java. |
| Aspose.Cells pour Java (dernière version) | Fournit les API `Workbook`, `Worksheet` et d’importation. |
| IDE ou outil de construction (par ex., Maven, Gradle) | Simplifie la gestion des dépendances et l’exécution. |
| Permission d’écriture sur un dossier pour le fichier de sortie | Le classeur est enregistré sous `ImportWithStyle.xlsx`. |

Ajoutez la dépendance Aspose.Cells à votre `pom.xml` si vous utilisez Maven :

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## Étape 1 : Préparer les objets personnalisés à importer

La première étape consiste à créer une collection qui représente les lignes que vous souhaitez placer dans Excel. Dans cet exemple, nous utilisons une `List<Map<String,Object>>` où chaque map agit comme une ligne avec les noms de colonnes comme clés.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Pourquoi c’est important :**  
`importCustomObjects` attend un tableau d’objets. En utilisant une `Map`, vous conservez les noms de colonnes, ce qui permet à Aspose.Cells de les associer automatiquement aux cellules. Cette approche reflète un `DataTable` typique en .NET ou un `ResultSet` provenant de JDBC, rendant le code réutilisable dans différents projets.

---

## Étape 2 : Définir un style d’en‑tête à appliquer lors de l’importation

Une ligne d’en‑tête claire améliore la lisibilité. Aspose.Cells vous permet de créer un objet `Style`, de définir sa police en gras et de le transmettre via un tableau `ImportTableOptions`.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Pourquoi c’est important :**  
Si vous omettez le tableau de styles, l’en‑tête apparaît avec la police par défaut, ce qui peut ne pas se démarquer. En préparant le style une fois, vous évitez les appels répétitifs pour chaque ligne et gardez la logique d’importation propre.

---

## Étape 3 : Importer les objets personnalisés avec le tableau de styles

Vous combinez maintenant les données et le style, puis appelez `importCustomObjects`. La méthode place les données à partir du coin supérieur gauche (ligne 0, colonne 0) et applique automatiquement le style d’en‑tête.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Pourquoi c’est important :**  
`importCustomObjects` analyse chaque map, crée des colonnes basées sur les clés (`Name`, `Score`) et écrit les valeurs dans les cellules appropriées. L’objet `ImportTableOptions` indique à Aspose.Cells d’utiliser le `styleArray` pour la première ligne, vous offrant ainsi un en‑tête en gras sans code supplémentaire.

---

## Étape 4 : Enregistrer le classeur et vérifier le résultat

Enfin, écrivez le classeur dans un fichier. Le fichier Excel généré contient une ligne d’en‑tête stylisée suivie des lignes de données.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Résultat attendu :**  

| **Name** | **Score** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

Les cellules d’en‑tête (`Name`, `Score`) apparaissent en gras, conformément au style défini à l’Étape 2.

## Variantes courantes et cas limites

| Situation | Ajustement recommandé |
|-----------|-----------------------|
| **Ordre des colonnes différent** | Assurez‑vous que les clés de la `Map` sont insérées dans l’ordre souhaité, ou utilisez un POJO personnalisé avec des champs annotés et un tableau `PropertyDescriptor`. |
| **Ensembles de données volumineux (>10 000 lignes)** | Augmentez le paramètre `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` pour éviter les `OutOfMemoryError`. |
| **Formats numériques personnalisés** | Ajoutez un second `Style` dans `styleArray` pour les lignes de données, par ex., définissez `NumberFormat` à `"0"` pour les scores entiers. |
| **Multiples feuilles de calcul** | Appelez `importCustomObjects` sur chaque feuille cible, en ajustant la ligne/colonne de départ selon les besoins. |
| **Texte d’en‑tête spécifique à la locale** | Remplissez manuellement la ligne d’en‑tête avant l’importation, puis appliquez le style à toute la plage avec `Cells.applyStyle`. |

---

## Astuces avancées pour un export Java robuste vers Excel

* **Réutiliser le classeur temporaire** – Créer un nouveau `Workbook` pour chaque style ajoute du surcoût. Conservez une seule instance si vous avez besoin de plusieurs styles.  
* **Valider les données avant l’importation** – Les valeurs null dans une map deviennent des cellules vides ; vous pouvez les remplacer par des valeurs par défaut en pré‑traitant la liste.  
* **Fermer les ressources** – Bien qu’Aspose.Cells gère la mémoire en interne, appeler explicitement `workbook.dispose()` après l’enregistrement libère rapidement les ressources natives.  
* **Définir `Workbook.setForceFullCalculation(true)`** si votre classeur contient des formules qui doivent être évaluées avant l’enregistrement.
