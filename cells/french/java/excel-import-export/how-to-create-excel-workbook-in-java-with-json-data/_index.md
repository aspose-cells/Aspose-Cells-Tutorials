# Comment créer un classeur Excel en Java avec des données JSON

Si vous devez **create Excel workbook java** les développeurs sont souvent confrontés au défi de charger des données JSON dans une feuille de calcul. Ce guide vous montre comment **populate Excel from JSON**, y compris comment **convert JSON array excel** et **populate workbook from json** de manière propre et réutilisable.

Travailler avec JSON est courant lorsque les services exposent des données via des API REST, et Excel reste le format de référence pour le reporting et l'analyse. À la fin de ce tutoriel, vous disposerez d'un programme Java exécutable qui :

* crée un nouveau classeur Excel,
* lit un tableau JSON (ou toute structure JSON) et écrit ses valeurs dans des cellules,
* enregistre le fichier sur le disque, prêt pour le traitement en aval.

Aucun outil externe n'est requis au-delà de la bibliothèque Aspose.Cells for Java, qui fournit le `SmartMarkerProcessor` utilisé dans le code d'exemple.

## Prérequis

| Prérequis | Raison |
|--------------|--------|
| Kit de développement Java (JDK) ≥ 8 | Nécessaire pour compiler et exécuter l'exemple |
| Maven ou Gradle (optionnel) | Simplifie la gestion des dépendances |
| Aspose.Cells for Java (v23.10 ou ultérieur) | Fournit les classes `Workbook` et `SmartMarkerProcessor` |
| Connaissances de base en JSON et Java I/O | Vous aide à comprendre le flux de données |

Si vous préférez ne pas utiliser d'outil de construction, vous pouvez télécharger le JAR Aspose.Cells depuis le [site Aspose](https://products.aspose.com/cells/java/) et l'ajouter manuellement au classpath de votre projet.

## Étape 1 : Configurer le projet et ajouter la dépendance Aspose.Cells

### Utilisateurs Maven

Ajoutez la dépendance suivante à votre `pom.xml` :

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Utilisateurs Gradle

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

Si vous n'utilisez pas d'outil de construction, placez le JAR téléchargé dans le dossier `libs/` et incluez‑le dans le classpath lors de la compilation :

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## Étape 2 : Créer un nouveau classeur et configurer le processeur SmartMarker

Le `SmartMarkerProcessor` simplifie le mappage des valeurs JSON vers les cellules Excel. En appelant `setArrayAsSingle(true)`, nous indiquons au processeur de traiter un tableau JSON complet comme une valeur unique, ce qui est utile lorsque vous souhaitez que chaque élément occupe sa propre cellule dans une ligne.

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**Pourquoi c'est important :**  
Créer le classeur à l'avance vous fournit une toile vierge. Configurer `setArrayAsSingle(true)` empêche le processeur d'aplatir le tableau en une chaîne unique (par ex., `["A","B","C"]`) et vous permet de contrôler la mise en page manuellement.

## Étape 3 : Définir les données JSON à insérer

Pour ce tutoriel, nous utilisons un tableau JSON simple, mais la même approche fonctionne avec des objets, des tableaux imbriqués ou des structures complexes.

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**Astuce :** Si votre JSON provient d'un fichier ou d'un point d'accès REST, remplacez la chaîne littérale par un `String` lu depuis la source, par ex., `Files.readString(Paths.get("data.json"))`.

## Étape 4 : Traiter le classeur avec les données JSON

Nous laissons maintenant le `SmartMarkerProcessor` mapper le tableau JSON sur la première feuille de calcul. Le comportement par défaut écrit chaque élément dans des cellules successives à partir de `A1`.

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

En coulisses, Aspose.Cells analyse le JSON, crée une table de données temporaire et écrit les valeurs dans la feuille. Comme nous avons défini `ArrayAsSingle` à `true`, les éléments du tableau sont placés horizontalement sur la première ligne.

## Étape 5 : Enregistrer le classeur dans un fichier

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

Lorsque vous exécutez le programme, vous devriez voir un fichier nommé **CreatedFromJson.xlsx** dans votre répertoire de travail. L'ouvrir avec Excel (ou tout visualiseur compatible) affichera :

| A | B | C |
|---|---|---|
| A | B | C | *(les valeurs apparaissent dans les cellules A1, B1, C1)*

### Résultat attendu

```
Workbook saved to CreatedFromJson.xlsx
```

Et la feuille Excel ressemble à :

```

| A | B | C |
+---+---+---+
```

## Étape 6 : Gestion de structures JSON plus complexes (optionnel)

### 6.1 Remplir un classeur à partir d'un objet JSON

Si votre JSON est un objet plutôt qu'un tableau, vous pouvez toujours utiliser `SmartMarkerProcessor`. Par exemple :

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

Le processeur créera des plages nommées (`title`, `month`, `values`) que vous pourrez référencer dans votre modèle Excel à l'aide de Smart Markers tels que `&=title` et `&=values`.

### 6.2 Convertir un tableau JSON imbriqué en liste verticale

Parfois, vous avez besoin que le tableau remplisse une colonne plutôt qu'une ligne. Définissez la cellule de départ manuellement avant le traitement :

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

Les valeurs **A**, **B**, **C** apparaissent maintenant dans les cellules A2, A3, A4 respectivement.

## Pièges courants et comment les éviter

| Problème | Cause | Solution |
|-------|-------|-----|
| **Tableau écrit comme une chaîne unique** | `setArrayAsSingle(false)` (par défaut) | Appelez `processor.setArrayAsSingle(true)` |
| **Fichier introuvable lors de l'enregistrement** | Chemin invalide ou permissions d'écriture manquantes | Utilisez un chemin absolu ou assurez‑vous que le répertoire existe |
| **Erreur d'analyse JSON** | Chaîne JSON mal formée | Validez le JSON avec un outil ou utilisez une bibliothèque comme Jackson pour générer la chaîne |
| **Cellules écrasées involontairement** | Traitement de la même feuille plusieurs fois sans réinitialiser la cellule de départ | Appelez `processor.setStartCell("A1")` avant chaque appel à `process` |

## Astuce pro : réutiliser le classeur comme modèle

Au lieu de commencer à chaque fois avec un classeur vierge, vous pouvez charger un modèle pré‑conçu qui contient déjà des en‑têtes, des formules ou du style :

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

Cette approche combine le raffinement visuel d'un fichier Excel créé à la main avec l'automatisation de **populate workbook from json**.
