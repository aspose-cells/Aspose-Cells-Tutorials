# Jak zmienić kierunek znaczników wykresu w Javie przy użyciu Aspose.Cells

## Wprowadzenie

Zmiana kierunku znaczników wykresu to powszechny sposób na poprawę czytelności wykresów Excel, szczególnie przy długich nazwach kategorii lub gęstych zestawach danych. W tym przewodniku nauczysz się **jak zmienić kierunek znaczników wykresu** przy użyciu Aspose.Cells dla Javy, od instalacji biblioteki po zapisanie finalnego skoroszytu. Omówimy także, dlaczego właściwa rotacja etykiet jest istotna w raportach finansowych, wizualizacjach naukowych i pulpitach biznesowych.

## Szybkie odpowiedzi
- **Jaka biblioteka obsługuje rotację etykiet wykresu?** Aspose.Cells for Java.
- **Który artefakt Maven dodaje tę funkcjonalność?** `com.aspose:aspose-cells`.
- **Czy mogę ustawić kąt etykiety na pionowy?** Tak, użyj `ChartTextDirectionType.VERTICAL`.
- **Czy potrzebna jest licencja do użytku produkcyjnego?** Wymagana jest stała licencja; tymczasowa licencja działa w trybie ewaluacyjnym.
- **Czy API jest kompatybilne z Javą 8 i nowszymi?** Tak, obsługuje Javę 8‑21.

## Co to jest zmiana kierunku znaczników wykresu?
**Zmiana kierunku znaczników wykresu** odnosi się do dostosowania orientacji etykiet znaczników osi kategorii (np. poziome, pionowe lub obrócone), aby lepiej pasowały do obszaru wykresu. Operacja ta jest wykonywana za pomocą metody `setTickLabelDirection` obiektu `ChartAxis` w Aspose.Cells.

## Dlaczego warto używać Aspose.Cells dla Javy do obracania etykiet znaczników?
Aspose.Cells obsługuje **ponad 150 formatów plików**, może radzić sobie z skoroszytami zawierającymi **ponad 500 arkuszy** bez ładowania całego pliku do pamięci oraz wykonuje rotację etykiet w **mniej niż 0,2 sekundy** dla typowych rozmiarów wykresów. Te zmierzone możliwości czynią go niezawodnym wyborem do automatyzacji Excel na poziomie przedsiębiorstwa.

## Wymagania wstępne
- **Aspose.Cells for Java** w wersji 25.3 lub nowszej.
- Zestaw deweloperski Java 8+ oraz preferowane IDE (IntelliJ IDEA, Eclipse itp.).
- Maven lub Gradle do zarządzania zależnościami.
- Tymczasowa lub stała licencja Aspose.Cells (zobacz sekcję licencji poniżej).

## Konfiguracja Aspose.Cells dla Javy
Aby rozpocząć, dodaj zależność Aspose.Cells do swojego pliku budowania.

**Maven**  
```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>25.3</version>
    <classifier>jdk17</classifier>
</dependency>
```

**Gradle**  
```gradle
implementation 'com.aspose:aspose-cells:25.3:jdk17'
```

Klasa `Workbook` jest punktem wejścia dla wszystkich operacji na Excelu. Po dodaniu biblioteki możesz utworzyć instancję skoroszytu w następujący sposób:

## Jak zmienić kierunek znaczników wykresu w Javie?
Aby zmodyfikować orientację etykiet znaczników, musisz załadować docelowy skoroszyt, pobrać konkretny wykres, uzyskać dostęp do jego osi kategorii i wywołać `setTickLabelDirection` z żądanym `ChartTextDirectionType`. Ten ciąg operacji można wykonać w kilku linijkach kodu Java, co ułatwia integrację z istniejącymi przepływami automatyzacji.

1. Załaduj skoroszyt zawierający wykres, który chcesz zmodyfikować.  
2. Pobierz arkusz i obiekt wykresu według jego indeksu.  
3. Uzyskaj dostęp do osi kategorii (`getCategoryAxis()`) i wywołaj `setTickLabelDirection` z żądanym `ChartTextDirectionType`.  
4. Zapisz skoroszyt do nowego pliku.

## Przewodnik implementacji

### Ładowanie skoroszytu i wykresu
Klasa `Workbook` reprezentuje cały plik Excel w pamięci. Klasa `Worksheet` zapewnia dostęp do poszczególnych arkuszy, a klasa `Chart` reprezentuje konkretny wykres.

```java
Workbook workbook = new Workbook("input.xlsx");               // 1️⃣ Load file
Worksheet sheet = workbook.getWorksheets().get(0);            // 2️⃣ First sheet
Chart chart = sheet.getCharts().get(0);                       // 3️⃣ First chart on the sheet
```

### Zmiana kierunku etykiet znaczników
`ChartAxis` kontroluje wszystkie właściwości związane z osią. `ChartTextDirectionType` jest wyliczeniem definiującym orientację.

```java
ChartAxis categoryAxis = chart.getCategoryAxis();            // Access category axis
categoryAxis.setTickLabelDirection(ChartTextDirectionType.HORIZONTAL); // 4️⃣ Set direction
```

- `ChartTextDirectionType.HORIZONTAL` → etykiety odczytywane od lewej do prawej.  
- `ChartTextDirectionType.VERTICAL` → etykiety odczytywane od góry do dołu.  
- `ChartTextDirectionType.ROTATED_45` → etykiety obrócone o 45° (dostępne w nowszych wersjach).

### Zapisywanie skoroszytu
Po dostosowaniu osi, zapisz zmiany:

```java
workbook.save("output.xlsx", SaveFormat.XLSX);
```

## Typowe problemy i rozwiązania
- **Nieprawidłowy indeks wykresu** – Sprawdź, czy wykres istnieje, wywołując `sheet.getCharts().getCount()`.  
- **Licencja nie została zastosowana** – Jeśli widzisz znak wodny, upewnij się, że plik licencji został załadowany przed jakąkolwiek operacją na skoroszycie.  
- **Nieobsługiwana orientacja** – Niektóre starsze typy wykresów obsługują tylko poziome etykiety; zaktualizuj do najnowszej wersji Aspose.Cells, aby uzyskać dostęp do wszystkich wartości wyliczenia.

## Praktyczne zastosowania
Zmiana kierunku etykiet znaczników sprawdza się w sytuacjach, gdy miejsce jest ograniczone:

1. **Finansowe osie czasu** – Poziome etykiety utrzymują czytelność ciągów dat na gęstych wykresach szeregów czasowych.  
2. **Wykresy naukowe** – Pionowe etykiety zwalniają miejsce w poziomie dla dłuższych nazw zmiennych.  
3. **Pulpity biznesowe** – Obrócone etykiety zapobiegają nakładaniu się tekstu w wykresach słupkowych z wieloma kategoriami.

## Rozważania dotyczące wydajności
Podczas przetwarzania skoroszytów z **setkami wykresów**, stosuj następujące najlepsze praktyki:

- Załaduj skoroszyt raz i ponownie używaj tej samej instancji `Workbook`.  
- Zastosuj zmiany etykiet w pętli, a następnie wywołaj `workbook.save` jednorazowo, aby zminimalizować operacje I/O.  
- Używaj flagi `setCalculateFormula` tylko wtedy, gdy musisz przeliczyć formuły po modyfikacjach.

## Najczęściej zadawane pytania

**P: Czy mogę obrócić etykiety znaczników pod dowolnym kątem?**  
O: Aspose.Cells obecnie obsługuje predefiniowane wartości wyliczenia (poziome, pionowe, 45°). Dla własnych kątów możesz połączyć rotację z `setTickLabelAlignment`.

**P: Czy API działa z plikami Excel chronionymi hasłem?**  
O: Tak. Załaduj skoroszyt przy użyciu `new Workbook("file.xlsx", new LoadOptions(LoadFormat.XLSX) {{ setPassword("pwd"); }})`.

**P: Czy istnieje limit liczby wykresów, które mogę zmodyfikować w jednym skoroszycie?**  
O: Nie ma sztywnego limitu; wydajność zależy od dostępnej pamięci. Przetworzenie skoroszytu z 1 000 wykresów zazwyczaj kończy się w mniej niż 30 sekund na standardowym serwerze.

**P: Jak programowo zastosować tymczasową licencję?**  
O: Klasa `License` ładuje i stosuje plik licencji Aspose.Cells w czasie wykonywania. Utwórz obiekt `License` i wywołaj `setLicense("Aspose.Total.Java.lic")` przed jakąkolwiek operacją Aspose.Cells.

**P: Czy zmiana kierunku znaczników wpłynie na istniejące serie danych?**  
O: Nie. Operacja modyfikuje jedynie renderowanie etykiet osi; wartości danych pozostają niezmienione.
