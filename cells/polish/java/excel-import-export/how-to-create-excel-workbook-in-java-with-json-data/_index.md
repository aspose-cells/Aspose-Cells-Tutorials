# Jak utworzyć skoroszyt Excel w Javie z danymi JSON

Jeśli potrzebujesz **create Excel workbook java**, programiści często napotykają wyzwanie ładowania danych JSON do arkusza kalkulacyjnego. Ten przewodnik pokazuje, jak **populate Excel from JSON**, w tym jak **convert JSON array excel** oraz **populate workbook from json** w czysty, powtarzalny sposób.

Praca z JSON jest powszechna, gdy usługi udostępniają dane poprzez REST API, a Excel pozostaje formatem numer 1 do raportowania i analizy. Po zakończeniu tego tutorialu będziesz mieć działający program w Javie, który:

* tworzy nowy skoroszyt Excel,
* odczytuje tablicę JSON (lub dowolną strukturę JSON) i zapisuje jej wartości w komórkach,
* zapisuje plik na dysku gotowy do dalszego przetwarzania.

Nie są wymagane żadne zewnętrzne narzędzia poza biblioteką Aspose.Cells for Java, która dostarcza `SmartMarkerProcessor` używanego w przykładowym kodzie.

## Wymagania wstępne

Przed rozpoczęciem upewnij się, że masz:

| Wymaganie | Powód |
|-----------|-------|
| Java Development Kit (JDK) ≥ 8 | Wymagany do kompilacji i uruchomienia przykładu |
| Maven lub Gradle (opcjonalnie) | Ułatwia zarządzanie zależnościami |
| Aspose.Cells for Java (v23.10 lub nowszy) | Dostarcza klasy `Workbook` i `SmartMarkerProcessor` |
| Podstawowa znajomość JSON i Java I/O | Pomaga zrozumieć przepływ danych |

Jeśli nie chcesz używać narzędzia do budowania, możesz pobrać plik JAR Aspose.Cells ze [strony Aspose](https://products.aspose.com/cells/java/) i dodać go ręcznie do classpath swojego projektu.

## Krok 1: Konfiguracja projektu i dodanie zależności Aspose.Cells

### Użytkownicy Maven

Dodaj następującą zależność do swojego `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Użytkownicy Gradle

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

Jeśli nie używasz narzędzia do budowania, umieść pobrany plik JAR w folderze `libs/` i dołącz go do classpath przy kompilacji:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## Krok 2: Utwórz nowy skoroszyt i skonfiguruj procesor SmartMarker

`SmartMarkerProcessor` upraszcza mapowanie wartości JSON do komórek Excel. Wywołując `setArrayAsSingle(true)` informujemy procesor, aby traktował całą tablicę JSON jako pojedynczą wartość, co jest przydatne, gdy chcesz, aby każdy element zajmował własną komórkę w wierszu.

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**Dlaczego to ważne:**  
Utworzenie skoroszytu z góry daje czyste płótno. Konfiguracja `setArrayAsSingle(true)` zapobiega spłaszczaniu tablicy do jednego łańcucha (np. `["A","B","C"]`) i pozwala ręcznie kontrolować układ.

## Krok 3: Zdefiniuj dane JSON, które chcesz wstawić

W tym tutorialu używamy prostej tablicy JSON, ale to samo podejście działa z obiektami, zagnieżdżonymi tablicami lub bardziej złożonymi strukturami.

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**Wskazówka:** Jeśli Twój JSON pochodzi z pliku lub endpointu REST, zamień dosłowny łańcuch na `String` odczytany ze źródła, np. `Files.readString(Paths.get("data.json"))`.

## Krok 4: Przetwórz skoroszyt przy użyciu danych JSON

Teraz pozwalamy `SmartMarkerProcessor` mapować tablicę JSON na pierwszy arkusz. Domyślne zachowanie zapisuje każdy element w kolejnych komórkach zaczynając od `A1`.

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

Za kulisami Aspose.Cells parsuje JSON, tworzy tymczasową tabelę danych i zapisuje wartości w arkuszu. Ponieważ ustawiliśmy `ArrayAsSingle` na `true`, elementy tablicy są rozmieszczane poziomo w pierwszym wierszu.

## Krok 5: Zapisz skoroszyt do pliku

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

Po uruchomieniu programu powinien pojawić się plik o nazwie **CreatedFromJson.xlsx** w katalogu roboczym. Otwierając go w Excelu (lub innym kompatybilnym podglądzie) zobaczysz:

| A | B | C |
|---|---|---|
| A | B | C | *(wartości pojawiają się w komórkach A1, B1, C1)*

### Oczekiwany wynik

```
Workbook saved to CreatedFromJson.xlsx
```

A arkusz Excel wygląda tak:

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## Krok 6: Obsługa bardziej złożonych struktur JSON (opcjonalnie)

### 6.1 Wypełnianie skoroszytu z obiektu JSON

Jeśli Twój JSON jest obiektem, a nie tablicą, nadal możesz użyć `SmartMarkerProcessor`. Na przykład:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

Procesor utworzy nazwane zakresy (`title`, `month`, `values`), które możesz odwoływać w szablonie Excel przy użyciu Smart Markerów takich jak `&=title` i `&=values`.

### 6.2 Konwersja zagnieżdżonej tablicy JSON na listę pionową

Czasami potrzebujesz, aby tablica wypełniła kolumnę zamiast wiersza. Ustaw początkową komórkę ręcznie przed przetworzeniem:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

Teraz wartości **A**, **B**, **C** pojawiają się w komórkach A2, A3, A4 odpowiednio.

## Typowe problemy i jak ich unikać

| Problem | Przyczyna | Rozwiązanie |
|---------|-----------|-------------|
| **Tablica zapisana jako pojedynczy łańcuch** | `setArrayAsSingle(false)` (domyślnie) | Wywołaj `processor.setArrayAsSingle(true)` |
| **Plik nie został znaleziony przy zapisie** | Nieprawidłowa ścieżka lub brak uprawnień do zapisu | Użyj ścieżki bezwzględnej lub upewnij się, że katalog istnieje |
| **Błąd parsowania JSON** | Niepoprawny format JSON | Zweryfikuj JSON przy pomocy narzędzia lub użyj biblioteki takiej jak Jackson do generowania łańcucha |
| **Komórki nadpisane niezamierzenie** | Przetwarzanie tego samego arkusza wielokrotnie bez resetowania komórki startowej | Wywołaj `processor.setStartCell("A1")` przed każdym wywołaniem `process` |

## Pro tip: ponowne użycie skoroszytu jako szablonu

Zamiast za każdym razem zaczynać od pustego skoroszytu, możesz wczytać wcześniej przygotowany szablon, który już zawiera nagłówki, formuły lub formatowanie:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

To podejście łączy wizualny polish ręcznie przygotowanego pliku Excel z automatyzacją **populate workbook from json**.
