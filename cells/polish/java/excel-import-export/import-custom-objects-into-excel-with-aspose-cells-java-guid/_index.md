# Importowanie niestandardowych obiektów do Excela przy użyciu Aspose.Cells – przewodnik Java

Jeśli potrzebujesz **importować niestandardowe obiekty** do arkusza Excel, ten przewodnik przeprowadzi Cię przez cały proces przy użyciu Aspose.Cells for Java. Zobaczysz, jak **importować dane do Excela**, zastosować pogrubiony styl nagłówka i wygenerować gotowy do udostępnienia plik `.xlsx`.

Eksportowanie danych tabelarycznych z Javy często wymaga ręcznego zapisywania komórek po jednej, co jest podatne na błędy i trudne w utrzymaniu. Korzystając z API `importCustomObjects` unikasz kodu szablonowego, zachowujesz integralność modelu danych i uzyskujesz precyzyjną kontrolę nad stylizacją.

W tym tutorialu:

* Zbudować listę obiektów Java `Map`, które naśladują typową tabelę danych.
* Utworzyć wielokrotnego użytku styl nagłówka (pogrubiona czcionka) przy użyciu Aspose.Cells.
* Zaimportować niestandardowe obiekty do arkusza, jednocześnie stosując tablicę stylów.
* Zapisać skoroszyt na dysku i zweryfikować wynik.

Jedynym wymogiem wstępnym jest środowisko programistyczne Java (zalecane JDK 8+) oraz biblioteka Aspose.Cells for Java.

| Wymaganie | Powód |
|-----------|-------|
| JDK 8 lub nowszy | Wymagany do kompilacji i uruchomienia kodu Java. |

| IDE lub narzędzie budujące (np. Maven, Gradle) | Ułatwia zarządzanie zależnościami i uruchamianie. |

```xml
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## Krok 1: Przygotowanie niestandardowych obiektów do importu

Pierwszy krok to stworzenie kolekcji, która reprezentuje wiersze, które chcesz umieścić w Excelu. W tym przykładzie używamy `List<Map<String,Object>>`, gdzie każda mapa działa jak wiersz z nazwami kolumn jako kluczami.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Dlaczego to ważne:**  
`importCustomObjects` oczekuje tablicy obiektów. Używając `Map`, zachowujesz nazwy kolumn, co pozwala Aspose.Cells automatycznie mapować je do komórek. Takie podejście odzwierciedla typowy `DataTable` w .NET lub `ResultSet` z JDBC, co czyni kod wielokrotnego użytku w różnych projektach.

---

## Krok 2: Definiowanie stylu nagłówka do zastosowania przy imporcie

Wyraźny wiersz nagłówka poprawia czytelność. Aspose.Cells pozwala utworzyć obiekt `Style`, ustawić czcionkę na pogrubioną i przekazać go za pomocą tablicy `ImportTableOptions`.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Dlaczego to ważne:**  
Jeśli pominiesz tablicę stylów, nagłówek pojawi się domyślną czcionką, co może nie wyróżniać się wystarczająco. Przygotowując styl raz, unikniesz powtarzalnych wywołań dla każdego wiersza i utrzymasz czystą logikę importu.

---

## Krok 3: Importowanie niestandardowych obiektów z tablicą stylów

Teraz łączysz dane i styl, a następnie wywołujesz `importCustomObjects`. Metoda umieszcza dane zaczynając od lewego górnego rogu (wiersz 0, kolumna 0) i automatycznie stosuje styl nagłówka.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Dlaczego to ważne:**  
`importCustomObjects` analizuje każdą mapę, tworzy kolumny na podstawie kluczy (`Name`, `Score`) i zapisuje wartości w odpowiednich komórkach. Obiekt `ImportTableOptions` informuje Aspose.Cells, aby użył `styleArray` dla pierwszego wiersza, dając Ci pogrubiony nagłówek bez dodatkowego kodu.

---

## Krok 4: Zapis skoroszytu i weryfikacja wyniku

Na koniec zapisujemy skoroszyt do pliku. Wygenerowany plik Excel zawiera stylizowany wiersz nagłówka, po którym następują wiersze danych.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Oczekiwany wynik:**  

| **Nazwa** | **Wynik** |
|-----------|-----------|
| Alice     | 95        |
| Bob       | 82        |

Komórki nagłówka (`Name`, `Score`) pojawiają się pogrubioną czcionką, zgodnie ze stylem zdefiniowanym w Kroku 2.

## Typowe warianty i przypadki brzegowe

| Sytuacja | Zalecana korekta |
|----------|------------------|
| **Inna kolejność kolumn** | Upewnij się, że klucze w `Map` są wstawiane w żądanej kolejności, lub użyj własnego POJO z oznaczonymi polami i tablicą `PropertyDescriptor`. |
| **Duże zestawy danych (>10 000 wierszy)** | Zwiększ `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)`, aby uniknąć `OutOfMemoryError`. |
| **Niestandardowe formaty liczb** | Dodaj drugi `Style` w `styleArray` dla wierszy danych, np. ustaw `NumberFormat` na `"0"` dla całkowitych wyników. |
| **Wiele arkuszy** | Wywołaj `importCustomObjects` na każdym docelowym arkuszu, dostosowując wiersz/kolumnę początkową w razie potrzeby. |
| **Tekst nagłówka specyficzny dla lokalizacji** | Wypełnij wiersz nagłówka ręcznie przed importem, a następnie zastosuj styl do całego zakresu używając `Cells.applyStyle`. |

## Pro tipy dla solidnego eksportu Java do Excela

* **Ponowne użycie tymczasowego skoroszytu** – Tworzenie nowego `Workbook` dla każdego stylu zwiększa obciążenie. Zachowaj jedną instancję, jeśli potrzebujesz wielu stylów.  
* **Waliduj dane przed importem** – Wartości null w mapie stają się pustymi komórkami; możesz je zastąpić wartościami domyślnymi, przetwarzając listę wcześniej.  
* **Zamykaj zasoby** – Chociaż Aspose.Cells zarządza pamięcią wewnętrznie, wywołanie `workbook.dispose()` po zapisaniu natychmiast zwalnia zasoby natywne.  
* **Ustaw `Workbook.setForceFullCalculation(true)`**, jeśli Twój skoroszyt zawiera formuły, które muszą być obliczone przed zapisem.
