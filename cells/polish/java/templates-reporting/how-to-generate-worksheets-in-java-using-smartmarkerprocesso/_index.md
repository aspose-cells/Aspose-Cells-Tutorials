# Jak generować arkusze w Java przy użyciu SmartMarkerProcessor

Jeśli potrzebujesz **how to generate worksheets** w pliku Excel, ten przewodnik pokaże Ci kompletną, gotową do uruchomienia rozwiązanie. Po przeczytaniu pierwszych dwóch zdań zrozumiesz, jak generować arkusze i dynamiczne arkusze Excel z kolekcji obiektów oraz będziesz mieć działający przykład kodu, który automatyzuje tworzenie Excela jednym wywołaniem metody.

Tworzenie oddzielnych arkuszy dla każdego pracownika, projektu lub innego podmiotu jest powszechnym wymaganiem, gdy trzeba **populate excel workbook** dane programowo. Ten tutorial przechodzi przez każdy krok — od przygotowania szablonu po przetworzenie listy i zapisanie finalnego pliku — abyś mógł od razu zastosować tę technikę w swoich aplikacjach Java.

## Co osiągniesz

* Wygeneruj główny arkusz, który wymienia informacje na wysokim poziomie.  
* Utwórz dane **multiple sheets from list**, każdy arkusz automatycznie nazwany.  
* **Automate excel creation** bez ręcznego dodawania wierszy lub kolumn.  
* **Populate excel workbook** przy użyciu złożonych struktur danych (obiekty, mapy, tablice).  

Wymagania wstępne:

* Zainstalowany Java 8 lub nowszy.  
* Maven (lub inny system budowania), aby dodać bibliotekę Aspose.Cells for Java.  
* Podstawowa znajomość kolekcji Java.  

> **Pro tip:** Składnia SmartMarker (`${EmployeeMaster}`) działa z każdym typem kolekcji implementującym `java.util.Collection`. Używaj jej, aby utrzymać szablony czyste i łatwe w utrzymaniu.

## Jak generować arkusze przy użyciu SmartMarkerProcessor

Ta sekcja zawiera podstawowy kod, który sprawia, że **how to generate worksheets** jest prosty. Wyjaśnimy, dlaczego każda linia ma znaczenie, nie tylko co robi.

### Krok 1: Dodaj zależność Aspose.Cells

Jeśli używasz Maven, dołącz poniższy fragment do swojego `pom.xml`. Biblioteka udostępnia klasę `SmartMarkerProcessor` używaną w całym przewodniku.

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **Why:** Aspose.Cells obsługuje operacje I/O plików Excel, parsowanie Smart Marker i zarządzanie arkuszami wewnętrznie, pozwalając Ci skupić się na danych, a nie na niskopoziomowych operacjach na plikach.

### Krok 2: Przygotuj szablon Excel

Utwórz plik Excel o nazwie `EmployeeTemplate.xlsx` z jedną komórką zawierającą placeholder Smart Marker:

| A |
|---|
| `${EmployeeMaster}` |

Gdy procesor zostanie uruchomiony, zastąpi ten placeholder **detail sheet**, który zawiera jeden wiersz na pracownika.

> **Why:** Placeholder informuje procesor, gdzie wstrzyknąć dane. Użycie osobnego szablonu zachowuje formatowanie (czcionki, obramowania, szerokości kolumn).

### Krok 3: Zdefiniuj model danych

Poniżej znajduje się minimalna klasa `Employee` oraz metoda pomocnicza budująca listę pracowników. Lista zostanie użyta do demonstracji **multiple sheets from list**.

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **Why:** Zwykły obiekt Java (POJO) mapuje się bezpośrednio na pola Smart Marker (`firstName`, `lastName`, `department`). Dzięki temu **populate excel workbook** jest proste i typowo‑bezpieczne.

### Krok 4: Skonfiguruj SmartMarkerProcessor

Teraz łączymy wszystko razem. Procesor odczyta szablon, zastąpi marker i utworzy nowy arkusz o nazwie `EmployeeDetail`.

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

Wyjaśnienie kluczowych linii

| Line | Reason |
|------|--------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | Ładuje szablon, który już zawiera placeholder Smart Marker. |
| `data.put("EmployeeMaster", employees);` | Łączy listę Java z markerem `${EmployeeMaster}`. |
| `processor.setDetailSheetNewName("EmployeeDetail");` | Nadaje wygenerowanemu arkuszowi znaczącą nazwę zamiast domyślnego `Sheet1`. |
| `processor.process(wb, data);` | **How to generate worksheets** – procesor odczytuje marker, tworzy nowy arkusz i wypełnia go wierszami dla każdego `Employee`. |
| `wb.save("EmployeesReport.xlsx");` | Zapisuje **dynamic excel sheets** na dysku. |

### Krok 5: Zweryfikuj wynik

Otwórz `EmployeesReport.xlsx`. Powinieneś zobaczyć dwa arkusze:

1. **Sheet1** – oryginalny szablon (może być ukryty lub usunięty).  
2. **EmployeeDetail** – **dynamic excel sheet** z kolumnami `firstName`, `lastName`, `department` oraz jednym wierszem na pracownika.

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **Why this matters:** Plik teraz zawiera **multiple sheets from list** bez ręcznego iterowania czy adresowania komórek. Silnik Smart Marker zajmuje się tworzeniem wierszy, konwersją danych i dziedziczeniem formatowania.

### Krok 6: Obsłuż przypadki brzegowe

#### Pusta lista danych

Jeśli `employees` jest pusty, procesor nadal tworzy arkusz `EmployeeDetail`, ale pozostawia go pustym. Możesz zapobiec dodaniu arkusza, sprawdzając rozmiar kolekcji przed przetworzeniem:

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### Bardzo duże listy

Dla tysięcy wierszy rozważ zwiększenie przydziału pamięci (`-Xmx2g`) lub użycie `processor.setAutoFitRows(false)`, aby przyspieszyć przetwarzanie.

#### Niestandardowe nazewnictwo arkuszy według grupy

Jeśli potrzebujesz osobnego arkusza dla każdego działu, możesz użyć **multiple detail sheets**:

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

Placeholder `${department}` jest pobierany z każdego obiektu `Employee`, tworząc arkusze takie jak `Dept_Sales`, `Dept_Marketing` itp.
