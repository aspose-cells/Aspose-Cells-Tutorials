# Tworzenie arkuszy szczegółowych w Javie z użyciem smart markers Aspose.Cells

Jeśli potrzebujesz **tworzyć arkusze szczegółowe** w aplikacji Java, ten tutorial pokazuje, jak zrobić to przy użyciu smart markers Aspose.Cells. Zobaczysz kompletny, działający przykład, który **java create worksheets**, pobiera **sheet name from field** i **process data source** w zaledwie kilku linijkach kodu.

Poradnik obejmuje wszystko, od konfiguracji projektu po zapisanie finalnego skoroszytu, dzięki czemu możesz skopiować‑wkleić rozwiązanie do własnego projektu i natychmiast je dostosować. Nie jest wymagana żadna zewnętrzna dokumentacja — wszystko, czego potrzebujesz, znajduje się tutaj.

## Czego się nauczysz

* Jak **używać smart markers** do duplikowania szablonu arkusza dla każdego wiersza w głównym zestawie danych.  
* Jak dynamicznie ustawiać nazwę każdego nowego arkusza na podstawie wartości pola (np. `Order_123`).  
* Jak dostarczyć kolekcję Java jako **process data source** dla silnika smart marker.  
* Wskazówki dotyczące obsługi przypadków brzegowych, takich jak puste dane, specjalne znaki w nazwach arkuszy oraz kwestie wydajności przy dużych zestawach danych.

### Prerequisites

| Wymaganie | Powód |
|-------------|--------|
| Java 8 or higher | Aspose.Cells for Java supports Java 8+. |
| Maven or Gradle build system | Simplifies adding the Aspose.Cells dependency. |
| Basic knowledge of Java collections | Needed to build the data source for the smart markers. |
| A template Excel file (`Template.xlsx`) with a placeholder smart marker in cell **A1** | Szablon pliku Excel (`Template.xlsx`) z placeholderem smart marker w komórce **A1**. The template drives the detail‑sheet generation. |

> **Wskazówka:** Trzymaj plik szablonu skoroszytu w folderze `resources` projektu, aby był pakowany z Twoim plikiem JAR.

## Krok 1: Dodaj Aspose.Cells do swojego projektu (java create worksheets)

Jeśli używasz **Mavena**, dodaj następującą zależność do `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

Dla **Gradle**, umieść tę linię w `build.gradle`:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

Te linie udostępniają API **java create worksheets** w czasie kompilacji.

## Krok 2: Załaduj szablon skoroszytu

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*Dlaczego to ważne:* Obiekt `Workbook` jest punktem wejścia dla wszystkich operacji Excel. Załadowanie szablonu zapewnia, że zaczynasz od prawidłowego układu i wszelkiego wstępnie zdefiniowanego formatowania.

## Krok 3: Wstaw smart marker, który tworzy nowy arkusz dla każdego wiersza głównego (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

Składnia `${Orders:DetailSheetNewName=Order_${OrderId}}` jest rdzeniem **use smart markers**. Wykonuje trzy rzeczy:

1. Iteruje po kolekcji `Orders`.  
2. Tworzy **nowy arkusz** dla każdego elementu.  
3. Ustawia **sheet name from field** `OrderId` (z prefiksem `Order_`).

## Krok 4: Przygotuj źródło danych (process data source)

Poniżej znajduje się minimalny przykład używający `List<Map<String, Object>>`. Zastąp go swoim rzeczywistym źródłem danych — wierszami z bazy danych, deserializacją JSON itp.

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*Dlaczego to ważne:* Krok **process data source** wiąże Twoją kolekcję Java z silnikiem smart marker. Klucz (`"Orders"`) musi dokładnie odpowiadać nazwie smart marker.

## Krok 5: Przetwórz smart markers (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

Gdy uruchomiony jest `process`, Aspose.Cells odczytuje kolekcję `Orders`, klonuje szablon arkusza dla każdego wpisu i zmienia nazwę każdego arkusza zgodnie z polem `OrderId`. To jest sedno użycia **process data source**.

## Krok 6: Zapisz skoroszyt z zduplikowanymi arkuszami szczegółowymi

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

Po wykonaniu znajdziesz plik `DuplicatedDetailSheets.xlsx` zawierający:

* `Sheet1` – oryginalny szablon (niezmieniony).  
* `Order_101` – arkusz szczegółowy dla pierwszego zamówienia.  
* `Order_102` – arkusz szczegółowy dla drugiego zamówienia.

### Oczekiwany wynik (fragment)

| Nazwa arkusza | A1 (smart marker) | Zawartość wynikowa |
|------------|-------------------|-------------------|
| Order_101  | `${Orders:...}`   | Wypełniony danymi z `order1` |
| Order_102  | `${Orders:...}`   | Wypełniony danymi z `order2` |

Otwórz plik w Excelu, aby zweryfikować, że każdy arkusz ma prawidłową nazwę i zawiera wiersze danych.

## Obsługa typowych wariantów i przypadków brzegowych

### Puste źródło danych

Jeśli `orders` jest pusty, procesor smart marker nie tworzy **nowych arkuszy**. Aby uniknąć pustego skoroszytu, dodaj zabezpieczenie:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### Specjalne znaki w nazwach arkuszy

Nazwy arkuszy Excel nie mogą zawierać znaków `\ / ? * [ ] :`. Oczyść pole przed użyciem:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### Duże zestawy danych

Dla tysięcy wierszy rozważ zwiększenie pamięci JVM (`-Xmx2g`) oraz wywoływanie `workbook.calculateFormula()` dopiero po wygenerowaniu wszystkich arkuszy, aby poprawić wydajność.
