# Jak wyeksportować dane do Excela przy użyciu szablonu C# – przewodnik krok po kroku

Jeśli potrzebujesz **wyeksportować dane do Excela** z aplikacji .NET, ten przewodnik przedstawia kompletną, działającą od początku do końca rozwiązanie. Ładując szablon Excela, który już zawiera znaczniki Smart Marker, możesz **zautomatyzować generowanie plików Excel** i uzyskać elegancki **raport pracowników w Excelu** bez pisania kodu komórka po komórce.

Zobaczysz, jak:

* Załadować szablon Excela (`load excel template`), który definiuje układ.
* Przekazać listę obiektów pracowników do szablonu.
* Wygenerować finalny skoroszyt i zapisać go jako `output.xlsx`.

Wszystkie niezbędne fragmenty kodu są dołączone, więc możesz je od razu skopiować, wkleić i uruchomić.

## Prerequisites

* .NET 6.0 lub nowszy (kod działa również z .NET Framework 4.7+).  
* Pakiet NuGet **Aspose.Cells for .NET** – dostarcza klasy `Workbook`, `SmartMarkerProcessor` oraz obsługę Smart Marker.  
* Folder o nazwie `YOUR_DIRECTORY` zawierający plik `template.xlsx`. Szablon powinien mieć znaczniki Smart Marker, takie jak `&=EmployeeList.Name`, w komórkach, w których mają pojawić się dane.

> **Pro tip:** Umieść szablon w tym samym folderze projektu i ustaw jego właściwość *Copy to Output Directory* na *Copy always*, aby ścieżka była prawidłowo rozwiązywana podczas debugowania.

## Full source code

```csharp
using System;
using System.Collections.Generic;
using Aspose.Cells;

namespace ExcelExportDemo
{
    // Simple POCO that represents an employee record
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Step 1: Load the Excel template that contains Smart Marker tags
            string templatePath = @"YOUR_DIRECTORY\template.xlsx";
            Workbook wb = new Workbook(templatePath);

            // Step 2: Prepare a data source – a list of employee objects
            List<Employee> employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Step 3: Create a SmartMarkerProcessor instance
            SmartMarkerProcessor sp = new SmartMarkerProcessor();

            // Step 4: Apply the employee data to the workbook using the processor
            // The tag &amp;=EmployeeList.Name in the template will be replaced with each employee's name,
            // and &amp;=EmployeeList.Position will be replaced with the corresponding position.
            sp.Process(wb, employeeList);

            // Step 5: Save the populated workbook
            string outputPath = @"YOUR_DIRECTORY\output.xlsx";
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

### Co robi kod

| Krok | Dlaczego jest ważny | Kluczowe linie |
|------|---------------------|----------------|
| **Load Excel template** | Ponowne użycie gotowego układu oszczędza czas i zapewnia spójny styl. | `Workbook wb = new Workbook(templatePath);` |
| **Prepare data source** | Smart Markery działają z dowolną kolekcją `IEnumerable`; tutaj używamy listy `Employee`. | `List<Employee> employeeList = …` |
| **Create processor** | `SmartMarkerProcessor` analizuje szablon, znajduje znaczniki i wstawia dane. | `SmartMarkerProcessor sp = new SmartMarkerProcessor();` |
| **Process data** | Procesor zamienia każdy znacznik Smart Marker na odpowiadającą wartość właściwości. | `sp.Process(wb, employeeList);` |
| **Save workbook** | Finalny plik może zostać wysłany do użytkownika, zapisany na serwerze lub dołączony do e‑maila. | `wb.Save(outputPath);` |

Wynikiem jest plik **raport pracowników w Excelu**, w którym każdy wiersz zawiera imię i stanowisko pracownika, dokładnie tam, gdzie w szablonie umieszczono znaczniki.

## Load an Excel template

Kiedy `load excel template` przy pomocy `new Workbook(path)`, Aspose.Cells odczytuje cały skoroszyt — łącznie ze stylami, formułami i znacznikami Smart Marker. Takie podejście jest lepsze niż tworzenie skoroszytu od zera, ponieważ:

* **Kontrola projektu** – Projektanci mogą formatować nagłówki, dodawać logo firmy i ustawiać szerokość kolumn bez ingerencji w kod.
* **Wersjonowanie** – Aktualizacja szablonu nie wymaga rekompilacji aplikacji.
* **Lokalizacja** – Można utrzymywać osobne pliki szablonów dla różnych języków.

Jeśli wolisz czyste rozwiązanie .NET bez bibliotek firm trzecich, możesz użyć **ClosedXML** lub **EPPlus**, ale brakuje im wbudowanej obsługi Smart Marker, co oznacza konieczność pisania pętli kopiujących dane komórka po komórce.

## Automate Excel generation with Smart Markers

Smart Markery to znaczniki wyglądające jak `&=Collection.Property`. Gdy procesor zostaje uruchomiony:

* Iteruje po kolekcji (`employeeList` w naszym przykładzie).
* Dla każdego elementu zapisuje wartość właściwości w odpowiedniej komórce.
* Automatycznie rozszerza wiersze lub kolumny w razie potrzeby.

Ten mechanizm **automatyzuje generowanie Excela** i eliminuje ręczną logikę iteracji. Ten sam wzorzec działa dla dowolnej struktury danych — zamówień, faktur, list inwentarzowych itp.

### Common variations

| Wariant | Jak zaimplementować |
|-----------|----------------------|
| **Multiple collections** | Dodaj kolejne listy (np. `List<Department>`) i odwołuj się do nich innymi znacznikami, takimi jak `&=DepartmentList.Name`. |
| **Nested collections** | Użyj notacji kropkowej: `&=EmployeeList.Projects.ProjectName`, gdzie `Projects` jest właściwością kolekcji wewnątrz `Employee`. |
| **Conditional formatting** | Umieść regułę formatowania warunkowego w szablonie; procesor zachowa ją dla wygenerowanych wierszy. |

## Create an employee report Excel

Określenie **employee report Excel** opisuje typowy scenariusz biznesowy: menedżer potrzebuje wydrukowalnej listy pracowników. Wstawiając znaczniki Smart Marker bezpośrednio do szablonu, otrzymujesz:

* Wiersz nagłówka z pogrubioną czcionką i kolorem tła.
* Automatycznie dopasowane szerokości kolumn w zależności od danych.
* Opcjonalne wiersze podsumowujące (np. liczba pracowników), które możesz obliczyć standardowymi formułami Excela.

Jeśli potrzebujesz dodać wiersz podsumowujący, po prostu umieść formułę taką jak `=COUNTA(A2:A100)` w szablonie; procesor jej nie zmieni.

## Generate Excel template C# – best practices

Podczas pisania kodu **generate Excel template C#** pamiętaj o następujących wytycznych:

1. **Rozdziel odpowiedzialności** – Trzymaj ładowanie szablonu, przygotowanie danych i przetwarzanie w oddzielnych metodach. Ułatwia to testy jednostkowe.
2. **Waliduj wejście** – Upewnij się, że plik szablonu istnieje, a kolekcja danych nie jest nullem przed wywołaniem `Process`.
3. **Zwalniaj zasoby** – Choć Aspose.Cells zarządza pamięcią, warto objąć `Workbook` w blok `using`, gdy pracujesz z dużymi plikami.
4. **Obsługa wyjątków** – Złap `Exception` wokół `sp.Process`, aby wyświetlić problemy, takie jak niezgodne nazwy znaczników.

```csharp
static Workbook LoadTemplate(string path)
{
    if (!File.Exists(path))
        throw new FileNotFoundException($"Template not found: {path}");
    return new Workbook(path);
}
```

## Troubleshooting common issues

| Objaw | Prawdopodobna przyczyna | Rozwiązanie |
|-------|--------------------------|-------------|
| Brak danych po przetworzeniu | Znaczniki Smart Marker są źle napisane lub umieszczone w scalonych komórkach. | Sprawdź, czy znaczniki mają dokładną składnię `&=Collection.Property` i nie znajdują się w połączonych obszarach. |
| Plik wyjściowy jest pusty lub uszkodzony | Skoroszyt został zapisany przed zakończeniem przetwarzania. | Upewnij się, że `sp.Process` uruchamia się **przed** `wb.Save`. |
| Duża lista pracowników spowalnia generowanie | Darmowa wersja Aspose.Cells może mieć limity wydajności. | Przejdź na wersję licencjonowaną lub przetwarzaj dane w partiach. |
| Niepoprawna ścieżka szablonu | Ścieżka względna rozwiązuje się do innego folderu w czasie wykonywania. | Użyj `Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "template.xlsx")` lub ustaw właściwość pliku *Copy to Output Directory*. |

## Complete example recap

Poniżej znajduje się cały program w jednym bloku, gotowy do skopiowania i wklejenia:

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Load the template
            string templatePath = Path.Combine("YOUR_DIRECTORY", "template.xlsx");
            Workbook wb = new Workbook(templatePath);

            // Prepare data
            var employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Process Smart Markers
            var sp = new SmartMarkerProcessor();
            sp.Process(wb, employeeList);

            // Save the result
            string outputPath = Path.Combine("YOUR_DIRECTORY", "output.xlsx");
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

Uruchomienie tego programu tworzy plik **employee report Excel**, który możesz wysłać e‑mailem, wydrukować lub poddać dalszej obróbce.
