# Jak utworzyć skoroszyt Excel w C# z niestandardowym formatowaniem i zapisać jako XLSX

Jeśli potrzebujesz **create Excel workbook C#**, które importuje dane, stosuje niestandardowy format liczbowy i zmienia kolor czcionki komórki, ten tutorial pokaże Ci dokładnie, jak to zrobić. Otrzymasz gotowy do uruchomienia przykład, który w kilka sekund wygeneruje sformatowany plik `StyleArrayImport.xlsx`.

Praca z Excelem w C# często wiąże się z powtarzalnymi ręcznymi krokami — definiowaniem formatów, stosowaniem kolorów i pamiętaniem o prawidłowym zapisie pliku. Po zakończeniu tego przewodnika zautomatyzujesz wszystkie te zadania, dzięki czemu będziesz mógł skupić się na danych, a nie na interfejsie użytkownika.

Nauczysz się jak:

* importować `DataTable` do arkusza,
* używać `StyleArray` do **apply custom number format** i **change cell font color**,
* **save workbook as XLSX** jednym wywołaniem metody,
* oraz zweryfikować, że **format imported data excel** wygląda dokładnie tak, jak zamierzono.

Jedynym wymogiem wstępnym jest odwołanie do biblioteki **Aspose.Cells for .NET** (lub dowolnego kompatybilnego API, które udostępnia `Workbook`, `Worksheet` i `StyleArray`). Kod jest przeznaczony dla .NET 6+, ale wcześniejsze wersje działają po niewielkich modyfikacjach.

## Step 1: Prepare the sample DataTable

Krok 1: Przygotuj przykładową DataTable

Najpierw utwórz `DataTable`, który naśladuje dane, które normalnie pobierałbyś z bazy danych lub innego źródła. Tabela zawiera kolumnę **Name** (string) oraz kolumnę **Amount** (decimal), którą sformatujemy później.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Dlaczego to ważne:** Użycie `DataTable` pozwala zachować logikę importu niezależną od źródła danych, co jest powszechnym wzorcem przy generowaniu raportów z baz danych, plików CSV lub API.

## Step 2: Define a StyleArray to **apply custom number format** and **change cell font color**

Krok 2: Zdefiniuj StyleArray, aby **apply custom number format** i **change cell font color**

`StyleArray` pozwala spakować instrukcje formatowania, które zostaną zastosowane do każdej komórki importowanej z `DataTable`. W tym przykładzie:

* ustaw `Number` na `#,##0.00` – typowy format księgowy z separatorem tysięcy,
* ustaw `FontColor` na `Color.Blue` – aby liczby wyróżniały się.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**Dlaczego używać StyleArray?** Stosowanie stylu w czasie importu eliminuje potrzebę drugiego przejścia po arkuszu, co zwiększa wydajność przy dużych zestawach danych.

---

## Step 3: **Create Excel workbook C#** – instantiate Workbook and get the first Worksheet

Krok 3: **Create Excel workbook C#** – utwórz instancję Workbook i pobierz pierwszy Worksheet

Teraz tworzymy pusty skoroszyt i uzyskujemy referencję do pierwszego arkusza (indeks 0). Ten arkusz staje się miejscem docelowym dla naszych importowanych danych.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Wyjaśnienie:** `Workbook` reprezentuje cały plik Excel, natomiast `Worksheet` reprezentuje pojedynczą zakładkę. Domyślny skoroszyt zawiera jeden arkusz, co wystarcza dla większości prostych raportów.

---

## Step 4: Import the DataTable using the **StyleArray** to **format imported data excel**

Krok 4: Importuj DataTable używając **StyleArray**, aby **format imported data excel**

Metoda `ImportDataTable` kopiuje wiersze i kolumny tabeli do arkusza, zaczynając od komórki `A1` (wiersz 0, kolumna 0). Argument `true` mówi metodzie, aby uwzględniła nagłówki kolumn. Ponieważ przekazujemy `styleArray`, każda zaimportowana komórka otrzymuje niestandardowy format liczbowy i kolor czcionki.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**Co się dzieje w tle:** Aspose.Cells iteruje po każdym wierszu, zapisuje wartość, a następnie stosuje styl zdefiniowany w `styleArray`. Liczby wyświetlane są z przecinkami i dwoma miejscami po przecinku, a tekst jest renderowany na niebiesko.

---

## Step 5: **Save workbook as XLSX** – write the file to disk

Krok 5: **Save workbook as XLSX** – zapisz plik na dysku

Na koniec zapisujemy skoroszyt do pliku `.xlsx`. Ścieżkę możesz zmienić na dowolny zapisywalny katalog na swoim komputerze.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Weryfikacja wyniku:** Otwórz wygenerowany plik w Excelu. Powinieneś zobaczyć trzy wiersze danych, kolumnę **Amount** sformatowaną z przecinkami, dwoma miejscami po przecinku i wyświetlaną niebieską czcionką. To potwierdza, że krok **format imported data excel** zakończył się sukcesem.

## Full Working Example

Pełny działający przykład

Skopiuj cały poniższy blok do nowego projektu konsolowego i uruchom go. Nie jest wymagany dodatkowy kod.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Oczekiwany wynik w konsoli:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

Otwórz plik i zweryfikuj, że kolumna **Amount** wyświetla wartości takie jak `1,234.56` niebieską czcionką.

## Common Questions & Edge Cases

Często zadawane pytania i przypadki brzegowe

| Pytanie | Odpowiedź |
|----------|--------|
| *Czy mogę zastosować różne formaty do poszczególnych kolumn?* | Tak. Po zaimportowaniu pobierz obiekt `Style` kolumny (`worksheet.Cells.Columns[1].Style`) i ustaw inny `Number` lub `FontColor`. |
| *Co zrobić, jeśli muszę sformatować daty zamiast liczb?* | Ustaw `styleArray.Number = "mm-dd-yyyy"` i opcjonalnie `styleArray.FontColor` dla komórek z datami. |
| *Czy niebieska czcionka jest widoczna w ciemnych motywach Excela?* | Niebieska czcionka może być trudna do odczytania na ciemnym tle. Użyj jaśniejszego odcienia (`Color.LightBlue`) lub kontrastowego koloru (`Color.Black`). |
| *Jak zaimportować bardzo dużą DataTable (setki tysięcy wierszy)?* | Użyj `ImportDataTable` z przeciążeniem `ImportDataTableOptions`, aby strumieniowo wczytywać dane, lub podziel import na wiele arkuszy, aby nie przekroczyć limitu wierszy w Excelu (1 048 576 wierszy). |
| *Czy mogę wyeksportować do CSV zamiast XLSX?* | Zastąp `SaveFormat.Xlsx` przez `SaveFormat.Csv`. Pamiętaj, że informacje o formatowaniu (format liczbowy, kolor czcionki) są tracone w CSV, ponieważ jest to format czystego tekstu. |

## Tips for Production Use

Wskazówki do użycia w produkcji

* **Pro tip:** Przechowuj w pamięci obiekt `Style`, jeśli musisz zastosować to samo formatowanie w wielu arkuszach; tworzenie nowego `StyleArray` dla każdego importu zwiększa narzut.
* **Uwaga na różnice kulturowe:** Wzorzec `Number` `#,##0.00` używa kultury niezmiennej. Jeśli potrzebujesz separatorów specyficznych dla lokalizacji, użyj `NumberFormatInfo` lub pozwól Excelowi dostosować je na podstawie ustawień regionalnych użytkownika.
* **Obsługa błędów:** Otocz wywołanie `Save` blokiem try‑catch, aby obsłużyć wyjątki I/O (np. brak uprawnień lub zablokowane pliki).
