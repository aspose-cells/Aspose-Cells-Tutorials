# Tworzenie pliku Excel w C# – stylowanie komórek i ustawianie formatu waluty

Jeśli potrzebujesz **tworzyć plik Excel w C#**, który wygląda profesjonalnie, ten przewodnik pokaże Ci dokładnie, jak stylować komórki w Excelu i sformatować kolumnę jako walutę. Zobaczysz kompletny, end‑to‑end przykład, który importuje `DataTable`, stosuje pogrubiony nagłówek i ustawia format liczbowy `$#,##0.00` dla kolumny cen.

Tutorial obejmuje wszystko, czego potrzebujesz: wymagane pakiety NuGet, pełny kod źródłowy, wyjaśnienia, dlaczego każdy element ma znaczenie, oraz wskazówki dotyczące obsługi przypadków brzegowych, takich jak puste wiersze czy różne lokalizacje. Po zakończeniu będziesz w stanie wygenerować plik `.xlsx` z ładnie sformatowaną kolumną cen w zaledwie kilku linijkach C#.

## Wymagania wstępne

- .NET 6.0 lub nowszy (kod działa również z .NET Framework 4.6+)
- Visual Studio 2022 lub dowolny edytor C#, którego używasz
- Biblioteka **Aspose.Cells for .NET** lub **GemBox.Spreadsheet** (obie obsługują `ImportTableOptions`). Poniższy przykład używa **Aspose.Cells**, ponieważ udostępnia prostą właściwość `StyleArray`.
- Podstawowa znajomość kolekcji C# i `DataTable`

> **Wskazówka:** Jeśli wolisz darmową alternatywę, zamień `Aspose.Cells` na `GemBox.Spreadsheet`. API do importowania `DataTable` ze stylami jest prawie identyczne; wystarczy zmienić przestrzeń nazw i nazwę pakietu NuGet.

## Krok 1: Zainstaluj bibliotekę Excel

Otwórz Menedżer pakietów NuGet i zainstaluj bibliotekę:

```bash
dotnet add package Aspose.Cells
```

> **Dlaczego ten krok?** Biblioteka dostarcza klasy `Workbook`, `Worksheet`, `Style` i `ImportTableOptions` używane później. Bez niej musiałbyś ręcznie pisać format Office Open XML, co jest podatne na błędy.

## Krok 2: Utwórz `DataTable` z przykładowymi danymi

`DataTable` to wygodny sposób przechowywania danych tabelarycznych przed ich eksportem do Excela. W tym przykładzie mamy dwie kolumny: *Product* i *Price*.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Wyjaśnienie:**  
> - `Columns.Add("Price", typeof(double))` informuje tabelę, że wartości cen mają być traktowane jako liczby, co jest wymagane do formatowania liczb później.  
> - Dodanie kilku wierszy daje nam dane do weryfikacji kroku **formatowanie kolumny jako waluty**.

## Krok 3: Zdefiniuj style, które chcesz zastosować

Utworzymy tablicę obiektów `Style`, która odpowiada kolejności kolumn. Pierwszy element stylizuje wiersz nagłówka, drugi pozostawia kolumnę *Product* bez zmian, a trzeci stosuje format liczbowy waluty.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### Dlaczego używać **tablicy stylów**?

`ImportTableOptions.StyleArray` mapuje każdą kolumnę na `Style`. To najwydajniejszy sposób na **dodanie formatu liczbowego** i **stylowanie komórek Excel** w jednej operacji importu, unikając drugiego przebiegu po arkuszu.

## Krok 4: Skonfiguruj opcje importu

Teraz łączymy tablicę stylów z operacją importu. Obiekt `ImportTableOptions` pozwala także kontrolować, czy pierwszy wiersz ma być traktowany jako nagłówek.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Uwaga:** `IsFieldNameShown` domyślnie ma wartość `true`, ale ustawienie jej explicite czyni intencję jasną dla przyszłych czytelników.

## Krok 5: Utwórz skoroszyt, zaimportuj tabelę i zapisz

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### Oczekiwany wynik

Po otwarciu `DataTableWithStyles.xlsx`:

- Pierwszy wiersz (nagłówek) jest **pogrubiony**.
- Kolumna *Price* wyświetla wartości jako **$1.20**, **$3.50**, **$0.75**.
- Kolumna *Product* zachowuje domyślną czcionkę.

Udało Ci się **utworzyć plik Excel w C#** z sformatowaną kolumną walutową i stylowanymi komórkami nagłówka.

## Krok 6: Obsługa typowych wariantów i przypadków brzegowych

### a. Inna lokalizacja lub własny symbol waluty

Jeśli potrzebujesz euro lub innej waluty, zamień wbudowany format `164` na własny ciąg formatowania:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. Dodawanie kolejnych kolumn później

Gdy dodajesz dodatkowe kolumny, rozszerz tablicę `columnStyles` odpowiednio. Użyj `null` dla kolumn, które mają zachować domyślny styl.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. Pusty `DataTable`

Jeśli `DataTable` nie zawiera wierszy, Aspose.Cells i tak tworzy wiersz nagłówka. Jednak skoroszyt będzie zawierał tylko jeden wiersz. Aby uniknąć pustego pliku, sprawdź liczbę wierszy przed importem:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Użycie `GemBox.Spreadsheet` zamiast Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

Logika pozostaje identyczna, co pokazuje, że tutorial jest **agnostyczny względem biblioteki** przy **formatowaniu kolumny jako waluty**.

## Krok 7: Weryfikacja pliku programowo (opcjonalnie)

Możesz otworzyć wygenerowany skoroszyt i sprawdzić, czy format liczbowy został poprawnie zastosowany — przydatne w testach jednostkowych.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```
