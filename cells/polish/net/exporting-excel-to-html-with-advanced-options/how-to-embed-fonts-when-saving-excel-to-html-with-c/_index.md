# Jak osadzić czcionki przy zapisywaniu Excela do HTML w C#

Osadzanie czcionek przy zapisywaniu skoroszytu Excel do HTML jest powszechnym wymogiem, aby zachować dokładny wygląd arkuszy kalkulacyjnych we wszystkich przeglądarkach. Jeśli potrzebujesz wyeksportować Excel do HTML, zachowując oryginalne kroje pisma, ten przewodnik pokaże Ci kompletną, gotową do uruchomienia rozwiązanie.

Dowiesz się, jak **eksportować Excel do HTML**, **konwertować Excel do HTML** z osadzonymi czcionkami oraz jak uniknąć typowego problemu „brakującej czcionki”, który psuje układ na komputerach klientów. Nie są potrzebne żadne zewnętrzne narzędzia — wystarczy biblioteka Aspose.Cells i kilka linii C#.

## Wymagania wstępne

Zanim rozpoczniesz, upewnij się, że masz:

* .NET 6.0 (lub nowszy) zainstalowany.
* Licencjonowaną kopię **Aspose.Cells for .NET** – wersja próbna wystarczy do testów.
* IDE, takie jak Visual Studio 2022 lub VS Code.

Jeśli już to masz, możesz od razu przejść do kodu.

## Krok 1: Utwórz skoroszyt i dodaj przykładowe dane

Najpierw generujemy mały skoroszyt, abyś mógł zobaczyć efekt osadzonych czcionek. Poniższy kod tworzy arkusz, zapisuje kilka komórek i stosuje niestandardową czcionkę.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### Dlaczego dodajemy niestandardową czcionkę

Osadzanie czcionek ma znaczenie tylko wtedy, gdy skoroszyt używa krojów, które mogą nie być dostępne na urządzeniu klienta. Ustawiając wyraźnie **Arial** (lub dowolną inną czcionkę), możemy zweryfikować, że wyjściowy HTML naprawdę zawiera dane czcionki.

## Krok 2: Skonfiguruj opcje zapisu HTML, aby osadzić czcionki

Aspose.Cells udostępnia klasę `HtmlSaveOptions`. Ustawienie `EmbedFonts = true` instruuje bibliotekę, aby osadziła wymagane pliki czcionek bezpośrednio w generowanym HTML jako URI zakodowane w Base64.

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### Co tak naprawdę robi „embed fonts in html”

Gdy `EmbedFonts` jest ustawione na true, Aspose.Cells pobiera pliki czcionek z systemu (lub z kolekcji czcionek osadzonych w skoroszycie) i konwertuje je na ciągi **Base64**. Te ciągi są następnie umieszczane wewnątrz bloku `<style>` przy użyciu reguły `@font-face`. Powstały HTML można otworzyć na dowolnym urządzeniu, nie wymagając zainstalowania oryginalnej czcionki.

## Krok 3: Zapisz skoroszyt jako HTML z osadzonymi czcionkami

Teraz zapisujemy skoroszyt na dysk. Plik będzie zawierał dane czcionki, więc otwarcie go w nowoczesnej przeglądarce pokaże dokładnie taką samą typografię jak w oryginalnym pliku Excel.

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### Oczekiwany rezultat

* `embedded.html` znajduje się w folderze `output`.
* Otwierając plik w Chrome, Edge lub Firefox, arkusz wyświetla tekst **Arial**, nawet jeśli przeglądarka nie ma tej czcionki zainstalowanej.
* Analiza źródła HTML ujawnia blok `<style>` zawierający regułę `@font-face` z długim deklaracją `src: url(data:font/ttf;base64,…)` – to jest osadzona czcionka.

## Krok 4: Zweryfikuj działanie HTML na innym komputerze (opcjonalnie)

Aby mieć pewność, że osadzanie się powiodło:

1. Skopiuj `output/embedded.html` na inny komputer (lub maszynę wirtualną), który **nie** ma zainstalowanej niestandardowej czcionki.
2. Otwórz plik w przeglądarce.
3. Układ i typografia powinny być identyczne jak w pierwotnym widoku Excela.

Jeśli czcionka przełącza się na domyślną, sprawdź, czy plik czcionki jest dostępny na maszynie budującej i czy masz uprawnienia do jego odczytu.

## Często zadawane pytania i przypadki brzegowe

### Czy osadzanie zwiększa rozmiar pliku?

Tak. Osadzenie czcionki TrueType lub OpenType może dodać **kilkadziesiąt kilobajtów** do pliku HTML. W przypadku dużych skoroszytów z wieloma unikalnymi czcionkami rozważ:

* Podzestawienie czcionki (tylko używane znaki) – Aspose.Cells robi to automatycznie dla większości popularnych czcionek.
* Ustawienie `ExportEmbeddedImages = false`, jeśli nie potrzebujesz osadzonych obrazów.

### Co zrobić, jeśli chcę osadzić tylko określone czcionki?

`HtmlSaveOptions` nie udostępnia bezpośredniej białej listy, ale możesz kontrolować, które czcionki pojawią się, **ograniczając użycie czcionek w skoroszycie** przed wywołaniem `Save`. Usuń niepotrzebne przypisania czcionek lub zamień je na standardowe czcionki web‑safe.

### Czy mogę osadzać czcionki przy konwersji do innych formatów (np. PDF)?

Właściwość `EmbedFonts` istnieje również w `PdfSaveOptions`. Zasada jest identyczna: dane czcionki są osadzane, dzięki czemu PDF wyświetla się poprawnie w każdym czytniku.

## Pełny, gotowy do uruchomienia przykład

Poniżej znajduje się kompletny program, który możesz skopiować i wkleić do nowego projektu konsolowego.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

Uruchomienie programu wygeneruje **plik HTML zawierający osadzony krój Arial**, zapewniając identyczny wygląd wizualny niezależnie od miejsca otwarcia pliku.

## Podsumowanie

Teraz wiesz, **jak osadzić czcionki przy zapisywaniu Excela do HTML** przy użyciu C#. Konfigurując `HtmlSaveOptions.EmbedFonts = true`, możesz niezawodnie **eksportować Excel do HTML** i **konwertować Excel do HTML** bez obaw o brakujące czcionki po stronie klienta. Ta technika jest niezbędna w raportowaniu web‑owym, pulpitach przyjaznych e‑mailom lub w każdej sytuacji, gdy udostępniasz treść wywodzącą się z Excela jako HTML.

### Co dalej?

* **Dostosuj CSS** generowany przez Aspose.Cells, aby pasował do wytycznych stylu Twojej witryny.  
* **Osadzaj obrazy** selektywnie, przełączając `ExportEmbeddedImages`.  
* **Zbadaj inne formaty eksportu** takie jak PDF czy SVG, zachowując jednocześnie osadzanie czcionek.  

Śmiało eksperymentuj z różnymi czcionkami, większymi arkuszami lub skoroszytami wielostronicowymi. Ten sam znacznik `EmbedFonts` działa we wszystkich obsługiwanych formatach wyjściowych, dając Ci spójną kontrolę nad osadzaniem czcionek, gdziekolwiek jej potrzebujesz. Powodzenia w kodowaniu!
