# Jak osadzić czcionki w HTML przy zapisywaniu skoroszytu

Jeśli potrzebujesz **jak osadzić czcionki w HTML** podczas eksportowania arkusza kalkulacyjnego, ten samouczek pokaże Ci kompletną, gotową do uruchomienia rozwiązanie. Niezależnie od tego, czy budujesz portal raportowy, czy widok analityki po stronie klienta, osadzanie czcionek zapewnia, że renderowany HTML wygląda dokładnie tak jak oryginalny skoroszyt, bez względu na zainstalowane czcionki u odbiorcy.

Dowiesz się również, jak najlepiej **zapisac skoroszyt jako HTML** przy użyciu Aspose.Cells, poznasz typowe pułapki i otrzymasz wskazówki dotyczące obsługi dużych skoroszytów lub własnych plików czcionek. Nie wymagana jest żadna zewnętrzna dokumentacja — wszystko, czego potrzebujesz, znajduje się w tym przewodniku.

## Wymagania wstępne

- .NET 6.0 lub nowszy (kod działa również z .NET Framework 4.7+)
- Ważna licencja Aspose.Cells for .NET (lub możesz użyć trybu darmowej ewaluacji)
- Podstawowa znajomość C# oraz IDE, np. Visual Studio 2022
- Pliki czcionek TrueType (.ttf) lub OpenType (.otf), które chcesz osadzić (muszą być dostępne dla uruchamianego procesu)

## Krok 1: Konfiguracja projektu i import Aspose.Cells

Utwórz nową aplikację konsolową i dodaj pakiet NuGet Aspose.Cells:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

Następnie otwórz **Program.cs** i dodaj wymagane dyrektywy `using`:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **Wskazówka:** Umieść własne czcionki w folderze o nazwie `fonts` w katalogu głównym projektu. Dzięki temu rozwiązanie jest przenośne i łatwo będzie je później odwoływać.

## Krok 2: Utwórz lub wczytaj skoroszyt

Do celów demonstracyjnych utworzymy prosty skoroszyt z kilkoma sformatowanymi komórkami:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **Dlaczego to ważne:** Jeśli pominiesz własny styl, wyeksportowany HTML powróci do domyślnych czcionek przeglądarki, co podważa cel **jak osadzić czcionki w HTML**.

## Krok 3: Skonfiguruj `HtmlSaveOptions`, aby osadzić czcionki

Sednem **jak osadzić czcionki w HTML** jest klasa `HtmlSaveOptions`. Ustawienie `EmbedFonts = true` instruuje Aspose.Cells, aby osadził wszystkie odwołane czcionki TrueType/OpenType bezpośrednio w generowanym HTML jako dane URI zakodowane w Base64.

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### Jak działa osadzanie

Gdy `EmbedFonts` jest ustawione na `true`, Aspose.Cells przeszukuje definicje stylów skoroszytu, znajduje odpowiadające pliki czcionek w systemie (lub w folderze `fonts`, który dodałeś), odczytuje ich dane binarne i wstawia blok `<style>` podobny do:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

Ponieważ dane czcionki są zakodowane bezpośrednio w HTML, strona renderuje się poprawnie nawet na maszynach, które nie mają zainstalowanej tej czcionki.

## Krok 4: Zapisz skoroszyt jako HTML

Teraz możesz **zapisac skoroszyt jako HTML** z użyciem skonfigurowanych opcji. Wybierz katalog, do którego aplikacja może zapisywać (np. `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

Uruchomienie programu generuje pojedynczy plik `report.html`. Otwórz go w dowolnej nowoczesnej przeglądarce, a zobaczysz nagłówek „Quarterly Sales” wyrenderowany czcionką **Pacifico**, nawet jeśli czcionka nie jest zainstalowana w Twoim systemie operacyjnym.

### Oczekiwany wynik

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

Atrybut `src:` zawiera długi ciąg Base64 — to są osadzone dane czcionki, które umożliwiają **jak osadzić czcionki w HTML**.

## Krok 5: Zweryfikuj osadzanie czcionek i rozwiąż problemy

1. Otwórz plik HTML w Chrome lub Edge. Jeśli własna czcionka się pojawi, osadzanie powiodło się.  
2. Zbadaj źródło strony. Poszukaj reguły `@font-face` wygenerowanej przez Aspose.Cells.  
3. Typowe problemy:  
   - *Brak pliku czcionki:* Upewnij się, że plik czcionki jest dostępny. Możesz explicite dodać folder do ścieżki wyszukiwania:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *Duży rozmiar HTML:* Osadzanie wielu czcionek może zwiększyć rozmiar pliku. Użyj `ExportToSingleFile = false`, aby zachować czcionki jako osobne pliki `.ttf` w folderze zasobów.

   - *Nieobsługiwany format czcionki:* Aspose.Cells osadza jedynie TrueType (`.ttf`) i OpenType (`.otf`). Przed osadzeniem skonwertuj inne formaty.

## Pełny działający przykład

Poniżej znajduje się kompletny program, który możesz skopiować, wkleić i uruchomić bez modyfikacji (z wyjątkiem opcjonalnej linii licencyjnej).

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

Uruchomienie tego programu tworzy `output/report.html`. Otwórz plik i zobaczysz czcionkę **Pacifico** wyrenderowaną poprawnie — demonstrując **jak osadzić czcionki w HTML** podczas **zapisywania skoroszytu jako HTML**.

## Najczęściej zadawane pytania

| Pytanie | Odpowiedź |
|----------|--------|
| *Czy mogę osadzić tylko wybrane czcionki?* | Tak. Ustaw `htmlOpt.EmbedAllFonts = false` (dostępne w nowszych wersjach) i użyj `htmlOpt.FontsToEmbed`, aby wymienić dokładne nazwy czcionek. |
| *Co zrobić, jeśli muszę osadzić czcionki dla wielu arkuszy?* | Ustaw `ExportActiveWorksheetOnly = false`, aby wyeksportować wszystkie arkusze, a Aspose.Cells osadzi czcionki użyte w całym skoroszycie. |
| *Czy osadzone czcionki będą działać w przeglądarkach mobilnych?* | Nowoczesne przeglądarki mobilne obsługują czcionki zakodowane w Base64, więc osadzone czcionki renderują się poprawnie, o ile format czcionki jest obsługiwany (TTF lub OTF). |
| *Jak duży może stać się plik HTML?* | Osadzenie czcionki TrueType o wielkości 200 KB zwiększa rozmiar HTML o mniej więcej tę samą wartość (Base64 dodaje ~33 % narzutu). Przy wielu czcionkach rozważ eksport do folderu (`ExportToSingleFile = false`), aby utrzymać HTML w lekkiej formie. |
