# Jak wyeksportować tabele przestawne jako obrazy przy użyciu Aspose.Cells w C#

Jeśli potrzebujesz **how to export pivot** danych do przenośnego obrazu, Aspose.Cells upraszcza ten proces. Ten tutorial pokazuje dokładnie, jak wyeksportować tabele przestawne jako pliki PNG, abyś mógł osadzać je w raportach, e‑mailach lub dokumentacji bez konieczności posiadania Excela na docelowym komputerze.

Eksportowanie tabeli przestawnej jako obrazu eliminuje problemy z formatowaniem zależnym od wersji i pozwala osobom nietechnicznym natychmiast zobaczyć analizę. Omówimy wszystko od konfiguracji projektu po renderowanie ostatecznego **export pivot table image**, a także wyjaśnimy, jak **save pivot as image** do późniejszego ponownego użycia.

## Jak wyeksportować tabele przestawne jako obrazy przy użyciu Aspose.Cells

Poniżej znajduje się kompletny, gotowy do uruchomienia przykład, który ładuje skoroszyt, odświeża tabelę przestawną, konfiguruje opcje obrazu i zapisuje plik wyjściowy. Każdy krok zawiera krótkie uzasadnienie, abyś rozumiał *dlaczego* kod jest napisany w ten sposób, a nie tylko *co* robi.

### 1. Skonfiguruj środowisko Aspose.Cells

1. Zainstaluj pakiet NuGet:

   ```bash
   dotnet add package Aspose.Cells
   ```

2. Dodaj wymagane dyrektywy `using` na początku swojego pliku C#:

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **Pro tip:** Ustaw docelową wersję .NET 6 lub nowszą, aby skorzystać z najnowszych usprawnień wydajności w Aspose.Cells.

### 2. Załaduj skoroszyt i zlokalizuj tabelę przestawną

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*Dlaczego to ważne:* Klasa `Workbook` parsuje plik XLSX i daje dostęp do wszystkich arkuszy. Wybranie właściwego arkusza jest kluczowe, ponieważ skoroszyt może zawierać wiele tabel przestawnych.

### 3. Odśwież tabelę przestawną, aby pobrać najnowsze dane źródłowe

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

Odświeżanie zapewnia, że wszelkie zmiany wprowadzone w zakresie źródłowym po zapisaniu pliku zostaną odzwierciedlone w renderowanym obrazie. Pominięcie tego kroku może skutkować przestarzałymi lub nieprecyzyjnymi wizualizacjami.

### 4. Skonfiguruj opcje eksportu obrazu (export pivot table image)

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

Obiekt `ImageOrPrintOptions` pozwala kontrolować format, rozdzielczość i inne szczegóły renderowania. PNG jest najczęściej wybieranym formatem dla wyraźnych, kompatybilnych z webem grafik, ale możesz przełączyć się na `ImageFormat.Jpeg`, jeśli rozmiar pliku jest istotny.

### 5. Renderuj i **save pivot as image**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

`RenderToImage` wykonuje najcięższą pracę: rysuje tabelę przestawną dokładnie tak, jak wygląda w Excelu i zapisuje binarne dane PNG na dysku. Metoda zwraca `void`, więc możesz bezpiecznie założyć, że plik istnieje po zakończeniu wywołania, bez potrzeby dodatkowych sprawdzeń.

Po uruchomieniu programu znajdziesz `Pivot.png` w określonym folderze. Otwarcie pliku powinno wyświetlić wierny zrzut oryginalnej tabeli przestawnej, w tym nagłówki kolumn, sumy wierszy i wszelkie zastosowane formatowanie.

### 6. Typowe warianty i przypadki brzegowe

| Scenariusz | Dostosowanie |
|------------|--------------|
| **Large pivots** (wiele wierszy/kolumn) | Zwiększ `HorizontalResolution` i `VerticalResolution` do 300 dpi, aby uzyskać wyraźniejszy wynik. |
| **Custom styling** (kolory tła, czcionki) | Upewnij się, że definicje stylów skoroszytu są załadowane przed wywołaniem `Refresh()`. |
| **Multiple pivots** w jednym arkuszu | Iteruj po `worksheet.PivotTables` i wywołaj `RenderToImage` dla każdej, używając unikalnych nazw plików. |
| **Export to JPEG** zamiast PNG | Zmień `ImageFormat = ImageFormat.Jpeg` i opcjonalnie ustaw `Quality` w obiekcie `JpegSaveOptions`. |

Te warianty pozwalają Ci **export pivot table image** w dokładnym formacie, którego oczekuje Twój system downstream.

## Pełny kod źródłowy do szybkiego kopiowania

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

Uruchomienie programu generuje plik PNG pokazany powyżej, kończąc przepływ pracy **save pivot as image** w mniej niż minutę.
