# Excel'i HTML olarak kaydederken C# ile yazı tiplerini gömmek

Excel çalışma kitabını HTML olarak kaydederken yazı tiplerini gömmek, tarayıcılar arasında elektronik tablolarınızın tam görünümünü korumak için yaygın bir gereksinimdir. Orijinal yazı tiplerini koruyarak Excel'i HTML'ye dışa aktarmanız gerekiyorsa, bu kılavuz size tam, çalıştırmaya hazır bir çözüm gösterir.

Bu rehberde **export Excel to HTML**, **convert Excel to HTML** işlemlerini gömülü yazı tipleriyle nasıl yapacağınızı öğrenecek ve istemci makinelerde düzeni bozan tipik “missing‑font” sorunundan kaçınacaksınız. Harici bir araç gerekmez—sadece Aspose.Cells kütüphanesi ve birkaç satır C# yeterlidir.

## Önkoşullar

Başlamadan önce şunların yüklü olduğundan emin olun:

* .NET 6.0 (veya daha yeni) yüklü.
* **Aspose.Cells for .NET** lisanslı bir kopya – ücretsiz deneme sürümü test için çalışır.
* Visual Studio 2022 veya VS Code gibi bir IDE.

Bu gereksinimlere zaten sahipseniz, doğrudan koda geçebilirsiniz.

## Adım 1: Bir çalışma kitabı oluşturun ve örnek veri ekleyin

İlk olarak gömülü yazı tiplerinin etkisini görebilmeniz için küçük bir çalışma kitabı oluşturuyoruz. Aşağıdaki kod bir çalışma sayfası oluşturur, birkaç hücre yazar ve özel bir yazı tipi uygular.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### Neden özel bir yazı tipi ekliyoruz

Yazı tiplerini gömmek, yalnızca çalışma kitabı istemci cihazında bulunmayabilecek yazı tipleri kullandığında önem kazanır. **Arial** (veya başka bir yazı tipi) açıkça ayarlanarak HTML çıktısının gerçekten yazı tipi verisini içerdiğini doğrulayabiliriz.

## Adım 2: Yazı tiplerini gömmek için HTML kaydetme seçeneklerini yapılandırın

Aspose.Cells, `HtmlSaveOptions` sınıfını sağlar. `EmbedFonts = true` ayarlandığında kütüphane, gerekli yazı tipi dosyalarını doğrudan oluşturulan HTML'e Base64‑kodlu veri URI'ları olarak gömer.

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### “embed fonts in html” gerçekte ne yapar

`EmbedFonts` true olduğunda, Aspose.Cells sistemden (veya çalışma kitabının gömülü yazı tipi koleksiyonundan) yazı tipi dosyalarını çıkarır ve **Base64** dizgilerine dönüştürür. Bu dizgiler daha sonra `@font-face` kullanılarak bir `<style>` bloğu içine yerleştirilir. Ortaya çıkan HTML, orijinal yazı tipinin yüklü olmasına gerek kalmadan herhangi bir cihazda açılabilir.

## Adım 3: Çalışma kitabını gömülü yazı tipleriyle HTML olarak kaydedin

Şimdi çalışma kitabını diske yazıyoruz. Dosya yazı tipi verisini içerecek, böylece herhangi bir modern tarayıcıda açtığınızda orijinal Excel dosyasıyla aynı tipografi gösterilecektir.

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### Beklenen sonuç

* `embedded.html`, `output` klasöründe bulunur.
* Dosyayı Chrome, Edge veya Firefox'ta açmak, tarayıcının makinesinde Arial olmasa bile çalışma sayfasını **Arial** metniyle gösterir.
* HTML kaynağını incelemek, uzun bir `src: url(data:font/ttf;base64,…)` bildirimi içeren bir `@font-face` kuralı bulunan bir `<style>` bloğu gösterir – bu gömülü yazı tipidir.

## Adım 4: HTML'nin başka bir makinede çalıştığını doğrulayın (isteğe bağlı)

Tam olarak gömmenin başarılı olduğundan emin olmak için:

1. `output/embedded.html` dosyasını özel yazı tipi yüklü **olmayan** başka bir bilgisayara (veya sanal makineye) kopyalayın.
2. Dosyayı bir tarayıcıda açın.
3. Düzen ve tipografi, orijinal Excel görünümüyle eşleşmelidir.

Eğer yazı tipi genel bir tipe geri dönüyorsa, yazı tipi dosyasının derleme makinesinde erişilebilir olduğundan ve okuma izninizin olduğundan emin olun.

## Yaygın sorular ve uç durumlar

### Gömme dosya boyutunu artırır mı?

Evet. TrueType veya OpenType bir yazı tipini gömmek, HTML dosyasına **onlarca kilobyte** ekleyebilir. Birçok benzersiz yazı tipine sahip büyük çalışma kitapları için şunları düşünün:

* Yazı tipini alt kümeleme (sadece kullandığınız karakterler) – Aspose.Cells bunu çoğu yaygın yazı tipi için otomatik yapar.
* Gömülü görüntülere ihtiyacınız yoksa `ExportEmbeddedImages = false` kullanın.

### Sadece belirli yazı tiplerini gömmem gerekirse?

`HtmlSaveOptions` doğrudan bir beyaz liste sunmaz, ancak `Save` çağırmadan önce **çalışma kitabında kullanılan yazı tiplerini sınırlayarak** hangi yazı tiplerinin görüneceğini kontrol edebilirsiniz. Gereksiz yazı tipi atamalarını kaldırın veya standart web‑güvenli yazı tipleriyle değiştirin.

### Diğer formatlara (ör. PDF) dönüştürürken yazı tiplerini gömebilir miyim?

`PdfSaveOptions` üzerinde aynı `EmbedFonts` özelliği bulunur. Kavram aynı: yazı tipi verisi gömülür, böylece PDF herhangi bir görüntüleyicide doğru şekilde render edilir.

## Tam, çalıştırılabilir örnek

Aşağıda yeni bir konsol projesine kopyalayıp yapıştırabileceğiniz tam program bulunmaktadır.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

Programı çalıştırmak, **gömülü Arial yazı tipini içeren bir HTML dosyası** üretir ve dosyanın açıldığı her yerde görsel tutarlılığı garanti eder.

## Sonuç

Artık C# kullanarak **Excel'i HTML olarak kaydederken yazı tiplerini nasıl gömeceğinizi** biliyorsunuz. `HtmlSaveOptions.EmbedFonts = true` yapılandırmasıyla, istemci tarafında eksik yazı tipleri konusunda endişelenmeden güvenilir bir şekilde **Excel'i HTML olarak dışa aktarabilir** ve **Excel'i HTML'ye dönüştürebilirsiniz**. Bu teknik, web‑tabanlı raporlama, e‑posta‑uyumlu panolar veya Excel türevi içeriği HTML olarak paylaştığınız herhangi bir senaryo için gereklidir.

### Sıradaki adım?

* **Aspose.Cells** tarafından oluşturulan CSS'i sitenizin stil kılavuzuna uyacak şekilde özelleştirin.  
* `ExportEmbeddedImages` ayarını değiştirerek **görüntüleri** seçici olarak gömün.  
* Yazı tiplerini gömmeye devam ederken PDF veya SVG gibi **diğer dışa aktarım formatlarını** keşfedin.  

Farklı yazı tipleri, daha büyük çalışma sayfaları veya çok‑sayfalı çalışma kitaplarıyla denemeler yapmaktan çekinmeyin. Aynı `EmbedFonts` bayrağı, desteklenen tüm çıktı formatlarında çalışır ve ihtiyacınız olan her yerde yazı tipi gömme üzerinde tutarlı kontrol sağlar. Kodlamanın tadını çıkarın!
