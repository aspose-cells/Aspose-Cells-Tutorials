# Çalışma Kitabını Kaydederken HTML'de Yazı Tiplerini Nasıl Gömülür

Bir elektronik tabloyu dışa aktarırken **HTML'de yazı tiplerini nasıl gömeceğinizi** öğrenmeniz gerekiyorsa, bu öğretici size eksiksiz, çalıştırmaya hazır bir çözüm gösterir. Raporlama portalı ya da istemci tarafı analiz görünümü oluşturuyor olsanız da, yazı tiplerini gömmek, oluşturulan HTML'nin orijinal çalışma kitabı gibi görünmesini, izleyicinin yüklü yazı tiplerinden bağımsız olarak garanti eder.

Ayrıca Aspose.Cells kullanarak **çalışma kitabını HTML olarak kaydetmenin** en iyi yolunu öğrenecek, yaygın tuzakları görecek ve büyük çalışma kitapları ya da özel yazı tipi dosyalarıyla başa çıkmak için ipuçları alacaksınız. Harici bir dokümantasyona ihtiyaç yok—gereken her şey bu rehberde.

## Ön Koşullar

- .NET 6.0 veya daha yeni bir sürüm (kod .NET Framework 4.7+ ile de çalışır)
- Geçerli bir Aspose.Cells for .NET lisansı (veya ücretsiz değerlendirme modunu kullanabilirsiniz)
- Temel C# bilgisi ve Visual Studio 2022 gibi bir IDE
- Gömmek istediğiniz TrueType (.ttf) veya OpenType (.otf) yazı tipi dosyaları (çalışan süreç tarafından erişilebilir olmalıdır)

## Adım 1: Projeyi Kurun ve Aspose.Cells'i İçe Aktarın

Yeni bir konsol uygulaması oluşturun ve Aspose.Cells NuGet paketini ekleyin:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

Ardından **Program.cs** dosyasını açın ve gerekli `using` yönergelerini ekleyin:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **Pro tip:** Özel yazı tiplerinizi proje kökünde `fonts` adlı bir klasöre yerleştirin. Bu, çözümün taşınabilir olmasını sağlar ve daha sonra onlara referans vermeyi kolaylaştırır.

## Adım 2: Bir Çalışma Kitabı Oluşturun veya Yükleyin

Gösterim amacıyla, birkaç biçimlendirilmiş hücreye sahip basit bir çalışma kitabı oluşturacağız:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **Neden önemli:** Özel stili atlayarsanız, dışa aktarılan HTML tarayıcının varsayılan yazı tiplerine geri dönecek ve **HTML'de yazı tiplerini nasıl gömeceğiniz** amacını boşa çıkaracaktır.

## Adım 3: `HtmlSaveOptions`'ı Yazı Tiplerini Gömmek İçin Yapılandırın

**HTML'de yazı tiplerini nasıl gömeceğiniz** konusunun özü `HtmlSaveOptions` sınıfındadır. `EmbedFonts = true` ayarı, Aspose.Cells'e başvurulan tüm TrueType/OpenType yazı tiplerini doğrudan oluşturulan HTML'ye Base64‑kodlu veri URI'ları olarak gömmesini söyler.

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### Gömmenin Çalışma Şekli

`EmbedFonts` `true` olduğunda, Aspose.Cells çalışma kitabının stil tanımlarını tarar, sistemdeki (veya eklediğiniz `fonts` klasöründeki) ilgili yazı tipi dosyalarını bulur, ikili verilerini okur ve aşağıdakine benzer bir `<style>` bloğu ekler:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

Yazı tipi verileri doğrudan HTML içinde kodlandığı için, sayfa yazı tipi yüklü olmayan makinelerde bile doğru şekilde görüntülenir.

## Adım 4: Çalışma Kitabını HTML Olarak Kaydedin

Artık yapılandırılmış seçeneklerle **çalışma kitabını HTML olarak kaydedebilirsiniz**. Uygulamanın yazabileceği bir dizin seçin (ör. `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

Programı çalıştırdığınızda tek bir `report.html` dosyası üretilir. Modern bir tarayıcıda açtığınızda, “Quarterly Sales” başlığının **Pacifico** yazı tipiyle render edildiğini göreceksiniz, hatta bu yazı tipi işletim sisteminizde yüklü olmasa bile.

### Beklenen Çıktı

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

`src:` özniteliği uzun bir Base64 dizesi içerir—bu, **HTML'de yazı tiplerini nasıl gömeceğiniz** sağlayan gömülü yazı tipi verisidir.

## Adım 5: Yazı Tipi Gömmesini Doğrulayın ve Sorun Giderin

1. **HTML dosyasını Chrome veya Edge'de açın.** Özel yazı tipi görünüyorsa, gömme başarılıdır.  
2. **Sayfa kaynağını inceleyin.** Aspose.Cells tarafından oluşturulan `@font-face` kuralını arayın.  
3. **Yaygın sorunlar:**  
   - *Yazı tipi dosyası eksik:* Yazı tipi dosyasının erişilebilir olduğundan emin olun. Arama yoluna açıkça bir klasör ekleyebilirsiniz:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *Büyük HTML boyutu:* Çok sayıda yazı tipi gömmek dosyayı şişirebilir. Yazı tiplerini ayrı `.ttf` dosyaları olarak bir kaynak klasöründe tutmak için `ExportToSingleFile = false` kullanın.

   - *Desteklenmeyen yazı tipi formatı:* Aspose.Cells yalnızca TrueType (`.ttf`) ve OpenType (`.otf`) dosyalarını gömer. Diğer formatları gömmeden önce dönüştürün.

## Tam Çalışan Örnek

Aşağıda, (isteğe bağlı lisans satırı hariç) değişiklik yapmadan kopyalayıp yapıştırıp çalıştırabileceğiniz tam program bulunmaktadır.

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

Bu programı çalıştırdığınızda `output/report.html` oluşturulur. Dosyayı açtığınızda **Pacifico** yazı tipinin doğru şekilde render edildiğini göreceksiniz—bu da **HTML'de yazı tiplerini nasıl gömeceğiniz** ve **çalışma kitabını HTML olarak kaydetme** konularını göstermektedir.

## Sıkça Sorulan Sorular

| Soru | Cevap |
|------|-------|
| *Sadece belirli yazı tiplerini gömebilir miyim?* | Evet. `htmlOpt.EmbedAllFonts = false` ayarlayın (yeni sürümlerde mevcuttur) ve kesin yazı tipi adlarını listelemek için `htmlOpt.FontsToEmbed` kullanın. |
| *Birden fazla çalışma sayfası için yazı tiplerini gömmem gerekiyorsa ne yapmalıyım?* | `ExportActiveWorksheetOnly = false` ayarlayın, böylece her çalışma sayfası dışa aktarılır ve Aspose.Cells tüm çalışma kitabı boyunca kullanılan yazı tiplerini gömer. |
| *Gömülü yazı tipleri mobil tarayıcılarda çalışır mı?* | Modern mobil tarayıcılar Base64‑kodlu yazı tiplerini destekler, bu yüzden gömülü yazı tipleri, yazı tipi formatı (TTF veya OTF) desteklendiği sürece doğru şekilde render edilir. |
| *HTML dosyası ne kadar büyük olabilir?* | 200 KB bir TrueType yazı tipini gömmek, HTML boyutuna yaklaşık aynı miktarı ekler (Base64 ~%33 ek yük getirir). Birçok yazı tipi için, HTML'i hafif tutmak amacıyla bir klasöre dışa aktarmayı (`ExportToSingleFile = false`) düşünün. |

Artık **HTML'de yazı tiplerini nasıl gömeceğinizi** **çalışma kitabını kaydederken** biliyorsunuz.
