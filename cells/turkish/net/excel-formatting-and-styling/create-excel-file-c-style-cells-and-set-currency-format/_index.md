# Create excel file c# – style cells and set currency format

Eğer **create excel file c#** işlemini profesyonel bir görünüme kavuşturmak istiyorsanız, bu rehber size Excel hücrelerini nasıl stilize edeceğinizi ve bir sütunu para birimi olarak nasıl biçimlendireceğinizi adım adım gösterir. `DataTable`'ı içe aktaran, kalın bir başlık uygulayan ve fiyat sütunu için `$#,##0.00` sayı formatını ayarlayan eksiksiz bir uçtan uca örnek göreceksiniz.

Bu öğretici, ihtiyacınız olan her şeyi kapsar: gerekli NuGet paketleri, tam kaynak kodu, her parçanın neden önemli olduğuna dair açıklamalar ve boş satırlar ya da farklı yerel ayarlar gibi kenar durumlarını ele almanız için ipuçları. Sonunda sadece birkaç C# satırıyla güzel biçimlendirilmiş bir fiyat sütunu içeren bir `.xlsx` dosyası oluşturabileceksiniz.

## Prerequisites

- .NET 6.0 veya daha yenisi (kod .NET Framework 4.6+ ile de çalışır)
- Visual Studio 2022 veya tercih ettiğiniz herhangi bir C# editörü
- **Aspose.Cells for .NET** veya **GemBox.Spreadsheet** kütüphanesi (her ikisi de `ImportTableOptions`'ı destekler). Aşağıdaki örnek **Aspose.Cells** kullanır çünkü basit bir `StyleArray` özelliği sunar.
- C# koleksiyonları ve `DataTable` hakkında temel bilgi

> **Pro tip:** Ücretsiz bir alternatif tercih ediyorsanız, `Aspose.Cells` yerine `GemBox.Spreadsheet` kullanın. `DataTable`'ı stillerle içe aktarma API'si neredeyse aynı; sadece ad alanı ve NuGet paket adını değiştirmeniz yeterli.

## Step 1: Install the Excel library

NuGet Package Manager'ı açın ve kütüphaneyi kurun:

```bash
dotnet add package Aspose.Cells
```

> **Why this step?** Kütüphane, daha sonra kullanılacak `Workbook`, `Worksheet`, `Style` ve `ImportTableOptions` sınıflarını sağlar. Onsuz, Office Open XML formatını manuel olarak yazmanız gerekir ki bu hata yapma olasılığını artırır.

## Step 2: Create a DataTable with sample data

`DataTable`, Excel'e dışa aktarmadan önce tablo verilerini tutmanın pratik bir yoludur. Bu örnekte iki sütunumuz var: *Product* ve *Price*.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Explanation:**  
> - `Columns.Add("Price", typeof(double))` tabloya fiyat değerlerinin sayı olarak ele alınacağını söyler; bu, daha sonra sayı biçimlendirmesi için gereklidir.  
> - Birkaç satır eklemek, **format column currency** adımını doğrulamak için veri sağlar.

## Step 3: Define the styles you want to apply

Sütun sırasına uyan bir `Style` nesneleri dizisi oluşturacağız. İlk giriş başlık satırını stilize eder, ikincisi *Product* sütununu dokunulmamış bırakır ve üçüncüsü para birimi sayı formatını uygular.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### Why use a **style array**?

`ImportTableOptions.StyleArray` her sütunu bir `Style` ile eşleştirir. Bu, **add number format** ve **style excel cells** işlemlerini tek bir içe aktarma adımında yapmanın en verimli yoludur; böylece çalışma sayfası üzerinde ikinci bir geçişe gerek kalmaz.

## Step 4: Configure import options

Şimdi stil dizisini içe aktarma işlemine bağlayacağız. `ImportTableOptions` nesnesi ayrıca ilk satırın başlık olarak ele alınıp alınmayacağını kontrol etmenizi sağlar.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Note:** `IsFieldNameShown` varsayılan olarak `true` değerindedir, ancak bunu açıkça ayarlamak gelecekteki okuyucular için niyeti netleştirir.

## Step 5: Create a workbook, import the table, and save

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### Expected result

`DataTableWithStyles.xlsx` dosyasını açtığınızda:

- İlk satır (başlık) **kalın** olacaktır.
- *Price* sütunu değerleri **$1.20**, **$3.50**, **$0.75** şeklinde gösterilir.
- *Product* sütunu varsayılan yazı tipini korur.

Bu şekilde **created an excel file c#** işlemini, biçimlendirilmiş bir para birimi sütunu ve stilize başlık hücreleriyle başarıyla tamamlamış oldunuz.

## Step 6: Handling common variations and edge cases

### a. Different locale or custom currency symbol

Euro ya da başka bir para birimi gerekiyorsa, yerleşik `164` formatını özel bir format dizesiyle değiştirin:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. Adding more columns later

Ek sütunlar eklediğinizde, `columnStyles` dizisini buna göre genişletin. Varsayılan stili koruması gereken sütunlar için `null` kullanın.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. Empty DataTable

`DataTable`'da satır yoksa, Aspose.Cells hâlâ başlık satırını oluşturur. Ancak, çalışma kitabı sadece bir satır içerir. Boş bir dosya oluşmasını önlemek için içe aktarmadan önce satır sayısını kontrol edin:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Using `GemBox.Spreadsheet` instead of Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

Mantık aynı kalır; bu da öğreticinin **format column currency** açısından alt kütüphane bağımsız olduğunu gösterir.

## Step 7: Verify the file programmatically (optional)

Oluşturulan çalışma kitabını açıp sayı formatının doğru uygulanıp uygulanmadığını doğrulayabilirsiniz—birim testleri için faydalıdır.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```
