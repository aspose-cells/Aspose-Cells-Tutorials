# C# ile özel biçimlendirme ve XLSX olarak kaydetme ile Excel çalışma kitabı oluşturma

Eğer **C# ile Excel çalışma kitabı oluşturma** ihtiyacınız varsa ve veri içe aktarmak, özel bir sayı biçimi uygulamak ve hücre yazı tipinin rengini değiştirmek istiyorsanız, bu öğretici tam olarak nasıl yapılacağını gösterir. Hazır‑çalıştır örneği sayesinde birkaç saniye içinde biçimlendirilmiş bir `StyleArrayImport.xlsx` dosyası elde edeceksiniz.

C# üzerinden Excel ile çalışmak genellikle tekrarlayan manuel adımları içerir—biçim tanımlama, renk uygulama ve dosyayı doğru şekilde kaydetmeyi hatırlama. Bu rehberin sonunda bu görevlerin tümünü otomatikleştirecek, böylece UI yerine verilere odaklanabileceksiniz.

Şunları öğreneceksiniz:

* bir `DataTable`'ı çalışma sayfasına içe aktarmak,
* bir `StyleArray` kullanarak **özel sayı biçimi uygulamak** ve **hücre yazı tipi rengini değiştirmek**,
* **çalışma kitabını XLSX olarak kaydetmek** tek bir metod çağrısıyla,
* ve **format imported data excel** adımının tam olarak istediğiniz gibi göründüğünü doğrulamak.

Tek ön koşul, **Aspose.Cells for .NET** kütüphanesine (veya `Workbook`, `Worksheet` ve `StyleArray` sağlayan herhangi bir uyumlu API) bir referansın olmasıdır. Kod .NET 6+ hedeflemektedir, ancak daha eski sürümler küçük ayarlamalarla çalışır.

## Adım 1: Örnek DataTable'ı Hazırlama

İlk olarak, normalde bir veritabanı ya da başka bir kaynaktan alacağınız veriyi taklit eden bir `DataTable` oluşturun. Tablo, **Name** (string) ve daha sonra biçimlendireceğimiz **Amount** (decimal) sütunlarını içerir.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Neden önemli:** `DataTable` kullanmak, içe aktarma mantığını veri kaynağından bağımsız tutar; bu, veritabanları, CSV dosyaları veya API'lerden rapor üretirken yaygın bir desendir.

## Adım 2: **özel sayı biçimi uygulamak** ve **hücre yazı tipi rengini değiştirmek** için bir StyleArray Tanımlama

`StyleArray`, `DataTable`'dan içe aktarılan her hücreye uygulanacak biçimlendirme talimatlarını paketlemenizi sağlar. Bu örnekte:

* `Number` değerini `#,##0.00` olarak ayarlıyoruz – binlik ayırıcıları olan tipik bir muhasebe formatı,
* `FontColor` değerini `Color.Blue` olarak ayarlıyoruz – sayıları öne çıkarmak için.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**StyleArray neden kullanılır?** İçe aktarma sırasında stili uygulamak, çalışma sayfası üzerinde ikinci bir geçiş yapmayı önler ve büyük veri kümelerinde performansı artırır.

## Adım 3: **C# ile Excel çalışma kitabı oluşturma** – Workbook nesnesini oluşturun ve ilk Worksheet'i alın

Şimdi boş bir çalışma kitabı oluşturup ilk çalışma sayfasına (indeks 0) referans elde ediyoruz. Bu çalışma sayfası içe aktardığımız verinin hedefi olacaktır.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Açıklama:** `Workbook`, tüm Excel dosyasını temsil ederken `Worksheet` tek bir sekmeyi temsil eder. Varsayılan çalışma kitabı bir sayfa içerir; bu, çoğu basit rapor için yeterlidir.

---

## Adım 4: **StyleArray** kullanarak **format imported data excel** işlemini gerçekleştirin

`ImportDataTable` metodu, tablo satırlarını ve sütunlarını çalışma sayfasına, `A1` hücresinden (satır 0, sütun 0) başlayarak kopyalar. `true` argümanı, sütun başlıklarının da dahil edilmesini sağlar. `styleArray`'i gönderdiğimiz için, içe aktarılan her hücre özel sayı biçimi ve yazı tipi rengi alır.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**Arka planda neler oluyor:** Aspose.Cells her satırı dolaşır, değeri yazar ve ardından `styleArray` içinde tanımlı stili uygular. Sayılar virgül ve iki ondalık basamakla gösterilir, metin ise mavi renkte görüntülenir.

## Adım 5: **çalışma kitabını XLSX olarak kaydetme** – dosyayı diske yazma

Son olarak, çalışma kitabını bir `.xlsx` dosyasına kalıcı hâle getirin. Yol kısmını makinenizdeki yazılabilir bir dizine göre değiştirebilirsiniz.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Sonuç doğrulama:** Oluşturulan dosyayı Excel'de açın. Üç veri satırını, **Amount** sütununun virgüllü, iki ondalık basamaklı ve mavi yazı tipinde olduğunu görmelisiniz. Bu, **format imported data excel** adımının başarılı olduğunu kanıtlar.

## Tam Çalışan Örnek

Aşağıdaki bloğu yeni bir konsol projesine yapıştırın ve çalıştırın. Başka bir koda ihtiyaç yok.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Konsolda beklenen çıktı:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

Dosyayı açın ve **Amount** sütununun `1,234.56` gibi değerleri mavi yazı tipinde gösterdiğini doğrulayın.

## Yaygın Sorular & Kenar Durumları

| Soru | Cevap |
|----------|--------|
| *Farklı sütunlara farklı biçimler uygulayabilir miyim?* | Evet. İçe aktardıktan sonra, sütunun `Style` nesnesini (`worksheet.Cells.Columns[1].Style`) alıp farklı bir `Number` ya da `FontColor` ayarlayabilirsiniz. |
| *Sayılardan ziyade tarihleri biçimlendirmem gerekirse?* | `styleArray.Number = "mm-dd-yyyy"` olarak ayarlayın ve tarih hücreleri için isteğe bağlı olarak `styleArray.FontColor` belirleyin. |
| *Mavi yazı tipi koyu Excel temalarında görünür mü?* | Mavi, koyu arka planlarda okunması zor olabilir. Daha açık bir ton (`Color.LightBlue`) ya da zıt bir renk (`Color.Black`) kullanın. |
| *Yüz binlerce satır içeren çok büyük bir DataTable'ı nasıl içe aktarırım?* | `ImportDataTable` metodunun `ImportDataTableOptions` aşırı yüklemesini kullanarak veriyi akış halinde aktarın veya Excel'in satır sınırı (1.048.576 satır) içinde kalmak için veriyi birden fazla çalışma sayfasına bölün. |
| *XLSX yerine CSV olarak dışa aktarabilir miyim?* | `SaveFormat.Xlsx` yerine `SaveFormat.Csv` kullanın. Ancak CSV düz metin formatı olduğundan biçim (sayı formatı, yazı tipi rengi) kaybolur. |

## Üretim Kullanımı İçin İpuçları

* **Pro ipucu:** Aynı biçimlendirmeyi birçok çalışma sayfasına uygulamanız gerekiyorsa `Style` nesnesini önbelleğe alın; her içe aktarma için yeni bir `StyleArray` oluşturmak ek yük getirir.
* **Kültür farklarına dikkat:** `Number` deseni `#,##0.00` evrensel kültürü izler. Yerel ayırıcılar gerekiyorsa `NumberFormatInfo` kullanın ya da Excel'in kullanıcı bölgesel ayarlarına göre otomatik ayarlanmasına izin verin.
* **Hata yönetimi:** `Save` çağrısını bir try‑catch bloğuna sararak I/O istisnalarını (yetersiz izin, kilitli dosyalar vb.) yakalayın.
