# C# şablonu kullanarak Excel'e veri dışa aktarma – adım adım kılavuz

Bir .NET uygulamasından **Excel'e veri dışa aktarmanız** gerekiyorsa, bu kılavuz uçtan uca çalışan tam bir çözüm gösterir. Smart Marker etiketlerini zaten içeren bir Excel şablonu yükleyerek **Excel oluşturmayı otomatikleştirebilir** ve hücre hücre kod yazmadan şık bir **employee report Excel** oluşturabilirsiniz.

Şunları göreceksiniz:

* Excel şablonunu (`load excel template`) yükleyin; bu şablon düzeni tanımlar.
* Şablona bir çalışan nesnesi listesi besleyin.
* Son çalışma kitabını oluşturun ve `output.xlsx` olarak kaydedin.

Gerekli tüm kod dahil edilmiştir, böylece hemen kopyalayıp yapıştırıp çalıştırabilirsiniz.

## Önkoşullar

* .NET 6.0 veya daha yeni bir sürüm (kod .NET Framework 4.7+ ile de çalışır).  
* **Aspose.Cells for .NET** NuGet paketi – `Workbook`, `SmartMarkerProcessor` ve Smart Marker desteği sağlar.  
* `YOUR_DIRECTORY` adlı bir klasör ve içinde `template.xlsx` bulunmalıdır. Şablonda, verinin görünmesini istediğiniz hücrelerde `&=EmployeeList.Name` gibi Smart Marker etiketleri olmalıdır.

> **Pro tip:** Şablonu aynı proje klasöründe tutun ve *Copy to Output Directory* özelliğini *Copy always* olarak ayarlayın; böylece hata ayıklama sırasında yol doğru çözülür.

## Tam kaynak kodu

```csharp
using System;
using System.Collections.Generic;
using Aspose.Cells;

namespace ExcelExportDemo
{
    // Simple POCO that represents an employee record
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Step 1: Load the Excel template that contains Smart Marker tags
            string templatePath = @"YOUR_DIRECTORY\template.xlsx";
            Workbook wb = new Workbook(templatePath);

            // Step 2: Prepare a data source – a list of employee objects
            List<Employee> employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Step 3: Create a SmartMarkerProcessor instance
            SmartMarkerProcessor sp = new SmartMarkerProcessor();

            // Step 4: Apply the employee data to the workbook using the processor
            // The tag &amp;=EmployeeList.Name in the template will be replaced with each employee's name,
            // and &amp;=EmployeeList.Position will be replaced with the corresponding position.
            sp.Process(wb, employeeList);

            // Step 5: Save the populated workbook
            string outputPath = @"YOUR_DIRECTORY\output.xlsx";
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

### Kodun yaptığı şey

| Adım | Neden önemli | Ana satır(lar) |
|------|--------------|----------------|
| **Load Excel template** | Önceden tasarlanmış bir düzeni yeniden kullanmak zaman tasarrufu sağlar ve tutarlı stil garantiler. | `Workbook wb = new Workbook(templatePath);` |
| **Prepare data source** | Smart Marker'lar herhangi bir `IEnumerable` koleksiyonuyla çalışır; burada bir `Employee` listesi kullanıyoruz. | `List<Employee> employeeList = …` |
| **Create processor** | `SmartMarkerProcessor` şablonu ayrıştırır, etiketleri bulur ve veriyi ekler. | `SmartMarkerProcessor sp = new SmartMarkerProcessor();` |
| **Process data** | İşlemci, her Smart Marker etiketini ilgili özellik değeriyle değiştirir. | `sp.Process(wb, employeeList);` |
| **Save workbook** | Son dosya kullanıcıya gönderilebilir, bir sunucuda saklanabilir veya e-postaya eklenebilir. | `wb.Save(outputPath);` |

Sonuç, her satırda bir çalışanın adı ve pozisyonunu içeren bir **employee report Excel** dosyasıdır; etiketlerin orijinal şablonda yer aldığı yerde tam olarak görünür.

## Excel şablonu yükleme

`new Workbook(path)` ile `load excel template` yaptığınızda, Aspose.Cells tüm çalışma kitabını—stil, formül ve Smart Marker yer tutucularını da—okur. Bu yaklaşım, sıfırdan bir çalışma kitabı oluşturmaktan tercih edilir çünkü:

* **Design control** – Tasarımcılar başlıkları biçimlendirebilir, şirket logoları ekleyebilir ve kod dokunmadan sütun genişliklerini ayarlayabilir.
* **Versioning** – Şablonu güncellemek uygulamanın yeniden derlenmesini gerektirmez.
* **Localization** – Farklı diller için ayrı şablon dosyaları tutabilirsiniz.

Üçüncü taraf kütüphaneler olmadan saf bir .NET çözümünü tercih ederseniz, **ClosedXML** veya **EPPlus** kullanabilirsiniz, ancak bunlar yerleşik Smart Marker desteğine sahip değildir; bu da veriyi hücre hücre kopyalayan döngüler yazmanız gerektiği anlamına gelir.

## Smart Marker'larla Excel oluşturmayı otomatikleştirme

Smart Marker'lar `&=Collection.Property` gibi görünen yer tutuculardır. İşlemci çalıştığında:

* Koleksiyon üzerinde (`employeeList` örneğimizde) yineleme yapar.
* Her öğe için ilgili hücreye özellik değerini yazar.
* Gerektiğinde satırları veya sütunları otomatik olarak genişletir.

Bu mekanizma **Excel oluşturmayı otomatikleştirir** ve manuel yineleme mantığını ortadan kaldırır. Aynı desen, siparişler, faturalar, envanter listeleri vb. gibi herhangi bir veri şekli için çalışır.

### Yaygın varyasyonlar

| Varyasyon | Nasıl uygulanır |
|-----------|------------------|
| **Multiple collections** | Daha fazla liste ekleyin (ör. `List<Department>`) ve `&=DepartmentList.Name` gibi farklı etiketlerle referans verin. |
| **Nested collections** | Nokta gösterimini kullanın: `&=EmployeeList.Projects.ProjectName`; burada `Projects`, `Employee` içinde bir koleksiyon özelliğidir. |
| **Conditional formatting** | Şablona bir Excel koşullu biçimlendirme kuralı yerleştirin; işlemci bunu oluşturulan satırlar için korur. |

## Bir employee report Excel oluşturma

**employee report Excel** terimi tipik bir iş senaryosunu gösterir: bir yönetici personel listesini yazdırılabilir istiyor. Smart Marker etiketlerini doğrudan şablona gömerek şunları elde edersiniz:

* Kalın yazı tipleri ve arka plan rengi içeren bir başlık satırı.
* Veriye dayalı otomatik genişlikte sütunlar.
* İsteğe bağlı toplam satırları (ör. çalışan sayısı) standart Excel formülleriyle hesaplayabilirsiniz.

Toplam satırı eklemeniz gerekiyorsa, şablona `=COUNTA(A2:A100)` gibi bir formül yerleştirin; işlemci buna dokunmaz.

## Excel şablonu C# üretimi – en iyi uygulamalar

**generate Excel template C#** kodu yazarken, aşağıdaki yönergeleri aklınızda bulundurun:

1. **Separate concerns** – Şablon yükleme, veri hazırlama ve işleme adımlarını ayrı metodlarda tutun. Bu, birim testlerini kolaylaştırır.
2. **Validate input** – `Process` çağırmadan önce şablon dosyasının var olduğundan ve veri koleksiyonunun null olmadığından emin olun.
3. **Dispose resources** – Aspose.Cells belleği yönetse de, büyük dosyalarla çalışıyorsanız `Workbook`'ı bir `using` bloğu içinde sarın.
4. **Handle exceptions** – `sp.Process` etrafında `Exception` yakalayarak eşleşmeyen etiket adları gibi sorunları ortaya çıkarın.

```csharp
static Workbook LoadTemplate(string path)
{
    if (!File.Exists(path))
        throw new FileNotFoundException($"Template not found: {path}");
    return new Workbook(path);
}
```

## Tam örnek özeti

Aşağıda hızlı kopyala‑yapıştır için tüm program tek bir blokta verilmiştir:

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Load the template
            string templatePath = Path.Combine("YOUR_DIRECTORY", "template.xlsx");
            Workbook wb = new Workbook(templatePath);

            // Prepare data
            var employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Process Smart Markers
            var sp = new SmartMarkerProcessor();
            sp.Process(wb, employeeList);

            // Save the result
            string outputPath = Path.Combine("YOUR_DIRECTORY", "output.xlsx");
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

Bu programı çalıştırmak, e-posta ile gönderilebilen, yazdırılabilen veya daha fazla işlenebilen bir **employee report Excel** dosyası oluşturur.
