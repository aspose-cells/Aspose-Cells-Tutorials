# Aspose.Cells kullanarak C#'ta pivot tablolarını görüntü olarak dışa aktarma

Pivot verilerini taşınabilir bir resim olarak dışa aktarmanız gerekiyorsa, Aspose.Cells bu süreci basitleştirir. Bu öğreticide, pivot tablolarını PNG dosyaları olarak **pivot'i dışa aktarma** nasıl yapılacağını adım adım gösteriyoruz, böylece raporlara, e-postalara veya belgelere Excel'e ihtiyaç duymadan ekleyebilirsiniz.

Pivot'i bir görüntü olarak dışa aktarmak, sürüm‑spesifik biçimlendirme sorunlarını ortadan kaldırır ve teknik olmayan paydaşların analizi anında görmesini sağlar. Proje kurulumundan son **export pivot table image**'ın oluşturulmasına kadar her şeyi ele alacağız ve ayrıca gelecekte yeniden kullanmak için **save pivot as image**'ı nasıl yapacağınızı açıklayacağız.

## Aspose.Cells ile pivot tablolarını görüntü olarak dışa aktarma

Aşağıda, bir çalışma kitabını yükleyen, pivot'u yenileyen, görüntü seçeneklerini yapılandıran ve çıktı dosyasını yazan tam, çalıştırılabilir bir örnek bulunmaktadır. Her adım, kodun *neden* o şekilde yazıldığını, sadece *ne* yaptığını anlamanız için kısa bir gerekçe içerir.

### 1. Aspose.Cells ortamını kurma

1. NuGet paketini yükleyin:

   ```bash
   dotnet add package Aspose.Cells
   ```

2. C# dosyanızın üst kısmına gerekli `using` yönergelerini ekleyin:

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **Pro tip:** En son performans iyileştirmelerinden yararlanmak için .NET 6 veya daha yenisini hedefleyin.

### 2. Çalışma kitabını yükleyin ve pivot tabloyu bulun

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*Neden önemli:* `Workbook` sınıfı XLSX dosyasını ayrıştırır ve tüm çalışma sayfalarına erişim sağlar. Doğru çalışma sayfasını seçmek, bir çalışma kitabının birden fazla pivot içerebileceği için çok önemlidir.

### 3. Pivot tabloyu yenileyerek en son kaynak verileri yakalayın

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

Yenileme, dosya kaydedildikten sonra kaynak aralıkta yapılan değişikliklerin oluşturulan görüntüde yansıtılmasını garanti eder. Bu adımı atlamak, eski veya hatalı görseller üretmenize neden olabilir.

### 4. Görüntü dışa aktarma seçeneklerini yapılandırma (export pivot table image)

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

`ImageOrPrintOptions` nesnesi, format, çözünürlük ve diğer render detaylarını kontrol etmenizi sağlar. PNG, keskin ve web‑uyumlu grafikler için en yaygın seçimdir, ancak dosya boyutu bir endişe ise `ImageFormat.Jpeg`'e geçebilirsiniz.

### 5. Render edin ve **save pivot as image**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

`RenderToImage` ağır işi yapar: pivot'i Excel'de göründüğü gibi çizer ve ikili PNG verisini diske yazar. Metot `void` döndürdüğü için, ek kontroller yapmadan çağrı tamamlandığında dosyanın var olduğunu güvenle varsayabilirsiniz.

#### Beklenen sonuç

Program çalıştıktan sonra, belirtilen klasörde `Pivot.png` dosyasını bulacaksınız. Dosyayı açtığınızda, orijinal pivot tablonun sütun başlıkları, satır toplamları ve uygulanmış biçimlendirmeler dahil olmak üzere doğru bir anlık görüntüsünü göstermelidir.

### 6. Yaygın varyasyonlar ve uç durumlar

| Senaryo | Ayar |
|----------|------------|
| **Büyük pivot'lar** (çok satır/sütun) | `HorizontalResolution` ve `VerticalResolution` değerlerini daha net çıktı için 300 dpi'ye yükseltin. |
| **Özel stil** (arka plan renkleri, yazı tipleri) | `Refresh()` çağırmadan önce çalışma kitabının stil tanımlarının yüklendiğinden emin olun. |
| **Bir sayfada birden fazla pivot** | `worksheet.PivotTables` içinde döngü yapın ve her biri için `RenderToImage` çağırın, farklı dosya adları kullanarak. |
| **PNG yerine JPEG olarak dışa aktar** | `ImageFormat = ImageFormat.Jpeg` olarak değiştirin ve isteğe bağlı olarak bir `JpegSaveOptions` nesnesinde `Quality` ayarlayın. |

Bu varyasyonlar, **export pivot table image**'ı alt sisteminizin beklediği tam formatta dışa aktarmanızı sağlar.

## Hızlı kopyala‑yapıştır için tam kaynak kodu

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

Programı çalıştırmak, yukarıda gösterilen PNG dosyasını üretir ve **save pivot as image** iş akışını bir dakikadan kısa sürede tamamlar.
