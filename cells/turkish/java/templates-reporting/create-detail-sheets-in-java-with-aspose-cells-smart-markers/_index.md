# Java ile Aspose.Cells akıllı işaretçiler kullanarak detay sayfaları oluşturma

Eğer bir Java uygulamasında **create detail sheets** oluşturmanız gerekiyorsa, bu öğretici Aspose.Cells akıllı işaretçileriyle bunu nasıl yapacağınızı gösterir. **java create worksheets**, **sheet name from field** ve **process data source** işlemlerini sadece birkaç satır kodla gerçekleştiren eksiksiz, çalıştırılabilir bir örnek göreceksiniz.

Bu kılavuz, proje kurulumundan son çalışma kitabının kaydedilmesine kadar her şeyi kapsar, böylece çözümü kendi projenize kopyalayıp yapıştırabilir ve anında uyarlayabilirsiniz. Harici bir dokümantasyona ihtiyaç yok—gereken her şey burada.

## Öğrenecekleriniz

* **use smart markers** kullanarak bir şablon çalışma sayfasını ana veri kümesindeki her satır için çoğaltmayı.  
* Her yeni sayfanın adını bir alan değerine (ör. `Order_123`) göre dinamik olarak ayarlamayı.  
* Akıllı işaretçi motoru için **process data source** olarak bir Java koleksiyonunu beslemeyi.  
* Boş veri, sayfa adlarındaki özel karakterler ve büyük veri kümeleri için performans gibi kenar durumlarını ele alma ipuçlarını.

### Önkoşullar

| Gereksinim | Sebep |
|------------|-------|
| Java 8 ve üzeri | Aspose.Cells for Java, Java 8+ destekler. |
| Maven veya Gradle yapı sistemi | Aspose.Cells bağımlılığını eklemeyi basitleştirir. |
| Java koleksiyonları hakkında temel bilgi | Akıllı işaretçiler için veri kaynağını oluşturmak gerekir. |
| **A1** hücresinde bir yer tutucu akıllı işaretçi bulunan bir şablon Excel dosyası (`Template.xlsx`) | Şablon, detay‑sayfa oluşturmayı yönlendirir. |

> **Pro ipucu:** Şablon çalışma kitabını projenizin `resources` klasöründe tutun, böylece JAR dosyanıza paketlenir.

## Adım 1: Aspose.Cells'i projenize ekleyin (java create worksheets)

**Maven** kullanıyorsanız, `pom.xml` dosyasına aşağıdaki bağımlılığı ekleyin:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

**Gradle** için, `build.gradle` dosyasına şu satırı ekleyin:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

Bu satırlar, **java create worksheets** API'lerini derleme zamanında kullanılabilir hâle getirir.

## Adım 2: Şablon çalışma kitabını yükleyin

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*Bu neden önemli:* `Workbook` nesnesi tüm Excel işlemlerinin giriş noktasıdır. Şablonu yüklemek, doğru düzen ve önceden tanımlı biçimlendirmeyle başlamanızı sağlar.

## Adım 3: Her ana satır için yeni bir sayfa oluşturan akıllı işaretçi ekleyin (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

`${Orders:DetailSheetNewName=Order_${OrderId}}` sözdizimi, **use smart markers** özelliğinin çekirdeğidir. Üç şey yapar:

1. `Orders` koleksiyonunu yineleyerek.  
2. Her öğe için **new worksheet** oluşturur.  
3. `OrderId` alanından (ön ek `Order_` ile) **sheet name from field** ayarlar.

## Adım 4: Veri kaynağını hazırlayın (process data source)

Aşağıda `List<Map<String, Object>>` kullanan minimal bir örnek yer alıyor. Gerçek veri kaynağınızla—veritabanı satırları, JSON ayrıştırması vb.—değiştirin.

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*Bu neden önemli:* **process data source** adımı, Java koleksiyonunuzu akıllı işaretçi motoruna bağlar. Anahtar (`"Orders"`), akıllı işaretçi adıyla tam olarak eşleşmelidir.

## Adım 5: Akıllı işaretçileri işleyin (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

`process` çalıştığında, Aspose.Cells `Orders` koleksiyonunu okur, şablon çalışma sayfasını her giriş için kopyalar ve her sayfayı `OrderId` alanına göre yeniden adlandırır. Bu, **process data source** kullanımının kalbidir.

## Adım 6: Çoğaltılmış detay sayfalarıyla çalışma kitabını kaydedin

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

Çalıştırdıktan sonra, `DuplicatedDetailSheets.xlsx` dosyasının içinde şunları bulacaksınız:

* `Sheet1` – orijinal şablon (değişmemiş).  
* `Order_101` – ilk sipariş için detay sayfası.  
* `Order_102` – ikinci sipariş için detay sayfası.

### Beklenen çıktı (alıntı)

| Sayfa adı | A1 (akıllı işaretçi) | Oluşan içerik |
|-----------|----------------------|----------------|
| Order_101 | `${Orders:...}`      | `order1` verileriyle doldurulmuş |
| Order_102 | `${Orders:...}`      | `order2` verileriyle doldurulmuş |

Dosyayı Excel'de açarak her sayfanın doğru adlandırıldığını ve veri satırlarını içerdiğini doğrulayın.

## Yaygın varyasyonlar ve kenar durumlarıyla başa çıkma

### Boş veri kaynağı

`orders` boş ise, akıllı işaretçi işlemcisi **yeni worksheet oluşturmaz**. Boş bir çalışma kitabı oluşmasını önlemek için bir koruma ekleyin:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### Sayfa adlarındaki özel karakterler

Excel sayfa adları `\ / ? * [ ] :` karakterlerini içeremez. Kullanımdan önce alanı temizleyin:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### Büyük veri kümeleri

Binlerce satır için, JVM yığın boyutunu (`-Xmx2g`) artırmayı ve tüm sayfalar oluşturulduktan sonra `workbook.calculateFormula()` çağırmayı düşünün; bu, performansı artırır.
