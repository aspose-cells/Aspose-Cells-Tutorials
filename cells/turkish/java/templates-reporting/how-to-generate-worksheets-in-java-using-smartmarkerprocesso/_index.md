# Java'da SmartMarkerProcessor Kullanarak Çalışma Sayfaları Nasıl Oluşturulur

Excel dosyasında **çalışma sayfaları nasıl oluşturulur** ihtiyacınız varsa, bu kılavuz size eksiksiz, çalıştırmaya hazır bir çözüm gösterir. İlk iki cümlenin sonunda, nesneler koleksiyonundan çalışma sayfaları ve dinamik excel sayfaları nasıl oluşturulacağını anlayacak ve tek bir metod çağrısıyla excel oluşturmayı otomatikleştiren çalışan bir kod örneğine sahip olacaksınız.

Her çalışan, proje veya başka bir varlık için ayrı çalışma sayfaları oluşturmak, **excel çalışma kitabını doldurmak** gerektiğinde yaygın bir gereksinimdir. Bu öğretici, şablonu ayarlamadan listeyi işlemeye ve son dosyayı kaydetmeye kadar her adımı anlatır—böylece tekniği kendi Java uygulamalarınızda anında uygulayabilirsiniz.

## Neler Başaracaksınız

* Yüksek seviyeli bilgileri listeleyen bir ana çalışma sayfası oluşturun.  
* Liste verilerinden **listeden çoklu sayfalar** oluştur, her sayfaya otomatik olarak ad verilir.  
* **excel oluşturmayı otomatikleştir** satır veya sütunları manuel eklemeden.  
* **excel çalışma kitabını doldur** zengin veri yapıları (nesneler, haritalar, diziler) ile.  

Önkoşullar:

* Java 8 veya daha yeni bir sürüm yüklü.  
* Aspose.Cells for Java kütüphanesini eklemek için Maven (veya başka bir yapı aracı).  
* Java koleksiyonları hakkında temel bir anlayış.  

> **Pro ipucu:** SmartMarker sözdizimi (`${EmployeeMaster}`) `java.util.Collection` arayüzünü uygulayan herhangi bir koleksiyon türüyle çalışır. Şablonlarınızı temiz ve sürdürülebilir tutmak için kullanın.

## SmartMarkerProcessor ile Çalışma Sayfaları Nasıl Oluşturulur

Bu bölüm, **çalışma sayfaları nasıl oluşturulur** işlemini sorunsuz hale getiren temel kodu içerir. Sadece ne yaptığını değil, her satırın neden önemli olduğunu açıklayacağız.

### Adım 1: Aspose.Cells Bağımlılığını Ekleyin

Maven kullanıyorsanız, aşağıdakileri `pom.xml` dosyanıza ekleyin. Kütüphane, bu kılavuz boyunca kullanılan `SmartMarkerProcessor` sınıfını sağlar.

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **Neden:** Aspose.Cells, Excel dosya G/Ç, Smart Marker ayrıştırma ve sayfa yönetimini dahili olarak ele alır, böylece düşük seviyeli dosya işlemleri yerine verilere odaklanabilirsiniz.

### Adım 2: Excel Şablonunu Hazırlayın

`EmployeeTemplate.xlsx` adlı bir Excel dosyası oluşturun ve içinde Smart Marker yer tutucusunu içeren tek bir hücre bulunsun:

| A |
|---|
| `${EmployeeMaster}` |

İşlemci çalıştığında, bu yer tutucuyu her çalışan için bir satır içeren bir **detay sayfası** ile değiştirecektir.

> **Neden:** Yer tutucu, işlemciye verileri nerede enjekte edeceğini söyler. Ayrı bir şablon kullanmak, biçimlendirmeyi (yazı tipleri, kenarlıklar, sütun genişlikleri) korur.

### Adım 3: Veri Modelini Tanımlayın

Aşağıda, çalışanların bir listesini oluşturan minimal bir `Employee` sınıfı ve yardımcı bir metod bulunmaktadır. Liste, **listeden çoklu sayfalar** göstermek için kullanılacak.

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **Neden:** Düz bir Java nesnesi (POJO), Smart Marker alanlarına (`firstName`, `lastName`, `department`) doğrudan eşlenir. Bu, **excel çalışma kitabını doldurmayı** basit ve tip‑güvenli hale getirir.

### Adım 4: SmartMarkerProcessor'ı Kurun

Şimdi her şeyi bir araya bağlayacağız. İşlemci şablonu okuyacak, işaretleyiciyi değiştirecek ve `EmployeeDetail` adlı yeni bir sayfa oluşturacak.

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

**Ana satırların açıklaması**

| Satır | Açıklama |
|------|----------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | Smart Marker yer tutucusunu zaten içeren şablonu yükler. |
| `data.put("EmployeeMaster", employees);` | Java listesini `${EmployeeMaster}` işaretleyicisine bağlar. |
| `processor.setDetailSheetNewName("EmployeeDetail");` | Oluşturulan sayfaya varsayılan `Sheet1` yerine anlamlı bir ad verir. |
| `processor.process(wb, data);` | **çalışma sayfaları nasıl oluşturulur** – işlemci işaretleyiciyi okur, yeni bir sayfa oluşturur ve her `Employee` için satırlarla doldurur. |
| `wb.save("EmployeesReport.xlsx");` | **dinamik excel sayfalarını** diske kaydeder. |

### Adım 5: Çıktıyı Doğrulayın

`EmployeesReport.xlsx` dosyasını açın. İki çalışma sayfası görmelisiniz:

1. **Sheet1** – orijinal şablon (gizlenebilir veya kaldırılabilir).  
2. **EmployeeDetail** – `firstName`, `lastName`, `department` sütunlarına sahip bir **dinamik excel sayfası** ve her çalışan için bir satır.

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **Neden önemli:** Dosya artık **listeden çoklu sayfalar** içeriyor ve manuel döngü veya hücre adreslemesi gerektirmiyor. Smart Marker motoru satır oluşturma, veri dönüştürme ve biçim mirasını halleder.

### Adım 6: Kenar Durumlarını Ele Alın

#### Boş veri listesi

`employees` boşsa, işlemci yine de `EmployeeDetail` sayfasını oluşturur ancak boş bırakır. Sayfanın eklenmesini, işlemden önce koleksiyon boyutunu kontrol ederek önleyebilirsiniz:

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### Çok büyük listeler

Binlerce satır için, bellek tahsisatını (`-Xmx2g`) artırmayı veya işleme hızını artırmak için `processor.setAutoFitRows(false)` kullanmayı düşünün.

#### Grup Başına Özel Sayfa Adlandırma

Her departman için ayrı bir sayfa gerekiyorsa, **çoklu detay sayfaları** kullanabilirsiniz:

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

Yer tutucu `${department}` her `Employee` nesnesinden alınır ve `Dept_Sales`, `Dept_Marketing` gibi sayfalar üretir.
