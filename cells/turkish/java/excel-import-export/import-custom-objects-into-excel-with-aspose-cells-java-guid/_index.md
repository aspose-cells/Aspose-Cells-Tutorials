# Aspose.Cells – Java rehberi ile Excel'e özel nesneleri içe aktar

Eğer bir Excel çalışma sayfasına **özel nesneleri içe aktarmanız** gerekiyorsa, bu rehber Aspose.Cells for Java kullanarak sürecin tamamını adım adım gösterir. **Verileri Excel'e içe aktarmayı**, kalın bir başlık stili uygulamayı ve paylaşılmaya hazır bir `.xlsx` dosyası oluşturmayı göreceksiniz.

Java'dan tablo verilerini dışa aktarmak genellikle hücre‑hücre manuel yazma gerektirir; bu hataya açıktır ve bakımını zorlaştırır. `importCustomObjects` API'sini kullanarak gereksiz koddan kaçınır, veri modelinizi bozulmadan tutar ve ince ayarlı stil kontrolü elde edersiniz.

Bu öğreticide şunları yapacaksınız:

* Tipik bir veri tablosunu taklit eden bir Java `Map` nesneleri listesi oluşturmak.
* Aspose.Cells ile yeniden kullanılabilir bir başlık stili (kalın yazı tipi) yaratmak.
* Stil dizisini uygulayarak özel nesneleri bir çalışma sayfasına içe aktarmak.
* Çalışma kitabını diske kaydetmek ve sonucu doğrulamak.

Tek ön koşul, bir Java geliştirme ortamı (JDK 8+ önerilir) ve Aspose.Cells for Java kütüphanesidir.


## Adım 1: İçe aktarılacak özel nesneleri hazırlama

İlk adım, Excel'e yerleştirmek istediğiniz satırları temsil eden bir koleksiyon oluşturmaktır. Bu örnekte her harita bir satır gibi davranan `List<Map<String,Object>>` kullanıyoruz; sütun adları anahtar olarak bulunur.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Neden önemli:**  
`importCustomObjects` bir nesne dizisi bekler. `Map` kullanarak sütun adlarını korur, Aspose.Cells'in bunları hücrelere otomatik olarak eşlemesini sağlarsınız. Bu yaklaşım .NET'teki tipik bir `DataTable` ya da JDBC'den gelen `ResultSet` ile aynıdır ve kodun farklı projelerde yeniden kullanılmasını kolaylaştırır.

---

## Adım 2: İçe aktarımda uygulanacak bir başlık stili tanımlama

Açık bir başlık satırı okunabilirliği artırır. Aspose.Cells size bir `Style` nesnesi oluşturma, yazı tipini kalın yapma ve bunu bir `ImportTableOptions` dizisi aracılığıyla geçirme imkanı verir.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Neden önemli:**  
Stil dizisini atlamazsanız başlık varsayılan yazı tipinde görünür ve öne çıkmaz. Stili bir kez hazırlayarak her satır için tekrarlayan çağrılardan kaçınır ve içe aktarma mantığını temiz tutarsınız.

---

## Adım 3: Stil dizisiyle özel nesneleri içe aktar

Şimdi veriyi ve stili birleştirip `importCustomObjects` metodunu çağırıyorsunuz. Metod, veriyi sol‑üst köşeden (satır 0, sütun 0) başlayarak yerleştirir ve başlık stilini otomatik olarak uygular.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Neden önemli:**  
`importCustomObjects` her haritayı ayrıştırır, anahtarlar (`Name`, `Score`) temelinde sütunlar oluşturur ve değerleri ilgili hücrelere yazar. `ImportTableOptions` nesnesi, ilk satır için `styleArray` kullanılacağını Aspose.Cells'e bildirir; böylece ekstra kod yazmadan kalın bir başlık elde edersiniz.

---

## Adım 4: Çalışma kitabını kaydet ve çıktıyı doğrula

Son olarak, çalışma kitabını bir dosyaya yazın. Oluşturulan Excel dosyası, veri satırlarının önünde stillendirilmiş bir başlık satırı içerir.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Beklenen sonuç:**  

| **İsim** | **Puan** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

Başlık hücreleri (`İsim`, `Puan`) kalın fontta görünür ve Adım 2'de tanımlanan stil ile eşleşir.

## Yaygın varyasyonlar ve uç durumlar

| Durum | Önerilen ayarlama |
|-----------|------------------------|
| **Farklı sütun sırası** | `Map` anahtarlarının istenen sırada eklenmesini sağlayın veya anotasyonlu alanlara sahip özel bir POJO ve `PropertyDescriptor` dizisi kullanın. |
| **Büyük veri setleri (>10 000 satır)** | `OutOfMemoryError` oluşmasını önlemek için `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` değerini artırın. |
| **Özel sayı formatları** | Veri satırları için `styleArray` içinde ikinci bir `Style` ekleyin; ör. tam sayı puanlar için `NumberFormat`'ı `"0"` olarak ayarlayın. |
| **Birden fazla çalışma sayfası** | Her hedef çalışma sayfasında `importCustomObjects` çağırın ve başlangıç satırını/sütununu gerektiği gibi ayarlayın. |
| **Bölge‑spesifik başlık metni** | İçe aktarmadan önce başlık satırını manuel olarak doldurun, ardından `Cells.applyStyle` kullanarak tüm aralığa stili uygulayın. |

## Java'dan Excel'e sağlam dışa aktarım için profesyonel ipuçları

* **Geçici çalışma kitabını yeniden kullanın** – Her stil için yeni bir `Workbook` oluşturmak ek yük getirir. Birden fazla stil gerekiyorsa tek bir örnek tutun.  
* **İçe aktarmadan önce verileri doğrulayın** – Bir haritadaki null değerler boş hücre olur; listeyi ön işleyerek varsayılanlarla değiştirebilirsiniz.  
* **Kaynakları kapatın** – Aspose.Cells dahili olarak belleği yönetse de, kaydetmeden sonra `workbook.dispose()` çağırmak yerel kaynakları hemen serbest bırakır.  
* **`Workbook.setForceFullCalculation(true)`** ayarlayın eğer çalışma kitabınızda kaydetmeden önce değerlendirilmesi gereken formüller varsa.
