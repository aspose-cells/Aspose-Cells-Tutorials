# Java’da JSON Verileriyle Excel Çalışma Kitabı Nasıl Oluşturulur

Eğer **create Excel workbook java** ihtiyacınız varsa, geliştiriciler genellikle JSON verilerini bir elektronik tabloya yükleme zorluğuyla karşılaşırlar. Bu rehber, **populate Excel from JSON**, **convert JSON array excel** ve **populate workbook from json** işlemlerini temiz ve tekrarlanabilir bir şekilde nasıl yapacağınızı gösterir.

JSON ile çalışmak, hizmetlerin REST API'leri aracılığıyla veri sunması yaygın olduğunda ve Excel raporlama ve analiz için hâlâ tercih edilen format olduğunda sıkça karşılaşılan bir durumdur. Bu öğreticinin sonunda aşağıdaki özelliklere sahip çalıştırılabilir bir Java programına sahip olacaksınız:

* yeni bir Excel çalışma kitabı oluşturur,
* bir JSON dizisini (veya herhangi bir JSON yapısını) okur ve değerlerini hücrelere yazar,
* dosyayı diske kaydeder, böylece sonraki işlemler için hazır olur.

Örnek kodda kullanılan `SmartMarkerProcessor` sınıfını sağlayan Aspose.Cells for Java kütüphanesi dışında dış araçlara ihtiyaç yoktur.

## Önkoşullar

Başlamadan önce aşağıdakilere sahip olduğunuzdan emin olun:

| Gereklilik | Sebep |
|------------|-------|
| Java Development Kit (JDK) ≥ 8 | Örneği derlemek ve çalıştırmak için gereklidir |
| Maven veya Gradle (isteğe bağlı) | Bağımlılık yönetimini basitleştirir |
| Aspose.Cells for Java (v23.10 veya daha yeni) | `Workbook` ve `SmartMarkerProcessor` sınıflarını sağlar |
| JSON ve Java I/O temelleri | Veri akışını anlamanıza yardımcı olur |

Bir yapı aracı kullanmak istemiyorsanız, Aspose.Cells JAR dosyasını [Aspose web sitesinden](https://products.aspose.com/cells/java/) indirip projenizin sınıf yoluna manuel olarak ekleyebilirsiniz.

## Adım 1: Projeyi kurun ve Aspose.Cells bağımlılığını ekleyin

### Maven kullanıcıları

Aşağıdaki bağımlılığı `pom.xml` dosyanıza ekleyin:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Gradle kullanıcıları

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

Bir yapı aracı kullanmıyorsanız, indirdiğiniz JAR dosyasını `libs/` klasörüne koyun ve derlerken sınıf yoluna ekleyin:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## Adım 2: Yeni bir çalışma kitabı oluşturun ve SmartMarker işlemcisini yapılandırın

`SmartMarkerProcessor`, JSON değerlerini Excel hücrelerine eşlemeyi basitleştirir. `setArrayAsSingle(true)` çağrısı, işlemciye bir JSON dizisini tek bir değer olarak ele almasını söyler; bu, her öğenin bir satırdaki kendi hücresine yerleştirilmesi istendiğinde kullanışlıdır.

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**Neden önemli:**  
Çalışma kitabını önceden oluşturmak temiz bir tuval sağlar. `setArrayAsSingle(true)` yapılandırması, işlemcinin diziyi tek bir dizeye (ör. `["A","B","C"]`) dönüştürmesini engeller ve düzeni manuel olarak kontrol etmenize olanak tanır.

## Adım 3: Eklemek istediğiniz JSON verisini tanımlayın

Bu öğreticide basit bir JSON dizisi kullanıyoruz, ancak aynı yaklaşım nesneler, iç içe diziler veya karmaşık yapılar için de çalışır.

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**İpucu:** JSON dosyadan veya bir REST uç noktasından geliyorsa, sabit dizeyi `Files.readString(Paths.get("data.json"))` gibi bir kaynak okumasıyla değiştirin.

## Adım 4: Çalışma kitabını JSON verisiyle işleyin

Şimdi `SmartMarkerProcessor`'ı JSON dizisini ilk çalışma sayfasına eşlemeye bırakıyoruz. Varsayılan davranış, her öğeyi `A1` hücresinden başlayarak ardışık hücrelere yazar.

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

Arka planda, Aspose.Cells JSON'u ayrıştırır, geçici bir veri tablosu oluşturur ve değerleri çalışma sayfasına yazar. `ArrayAsSingle` değerini `true` olarak ayarladığımız için dizi öğeleri ilk satırda yatay olarak yerleştirilir.

## Adım 5: Çalışma kitabını bir dosyaya kaydedin

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

Programı çalıştırdığınızda çalışma dizininizde **CreatedFromJson.xlsx** adlı bir dosya görmelisiniz. Excel (veya uyumlu bir görüntüleyici) ile açtığınızda şu şekilde görüntülenir:

| A | B | C |
|---|---|---|
| A | B | C | *(değerler A1, B1, C1 hücrelerinde görünür)*

### Beklenen çıktı

```
Workbook saved to CreatedFromJson.xlsx
```

Ve Excel sayfası şu şekilde görünür:

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## Adım 6: Daha karmaşık JSON yapılarıyla çalışmak (isteğe bağlı)

### 6.1 Bir JSON nesnesinden çalışma kitabı doldurma

JSON bir dizi yerine nesne ise yine `SmartMarkerProcessor` kullanabilirsiniz. Örneğin:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

İşlemci, Excel şablonunuzda `&=title` ve `&=values` gibi Smart Marker'lar aracılığıyla başvurabileceğiniz adlandırılmış aralıklar (`title`, `month`, `values`) oluşturur.

### 6.2 İç içe bir JSON dizisini dikey listeye dönüştürme

Bazen dizinin bir satır yerine bir sütunu doldurması gerekir. İşleme başlamadan önce başlangıç hücresini manuel olarak ayarlayın:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

Şimdi **A**, **B**, **C** değerleri sırasıyla A2, A3, A4 hücrelerinde görünür.

## Yaygın hatalar ve nasıl önlenir

| Sorun | Neden | Çözüm |
|-------|-------|-------|
| **Dizi tek bir string olarak yazıldı** | `setArrayAsSingle(false)` (varsayılan) | `processor.setArrayAsSingle(true)` çağırın |
| **Kaydedilirken dosya bulunamadı** | Geçersiz yol veya yazma izinlerinin eksik olması | Mutlak bir yol kullanın veya dizinin var olduğundan emin olun |
| **JSON ayrıştırma hatası** | Geçersiz JSON dizesi | JSON'u bir araçla doğrulayın veya Jackson gibi bir kütüphane kullanarak dizeyi oluşturun |
| **Hücreler istem dışı üzerine yazıldı** | Aynı çalışma sayfasını başlangıç hücresi sıfırlanmadan birden fazla kez işlemek | Her `process` çağrısından önce `processor.setStartCell("A1")` çağırın |

## Pro ipucu: Çalışma kitabını şablon olarak yeniden kullanın

Her seferinde boş bir çalışma kitabı oluşturmak yerine, başlıklar, formüller veya stil içeren önceden tasarlanmış bir şablonu yükleyebilirsiniz:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

Bu yaklaşım, el yapımı bir Excel dosyasının görsel şıklığını, **populate workbook from json** otomasyonu ile birleştirir.
