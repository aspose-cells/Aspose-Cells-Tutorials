# 使用 SmartMarkerProcessor 在 Java 中生成工作表

如果您需要在 Excel 文件中 **how to generate worksheets**，本指南为您提供一个完整、可直接运行的解决方案。阅读前两句话后，您将了解如何从对象集合生成工作表和动态 Excel 表，并拥有一个只需一次方法调用即可自动化 Excel 创建的可运行代码示例。

在需要以编程方式 **populate excel workbook** 数据时，为每个员工、项目或其他实体创建单独的工作表是常见需求。本教程将逐步演示从设置模板到处理列表并保存最终文件的每一步，让您能够立即在自己的 Java 应用中应用此技术。

## 您将实现的目标

* 生成一个列出高级信息的主工作表。  
* 从 **multiple sheets from list** 数据创建工作表，每个工作表自动命名。  
* **Automate excel creation**，无需手动添加行或列。  
* **Populate excel workbook**，使用丰富的数据结构（对象、映射、数组）。  

前提条件：

* 已安装 Java 8 或更高版本。  
* 使用 Maven（或其他构建工具）添加 Aspose.Cells for Java 库。  
* 对 Java 集合有基本了解。  

> **专业提示：** SmartMarker 语法（`${EmployeeMaster}`）适用于任何实现 `java.util.Collection` 的集合类型。使用它可以保持模板的简洁和可维护性。

## 使用 SmartMarkerProcessor 生成工作表的步骤

本节包含实现 **how to generate worksheets** 的核心代码。我们将解释每行代码的重要性，而不仅仅是它的功能。

### 步骤 1：添加 Aspose.Cells 依赖

如果您使用 Maven，请在 `pom.xml` 中加入以下内容。该库提供本指南中使用的 `SmartMarkerProcessor` 类。

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **原因：** Aspose.Cells 在内部处理 Excel 文件 I/O、Smart Marker 解析和工作表管理，让您专注于数据而非低层文件操作。

### 步骤 2：准备 Excel 模板

创建一个名为 `EmployeeTemplate.xlsx` 的 Excel 文件，在单元格中放置 Smart Marker 占位符：

| A |
|---|
| `${EmployeeMaster}` |

当处理器运行时，它会将此占位符替换为包含每位员工一行的 **detail sheet**。

> **原因：** 占位符告诉处理器数据注入的位置。使用单独的模板可保持您的格式（字体、边框、列宽）不变。

### 步骤 3：定义数据模型

下面是一个最小的 `Employee` 类以及一个构建员工列表的辅助方法。该列表将用于演示 **multiple sheets from list**。

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **原因：** 普通的 Java 对象（POJO）直接映射到 Smart Marker 字段（`firstName`、`lastName`、`department`）。这使得 **populate excel workbook** 变得直接且类型安全。

### 步骤 4：设置 SmartMarkerProcessor

现在我们将所有内容连接起来。处理器将读取模板，替换标记，并创建一个名为 `EmployeeDetail` 的新工作表。

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

**关键行说明**

| 行 | 原因 |
|------|--------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | 加载已经包含 Smart Marker 占位符的模板。 |
| `data.put("EmployeeMaster", employees);` | 将 Java 列表绑定到标记 `${EmployeeMaster}`。 |
| `processor.setDetailSheetNewName("EmployeeDetail");` | 为生成的工作表赋予有意义的名称，而不是默认的 `Sheet1`。 |
| `processor.process(wb, data);` | **How to generate worksheets** —— 处理器读取标记，创建新工作表，并为每个 `Employee` 填充行。 |
| `wb.save("EmployeesReport.xlsx");` | 将 **dynamic excel sheets** 保存到磁盘。 |

### 步骤 5：验证输出

打开 `EmployeesReport.xlsx`。您应该看到两个工作表：

1. **Sheet1** – 原始模板（可隐藏或删除）。  
2. **EmployeeDetail** – 包含列 `firstName`、`lastName`、`department`，每位员工一行的 **dynamic excel sheet**。

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **此原因重要性：** 该文件现在包含 **multiple sheets from list**，无需手动循环或单元格定位。Smart Marker 引擎负责行创建、数据转换和格式继承。

### 步骤 6：处理边缘情况

#### 空数据列表

如果 `employees` 为空，处理器仍会创建 `EmployeeDetail` 工作表，但保持为空。您可以在处理前检查集合大小，以防止添加该工作表：

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### 超大列表

对于数千行数据，考虑增加内存分配（`-Xmx2g`）或使用 `processor.setAutoFitRows(false)` 来加快处理速度。

#### 按组自定义工作表命名

如果您需要为每个部门创建单独的工作表，可以使用 **multiple detail sheets**：

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

占位符 `${department}` 来自每个 `Employee` 对象，生成如 `Dept_Sales`、`Dept_Marketing` 等工作表。
