# 将自定义对象导入 Excel（Aspose.Cells – Java 指南）

如果您需要 **将自定义对象** 导入 Excel 工作表，本指南将使用 Aspose.Cells for Java 带您完整演示整个过程。您将看到如何 **将数据导入 Excel**、应用粗体标题样式，并生成可直接共享的 `.xlsx` 文件。

从 Java 导出表格数据通常需要手动逐单元格写入，这既容易出错又难以维护。通过利用 `importCustomObjects` API，您可以避免样板代码，保持数据模型完整，并获得细粒度的样式控制。

在本教程中，您将：

* 构建一个 Java `Map` 对象列表，模拟典型的数据表。
* 使用 Aspose.Cells 创建可复用的标题样式（粗体字体）。
* 在导入自定义对象时应用样式数组到工作表。
* 将工作簿保存到磁盘并验证结果。

唯一的前置条件是具备 Java 开发环境（建议 JDK 8+）以及 Aspose.Cells for Java 库。

---

## 您需要的条件

| Requirement | Reason |
|-------------|--------|
| JDK 8 或更高版本 | 编译并运行 Java 代码所必需。 |
| Aspose.Cells for Java（最新版本） | 提供 `Workbook`、`Worksheet` 和导入 API。 |

| 对输出文件所在文件夹的写入权限 | 工作簿将保存为 `ImportWithStyle.xlsx`。 |

```xml

    <groupId>com.aspose</groupId>

    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## 步骤 1：准备要导入的自定义对象

第一步是创建一个集合，表示您想放入 Excel 的行。在本例中，我们使用 `List<Map<String,Object>>`，其中每个 map 类似于一行，列名作为键。

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**为什么重要：**  
`importCustomObjects` 需要一个对象数组。使用 `Map` 可以保留列名，使 Aspose.Cells 能自动将它们映射到单元格。此做法类似 .NET 中的 `DataTable` 或 JDBC 的 `ResultSet`，便于在不同项目中复用代码。

---

## 步骤 2：定义导入时使用的标题样式

清晰的标题行有助于提升可读性。Aspose.Cells 允许您创建 `Style` 对象，将字体设为粗体，并通过 `ImportTableOptions` 数组传递。

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**为什么重要：**  
如果省略样式数组，标题将使用默认字体，可能不够突出。一次性准备好样式后，可避免对每行重复调用，从而保持导入逻辑简洁。

---

## 步骤 3：使用样式数组导入自定义对象

现在将数据和样式组合起来，调用 `importCustomObjects`。该方法从左上角（第 0 行，第 0 列）开始放置数据，并自动为标题行应用样式。

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**为什么重要：**  
`importCustomObjects` 会解析每个 map，根据键（`Name`、`Score`）创建列，并将对应的值写入单元格。`ImportTableOptions` 对象指示 Aspose.Cells 对第一行使用 `styleArray`，从而实现粗体标题，无需额外代码。

---

## 步骤 4：保存工作簿并验证输出

最后，将工作簿写入文件。生成的 Excel 文件包含一个已加样式的标题行，随后是数据行。

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**预期结果：**  

| **Name** | **Score** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

标题单元格（`Name`、`Score`）以粗体显示，符合步骤 2 中定义的样式。

## 常见变体和边缘情况

| Situation | Recommended adjustment |
|-----------|------------------------|
| **Different column order** | 确保 `Map` 键按所需顺序插入，或使用带注解字段的自定义 POJO 并提供 `PropertyDescriptor` 数组。 |
| **Large data sets (>10 000 rows)** | 增加 `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` 以避免 `OutOfMemoryError`。 |
| **Custom number formats** | 在 `styleArray` 中为数据行添加第二个 `Style`，例如将 `NumberFormat` 设置为 `"0"` 以显示整数分数。 |
| **Multiple worksheets** | 在每个目标工作表上调用 `importCustomObjects`，并根据需要调整起始行/列。 |
| **Locale‑specific header text** | 在导入前手动填充标题行，然后使用 `Cells.applyStyle` 将样式应用于整个范围。 |

---

## 提升 Java 导出 Excel 稳定性的专业技巧

* **复用临时工作簿** – 为每种样式创建新 `Workbook` 会增加开销。如需多种样式，保持单实例即可。  
* **导入前验证数据** – map 中的 null 会变成空单元格；可在预处理列表时用默认值替换。  
* **关闭资源** – 虽然 Aspose.Cells 会内部管理内存，保存后显式调用 `workbook.dispose()` 可及时释放本机资源。  
* **若工作簿包含公式**，在保存前调用 `Workbook.setForceFullCalculation(true)`，确保公式先行计算。
