# 如何在 Java 中使用 JSON 数据创建 Excel 工作簿

如果您需要 **create Excel workbook java**（创建 Excel 工作簿 Java），开发者经常面临将 JSON 数据加载到电子表格的挑战。本指南将向您展示如何 **populate Excel from JSON**（从 JSON 填充 Excel），包括如何 **convert JSON array excel**（将 JSON 数组转换为 Excel）以及 **populate workbook from json**（从 JSON 填充工作簿），以一种简洁、可重复的方式。

当服务通过 REST API 暴露数据时，使用 JSON 很常见，而 Excel 仍然是报告和分析的首选格式。完成本教程后，您将拥有一个可运行的 Java 程序，能够：

* 创建一个新的 Excel 工作簿，
* 读取 JSON 数组（或任何 JSON 结构）并将其值写入单元格，
* 将文件保存到磁盘，以供后续处理。

除了 Aspose.Cells for Java 库外，无需任何外部工具，该库提供了示例代码中使用的 `SmartMarkerProcessor`。

## 前提条件

在开始之前，请确保您具备以下条件：

| 前提条件 | 原因 |
|--------------|--------|
| Java Development Kit (JDK) ≥ 8 | 编译和运行示例所需 |
| Maven 或 Gradle（可选） | 简化依赖管理 |
| Aspose.Cells for Java (v23.10 或更高) | 提供 `Workbook` 和 `SmartMarkerProcessor` 类 |
| 基本的 JSON 与 Java I/O 知识 | 有助于理解数据流 |

如果您不想使用构建工具，可以从 [Aspose 网站](https://products.aspose.com/cells/java/) 下载 Aspose.Cells JAR，并手动将其添加到项目的类路径中。

## 第一步：设置项目并添加 Aspose.Cells 依赖

### Maven 用户

在您的 `pom.xml` 中添加以下依赖：

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Gradle 用户

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

如果您未使用构建工具，请将下载的 JAR 放入 `libs/` 文件夹，并在编译时将其包含在类路径中：

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## 第二步：创建新工作簿并配置 SmartMarker 处理器

`SmartMarkerProcessor` 简化了将 JSON 值映射到 Excel 单元格的过程。通过调用 `setArrayAsSingle(true)`，我们告诉处理器将整个 JSON 数组视为单个值，这在您希望每个元素占据行中各自单元格时非常有用。

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**为什么这很重要：**  
提前创建工作簿可为您提供一个干净的画布。配置 `setArrayAsSingle(true)` 可防止处理器将数组展平为单个字符串（例如 `["A","B","C"]`），而是让您手动控制布局。

## 第三步：定义要插入的 JSON 数据

在本教程中，我们使用一个简单的 JSON 数组，但相同的方法也适用于对象、嵌套数组或复杂结构。

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**提示：** 如果您的 JSON 来自文件或 REST 接口，请将字面字符串替换为从源读取的 `String`，例如 `Files.readString(Paths.get("data.json"))`。

## 第四步：使用 JSON 数据处理工作簿

现在我们让 `SmartMarkerProcessor` 将 JSON 数组映射到第一个工作表。默认行为是将每个元素写入从 `A1` 开始的连续单元格。

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

在幕后，Aspose.Cells 解析 JSON，创建临时数据表，并将值写入工作表。由于我们将 `ArrayAsSingle` 设置为 `true`，数组元素会水平放置在第一行。

## 第五步：将工作簿保存为文件

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

运行程序后，您应该会在工作目录中看到名为 **CreatedFromJson.xlsx** 的文件。使用 Excel（或任何兼容的查看器）打开它将显示：

| A | B | C |
|---|---|---|
| A | B | C | *(值显示在单元格 A1、B1、C1 中)*

### 预期输出

```
Workbook saved to CreatedFromJson.xlsx
```

Excel 表格如下所示：

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## 第六步：处理更复杂的 JSON 结构（可选）

### 6.1 从 JSON 对象填充工作簿

如果您的 JSON 是对象而不是数组，仍然可以使用 `SmartMarkerProcessor`。例如：

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

处理器将创建命名范围（`title`、`month`、`values`），您可以在 Excel 模板中使用 Smart Marker 如 `&=title` 和 `&=values` 来引用它们。

### 6.2 将嵌套 JSON 数组转换为垂直列表

有时您需要将数组填充到列而不是行。在处理之前手动设置起始单元格：

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

现在值 **A**、**B**、**C** 分别出现在单元格 A2、A3、A4 中。

## 常见陷阱及避免方法

| 问题 | 原因 | 解决方案 |
|-------|-------|-----|
| **数组写成单个字符串** | `setArrayAsSingle(false)`（默认） | 调用 `processor.setArrayAsSingle(true)` |
| **保存时文件未找到** | 路径无效或缺少写入权限 | 使用绝对路径或确保目录存在 |
| **JSON 解析错误** | JSON 字符串格式错误 | 使用工具验证 JSON，或使用如 Jackson 的库生成字符串 |
| **单元格意外被覆盖** | 多次处理同一工作表而未重置起始单元格 | 在每次 `process` 调用前调用 `processor.setStartCell("A1")` |

## 专业提示：将工作簿用作模板

与其每次都从空白工作簿开始，您可以加载预先设计好的模板，其中已包含标题、公式或样式：

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

此方法将手工打造的 Excel 文件的视觉精致与 **populate workbook from json**（从 JSON 填充工作簿）的自动化相结合。
