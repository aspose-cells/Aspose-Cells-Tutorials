# 如何在 Java 中使用 Aspose.Cells 更改图表刻度方向

## 介绍

## 快速答案
- **什么库处理图表标签旋转？** Aspose.Cells for Java.
- **哪个 Maven 构件提供此功能？** `com.aspose:aspose-cells`.
- **我可以将标签角度设置为垂直吗？** 是的，使用 `ChartTextDirectionType.VERTICAL`。
- **生产使用是否需要许可证？** 需要永久许可证；临时许可证可用于评估。
- **API 是否兼容 Java 8 及更高版本？** 是的，支持 Java 8‑21。

## 什么是更改图表刻度方向？
**更改图表刻度方向** 是指调整类别轴刻度标签的方向（例如水平、垂直或旋转），以便它们在图表区域内更好地适配。此操作通过 Aspose.Cells 中 `ChartAxis` 对象的 `setTickLabelDirection` 方法完成。

## 为什么使用 Aspose.Cells for Java 来旋转刻度标签？
Aspose.Cells 处理 **150 多种文件格式**，能够在不将整个文件加载到内存的情况下处理包含 **500+ 工作表** 的工作簿，并且对典型图表大小的标签旋转耗时 **低于 0.2 秒**。这些量化的能力使其成为企业级 Excel 自动化的可靠选择。

## 前置条件
- **Aspose.Cells for Java** 版本 25.3 或更高。
- Java 8+ 开发工具包以及您喜欢的 IDE（IntelliJ IDEA、Eclipse 等）。
- 用于依赖管理的 Maven 或 Gradle。
- 临时或永久的 Aspose.Cells 许可证（见下文许可证章节）。

## 设置 Aspose.Cells for Java
首先，将 Aspose.Cells 依赖添加到您的构建文件中。

**Maven**  
```xml
<dependency>
    <groupId>com.aspose</groupId>

    <version>25.3</version>
    <classifier>jdk17</classifier>
</dependency>
```

**Gradle**  
```gradle
implementation 'com.aspose:aspose-cells:25.3:jdk17'
```

## 如何在 Java 中更改图表刻度方向？
要修改刻度标签方向，您必须加载目标工作簿，获取特定图表，访问其类别轴，并使用所需的 `ChartTextDirectionType` 调用 `setTickLabelDirection`。此过程只需几行 Java 代码即可完成，便于集成到现有的自动化工作流中。

1. 加载包含您想要修改的图表的工作簿。  
2. 通过索引检索工作表和图表对象。  
3. 访问类别轴 (`getCategoryAxis()`) 并使用所需的 `ChartTextDirectionType` 调用 `setTickLabelDirection`。  
4. 将工作簿保存为新文件。

## 实现指南

### 加载工作簿和图表
`Workbook` 类在内存中表示整个 Excel 文件。`Worksheet` 类提供对各个工作表的访问，`Chart` 类表示特定的图表。

```java
Workbook workbook = new Workbook("input.xlsx");               // 1️⃣ Load file
Worksheet sheet = workbook.getWorksheets().get(0);            // 2️⃣ First sheet
Chart chart = sheet.getCharts().get(0);                       // 3️⃣ First chart on the sheet
```

### 更改刻度标签方向
`ChartAxis` 控制所有轴相关属性。`ChartTextDirectionType` 是定义方向的枚举。

```java
ChartAxis categoryAxis = chart.getCategoryAxis();            // Access category axis
categoryAxis.setTickLabelDirection(ChartTextDirectionType.HORIZONTAL); // 4️⃣ Set direction
```

- `ChartTextDirectionType.HORIZONTAL` → 标签从左到右读取。  
- `ChartTextDirectionType.VERTICAL` → 标签从上到下读取。  
- `ChartTextDirectionType.ROTATED_45` → 标签旋转 45°（在新版本中可用）。

### 保存工作簿
调整轴后，保存更改：

```java
workbook.save("output.xlsx", SaveFormat.XLSX);
```

## 常见问题及解决方案
- **图表索引不正确** – 通过检查 `sheet.getCharts().getCount()` 来确认图表是否存在。  
- **许可证未应用** – 如果看到水印，请确保在任何工作簿操作之前加载许可证文件。  
- **不支持的方向** – 某些旧图表类型仅支持水平标签；升级到最新的 Aspose.Cells 版本以访问所有枚举值。

## 实际应用
在空间受限的场景中，更改刻度标签方向尤为有用：

1. **金融时间线** – 水平标签在密集的时间序列图表上保持日期字符串可读。  
2. **科学图形** – 垂直标签为更长的变量名释放水平空间。  
3. **业务仪表板** – 旋转标签防止多类别柱状图中的文字重叠。

## 性能考虑因素
在处理包含 **数百个图表** 的工作簿时，请遵循以下最佳实践：

- 仅加载一次工作簿并重复使用同一 `Workbook` 实例。  
- 在循环中应用标签更改，然后仅调用一次 `workbook.save` 以最小化 I/O。  
- 仅在需要在修改后重新计算公式时使用 `setCalculateFormula` 标志。

## 常见问答

**问：我可以将刻度标签旋转到任意角度吗？**  
答：Aspose.Cells 目前仅支持预定义的枚举值（水平、垂直、45°）。若需自定义角度，可将旋转与 `setTickLabelAlignment` 结合使用。

**问：API 能够处理受密码保护的 Excel 文件吗？**  
答：可以。使用 `new Workbook("file.xlsx", new LoadOptions(LoadFormat.XLSX) {{ setPassword("pwd"); }})` 加载工作簿。

**问：在一个工作簿中可以修改的图表数量有限制吗？**  
答：没有硬性限制；性能取决于可用内存。处理包含 1,000 个图表的工作簿通常在标准服务器上在 30 秒以内完成。

**问：如何以编程方式应用临时许可证？**  
答：`License` 类在运行时加载并应用您的 Aspose.Cells 许可证文件。在任何 Aspose.Cells 操作之前，创建 `License` 对象并调用 `setLicense("Aspose.Total.Java.lic")`。

**问：更改刻度方向会影响现有的数据系列吗？**  
答：不会。此操作仅修改轴标签的渲染，数据值保持不变。
