# 如何使用 C# 创建带自定义格式的 Excel 工作簿并保存为 XLSX

如果您需要 **创建 Excel 工作簿 C#**，实现导入数据、应用自定义数字格式以及更改单元格字体颜色，本教程将一步步演示。您将获得一个可直接运行的示例，几秒钟内生成带样式的 `StyleArrayImport.xlsx` 文件。

在 C# 中操作 Excel 往往需要重复的手动步骤——定义格式、设置颜色、记得正确保存文件。阅读完本指南后，您将实现这些任务的自动化，专注于数据本身，而不是 UI。

您将学习如何：

* 将 `DataTable` 导入工作表，
* 使用 `StyleArray` **应用自定义数字格式** 并 **更改单元格字体颜色**，
* 通过一次方法调用 **将工作簿保存为 XLSX**，
* 验证 **format imported data excel** 的格式是否如预期显示。

唯一的前置条件是引用 **Aspose.Cells for .NET** 库（或任何提供 `Workbook`、`Worksheet`、`StyleArray` 的兼容 API）。代码面向 .NET 6+，但在早期版本上只需少量调整即可运行。

## 步骤 1：准备示例 DataTable

首先，创建一个 `DataTable`，模拟您通常从数据库或其他来源获取的数据。该表包含 **Name** 列（字符串）和 **Amount** 列（decimal），后者将在后面进行格式化。

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**为什么重要：** 使用 `DataTable` 可以让导入逻辑独立于数据源，这在从数据库、CSV 文件或 API 生成报表时是一种常见模式。

## 步骤 2：定义 StyleArray 以 **应用自定义数字格式** 并 **更改单元格字体颜色**

`StyleArray` 让您将格式化指令打包，在从 `DataTable` 导入的每个单元格上一次性应用。在本例中我们：

* 将 `Number` 设置为 `#,##0.00` —— 常见的会计格式，带千位分隔符，
* 将 `FontColor` 设置为 `Color.Blue` —— 使数字更突出。

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**为何使用 StyleArray？** 在导入时一次性应用样式，可避免对工作表进行第二遍遍历，从而提升大数据集的性能。

---

## 步骤 3：**创建 Excel 工作簿 C#** —— 实例化 Workbook 并获取第一个 Worksheet

现在我们创建一个空工作簿，并获取第一个工作表（索引 0）的引用。该工作表将作为导入数据的目标。

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**说明：** `Workbook` 代表整个 Excel 文件，`Worksheet` 代表单个标签页。默认工作簿仅包含一个工作表，已足够满足大多数简单报表需求。

---

## 步骤 4：使用 **StyleArray** 导入 DataTable 以 **format imported data excel**

`ImportDataTable` 方法将表的行列复制到工作表，从单元格 `A1`（第 0 行，第 0 列）开始。`true` 参数表示包含列标题。因为我们传入了 `styleArray`，每个导入的单元格都会获得自定义数字格式和字体颜色。

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**内部工作原理：** Aspose.Cells 会遍历每一行，写入值后再应用 `styleArray` 中定义的样式。数字将显示千位分隔符和两位小数，文本则以蓝色呈现。

---

## 步骤 5：**将工作簿保存为 XLSX** —— 将文件写入磁盘

最后，将工作簿持久化为 `.xlsx` 文件。您可以将路径改为机器上任意可写目录。

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**结果验证：** 在 Excel 中打开生成的文件。您应看到三行数据，**Amount** 列已使用千位分隔符、两位小数，并以蓝色字体显示。这表明 **format imported data excel** 步骤已成功。

## 完整工作示例

将下面的代码块完整复制到新的控制台项目中并运行。无需额外代码。

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**控制台预期输出：**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

打开文件并验证 **Amount** 列的值如 `1,234.56`，且为蓝色字体。

## 常见问题与边缘情况

| 问题 | 解答 |
|------|------|
| *我可以为不同列应用不同的格式吗？* | 可以。导入后，获取列的 `Style` 对象（`worksheet.Cells.Columns[1].Style`），并设置不同的 `Number` 或 `FontColor`。 |
| *如果需要格式化日期而不是数字怎么办？* | 将 `styleArray.Number = "mm-dd-yyyy"`，并可选地为日期单元格设置 `styleArray.FontColor`。 |
| *蓝色字体在深色 Excel 主题下是否可见？* | 在深色背景上蓝色可能难以阅读。可使用更浅的色调（`Color.LightBlue`）或对比度更高的颜色（`Color.Black`）。 |
| *如何导入非常大的 DataTable（数十万行）？* | 使用带 `ImportDataTableOptions` 重载的 `ImportDataTable` 进行流式导入，或将数据拆分到多个工作表，以避免超出 Excel 的行限制（1,048,576 行）。 |
| *能导出为 CSV 而不是 XLSX 吗？* | 将 `SaveFormat.Xlsx` 替换为 `SaveFormat.Csv`。请注意，CSV 为纯文本格式，格式信息（数字格式、字体颜色）会丢失。 |

## 生产环境使用技巧

* **专业技巧：** 如果需要对多个工作表应用相同的格式，请缓存 `Style` 对象；为每次导入创建新的 `StyleArray` 会增加开销。
* **注意文化差异：** `Number` 模式 `#,##0.00` 使用不变文化。如果需要本地化的分隔符，请使用 `NumberFormatInfo`，或让 Excel 根据用户的区域设置自动处理。
* **错误处理：** 将 `Save` 调用包装在 try‑catch 块中，以捕获 I/O 异常（例如权限不足或文件被锁定）。
