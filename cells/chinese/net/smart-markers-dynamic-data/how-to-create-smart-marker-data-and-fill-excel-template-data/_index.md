# 如何创建 Smart Marker 数据并填充 Excel 模板数据

如果您需要为 Excel 工作簿 **创建 Smart Marker 数据**，Aspose.Cells Smart Markers 能让这变得轻而易举。本教程展示了如何使用几行 C# 代码 **填充 Excel 模板数据**。

您将学习如何在模板中嵌入 Smart Marker 标记、提供数据源、运行处理器并保存填充后的文件。无需任何外部工具——只需 Aspose.Cells for .NET 和一个基本的 C# 项目。

## 您需要的环境

- .NET 6.0 或更高（代码同样适用于 .NET Framework 4.7+）
- Aspose.Cells for .NET（NuGet 包 `Aspose.Cells`）
- 包含 Smart Marker 标记（如 `${Comment:fieldName}`）的 Excel 工作簿
- C# IDE（Visual Studio、Rider 或 VS Code）

> **专业提示：** 将工作簿放在与项目相同的文件夹中，或使用绝对路径，以避免文件未找到错误。

## 使用 Aspose.Cells 创建 Smart Marker 数据

解决方案的核心是 `SmartMarkerProcessor`。它会扫描工作表中的标记，从数据源中提取匹配的值，并将结果写回工作表。

```csharp
using Aspose.Cells;
using System;

// 1️⃣ Load the workbook that contains Smart Marker tags.
Workbook workbook = new Workbook("Template.xlsx");

// 2️⃣ Get the worksheet where the tags reside.
Worksheet ws = workbook.Worksheets[0];

// 3️⃣ Prepare the data source that supplies values for the markers.
var dataSource = new[]
{
    new { fieldName = "Sample comment text generated by C#." }
};

// 4️⃣ Create a SmartMarkerProcessor instance.
SmartMarkerProcessor processor = new SmartMarkerProcessor();

// 5️⃣ Process the worksheet, replacing Smart Marker tags with data from the source.
processor.Process(ws, dataSource);

// 6️⃣ Save the populated workbook.
workbook.Save("Result.xlsx");
```

### 每行代码的意义

1. **加载工作簿** 为处理器提供一个具体的文件进行操作。  
2. **选择工作表** 确保处理器扫描正确的工作表；您可以通过索引或名称定位任意工作表。  
3. **数据源** 是一个匿名对象数组。每个属性名（`fieldName`）必须与 `${Comment:fieldName}` 中的标记名称匹配。  
4. **`SmartMarkerProcessor`** 是解析标记并执行替换的引擎。  
5. **`Process`** 执行核心工作：读取每个 `${...}` 标记，在数据源中查找对应属性，并将值写入单元格。  
6. **保存工作簿** 将更新后的文件写入磁盘，供后续使用。

## 准备 Excel 模板以 **填充 Excel 模板数据**

1. 打开一个新的 Excel 工作簿。  
2. 在需要动态内容的任意单元格中输入 Smart Marker 标记，例如：  

   ```
   ${Comment:fieldName}
   ```

3. 将文件另存为 `Template.xlsx`。  

标记语法遵循 `${<CollectionName>:<PropertyName>}` 模式。在本简易示例中我们省略了集合名称，使用默认集合，即传递给 `Process` 的数据源。

> **特殊情况：** 如果标记引用的属性在数据源中不存在，Aspose.Cells 会保持单元格原样不变。务必确保属性名称完全匹配，包括大小写。

## 为 **使用 Aspose.Cells Smart Markers** 构建数据源

您可以提供任意可枚举集合——数组、`List<T>`、`DataTable`，甚至自定义对象。处理器会遍历集合，并在使用表格样式标记时为每个项目重复行。

```csharp
// Example with a List<T>
var comments = new List<Comment>
{
    new Comment { fieldName = "First comment." },
    new Comment { fieldName = "Second comment." }
};

processor.Process(ws, comments);
```

```csharp
public class Comment
{
    public string fieldName { get; set; }
}
```

当提供多行数据时，Aspose.Cells 会自动扩展模板区域以容纳所有项目，这在生成报表、发票或数据驱动表格时非常有用。

## 使用 **Aspose.Cells Smart Markers** 处理工作表

`Process` 方法可以接受可选设置，例如：

- `SmartMarkerOptions` 用于控制空单元格的处理方式。  
- `DataSourceOptions` 用于指定不同的集合名称。

```csharp
SmartMarkerOptions options = new SmartMarkerOptions
{
    // Preserve empty cells as blanks instead of removing them.
    PreserveEmptyCells = true
};

processor.Process(ws, dataSource, options);
```

这些选项让您对 **填充 Excel 模板数据** 操作拥有细粒度的控制，确保输出符合您的格式要求。

## 保存结果并验证输出

处理完成后，您可以将工作簿保存为 Aspose.Cells 支持的任何格式，如 XLSX、CSV 或 PDF。

```csharp
workbook.Save("Result.pdf", SaveFormat.Pdf);
```

打开 `Result.xlsx`（或 `Result.pdf`），验证 `${Comment:fieldName}` 占位符已被 **Sample comment text generated by C#** 替换。如果单元格仍显示原始标记，请再次检查数据源中的属性名称。

## 常见问题及规避方法

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 标记未被替换 | 属性名称不匹配（例如 `fieldname` 与 `fieldName`） | 确保大小写完全一致 |
| 行未复制 | 数据源仅包含单个对象，而模板期望表格 | 提供包含多项的集合 |
| 保存工作簿时崩溃 | 使用了过期的 Aspose.Cells 版本 | 升级到最新的 NuGet 包 |
| 格式丢失 | 处理器覆盖了单元格样式 | 使用 `SmartMarkerOptions.PreserveCellFormatting = true` 保留样式 |

## 完整可运行示例

下面是一个独立的程序，您可以直接复制、粘贴并运行。

```csharp
using Aspose.Cells;
using System;
using System.Collections.Generic;

namespace SmartMarkerDemo
{
    class Program
    {
        static void Main()
        {
            // Load the template that contains the Smart Marker tag ${Comment:fieldName}
            Workbook workbook = new Workbook("Template.xlsx");
            Worksheet ws = workbook.Worksheets[0];

            // Create a list of data objects – each object maps to the marker property.
            var data = new List<Comment>
            {
                new Comment { fieldName = "First generated comment." },
                new Comment { fieldName = "Second generated comment." },
                new Comment { fieldName = "Third generated comment." }
            };

            // Initialise the processor and run it.
            SmartMarkerProcessor processor = new SmartMarkerProcessor();
            processor.Process(ws, data);

            // Save the populated workbook.
            workbook.Save("Result.xlsx");
            Console.WriteLine("Smart marker processing complete. Check Result.xlsx.");
        }
    }

    public class Comment
    {
        public string fieldName { get; set; }
    }
}
```

**预期结果：** 在 `Result.xlsx` 中，原本包含 `${Comment:fieldName}` 的单元格会展开为三行，每行填入 `data` 列表中对应的评论文本。
