# 如何在将 Excel 保存为 HTML 时嵌入字体（使用 C#）

在将 Excel 工作簿保存为 HTML 时嵌入字体是一个常见需求，用于在不同浏览器中保持电子表格的精确外观。如果您需要在导出 Excel 为 HTML 时保留原始字体，本指南将为您展示一个完整、可直接运行的解决方案。

您将学习如何 **export Excel to HTML**、**convert Excel to HTML** 并嵌入字体，以及如何避免在客户端机器上导致布局错乱的典型“missing‑font”问题。无需外部工具——只需 Aspose.Cells 库和几行 C# 代码。

## 前提条件

* .NET 6.0（或更高版本）已安装。
* 拥有 **Aspose.Cells for .NET** 的授权副本——免费试用版可用于测试。
* 使用 Visual Studio 2022 或 VS Code 等 IDE。

如果您已经具备上述条件，可以直接进入代码部分。

## 步骤 1：创建工作簿并添加示例数据

首先我们生成一个小型工作簿，以便您看到嵌入字体的效果。下面的代码创建了一个工作表，写入了几个单元格，并应用了自定义字体。

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### 为什么要添加自定义字体

只有当工作簿使用的字体可能在客户端设备上不存在时，嵌入字体才有意义。通过显式设置 **Arial**（或其他任何字体），我们可以验证 HTML 输出确实包含了字体数据。

## 步骤 2：配置 HTML 保存选项以嵌入字体

Aspose.Cells 提供了 `HtmlSaveOptions` 类。将 `EmbedFonts = true` 设置为 true，告诉库将所需的字体文件直接嵌入生成的 HTML 中，作为 Base64 编码的 data URI。

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### “在 HTML 中嵌入字体” 实际上是怎么做的

当 `EmbedFonts` 为 true 时，Aspose.Cells 会从系统（或工作簿的嵌入字体集合）中提取字体文件并将其转换为 **Base64** 字符串。这些字符串随后被放入使用 `@font-face` 的 `<style>` 块中。生成的 HTML 可以在任何设备上打开，而无需安装原始字体。

## 步骤 3：将工作簿保存为带嵌入字体的 HTML

现在我们将工作簿写入磁盘。文件将包含字体数据，因此在任何现代浏览器中打开时，都能显示与原始 Excel 文件完全相同的排版。

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### 预期结果

* `embedded.html` 位于 `output` 文件夹中。
* 在 Chrome、Edge 或 Firefox 中打开该文件时，即使浏览器所在机器没有 Arial，也会显示带 **Arial** 文本的工作表。
* 检查 HTML 源码会发现一个 `<style>` 块，其中包含一个 `@font-face` 规则，带有长串 `src: url(data:font/ttf;base64,…)` 声明——这就是嵌入的字体。

## 步骤 4：在另一台机器上验证 HTML 是否正常工作（可选）

为确保嵌入成功，请执行以下操作：

1. 将 `output/embedded.html` 复制到另一台没有安装自定义字体的计算机（或虚拟机）上。
2. 在浏览器中打开该文件。
3. 布局和排版应与原始 Excel 视图保持一致。

如果字体回退为通用字体，请再次确认构建机器上字体文件可访问且您拥有读取权限。

## 常见问题与边缘情况

### 嵌入会增加文件大小吗？

是的。嵌入 TrueType 或 OpenType 字体会使 HTML 文件增加 **数十 KB**。对于包含大量不同字体的大型工作簿，建议考虑：

* 对字体进行子集化（仅保留使用的字符）——Aspose.Cells 会对大多数常用字体自动执行此操作。
* 如果不需要嵌入图像，可将 `ExportEmbeddedImages = false`。

### 如果只想嵌入特定字体怎么办？

`HtmlSaveOptions` 并未提供直接的白名单，但您可以在调用 `Save` 之前 **限制工作簿中使用的字体** 来控制出现的字体。删除不必要的字体分配或将其替换为标准的 Web 安全字体。

### 转换为其他格式（例如 PDF）时可以嵌入字体吗？

`PdfSaveOptions` 同样具有 `EmbedFonts` 属性。概念相同：将字体数据嵌入，以便 PDF 在任何阅读器中都能正确渲染。

## 完整、可运行的示例

下面是完整的程序代码，您可以复制粘贴到新的控制台项目中。

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

运行该程序会生成一个 **包含嵌入 Arial 字体的 HTML 文件**，确保无论在何处打开文件都能保持视觉一致性。

## 结论

现在您已经了解了使用 C# **在将 Excel 保存为 HTML 时嵌入字体** 的方法。通过将 `HtmlSaveOptions.EmbedFonts = true` 配置好，您可以可靠地 **export Excel to HTML** 和 **convert Excel to HTML**，而无需担心客户端缺少字体。此技术对于基于 Web 的报表、适合邮件的仪表板，或任何以 HTML 形式共享 Excel 派生内容的场景都至关重要。
