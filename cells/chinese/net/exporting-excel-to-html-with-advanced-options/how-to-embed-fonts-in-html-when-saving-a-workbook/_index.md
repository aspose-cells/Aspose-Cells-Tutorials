# 在保存工作簿时如何在 HTML 中嵌入字体

如果您在导出电子表格时需要**在 HTML 中嵌入字体**，本教程提供了一个完整、可直接运行的解决方案。无论您是构建报告门户还是客户端分析视图，嵌入字体都能确保渲染后的 HTML 与原始工作簿完全一致，且不受查看者已安装字体的影响。

您还将学习使用 Aspose.Cells **将工作簿保存为 HTML** 的最佳方法，了解常见陷阱，并获取处理大型工作簿或自定义字体文件的技巧。无需外部文档——本指南包含您所需的一切。

## 前提条件

- .NET 6.0 或更高（代码同样适用于 .NET Framework 4.7+）
- 有效的 Aspose.Cells for .NET 许可证（或使用免费评估模式）
- 基本的 C# 知识以及如 Visual Studio 2022 的 IDE
- 您想要嵌入的 TrueType（.ttf）或 OpenType（.otf）字体文件（必须对运行进程可访问）

## 第一步：设置项目并导入 Aspose.Cells

创建一个新的控制台应用程序并添加 Aspose.Cells NuGet 包：

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

然后打开 **Program.cs** 并添加所需的 `using` 指令：

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **小贴士：** 将自定义字体放在项目根目录下名为 `fonts` 的文件夹中。这使得解决方案更便携，并且以后引用它们更加方便。

## 第二步：创建或加载工作簿

为了演示，我们将创建一个包含少量样式单元格的简单工作簿：

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **为什么这很重要：** 如果省略自定义样式，导出的 HTML 将回退到浏览器的默认字体，失去 **在 HTML 中嵌入字体** 的意义。

## 第三步：配置 `HtmlSaveOptions` 以嵌入字体

**在 HTML 中嵌入字体** 的核心在于 `HtmlSaveOptions` 类。将 `EmbedFonts = true` 设置为 true，告诉 Aspose.Cells 将所有引用的 TrueType/OpenType 字体直接嵌入生成的 HTML 中，作为 Base64 编码的 data URI。

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### 嵌入工作原理

当 `EmbedFonts` 为 `true` 时，Aspose.Cells 会扫描工作簿的样式定义，定位系统（或您添加的 `fonts` 文件夹）中的相应字体文件，读取其二进制数据，并注入类似以下的 `<style>` 块：

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

由于字体数据直接编码在 HTML 中，即使在未安装该字体的机器上，页面也能正确渲染。

## 第四步：将工作簿保存为 HTML

现在您可以使用已配置的选项 **将工作簿保存为 HTML**。选择一个应用程序可写入的目录（例如 `output`）。

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

运行程序会生成一个 `report.html` 文件。使用任意现代浏览器打开它，您会看到 “Quarterly Sales” 标题使用 **Pacifico** 字体渲染，即使操作系统未安装该字体。

### 预期输出

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

`src:` 属性包含一长串 Base64 字符串——这就是实现 **在 HTML 中嵌入字体** 的嵌入式字体数据。

## 第五步：验证字体嵌入并排除故障

1. **在 Chrome 或 Edge 中打开 HTML 文件。** 如果自定义字体出现，则嵌入成功。  
2. **检查页面源代码。** 查找 Aspose.Cells 生成的 `@font-face` 规则。  
3. **常见问题：**  
   - *缺少字体文件：* 确保字体文件可访问。您可以显式将文件夹添加到搜索路径：

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *HTML 文件过大：* 嵌入大量字体会导致文件膨胀。使用 `ExportToSingleFile = false` 将字体保留为资源文件夹中的独立 `.ttf` 文件。  

   - *不支持的字体格式：* Aspose.Cells 仅嵌入 TrueType（`.ttf`）和 OpenType（`.otf`）字体。请在嵌入前将其他格式转换为支持的格式。

## 完整工作示例

下面是完整的程序代码，您可以直接复制、粘贴并运行，无需修改（除可选的许可证行外）。

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

运行此程序会生成 `output/report.html`。打开该文件，您将看到 **Pacifico** 字体正确渲染——展示了在 **将工作簿保存为 HTML** 时 **在 HTML 中嵌入字体** 的效果。

## 常见问题

| Question | Answer |
|----------|--------|
| *我可以只嵌入特定的字体吗？* | 可以。将 `htmlOpt.EmbedAllFonts = false`（在新版本中可用），并使用 `htmlOpt.FontsToEmbed` 列出确切的字体名称。 |
| *如果需要为多个工作表嵌入字体怎么办？* | 将 `ExportActiveWorksheetOnly = false`，这样会导出所有工作表，Aspose.Cells 将嵌入整个工作簿中使用的字体。 |
| *嵌入的字体在移动浏览器上能工作吗？* | 现代移动浏览器支持 Base64 编码的字体，只要字体格式受支持（TTF 或 OTF），嵌入的字体即可正确渲染。 |
| *HTML 文件会变得多大？* | 嵌入一个 200 KB 的 TrueType 字体会大致增加相同大小的 HTML（Base64 会增加约 33 % 的开销）。如果有很多字体，建议导出到文件夹（`ExportToSingleFile = false`），以保持 HTML 轻量。 |
