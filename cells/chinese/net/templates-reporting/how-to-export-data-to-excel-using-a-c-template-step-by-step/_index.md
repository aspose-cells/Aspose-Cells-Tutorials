# 如何使用 C# 模板导出数据到 Excel – 步骤指南

如果您需要 **将数据导出到 Excel**，本指南提供了一个完整的端到端解决方案。通过加载已经包含 Smart Marker 标记的 Excel 模板，您可以 **自动生成 Excel**，并生成精美的 **employee report Excel**，无需编写逐单元格的代码。

您将了解如何：

* 加载定义布局的 Excel 模板（`load excel template`）。
* 将员工对象列表填充到模板中。
* 生成最终工作簿并保存为 `output.xlsx`。

所有必需的代码已包含，您可以直接复制、粘贴并运行。

## 前置条件

* .NET 6.0 或更高（该代码同样适用于 .NET Framework 4.7+）。  
* **Aspose.Cells for .NET** NuGet 包——提供 `Workbook`、`SmartMarkerProcessor` 与 Smart Marker 支持。  
* 一个名为 `YOUR_DIRECTORY` 的文件夹，内部包含 `template.xlsx`。模板应在需要显示数据的单元格中放置类似 `&=EmployeeList.Name` 的 Smart Marker 标记。

> **专业提示：** 将模板放在同一项目文件夹下，并将其 *Copy to Output Directory* 属性设为 *Copy always*，这样在调试时路径能够正确解析。

## 完整源代码

```csharp
using System;
using System.Collections.Generic;
using Aspose.Cells;

namespace ExcelExportDemo
{
    // Simple POCO that represents an employee record
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Step 1: Load the Excel template that contains Smart Marker tags
            string templatePath = @"YOUR_DIRECTORY\template.xlsx";
            Workbook wb = new Workbook(templatePath);

            // Step 2: Prepare a data source – a list of employee objects
            List<Employee> employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Step 3: Create a SmartMarkerProcessor instance
            SmartMarkerProcessor sp = new SmartMarkerProcessor();

            // Step 4: Apply the employee data to the workbook using the processor
            // The tag &amp;=EmployeeList.Name in the template will be replaced with each employee's name,
            // and &amp;=EmployeeList.Position will be replaced with the corresponding position.
            sp.Process(wb, employeeList);

            // Step 5: Save the populated workbook
            string outputPath = @"YOUR_DIRECTORY\output.xlsx";
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

### 代码功能概述

| 步骤 | 为什么重要 | 关键代码 |
|------|------------|----------|
| **加载 Excel 模板** | 重用预先设计的布局可节省时间并保证样式一致。 | `Workbook wb = new Workbook(templatePath);` |
| **准备数据源** | Smart Marker 支持任意 `IEnumerable` 集合；这里使用 `Employee` 列表。 | `List<Employee> employeeList = …` |
| **创建处理器** | `SmartMarkerProcessor` 解析模板，查找标记并注入数据。 | `SmartMarkerProcessor sp = new SmartMarkerProcessor();` |
| **处理数据** | 处理器将每个 Smart Marker 标记替换为对应的属性值。 | `sp.Process(wb, employeeList);` |
| **保存工作簿** | 最终文件可发送给用户、存储在服务器或作为邮件附件。 | `wb.Save(outputPath);` |

结果是一个 **employee report Excel** 文件，每行包含员工的姓名和职位，正好对应原始模板中放置标记的位置。

## 加载 Excel 模板

当您使用 `new Workbook(path)` **load excel template** 时，Aspose.Cells 会读取整个工作簿——包括样式、公式以及 Smart Marker 占位符。这种方式优于从头创建工作簿，因为：

* **设计可控** – 设计师可以在不触及代码的情况下格式化标题、添加公司徽标、设置列宽。  
* **版本管理** – 更新模板无需重新编译应用程序。  
* **本地化** – 可以为不同语言维护不同的模板文件。

如果您倾向于使用纯 .NET 方案而不依赖第三方库，也可以考虑 **ClosedXML** 或 **EPPlus**，但它们缺少内置的 Smart Marker 支持，这意味着您必须编写循环逐单元格复制数据。

## 使用 Smart Marker 自动生成 Excel

Smart Marker 是形如 `&=Collection.Property` 的占位符。处理器运行时：

* 遍历集合（本例中的 `employeeList`）。  
* 对每个项目，将属性值写入对应单元格。  
* 根据需要自动扩展行或列。

此机制 **自动生成 Excel**，消除了手动迭代的逻辑。相同模式同样适用于订单、发票、库存列表等任何数据结构。

### 常见变体

| 变体 | 实现方式 |
|------|----------|
| **多个集合** | 添加更多列表（例如 `List<Department>`），并使用不同的标记如 `&=DepartmentList.Name` 引用。 |
| **嵌套集合** | 使用点符号：`&=EmployeeList.Projects.ProjectName`，其中 `Projects` 是 `Employee` 内的集合属性。 |
| **条件格式** | 在模板中放置 Excel 条件格式规则，处理器会在生成的行中保留该规则。 |

## 创建 employee report Excel

**employee report Excel** 代表一种典型的业务场景：管理者需要一份可打印的员工名单。通过在模板中直接嵌入 Smart Marker 标记，您可以获得：

* 带有粗体字体和背景色的标题行。  
* 根据数据自动调整列宽。  
* 可选的合计行（例如员工数量），可使用标准 Excel 公式计算。

如果需要添加合计行，只需在模板中放置类似 `=COUNTA(A2:A100)` 的公式，处理器不会对其进行干扰。

## 生成 Excel 模板 C# – 最佳实践

在编写 **generate Excel template C#** 代码时，请遵循以下指南：

1. **关注点分离** – 将模板加载、数据准备和处理分别放在不同的方法中，便于单元测试。  
2. **验证输入** – 在调用 `Process` 前确保模板文件存在且数据集合不为 null。  
3. **释放资源** – 虽然 Aspose.Cells 已自行管理内存，但在处理大文件时仍建议使用 `using` 块包装 `Workbook`。  
4. **异常处理** – 在 `sp.Process` 周围捕获 `Exception`，以便捕获标记名称不匹配等问题。

```csharp
static Workbook LoadTemplate(string path)
{
    if (!File.Exists(path))
        throw new FileNotFoundException($"Template not found: {path}");
    return new Workbook(path);
}
```

| Name      | Position   |
|-----------|------------|
| John Doe  | Developer  |
| Jane Smith| Manager    |

所有来自 `template.xlsx` 的格式——如标题背景色、列宽以及任何徽标图片——均保持不变。

## 常见问题排查

| 症状 | 可能原因 | 解决办法 |
|------|----------|----------|
| 处理后没有数据显示 | Smart Marker 标记拼写错误或放在合并单元格中。 | 确认标记严格遵循 `&=Collection.Property` 语法，且不在合并区域内。 |
| 输出文件为空或损坏 | 工作簿在处理完成前已保存。 | 确保 **在** `wb.Save` 之前执行 `sp.Process`。 |
| 大量员工列表导致生成缓慢 | 使用 Aspose.Cells 免费版可能存在性能限制。 | 升级到授权版或分批处理数据。 |
| 模板路径错误 | 相对路径在运行时解析到不同文件夹。 | 使用 `Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "template.xlsx")`，或设置文件的 *Copy to Output Directory* 属性。 |

## 完整示例回顾

以下是一整段程序代码，方便直接复制粘贴：

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Load the template
            string templatePath = Path.Combine("YOUR_DIRECTORY", "template.xlsx");
            Workbook wb = new Workbook(templatePath);

            // Prepare data
            var employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Process Smart Markers
            var sp = new SmartMarkerProcessor();
            sp.Process(wb, employeeList);

            // Save the result
            string outputPath = Path.Combine("YOUR_DIRECTORY", "output.xlsx");
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

运行此程序即可生成 **employee report Excel** 文件，可用于邮件发送、打印或进一步处理。
