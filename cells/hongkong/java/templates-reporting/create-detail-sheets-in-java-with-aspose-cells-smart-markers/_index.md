# 使用 Aspose.Cells 智能標記在 Java 中建立明細工作表

如果您需要在 Java 應用程式中 **建立明細工作表**，本教學將示範如何使用 Aspose.Cells 智能標記來完成。您將看到一個完整、可執行的範例，能 **java create worksheets**、從欄位 **sheet name from field** 取得工作表名稱，並在幾行程式碼內 **process data source**。

本指南涵蓋從專案設定到儲存最終活頁簿的全部步驟，讓您可以直接複製貼上解決方案到自己的專案並立即調整。無需外部文件——所有需要的資訊都在此。

## 您將學習到

* 如何 **use smart markers** 於每筆主資料列複製範本工作表。  
* 如何根據欄位值（例如 `Order_123`）動態設定每個新工作表的名稱。  
* 如何將 Java 集合作為 **process data source** 提供給智能標記引擎。  
* 處理空資料、工作表名稱特殊字元，以及大型資料集效能考量的技巧。

### 前置條件

| Requirement | Reason |
|-------------|--------|
| Java 8 或更高版本 | Aspose.Cells for Java 支援 Java 8+。 |
| Maven 或 Gradle 建置系統 | 簡化加入 Aspose.Cells 相依性。 |
| 基本的 Java 集合知識 | 需要用來建立智能標記的資料來源。 |
| 含有佔位符智能標記於 **A1** 儲存格的範本 Excel 檔 (`Template.xlsx`) | 範本驅動明細工作表的產生。 |

> **專業提示：** 請將範本活頁簿放在專案的 `resources` 資料夾中，以便與您的 JAR 一起打包。

## 步驟 1：將 Aspose.Cells 加入您的專案 (java create worksheets)

如果您使用 **Maven**，請將以下相依性加入 `pom.xml`：

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

對於 **Gradle**，請在 `build.gradle` 中加入此行：

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

這些程式碼會在編譯時提供 **java create worksheets** API。

## 步驟 2：載入範本活頁簿

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*為何重要：* `Workbook` 物件是所有 Excel 操作的入口。載入範本可確保您從正確的版面配置與任何預先定義的格式開始。

## 步驟 3：插入智能標記，以在每個主資料列建立新工作表 (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

`${Orders:DetailSheetNewName=Order_${OrderId}}` 語法是 **use smart markers** 的核心。它執行三項功能：

1. 迭代 `Orders` 集合。  
2. 為每個元素 **new worksheet**。  
3. 設定 **sheet name from field** `OrderId`（前綴為 `Order_`）。

## 步驟 4：準備資料來源 (process data source)

以下示範使用 `List<Map<String, Object>>` 的最小範例。請將其替換為您的實際資料來源——資料庫列、JSON 反序列化等。

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*為何重要：* **process data source** 步驟將您的 Java 集合綁定至智能標記引擎。鍵名（`"Orders"`）必須與智能標記名稱完全相同。

## 步驟 5：處理智能標記 (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

當 `process` 執行時，Aspose.Cells 會讀取 `Orders` 集合，為每筆資料克隆範本工作表，並依 `OrderId` 欄位重新命名工作表。這就是 **process data source** 用法的核心。

## 步驟 6：儲存包含重複明細工作表的活頁簿

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

執行後，您會在 `DuplicatedDetailSheets.xlsx` 中看到：

* `Sheet1` – 原始範本（未變更）。  
* `Order_101` – 第一筆訂單的明細工作表。  
* `Order_102` – 第二筆訂單的明細工作表。

### 預期輸出（摘錄）

| 工作表名稱 | A1（智能標記） | 產生內容 |
|------------|-------------------|-------------------|
| Order_101  | `${Orders:...}`   | Populated with data from `order1` |
| Order_102  | `${Orders:...}`   | Populated with data from `order2` |

在 Excel 中開啟檔案，即可驗證每個工作表名稱正確且包含資料列。

## 處理常見變化與邊緣情況

### 空資料來源

如果 `orders` 為空，智能標記處理器 **不會建立新工作表**。為避免產生空活頁簿，請加入防護：

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### 工作表名稱中的特殊字元

Excel 工作表名稱不能包含 `\ / ? * [ ] :`。使用前先清理欄位內容：

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### 大型資料集

對於數千筆資料，建議增加 JVM 堆積大小（`-Xmx2g`），並在所有工作表產生完畢後才呼叫 `workbook.calculateFormula()`，以提升效能。
