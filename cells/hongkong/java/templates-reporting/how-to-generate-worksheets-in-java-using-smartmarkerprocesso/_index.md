# 如何在 Java 中使用 SmartMarkerProcessor 產生工作表

如果你需要在 Excel 檔案中 **how to generate worksheets**，本指南將為你展示一個完整、即時可執行的解決方案。閱讀完前兩句後，你將了解如何從物件集合產生工作表與動態 Excel 工作表，並且擁有一個只需呼叫單一方法即可自動化 Excel 建立的可執行程式碼範例。

在每位員工、專案或其他實體建立獨立工作表是程式化 **populate excel workbook** 資料時的常見需求。本教學將逐步說明從設定範本、處理清單到儲存最終檔案的每個步驟，讓你能立即在自己的 Java 應用程式中套用此技巧。

## 你將達成的目標

* 產生一個列出高層資訊的主工作表。  
* 從 **multiple sheets from list** 資料建立多張工作表，且每張工作表自動命名。  
* **Automate excel creation**，無需手動新增列或欄。  
* **Populate excel workbook**，使用豐富的資料結構（物件、映射、陣列）。  

先決條件：

* 已安裝 Java 8 或更新版本。  
* Maven（或其他建置工具）以加入 Aspose.Cells for Java 函式庫。  
* 具備 Java 集合的基本概念。  

> **專業提示：** SmartMarker 語法 (`${EmployeeMaster}`) 可用於任何實作 `java.util.Collection` 的集合類型。使用它可讓你的範本保持乾淨且易於維護。

## 使用 SmartMarkerProcessor 產生工作表的方式

本節包含使 **how to generate worksheets** 變得輕鬆的核心程式碼。我們將說明每一行程式碼的重要性，而不僅僅是它的功能。

### 步驟 1：加入 Aspose.Cells 相依性

如果你使用 Maven，請在 `pom.xml` 中加入以下內容。此函式庫提供本指南中廣泛使用的 `SmartMarkerProcessor` 類別。

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **為什麼：** Aspose.Cells 內部處理 Excel 檔案 I/O、Smart Marker 解析與工作表管理，讓你專注於資料本身，而不必關注低階檔案操作。

### 步驟 2：準備 Excel 範本

建立一個名為 `EmployeeTemplate.xlsx` 的 Excel 檔案，於單一儲存格內放入 Smart Marker 佔位符：

| A |
|---|
| `${EmployeeMaster}` |

當處理器執行時，會將此佔位符取代為一個 **detail sheet**，其中每位員工佔一列。

> **為什麼：** 佔位符告訴處理器資料要插入的位置。使用獨立的範本可保留你的格式設定（字型、框線、欄寬）不變。

### 步驟 3：定義資料模型

以下是一個最小化的 `Employee` 類別以及建立員工清單的輔助方法。此清單將用於示範 **multiple sheets from list**。

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **為什麼：** 一個普通的 Java 物件（POJO）直接對應到 Smart Marker 欄位（`firstName`、`lastName`、`department`）。這讓 **populate excel workbook** 變得簡單且具型別安全性。

### 步驟 4：設定 SmartMarkerProcessor

現在我們將所有元件串接起來。處理器會讀取範本、取代標記，並建立一個名為 `EmployeeDetail` 的新工作表。

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

關鍵行說明

| 行 | 原因 |
|------|--------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | 載入已包含 Smart Marker 佔位符的範本。 |
| `data.put("EmployeeMaster", employees);` | 將 Java 清單綁定至標記 `${EmployeeMaster}`。 |
| `processor.setDetailSheetNewName("EmployeeDetail");` | 為產生的工作表賦予有意義的名稱，取代預設的 `Sheet1`。 |
| `processor.process(wb, data);` | **How to generate worksheets** – 處理器讀取標記、建立新工作表，並為每個 `Employee` 填入列。 |
| `wb.save("EmployeesReport.xlsx");` | 將 **dynamic excel sheets** 儲存至磁碟。 |

### 步驟 5：驗證輸出

開啟 `EmployeesReport.xlsx`。你應該會看到兩個工作表：

1. **Sheet1** – 原始範本（可隱藏或移除）。  
2. **EmployeeDetail** – 一個包含 `firstName`、`lastName`、`department` 欄位且每位員工佔一列的 **dynamic excel sheet**。

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **為什麼這很重要：** 檔案現在已包含 **multiple sheets from list**，無需手動迴圈或儲存格定位。Smart Marker 引擎負責列的建立、資料轉換與格式繼承。

### 步驟 6：處理邊緣情況

#### 空資料清單

如果 `employees` 為空，處理器仍會建立 `EmployeeDetail` 工作表，但會保持空白。你可以在處理前檢查集合大小，以避免新增此工作表：

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### 超大型清單

若有數千列，建議增加記憶體配置（`-Xmx2g`）或使用 `processor.setAutoFitRows(false)` 以加速處理。

#### 依群組自訂工作表名稱

若需為每個部門建立獨立工作表，可使用 **multiple detail sheets**：

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

佔位符 `${department}` 取自每個 `Employee` 物件，產生如 `Dept_Sales`、`Dept_Marketing` 等工作表。
