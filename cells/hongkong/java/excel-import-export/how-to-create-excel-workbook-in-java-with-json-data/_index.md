# 如何在 Java 中使用 JSON 資料建立 Excel 活頁簿

如果您需要 **create Excel workbook java**，開發人員常常會面臨將 JSON 資料載入試算表的挑戰。本指南將向您展示如何 **populate Excel from JSON**，包括如何 **convert JSON array excel** 以及 **populate workbook from json**，以乾淨且可重複的方式。

在服務透過 REST API 提供資料時，使用 JSON 是很常見的，而 Excel 仍然是報告與分析的首選格式。完成本教學後，您將擁有一個可執行的 Java 程式，能夠：

* 建立新的 Excel 活頁簿，
* 讀取 JSON 陣列（或任何 JSON 結構）並將其值寫入儲存格，
* 將檔案儲存至磁碟，供後續處理使用。

除了 Aspose.Cells for Java 函式庫之外，無需其他外部工具，該函式庫提供了範例程式碼中使用的 `SmartMarkerProcessor`。

## 前置條件

在開始之前，請確保您已具備以下條件：

| 前置條件 | 原因 |
|--------------|--------|
| Java Development Kit (JDK) ≥ 8 | 需要編譯與執行範例 |
| Maven or Gradle (optional) | 簡化相依性管理 |
| Aspose.Cells for Java (v23.10 or later) | 提供 `Workbook` 與 `SmartMarkerProcessor` 類別 |
| Basic knowledge of JSON and Java I/O | 有助於了解資料流程 |

如果您不想使用建置工具，可以從 [Aspose website](https://products.aspose.com/cells/java/) 下載 Aspose.Cells JAR，並手動將其加入專案的 classpath。

## 步驟 1：設定專案並加入 Aspose.Cells 相依性

### Maven 使用者

在您的 `pom.xml` 中加入以下相依性：

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Gradle 使用者

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

如果您未使用建置工具，請將下載的 JAR 放入 `libs/` 資料夾，並在編譯時將其加入 classpath：

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## 步驟 2：建立新活頁簿並設定 SmartMarker 處理器

`SmartMarkerProcessor` 簡化了將 JSON 值對映至 Excel 儲存格的過程。透過呼叫 `setArrayAsSingle(true)`，我們告訴處理器將整個 JSON 陣列視為單一值，這在您希望每個元素佔用同一列的不同儲存格時非常有用。

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**為何重要：**  
提前建立活頁簿可提供乾淨的畫布。設定 `setArrayAsSingle(true)` 可防止處理器將陣列展平成單一字串（例如 `["A","B","C"]`），而是讓您自行控制版面配置。

## 步驟 3：定義要插入的 JSON 資料

本教學使用簡單的 JSON 陣列，但相同方法亦適用於物件、巢狀陣列或複雜結構。

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**提示：** 若您的 JSON 來源於檔案或 REST 端點，請將字面字串改為從來源讀取的 `String`，例如 `Files.readString(Paths.get("data.json"))`。

## 步驟 4：使用 JSON 資料處理活頁簿

現在讓 `SmartMarkerProcessor` 將 JSON 陣列映射到第一個工作表。預設行為是將每個元素寫入從 `A1` 開始的連續儲存格。

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

在背後，Aspose.Cells 會解析 JSON，建立暫時的資料表，並將值寫入工作表。由於我們將 `ArrayAsSingle` 設為 `true`，陣列元素會水平排列在第一列。

## 步驟 5：將活頁簿儲存為檔案

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

執行程式後，您應該會在工作目錄中看到名為 **CreatedFromJson.xlsx** 的檔案。使用 Excel（或任何相容檢視器）開啟它會顯示：

| A | B | C |
|---|---|---|
| A | B | C | *(值顯示於儲存格 A1、B1、C1)*

```

```

```
+---+---+---+
```

## 步驟 6：處理更複雜的 JSON 結構（可選）

### 6.1 從 JSON 物件填充活頁簿

如果您的 JSON 是物件而非陣列，仍可使用 `SmartMarkerProcessor`。例如：

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

處理器會建立命名範圍（`title`、`month`、`values`），您可以在 Excel 範本中使用 Smart Marker 如 `&=title` 與 `&=values` 來參照它們。

### 6.2 將巢狀 JSON 陣列轉換為垂直清單

有時您需要將陣列填滿欄而非列。請在處理前手動設定起始儲存格：

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

現在值 **A**、**B**、**C** 分別出現在儲存格 A2、A3、A4。

## 常見陷阱與避免方法

| 問題 | 原因 | 解決方案 |
|-------|-------|-----|
| **Array written as a single string** | `setArrayAsSingle(false)` (default) | 呼叫 `processor.setArrayAsSingle(true)` |
| **File not found when saving** | Invalid path or missing write permissions | 使用絕對路徑或確保目錄存在 |
| **JSON parsing error** | Malformed JSON string | 使用工具驗證 JSON，或使用如 Jackson 的函式庫產生字串 |
| **Cells overwritten unintentionally** | Processing the same worksheet multiple times without resetting the start cell | 在每次 `process` 呼叫前呼叫 `processor.setStartCell("A1")` |

## 專業提示：將活頁簿作為範本重複使用

與其每次從空白活頁簿開始，您可以載入預先設計好的範本，該範本已包含標題、公式或樣式：

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

此方法結合了手工製作 Excel 檔的視覺精緻度與 **populate workbook from json** 的自動化。
