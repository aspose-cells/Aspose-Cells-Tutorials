# 使用 Aspose.Cells 匯入自訂物件至 Excel – Java 教學

如果您需要將**自訂物件**匯入 Excel 工作表，本指南將帶您使用 Aspose.Cells for Java 完整流程。您將看到如何**將資料匯入 Excel**、套用粗體標題樣式，並產生可直接分享的 `.xlsx` 檔案。

從 Java 匯出表格資料通常需要手動逐格寫入，容易出錯且難以維護。透過使用 `importCustomObjects` API，您可以避免樣板程式碼，保持資料模型完整，並取得精細的樣式控制。

在本教學中您將：

* 建立一個模擬典型資料表的 Java `Map` 物件清單。  
* 使用 Aspose.Cells 建立可重複使用的標題樣式（粗體字型）。  
* 在匯入時套用樣式陣列，將自訂物件寫入工作表。  
* 將活頁簿儲存至磁碟並驗證結果。

唯一的前置條件是具備 Java 開發環境（建議 JDK 8 以上）以及 Aspose.Cells for Java 函式庫。

---

## 您需要的條件

| Requirement | Reason |
|-------------|--------|
| JDK 8 或更新版本 | 必須編譯與執行 Java 程式碼。 |
| Aspose.Cells for Java（最新版本） | 提供 `Workbook`、`Worksheet` 與匯入 API。 |
| IDE 或建置工具（例如 Maven、Gradle） | 簡化相依管理與執行。 |
| 目錄寫入權限 | 活頁簿會儲存為 `ImportWithStyle.xlsx`。 |

如果您使用 Maven，請將 Aspose.Cells 相依加入 `pom.xml`：

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## 第一步：準備要匯入的自訂物件

第一步是建立一個集合，代表您想放入 Excel 的列。在此範例中，我們使用 `List<Map<String,Object>>`，每個 Map 如同一列，欄位名稱作為鍵。

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**為什麼這很重要：**  
`importCustomObjects` 需要一個物件陣列。使用 `Map` 可以保留欄位名稱，讓 Aspose.Cells 自動對應至儲存格。此作法類似 .NET 的 `DataTable` 或 JDBC 的 `ResultSet`，可在不同專案間重複使用。

---

## 第二步：定義匯入時使用的標題樣式

清晰的標題列能提升可讀性。Aspose.Cells 允許您建立 `Style` 物件，將字型設為粗體，並透過 `ImportTableOptions` 陣列傳遞。

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**為什麼這很重要：**  
若省略樣式陣列，標題會使用預設字型，可能不夠突出。事先準備樣式即可避免對每一列重複呼叫，保持匯入程式碼簡潔。

---

## 第三步：使用樣式陣列匯入自訂物件

現在將資料與樣式結合，呼叫 `importCustomObjects`。此方法會從左上角 (第 0 列、第 0 欄) 開始寫入資料，並自動套用標題樣式。

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**為什麼這很重要：**  
`importCustomObjects` 會解析每個 Map，依鍵 (`Name`、`Score`) 建立欄位，並將值寫入對應儲存格。`ImportTableOptions` 物件告訴 Aspose.Cells 使用 `styleArray` 於第一列，讓您不需額外程式碼即可得到粗體標題。

---

## 第四步：儲存活頁簿並驗證輸出

最後，將活頁簿寫入檔案。產生的 Excel 檔案包含已套用樣式的標題列，後接資料列。

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**預期結果：**  

| **姓名** | **分數** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

標題儲存格 (`Name`、`Score`) 以粗體字型顯示，與第 2 步定義的樣式相符。

## 常見變化與邊緣情況

| Situation | Recommended adjustment |
|-----------|------------------------|
| **不同的欄位順序** | 確保 `Map` 鍵的插入順序符合需求，或使用帶有註解欄位的自訂 POJO 並搭配 `PropertyDescriptor` 陣列。 |
| **大型資料集（>10 000 列）** | 提升 `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` 以避免 `OutOfMemoryError`。 |
| **自訂數字格式** | 在 `styleArray` 中為資料列加入第二個 `Style`，例如將 `NumberFormat` 設為 `"0"` 以顯示整數分數。 |
| **多工作表** | 在每個目標工作表上呼叫 `importCustomObjects`，並依需要調整起始列/欄。 |
| **依語系的標題文字** | 在匯入前手動填入標題列，然後使用 `Cells.applyStyle` 將樣式套用至整個範圍。 |

---

## 提升 Java 匯出至 Excel 的實用技巧

* **重複使用暫存活頁簿** – 為每種樣式都建立新 `Workbook` 會增加開銷。若需多種樣式，請保留單一實例。  
* **匯入前先驗證資料** – Map 中的 null 會變成空儲存格；可在前置處理時將其替換為預設值。  
* **關閉資源** – 雖然 Aspose.Cells 內部會管理記憶體，仍建議在儲存後明確呼叫 `workbook.dispose()` 以即時釋放原生資源。  
* **設定 `Workbook.setForceFullCalculation(true)`** – 若活頁簿內含必須在儲存前計算的公式，請啟用此設定。
