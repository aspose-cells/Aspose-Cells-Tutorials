# 如何在 Java 使用 Aspose.Cells 更改圖表刻度方向

## 簡介

更改圖表刻度方向是提升 Excel 圖表可讀性的一種常見做法，特別是在面對長類別名稱或資料密集的情況下。在本指南中，您將學習 **更改圖表刻度方向**，從安裝函式庫到儲存最終活頁簿。我們亦會說明為何正確的標籤旋轉對財務報表、科學視覺化以及商業儀表板都相當重要。

## 快速回答
- **哪個函式庫負責圖表標籤旋轉？** Aspose.Cells for Java.
- **哪個 Maven 套件提供此功能？** `com.aspose:aspose-cells`.
- **我可以將標籤角度設定為垂直嗎？** Yes, use `ChartTextDirectionType.VERTICAL`.
- **在正式環境使用是否需要授權？** A permanent license is required; a temporary license works for evaluation.
- **此 API 是否相容於 Java 8 及以上版本？** Yes, it supports Java 8‑21.

## 什麼是更改圖表刻度方向？

**更改圖表刻度方向** 是指調整類別軸刻度標籤的方向（例如水平、垂直或旋轉），使其在圖表區域內更好地適應。此操作是透過 Aspose.Cells 中 `ChartAxis` 物件的 `setTickLabelDirection` 方法執行。

## 為什麼使用 Aspose.Cells for Java 來旋轉刻度標籤？

Aspose.Cells 可處理 **超過 150 種檔案格式**，能在不將整個檔案載入記憶體的情況下處理包含 **500 多個工作表** 的活頁簿，且對於一般圖表大小的標籤旋轉執行時間 **低於 0.2 秒**。這些具體的效能指標使其成為企業級 Excel 自動化的可靠選擇。

## 如何在 Java 中更改圖表刻度方向？
若要修改刻度標籤的方向，必須載入目標活頁簿、取得特定圖表、存取其類別軸，並以所需的 `ChartTextDirectionType` 呼叫 `setTickLabelDirection`。此流程僅需幾行 Java 程式碼，即可輕鬆整合至現有的自動化工作流程。

1. 載入包含您想要修改之圖表的活頁簿。  
2. 依索引取得工作表與圖表物件。  
3. 存取類別軸 (`getCategoryAxis()`)，並以所需的 `ChartTextDirectionType` 呼叫 `setTickLabelDirection`。  
4. 將活頁簿儲存為新檔案。

## 實作指南

### 載入活頁簿與圖表
`Workbook` 類別在記憶體中代表整個 Excel 檔案。`Worksheet` 類別讓您存取個別工作表，而 `Chart` 類別則代表特定圖表。

```java
Workbook workbook = new Workbook("input.xlsx");               // 1️⃣ Load file
Worksheet sheet = workbook.getWorksheets().get(0);            // 2️⃣ First sheet
Chart chart = sheet.getCharts().get(0);                       // 3️⃣ First chart on the sheet
```

### 變更刻度標籤方向
`ChartAxis` 控制所有與軸相關的屬性。`ChartTextDirectionType` 為定義方向的列舉型別。

```java
ChartAxis categoryAxis = chart.getCategoryAxis();            // Access category axis
categoryAxis.setTickLabelDirection(ChartTextDirectionType.HORIZONTAL); // 4️⃣ Set direction
```

- `ChartTextDirectionType.HORIZONTAL` → 標籤由左至右閱讀。  
- `ChartTextDirectionType.VERTICAL` → 標籤由上至下閱讀。  
- `ChartTextDirectionType.ROTATED_45` → 標籤旋轉 45°（較新版本支援）。

### 儲存活頁簿
調整軸之後，將變更寫入檔案：

```java
workbook.save("output.xlsx", SaveFormat.XLSX);
```

## 常見問題與解決方案
- **圖表索引不正確** – 透過檢查 `sheet.getCharts().getCount()` 來確認圖表是否存在。  
- **授權未套用** – 若看到浮水印，請確保在任何活頁簿操作之前已載入授權檔案。  
- **不支援的方向** – 某些較舊的圖表類型僅支援水平標籤；請升級至最新的 Aspose.Cells 版本以取得所有列舉值。

## 實務應用
在空間受限的情境下，更改刻度標籤方向特別有用：

1. **財務時間軸** – 水平標籤在密集的時間序列圖表中保持日期字串可讀。  
2. **科學圖形** – 垂直標籤釋放水平空間，以容納較長的變數名稱。  
3. **商業儀表板** – 旋轉標籤可防止多類別長條圖中的文字重疊。

## 效能考量
在處理包含 **數百個圖表** 的活頁簿時，請遵循以下最佳實踐：

- 只載入活頁簿一次，並重複使用相同的 `Workbook` 實例。  
- 在迴圈中套用標籤變更，最後一次性呼叫 `workbook.save` 以減少 I/O。  
- 僅在需要在修改後重新計算公式時，才使用 `setCalculateFormula` 旗標。

## 常見問與答

**問：我可以將刻度標籤旋轉到任意角度嗎？**  
答：Aspose.Cells 目前僅支援預先定義的列舉值（水平、垂直、45°）。若需自訂角度，可結合 `setTickLabelAlignment` 進行旋轉。

**問：此 API 能處理受密碼保護的 Excel 檔案嗎？**  
答：可以。使用以下方式載入活頁簿：`new Workbook("file.xlsx", new LoadOptions(LoadFormat.XLSX) {{ setPassword("pwd"); }})`。

**問：在同一本活頁簿中可修改的圖表數量有上限嗎？**  
答：沒有硬性上限；效能取決於可用記憶體。處理含 1,000 個圖表的活頁簿通常在標準伺服器上於 30 秒內完成。

**問：如何以程式方式套用臨時授權？**  
答：`License` 類別會在執行時載入並套用您的 Aspose.Cells 授權檔案。於任何 Aspose.Cells 操作之前，建立 `License` 物件並呼叫 `setLicense("Aspose.Total.Java.lic")`。

**問：更改刻度方向會影響現有的資料系列嗎？**  
答：不會。此操作僅修改軸標籤的呈現方式，資料值保持不變。
