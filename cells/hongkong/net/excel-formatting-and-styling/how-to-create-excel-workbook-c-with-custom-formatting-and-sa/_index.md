# 如何使用 C# 建立 Excel 工作簿並套用自訂格式，儲存為 XLSX

如果您需要 **create Excel workbook C#** 來匯入資料、套用自訂數字格式，並變更儲存格字型顏色，本教學將完整示範。您將獲得一個可直接執行的範例，能在數秒內產生已套用樣式的 `StyleArrayImport.xlsx` 檔案。

從 C# 操作 Excel 時，常會遇到需要重複手動設定格式、套用顏色、以及記得正確儲存檔案等步驟。完成本指南後，您將自動化所有這些工作，讓您可以專注於資料本身，而非使用者介面。

您將學會：

* 匯入 `DataTable` 到工作表，
* 使用 `StyleArray` 來 **apply custom number format** 並 **change cell font color**，
* 只需一次方法呼叫即可 **save workbook as XLSX**，
* 以及驗證 **format imported data excel** 完全如預期顯示。

唯一的前置條件是參考 **Aspose.Cells for .NET** 函式庫（或任何提供 `Workbook`、`Worksheet` 與 `StyleArray` 的相容 API）。程式碼以 .NET 6+ 為目標，較早的版本只需稍作調整即可執行。

## Step 1: Prepare the sample DataTable

首先，建立一個模擬您平時會從資料庫或其他來源取得的 `DataTable`。此表格包含 **Name**（字串）欄位與 **Amount**（十進位）欄位，我們稍後會為其套用格式。

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Why this matters:** 使用 `DataTable` 能讓匯入邏輯與資料來源解耦，這在從資料庫、CSV 檔或 API 產生報表時是常見的做法。

## Step 2: Define a StyleArray to **apply custom number format** and **change cell font color**

`StyleArray` 讓您將格式指令打包，並套用到每一個從 `DataTable` 匯入的儲存格。在此範例中，我們：

* 設定 `Number` 為 `#,##0.00` ── 典型的會計格式，含千位分隔符，
* 設定 `FontColor` 為 `Color.Blue` ── 使數字更為醒目。

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**Why use a StyleArray?** 在匯入時一次套用樣式，可避免對工作表進行第二次遍歷，提升大量資料集的效能。

---

## Step 3: **Create Excel workbook C#** – instantiate Workbook and get the first Worksheet

現在建立一個空的 workbook，並取得第一張工作表（索引 0）。此工作表將作為匯入資料的目的地。

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Explanation:** `Workbook` 代表整個 Excel 檔案，而 `Worksheet` 代表單一分頁。預設的 workbook 只包含一張工作表，已足夠處理大多數簡易報表。

---

## Step 4: Import the DataTable using the **StyleArray** to **format imported data excel**

`ImportDataTable` 方法會將資料表的列與欄複製到工作表，起始位置為 `A1`（第 0 列，第 0 欄）。`true` 參數表示同時匯入欄位標題。因為傳入了 `styleArray`，每個匯入的儲存格都會套用自訂的數字格式與字型顏色。

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**What happens under the hood:** Aspose.Cells 會逐列寫入值，然後套用 `styleArray` 中定義的樣式。數字會顯示千位分隔符與兩位小數，文字則以藍色呈現。

---

## Step 5: **Save workbook as XLSX** – write the file to disk

最後，將 workbook 持久化為 `.xlsx` 檔案。您可以自行更改路徑，指向機器上任何可寫入的目錄。

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Result verification:** 在 Excel 中開啟產生的檔案，您應該會看到三筆資料，且 **Amount** 欄位已以千位分隔、兩位小數且藍色字型顯示。這證明 **format imported data excel** 步驟已成功執行。

## Full Working Example

將下方完整程式碼貼到新的主控台專案中執行。無需額外程式碼。

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Expected output in the console:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

開啟檔案並確認 **Amount** 欄位的值如 `1,234.56`，且以藍色字型顯示。

## Common Questions & Edge Cases

| Question | Answer |
|----------|--------|
| *Can I apply different formats to individual columns?* | 可以。匯入後取得該欄的 `Style` 物件（`worksheet.Cells.Columns[1].Style`），再設定不同的 `Number` 或 `FontColor`。 |
| *What if I need to format dates instead of numbers?* | 設定 `styleArray.Number = "mm-dd-yyyy"`，必要時也可為日期儲存格設定 `styleArray.FontColor`。 |
| *Is the blue font visible on dark Excel themes?* | 藍色在深色佈景主題上可能較難閱讀。可改用較淡的藍色 (`Color.LightBlue`) 或對比度較高的顏色（如 `Color.Black`）。 |
| *How do I import a very large DataTable (hundreds of thousands of rows)?* | 使用 `ImportDataTable` 搭配 `ImportDataTableOptions` 重載以串流方式匯入，或將資料分割至多個工作表，以免超過 Excel 的列上限（1,048,576 列）。 |
| *Can I export to CSV instead of XLSX?* | 將 `SaveFormat.Xlsx` 改為 `SaveFormat.Csv` 即可。請注意，CSV 為純文字格式，會遺失所有格式資訊（數字格式、字型顏色）。 |

## Tips for Production Use

* **Pro tip:** 若需在多個工作表上套用相同格式，請快取 `Style` 物件；每次匯入都重新建立 `StyleArray` 會增加額外開銷。  
* **Watch out for culture differences:** `Number` 樣式 `#,##0.00` 依照不變文化（Invariant Culture）設定。若需符合本地化的千位與小數分隔符，請使用 `NumberFormatInfo`，或交由 Excel 依使用者的區域設定自動處理。  
* **Error handling:** 建議將 `Save` 呼叫包在 try‑catch 區塊，處理 I/O 例外（例如權限不足或檔案被鎖定）。
