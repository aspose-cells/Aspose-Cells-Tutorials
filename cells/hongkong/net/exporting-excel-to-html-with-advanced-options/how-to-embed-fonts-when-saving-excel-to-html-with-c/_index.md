# 如何在將 Excel 儲存為 HTML 時嵌入字型（C#）

在將 Excel 工作簿儲存為 HTML 時嵌入字型，是在不同瀏覽器中保留試算表外觀的常見需求。如果您需要在匯出 Excel 為 HTML 時保留原始字型，本指南將提供完整、可直接執行的解決方案。

您將學會 **匯出 Excel 為 HTML**、**將 Excel 轉換為 HTML 並嵌入字型**，以及避免在客戶端機器上因「缺少字型」而導致版面配置錯亂的常見問題。無需外部工具——只需要 Aspose.Cells 程式庫與少量 C# 程式碼。

## 前置條件

開始之前，請確保您已具備：

* 已安裝 .NET 6.0（或更新版本）。
* 已取得 **Aspose.Cells for .NET** 的授權副本——免費試用版可用於測試。
* 如 Visual Studio 2022 或 VS Code 等開發環境。

如果上述條件皆已符合，您可以直接進入程式碼部分。

## 步驟 1：建立工作簿並加入範例資料

首先產生一個小型工作簿，讓您能看到嵌入字型的效果。以下程式碼會建立工作表、寫入幾個儲存格，並套用自訂字型。

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### 為何要加入自訂字型

只有當工作簿使用的字型在客戶端裝置上可能不存在時，嵌入字型才有意義。透過明確設定 **Arial**（或其他任意字型），我們可以驗證產生的 HTML 確實包含了字型資料。

## 步驟 2：設定 HTML 儲存選項以嵌入字型

Aspose.Cells 提供 `HtmlSaveOptions` 類別。將 `EmbedFonts = true` 設為 true，便會指示程式庫直接將所需的字型檔案以 Base64 編碼的資料 URI 方式嵌入產生的 HTML 中。

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### 「在 HTML 中嵌入字型」實際上會發生什麼

當 `EmbedFonts` 為 true 時，Aspose.Cells 會從系統（或工作簿的嵌入字型集合）中提取字型檔案，並將其轉換為 **Base64** 字串。這些字串隨後會放入 `<style>` 區塊，使用 `@font-face` 方式宣告。最終的 HTML 可在任何裝置上開啟，且不需要事先安裝原始字型。

## 步驟 3：將工作簿儲存為含嵌入字型的 HTML

現在把工作簿寫入磁碟。檔案內已包含字型資料，於任何現代瀏覽器開啟時，都會呈現與原始 Excel 完全相同的排版與字型。

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### 預期結果

* `embedded.html` 會位於 `output` 資料夾內。
* 在 Chrome、Edge 或 Firefox 開啟該檔案時，工作表會以 **Arial** 文字顯示，即使瀏覽器所在機器沒有安裝 Arial。
* 檢視 HTML 原始碼會看到一段 `<style>` 區塊，內含 `@font-face` 規則，`src: url(data:font/ttf;base64,…)` 的長字串即為嵌入的字型。

## 步驟 4：在其他機器上驗證 HTML 是否正常（可選）

為了徹底確認嵌入成功，請：

1. 將 `output/embedded.html` 複製到另一台沒有安裝該自訂字型的電腦（或虛擬機）。
2. 用瀏覽器開啟該檔案。
3. 版面與字型應與原始 Excel 檢視結果完全相同。

若字型退回為通用字型，請再次確認建置機器上字型檔案可存取，且程式有讀取權限。

## 常見問題與邊緣情況

### 嵌入字型會增加檔案大小嗎？

會。將 TrueType 或 OpenType 字型嵌入 HTML 會使檔案增加 **數十 KB**。若工作簿較大且使用多種字型，建議：

* 只保留實際使用的字元子集——Aspose.Cells 會自動對常見字型執行子集化。
* 若不需要嵌入圖片，可將 `ExportEmbeddedImages = false`。

### 若只想嵌入特定字型該怎麼辦？

`HtmlSaveOptions` 並未提供直接的白名單機制，但您可以在呼叫 `Save` 前**限制工作簿中使用的字型**。移除不必要的字型指派或改為使用標準的 Web‑safe 字型即可。

### 轉換成其他格式（例如 PDF）時可以嵌入字型嗎？

`PdfSaveOptions` 也有相同的 `EmbedFonts` 屬性。概念相同：將字型資料嵌入，使 PDF 在任何檢視器上都能正確呈現。

## 完整可執行範例

以下是可直接貼到新 Console 專案中的完整程式碼。

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

執行程式後會產生一個 **包含嵌入 Arial 字型的 HTML 檔案**，確保在任何開啟環境下皆能保持視覺一致性。

## 結論

現在您已掌握 **在 C# 中將 Excel 儲存為 HTML 時嵌入字型** 的方法。只要將 `HtmlSaveOptions.EmbedFonts = true` 設定為 true，即可可靠地 **匯出 Excel 為 HTML**、**將 Excel 轉換為 HTML**，而不必擔心客戶端缺少字型。此技巧對於網頁報表、電子郵件儀表板，或任何以 HTML 形式分享 Excel 內容的情境，都相當重要。

### 接下來可以做什麼？

* **自訂 Aspose.Cells 產生的 CSS**，以符合網站風格指南。  
* 透過切換 `ExportEmbeddedImages`，**選擇性嵌入圖片**。  
* **探索其他匯出格式**（如 PDF 或 SVG），同樣支援字型嵌入。

歡迎嘗試不同字型、較大的工作表或多工作表的工作簿。`EmbedFonts` 旗標在所有支援的輸出格式中皆可使用，讓您在任何需要的地方都能一致控制字型嵌入。祝開發順利！
