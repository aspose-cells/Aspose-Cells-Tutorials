# 如何在 HTML 中嵌入字型並儲存活頁簿

如果您在匯出試算表時需要 **在 HTML 中嵌入字型**，本教學將提供完整、可直接執行的解決方案。無論是建置報表入口網站或是客戶端分析視圖，嵌入字型都能確保產生的 HTML 與原始活頁簿的呈現完全相同，即使檢視者的電腦未安裝該字型。

您還會學會使用 Aspose.Cells **將活頁簿儲存為 HTML** 的最佳方式、常見陷阱，以及處理大型活頁簿或自訂字型檔的技巧。無需額外文件——本指南已涵蓋所有需求。

## 前置條件

開始之前，請確保您已具備：

- .NET 6.0 或更新版本（程式碼同樣支援 .NET Framework 4.7+）
- 有效的 Aspose.Cells for .NET 授權（或使用免費評估模式）
- 基本的 C# 知識與 Visual Studio 2022 等開發環境
- 您欲嵌入的 TrueType（.ttf）或 OpenType（.otf）字型檔（必須可被執行程序存取）

## 步驟 1：建立專案並匯入 Aspose.Cells

建立一個新的主控台應用程式，並加入 Aspose.Cells NuGet 套件：

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

接著開啟 **Program.cs**，加入必要的 `using` 指示詞：

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **小技巧：** 將自訂字型放在專案根目錄下名為 `fonts` 的資料夾中。這樣可保持解決方案的可移植性，且日後引用更方便。

## 步驟 2：建立或載入活頁簿

以下示範會建立一個簡單的活頁簿，內含幾個已套用樣式的儲存格：

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **為什麼重要：** 若省略自訂樣式，匯出的 HTML 會退回使用瀏覽器的預設字型，失去 **在 HTML 中嵌入字型** 的意義。

## 步驟 3：設定 `HtmlSaveOptions` 以嵌入字型

**在 HTML 中嵌入字型** 的核心在於 `HtmlSaveOptions` 類別。將 `EmbedFonts = true` 設為 true 後，Aspose.Cells 會將所有引用的 TrueType/OpenType 字型直接以 Base64 編碼的 data URI 方式嵌入產生的 HTML 中。

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### 嵌入原理

當 `EmbedFonts` 為 `true` 時，Aspose.Cells 會掃描活頁簿的樣式定義，找出系統（或您在 `fonts` 資料夾中放置的）對應字型檔，讀取其二進位資料，並注入類似以下的 `<style>` 區塊：

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

因為字型資料已直接編碼在 HTML 內，即使在未安裝該字型的機器上，頁面也能正確呈現。

## 步驟 4：將活頁簿儲存為 HTML

現在可以使用先前設定好的選項 **將活頁簿儲存為 HTML**。請選擇程式有寫入權限的目錄（例如 `output`）。

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

執行程式後會產生單一的 `report.html` 檔案。使用任何現代瀏覽器開啟，即可看到「Quarterly Sales」標題以 **Pacifico** 字型顯示，即使該字型未安裝於作業系統。

### 預期輸出

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

`src:` 屬性內包含長長的 Base64 字串——這就是支援 **在 HTML 中嵌入字型** 所必須的嵌入字型資料。

## 步驟 5：驗證字型嵌入與除錯

1. **在 Chrome 或 Edge 開啟 HTML 檔案。** 若自訂字型正確顯示，表示嵌入成功。  
2. **檢查頁面原始碼。** 尋找 Aspose.Cells 產生的 `@font-face` 規則。  
3. **常見問題：**  
   - *找不到字型檔案：* 確認字型檔可被存取。您也可以明確將資料夾加入搜尋路徑：

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *HTML 檔案過大：* 嵌入多個字型會使檔案膨脹。可將 `ExportToSingleFile = false`，讓字型以獨立的 `.ttf` 檔案存放於資源資料夾中。  

   - *不支援的字型格式：* Aspose.Cells 只支援 TrueType（`.ttf`）與 OpenType（`.otf`）字型。請先將其他格式轉換後再嵌入。

## 完整範例程式

以下是完整程式碼，您可直接複製、貼上並執行（僅需自行加入授權程式碼行）。

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

執行後會在 `output/report.html` 產生檔案。開啟後即可看到 **Pacifico** 字型正確渲染——示範了 **在 HTML 中嵌入字型** 同時 **將活頁簿儲存為 HTML** 的完整流程。

## 常見問與答

| 問題 | 解答 |
|----------|--------|
| *我可以只嵌入特定的字型嗎？* | 可以。將 `htmlOpt.EmbedAllFonts = false`（較新版本支援），再使用 `htmlOpt.FontsToEmbed` 列出欲嵌入的字型名稱。 |
| *如果需要為多個工作表嵌入字型該怎麼做？* | 設定 `ExportActiveWorksheetOnly = false`，讓所有工作表皆被匯出，Aspose.Cells 會自動嵌入整本活頁簿使用的字型。 |
| *嵌入的字型在行動裝置瀏覽器上會正常嗎？* | 現代行動瀏覽器支援 Base64 編碼的字型，只要字型格式為 TTF 或 OTF，皆能正確呈現。 |
| *HTML 檔案會變得有多大？* | 嵌入一個 200 KB 的 TrueType 字型大約會使 HTML 增加相同大小（Base64 會多約 33 % 的開銷）。若字型數量眾多，建議使用資料夾輸出 (`ExportToSingleFile = false`) 以保持 HTML 輕量。 |
