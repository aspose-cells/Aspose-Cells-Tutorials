# 如何使用 Aspose.Cells 在 C# 中將樞紐分析表匯出為圖片

如果您需要 **將樞紐分析資料匯出** 為可攜式圖片，Aspose.Cells 讓這個過程變得簡單直觀。本教學將示範如何將樞紐分析表匯出為 PNG 檔案，讓您可以在報告、電子郵件或文件中嵌入，而不需要在目標機器上安裝 Excel。

將樞紐分析表匯出為圖片可避免版本特定的格式問題，並讓非技術人員即時查看分析結果。我們將從專案設定說明到最終 **匯出樞紐分析表圖片**，同時說明如何 **將樞紐分析表儲存為圖片** 以供日後重複使用。

## 使用 Aspose.Cells 匯出樞紐分析表為圖片的方法

以下是完整、可執行的範例程式碼，會載入活頁簿、重新整理樞紐分析表、設定圖片選項，最後寫入輸出檔案。每一步都附有簡短說明，讓您了解 *為什麼* 這樣寫，而不只是 *做了什麼*。

### 1. 設定 Aspose.Cells 環境

1. 安裝 NuGet 套件：

   ```bash
   dotnet add package Aspose.Cells
   ```

2. 在 C# 檔案頂部加入必要的 `using` 指令：

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **專業提示：** 目標 .NET 6 或更新版本，可享有 Aspose.Cells 最新的效能提升。

### 2. 載入活頁簿並定位樞紐分析表

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*為什麼重要：* `Workbook` 類別會解析 XLSX 檔案，讓您取得所有工作表。正確選取工作表很關鍵，因為一本活頁簿可能包含多個樞紐分析表。

### 3. 重新整理樞紐分析表以取得最新來源資料

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

重新整理可確保在檔案儲存後對來源範圍所做的任何變更，都會反映在產生的圖片中。若略過此步驟，可能會產生過時或不正確的視覺結果。

### 4. 設定圖片匯出選項（匯出樞紐分析表圖片）

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

`ImageOrPrintOptions` 物件讓您控制格式、解析度與其他渲染細節。PNG 是最常用的銳利、網頁相容圖形格式；若在意檔案大小，也可以改用 `ImageFormat.Jpeg`。

### 5. 渲染並 **將樞紐分析表儲存為圖片**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

`RenderToImage` 承擔主要工作：它會將樞紐分析表依 Excel 中的顯示方式繪製，並將二進位 PNG 資料寫入磁碟。此方法回傳 `void`，因此您可以在呼叫完成後直接假設檔案已存在，無需額外檢查。

#### 預期結果

程式執行完畢後，您會在指定資料夾中找到 `Pivot.png`。開啟該檔案應顯示原始樞紐分析表的完整快照，包括欄位標題、列總計以及任何套用的格式。

### 6. 常見變體與邊緣案例

| 情境 | 調整方式 |
|----------|------------|
| **大型樞紐分析表**（列/欄很多） | 將 `HorizontalResolution` 與 `VerticalResolution` 提升至 300 dpi，以獲得更清晰的輸出。 |
| **自訂樣式**（背景色、字型） | 在呼叫 `Refresh()` 之前，確保已載入活頁簿的樣式定義。 |
| **同一工作表內有多個樞紐分析表** | 迭代 `worksheet.PivotTables`，對每個樞紐分析表呼叫 `RenderToImage`，並使用不同的檔名。 |
| **匯出為 JPEG 而非 PNG** | 將 `ImageFormat = ImageFormat.Jpeg`，必要時在 `JpegSaveOptions` 物件上設定 `Quality`。 |

這些變體讓您可以 **匯出樞紐分析表圖片**，符合下游系統的精確需求。

## 完整原始碼，直接複製貼上

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

執行程式後會產生上方顯示的 PNG 檔案，完成 **將樞紐分析表儲存為圖片** 的工作流程，整個過程不到一分鐘。
