# 如何建立智慧標記資料並填充 Excel 範本資料

如果您需要為 Excel 活頁簿 **建立智慧標記資料**，Aspose.Cells 的智慧標記能讓這個過程變得輕鬆。本教學示範如何使用智慧標記在幾行 C# 程式碼中 **填充 Excel 範本資料**。

您將學會如何在範本中嵌入 Smart Marker 標籤、提供資料來源、執行處理器，並儲存填充後的檔案。無需任何外部工具——只需要 Aspose.Cells for .NET 以及一個基本的 C# 專案。

## 您需要的環境

- .NET 6.0 或更新版本（此程式碼亦相容 .NET Framework 4.7+）
- Aspose.Cells for .NET（NuGet 套件 `Aspose.Cells`）
- 包含 Smart Marker 標籤（例如 `${Comment:fieldName}`）的 Excel 活頁簿
- C# IDE（Visual Studio、Rider 或 VS Code）

> **小技巧：** 將活頁簿放在與專案相同的資料夾中，或使用絕對路徑，以避免找不到檔案的錯誤。

## 使用 Aspose.Cells 建立智慧標記資料

此解決方案的核心是 `SmartMarkerProcessor`。它會掃描工作表中的標籤，從資料來源取得相符的值，並將結果寫回工作表。

```csharp
using Aspose.Cells;
using System;

// 1️⃣ Load the workbook that contains Smart Marker tags.
Workbook workbook = new Workbook("Template.xlsx");

// 2️⃣ Get the worksheet where the tags reside.
Worksheet ws = workbook.Worksheets[0];

// 3️⃣ Prepare the data source that supplies values for the markers.
var dataSource = new[]
{
    new { fieldName = "Sample comment text generated by C#." }
};

// 4️⃣ Create a SmartMarkerProcessor instance.
SmartMarkerProcessor processor = new SmartMarkerProcessor();

// 5️⃣ Process the worksheet, replacing Smart Marker tags with data from the source.
processor.Process(ws, dataSource);

// 6️⃣ Save the populated workbook.
workbook.Save("Result.xlsx");
```

### 為什麼每一行都很重要

1. **載入活頁簿** 為處理器提供具體的檔案以供操作。  
2. **選取工作表** 確保處理器掃描正確的工作表；您可以依索引或名稱定位任何工作表。  
3. **資料來源** 為匿名物件陣列。每個屬性名稱（`fieldName`）必須與 `${Comment:fieldName}` 內的標記名稱相符。  
4. **`SmartMarkerProcessor`** 為解析標籤並執行取代的引擎。  
5. **`Process`** 承擔主要工作：它會讀取每個 `${...}` 標籤，於資料來源中查找相符的屬性，並將值寫入儲存格。  
6. **儲存活頁簿** 將更新後的檔案寫入磁碟，供後續使用。

## 準備 Excel 範本以 **填充 Excel 範本資料**

1. 開啟一個新的 Excel 活頁簿。  
2. 在任何需要動態內容的儲存格中，輸入 Smart Marker 標籤，例如：

   ```
   ${Comment:fieldName}
   ```

3. 將檔案儲存為 `Template.xlsx`。

標籤語法遵循 `${<CollectionName>:<PropertyName>}` 的模式。在此簡單範例中，我們省略集合名稱，使用預設集合，即傳遞給 `Process` 的資料來源。

> **邊緣情況：** 若標籤引用的屬性在資料來源中不存在，Aspose.Cells 會保持儲存格不變。務必確認屬性名稱完全相符，包含大小寫。

## 建立 **使用 Aspose.Cells 智慧標記** 的資料來源

您可以提供任何可列舉的集合——陣列、`List<T>`、`DataTable`，甚至自訂物件。當使用表格樣式的標記時，處理器會遍歷集合，為每個項目重複列。

```csharp
// Example with a List<T>
var comments = new List<Comment>
{
    new Comment { fieldName = "First comment." },
    new Comment { fieldName = "Second comment." }
};

processor.Process(ws, comments);
```

```csharp
public class Comment
{
    public string fieldName { get; set; }
}
```

當您提供多列資料時，Aspose.Cells 會自動擴展範本區域以容納所有項目，這對於產生報告、發票或資料驅動的表格非常有用。

## 使用 **Aspose.Cells 智慧標記** 處理工作表

`Process` 方法可以接受可選設定，例如：

- `SmartMarkerOptions` 用於控制空儲存格的處理方式。
- `DataSourceOptions` 用於指定不同的集合名稱。

```csharp
SmartMarkerOptions options = new SmartMarkerOptions
{
    // Preserve empty cells as blanks instead of removing them.
    PreserveEmptyCells = true
};

processor.Process(ws, dataSource, options);
```

這些選項讓您對 **填充 Excel 範本資料** 的操作擁有精細的控制，確保輸出符合您的格式需求。

## 儲存結果並驗證輸出

處理完成後，您可以將活頁簿儲存為 Aspose.Cells 支援的任何格式，例如 XLSX、CSV 或 PDF。

```csharp
workbook.Save("Result.pdf", SaveFormat.Pdf);
```

開啟 `Result.xlsx`（或 `Result.pdf`）以驗證 `${Comment:fieldName}` 佔位符已被 **由 C# 產生的範例評論文字** 取代。若儲存格仍顯示原始標籤，請再次檢查資料來源中的屬性名稱。

## 常見陷阱與避免方法

| 問題 | 原因 | 解決方式 |
|------|------|----------|
| 標籤未被取代 | 屬性名稱不匹配（例如 `fieldname` 與 `fieldName`） | 確保大小寫完全相符 |
| 列未被複製 | 資料來源僅包含單一物件，而範本預期為表格 | 提供包含多個項目的集合 |
| 儲存活頁簿時崩潰 | 使用過時的 Aspose.Cells 版本 | 升級至最新的 NuGet 套件 |
| 格式遺失 | 處理器覆寫了儲存格樣式 | 使用 `SmartMarkerOptions.PreserveCellFormatting = true` 以保留樣式 |

## 完整範例程式

以下是一個獨立的程式範例，您可以直接複製、貼上並執行。

```csharp
using Aspose.Cells;
using System;
using System.Collections.Generic;

namespace SmartMarkerDemo
{
    class Program
    {
        static void Main()
        {
            // Load the template that contains the Smart Marker tag ${Comment:fieldName}
            Workbook workbook = new Workbook("Template.xlsx");
            Worksheet ws = workbook.Worksheets[0];

            // Create a list of data objects – each object maps to the marker property.
            var data = new List<Comment>
            {
                new Comment { fieldName = "First generated comment." },
                new Comment { fieldName = "Second generated comment." },
                new Comment { fieldName = "Third generated comment." }
            };

            // Initialise the processor and run it.
            SmartMarkerProcessor processor = new SmartMarkerProcessor();
            processor.Process(ws, data);

            // Save the populated workbook.
            workbook.Save("Result.xlsx");
            Console.WriteLine("Smart marker processing complete. Check Result.xlsx.");
        }
    }

    public class Comment
    {
        public string fieldName { get; set; }
    }
}
```

**預期結果：** 在 `Result.xlsx` 中，原本包含 `${Comment:fieldName}` 的儲存格會展開為三列，每列填入 `data` 清單中相對應的評論文字。
