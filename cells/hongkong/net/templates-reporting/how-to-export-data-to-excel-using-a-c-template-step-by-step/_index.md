# 如何使用 C# 範本匯出資料至 Excel – 步驟說明指南

如果您需要 **將資料匯出至 Excel**，本指南提供一個完整的端對端解決方案。透過載入已包含 Smart Marker 標記的 Excel 範本，您可以 **自動產生 Excel**，並產出精緻的 **員工報表 Excel**，無需撰寫逐格的程式碼。

您將會學會：

* 載入定義版面配置的 Excel 範本（`load excel template`）。
* 將員工物件清單注入範本。
* 產生最終活頁簿並儲存為 `output.xlsx`。

所有必要程式碼皆已提供，您可以直接複製、貼上並執行。

## 前置條件

* .NET 6.0 或更新版本（此程式碼亦相容 .NET Framework 4.7+）。  
* **Aspose.Cells for .NET** NuGet 套件 – 提供 `Workbook`、`SmartMarkerProcessor` 與 Smart Marker 支援。  
* 一個名為 `YOUR_DIRECTORY` 的資料夾，內含 `template.xlsx`。範本應在欲顯示資料的儲存格內放置如 `&=EmployeeList.Name` 的 Smart Marker 標記。

> **專業小技巧：** 將範本放在同一個專案資料夾，並將其 *Copy to Output Directory* 屬性設為 *Copy always*，即可在除錯時正確解析路徑。

## 完整原始碼

```csharp
using System;
using System.Collections.Generic;
using Aspose.Cells;

namespace ExcelExportDemo
{
    // Simple POCO that represents an employee record
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Step 1: Load the Excel template that contains Smart Marker tags
            string templatePath = @"YOUR_DIRECTORY\template.xlsx";
            Workbook wb = new Workbook(templatePath);

            // Step 2: Prepare a data source – a list of employee objects
            List<Employee> employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Step 3: Create a SmartMarkerProcessor instance
            SmartMarkerProcessor sp = new SmartMarkerProcessor();

            // Step 4: Apply the employee data to the workbook using the processor
            // The tag &amp;=EmployeeList.Name in the template will be replaced with each employee's name,
            // and &amp;=EmployeeList.Position will be replaced with the corresponding position.
            sp.Process(wb, employeeList);

            // Step 5: Save the populated workbook
            string outputPath = @"YOUR_DIRECTORY\output.xlsx";
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

### 程式碼功能說明

| 步驟 | 為何重要 | 主要程式碼 |
|------|----------|------------|
| **載入 Excel 範本** | 重複使用已設計好的版面可節省時間，且保證樣式一致。 | `Workbook wb = new Workbook(templatePath);` |
| **準備資料來源** | Smart Marker 能處理任何 `IEnumerable` 集合；此處使用 `Employee` 清單。 | `List<Employee> employeeList = …` |
| **建立處理器** | `SmartMarkerProcessor` 會解析範本、尋找標記並注入資料。 | `SmartMarkerProcessor sp = new SmartMarkerProcessor();` |
| **處理資料** | 處理器會將每個 Smart Marker 標記替換為對應的屬性值。 | `sp.Process(wb, employeeList);` |
| **儲存活頁簿** | 最終檔案可提供給使用者、存放於伺服器，或作為電子郵件附件。 | `wb.Save(outputPath);` |

最終會產生一個 **員工報表 Excel** 檔案，每一列都包含員工的姓名與職稱，正好對應原始範本中標記所在的位置。

## 載入 Excel 範本

當您使用 `new Workbook(path)` **load excel template** 時，Aspose.Cells 會讀取整個活頁簿——包括樣式、公式與 Smart Marker 佔位符。此作法較從頭建立活頁簿更具優勢，原因如下：

* **設計控制** – 設計師可在不觸碰程式碼的情況下，格式化標題、加入公司標誌、設定欄寬。  
* **版本管理** – 更新範本不需要重新編譯應用程式。  
* **在地化** – 可為不同語系保留不同的範本檔案。

若您偏好純 .NET 解決方案且不使用第三方函式庫，也可以改用 **ClosedXML** 或 **EPPlus**，但它們缺乏內建的 Smart Marker 支援，意味著您必須自行撰寫逐格寫入的迴圈。

## 使用 Smart Marker 自動產生 Excel

Smart Marker 是形如 `&=Collection.Property` 的佔位符。處理器執行時會：

* 依序遍歷集合（本例為 `employeeList`）。  
* 為每筆資料將屬性值寫入對應的儲存格。  
* 必要時自動展開列或欄。

此機制 **自動產生 Excel**，免除手動迭代的程式邏輯。相同模式同樣適用於訂單、發票、庫存清單等任何資料形態。

### 常見變化

| 變化 | 實作方式 |
|------|----------|
| **多個集合** | 新增更多清單（例如 `List<Department>`），並以不同標記如 `&=DepartmentList.Name` 參照。 |
| **巢狀集合** | 使用點記法：`&=EmployeeList.Projects.ProjectName`，其中 `Projects` 為 `Employee` 內的集合屬性。 |
| **條件格式** | 在範本中放置 Excel 條件格式規則，處理器會保留該規則於產生的列。 |

## 建立員工報表 Excel

**employee report Excel** 這個詞彙代表典型的商業需求：主管需要一份可列印的員工清單。將 Smart Marker 標記直接嵌入範本，可得到：

* 以粗體與背景色呈現的標題列。  
* 依資料自動調整欄寬。  
* 可選的合計列（例如員工總數），可使用標準 Excel 公式計算。

若需加入合計列，只要在範本中放置類似 `=COUNTA(A2:A100)` 的公式，處理器不會干擾它。

## 產生 Excel 範本 C# – 最佳實踐

在 **generate Excel template C#** 程式碼時，請遵守以下原則：

1. **關注點分離** – 將範本載入、資料準備與處理分別放在不同方法中，便於單元測試。  
2. **驗證輸入** – 在呼叫 `Process` 前，確保範本檔案存在且資料集合不為 null。  
3. **釋放資源** – 雖然 Aspose.Cells 會自行管理記憶體，若處理大型檔案，仍建議將 `Workbook` 包在 `using` 區塊。  
4. **例外處理** – 在 `sp.Process` 周圍捕捉 `Exception`，以回報標記名稱不匹配等問題。

```csharp
static Workbook LoadTemplate(string path)
{
    if (!File.Exists(path))
        throw new FileNotFoundException($"Template not found: {path}");
    return new Workbook(path);
}
```

| 姓名      | 職稱      |
|-----------|-----------|
| John Doe  | Developer |
| Jane Smith| Manager   |

`template.xlsx` 中的所有格式——例如標題背景色、欄寬、以及任何商標圖片——皆保持不變。

## 常見問題排除

| 症狀 | 可能原因 | 解決方式 |
|------|----------|----------|
| 處理後未顯示資料 | Smart Marker 標記拼寫錯誤或放在合併儲存格內。 | 確認標記符合 `&=Collection.Property` 語法，且未置於合併區域。 |
| 輸出檔案為空或損毀 | 活頁簿於處理完成前已儲存。 | 確保 `sp.Process` **先於** `wb.Save` 執行。 |
| 大量員工清單導致產生緩慢 | 使用 Aspose.Cells 免費版可能有效能限制。 | 升級至授權版或分批處理資料。 |
| 範本路徑錯誤 | 相對路徑在執行時指向不同資料夾。 | 使用 `Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "template.xlsx")`，或設定檔案的 *Copy to Output Directory* 屬性。 |

## 完整範例回顧

以下提供整個程式碼區塊，方便一次複製貼上：

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Load the template
            string templatePath = Path.Combine("YOUR_DIRECTORY", "template.xlsx");
            Workbook wb = new Workbook(templatePath);

            // Prepare data
            var employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Process Smart Markers
            var sp = new SmartMarkerProcessor();
            sp.Process(wb, employeeList);

            // Save the result
            string outputPath = Path.Combine("YOUR_DIRECTORY", "output.xlsx");
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

執行此程式即會產生 **員工報表 Excel** 檔案，您可以將其以電子郵件寄送、列印，或進一步處理。
