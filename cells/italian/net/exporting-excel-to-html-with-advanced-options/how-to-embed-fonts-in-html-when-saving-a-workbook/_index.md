# Come incorporare i font in HTML durante il salvataggio di una cartella di lavoro

Se hai bisogno di **come incorporare i font in HTML** durante l'esportazione di un foglio di calcolo, questo tutorial ti mostra una soluzione completa, pronta all'uso. Che tu stia costruendo un portale di reporting o una vista analitica lato client, incorporare i font garantisce che l'HTML renderizzato abbia esattamente lo stesso aspetto della cartella di lavoro originale, indipendentemente dai font installati sul dispositivo dell'utente.

Imparerai anche il modo migliore per **salvare la cartella di lavoro come HTML** usando Aspose.Cells, vedrai le insidie più comuni e otterrai consigli per gestire cartelle di lavoro di grandi dimensioni o file di font personalizzati. Non è necessaria alcuna documentazione esterna: tutto ciò che ti serve è in questa guida.

## Prerequisiti

Prima di iniziare, assicurati di avere:

- .NET 6.0 o successivo (il codice funziona anche con .NET Framework 4.7+)
- Una licenza valida di Aspose.Cells for .NET (oppure puoi utilizzare la modalità di valutazione gratuita)
- Conoscenze di base di C# e un IDE come Visual Studio 2022
- I file di font TrueType (.ttf) o OpenType (.otf) che desideri incorporare (devono essere accessibili al processo in esecuzione)

## Passo 1: Configura il progetto e importa Aspose.Cells

Crea una nuova applicazione console e aggiungi il pacchetto NuGet Aspose.Cells:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

Quindi apri **Program.cs** e aggiungi le direttive `using` richieste:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **Consiglio professionale:** Posiziona i tuoi font personalizzati in una cartella chiamata `fonts` nella radice del progetto. Questo rende la soluzione portabile e facilita il riferimento successivo.

## Passo 2: Crea o carica una cartella di lavoro

Per dimostrazione, creeremo una semplice cartella di lavoro con alcune celle formattate:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **Perché è importante:** Se ometti lo stile personalizzato, l'HTML esportato ricadrà sui font predefiniti del browser, vanificando lo scopo di **come incorporare i font in HTML**.

## Passo 3: Configura `HtmlSaveOptions` per incorporare i font

Il cuore di **come incorporare i font in HTML** risiede nella classe `HtmlSaveOptions`. Impostare `EmbedFonts = true` indica ad Aspose.Cells di incorporare tutti i font TrueType/OpenType referenziati direttamente nell'HTML generato come URI dati Base64.

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### Come funziona l'incorporamento

Quando `EmbedFonts` è `true`, Aspose.Cells analizza le definizioni di stile della cartella di lavoro, individua i file di font corrispondenti sul sistema (o nella cartella `fonts` che hai aggiunto), legge i dati binari e inserisce un blocco `<style>` simile a:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

Poiché i dati del font sono codificati direttamente nell'HTML, la pagina viene renderizzata correttamente anche su macchine che non hanno il font installato.

## Passo 4: Salva la cartella di lavoro come HTML

Ora puoi **salvare la cartella di lavoro come HTML** con le opzioni configurate. Scegli una directory in cui l'applicazione possa scrivere (ad esempio `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

L'esecuzione del programma produce un unico file `report.html`. Aprilo in qualsiasi browser moderno e vedrai l'intestazione “Quarterly Sales” renderizzata con il font **Pacifico**, anche se il font non è installato sul tuo sistema operativo.

### Output previsto

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

L'attributo `src:` contiene una lunga stringa Base64—questi sono i dati del font incorporati che consentono **come incorporare i font in HTML**.

## Passo 5: Verifica l'incorporamento dei font e risolvi i problemi

1. **Apri il file HTML in Chrome o Edge.** Se il font personalizzato appare, l'incorporamento è riuscito.  
2. **Ispeziona il sorgente della pagina.** Cerca la regola `@font-face` generata da Aspose.Cells.  
3. **Problemi comuni:**  
   - *File di font mancante:* Assicurati che il file di font sia raggiungibile. Puoi aggiungere esplicitamente una cartella al percorso di ricerca:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *Dimensione HTML elevata:* Incorporare molti font può gonfiare il file. Usa `ExportToSingleFile = false` per mantenere i font come file `.ttf` separati in una cartella delle risorse.

   - *Formato di font non supportato:* Aspose.Cells incorpora solo TrueType (`.ttf`) e OpenType (`.otf`). Converti altri formati prima dell'incorporamento.

## Esempio completo funzionante

Di seguito trovi il programma completo che puoi copiare, incollare ed eseguire senza modifiche (eccetto la riga opzionale della licenza).

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

Eseguendo questo programma verrà creato `output/report.html`. Apri il file e vedrai il font **Pacifico** renderizzato correttamente—dimostrando **come incorporare i font in HTML** mentre **salvi la cartella di lavoro come HTML**.

## Domande frequenti

| Domanda | Risposta |
|----------|----------|
| *Posso incorporare solo font specifici?* | Sì. Imposta `htmlOpt.EmbedAllFonts = false` (disponibile nelle versioni più recenti) e utilizza `htmlOpt.FontsToEmbed` per elencare i nomi dei font desiderati. |
| *E se devo incorporare font per più fogli di lavoro?* | Imposta `ExportActiveWorksheetOnly = false` così ogni foglio di lavoro viene esportato, e Aspose.Cells incorporerà i font usati in tutta la cartella di lavoro. |
| *I font incorporati funzioneranno sui browser mobili?* | I browser mobili moderni supportano i font codificati in Base64, quindi i font incorporati vengono renderizzati correttamente finché il formato del font è supportato (TTF o OTF). |
| *Quanto può crescere il file HTML?* | Incorporare un font TrueType da 200 KB aggiunge circa la stessa quantità al file HTML (Base64 aggiunge ~33 % di overhead). Per molti font, considera l'esportazione in una cartella (`ExportToSingleFile = false`) per mantenere leggero l'HTML. |
