# Come incorporare i font quando si salva Excel in HTML con C#

Come incorporare i font quando si salva una cartella di lavoro Excel in HTML è una necessità comune per preservare l’aspetto esatto dei fogli di calcolo su tutti i browser. Se devi esportare Excel in HTML mantenendo i caratteri originali, questa guida ti mostra una soluzione completa, pronta all’uso.

Imparerai a **esportare Excel in HTML**, **convertire Excel in HTML** con font incorporati e a evitare il tipico problema del “font mancante” che rompe il layout sui computer client. Non sono necessari strumenti esterni: basta la libreria Aspose.Cells e poche righe di C#.

## Prerequisiti

Prima di iniziare, assicurati di avere:

* .NET 6.0 (o successivo) installato.
* Una copia con licenza di **Aspose.Cells for .NET** – la versione di prova gratuita è sufficiente per i test.
* Un IDE come Visual Studio 2022 o VS Code.

Se hai già tutto questo, puoi passare direttamente al codice.

## Passo 1: Creare una cartella di lavoro e aggiungere dati di esempio

Per prima cosa generiamo una piccola cartella di lavoro così da poter vedere l’effetto dei font incorporati. Il codice qui sotto crea un foglio di lavoro, scrive alcune celle e applica un font personalizzato.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### Perché aggiungiamo un font personalizzato

Incorporare i font è utile solo quando la cartella di lavoro utilizza caratteri che potrebbero non essere presenti sul dispositivo client. Impostando esplicitamente **Arial** (o qualsiasi altro font) possiamo verificare che l’output HTML contenga davvero i dati del font.

## Passo 2: Configurare le opzioni di salvataggio HTML per incorporare i font

Aspose.Cells fornisce la classe `HtmlSaveOptions`. Impostare `EmbedFonts = true` indica alla libreria di incorporare i file dei font richiesti direttamente nell’HTML generato come URI dati codificati in Base64.

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### Cosa fa realmente “incorporare i font in html”

Quando `EmbedFonts` è true, Aspose.Cells estrae i file dei font dal sistema (o dalla collezione di font incorporati nella cartella di lavoro) e li converte in stringhe **Base64**. Quelle stringhe vengono poi inserite in un blocco `<style>` tramite `@font-face`. L’HTML risultante può essere aperto su qualsiasi dispositivo senza dover installare il font originale.

## Passo 3: Salvare la cartella di lavoro come HTML con i font incorporati

Ora scriviamo la cartella di lavoro su disco. Il file conterrà i dati del font, quindi aprirlo in qualsiasi browser moderno mostrerà la stessa tipografia dell’originale file Excel.

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### Risultato atteso

* `embedded.html` si trova nella cartella `output`.
* Aprendo il file in Chrome, Edge o Firefox si visualizza il foglio con testo **Arial**, anche se la macchina del browser non dispone di Arial.
* Esaminando il sorgente HTML si trova un blocco `<style>` contenente una regola `@font-face` con una lunga dichiarazione `src: url(data:font/ttf;base64,…)` – quel segmento è il font incorporato.

## Passo 4: Verificare che l’HTML funzioni su un altro computer (opzionale)

Per essere assolutamente certi che l’incorporamento sia riuscito:

1. Copia `output/embedded.html` su un computer diverso (o su una macchina virtuale) che **non** abbia il font personalizzato installato.
2. Apri il file in un browser.
3. Il layout e la tipografia dovrebbero corrispondere alla visualizzazione originale di Excel.

Se il font torna a un generico, ricontrolla che il file del font sia accessibile sulla macchina di build e che tu abbia i permessi per leggerlo.

## Domande comuni e casi particolari

### L’incorporamento aumenta le dimensioni del file?

Sì. Incorporare un font TrueType o OpenType può aggiungere **decine di kilobyte** al file HTML. Per cartelle di lavoro grandi con molti font unici, considera:

* Sottocampionare il font (solo i caratteri effettivamente usati) – Aspose.Cells lo fa automaticamente per la maggior parte dei font comuni.
* Usare `ExportEmbeddedImages = false` se non ti servono le immagini incorporate.

### E se devo incorporare solo font specifici?

`HtmlSaveOptions` non espone una whitelist diretta, ma puoi controllare quali font compaiono **limitando i font usati nella cartella di lavoro** prima di chiamare `Save`. Rimuovi le assegnazioni di font non necessarie o sostituiscile con font web‑safe standard.

### Posso incorporare i font quando converto in altri formati (ad es., PDF)?

La stessa proprietà `EmbedFonts` esiste su `PdfSaveOptions`. Il concetto è identico: i dati del font vengono incorporati così il PDF viene renderizzato correttamente su qualsiasi visualizzatore.

## Esempio completo, eseguibile

Di seguito trovi il programma completo che puoi copiare‑incollare in un nuovo progetto console.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

Eseguendo il programma otterrai un **file HTML che contiene il font Arial incorporato**, garantendo la fedeltà visiva ovunque il file venga aperto.

## Conclusione

Ora sai **come incorporare i font quando si salva Excel in HTML** usando C#. Configurando `HtmlSaveOptions.EmbedFonts = true`, puoi esportare Excel in HTML e **convertire Excel in HTML** senza preoccuparti dei font mancanti sul lato client. Questa tecnica è fondamentale per reportistica web, dashboard compatibili con email o qualsiasi scenario in cui condividi contenuti derivati da Excel in formato HTML.

### Qual è il prossimo passo?

* **Personalizza il CSS** generato da Aspose.Cells per allinearlo alla guida di stile del tuo sito.  
* **Incorpora le immagini** selettivamente attivando `ExportEmbeddedImages`.  
* **Esplora altri formati di esportazione** come PDF o SVG mantenendo l’incorporamento dei font.  

Sentiti libero di sperimentare con font diversi, fogli di lavoro più grandi o cartelle di lavoro a più fogli. La stessa opzione `EmbedFonts` funziona su tutti i formati di output supportati, offrendoti un controllo coerente sull’incorporamento dei font ovunque ne abbia bisogno. Buon coding!
