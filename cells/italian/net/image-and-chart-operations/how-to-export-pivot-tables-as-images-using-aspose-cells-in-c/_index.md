# Come esportare tabelle pivot come immagini usando Aspose.Cells in C#

Se hai bisogno di **come esportare pivot** i dati in un'immagine portatile, Aspose.Cells rende il processo semplice. Questo tutorial ti mostra esattamente come esportare le tabelle pivot come file PNG, così da poterle incorporare in report, email o documentazione senza richiedere Excel sulla macchina di destinazione.

Esportare una pivot come immagine elimina i problemi di formattazione specifici della versione e consente agli stakeholder non tecnici di visualizzare l'analisi immediatamente. Copriremo tutto, dalla configurazione del progetto al rendering dell'**immagine della tabella pivot esportata**, e spiegheremo anche come **salvare la pivot come immagine** per un riutilizzo futuro.

## Come esportare tabelle pivot come immagini con Aspose.Cells

Di seguito trovi l'esempio completo e eseguibile che carica una cartella di lavoro, aggiorna la pivot, configura le opzioni immagine e scrive il file di output. Ogni passaggio include una breve motivazione così capirai *perché* il codice è scritto in quel modo, non solo *cosa* fa.

### 1. Configura l'ambiente Aspose.Cells

1. Installa il pacchetto NuGet:

   ```bash
   dotnet add package Aspose.Cells
   ```

2. Aggiungi le direttive `using` richieste nella parte superiore del tuo file C#:

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **Consiglio professionale:** Mira a .NET 6 o versioni successive per beneficiare dei più recenti miglioramenti delle prestazioni in Aspose.Cells.

### 2. Carica la cartella di lavoro e individua la tabella pivot

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*Perché è importante:* La classe `Workbook` analizza il file XLSX e ti dà accesso a tutti i fogli di lavoro. Selezionare il foglio corretto è essenziale perché una cartella di lavoro può contenere più pivot.

### 3. Aggiorna la tabella pivot per catturare i dati di origine più recenti

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

L'aggiornamento garantisce che eventuali modifiche apportate all'intervallo di origine dopo il salvataggio del file siano riflesse nell'immagine renderizzata. Saltare questo passaggio può produrre visualizzazioni obsolete o imprecise.

### 4. Configura le opzioni di esportazione immagine (esporta immagine della tabella pivot)

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

L'oggetto `ImageOrPrintOptions` ti consente di controllare il formato, la risoluzione e altri dettagli di rendering. PNG è la scelta più comune per grafica nitida e compatibile con il web, ma potresti passare a `ImageFormat.Jpeg` se la dimensione del file è un problema.

### 5. Renderizza e **salva la pivot come immagine**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

`RenderToImage` esegue il lavoro pesante: disegna la pivot esattamente come appare in Excel e scrive i dati binari PNG su disco. Il metodo restituisce `void`, quindi puoi presumere in sicurezza che il file esista al termine della chiamata senza necessità di ulteriori controlli.

#### Risultato atteso

Dopo l'esecuzione del programma, troverai `Pivot.png` nella cartella specificata. Aprire il file dovrebbe mostrare una fedele istantanea della tabella pivot originale, includendo le intestazioni di colonna, i totali di riga e qualsiasi formattazione applicata.

### 6. Variazioni comuni e casi limite

| Scenario | Regolazione |
|----------|------------|
| **Pivot di grandi dimensioni** (molte righe/colonne) | Aumenta `HorizontalResolution` e `VerticalResolution` a 300 dpi per un output più nitido. |
| **Stile personalizzato** (colori di sfondo, caratteri) | Assicurati che le definizioni di stile della cartella di lavoro siano caricate prima di chiamare `Refresh()`. |
| **Pivot multiple** in un foglio | Itera su `worksheet.PivotTables` e chiama `RenderToImage` per ciascuna, usando nomi file distinti. |
| **Esporta in JPEG** invece di PNG | Modifica `ImageFormat = ImageFormat.Jpeg` e opzionalmente imposta `Quality` su un oggetto `JpegSaveOptions`. |

Queste variazioni ti consentono di **esportare l'immagine della tabella pivot** nel formato esatto che il tuo sistema a valle si aspetta.

## Codice sorgente completo per copia‑incolla veloce

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

Eseguendo il programma si genera il file PNG mostrato sopra, completando il flusso di lavoro **salva la pivot come immagine** in meno di un minuto.
