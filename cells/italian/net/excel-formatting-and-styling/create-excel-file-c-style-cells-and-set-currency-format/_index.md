# Creare un file Excel con C# – formattare le celle e impostare il formato valuta

Se hai bisogno di **creare un file Excel con C#** dall’aspetto professionale, questa guida ti mostra esattamente come formattare le celle di Excel e impostare una colonna come valuta. Vedrai un esempio completo, end‑to‑end, che importa un `DataTable`, applica un’intestazione in grassetto e imposta il formato numerico `$#,##0.00` per la colonna prezzo.

Il tutorial copre tutto ciò di cui hai bisogno: i pacchetti NuGet richiesti, il codice sorgente completo, spiegazioni sul perché ogni elemento è importante e consigli per gestire casi particolari come righe vuote o impostazioni locali diverse. Alla fine sarai in grado di generare un file `.xlsx` con una colonna prezzo formattata correttamente in poche righe di C#.

## Prerequisiti

- .NET 6.0 o successivo (il codice funziona anche con .NET Framework 4.6+)
- Visual Studio 2022 o qualsiasi editor C# tu preferisca
- La libreria **Aspose.Cells for .NET** o **GemBox.Spreadsheet** (entrambi supportano `ImportTableOptions`). L’esempio qui sotto utilizza **Aspose.Cells** perché fornisce una semplice proprietà `StyleArray`.
- Conoscenze di base delle collezioni C# e di `DataTable`

> **Pro tip:** Se preferisci un’alternativa gratuita, sostituisci `Aspose.Cells` con `GemBox.Spreadsheet`. L’API per importare un `DataTable` con stili è quasi identica; basta cambiare lo spazio dei nomi e il nome del pacchetto NuGet.

## Step 1: Installare la libreria Excel

Apri il NuGet Package Manager e installa la libreria:

```bash
dotnet add package Aspose.Cells
```

> **Perché questo passaggio?** La libreria fornisce le classi `Workbook`, `Worksheet`, `Style` e `ImportTableOptions` utilizzate successivamente. Senza di essa dovresti scrivere manualmente il formato Office Open XML, il che è soggetto a errori.

## Step 2: Creare un DataTable con dati di esempio

Un `DataTable` è un modo comodo per contenere dati tabulari prima di esportarli in Excel. In questo esempio abbiamo due colonne: *Product* e *Price*.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Spiegazione:**  
> - `Columns.Add("Price", typeof(double))` indica alla tabella di trattare i valori di prezzo come numeri, requisito necessario per la formattazione numerica successiva.  
> - L’aggiunta di alcune righe fornisce dati per verificare il passaggio **format column currency**.

## Step 3: Definire gli stili da applicare

Creeremo un array di oggetti `Style` che corrisponde all’ordine delle colonne. La prima voce stila la riga di intestazione, la seconda lascia invariata la colonna *Product*, e la terza applica un formato numerico di valuta.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### Perché usare un **style array**?

`ImportTableOptions.StyleArray` associa ogni colonna a uno `Style`. Questo è il modo più efficiente per **add number format** e **style excel cells** in un’unica operazione di importazione, evitando un secondo passaggio sul foglio di lavoro.

## Step 4: Configurare le opzioni di importazione

Ora colleghiamo l’array di stili all’operazione di importazione. L’oggetto `ImportTableOptions` consente anche di controllare se la prima riga è trattata come intestazione.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Nota:** `IsFieldNameShown` è impostato di default su `true`, ma specificarlo esplicitamente rende l’intento più chiaro per i lettori futuri.

## Step 5: Creare un workbook, importare la tabella e salvare

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### Risultato atteso

Quando apri `DataTableWithStyles.xlsx`:

- La prima riga (intestazione) è **grassetto**.
- La colonna *Price* mostra i valori come **$1.20**, **$3.50**, **$0.75**.
- La colonna *Product* mantiene il font predefinito.

Hai creato con successo **un file Excel con C#** con una colonna valuta formattata e le celle dell’intestazione stilizzate.

## Step 6: Gestire variazioni comuni e casi limite

### a. Locale diverso o simbolo di valuta personalizzato

Se ti serve l’euro o un’altra valuta, sostituisci il formato predefinito `164` con una stringa di formato personalizzata:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. Aggiungere altre colonne in seguito

Quando aggiungi colonne extra, estendi l’array `columnStyles` di conseguenza. Usa `null` per le colonne che devono mantenere lo stile predefinito.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. DataTable vuoto

Se il `DataTable` non contiene righe, Aspose.Cells crea comunque la riga di intestazione. Tuttavia, il workbook conterrà solo una riga. Per evitare un file vuoto, verifica il conteggio delle righe prima dell’importazione:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Usare `GemBox.Spreadsheet` al posto di Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

La logica rimane identica, dimostrando che il tutorial è **format column currency** indipendente dalla libreria sottostante.

## Step 7: Verificare il file programmaticamente (opzionale)

Puoi aprire il workbook generato e verificare che il formato numerico sia stato applicato correttamente—utile per i test unitari.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```
