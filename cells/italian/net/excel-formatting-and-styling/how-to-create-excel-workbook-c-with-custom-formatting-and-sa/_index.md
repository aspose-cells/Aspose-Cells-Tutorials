# Come creare una cartella di lavoro Excel C# con formattazione personalizzata e salvarla come XLSX

Se hai bisogno di **create Excel workbook C#** che importi dati, applichi un formato numerico personalizzato e cambi il colore del carattere della cella, questo tutorial ti mostra esattamente come fare. Otterrai un esempio pronto all'uso che produce un file `StyleArrayImport.xlsx` formattato in pochi secondi.

Lavorare con Excel da C# spesso comporta passaggi manuali ripetitivi: definire formati, applicare colori e ricordarsi di salvare correttamente il file. Alla fine di questa guida automatizzerai tutte queste operazioni, così potrai concentrarti sui dati invece che sull'interfaccia.

Imparerai a:

* importare un `DataTable` in un foglio di lavoro,
* usare un `StyleArray` per **apply custom number format** e **change cell font color**,
* **save workbook as XLSX** con una singola chiamata di metodo,
* e verificare che il **format imported data excel** appaia esattamente come previsto.

L'unico prerequisito è un riferimento alla libreria **Aspose.Cells for .NET** (o a qualsiasi API compatibile che fornisca `Workbook`, `Worksheet` e `StyleArray`). Il codice è destinato a .NET 6+, ma versioni precedenti funzionano con piccole modifiche.

---

## Prerequisiti

| Requisito | Motivo |
|-----------|--------|
| .NET 6 SDK o successivo | Fornisce l'ambiente di runtime per l'app console C#. |
| Aspose.Cells for .NET (pacchetto NuGet `Aspose.Cells`) | Fornisce le classi `Workbook`, `Worksheet` e `StyleArray` usate nell'esempio. |

Installa il pacchetto Aspose.Cells con il seguente comando:

```bash
dotnet add package Aspose.Cells
```

## Passo 1: Preparare il DataTable di esempio

Per prima cosa, crea un `DataTable` che imiti i dati che normalmente otterresti da un database o da un'altra fonte. La tabella include una colonna **Name** (string) e una colonna **Amount** (decimal) che formatteremo in seguito.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Perché è importante:** L'uso di un `DataTable` ti consente di mantenere la logica di importazione indipendente dalla sorgente dati, un modello comune quando si generano report da database, file CSV o API.

## Passo 2: Definire uno StyleArray per **apply custom number format** e **change cell font color**

`StyleArray` ti permette di raggruppare le istruzioni di formattazione che saranno applicate a ogni cella importata dal `DataTable`. In questo esempio:

* impostiamo `Number` a `#,##0.00` – un tipico formato contabile con separatore delle migliaia,
* impostiamo `FontColor` a `Color.Blue` – per far risaltare i numeri.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**Perché usare uno StyleArray?** Applicare uno stile al momento dell'importazione evita un secondo passaggio sul foglio di lavoro, migliorando le prestazioni con set di dati di grandi dimensioni.

---

## Passo 3: **Create Excel workbook C#** – istanziare Workbook e ottenere il primo Worksheet

Ora creiamo una cartella di lavoro vuota e otteniamo un riferimento al primo foglio (indice 0). Questo foglio diventa la destinazione per i dati importati.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Spiegazione:** `Workbook` rappresenta l'intero file Excel, mentre `Worksheet` rappresenta una singola scheda. Il workbook predefinito contiene un foglio, sufficiente per la maggior parte dei report semplici.

---

## Passo 4: Importare il DataTable usando lo **StyleArray** per **format imported data excel**

Il metodo `ImportDataTable` copia le righe e le colonne della tabella nel foglio, a partire dalla cella `A1` (riga 0, colonna 0). L'argomento `true` indica al metodo di includere le intestazioni di colonna. Poiché passiamo `styleArray`, ogni cella importata riceve il formato numerico personalizzato e il colore del carattere.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**Cosa succede dietro le quinte:** Aspose.Cells itera su ogni riga, scrive il valore e poi applica lo stile definito in `styleArray`. I numeri appaiono con virgole e due decimali, e il testo è visualizzato in blu.

---

## Passo 5: **Save workbook as XLSX** – scrivere il file su disco

Infine, persisti il workbook in un file `.xlsx`. Puoi modificare il percorso con qualsiasi directory scrivibile sulla tua macchina.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Verifica del risultato:** Apri il file generato in Excel. Dovresti vedere le tre righe di dati, la colonna **Amount** formattata con virgole, due decimali e visualizzata con carattere blu. Questo conferma che il passaggio **format imported data excel** è riuscito.

## Esempio completo funzionante

Copia l'intero blocco qui sotto in un nuovo progetto console e eseguilo. Non è necessario alcun codice aggiuntivo.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Output previsto nella console:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

Apri il file e verifica che la colonna **Amount** mostri valori come `1,234.56` in carattere blu.

## Domande comuni & casi limite

| Domanda | Risposta |
|----------|----------|
| *Posso applicare formati diversi a colonne individuali?* | Sì. Dopo l'importazione, recupera l'oggetto `Style` della colonna (`worksheet.Cells.Columns[1].Style`) e imposta un `Number` o `FontColor` diverso. |
| *E se devo formattare le date invece dei numeri?* | Imposta `styleArray.Number = "mm-dd-yyyy"` e opzionalmente `styleArray.FontColor` per le celle data. |
| *Il carattere blu è visibile sui temi scuri di Excel?* | Il blu può risultare difficile da leggere su sfondi scuri. Usa una tonalità più chiara (`Color.LightBlue`) o un colore di contrasto (`Color.Black`). |
| *Come importare un DataTable molto grande (centinaia di migliaia di righe)?* | Usa `ImportDataTable` con la sovraccarico `ImportDataTableOptions` per lo streaming dei dati, oppure suddividi l'importazione in più fogli per rimanere entro il limite di righe di Excel (1.048.576 righe). |
| *Posso esportare in CSV invece di XLSX?* | Sostituisci `SaveFormat.Xlsx` con `SaveFormat.Csv`. Nota che le informazioni di formattazione (formato numerico, colore del carattere) vengono perse nel CSV perché è un formato di testo semplice. |

## Consigli per l'uso in produzione

* **Pro tip:** Metti in cache l'oggetto `Style` se devi applicare la stessa formattazione a molti fogli; creare un nuovo `StyleArray` per ogni importazione aggiunge overhead.
* **Attenzione alle differenze culturali:** Il pattern `Number` `#,##0.00` segue la cultura invariata. Se ti servono separatori specifici per locale, usa `NumberFormatInfo` o lascia che Excel gestisca il tutto in base alle impostazioni regionali dell'utente.
* **Gestione degli errori:** Avvolgi la chiamata `Save` in un blocco try‑catch per gestire le eccezioni I/O (ad es., permessi insufficienti o file bloccati).
