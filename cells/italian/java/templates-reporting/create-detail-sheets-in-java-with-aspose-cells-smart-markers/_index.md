# Crea fogli di dettaglio in Java con i marker intelligenti di Aspose.Cells

Se hai bisogno di **creare fogli di dettaglio** in un'applicazione Java, questo tutorial ti mostra come farlo con i marker intelligenti di Aspose.Cells. Vedrai un esempio completo e eseguibile che **java create worksheets**, deriva il **sheet name from field** e **process data source** in poche righe di codice.

La guida copre tutto, dalla configurazione del progetto al salvataggio del workbook finale, così potrai copiare‑incollare la soluzione nel tuo progetto e adattarla immediatamente. Non è necessaria alcuna documentazione esterna—tutto ciò che ti serve è qui.

## Cosa imparerai

* Come **use smart markers** per duplicare un foglio di lavoro modello per ogni riga in un set di dati master.  
* Come impostare dinamicamente il nome di ogni nuovo foglio in base al valore di un campo (es. `Order_123`).  
* Come fornire una collezione Java come **process data source** per il motore dei marker intelligenti.  
* Suggerimenti per gestire casi particolari come dati vuoti, caratteri speciali nei nomi dei fogli e considerazioni sulle prestazioni per set di dati di grandi dimensioni.

### Prerequisiti

| Requisito | Motivo |
|-------------|--------|
| Java 8 o superiore | Aspose.Cells for Java supporta Java 8+. |
| Sistema di build Maven o Gradle | Semplifica l'aggiunta della dipendenza Aspose.Cells. |
| Conoscenza di base delle collezioni Java | Necessaria per costruire la fonte dati per i marker intelligenti. |
| Un file Excel modello (`Template.xlsx`) con un marker intelligente segnaposto nella cella **A1** | Il modello guida la generazione dei fogli di dettaglio. |

> **Pro tip:** Mantieni il workbook modello nella cartella `resources` del progetto in modo che venga incluso nel tuo JAR.

## Passo 1: Aggiungi Aspose.Cells al tuo progetto (java create worksheets)

Se usi **Maven**, aggiungi la seguente dipendenza a `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

Per **Gradle**, inserisci questa riga in `build.gradle`:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

Queste righe rendono le API **java create worksheets** disponibili al momento della compilazione.

## Passo 2: Carica il workbook modello

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*Perché è importante:* L'oggetto `Workbook` è il punto di ingresso per tutte le operazioni Excel. Caricare il modello garantisce di partire con il layout corretto e con eventuali formattazioni predefinite.

## Passo 3: Inserisci un marker intelligente che crea un nuovo foglio per ogni riga master (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

La sintassi `${Orders:DetailSheetNewName=Order_${OrderId}}` è il cuore di **use smart markers**. Fa tre cose:

1. Itera sulla collezione `Orders`.  
2. Crea un **new worksheet** per ogni elemento.  
3. Imposta il **sheet name from field** `OrderId` (con prefisso `Order_`).

## Passo 4: Prepara la fonte dati (process data source)

Di seguito trovi un esempio minimale che utilizza una `List<Map<String, Object>>`. Sostituiscilo con la tua fonte dati reale—righe di database, deserializzazione JSON, ecc.

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*Perché è importante:* Il passaggio **process data source** collega la tua collezione Java al motore dei marker intelligenti. La chiave (`"Orders"`) deve corrispondere esattamente al nome del marker intelligente.

## Passo 5: Processa i marker intelligenti (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

Quando `process` viene eseguito, Aspose.Cells legge la collezione `Orders`, clona il foglio modello per ogni voce e rinomina ogni foglio in base al campo `OrderId`. Questo è il fulcro dell'uso di **process data source**.

## Passo 6: Salva il workbook con i fogli di dettaglio duplicati

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

Dopo l'esecuzione, troverai `DuplicatedDetailSheets.xlsx` contenente:

* `Sheet1` – il modello originale (invariato).  
* `Order_101` – foglio di dettaglio per il primo ordine.  
* `Order_102` – foglio di dettaglio per il secondo ordine.

### Output previsto (estratto)

| Nome foglio | A1 (marker intelligente) | Contenuto risultante |
|------------|--------------------------|----------------------|
| Order_101  | `${Orders:...}`          | Popolato con i dati da `order1` |
| Order_102  | `${Orders:...}`          | Popolato con i dati da `order2` |

Apri il file in Excel per verificare che ogni foglio sia correttamente denominato e contenga le righe di dati.

## Gestione di variazioni comuni e casi limite

### Fonte dati vuota

Se `orders` è vuoto, il processore dei marker intelligenti **non crea nuovi worksheet**. Per evitare un workbook vuoto, aggiungi una guardia:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### Caratteri speciali nei nomi dei fogli

I nomi dei fogli Excel non possono contenere `\ / ? * [ ] :`. Pulisci il campo prima di usarlo:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### Set di dati di grandi dimensioni

Per migliaia di righe, considera di aumentare l'heap JVM (`-Xmx2g`) e di chiamare `workbook.calculateFormula()` solo dopo che tutti i fogli sono stati generati, per migliorare le prestazioni.
