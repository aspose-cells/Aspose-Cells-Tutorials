# Come generare fogli di lavoro in Java usando SmartMarkerProcessor

Se hai bisogno di **come generare fogli di lavoro** in un file Excel, questa guida ti mostra una soluzione completa, pronta all'uso. Alla fine delle prime due frasi capirai come generare fogli di lavoro e fogli Excel dinamici da una collezione di oggetti, e avrai un esempio di codice funzionante che automatizza la creazione di Excel con una singola chiamata di metodo.

Creare fogli di lavoro separati per ogni dipendente, progetto o qualsiasi altra entità è una necessità comune quando devi **popolare excel workbook** dati in modo programmatico. Questo tutorial guida attraverso ogni passaggio—dalla configurazione del modello all'elaborazione di una lista e al salvataggio del file finale—così potrai applicare immediatamente la tecnica nelle tue applicazioni Java.

## Cosa otterrai

* Genera un foglio di lavoro master che elenca informazioni di alto livello.  
* Crea **multiple sheets from list** dati, con ogni foglio denominato automaticamente.  
* **Automate excel creation** senza aggiungere manualmente righe o colonne.  
* **Populate excel workbook** con strutture dati ricche (oggetti, mappe, array).  

Prerequisiti:

* Java 8 o versioni successive installate.  
* Maven (o un altro tool di build) per aggiungere la libreria Aspose.Cells per Java.  
* Una conoscenza di base delle collezioni Java.  

> **Consiglio professionale:** La sintassi SmartMarker (`${EmployeeMaster}`) funziona con qualsiasi tipo di collezione che implementa `java.util.Collection`. Usala per mantenere i tuoi modelli puliti e manutenibili.

## Come generare fogli di lavoro con SmartMarkerProcessor

Questa sezione contiene il codice principale che rende **come generare fogli di lavoro** senza sforzo. Spiegheremo perché ogni riga è importante, non solo cosa fa.

### Passo 1: Aggiungi la dipendenza Aspose.Cells

Se utilizzi Maven, includi quanto segue nel tuo `pom.xml`. La libreria fornisce la classe `SmartMarkerProcessor` usata in tutta questa guida.

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **Perché:** Aspose.Cells gestisce I/O di file Excel, l'analisi di Smart Marker e la gestione dei fogli internamente, permettendoti di concentrarti sui dati anziché su operazioni di file a basso livello.

### Passo 2: Prepara il modello Excel

Crea un file Excel chiamato `EmployeeTemplate.xlsx` con una singola cella che contiene il segnaposto Smart Marker:

| A |
|---|
| `${EmployeeMaster}` |

Quando il processore viene eseguito, sostituirà questo segnaposto con un **detail sheet** che contiene una riga per ogni dipendente.

> **Perché:** Il segnaposto indica al processore dove inserire i dati. Usare un modello separato mantiene intatta la tua formattazione (font, bordi, larghezze colonne).

### Passo 3: Definisci il modello dati

Di seguito trovi una classe `Employee` minimale e un metodo di supporto che costruisce una lista di dipendenti. La lista sarà usata per dimostrare **multiple sheets from list**.

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **Perché:** Un semplice oggetto Java (POJO) si mappa direttamente ai campi Smart Marker (`firstName`, `lastName`, `department`). Questo rende **populate excel workbook** semplice e tipizzato in modo sicuro.

### Passo 4: Configura lo SmartMarkerProcessor

Ora colleghiamo tutto insieme. Il processore leggerà il modello, sostituirà il marcatore e creerà un nuovo foglio chiamato `EmployeeDetail`.

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

**Spiegazione delle righe chiave**

| Line | Reason |
|------|--------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | Carica il modello che contiene già il segnaposto Smart Marker. |
| `data.put("EmployeeMaster", employees);` | Associa la lista Java al marcatore `${EmployeeMaster}`. |
| `processor.setDetailSheetNewName("EmployeeDetail");` | Assegna al foglio generato un nome significativo invece del predefinito `Sheet1`. |
| `processor.process(wb, data);` | **How to generate worksheets** – il processore legge il marcatore, crea un nuovo foglio e lo riempie con righe per ogni `Employee`. |
| `wb.save("EmployeesReport.xlsx");` | Salva i **dynamic excel sheets** su disco. |

### Passo 5: Verifica l'output

Apri `EmployeesReport.xlsx`. Dovresti vedere due fogli di lavoro:

1. **Sheet1** – il modello originale (può essere nascosto o rimosso).  
2. **EmployeeDetail** – un **dynamic excel sheet** con le colonne `firstName`, `lastName`, `department` e una riga per ogni dipendente.

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **Perché è importante:** Il file ora contiene **multiple sheets from list** senza alcun ciclo manuale o indirizzamento di celle. Il motore Smart Marker si occupa della creazione delle righe, della conversione dei dati e dell'ereditarietà della formattazione.

### Passo 6: Gestisci i casi limite

#### Lista dati vuota

Se `employees` è vuota, il processore crea comunque il foglio `EmployeeDetail` ma lo lascia vuoto. Puoi impedire l'aggiunta del foglio controllando la dimensione della collezione prima dell'elaborazione:

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### Liste molto grandi

Per migliaia di righe, considera di aumentare l'allocazione di memoria (`-Xmx2g`) o di usare `processor.setAutoFitRows(false)` per velocizzare l'elaborazione.

#### Nominare i fogli in modo personalizzato per gruppo

Se hai bisogno di un foglio separato per ogni dipartimento, puoi usare **multiple detail sheets**:

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

Il segnaposto `${department}` è preso da ciascun oggetto `Employee`, producendo fogli come `Dept_Sales`, `Dept_Marketing`, ecc.
