# Come creare una cartella di lavoro Excel in Java con dati JSON

Se hai bisogno di **create Excel workbook java** gli sviluppatori si trovano spesso ad affrontare la sfida di caricare dati JSON in un foglio di calcolo. Questa guida ti mostra come **populate Excel from JSON**, includendo come **convert JSON array excel** e **populate workbook from json** in modo pulito e ripetibile.

Lavorare con JSON è comune quando i servizi espongono dati tramite REST API, e Excel rimane il formato di riferimento per report e analisi. Alla fine di questo tutorial avrai un programma Java eseguibile che:

* crea una nuova cartella di lavoro Excel,
* legge un array JSON (o qualsiasi struttura JSON) e scrive i suoi valori nelle celle,
* salva il file su disco pronto per l'elaborazione successiva.

Non sono necessari strumenti esterni oltre alla libreria Aspose.Cells for Java, che fornisce lo `SmartMarkerProcessor` usato nel codice di esempio.

## Prerequisiti

Prima di iniziare, assicurati di avere:

| Prerequisito | Motivo |
|--------------|--------|
| Java Development Kit (JDK) ≥ 8 | Necessario per compilare ed eseguire l'esempio |
| Maven o Gradle (opzionale) | Semplifica la gestione delle dipendenze |
| Aspose.Cells for Java (v23.10 o successivo) | Fornisce le classi `Workbook` e `SmartMarkerProcessor` |
| Conoscenza di base di JSON e Java I/O | Ti aiuta a comprendere il flusso dei dati |

Se preferisci non usare uno strumento di build, puoi scaricare il JAR di Aspose.Cells dal [Aspose website](https://products.aspose.com/cells/java/) e aggiungerlo manualmente al classpath del tuo progetto.

## Passo 1: Configura il progetto e aggiungi la dipendenza Aspose.Cells

### Utenti Maven

Aggiungi la seguente dipendenza al tuo `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Utenti Gradle

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

Se non utilizzi uno strumento di build, posiziona il JAR scaricato nella cartella `libs/` e includilo nel classpath durante la compilazione:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## Passo 2: Crea una nuova cartella di lavoro e configura il processore SmartMarker

Lo `SmartMarkerProcessor` semplifica la mappatura dei valori JSON nelle celle di Excel. Chiamando `setArrayAsSingle(true)` indichiamo al processore di trattare un intero array JSON come un valore singolo, utile quando vuoi che ogni elemento occupi la propria cella in una riga.

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**Perché è importante:**  
Creare la cartella di lavoro in anticipo ti fornisce una tela pulita. Configurare `setArrayAsSingle(true)` impedisce al processore di appiattire l'array in una singola stringa (es., `["A","B","C"]`) e ti consente di controllare manualmente il layout.

## Passo 3: Definisci i dati JSON da inserire

Per questo tutorial utilizziamo un semplice array JSON, ma lo stesso approccio funziona con oggetti, array annidati o strutture complesse.

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**Suggerimento:** Se il tuo JSON proviene da un file o da un endpoint REST, sostituisci la stringa letterale con una `String` letta dalla sorgente, ad esempio `Files.readString(Paths.get("data.json"))`.

## Passo 4: Elabora la cartella di lavoro con i dati JSON

Ora lasciamo che lo `SmartMarkerProcessor` mappi l'array JSON sul primo foglio di lavoro. Il comportamento predefinito scrive ogni elemento in celle successive a partire da `A1`.

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

Dietro le quinte, Aspose.Cells analizza il JSON, crea una tabella dati temporanea e scrive i valori nel foglio. Poiché abbiamo impostato `ArrayAsSingle` a `true`, gli elementi dell'array vengono posizionati orizzontalmente nella prima riga.

## Passo 5: Salva la cartella di lavoro su un file

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

Quando esegui il programma, dovresti vedere un file chiamato **CreatedFromJson.xlsx** nella tua directory di lavoro. Aprendolo con Excel (o qualsiasi visualizzatore compatibile) verrà mostrato:

| A | B | C |
|---|---|---|
| A | B | C | *(i valori appaiono nelle celle A1, B1, C1)*

### Output previsto

```
Workbook saved to CreatedFromJson.xlsx
```

E il foglio Excel appare così:

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## Passo 6: Gestire strutture JSON più complesse (opzionale)

### 6.1 Popolare una cartella di lavoro da un oggetto JSON

Se il tuo JSON è un oggetto anziché un array, puoi comunque usare `SmartMarkerProcessor`. Per esempio:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

Il processore creerà intervalli denominati (`title`, `month`, `values`) che potrai riferire nel tuo modello Excel usando Smart Markers come `&=title` e `&=values`.

### 6.2 Convertire un array JSON annidato in una lista verticale

A volte è necessario che l'array riempia una colonna invece di una riga. Imposta manualmente la cella di partenza prima dell'elaborazione:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

Ora i valori **A**, **B**, **C** appaiono rispettivamente nelle celle A2, A3, A4.

## Problemi comuni e come evitarli

| Problema | Causa | Soluzione |
|----------|-------|-----------|
| **Array scritto come stringa singola** | `setArrayAsSingle(false)` (predefinito) | Chiama `processor.setArrayAsSingle(true)` |
| **File non trovato durante il salvataggio** | Percorso non valido o permessi di scrittura mancanti | Usa un percorso assoluto o assicurati che la directory esista |
| **Errore di parsing JSON** | Stringa JSON malformata | Valida il JSON con uno strumento o usa una libreria come Jackson per generare la stringa |
| **Celle sovrascritte involontariamente** | Elaborazione dello stesso foglio più volte senza reimpostare la cella di partenza | Chiama `processor.setStartCell("A1")` prima di ogni chiamata a `process` |

## Suggerimento professionale: riutilizzare la cartella di lavoro come modello

Invece di partire da una cartella di lavoro vuota ogni volta, puoi caricare un modello pre‑progettato che contiene già intestazioni, formule o formattazioni:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

Questo approccio combina la rifinitura visiva di un file Excel realizzato a mano con l'automazione di **populate workbook from json**.
