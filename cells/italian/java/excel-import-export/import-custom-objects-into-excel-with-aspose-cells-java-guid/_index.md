# Importare oggetti personalizzati in Excel con Aspose.Cells – Guida Java

Se hai bisogno di **importare oggetti personalizzati** in un foglio di lavoro Excel, questa guida ti accompagna attraverso l'intero processo usando Aspose.Cells per Java. Vedrai come **importare dati in Excel**, applicare uno stile di intestazione in grassetto e generare un file `.xlsx` pronto da condividere.

Esportare dati tabulari da Java spesso richiede scritture manuali cella‑per‑cella, il che è soggetto a errori e difficile da mantenere. Sfruttando l'API `importCustomObjects` eviti il codice boilerplate, mantieni intatto il tuo modello di dati e ottieni un controllo di stile granulare.

In questo tutorial farai:

* Costruire una lista di oggetti Java `Map` che imita una tipica tabella di dati.
* Creare uno stile di intestazione riutilizzabile (font in grassetto) con Aspose.Cells.
* Importare gli oggetti personalizzati in un foglio di lavoro applicando l'array di stili.
* Salvare la cartella di lavoro su disco e verificare il risultato.

L'unico prerequisito è un ambiente di sviluppo Java (consigliato JDK 8+) e la libreria Aspose.Cells per Java.

---

## Di cosa avrai bisogno

| Requisito | Motivo |
|-------------|--------|
| JDK 8 or newer | Necessario per compilare ed eseguire il codice Java. |
| Aspose.Cells for Java (latest version) | Fornisce le API `Workbook`, `Worksheet` e di importazione. |

Add the Aspose.Cells dependency to your `pom.xml` if you use Maven:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## Passo 1: Preparare gli oggetti personalizzati da importare

Il primo passo è creare una collezione che rappresenti le righe che desideri inserire in Excel. In questo esempio utilizziamo una `List<Map<String,Object>>` dove ogni mappa funge da riga con i nomi delle colonne come chiavi.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Perché è importante:**  
`importCustomObjects` si aspetta un array di oggetti. Usando una `Map`, conservi i nomi delle colonne, consentendo ad Aspose.Cells di mapparle automaticamente alle celle. Questo approccio rispecchia una tipica `DataTable` in .NET o un `ResultSet` da JDBC, rendendo il codice riutilizzabile in diversi progetti.

---

## Passo 2: Definire uno stile di intestazione da applicare durante l'importazione

Una riga di intestazione chiara migliora la leggibilità. Aspose.Cells consente di creare un oggetto `Style`, impostare il suo font in grassetto e passarlo tramite un array `ImportTableOptions`.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Perché è importante:**  
Se ometti l'array di stili, l'intestazione appare con il font predefinito, che potrebbe non risaltare. Preparando lo stile una sola volta, eviti chiamate ripetitive per ogni riga e mantieni pulita la logica di importazione.

---

## Passo 3: Importare gli oggetti personalizzati con l'array di stili

Ora combini i dati e lo stile, quindi chiami `importCustomObjects`. Il metodo inserisce i dati a partire dall'angolo in alto a sinistra (riga 0, colonna 0) e applica automaticamente lo stile dell'intestazione.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Perché è importante:**  
`importCustomObjects` analizza ogni mappa, crea colonne basate sulle chiavi (`Name`, `Score`) e scrive i valori nelle celle appropriate. L'oggetto `ImportTableOptions` indica ad Aspose.Cells di usare `styleArray` per la prima riga, fornendoti un'intestazione in grassetto senza codice aggiuntivo.

---

## Passo 4: Salvare la cartella di lavoro e verificare l'output

Infine, scrivi la cartella di lavoro su un file. Il file Excel generato contiene una riga di intestazione formattata seguita dalle righe di dati.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Risultato atteso:**  

| **Name** | **Score** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

Le celle di intestazione (`Name`, `Score`) appaiono in grassetto, corrispondendo allo stile definito nel Passo 2.

## Varianti comuni e casi limite

| Situazione | Regolazione consigliata |
|-----------|------------------------|
| **Ordine delle colonne diverso** | Assicurati che le chiavi della `Map` siano inserite nell'ordine desiderato, oppure utilizza un POJO personalizzato con campi annotati e un array `PropertyDescriptor`. |
| **Grandi set di dati (>10 000 righe)** | Aumenta `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` per evitare `OutOfMemoryError`. |
| **Formati numerici personalizzati** | Aggiungi un secondo `Style` in `styleArray` per le righe di dati, ad esempio imposta `NumberFormat` a `"0"` per punteggi interi. |
| **Foglio di lavoro multipli** | Chiama `importCustomObjects` su ciascun foglio di destinazione, regolando riga/colonna di partenza secondo necessità. |
| **Testo dell'intestazione specifico per locale** | Popola manualmente la riga di intestazione prima dell'importazione, poi applica lo stile all'intero intervallo usando `Cells.applyStyle`. |

---

## Consigli professionali per un'esportazione Java robusta verso Excel

* **Riutilizza la cartella di lavoro temporanea** – Creare un nuovo `Workbook` per ogni stile aggiunge overhead. Mantieni un'unica istanza se ti servono più stili.  
* **Convalida i dati prima dell'importazione** – I valori null in una mappa diventano celle vuote; puoi sostituirli con valori predefiniti preelaborando la lista.  
* **Chiudi le risorse** – Sebbene Aspose.Cells gestisca la memoria internamente, chiamare esplicitamente `workbook.dispose()` dopo il salvataggio rilascia prontamente le risorse native.  
* **Imposta `Workbook.setForceFullCalculation(true)`** se la tua cartella di lavoro contiene formule che devono essere valutate prima del salvataggio.
