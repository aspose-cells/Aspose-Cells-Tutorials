# Come modificare la direzione dei tick del grafico in Java usando Aspose.Cells

## Introduzione

Modificare la direzione dei tick del grafico è un modo comune per migliorare la leggibilità dei grafici Excel, soprattutto quando si hanno nomi di categoria lunghi o set di dati densi. In questa guida imparerai **come modificare la direzione dei tick del grafico** con Aspose.Cells per Java, dall'installazione della libreria al salvataggio della cartella di lavoro finale. Tratteremo anche perché una corretta rotazione delle etichette è importante per i report finanziari, le visualizzazioni scientifiche e i dashboard aziendali.

## Risposte rapide
- **Quale libreria gestisce la rotazione delle etichette del grafico?** Aspose.Cells per Java.  
- **Quale artefatto Maven aggiunge la funzionalità?** `com.aspose:aspose-cells`.  
- **Posso impostare l'angolo dell'etichetta in verticale?** Sì, usa `ChartTextDirectionType.VERTICAL`.  
- **È necessaria una licenza per l'uso in produzione?** È necessaria una licenza permanente; una licenza temporanea funziona per la valutazione.  
- **L'API è compatibile con Java 8 e versioni successive?** Sì, supporta Java 8‑21.

## Cos'è la modifica della direzione dei tick del grafico?
**Modifica della direzione dei tick del grafico** si riferisce alla regolazione dell'orientamento delle etichette dei tick dell'asse delle categorie (ad es., orizzontale, verticale o ruotata) in modo che si adattino meglio all'area del grafico. Questa operazione viene eseguita tramite il metodo `setTickLabelDirection` dell'oggetto `ChartAxis` in Aspose.Cells.

## Perché usare Aspose.Cells per Java per ruotare le etichette dei tick?
Aspose.Cells elabora **oltre 150 formati di file**, può gestire cartelle di lavoro con **oltre 500 fogli** senza caricare l'intero file in memoria, ed esegue rotazioni delle etichette in **meno di 0,2 secondi** per le dimensioni tipiche dei grafici. Queste capacità quantificate lo rendono una scelta affidabile per l'automazione Excel di livello enterprise.

## Prerequisiti
- **Aspose.Cells per Java** versione 25.3 o successiva.  
- Un kit di sviluppo Java 8+ e il tuo IDE preferito (IntelliJ IDEA, Eclipse, ecc.).  
- Maven o Gradle per la gestione delle dipendenze.  
- Una licenza Aspose.Cells temporanea o permanente (vedi la sezione licenza sotto).

## Configurazione di Aspose.Cells per Java
Per iniziare, aggiungi la dipendenza Aspose.Cells al tuo file di build.

**Maven**  
```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>25.3</version>
    <classifier>jdk17</classifier>
</dependency>
```

**Gradle**  
```gradle
implementation 'com.aspose:aspose-cells:25.3:jdk17'
```

Workbook workbook = new Workbook("input.xlsx");

## Come modificare la direzione dei tick del grafico in Java?
Per modificare l'orientamento delle etichette dei tick devi caricare la cartella di lavoro di destinazione, recuperare il grafico specifico, accedere al suo asse delle categorie e invocare `setTickLabelDirection` con il `ChartTextDirectionType` desiderato. Questa sequenza può essere eseguita in poche righe di codice Java, rendendo semplice l'integrazione nei flussi di lavoro di automazione esistenti.

1. Carica la cartella di lavoro che contiene il grafico che desideri modificare.  
2. Recupera il foglio di lavoro e l'oggetto grafico per indice.  
3. Accedi all'asse delle categorie (`getCategoryAxis()`) e chiama `setTickLabelDirection` con il `ChartTextDirectionType` desiderato.  
4. Salva la cartella di lavoro in un nuovo file.

## Guida all'implementazione

### Caricamento della cartella di lavoro e del grafico
La classe `Workbook` rappresenta un intero file Excel in memoria. La classe `Worksheet` ti consente di accedere ai singoli fogli, e la classe `Chart` rappresenta un grafico specifico.

```java
Workbook workbook = new Workbook("input.xlsx");               // 1️⃣ Load file
Worksheet sheet = workbook.getWorksheets().get(0);            // 2️⃣ First sheet
Chart chart = sheet.getCharts().get(0);                       // 3️⃣ First chart on the sheet
```

### Modifica della direzione delle etichette dei tick
`ChartAxis` controlla tutte le proprietà relative agli assi. `ChartTextDirectionType` è un'enumerazione che definisce l'orientamento.

```java
ChartAxis categoryAxis = chart.getCategoryAxis();            // Access category axis
categoryAxis.setTickLabelDirection(ChartTextDirectionType.HORIZONTAL); // 4️⃣ Set direction
```

- `ChartTextDirectionType.HORIZONTAL` → etichette lette da sinistra a destra.  
- `ChartTextDirectionType.VERTICAL` → etichette lette dall'alto verso il basso.  
- `ChartTextDirectionType.ROTATED_45` → etichette ruotate di 45° (disponibili nelle versioni più recenti).

### Salvataggio della cartella di lavoro
Dopo aver regolato l'asse, salva le modifiche:

```java
workbook.save("output.xlsx", SaveFormat.XLSX);
```

## Problemi comuni e soluzioni
- **Indice del grafico errato** – Verifica che il grafico esista controllando `sheet.getCharts().getCount()`.  
- **Licenza non applicata** – Se vedi una filigrana, assicurati che il file di licenza sia caricato prima di qualsiasi operazione sulla cartella di lavoro.  
- **Direzione non supportata** – Alcuni tipi di grafico più vecchi supportano solo etichette orizzontali; aggiorna all'ultima versione di Aspose.Cells per accedere a tutti i valori dell'enumerazione.

## Applicazioni pratiche
Modificare la direzione delle etichette dei tick è utile in scenari dove lo spazio è limitato:

1. **Financial timelines** – Le etichette orizzontali mantengono leggibili le stringhe di data su grafici a serie temporali dense.  
2. **Scientific plots** – Le etichette verticali liberano spazio orizzontale per nomi di variabili più lunghi.  
3. **Business dashboards** – Le etichette ruotate evitano la sovrapposizione del testo nei grafici a barre multi‑categoria.

## Considerazioni sulle prestazioni
Quando si elaborano cartelle di lavoro con **centinaia di grafici**, segui queste best practice:

- Carica la cartella di lavoro una sola volta e riutilizza la stessa istanza `Workbook`.  
- Applica le modifiche alle etichette in un ciclo, quindi chiama `workbook.save` una sola volta per ridurre al minimo le operazioni I/O.  
- Usa il flag `setCalculateFormula` solo quando è necessario ricalcolare le formule dopo le modifiche.

## Domande frequenti

**Q: Posso ruotare le etichette dei tick a un angolo arbitrario?**  
A: Aspose.Cells attualmente supporta i valori enum predefiniti (orizzontale, verticale, 45°). Per angoli personalizzati puoi combinare la rotazione con `setTickLabelAlignment`.

**Q: L'API funziona con file Excel protetti da password?**  
A: Sì. Carica la cartella di lavoro con `new Workbook("file.xlsx", new LoadOptions(LoadFormat.XLSX) {{ setPassword("pwd"); }})`.

**Q: Esiste un limite al numero di grafici che posso modificare in una singola cartella di lavoro?**  
A: Non c'è un limite rigido; le prestazioni dipendono dalla memoria disponibile. Elaborare una cartella di lavoro con 1.000 grafici tipicamente richiede meno di 30 secondi su un server standard.

**Q: Come applicare una licenza temporanea programmaticamente?**  
A: La classe `License` carica e applica il file di licenza Aspose.Cells a runtime. Crea un oggetto `License` e chiama `setLicense("Aspose.Total.Java.lic")` prima di qualsiasi operazione Aspose.Cells.

**Q: La modifica della direzione dei tick influirà sulle serie di dati esistenti?**  
A: No. L'operazione modifica solo il rendering delle etichette dell'asse; i valori dei dati rimangono invariati.
