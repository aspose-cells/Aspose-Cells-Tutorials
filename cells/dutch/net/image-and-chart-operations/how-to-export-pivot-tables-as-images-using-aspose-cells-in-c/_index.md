# Hoe pivot‑tabellen exporteren als afbeeldingen met Aspose.Cells in C#

Als je **pivot exporteren** gegevens wilt exporteren naar een draagbare afbeelding, maakt Aspose.Cells het proces eenvoudig. Deze tutorial laat je precies zien hoe je pivot‑tabellen exporteert als PNG‑bestanden, zodat je ze kunt insluiten in rapporten, e‑mails of documentatie zonder dat Excel op de doelmachine nodig is.

Het exporteren van een pivot als afbeelding elimineert versie‑specifieke opmaakproblemen en stelt niet‑technische belanghebbenden in staat de analyse direct te bekijken. We behandelen alles van projectconfiguratie tot het renderen van de uiteindelijke **export pivot table image**, en we leggen ook uit hoe je **save pivot as image** kunt gebruiken voor toekomstig hergebruik.

## Hoe pivot‑tabellen exporteren als afbeeldingen met Aspose.Cells

Hieronder staat het volledige, uitvoerbare voorbeeld dat een werkmap laadt, de pivot ververst, afbeeldingsopties configureert en het uitvoerbestand schrijft. Elke stap bevat een korte toelichting zodat je begrijpt *waarom* de code op die manier is geschreven, en niet alleen *wat* hij doet.

### 1. De Aspose.Cells‑omgeving instellen

1. Installeer het NuGet‑pakket:

   ```bash
   dotnet add package Aspose.Cells
   ```

2. Voeg de vereiste `using`‑directieven toe aan de bovenkant van je C#‑bestand:

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **Pro tip:** Richt je op .NET 6 of later om te profiteren van de nieuwste prestatie‑verbeteringen in Aspose.Cells.

### 2. Laad de werkmap en vind de pivot‑tabel

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*Waarom dit belangrijk is:* De `Workbook`‑klasse parseert het XLSX‑bestand en geeft je toegang tot alle werkbladen. Het selecteren van het juiste werkblad is essentieel omdat een werkmap meerdere pivots kan bevatten.

### 3. Vernieuw de pivot‑tabel om de nieuwste brongegevens vast te leggen

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

Vernieuwen garandeert dat alle wijzigingen die na het opslaan van het bestand in het bronbereik zijn aangebracht, worden weergegeven in de gerenderde afbeelding. Het overslaan van deze stap kan verouderde of onnauwkeurige visuals opleveren.

### 4. Configureer afbeeldings‑exportopties (export pivot table image)

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

Het `ImageOrPrintOptions`‑object stelt je in staat het formaat, de resolutie en andere renderingsdetails te regelen. PNG is de meest voorkomende keuze voor scherpe, web‑compatibele graphics, maar je kunt overschakelen naar `ImageFormat.Jpeg` als de bestandsgrootte een zorg is.

### 5. Renderen en **save pivot as image**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

`RenderToImage` doet het zware werk: het tekent de pivot precies zoals deze in Excel verschijnt en schrijft de binaire PNG‑gegevens naar schijf. De methode retourneert `void`, dus je kunt er veilig van uitgaan dat het bestand bestaat nadat de oproep is voltooid, zonder extra controles.

#### Verwacht resultaat

Na het uitvoeren van het programma vind je `Pivot.png` in de opgegeven map. Het openen van het bestand moet een getrouwe weergave van de oorspronkelijke pivot‑tabel tonen, inclusief kolomkoppen, rijtotaal en eventuele toegepaste opmaak.

### 6. Veelvoorkomende variaties en randgevallen

| Scenario | Aanpassing |
|----------|------------|
| **Grote pivots** (veel rijen/kolommen) | Verhoog `HorizontalResolution` en `VerticalResolution` naar 300 dpi voor een duidelijkere output. |
| **Aangepaste styling** (achtergrondkleuren, lettertypen) | Zorg ervoor dat de stijldefinities van de werkmap zijn geladen voordat `Refresh()` wordt aangeroepen. |
| **Meerdere pivots** in één blad | Loop door `worksheet.PivotTables` en roep `RenderToImage` aan voor elk, met verschillende bestandsnamen. |
| **Exporteren naar JPEG** in plaats van PNG | Verander `ImageFormat = ImageFormat.Jpeg` en stel eventueel `Quality` in op een `JpegSaveOptions`‑object. |

Deze variaties stellen je in staat om **export pivot table image** in het exacte formaat te exporteren dat je downstream‑systeem verwacht.

## Volledige broncode voor snelle copy‑paste

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

Het uitvoeren van het programma genereert het PNG‑bestand dat hierboven wordt getoond, waardoor de **save pivot as image**‑workflow in minder dan een minuut voltooid is.

## Conclusie

Je weet nu **how to export pivot** tabellen naar afbeeldingsbestanden met Aspose.Cells in C#. De gids heeft je stap voor stap door het instellen van de bibliotheek, het laden van de werkmap, het vernieuwen van de pivot, het configureren van PNG‑opties en uiteindelijk het renderen van de **export pivot table image** geleid, en laat ook zien hoe je **save pivot as image** kunt gebruiken voor later hergebruik.

* **Integreren met ASP.NET Core** – genereer de PNG on‑the‑fly en retourneer deze als een HTTP‑respons voor web‑dashboards.
