# Excel‑bestand maken c# – cellen opmaken en valuta‑formaat instellen

Als je een **excel bestand c#** wilt maken dat er professioneel uitziet, laat deze gids je precies zien hoe je excel‑cellen kunt opmaken en een kolom als valuta kunt formatteren. Je ziet een compleet, end‑to‑end voorbeeld dat een `DataTable` importeert, een vetgedrukte header toepast, en een `$#,##0.00` getalformaat instelt voor de prijs‑kolom.

De tutorial behandelt alles wat je nodig hebt: vereiste NuGet‑pakketten, de volledige broncode, uitleg waarom elk onderdeel belangrijk is, en tips voor het omgaan met randgevallen zoals lege rijen of verschillende locales. Aan het einde kun je een `.xlsx`‑bestand genereren met een mooi opgemaakte prijskolom in slechts een paar regels C#.

## Prerequisites

- .NET 6.0 of later (de code werkt ook met .NET Framework 4.6+)
- Visual Studio 2022 of een andere C#‑editor naar keuze
- De **Aspose.Cells for .NET** of **GemBox.Spreadsheet** library (beide ondersteunen `ImportTableOptions`). Het voorbeeld hieronder gebruikt **Aspose.Cells** omdat het een eenvoudige `StyleArray`‑eigenschap biedt.
- Basiskennis van C#‑collecties en `DataTable`

> **Pro tip:** Als je een gratis alternatief wilt, vervang `Aspose.Cells` door `GemBox.Spreadsheet`. De API voor het importeren van een `DataTable` met stijlen is bijna identiek; wijzig alleen de namespace en de NuGet‑pakketnaam.

## Step 1: Install the Excel library

Open de NuGet Package Manager en installeer de library:

```bash
dotnet add package Aspose.Cells
```

> **Why this step?** De library levert de `Workbook`, `Worksheet`, `Style` en `ImportTableOptions` classes die later worden gebruikt. Zonder deze zou je het Office Open XML‑formaat handmatig moeten schrijven, wat foutgevoelig is.

## Step 2: Create a DataTable with sample data

Een `DataTable` is een handige manier om tabel‑data vast te houden voordat je deze naar Excel exporteert. In dit voorbeeld hebben we twee kolommen: *Product* en *Price*.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Explanation:**  
> - `Columns.Add("Price", typeof(double))` vertelt de tabel de prijswaarden als getallen te behandelen, wat later nodig is voor getalopmaak.  
> - Een paar rijen toevoegen geeft ons data om de **format column currency** stap te verifiëren.

## Step 3: Define the styles you want to apply

We maken een array van `Style`‑objecten die overeenkomt met de kolomvolgorde. Het eerste item stijlt de header‑rij, het tweede laat de *Product*‑kolom ongewijzigd, en het derde past een valuta‑getalformaat toe.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### Why use a **style array**?

`ImportTableOptions.StyleArray` koppelt elke kolom aan een `Style`. Dit is de meest efficiënte manier om **add number format** en **style excel cells** in één import‑operatie toe te passen, zonder een tweede doorloop over het werkblad.

## Step 4: Configure import options

Nu binden we de style‑array aan de import‑operatie. Het `ImportTableOptions`‑object laat je ook bepalen of de eerste rij als header wordt behandeld.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Note:** `IsFieldNameShown` staat standaard op `true`, maar expliciet instellen maakt de intentie duidelijk voor toekomstige lezers.

## Step 5: Create a workbook, import the table, and save

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### Expected result

Wanneer je `DataTableWithStyles.xlsx` opent:

- De eerste rij (header) is **vet**.
- De *Price*‑kolom toont waarden als **$1.20**, **$3.50**, **$0.75**.
- De *Product*‑kolom behoudt het standaardlettertype.

Je hebt succesvol een **excel bestand c#** gemaakt met een geformatteerde valuta‑kolom en gestylede header‑cellen.

## Step 6: Handling common variations and edge cases

### a. Different locale or custom currency symbol

Als je Euro of een andere valuta nodig hebt, vervang je het ingebouwde formaat `164` door een aangepaste format‑string:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. Adding more columns later

Wanneer je extra kolommen toevoegt, breid je de `columnStyles`‑array overeenkomstig uit. Gebruik `null` voor kolommen die de standaardstijl moeten behouden.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. Empty DataTable

Als de `DataTable` geen rijen bevat, maakt Aspose.Cells nog steeds de header‑rij aan. Het werkboek bevat dan echter slechts één rij. Controleer de rij‑telling vóór het importeren om een leeg bestand te voorkomen:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Using `GemBox.Spreadsheet` instead of Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

De logica blijft identiek, wat aantoont dat de tutorial **format column currency** onafhankelijk is van de onderliggende library.

## Step 7: Verify the file programmatically (optional)

Je kunt het gegenereerde werkboek openen en controleren of het getalformaat correct is toegepast—handig voor unit‑tests.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```
