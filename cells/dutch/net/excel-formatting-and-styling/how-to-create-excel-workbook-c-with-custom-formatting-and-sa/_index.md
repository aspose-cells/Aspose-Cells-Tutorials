# Hoe een Excel‑werkmap C# te maken met aangepaste opmaak en opslaan als XLSX

Als je een **create Excel workbook C#** nodig hebt die gegevens importeert, een aangepast getalformaat toepast en de letterkleur van de cel wijzigt, laat deze tutorial je precies zien hoe. Je krijgt een kant‑en‑klare voorbeeld die een gestylede `StyleArrayImport.xlsx`‑bestand in enkele seconden produceert.

Werken met Excel vanuit C# omvat vaak repetitieve handmatige stappen — het definiëren van opmaak, het toepassen van kleuren en het onthouden om het bestand correct op te slaan. Aan het einde van deze gids automatiseer je al deze taken, zodat je je kunt concentreren op de data in plaats van op de UI.

Je leert hoe je:

* een `DataTable` importeert in een werkblad,
* een `StyleArray` gebruikt om **aangepast getalformaat toe te passen** en **de letterkleur van de cel te wijzigen**,
* **de werkmap opslaat als XLSX** met één methode‑aanroep,
* en verifieert dat de **format imported data excel** er precies uitziet zoals bedoeld.

De enige voorwaarde is een referentie naar de **Aspose.Cells for .NET**‑bibliotheek (of een compatibele API die `Workbook`, `Worksheet` en `StyleArray` levert). De code richt zich op .NET 6+, maar eerdere versies werken met kleine aanpassingen.

---

## Vereisten

| Vereiste | Reden |
|----------|-------|
| .NET 6 SDK of later | Biedt de runtime voor de C#‑console‑applicatie. |

Installeer het Aspose.Cells‑pakket met de volgende opdracht:

```bash
dotnet add package Aspose.Cells
```

## Stap 1: Bereid de voorbeeld‑DataTable voor

Maak eerst een `DataTable` die de data nabootst die je normaal gesproken uit een database of een andere bron zou ophalen. De tabel bevat een **Name**‑kolom (string) en een **Amount**‑kolom (decimal) die we later zullen opmaken.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Waarom dit belangrijk is:** Het gebruik van een `DataTable` laat je de importlogica onafhankelijk houden van de gegevensbron, wat een veelvoorkomend patroon is bij het genereren van rapporten vanuit databases, CSV‑bestanden of API’s.

## Stap 2: Definieer een StyleArray om **aangepast getalformaat toe te passen** en **de letterkleur van de cel te wijzigen**

`StyleArray` stelt je in staat om opmaak‑instructies te bundelen die op elke cel worden toegepast die vanuit de `DataTable` wordt geïmporteerd. In dit voorbeeld:

* stellen we `Number` in op `#,##0.00` — een typisch boekhoudkundig formaat met duizendtallen,
* stellen we `FontColor` in op `Color.Blue` — zodat de getallen opvallen.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**Waarom een StyleArray gebruiken?** Een stijl toepassen tijdens het importeren voorkomt een tweede doorloop van het werkblad, wat de prestaties verbetert bij grote datasets.

---

## Stap 3: **Create Excel workbook C#** – instantieer Workbook en haal het eerste Worksheet

Nu maken we een lege werkmap en verkrijgen we een referentie naar het eerste werkblad (index 0). Dit werkblad wordt de bestemming voor onze geïmporteerde data.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Uitleg:** `Workbook` vertegenwoordigt het volledige Excel‑bestand, terwijl `Worksheet` één tabblad representeert. De standaardwerkmap bevat één blad, wat voldoende is voor de meeste eenvoudige rapporten.

---

## Stap 4: Importeer de DataTable met behulp van de **StyleArray** om **format imported data excel**

De `ImportDataTable`‑methode kopieert de rijen en kolommen van de tabel naar het werkblad, beginnend bij cel `A1` (rij 0, kolom 0). Het argument `true` geeft aan dat kolomkoppen moeten worden meegenomen. Omdat we `styleArray` doorgeven, krijgt elke geïmporteerde cel het aangepaste getalformaat en de blauwe letterkleur.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**Wat er onder de motorkap gebeurt:** Aspose.Cells doorloopt elke rij, schrijft de waarde en past vervolgens de stijl toe die in `styleArray` is gedefinieerd. Getallen verschijnen met komma’s en twee decimalen, en de tekst wordt in blauw weergegeven.

## Stap 5: **Save workbook as XLSX** – schrijf het bestand naar schijf

Tot slot slaan we de werkmap op in een `.xlsx`‑bestand. Je kunt het pad aanpassen naar elke schrijfbare map op je machine.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Resultaatverificatie:** Open het gegenereerde bestand in Excel. Je zou de drie rijen data moeten zien, waarbij de **Amount**‑kolom is opgemaakt met komma’s, twee decimalen en blauwe letters. Dit bevestigt dat de stap **format imported data excel** geslaagd is.

## Volledig werkend voorbeeld

Kopieer het volledige blok hieronder naar een nieuw console‑project en voer het uit. Er is geen extra code nodig.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Verwachte uitvoer in de console:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

Open het bestand en controleer of de **Amount**‑kolom waarden toont zoals `1,234.56` in blauwe letters.

## Veelgestelde vragen & randgevallen

| Vraag | Antwoord |
|-------|----------|
| *Kan ik verschillende opmaken toepassen op individuele kolommen?* | Ja. Na het importeren kun je het `Style`‑object van de kolom ophalen (`worksheet.Cells.Columns[1].Style`) en een andere `Number`‑ of `FontColor`‑waarde instellen. |
| *Wat als ik datums moet opmaken in plaats van getallen?* | Stel `styleArray.Number = "mm-dd-yyyy"` in en eventueel `styleArray.FontColor` voor datumcellen. |
| *Is de blauwe letterkleur goed leesbaar op donkere Excel‑thema’s?* | Blauw kan moeilijk leesbaar zijn op donkere achtergronden. Gebruik een lichtere tint (`Color.LightBlue`) of een contrasterende kleur (`Color.Black`). |
| *Hoe importeer ik een zeer grote DataTable (honderdduizenden rijen)?* | Gebruik `ImportDataTable` met de overload `ImportDataTableOptions` om data te streamen, of splits de import over meerdere werkbladen om binnen de rij‑limiet van Excel (1.048.576 rijen) te blijven. |
| *Kan ik exporteren naar CSV in plaats van XLSX?* | Vervang `SaveFormat.Xlsx` door `SaveFormat.Csv`. Let op: opmaak‑informatie (getalformaat, letterkleur) gaat verloren in CSV omdat het een platte‑tekstformaat is. |

## Tips voor productiegebruik

* **Pro tip:** Cache het `Style`‑object als je dezelfde opmaak op veel werkbladen moet toepassen; een nieuwe `StyleArray` voor elke import brengt extra overhead met zich mee.  
* **Let op cultuurverschillen:** Het `Number`‑patroon `#,##0.00` volgt de invariant‑culture. Als je locale‑specifieke scheidingstekens nodig hebt, gebruik dan `NumberFormatInfo` of laat Excel het op basis van de regionale instellingen van de gebruiker regelen.  
* **Foutafhandeling:** Plaats de `Save`‑aanroep in een try‑catch‑blok om I/O‑exceptions af te handelen (bijvoorbeeld onvoldoende rechten of vergrendelde bestanden).
