# Hoe lettertypen in HTML inbedden bij het opslaan van een werkmap

Als je **how to embed fonts in HTML** moet tijdens het exporteren van een spreadsheet, laat deze tutorial je een complete, kant‑klaar oplossing zien. Of je nu een rapportage‑portaal of een client‑side analytics‑weergave bouwt, het inbedden van lettertypen garandeert dat de gerenderde HTML er precies uitziet als de oorspronkelijke werkmap, ongeacht de geïnstalleerde lettertypen van de kijker.

Je leert ook de beste manier om **save workbook as HTML** te gebruiken met Aspose.Cells, ziet veelvoorkomende valkuilen, en krijgt tips voor het omgaan met grote werkmappen of aangepaste lettertypebestanden. Er is geen externe documentatie nodig—alles wat je nodig hebt staat in deze gids.

## Vereisten

- .NET 6.0 of later (de code werkt ook met .NET Framework 4.7+)
- Een geldige Aspose.Cells for .NET licentie (of je kunt de gratis evaluatiemodus gebruiken)
- Basis C#-kennis en een IDE zoals Visual Studio 2022
- De TrueType (.ttf) of OpenType (.otf) lettertypebestanden die je wilt inbedden (ze moeten toegankelijk zijn voor het draaiende proces)

## Stap 1: Het project opzetten en Aspose.Cells importeren

Maak een nieuwe console‑applicatie en voeg het Aspose.Cells NuGet‑pakket toe:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

Open vervolgens **Program.cs** en voeg de vereiste `using`‑directieven toe:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **Pro tip:** Plaats je aangepaste lettertypen in een map genaamd `fonts` in de project‑root. Dit houdt de oplossing draagbaar en maakt het later eenvoudig om ernaar te verwijzen.

## Stap 2: Een werkmap maken of laden

Voor demonstratie maken we een eenvoudige werkmap met een paar gestylede cellen:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **Waarom dit belangrijk is:** Als je de aangepaste stijl overslaat, valt de geëxporteerde HTML terug op de standaardlettertypen van de browser, waardoor het doel van **how to embed fonts in HTML** teniet wordt gedaan.

## Stap 3: `HtmlSaveOptions` configureren om lettertypen in te bedden

De kern van **how to embed fonts in HTML** zit in de `HtmlSaveOptions`‑klasse. Door `EmbedFonts = true` in te stellen, vertelt u Aspose.Cells om alle gerefereerde TrueType/OpenType‑lettertypen direct in de gegenereerde HTML in te bedden als Base64‑gecodeerde data‑URI's.

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### Hoe het inbedden werkt

Wanneer `EmbedFonts` `true` is, scant Aspose.Cells de stijldefinities van de werkmap, zoekt de bijbehorende lettertypebestanden op het systeem (of in de `fonts`‑map die je hebt toegevoegd), leest hun binaire data en injecteert een `<style>`‑blok vergelijkbaar met:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

Omdat de lettertype‑data direct in de HTML is gecodeerd, wordt de pagina correct weergegeven zelfs op machines die het lettertype niet geïnstalleerd hebben.

## Stap 4: De werkmap opslaan als HTML

Nu kun je **save workbook as HTML** uitvoeren met de geconfigureerde opties. Kies een map waar de applicatie naar kan schrijven (bijv. `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

Het uitvoeren van het programma genereert een enkel `report.html`‑bestand. Open het in een moderne browser en je ziet de “Quarterly Sales”‑kop weergegeven met het **Pacifico**‑lettertype, zelfs als het lettertype niet op je besturingssysteem geïnstalleerd is.

### Verwachte output

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

Het `src:`‑attribuut bevat een lange Base64‑string—dit is de ingesloten lettertype‑data die **how to embed fonts in HTML** mogelijk maakt.

## Stap 5: Controleer het inbedden van lettertypen en los problemen op

1. **Open het HTML‑bestand in Chrome of Edge.** Als het aangepaste lettertype verschijnt, is het inbedden geslaagd.  
2. **Inspecteer de paginabron.** Zoek naar de `@font-face`‑regel die door Aspose.Cells is gegenereerd.  
3. **Veelvoorkomende problemen:**  
   - *Ontbrekend lettertypebestand:* Zorg ervoor dat het lettertypebestand bereikbaar is. Je kunt expliciet een map toevoegen aan het zoekpad:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *Grote HTML‑grootte:* Het inbedden van veel lettertypen kan het bestand opsblazen. Gebruik `ExportToSingleFile = false` om lettertypen als afzonderlijke `.ttf`‑bestanden in een resources‑map te bewaren.

   - *Niet‑ondersteund lettertypeformaat:* Aspose.Cells embed alleen TrueType (`.ttf`) en OpenType (`.otf`). Converteer andere formaten vóór het inbedden.

## Volledig werkend voorbeeld

Hieronder staat het volledige programma dat je kunt kopiëren, plakken en uitvoeren zonder aanpassingen (behalve de optionele licentielijn).

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

Het uitvoeren van dit programma maakt `output/report.html`. Open het bestand en je ziet het **Pacifico**‑lettertype correct weergegeven—wat **how to embed fonts in HTML** laat zien tijdens het **save workbook as HTML**.

## Veelgestelde vragen

| Vraag | Antwoord |
|----------|--------|
| *Kan ik alleen specifieke lettertypen inbedden?* | Ja. Stel `htmlOpt.EmbedAllFonts = false` in (beschikbaar in nieuwere versies) en gebruik `htmlOpt.FontsToEmbed` om de exacte lettertypenamen op te sommen. |
| *Wat als ik lettertypen moet inbedden voor meerdere werkbladen?* | Stel `ExportActiveWorksheetOnly = false` in zodat elk werkblad wordt geëxporteerd, en Aspose.Cells zal de lettertypen die in de hele werkmap worden gebruikt inbedden. |
| *Werken ingesloten lettertypen op mobiele browsers?* | Moderne mobiele browsers ondersteunen Base64‑gecodeerde lettertypen, dus de ingesloten lettertypen worden correct weergegeven zolang het lettertypeformaat wordt ondersteund (TTF of OTF). |
| *Hoe groot kan het HTML‑bestand worden?* | Het inbedden van een 200 KB TrueType‑lettertype voegt ongeveer dezelfde hoeveelheid toe aan de HTML‑grootte (Base64 voegt ~33 % overhead toe). Bij veel lettertypen kun je overwegen om naar een map te exporteren (`ExportToSingleFile = false`) om de HTML lichtgewicht te houden. |
