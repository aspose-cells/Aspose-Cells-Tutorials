# Hoe lettertypen inbedden bij het opslaan van Excel naar HTML met C#

Hoe lettertypen inbedden bij het opslaan van een Excel‑werkmap naar HTML is een veelvoorkomende eis om de exacte weergave van je spreadsheets in browsers te behouden. Als je Excel naar HTML wilt exporteren en de oorspronkelijke lettertypen wilt behouden, laat deze gids je een complete, kant‑klaar‑te‑run‑nen oplossing zien.

Je leert hoe je **Excel naar HTML exporteert**, **Excel naar HTML converteert** met ingebedde lettertypen, en het typische “ontbrekend‑lettertype” probleem vermijdt dat de lay‑out op clientmachines breekt. Er zijn geen externe tools nodig—alleen de Aspose.Cells‑bibliotheek en een paar regels C#.

## Vereisten

Voordat je begint, zorg dat je het volgende hebt:

* .NET 6.0 (of later) geïnstalleerd.
* Een gelicentieerde kopie van **Aspose.Cells for .NET** – de gratis proefversie werkt voor testen.
* Een IDE zoals Visual Studio 2022 of VS Code.

Als je dit al hebt, kun je direct naar de code gaan.

## Stap 1: Maak een werkmap en voeg voorbeeldgegevens toe

Eerst genereren we een kleine werkmap zodat je het effect van ingebedde lettertypen kunt zien. De code hieronder maakt een werkblad, schrijft een paar cellen en past een aangepast lettertype toe.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### Waarom we een aangepast lettertype toevoegen

Inbedden van lettertypen is alleen relevant wanneer de werkmap lettertypen gebruikt die mogelijk niet op het clientapparaat aanwezig zijn. Door expliciet **Arial** (of een ander lettertype) in te stellen, kunnen we verifiëren dat de HTML‑output echt de lettertype‑gegevens bevat.

## Stap 2: Configureer HTML‑opslaoptopties om lettertypen in te bedden

Aspose.Cells biedt de klasse `HtmlSaveOptions`. Het instellen van `EmbedFonts = true` vertelt de bibliotheek om de benodigde lettertype‑bestanden direct in de gegenereerde HTML op te nemen als Base64‑gecodeerde data‑URI’s.

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### Wat “lettertypen inbedden in html” echt doet

Wanneer `EmbedFonts` true is, haalt Aspose.Cells de lettertype‑bestanden uit het systeem (of uit de ingebedde lettertype‑collectie van de werkmap) en zet ze om in **Base64**‑strings. Die strings worden vervolgens geplaatst in een `<style>`‑blok met `@font-face`. De resulterende HTML kan op elk apparaat worden geopend zonder dat het oorspronkelijke lettertype geïnstalleerd hoeft te zijn.

## Stap 3: Sla de werkmap op als HTML met ingebedde lettertypen

Nu schrijven we de werkmap naar schijf. Het bestand zal de lettertype‑gegevens bevatten, dus het openen in een moderne browser toont exact dezelfde typografie als het originele Excel‑bestand.

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### Verwacht resultaat

* `embedded.html` bevindt zich in de map `output`.
* Het openen van het bestand in Chrome, Edge of Firefox toont het werkblad met **Arial**‑tekst, zelfs als de browsermachine geen Arial heeft.
* Het inspecteren van de HTML‑bron onthult een `<style>`‑blok met een `@font-face`‑regel en een lange `src: url(data:font/ttf;base64,…)`‑verklaring – dat is het ingebedde lettertype.

## Stap 4: Controleer of de HTML op een andere machine werkt (optioneel)

Om er absoluut zeker van te zijn dat het inbedden geslaagd is:

1. Kopieer `output/embedded.html` naar een andere computer (of een virtuele machine) die **niet** het aangepaste lettertype geïnstalleerd heeft.
2. Open het bestand in een browser.
3. De lay‑out en typografie moeten overeenkomen met de oorspronkelijke Excel‑weergave.

Als het lettertype terugvalt op een generiek lettertype, controleer dan of het lettertype‑bestand toegankelijk is op de build‑machine en of je toestemming hebt om het te lezen.

## Veelgestelde vragen en randgevallen

### Verhoogt inbedden de bestandsgrootte?

Ja. Het inbedden van een TrueType‑ of OpenType‑lettertype kan **tientallen kilobytes** aan het HTML‑bestand toevoegen. Voor grote werkmappen met veel unieke lettertypen kun je overwegen:

* Het lettertype te subsetten (alleen de tekens die je gebruikt) – Aspose.Cells doet dit automatisch voor de meeste gangbare lettertypen.
* `ExportEmbeddedImages = false` te gebruiken als je geen afbeeldingen hoeft in te bedden.

### Wat als ik alleen specifieke lettertypen wil inbedden?

`HtmlSaveOptions` biedt geen directe whitelist, maar je kunt bepalen welke lettertypen verschijnen door **het aantal gebruikte lettertypen in de werkmap te beperken** vóór het aanroepen van `Save`. Verwijder onnodige lettertype‑toewijzingen of vervang ze door standaard web‑veilige lettertypen.

### Kan ik lettertypen inbedden bij het converteren naar andere formaten (bijv. PDF)?

Dezelfde `EmbedFonts`‑eigenschap bestaat op `PdfSaveOptions`. Het concept is identiek: de lettertype‑gegevens worden ingebed zodat de PDF correct wordt gerenderd in elke viewer.

## Volledig, uitvoerbaar voorbeeld

Hieronder staat het complete programma dat je kunt kopiëren‑plakken in een nieuw console‑project.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

Het uitvoeren van het programma levert een **HTML‑bestand dat het ingebedde Arial‑lettertype bevat**, waardoor visuele getrouwheid gegarandeerd is, ongeacht waar het bestand wordt geopend.

## Conclusie

Je weet nu **hoe je lettertypen inbedt bij het opslaan van Excel naar HTML** met C#. Door `HtmlSaveOptions.EmbedFonts = true` te configureren, kun je betrouwbaar **Excel naar HTML exporteren** en **Excel naar HTML converteren** zonder je zorgen te maken over ontbrekende lettertypen aan de client‑kant. Deze techniek is essentieel voor web‑gebaseerde rapportage, e‑mail‑vriendelijke dashboards, of elke situatie waarin je Excel‑afgeleid inhoud als HTML deelt.

### Wat is de volgende stap?

* **Pas de CSS** aan die door Aspose.Cells wordt gegenereerd om overeen te komen met de stijlrichtlijnen van je site.  
* **Bed afbeeldingen in** selectief door `ExportEmbeddedImages` te schakelen.  
* **Verken andere exportformaten** zoals PDF of SVG terwijl je nog steeds lettertypen inbedt.  

Voel je vrij om te experimenteren met verschillende lettertypen, grotere werkbladen of werkmappen met meerdere bladen. Dezelfde `EmbedFonts`‑vlag werkt in alle ondersteunde uitvoerformaten, waardoor je consistente controle hebt over het inbedden van lettertypen waar je het ook nodig hebt. Veel programmeerplezier!
