# Hoe gegevens exporteren naar Excel met een C#‑template – stapsgewijze handleiding

Als je **gegevens naar Excel wilt exporteren** vanuit een .NET‑applicatie, laat deze handleiding een complete oplossing zien die end‑to‑end werkt. Door een Excel‑template te laden dat al Smart Marker‑tags bevat, kun je **Excel‑generatie automatiseren** en een gepolijste **employee report Excel** produceren zonder code cel‑voor‑cel te schrijven.

Je ziet hoe je:

* Een Excel‑template laden (`load excel template`) die de lay-out definieert.  
* Een lijst met employee‑objecten aan de template voeren.  
* De uiteindelijke workbook genereren en opslaan als `output.xlsx`.

Alle benodigde code is inbegrepen, zodat je deze direct kunt kopiëren, plakken en uitvoeren.

## Vereisten

* .NET 6.0 of later (de code werkt ook met .NET Framework 4.7+).  
* Het **Aspose.Cells for .NET** NuGet‑pakket – het levert `Workbook`, `SmartMarkerProcessor` en Smart Marker‑ondersteuning.  
* Een map genaamd `YOUR_DIRECTORY` die `template.xlsx` bevat. Het template moet Smart Marker‑tags hebben zoals `&=EmployeeList.Name` in de cellen waar je gegevens wilt laten verschijnen.

> **Pro tip:** Houd het template in dezelfde projectmap en stel de eigenschap *Copy to Output Directory* in op *Copy always* zodat het pad correct wordt opgelost tijdens het debuggen.

## Volledige broncode

```csharp
using System;
using System.Collections.Generic;
using Aspose.Cells;

namespace ExcelExportDemo
{
    // Simple POCO that represents an employee record
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Step 1: Load the Excel template that contains Smart Marker tags
            string templatePath = @"YOUR_DIRECTORY\template.xlsx";
            Workbook wb = new Workbook(templatePath);

            // Step 2: Prepare a data source – a list of employee objects
            List<Employee> employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Step 3: Create a SmartMarkerProcessor instance
            SmartMarkerProcessor sp = new SmartMarkerProcessor();

            // Step 4: Apply the employee data to the workbook using the processor
            // The tag &amp;=EmployeeList.Name in the template will be replaced with each employee's name,
            // and &amp;=EmployeeList.Position will be replaced with the corresponding position.
            sp.Process(wb, employeeList);

            // Step 5: Save the populated workbook
            string outputPath = @"YOUR_DIRECTORY\output.xlsx";
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

### Wat de code doet

| Stap | Waarom het belangrijk is | Belangrijke regel(s) |
|------|--------------------------|----------------------|
| **Excel‑template laden** | Het hergebruiken van een vooraf ontworpen lay-out bespaart tijd en garandeert consistente styling. | `Workbook wb = new Workbook(templatePath);` |
| **Gegevensbron voorbereiden** | Smart Markers werken met elke `IEnumerable`‑collectie; hier gebruiken we een lijst van `Employee`. | `List<Employee> employeeList = …` |
| **Processor maken** | `SmartMarkerProcessor` parseert het template, vindt tags en injecteert gegevens. | `SmartMarkerProcessor sp = new SmartMarkerProcessor();` |
| **Gegevens verwerken** | De processor vervangt elke Smart Marker‑tag door de overeenkomstige eigenschapswaarde. | `sp.Process(wb, employeeList);` |
| **Workbook opslaan** | Het uiteindelijke bestand kan naar de gebruiker worden gestuurd, op een server worden opgeslagen of aan een e‑mail worden toegevoegd. | `wb.Save(outputPath);` |

Het resultaat is een **employee report Excel**‑bestand waarbij elke rij de naam en functie van een medewerker bevat, precies op de plaatsen waar de tags in het oorspronkelijke template stonden.

## Excel‑template laden

Wanneer je `load excel template` gebruikt met `new Workbook(path)`, leest Aspose.Cells de volledige workbook — inclusief stijlen, formules en Smart Marker‑plaatsaanduidingen. Deze aanpak heeft de voorkeur boven het maken van een workbook vanaf nul omdat:

* **Ontwerpcontrole** – Ontwerpers kunnen kopteksten opmaken, bedrijfslogo's toevoegen en kolombreedtes instellen zonder code aan te passen.  
* **Versiebeheer** – Het bijwerken van het template vereist geen hercompilatie van de applicatie.  
* **Lokalisatie** – Je kunt aparte template‑bestanden houden voor verschillende talen.

Als je de voorkeur geeft aan een pure .NET‑oplossing zonder externe bibliotheken, kun je **ClosedXML** of **EPPlus** gebruiken, maar deze missen ingebouwde Smart Marker‑ondersteuning, wat betekent dat je loops moet schrijven die gegevens cel‑voor‑cel kopiëren.

## Excel‑generatie automatiseren met Smart Markers

Smart Markers zijn plaatsaanduidingen die eruitzien als `&=Collection.Property`. Wanneer de processor wordt uitgevoerd:

* Het iterereert over de collectie (`employeeList` in ons voorbeeld).  
* Voor elk item schrijft het de eigenschapswaarde in de overeenkomstige cel.  
* Het breidt automatisch rijen of kolommen uit indien nodig.

Dit mechanisme **automatiseert Excel‑generatie** en elimineert handmatige iteratielogica. Hetzelfde patroon werkt voor elke datastructuur — bestellingen, facturen, voorraadlijsten, enz.

### Veelvoorkomende variaties

| Variatie | Hoe te implementeren |
|----------|----------------------|
| **Meerdere collecties** | Voeg meer lijsten toe (bijv. `List<Department>`) en verwijs ernaar met verschillende tags zoals `&=DepartmentList.Name`. |
| **Geneste collecties** | Gebruik puntnotatie: `&=EmployeeList.Projects.ProjectName` waarbij `Projects` een collectie‑eigenschap binnen `Employee` is. |
| **Voorwaardelijke opmaak** | Plaats een Excel‑voorwaardelijke opmaakregel in het template; de processor behoudt deze voor de gegenereerde rijen. |

## Een employee report Excel maken

De term **employee report Excel** duidt op een typisch zakelijk gebruiksscenario: een manager wil een afdrukbare lijst van personeelsleden. Door de Smart Marker‑tags direct in het template te embedden, krijg je:

* Een koptekst‑rij met vetgedrukte lettertypen en achtergrondkleur.  
* Automatisch aangepaste kolombreedtes op basis van de gegevens.  
* Optionele totalen‑rijen (bijv. aantal medewerkers) die je kunt berekenen met standaard Excel‑formules.

Als je een totalen‑rij wilt toevoegen, plaats dan eenvoudig een formule zoals `=COUNTA(A2:A100)` in het template; de processor zal deze niet verstoren.

## Excel‑template C# genereren – best practices

Wanneer je **Excel‑template C#**‑code genereert, houd dan rekening met de volgende richtlijnen:

1. **Scheiding van verantwoordelijkheden** – Houd het laden van het template, de gegevensvoorbereiding en de verwerking in afzonderlijke methoden. Dit maakt unit‑testing eenvoudiger.  
2. **Invoer valideren** – Zorg ervoor dat het template‑bestand bestaat en dat de gegevenscollectie niet null is voordat `Process` wordt aangeroepen.  
3. **Resources vrijgeven** – Hoewel Aspose.Cells het geheugen beheert, wikkel de `Workbook` in een `using`‑blok als je met grote bestanden werkt.  
4. **Fouten afhandelen** – Vang `Exception` rond `sp.Process` om problemen zoals niet‑overeenkomende tag‑namen zichtbaar te maken.  

```csharp
static Workbook LoadTemplate(string path)
{
    if (!File.Exists(path))
        throw new FileNotFoundException($"Template not found: {path}");
    return new Workbook(path);
}
```

| John Doe | Developer |
| Jane Smith | Manager |

Alle opmaak van `template.xlsx` — zoals achtergrondkleur van de koptekst, kolombreedtes en eventuele logo‑afbeelding — blijft behouden.

## Veelvoorkomende problemen oplossen

| Symptoom | Waarschijnlijke oorzaak | Oplossing |
|----------|--------------------------|-----------|
| Geen gegevens verschijnen na verwerking | Smart Marker‑tags zijn verkeerd gespeld of geplaatst in samengevoegde cellen. | Controleer of tags de exacte `&=Collection.Property`‑syntaxis volgen en niet binnen samengevoegde gebieden staan. |
| Uitvoerbestand is leeg of corrupt | De workbook werd opgeslagen voordat de verwerking voltooid was. | Zorg ervoor dat `sp.Process` **vóór** `wb.Save` wordt uitgevoerd. |
| Grote employee‑lijst vertraagt de generatie | Het gebruik van de gratis versie van Aspose.Cells kan prestatie‑limieten hebben. | Upgrade naar de gelicentieerde versie of verwerk gegevens in batches. |
| Template‑pad is onjuist | Relatief pad wordt tijdens runtime naar een andere map opgelost. | Gebruik `Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "template.xlsx")` of stel de eigenschap `Copy to Output Directory` van het bestand in. |

## Volledige voorbeeldsamenvatting

Hieronder staat het volledige programma in één blok voor snelle copy‑paste:

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Load the template
            string templatePath = Path.Combine("YOUR_DIRECTORY", "template.xlsx");
            Workbook wb = new Workbook(templatePath);

            // Prepare data
            var employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Process Smart Markers
            var sp = new SmartMarkerProcessor();
            sp.Process(wb, employeeList);

            // Save the result
            string outputPath = Path.Combine("YOUR_DIRECTORY", "output.xlsx");
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

Het uitvoeren van dit programma maakt een **employee report Excel**‑bestand dat kan worden gemaild, afgedrukt of verder verwerkt.

## Volgende stappen

* **Grafieken toevoegen** – Plaats een grafiek‑plaatsaanduiding in het template; de processor houdt de grafiek gekoppeld aan de gegenereerde gegevens.  
* **Exporteren naar andere formaten** – Aspose.Cells kan direct opslaan naar PDF, CSV of HTML (`wb.Save("report.pdf")`).  
* **Integreren met ASP.NET Core** – Retourneer de gegenereerde workbook als een bestandsdownload in een controller‑actie.
