# Importeer aangepaste objecten in Excel met Aspose.Cells – Java‑gids

Als je **custom objects** moet **importeren** in een Excel‑werkblad, leidt deze gids je door het volledige proces met behulp van Aspose.Cells voor Java. Je ziet hoe je **data naar Excel** kunt **importeren**, een vetgedrukte kopstijl toepast, en een kant‑en‑klare `.xlsx`‑bestand genereert.

Het exporteren van tabelgegevens vanuit Java vereist vaak handmatig cel‑voor‑cel schrijven, wat foutgevoelig en moeilijk te onderhouden is. Door gebruik te maken van de `importCustomObjects`‑API vermijd je boilerplate‑code, houd je je datamodel intact, en krijg je fijnmazige stijl‑controle.

In deze tutorial zul je:

* Een lijst van Java `Map`‑objecten bouwen die een typische datatabel nabootst.
* Een herbruikbare kopstijl (vet lettertype) maken met Aspose.Cells.
* De custom objects importeren in een werkblad terwijl je de stijl‑array toepast.
* De werkmap opslaan op schijf en het resultaat verifiëren.

Het enige vereiste is een Java‑ontwikkelomgeving (JDK 8+ aanbevolen) en de Aspose.Cells voor Java‑bibliotheek.

---

## Wat je nodig hebt

| Vereiste | Reden |
|----------|-------|
| JDK 8 of nieuwer | Vereist om de Java‑code te compileren en uit te voeren. |
| Aspose.Cells voor Java (nieuwste versie) | Biedt de `Workbook`, `Worksheet` en import‑API's. |
| IDE of build‑tool (bijv. Maven, Gradle) | Vereenvoudigt afhankelijkheidsbeheer en uitvoering. |
| Schrijfrechten op een map voor het uitvoerbestand | De werkmap wordt opgeslagen als `ImportWithStyle.xlsx`. |

Voeg de Aspose.Cells‑afhankelijkheid toe aan je `pom.xml` als je Maven gebruikt:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## Stap 1: Bereid de custom objects voor om te importeren

De eerste stap is het maken van een collectie die de rijen vertegenwoordigt die je in Excel wilt plaatsen. In dit voorbeeld gebruiken we een `List<Map<String,Object>>` waarbij elke map fungeert als een rij met kolomnamen als sleutels.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Waarom dit belangrijk is:**  
`importCustomObjects` verwacht een array van objecten. Door een `Map` te gebruiken, behoud je kolomnamen, waardoor Aspose.Cells ze automatisch naar cellen kan mappen. Deze aanpak weerspiegelt een typische `DataTable` in .NET of een `ResultSet` van JDBC, waardoor de code herbruikbaar is in verschillende projecten.

## Stap 2: Definieer een kopstijl om toe te passen bij import

Een duidelijke koprij verbetert de leesbaarheid. Aspose.Cells stelt je in staat een `Style`‑object te maken, het lettertype vet te maken, en het door te geven via een `ImportTableOptions`‑array.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Waarom dit belangrijk is:**  
Als je de stijl‑array weglaten, verschijnt de kop in het standaardlettertype, wat mogelijk niet opvalt. Door de stijl één keer voor te bereiden, vermijd je herhaalde aanroepen voor elke rij en houd je de importlogica overzichtelijk.

## Stap 3: Importeer de custom objects met de stijl‑array

Nu combineer je de data en stijl, en roep je `importCustomObjects` aan. De methode plaatst de data beginnend bij de linkerbovenhoek (rij 0, kolom 0) en past de kopstijl automatisch toe.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Waarom dit belangrijk is:**  
`importCustomObjects` parseert elke map, maakt kolommen op basis van de sleutels (`Name`, `Score`), en schrijft de waarden naar de juiste cellen. Het `ImportTableOptions`‑object vertelt Aspose.Cells om de `styleArray` te gebruiken voor de eerste rij, waardoor je een vetgedrukte kop krijgt zonder extra code.

## Stap 4: Sla de werkmap op en controleer de uitvoer

Tot slot schrijf je de werkmap naar een bestand. Het gegenereerde Excel‑bestand bevat een gestylede koprij gevolgd door de gegevensrijen.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Verwacht resultaat:**  

| **Name** | **Score** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

De kopcellen (`Name`, `Score`) verschijnen in vet lettertype, overeenkomend met de stijl die in Stap 2 is gedefinieerd.

## Veelvoorkomende variaties en randgevallen

| Situatie | Aanbevolen aanpassing |
|----------|-----------------------|
| **Andere kolomvolgorde** | Zorg ervoor dat de `Map`‑sleutels in de gewenste volgorde worden ingevoegd, of gebruik een custom POJO met geannoteerde velden en een `PropertyDescriptor`‑array. |
| **Grote datasets (>10 000 rijen)** | Verhoog de `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` om `OutOfMemoryError` te voorkomen. |
| **Aangepaste getalformaten** | Voeg een tweede `Style` toe in `styleArray` voor de gegevensrijen, bijv. stel `NumberFormat` in op `"0"` voor gehele scores. |
| **Meerdere werkbladen** | Roep `importCustomObjects` aan op elk doelwerkblad, en pas de start‑rij/kolom aan indien nodig. |
| **Locale‑specifieke koptekst** | Vul de koprij handmatig in vóór import, en pas vervolgens de stijl toe op het volledige bereik met `Cells.applyStyle`. |

## Pro‑tips voor een robuuste Java‑export naar Excel

* **Herbruik de tijdelijke werkmap** – Het maken van een nieuwe `Workbook` voor elke stijl voegt overhead toe. Houd één instantie bij als je meerdere stijlen nodig hebt.  
* **Valideer data vóór import** – Null‑waarden in een map worden lege cellen; je kunt ze vervangen door standaardwaarden door de lijst vooraf te verwerken.  
* **Sluit bronnen** – Hoewel Aspose.Cells intern geheugen beheert, zorgt een expliciete aanroep van `workbook.dispose()` na het opslaan ervoor dat native bronnen direct worden vrijgegeven.  
* **Stel `Workbook.setForceFullCalculation(true)` in** als je werkmap formules bevat die vóór het opslaan moeten worden geëvalueerd.
