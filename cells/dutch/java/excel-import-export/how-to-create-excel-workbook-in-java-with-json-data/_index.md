# Hoe maak je een Excel-werkmap in Java met JSON-gegevens

Als je **create Excel workbook java** moet, staan ontwikkelaars vaak voor de uitdaging om JSON-gegevens in een spreadsheet te laden. Deze gids laat zien hoe je **populate Excel from JSON** kunt doen, inclusief hoe je **convert JSON array excel** en **populate workbook from json** op een schone, herhaalbare manier.

Werken met JSON is gebruikelijk wanneer services gegevens via REST‑API's beschikbaar stellen, en Excel blijft het standaardformaat voor rapportage en analyse. Aan het einde van deze tutorial heb je een uitvoerbaar Java‑programma dat:

* een nieuwe Excel-werkmap maakt,
* een JSON-array (of elke JSON-structuur) leest en de waarden in cellen schrijft,
* het bestand opslaat op schijf, klaar voor verdere verwerking.

Er zijn geen externe tools nodig, behalve de Aspose.Cells for Java‑bibliotheek, die de `SmartMarkerProcessor` levert die in de voorbeeldcode wordt gebruikt.

## Vereisten

| Voorwaarde | Reden |
|------------|-------|
| Java Development Kit (JDK) ≥ 8 | Vereist om het voorbeeld te compileren en uit te voeren |
| Maven or Gradle (optional) | Vereenvoudigt het beheer van afhankelijkheden |
| Aspose.Cells for Java (v23.10 or later) | Levert de klassen `Workbook` en `SmartMarkerProcessor` |
| Basic knowledge of JSON and Java I/O | Helpt je de gegevensstroom te begrijpen |

Als je liever geen build‑tool gebruikt, kun je de Aspose.Cells JAR downloaden van de [Aspose website](https://products.aspose.com/cells/java/) en handmatig toevoegen aan de classpath van je project.

## Stap 1: Zet het project op en voeg de Aspose.Cells‑afhankelijkheid toe

### Maven‑gebruikers

Voeg de volgende afhankelijkheid toe aan je `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Gradle‑gebruikers

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

Als je geen build‑tool gebruikt, plaats dan de gedownloade JAR in de map `libs/` en voeg deze toe aan de classpath bij het compileren:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## Stap 2: Maak een nieuwe werkmap en configureer de SmartMarker‑processor

De `SmartMarkerProcessor` vereenvoudigt het toewijzen van JSON‑waarden aan Excel‑cellen. Door `setArrayAsSingle(true)` aan te roepen, vertellen we de processor een volledige JSON‑array als één enkele waarde te behandelen, wat handig is wanneer je elk element in een eigen cel in een rij wilt plaatsen.

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**Waarom dit belangrijk is:**  
Het vooraf maken van de werkmap geeft je een schoon canvas. Het configureren van `setArrayAsSingle(true)` voorkomt dat de processor de array omzet in één enkele string (bijv. `["A","B","C"]`) en stelt je in staat de lay-out handmatig te bepalen.

## Stap 3: Definieer de JSON‑gegevens die je wilt invoegen

Voor deze tutorial gebruiken we een eenvoudige JSON‑array, maar dezelfde aanpak werkt met objecten, geneste arrays of complexe structuren.

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**Tip:** Als je JSON afkomstig is van een bestand of een REST‑endpoint, vervang dan de letterlijke string door een `String` die uit de bron wordt gelezen, bijv. `Files.readString(Paths.get("data.json"))`.

## Stap 4: Verwerk de werkmap met de JSON‑gegevens

Nu laten we de `SmartMarkerProcessor` de JSON‑array op het eerste werkblad toepassen. Het standaardgedrag schrijft elk element in opeenvolgende cellen beginnend bij `A1`.

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

Achter de schermen parseert Aspose.Cells de JSON, maakt een tijdelijke datatabel aan en schrijft de waarden naar het werkblad. Omdat we `ArrayAsSingle` op `true` hebben gezet, worden de array‑elementen horizontaal over de eerste rij geplaatst.

## Stap 5: Sla de werkmap op in een bestand

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

Wanneer je het programma uitvoert, zou je een bestand met de naam **CreatedFromJson.xlsx** in je werkmap moeten zien. Het openen met Excel (of een andere compatibele viewer) toont:

| A | B | C |
|---|---|---|
| A | B | C | *(waarden verschijnen in cellen A1, B1, C1)*

### Verwachte output

```
Workbook saved to CreatedFromJson.xlsx
```

En het Excel‑blad ziet er als volgt uit:

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## Stap 6: Omgaan met complexere JSON‑structuren (optioneel)

### 6.1 Een werkmap vullen vanuit een JSON‑object

Als je JSON een object is in plaats van een array, kun je nog steeds `SmartMarkerProcessor` gebruiken. Bijvoorbeeld:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

De processor zal benoemde bereiken (`title`, `month`, `values`) aanmaken die je in je Excel‑template kunt refereren met Smart Markers zoals `&=title` en `&=values`.

### 6.2 Een geneste JSON‑array omzetten naar een verticale lijst

Soms moet de array een kolom vullen in plaats van een rij. Stel de startcel handmatig in vóór het verwerken:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

Nu verschijnen de waarden **A**, **B**, **C** respectievelijk in de cellen A2, A3, A4.

## Veelvoorkomende valkuilen en hoe ze te vermijden

| Probleem | Oorzaak | Oplossing |
|----------|---------|-----------|
| **Array written as a single string** | `setArrayAsSingle(false)` (default) | Roep `processor.setArrayAsSingle(true)` aan |
| **File not found when saving** | Ongeldig pad of ontbrekende schrijfrechten | Gebruik een absoluut pad of zorg dat de map bestaat |
| **JSON parsing error** | Misvormde JSON‑string | Valideer JSON met een tool of gebruik een bibliotheek zoals Jackson om de string te genereren |
| **Cells overwritten unintentionally** | Het verwerken van hetzelfde werkblad meerdere keren zonder de startcel te resetten | Roep `processor.setStartCell("A1")` aan vóór elke `process`‑aanroep |

## Pro‑tip: hergebruik de werkmap als sjabloon

In plaats van elke keer met een lege werkmap te beginnen, kun je een vooraf ontworpen sjabloon laden dat al kopteksten, formules of opmaak bevat:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

Deze aanpak combineert de visuele afwerking van een handgemaakte Excel‑file met de automatisering van **populate workbook from json**.
