# Hogyan változtassuk meg a diagram jelölőjelek irányát Java-ban az Aspose.Cells segítségével

## Bevezetés

A diagram jelölőjelek irányának módosítása gyakori módja az Excel-diagramok olvashatóságának javítására, különösen hosszú kategórianév vagy sűrű adatkészletek esetén. Ebben az útmutatóban megtanulja, **hogyan változtassa meg a diagram jelölőjelek irányát** az Aspose.Cells for Java segítségével, a könyvtár telepítésétől a végső munkafüzet mentéséig. Emellett bemutatjuk, miért fontos a megfelelő címkeforgatás pénzügyi jelentések, tudományos vizualizációk és üzleti műszerfalak esetén.

## Gyors válaszok
- **Melyik könyvtár kezeli a diagram címke forgatását?** Aspose.Cells for Java.
- **Mely Maven artefakt adja hozzá a funkcionalitást?** `com.aspose:aspose-cells`.
- **Beállíthatom a címke szögét függőlegesre?** Igen, használja a `ChartTextDirectionType.VERTICAL` értéket.
- **Szükségem van licencre a termelésben való használathoz?** Állandó licenc szükséges; egy ideiglenes licenc értékeléshez működik.
- **Az API kompatibilis a Java 8 és újabb verziókkal?** Igen, támogatja a Java 8‑21-et.

## Mi a diagram jelölőjelek irányának módosítása?
**A diagram jelölőjelek irányának módosítása** arra utal, hogy a kategória‑tengely jelölőcímkéinek tájolását (pl. vízszintes, függőleges vagy elforgatott) úgy állítjuk be, hogy jobban illeszkedjenek a diagram területébe. Ez a művelet az Aspose.Cells-ben a `ChartAxis` objektum `setTickLabelDirection` metódusával hajtható végre.

## Miért használjuk az Aspose.Cells for Java-t a jelölőjelek forgatásához?
Az Aspose.Cells **több mint 150 fájlformátumot** dolgoz fel, képes **500+ munkalappal** rendelkező munkafüzeteket kezelni anélkül, hogy az egész fájlt memóriába töltené, és a címkék forgatását **0,2 másodpercnél kevesebb** idő alatt hajtja végre tipikus diagramméretek esetén. Ezek a számszerű képességek megbízható választássá teszik vállalati szintű Excel-automatizáláshoz.

## Hogyan változtassuk meg a diagram jelölőjelek irányát Java-ban?
A jelölőcímke tájolásának módosításához be kell tölteni a cél munkafüzetet, le kell kérni a konkrét diagramot, hozzá kell férni a kategória tengelyéhez, és meg kell hívni a `setTickLabelDirection` metódust a kívánt `ChartTextDirectionType` értékkel. Ez a sorozat csak néhány Java kódsorban elvégezhető, így egyszerűen integrálható a meglévő automatizálási munkafolyamatokba.

1. Töltse be a diagramot tartalmazó munkafüzetet, amelyet módosítani szeretne.  
2. Szerezze be a munkalapot és a diagram objektumot az indexe alapján.  
3. Hozza el a kategória tengelyt (`getCategoryAxis()`) és hívja meg a `setTickLabelDirection` metódust a kívánt `ChartTextDirectionType` értékkel.  
4. Mentse a munkafüzetet egy új fájlba.

## Implementációs útmutató

### A munkafüzet és a diagram betöltése
A `Workbook` osztály egy teljes Excel-fájlt képvisel a memóriában. A `Worksheet` osztály hozzáférést biztosít az egyes lapokhoz, a `Chart` osztály pedig egy konkrét diagramot reprezentál.

```java
Workbook workbook = new Workbook("input.xlsx");               // 1️⃣ Load file
Worksheet sheet = workbook.getWorksheets().get(0);            // 2️⃣ First sheet
Chart chart = sheet.getCharts().get(0);                       // 3️⃣ First chart on the sheet
```

### A jelölőcímke irányának módosítása
`ChartAxis` vezérli az összes tengellyel kapcsolatos tulajdonságot. A `ChartTextDirectionType` egy felsorolás, amely meghatározza a tájolást.

```java
ChartAxis categoryAxis = chart.getCategoryAxis();            // Access category axis
categoryAxis.setTickLabelDirection(ChartTextDirectionType.HORIZONTAL); // 4️⃣ Set direction
```

- `ChartTextDirectionType.HORIZONTAL` → címkék balról jobbra olvashatók.  
- `ChartTextDirectionType.VERTICAL` → címkék felülről lefelé olvashatók.  
- `ChartTextDirectionType.ROTATED_45` → címkék 45°-kal elforgatva (újabb verziókban elérhető).

### A munkafüzet mentése
A tengely beállítása után mentse a változtatásokat:

```java
workbook.save("output.xlsx", SaveFormat.XLSX);
```

## Gyakori problémák és megoldások
- **Helytelen diagram index** – Ellenőrizze, hogy a diagram létezik-e a `sheet.getCharts().getCount()` lekérdezésével.  
- **Licenc nincs alkalmazva** – Ha vízjel látható, győződjön meg róla, hogy a licenc fájl betöltésre került minden munkafüzet művelet előtt.  
- **Nem támogatott irány** – Néhány régebbi diagramtípus csak vízszintes címkéket támogat; frissítsen a legújabb Aspose.Cells verzióra az összes enum érték eléréséhez.

## Gyakorlati alkalmazások
A jelölőcímke irányának módosítása kiemelkedik olyan helyzetekben, ahol a hely korlátozott:

1. **Pénzügyi idővonalak** – A vízszintes címkék olvashatóvá teszik a dátumkarakterláncokat a sűrű idősort ábrázoló diagramokon.  
2. **Tudományos ábrák** – A függőleges címkék felszabadítják a vízszintes helyet a hosszabb változónévhez.  
3. **Üzleti műszerfalak** – Az elforgatott címkék megakadályozzák a szöveg átfedését a többkategóriás oszlopdiagramokban.

## Teljesítmény szempontok
Amikor **százak diagramot** tartalmazó munkafüzeteket dolgoz fel, kövesse ezeket a legjobb gyakorlatokat:

- Töltsön be egy munkafüzetet egyszer, és használja újra ugyanazt a `Workbook` példányt.  
- Alkalmazza a címke változtatásokat egy ciklusban, majd egyszer hívja meg a `workbook.save`-t az I/O minimalizálása érdekében.  
- Használja a `setCalculateFormula` jelzőt csak akkor, ha a módosítások után újraszámolásra van szükség a képletekben.

## Gyakran ismételt kérdések

**Q: Forgathatom a jelölőcímkéket tetszőleges szögben?**  
A: Az Aspose.Cells jelenleg a meghatározott enum értékeket támogatja (vízszintes, függőleges, 45°). Egyéni szögekhez kombinálhatja a forgatást a `setTickLabelAlignment`-nal.

**Q: Az API működik jelszóval védett Excel fájlokkal?**  
A: Igen. Töltsön be egy munkafüzetet a `new Workbook("file.xlsx", new LoadOptions(LoadFormat.XLSX) {{ setPassword("pwd"); }})` kóddal.

**Q: Van korlát a módosítható diagramok számában egy munkafüzetben?**  
A: Nincs szigorú korlát; a teljesítmény a rendelkezésre álló memóriától függ. Egy 1 000 diagramot tartalmazó munkafüzet feldolgozása általában 30 másodpercnél kevesebb idő alatt befejeződik egy standard szerveren.

**Q: Hogyan alkalmazhatok ideiglenes licencet programozottan?**  
A: A `License` osztály betölti és alkalmazza az Aspose.Cells licencfájlt futásidőben. Hozzon létre egy `License` objektumot, és hívja meg a `setLicense("Aspose.Total.Java.lic")` metódust minden Aspose.Cells művelet előtt.

**Q: A jelölőjelek irányának módosítása befolyásolja a meglévő adat sorozatokat?**  
A: Nem. A művelet csak a tengelycímke megjelenítését módosítja; az adatértékek változatlanok maradnak.
