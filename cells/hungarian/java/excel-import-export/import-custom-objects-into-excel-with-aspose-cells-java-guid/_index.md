# Egyedi objektumok importálása Excelbe Aspose.Cells – Java útmutató

Ha **egyedi objektumokat** kell **importálni** egy Excel munkalapra, ez az útmutató végigvezeti a teljes folyamaton az Aspose.Cells for Java használatával. Megmutatjuk, hogyan **importálj adatot Excelbe**, alkalmazz egy félkövér fejlécstílust, és generálj egy megosztható `.xlsx` fájlt.

A táblázatos adatok exportálása Java‑ból gyakran manuális cellán‑kattintásos írással jár, ami hibára hajlamos és nehezen karbantartható. Az `importCustomObjects` API használatával elkerülheted a sablonkódot, megőrizheted az adatmodell integritását, és finomhangolt stílusvezérlést nyerhetsz.

Ebben a tutorialban:

* Létrehozunk egy Java `Map` objektumok listáját, amely egy tipikus adat táblát modellez.
* Létrehozunk egy újrahasználható fejlécstílust (félkövér betű) az Aspose.Cells segítségével.
* Importáljuk az egyedi objektumokat egy munkalapra, miközben alkalmazzuk a stílus tömböt.
* Elmentjük a munkafüzetet a lemezre, és ellenőrizzük az eredményt.

Az egyetlen előfeltétel egy Java fejlesztői környezet (JDK 8+ ajánlott) és az Aspose.Cells for Java könyvtár.

## 1. lépés: Készítsd elő az importálandó egyedi objektumokat

Az első lépés egy olyan gyűjtemény létrehozása, amely a sorokat reprezentálja, amelyeket az Excelbe szeretnél helyezni. Ebben a példában egy `List<Map<String,Object>>`‑t használunk, ahol minden map egy sort jelent, a kulcsok pedig az oszlopneveket.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Miért fontos:**  
Az `importCustomObjects` egy objektumtömböt vár. A `Map` használatával megőrzöd az oszlopneveket, így az Aspose.Cells automatikusan a megfelelő cellákhoz tudja rendelni őket. Ez a megközelítés hasonló egy .NET‑es `DataTable`‑hez vagy egy JDBC‑es `ResultSet`‑hez, és újrahasználhatóvá teszi a kódot különböző projektekben.

---

## 2. lépés: Definiálj egy fejlécstílust az importáláshoz

Egy jól látható fejlécsor javítja az olvashatóságot. Az Aspose.Cells lehetővé teszi egy `Style` objektum létrehozását, a betűtípust félkövérre állítva, majd ezt egy `ImportTableOptions` tömbön keresztül átadni.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Miért fontos:**  
Ha kihagyod a stílus tömböt, a fejléc az alapértelmezett betűtípussal jelenik meg, ami nem emelkedik ki. A stílus egyszeri előkészítésével elkerülöd az ismétlődő hívásokat minden sorra, és tisztább marad az importálási logika.

---

## 3. lépés: Importáld az egyedi objektumokat a stílus tömbbel

Most kombinálod az adatot és a stílust, majd meghívod az `importCustomObjects`‑t. A metódus a bal‑felső sarokból (0‑ás sor, 0‑ás oszlop) kezdi el a beírást, és automatikusan alkalmazza a fejlécstílust.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Miért fontos:**  
Az `importCustomObjects` minden map‑et feldolgoz, a kulcsok (`Name`, `Score`) alapján oszlopokat hoz létre, és az értékeket a megfelelő cellákba írja. Az `ImportTableOptions` objektum azt mondja az Aspose.Cells‑nek, hogy a `styleArray`‑t használja az első sorra, így félkövér fejlécet kapsz extra kód nélkül.

---

## 4. lépés: Mentsd el a munkafüzetet és ellenőrizd a kimenetet

Végül írd a munkafüzetet egy fájlba. A generált Excel‑fájl egy stílusos fejlécsort tartalmaz, amelyet a további adat sorok követnek.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Várható eredmény:**  

| **Name** | **Score** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

A fejléccellák (`Name`, `Score`) félkövér betűvel jelennek meg, a 2. lépésben definiált stílusnak megfelelően.

## Gyakori variációk és szélhelyzetek

| Helyzet | Ajánlott módosítás |
|-----------|------------------------|
| **Eltérő oszlopsorrend** | Győződj meg róla, hogy a `Map` kulcsai a kívánt sorrendben kerülnek be, vagy használj egy egyedi POJO‑t annotált mezőkkel és egy `PropertyDescriptor` tömböt. |
| **Nagy adathalmazok (>10 000 sor)** | Növeld az `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` értékét, hogy elkerüld a `OutOfMemoryError`‑t. |
| **Egyedi számformátumok** | Adj hozzá egy második `Style`‑t a `styleArray`‑hez az adat sorokhoz, például állítsd be a `NumberFormat`‑ot `"0"`‑ra az egész számokhoz. |
| **Több munkalap** | Hívd meg az `importCustomObjects`‑t minden cél munkalapon, a kezdő sor/oszlop szükség szerint módosítva. |
| **Nyelvspecifikus fejlécszöveg** | Töltsd fel a fejlécsort manuálisan importálás előtt, majd alkalmazd a stílust a teljes tartományra a `Cells.applyStyle`‑val. |

## Pro tippek egy robusztus Java‑os Excel‑exporthoz

* **Használd újra a temporális munkafüzetet** – Új `Workbook` létrehozása minden stílushoz plusz terhet jelent. Tarts egyetlen példányt, ha több stílust kell alkalmaznod.  
* **Érvényesítsd az adatot importálás előtt** – A map‑ben lévő null értékek üres cellákká válnak; előfeldolgozással helyettesítheted őket alapértelmezett értékekkel.  
* **Zárd le az erőforrásokat** – Bár az Aspose.Cells belsőleg kezeli a memóriát, a `workbook.dispose()` kifejezett meghívása a mentés után gyorsan felszabadítja a natív erőforrásokat.  
* **Állítsd be a `Workbook.setForceFullCalculation(true)`‑t**, ha a munkafüzetben képletek vannak, amelyeket a mentés előtt ki kell számolni.
