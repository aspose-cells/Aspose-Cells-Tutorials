# Részletes munkalapok létrehozása Java-ban az Aspose.Cells okos jelölőkkel

Ha Java‑alkalmazásban **részletes munkalapokat** kell létrehoznod, ez a bemutató megmutatja, hogyan teheted ezt meg az Aspose.Cells okos jelölőkkel. Egy teljes, futtatható példát láthatsz, amely **java create worksheets**, a **sheet name from field** értéket származtatja, és **process data source** néhány kódsorban.

Az útmutató mindent lefed a projekt beállításától a végső munkafüzet mentéséig, így a megoldást egyszerűen átmásolhatod a saját projektedbe és azonnal testre szabhatod. Külső dokumentációra nincs szükség – minden, amire szükséged van, itt megtalálható.

## Amit megtanulsz

* Hogyan **use smart markers**-t használj egy sablon munkalap megkettőzéséhez a mester adatkészlet minden sorához.  
* Hogyan állítsd be minden új munkalap nevét dinamikusan egy mező értéke alapján (például `Order_123`).  
* Hogyan tápláld egy Java gyűjteményt a **process data source**‑ként az okos jelölő motorhoz.  
* Tippek a szélhelyzetek kezelésére, például üres adatok, speciális karakterek a munkalap nevekben, és a nagy adatkészletek teljesítménybeli szempontjai.

### Előfeltételek

| Követelmény | Indoklás |
|-------------|----------|
| Java 8 vagy újabb | Az Aspose.Cells for Java támogatja a Java 8+ verziókat. |
| Maven vagy Gradle build rendszer | Megkönnyíti az Aspose.Cells függőség hozzáadását. |
| Alapvető Java gyűjtemények ismerete | Szükséges a smart markerek adatforrásának felépítéséhez. |
| Egy sablon Excel fájl (`Template.xlsx`) helyőrző smart markerrel az **A1** cellában | A sablon vezérli a részletes munkalapok generálását. |

> **Pro tipp:** Tartsd a sablon munkafüzetet a projekt `resources` mappájában, hogy a JAR‑ba legyen csomagolva.

## 1. lépés: Aspose.Cells hozzáadása a projekthez (java create worksheets)

Ha **Maven**‑t használsz, add hozzá a következő függőséget a `pom.xml`‑hez:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

**Gradle** esetén helyezd ezt a sort a `build.gradle` fájlba:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

Ezek a sorok teszik elérhetővé a **java create worksheets** API‑kat fordítási időben.

## 2. lépés: A sablon munkafüzet betöltése

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*Miért fontos:* A `Workbook` objektum az összes Excel művelet belépési pontja. A sablon betöltése biztosítja, hogy a helyes elrendezéssel és az előre definiált formázással kezdj.

## 3. lépés: Okos jelölő beszúrása, amely minden mester sorhoz új munkalapot hoz létre (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

A `${Orders:DetailSheetNewName=Order_${OrderId}}` szintaxis a **use smart markers** magja. Három dolgot csinál:

1. Iterál a `Orders` gyűjteményen.  
2. Létrehoz egy **new worksheet**‑et minden elemhez.  
3. Beállítja a **sheet name from field** `OrderId` értéket (az `Order_` előtaggal).

## 4. lépés: Az adatforrás előkészítése (process data source)

Az alábbiakban egy minimális példát látsz, amely `List<Map<String, Object>>`‑t használ. Cseréld le a saját valós adatforrásodra – adatbázis sorokra, JSON deszerializációra stb.

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*Miért fontos:* A **process data source** lépés a Java gyűjteményedet kötözi az okos jelölő motorhoz. A kulcs (`"Orders"`) pontosan meg kell egyezzen a smart marker nevével.

## 5. lépés: Az okos jelölők feldolgozása (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

Amikor a `process` fut, az Aspose.Cells beolvassa a `Orders` gyűjteményt, minden bejegyzéshez lemásolja a sablon munkalapot, és átnevezi a munkalapokat a `OrderId` mező alapján. Ez a **process data source** használatának a középpontja.

## 6. lépés: A munkafüzet mentése a megkettőzött részletes munkalapokkal

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

A futtatás után megtalálod a `DuplicatedDetailSheets.xlsx` fájlt, amely a következőket tartalmazza:

* `Sheet1` – az eredeti sablon (változatlan).  
* `Order_101` – részletes munkalap az első rendeléshez.  
* `Order_102` – részletes munkalap a második rendeléshez.

### Várható kimenet (részlet)

| Munkalap neve | A1 (smart marker) | Eredményes tartalom |
|---------------|-------------------|---------------------|
| Order_101     | `${Orders:...}`   | Az `order1` adataival feltöltve |
| Order_102     | `${Orders:...}`   | Az `order2` adataival feltöltve |

Nyisd meg a fájlt Excelben, hogy ellenőrizd, minden munkalap helyesen van elnevezve és tartalmazza az adat sorokat.

## Közös variációk és szélhelyzetek kezelése

### Üres adatforrás

Ha a `orders` üres, az okos jelölő feldolgozó **nem hoz létre új munkalapokat**. Egy üres munkafüzet elkerülése érdekében adj hozzá egy ellenőrzést:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### Speciális karakterek a munkalap nevekben

Az Excel munkalap nevek nem tartalmazhatják a `\ / ? * [ ] :` karaktereket. Tisztítsd meg a mezőt a használat előtt:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### Nagy adatkészletek

Több ezer sor esetén érdemes növelni a JVM heap méretét (`-Xmx2g`) és a `workbook.calculateFormula()` hívást csak az összes munkalap generálása után végrehajtani a teljesítmény javítása érdekében.
