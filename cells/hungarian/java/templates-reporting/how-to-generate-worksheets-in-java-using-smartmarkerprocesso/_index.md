# Módszerek munkalapok generálására Java-ban a SmartMarkerProcessor használatával

Ha **munkalapok generálására** van szükséged egy Excel fájlban, ez az útmutató egy teljes, azonnal futtatható megoldást mutat be. Az első két mondat végére megérted, hogyan lehet munkalapokat és dinamikus excel lapokat generálni objektumgyűjteményből, és lesz egy működő kódmintád, amely egyetlen metódushívással automatizálja az excel létrehozását.

Külön munkalapok létrehozása minden alkalmazott, projekt vagy bármely más entitás számára gyakori követelmény, amikor programozott módon kell **populate excel workbook** adatokat feltölteni. Ez az útmutató minden lépést részletez – a sablon beállításától a lista feldolgozásáig és a végleges fájl mentéséig – így azonnal alkalmazhatod a technikát saját Java alkalmazásaidban.

## Mit fogsz elérni

* Generálj egy fő munkalapot, amely felsorolja a magas szintű információkat.  
* Hozz létre **multiple sheets from list** adatokat, minden munkalap automatikusan elnevezve.  
* **Automate excel creation** manuális sor- vagy oszlop hozzáadás nélkül.  
* **Populate excel workbook** gazdag adatstruktúrákkal (objektumok, térképek, tömbök).  

Előfeltételek:

* Java 8 vagy újabb telepítve.  
* Maven (vagy más build eszköz) az Aspose.Cells for Java könyvtár hozzáadásához.  
* Alapvető ismeretek a Java gyűjteményekről.  

> **Pro tip:** A SmartMarker szintaxis (`${EmployeeMaster}`) bármely, a `java.util.Collection`-t megvalósító gyűjteménytípuszal működik. Használd a sablonok tisztán és karbantarthatóan tartásához.

## Munkalapok generálása a SmartMarkerProcessor segítségével

Ez a szakasz tartalmazza a fő kódot, amely **how to generate worksheets** egyszerűvé teszi. Megmagyarázzuk, miért fontos minden sor, nem csak azt, hogy mit csinál.

### 1. lépés: Aspose.Cells függőség hozzáadása

Ha Maven-t használsz, add hozzá a következőt a `pom.xml`-hez. A könyvtár biztosítja a `SmartMarkerProcessor` osztályt, amelyet az egész útmutatóban használunk.

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **Why:** Az Aspose.Cells kezeli az Excel fájl I/O-t, a Smart Marker elemzést és a munkalap-kezelést belsőleg, így az adatokra koncentrálhatsz az alacsony szintű fájlműveletek helyett.

### 2. lépés: Az Excel sablon előkészítése

Hozz létre egy `EmployeeTemplate.xlsx` nevű Excel fájlt, amely egyetlen cellát tartalmaz, benne a Smart Marker helyőrzővel:

| A |
|---|
| `${EmployeeMaster}` |

Amikor a processzor fut, lecseréli ezt a helyőrzőt egy **detail sheet**-re, amely minden alkalmazottra egy sort tartalmaz.

> **Why:** A helyőrző megmondja a processzornak, hová injektálja az adatokat. Külön sablon használata megőrzi a formázást (betűtípusok, szegélyek, oszlopszélességek).

### 3. lépés: Az adatmodell definiálása

Az alábbiakban egy minimális `Employee` osztály és egy segédmetódus látható, amely egy alkalmazottak listáját építi fel. A lista a **multiple sheets from list** bemutatására szolgál.

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **Why:** Egy egyszerű Java objektum (POJO) közvetlenül a Smart Marker mezőkhöz (`firstName`, `lastName`, `department`) térképeződik. Ez a **populate excel workbook** egyszerűvé és típusbiztossá teszi.

### 4. lépés: A SmartMarkerProcessor beállítása

Most mindent összekapcsolunk. A processzor beolvassa a sablont, lecseréli a jelölőt, és létrehoz egy új munkalapot `EmployeeDetail` néven.

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

**A kulcsfontosságú sorok magyarázata**

| Line | Reason |
|------|--------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | Betölti a sablont, amely már tartalmazza a Smart Marker helyőrzőt. |
| `data.put("EmployeeMaster", employees);` | A Java listát a `${EmployeeMaster}` jelölőhöz köti. |
| `processor.setDetailSheetNewName("EmployeeDetail");` | Értelmes nevet ad a generált munkalapnak az alapértelmezett `Sheet1` helyett. |
| `processor.process(wb, data);` | **How to generate worksheets** – a processzor beolvassa a jelölőt, létrehoz egy új munkalapot, és minden `Employee` számára sorokat tölt ki. |
| `wb.save("EmployeesReport.xlsx");` | Elmenti a **dynamic excel sheets**-et a lemezre. |

### 5. lépés: A kimenet ellenőrzése

Nyisd meg az `EmployeesReport.xlsx` fájlt. Két munkalapot kell látnod:

1. **Sheet1** – az eredeti sablon (elrejthető vagy eltávolítható).  
2. **EmployeeDetail** – egy **dynamic excel sheet** oszlopokkal `firstName`, `lastName`, `department` és egy sor minden alkalmazottra.

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **Why this matters:** A fájl most már **multiple sheets from list** tartalmaz manuális ciklus vagy cellacímzés nélkül. A Smart Marker motor gondoskodik a sorok létrehozásáról, az adatkonverzióról és a formázás öröklődéséről.

### 6. lépés: Szélsőséges esetek kezelése

#### Üres adatlista

Ha az `employees` üres, a processzor továbbra is létrehozza az `EmployeeDetail` munkalapot, de üresen hagyja. Megakadályozhatod a munkalap hozzáadását a gyűjtemény méretének ellenőrzésével a feldolgozás előtt:

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### Nagyon nagy listák

Ezrek sorok esetén fontold meg a memória allokáció növelését (`-Xmx2g`) vagy a `processor.setAutoFitRows(false)` használatát a feldolgozás felgyorsításához.

#### Egyedi munkalap elnevezés csoportonként

Ha minden részleghez külön munkalapra van szükség, használhatod a **multiple detail sheets**-t:

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

A `${department}` helyőrző minden `Employee` objektumból kerül ki, és olyan munkalapokat hoz létre, mint `Dept_Sales`, `Dept_Marketing`, stb.
