# Hogyan ágyazzuk be a betűtípusokat HTML-be a munkafüzet mentésekor

Ha **hogyan ágyazzuk be a betűtípusokat HTML-be** kell a táblázat exportálása során, ez az útmutató egy teljes, azonnal futtatható megoldást mutat be. Akár jelentésportált, akár kliensoldali analitikai nézetet épít, a betűtípusok beágyazása garantálja, hogy a megjelenített HTML pontosan úgy néz ki, mint az eredeti munkafüzet, függetlenül a néző által telepített betűtípusoktól.

Megtanulja a legjobb módját a **munkafüzet mentésének HTML‑ként** az Aspose.Cells használatával, megismeri a gyakori buktatókat, és tippeket kap a nagy munkafüzetek vagy egyéni betűtípusfájlok kezeléséhez. Külső dokumentációra nincs szükség – minden, amire szüksége van, ebben az útmutatóban található.

## Előfeltételek

- .NET 6.0 vagy újabb (a kód .NET Framework 4.7+‑vel is működik)
- Érvényes Aspose.Cells for .NET licenc (vagy használhatja az ingyenes értékelési módot)
- Alap C# ismeretek és egy IDE, például a Visual Studio 2022
- A beágyazni kívánt TrueType (.ttf) vagy OpenType (.otf) betűtípusfájlok (elérhetőnek kell lenniük a futó folyamat számára)

## 1. lépés: A projekt beállítása és az Aspose.Cells importálása

Hozzon létre egy új konzolos alkalmazást, és adja hozzá az Aspose.Cells NuGet csomagot:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

Ezután nyissa meg a **Program.cs** fájlt, és adja hozzá a szükséges `using` direktívákat:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **Pro tipp:** Helyezze egy `fonts` nevű mappába a projekt gyökerénél az egyéni betűtípusokat. Ez hordozhatóvá teszi a megoldást, és később egyszerűvé teszi a hivatkozást.

## 2. lépés: Munkafüzet létrehozása vagy betöltése

Bemutatásként egy egyszerű munkafüzetet hozunk létre néhány formázott cellával:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **Miért fontos:** Ha kihagyja az egyéni stílust, az exportált HTML a böngésző alapértelmezett betűtípusaira fog visszaesni, ezzel aláássa a **hogyan ágyazzuk be a betűtípusokat HTML-be** célját.

## 3. lépés: `HtmlSaveOptions` konfigurálása a betűtípusok beágyazásához

A **hogyan ágyazzuk be a betűtípusokat HTML-be** lényege a `HtmlSaveOptions` osztályban rejlik. Az `EmbedFonts = true` beállítás azt mondja az Aspose.Cells‑nek, hogy a hivatkozott TrueType/OpenType betűtípusokat közvetlenül a generált HTML-be ágyazza be Base64‑kódolt adat‑URI‑ként.

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### Hogyan működik a beágyazás

Amikor az `EmbedFonts` `true`, az Aspose.Cells átvizsgálja a munkafüzet stílusdefinícióit, megkeresi a megfelelő betűtípusfájlokat a rendszeren (vagy az általad hozzáadott `fonts` mappában), beolvassa azok bináris adatait, és egy `<style>` blokkot illeszt be, amely hasonló a következőhöz:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

Mivel a betűtípus adatai közvetlenül a HTML-ben vannak kódolva, az oldal helyesen jelenik meg még olyan gépeken is, ahol a betűtípus nincs telepítve.

## 4. lépés: A munkafüzet mentése HTML‑ként

Most már **mentheti a munkafüzetet HTML‑ként** a beállított opciókkal. Válasszon egy könyvtárat, amelybe az alkalmazás írni tud (pl. `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

A program futtatása egyetlen `report.html` fájlt hoz létre. Nyissa meg bármely modern böngészőben, és láthatja a „Quarterly Sales” fejlécet a **Pacifico** betűtípussal, még akkor is, ha a betűtípus nincs telepítve az operációs rendszerén.

### Várt kimenet

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

Az `src:` attribútum egy hosszú Base64 karakterláncot tartalmaz – ez a beágyazott betűtípus adat, amely lehetővé teszi a **hogyan ágyazzuk be a betűtípusokat HTML-be**.

## 5. lépés: A betűtípus beágyazás ellenőrzése és hibakeresés

1. **Nyissa meg a HTML fájlt Chrome‑ban vagy Edge‑ben.** Ha az egyéni betűtípus megjelenik, a beágyazás sikeres.  
2. **Vizsgálja meg az oldal forrását.** Keresse a Aspose.Cells által generált `@font-face` szabályt.  
3. **Gyakori problémák:**  
   - *Hiányzó betűtípusfájl:* Győződjön meg róla, hogy a betűtípusfájl elérhető. Kifejezetten hozzáadhat egy mappát a keresési úthoz:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *Nagy HTML méret:* Sok betűtípus beágyazása megnövelheti a fájlt. Használja az `ExportToSingleFile = false` beállítást, hogy a betűtípusok külön `.ttf` fájlokként legyenek a resources mappában.

   - *Nem támogatott betűtípusformátum:* Az Aspose.Cells csak TrueType (`.ttf`) és OpenType (`.otf`) betűtípusokat ágyaz be. Más formátumokat konvertáljon beágyazás előtt.

## Teljes működő példa

Az alábbiakban a teljes program látható, amelyet másolhat, beilleszthet és módosítások nélkül futtathat (kivéve az opcionális licencsort).

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

A program futtatása létrehozza a `output/report.html` fájlt. Nyissa meg a fájlt, és láthatja, hogy a **Pacifico** betűtípus helyesen jelenik meg – bemutatva a **hogyan ágyazzuk be a betűtípusokat HTML-be** miközben **a munkafüzetet HTML‑ként mentjük**.

## Gyakran ismételt kérdések

| Kérdés | Válasz |
|----------|--------|
| *Beágyazhatok csak bizonyos betűtípusokat?* | Igen. Állítsa be a `htmlOpt.EmbedAllFonts = false` értéket (újabb verziókban elérhető), és használja a `htmlOpt.FontsToEmbed`‑t a pontos betűtípusnevek felsorolásához. |
| *Mi van, ha több munkalapra kell betűtípusokat beágyazni?* | Állítsa be a `ExportActiveWorksheetOnly = false` értéket, hogy minden munkalap exportálásra kerüljön, és az Aspose.Cells a teljes munkafüzetben használt betűtípusokat beágyazza. |
| *Működnek-e a beágyazott betűtípusok mobil böngészőkben?* | A modern mobil böngészők támogatják a Base64‑kódolt betűtípusokat, így a beágyazott betűtípusok helyesen jelennek meg, amíg a betűtípusformátum támogatott (TTF vagy OTF). |
| *Mekkora lehet a HTML fájl?* | Egy 200 KB-os TrueType betűtípus beágyazása körülbelül ugyanannyit ad hozzá a HTML méretéhez (a Base64 ~33 % többletet jelent). Sok betűtípus esetén fontolja meg a mappába exportálást (`ExportToSingleFile = false`), hogy a HTML könnyű maradjon. |
