# Hogyan ágyazzunk be betűtípusokat Excel HTML‑re mentésekor C#‑ban

A betűtípusok beágyazása Excel munkafüzet HTML‑re mentésekor gyakori igény, amely biztosítja a táblázatok pontos megjelenését a böngészőkben. Ha Excel‑t szeretnél HTML‑be exportálni az eredeti betűtípusok megtartásával, ez az útmutató egy teljes, azonnal futtatható megoldást mutat be.

Megtanulod, hogyan **exportálj Excel‑t HTML‑re**, **konvertálj Excel‑t HTML‑re** beágyazott betűtípusokkal, és hogyan kerüld el a tipikus „hiányzó betűtípus” problémát, amely a kliens gépeken a megjelenést tönkreteszi. Nincs szükség külső eszközökre – csak az Aspose.Cells könyvtárra és néhány C# sorra.

## Előfeltételek

Mielőtt elkezdenéd, győződj meg róla, hogy a következők telepítve vannak:

* .NET 6.0 (vagy újabb).
* Az **Aspose.Cells for .NET** licencelt példánya – a ingyenes próbaverzió teszteléshez elegendő.
* Egy IDE, például a Visual Studio 2022 vagy a VS Code.

Ha már rendelkezel ezekkel, ugorj egyenesen a kódra.

## 1. lépés: Munkafüzet létrehozása és mintaadatok hozzáadása

Először egy kis munkafüzetet generálunk, hogy láthasd a beágyazott betűtípusok hatását. Az alábbi kód létrehoz egy munkalapot, néhány cellát ír bele, és egy egyedi betűtípust alkalmaz.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### Miért adunk hozzá egy egyedi betűtípust

A betűtípusok beágyazása csak akkor számít, ha a munkafüzet olyan betűtípusokat használ, amelyek esetleg nem állnak rendelkezésre a kliens eszközön. Az **Arial** (vagy bármely más betűtípus) kifejezett beállításával ellenőrizhetjük, hogy a HTML‑kimenet valóban tartalmazza-e a betűtípus adatokat.

## 2. lépés: HTML mentési beállítások konfigurálása a betűtípusok beágyazásához

Az Aspose.Cells a `HtmlSaveOptions` osztályt biztosítja. A `EmbedFonts = true` beállítás azt mondja a könyvtárnak, hogy a szükséges betűtípus‑fájlokat közvetlenül a generált HTML‑be ágyazza be Base64‑kódolt adat‑URI‑ként.

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### Mit jelent valójában a „betűtípusok beágyazása HTML‑be”

Amikor az `EmbedFonts` igaz, az Aspose.Cells kinyeri a betűtípus‑fájlokat a rendszerből (vagy a munkafüzet beágyazott betűtárából), és **Base64** karakterláncokká alakítja őket. Ezeket a karakterláncokat egy `<style>` blokkba helyezi a `@font-face` szabály segítségével. Az eredményül kapott HTML bármely eszközön megnyitható anélkül, hogy az eredeti betűtípus telepítve lenne.

## 3. lépés: Munkafüzet mentése HTML‑ként beágyazott betűtípusokkal

Most a munkafüzetet leírjuk a lemezre. A fájl tartalmazni fogja a betűtípus adatokat, így bármely modern böngészőben megnyitva pontosan ugyanazt a tipográfiát mutatja, mint az eredeti Excel‑fájl.

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### Várható eredmény

* Az `embedded.html` a `output` mappában található.
* A fájl Chrome‑ban, Edge‑ben vagy Firefox‑ban megnyitva a munkalap **Arial** szöveggel jelenik meg, még akkor is, ha a böngésző gépén nincs telepítve az Arial.
* A HTML forrásának vizsgálata egy `<style>` blokkot mutat, amely egy `@font-face` szabályt tartalmaz egy hosszú `src: url(data:font/ttf;base64,…)` deklarációval – ez a beágyazott betűtípus.

## 4. lépés: Ellenőrizd, hogy a HTML másik gépen is működik‑e (opcionális)

A beágyazás sikerességének teljes megerősítéséhez:

1. Másold az `output/embedded.html` fájlt egy másik számítógépre (vagy virtuális gépre), amelyen **nincs** telepítve az egyedi betűtípus.
2. Nyisd meg a fájlt egy böngészőben.
3. A elrendezésnek és a tipográfiának meg kell egyeznie az eredeti Excel‑nézettel.

Ha a betűtípus egy általánosabbra vált vissza, ellenőrizd, hogy a betűtípus‑fájl elérhető‑e a build gépen, és hogy van‑e olvasási jogosultságod hozzá.

## Gyakori kérdések és széljegyek

### Növeli-e a beágyazás a fájlméretet?

Igen. Egy TrueType vagy OpenType betűtípus beágyazása **több tíz kilobájt** méretet adhat a HTML‑fájlhoz. Nagy munkafüzeteknél, ahol sok egyedi betűtípus van, fontold meg:

* A betűtípus alhalmazra szűkítését (csak a használt karakterek) – az Aspose.Cells ezt automatikusan megteszi a legtöbb gyakori betűtípus esetén.
* `ExportEmbeddedImages = false` használatát, ha nincs szükség beágyazott képekre.

### Mi van, ha csak bizonyos betűtípusokat szeretnék beágyazni?

A `HtmlSaveOptions` nem biztosít közvetlen fehérlistát, de a megjelenő betűtípusok szabályozhatók a **munkafüzetben használt betűtípusok korlátozásával** a `Save` hívása előtt. Távolítsd el a felesleges betűtípus‑hozzárendeléseket, vagy cseréld le őket szabványos web‑biztonságos betűtípusokra.

### Beágyazhatok‑e betűtípusokat más formátumokba (pl. PDF)?

Az `EmbedFonts` tulajdonság ugyanúgy létezik a `PdfSaveOptions`‑ban is. A koncepció azonos: a betűtípus adat beágyazódik, így a PDF bármely nézőprogramon helyesen jelenik meg.

## Teljes, futtatható példa

Az alábbi teljes programot egyszerűen másold be egy új konzolos projektbe.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

A program futtatása egy **HTML‑fájlt hoz létre, amely tartalmazza a beágyazott Arial betűtípust**, ezáltal garantálva a vizuális hűséget bárhol, ahol a fájlt megnyitják.

## Összegzés

Most már tudod, **hogyan ágyazz be betűtípusokat Excel HTML‑re mentésekor** C#‑ban. A `HtmlSaveOptions.EmbedFonts = true` beállításával megbízhatóan **exportálhatsz Excel‑t HTML‑re** és **konvertálhatsz Excel‑t HTML‑re**, anélkül, hogy a kliens oldalon hiányzó betűtípusok okoznának gondot. Ez a technika elengedhetetlen web‑alapú jelentésekhez, e‑mail‑barát műszerfalakhoz vagy bármely olyan szituációhoz, ahol Excel‑alapú tartalmat HTML‑ként osztasz meg.

### Mi a következő lépés?

* **Testreszabhatod az Aspose.Cells által generált CSS‑t**, hogy illeszkedjen a weboldalad stílusirányelveihez.  
* **Képek beágyazását** szelektíven vezérelheted az `ExportEmbeddedImages` kapcsolóval.  
* **Fedezd fel a többi exportformátumot**, például a PDF‑et vagy az SVG‑t, miközben továbbra is betűtípusokat ágyazol be.  

Nyugodtan kísérletezz különböző betűtípusokkal, nagyobb munkalapokkal vagy több‑lapos munkafüzetekkel. Az `EmbedFonts` jelző minden támogatott kimeneti formátumban ugyanúgy működik, így konzisztens kontrollt biztosít a betűtípus‑beágyazás felett, ahol csak szükséged van rá. Boldog kódolást!
