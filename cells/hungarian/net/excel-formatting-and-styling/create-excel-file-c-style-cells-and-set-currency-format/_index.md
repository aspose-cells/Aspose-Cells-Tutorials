# Excel fájl létrehozása C#‑ban – cellák formázása és pénznem formátum beállítása

Ha professzionális kinézetű **create excel file c#**‑t kell készítenie, ez az útmutató pontosan megmutatja, hogyan formázzuk az excel cellákat és hogyan formázzuk a oszlopot pénznemként. Egy komplett, vég‑től‑végig példát fog látni, amely importál egy `DataTable`‑t, félkövér fejlécet alkalmaz, és `$#,##0.00` számformátumot állít be az ár oszlophoz.

A tutorial mindent lefed, amire szüksége van: a szükséges NuGet csomagokat, a teljes forráskódot, magyarázatot arra, hogy miért fontos minden részlet, valamint tippeket a széljegyek kezeléséhez, például üres sorok vagy különböző nyelvi beállítások esetén. A végére képes lesz egy `.xlsx` fájlt generálni, amelyben a ár oszlop szép formátummal rendelkezik, mindössze néhány C# sorral.

## Prerequisites

- .NET 6.0 vagy újabb (a kód .NET Framework 4.6+‑al is működik)
- Visual Studio 2022 vagy bármelyik kedvenc C# szerkesztő
- **Aspose.Cells for .NET** vagy **GemBox.Spreadsheet** könyvtár (mindkettő támogatja a `ImportTableOptions`‑t). Az alábbi példa **Aspose.Cells**‑et használ, mert egyszerű `StyleArray` tulajdonságot biztosít.
- Alapvető C# gyűjtemények és `DataTable` ismerete

> **Pro tip:** Ha ingyenes alternatívát keres, cserélje le az `Aspose.Cells`‑t a `GemBox.Spreadsheet`‑re. A `DataTable` importálásának API-ja stílusokkal majdnem azonos; csak a névtér és a NuGet csomag nevét kell módosítani.

## Step 1: Install the Excel library

Nyissa meg a NuGet Package Manager‑t, és telepítse a könyvtárat:

```bash
dotnet add package Aspose.Cells
```

> **Why this step?** A könyvtár biztosítja a később használt `Workbook`, `Worksheet`, `Style` és `ImportTableOptions` osztályokat. Nélküle saját kezűleg kellene az Office Open XML formátumot írni, ami hibára hajlamos.

## Step 2: Create a DataTable with sample data

A `DataTable` kényelmes módja a táblázatos adatok tárolásának, mielőtt exportálná őket Excelbe. Ebben a példában két oszlopunk van: *Product* és *Price*.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Explanation:**  
> - `Columns.Add("Price", typeof(double))` azt mondja a táblának, hogy az ár értékeket számként kezelje, ami a későbbi számformátumhoz szükséges.  
> - Néhány sor hozzáadása lehetővé teszi, hogy ellenőrizze a **format column currency** lépést.

## Step 3: Define the styles you want to apply

Létrehozunk egy `Style` objektumokból álló tömböt, amely megfelel az oszlopok sorrendjének. Az első elem a fejléc sorát formázza, a második változatlanul hagyja a *Product* oszlopot, a harmadik pedig pénznem számformátumot alkalmaz.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### Why use a **style array**?

Az `ImportTableOptions.StyleArray` minden oszlophoz egy `Style`‑t rendel. Ez a leghatékonyabb módja a **add number format** és a **style excel cells** egyetlen import műveletben történő elvégzésének, elkerülve a második átfutást a munkalapon.

## Step 4: Configure import options

Most a stílus tömböt kötjük az importálási művelethez. Az `ImportTableOptions` objektum lehetővé teszi, hogy szabályozzuk, a első sor fejléc‑ként legyen-e kezelve.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Note:** `IsFieldNameShown` alapértelmezés szerint `true`, de az explicit beállítás egyértelművé teszi a szándékot a jövőbeli olvasók számára.

## Step 5: Create a workbook, import the table, and save

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### Expected result

Amikor megnyitja a `DataTableWithStyles.xlsx` fájlt:

- Az első sor (fejléc) **félkövér**.
- A *Price* oszlop értékei **$1.20**, **$3.50**, **$0.75** formátumban jelennek meg.
- A *Product* oszlop az alapértelmezett betűtípust megtartja.

Sikeresen **created an excel file c#** egy formázott pénznem oszloppal és stílusos fejléc cellákkal.

## Step 6: Handling common variations and edge cases

### a. Different locale or custom currency symbol

Ha eurót vagy más pénznemet szeretne, cserélje le a beépített `164` formátumot egy egyéni formátumkarakterláncra:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. Adding more columns later

Ha további oszlopokat ad hozzá, bővítse ki a `columnStyles` tömböt ennek megfelelően. Az alapértelmezett stílus megtartásához használjon `null`‑t az adott oszlopnál.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. Empty DataTable

Ha a `DataTable`‑nek nincs sorja, az Aspose.Cells továbbra is létrehozza a fejléc sort. A munkafüzet azonban csak egy sort fog tartalmazni. Az üres fájl elkerülése érdekében ellenőrizze a sorok számát importálás előtt:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Using `GemBox.Spreadsheet` instead of Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

A logika változatlan marad, ami azt mutatja, hogy a tutorial **format column currency** független a használt könyvtártól.

## Step 7: Verify the file programmatically (optional)

Megnyithatja a generált munkafüzetet, és ellenőrizheti, hogy a számformátum helyesen lett‑e alkalmazva – hasznos egységtesztekhez.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```
