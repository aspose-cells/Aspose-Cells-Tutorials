# Hogyan hozzunk létre Excel munkafüzetet C#‑ban egyedi formázással és mentsük XLSX‑ként

Ha **create Excel workbook C#**‑ra van szükséged, amely adatot importál, egyedi számformátumot alkalmaz, és megváltoztatja a cella betűszínét, ez a bemutató pontosan megmutatja, hogyan. Kész, futtatható példát kapsz, amely néhány másodperc alatt egy formázott `StyleArrayImport.xlsx` fájlt hoz létre.

Az Excel C#‑beli használata gyakran ismétlődő manuális lépéseket igényel – formátumok definiálása, színek alkalmazása és a fájl helyes mentésének megjegyzése. A útmutató végére mindezeket a feladatokat automatizálod, így az adatokra koncentrálhatsz a felhasználói felület helyett.

Megtanulod, hogyan:

* importálj egy `DataTable`‑t egy munkalapra,
* használj egy `StyleArray`‑t a **apply custom number format** és a **change cell font color** alkalmazásához,
* **save workbook as XLSX** egyetlen metódushívással,
* és ellenőrizd, hogy a **format imported data excel** pontosan úgy jelenik meg, ahogy szeretnéd.

Az egyetlen előfeltétel a **Aspose.Cells for .NET** könyvtárra való hivatkozás (vagy bármely kompatibilis API, amely biztosítja a `Workbook`, `Worksheet` és `StyleArray` osztályokat). A kód .NET 6+ célra készült, de korábbi verziók kisebb módosításokkal is működnek.

## Step 1: Prepare the sample DataTable

Először hozz létre egy `DataTable`‑t, amely a szokásos adatbázisból vagy más forrásból származó adatokat utánozza. A táblázat tartalmaz egy **Name** oszlopot (string) és egy **Amount** oszlopot (decimal), amelyet később formázni fogunk.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Why this matters:** A `DataTable` használatával az importálási logikát függetlené teheted az adatforrástól, ami gyakori minta jelentéskészítéskor adatbázisokból, CSV‑fájlokból vagy API‑kból.

## Step 2: Define a StyleArray to **apply custom number format** and **change cell font color**

A `StyleArray` lehetővé teszi, hogy formázási utasításokat csomagolj, amelyeket minden, a `DataTable`‑ből importált cellára alkalmazunk. Ebben a példában:

* a `Number` értékét `#,##0.00`‑ra állítjuk – egy tipikus könyvelési formátum ezres elválasztóval,
* a `FontColor` értékét `Color.Blue`‑ra állítjuk – a számok kiemeléséhez.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**Why use a StyleArray?** A stílus importáláskor történő alkalmazása elkerüli a munkalap második átfutását, ami javítja a teljesítményt nagy adatkészletek esetén.

---

## Step 3: **Create Excel workbook C#** – instantiate Workbook and get the first Worksheet

Most egy üres munkafüzetet hozunk létre, és lekérjük az első munkalap (0‑s index) hivatkozását. Ez a munkalap lesz a célpontja az importált adatainknak.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Explanation:** A `Workbook` az egész Excel‑fájlt képviseli, míg a `Worksheet` egyetlen lapot. Az alapértelmezett munkafüzet egy lapot tartalmaz, ami a legtöbb egyszerű jelentéshez elegendő.

---

## Step 4: Import the DataTable using the **StyleArray** to **format imported data excel**

Az `ImportDataTable` metódus a táblázat sorait és oszlopait a munkalapba másolja, az `A1` cellától (0‑s sor, 0‑s oszlop) kezdve. A `true` argumentum azt mondja a metódusnak, hogy vegye fel az oszlopfejléceket is. Mivel átadjuk a `styleArray`‑t, minden importált cella megkapja az egyedi számformátumot és a betűszínt.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**What happens under the hood:** Az Aspose.Cells minden soron végigiterál, kiírja az értéket, majd alkalmazza a `styleArray`‑ben definiált stílust. A számok vesszővel és két tizedesjeggyel jelennek meg, a szöveg pedig kék színben jelenik meg.

## Step 5: **Save workbook as XLSX** – write the file to disk

Végül a munkafüzetet egy `.xlsx` fájlba mentjük. A fájl útvonalát a saját géped bármely írható könyvtárára módosíthatod.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Result verification:** Nyisd meg a generált fájlt Excelben. Látnod kell a három adatsort, a **Amount** oszlopot vesszőkkel, két tizedesjeggyel formázva, és kék betűszínnel megjelenítve. Ez megerősíti, hogy a **format imported data excel** lépés sikeres volt.

## Full Working Example

Másold az alábbi blokkot egy új konzolprojektbe, és futtasd. További kód nem szükséges.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Expected output in the console:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

Nyisd meg a fájlt, és ellenőrizd, hogy a **Amount** oszlop `1,234.56`‑hoz hasonló értékeket mutat kék betűszínben.

## Common Questions & Edge Cases

| Kérdés | Válasz |
|----------|--------|
| *Alkalmazhatok-e különböző formátumokat az egyes oszlopokra?* | Igen. Az importálás után lekérheted az oszlop `Style` objektumát (`worksheet.Cells.Columns[1].Style`), és beállíthatsz egy másik `Number` vagy `FontColor` értéket. |
| *Mi van, ha számok helyett dátumokat kell formáznom?* | Állítsd be a `styleArray.Number = "mm-dd-yyyy"`‑t, és opcionálisan a `styleArray.FontColor`‑t a dátumcellákhoz. |
| *Látható-e a kék betűszín a sötét Excel‑témákon?* | A kék nehezen olvasható lehet sötét háttéren. Használj világosabb árnyalatot (`Color.LightBlue`) vagy kontrasztos színt (`Color.Black`). |
| *Hogyan importáljak nagyon nagy DataTable‑t (több százezer sorral)?* | Használd az `ImportDataTable` metódus `ImportDataTableOptions` túlterhelését adatfolyamolvasáshoz, vagy oszd fel az importálást több munkalapra, hogy az Excel sorlimitje (1 048 576 sor) ne legyen átlépve. |
| *Exportálhatok CSV‑be az XLSX helyett?* | Cseréld a `SaveFormat.Xlsx`‑t `SaveFormat.Csv`‑ra. Figyelj, hogy a formázási információk (számformátum, betűszín) elvesznek a CSV‑ben, mivel az egyszerű szöveges formátum. |

## Tips for Production Use

* **Pro tip:** Cache-eld a `Style` objektumot, ha ugyanazt a formázást sok munkalapra kell alkalmaznod; minden importáláshoz új `StyleArray` létrehozása többletterhet jelent.
* **Figyelj a kultúrakülönbségekre:** A `Number` minta `#,##0.00` az invariáns kultúrára épül. Ha helyi specifikus elválasztókat szeretnél, használd a `NumberFormatInfo`‑t, vagy hagyd, hogy Excel a felhasználó regionális beállításai alapján kezelje.
* **Hibakezelés:** Tekerd a `Save` hívást try‑catch blokkba, hogy kezeld az I/O‑kivételt (pl. nem elegendő jogosultság vagy zárolt fájl).
