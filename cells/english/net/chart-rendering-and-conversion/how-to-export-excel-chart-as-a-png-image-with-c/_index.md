# How to export Excel chart as a PNG image with C#

If you need to **how to export Excel chart** into a portable image, this guide shows a complete, ready‑to‑run solution. Using Aspose.Cells you can **save Excel chart image** in PNG format with just three lines of code, and the tutorial also explains how to **set image format png** and **save Excel picture file** safely.

You’ll finish this article with a runnable program that loads a workbook, renders the first chart, and writes a `pivot.png` file to disk. No additional tools, no manual copy‑paste—just clean C# code you can drop into any .NET project.

## Prerequisites

Before you start, make sure you have:

* .NET 6.0 SDK or later (the code also works with .NET Framework 4.6+)
* Visual Studio 2022 or any C# editor
* An Aspose.Cells for .NET license (or a temporary evaluation key)
* An Excel file (`pivot.xlsx`) that contains at least one chart on the first worksheet

These items are the only external dependencies; the tutorial does not require Office installed on the machine.

## Step 1: Install Aspose.Cells

Open a terminal in your project folder and run:

```bash
dotnet add package Aspose.Cells
```

The package adds the `Aspose.Cells` namespace, which provides the `Workbook`, `ImageOrPrintOptions`, and other classes needed to **save Excel chart image**.

## Step 2: Create a minimal console program

Create a new console app (`dotnet new console -n ExportChartDemo`) and replace the autogenerated `Program.cs` with the following code. The program demonstrates **how to export Excel chart** and includes comments that explain each decision.

```csharp
using System;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // Required for ImageOrPrintOptions
using System.Drawing.Imaging;  // Provides ImageFormat enum

namespace ExportChartDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            // -----------------------------------------------------------------
            // 1️⃣ Load the workbook that contains the pivot chart
            // -----------------------------------------------------------------
            // Replace the path with the actual location of your Excel file.
            string workbookPath = @"YOUR_DIRECTORY\pivot.xlsx";
            Workbook workbook = new Workbook(workbookPath);

            // -----------------------------------------------------------------
            // 2️⃣ Set up image export options (PNG format)
            // -----------------------------------------------------------------
            // This is where we **set image format png** for the exported picture.
            ImageOrPrintOptions imageOptions = new ImageOrPrintOptions
            {
                ImageFormat = ImageFormat.Png,
                // Optional: control the resolution (DPI) of the output image.
                // Higher DPI yields larger files but sharper charts.
                HorizontalResolution = 300,
                VerticalResolution = 300
            };

            // -----------------------------------------------------------------
            // 3️⃣ Render the first picture (the chart) on the first worksheet
            // -----------------------------------------------------------------
            // Aspose.Cells stores charts as Picture objects inside the worksheet.
            // The index [0] refers to the first chart; adjust if you have multiple.
            Worksheet sheet = workbook.Worksheets[0];
            if (sheet.Pictures.Count == 0)
            {
                Console.WriteLine("No pictures found on the first worksheet.");
                return;
            }

            // Render the picture to a PNG file.
            string outputPath = @"YOUR_DIRECTORY\pivot.png";
            sheet.Pictures[0].RenderToImage(imageOptions, outputPath);

            Console.WriteLine($"Chart exported successfully to: {outputPath}");
        }
    }
}
```

### Why each part matters

* **Loading the workbook** – `Workbook` parses the `.xlsx` file without needing Microsoft Excel installed.
* **ImageOrPrintOptions** – This object controls the output format. Setting `ImageFormat = ImageFormat.Png` **sets image format png**, which is lossless and widely supported.
* **RenderToImage** – The `RenderToImage` method converts the chart (a `Picture` object) into an image file. The method also handles scaling, DPI, and transparency automatically.
* **Error handling** – The check for `sheet.Pictures.Count == 0` prevents a runtime exception if the worksheet has no charts, a common edge case when users point to the wrong sheet.

## Step 3: Run the program and verify the result

1. Build the project: `dotnet build`.
2. Execute it: `dotnet run --project ExportChartDemo`.

If everything is configured correctly, you’ll see:

```
Chart exported successfully to: YOUR_DIRECTORY\pivot.png
```

Open `pivot.png` with any image viewer. You should see the exact visual representation of the Excel chart, confirming that you have successfully **saved Excel picture file**.

## Step 4: Advanced options – exporting multiple charts

If your workbook contains more than one chart, you can loop through the `Pictures` collection:

```csharp
for (int i = 0; i < sheet.Pictures.Count; i++)
{
    string chartPath = $@"YOUR_DIRECTORY\chart_{i + 1}.png";
    sheet.Pictures[i].RenderToImage(imageOptions, chartPath);
    Console.WriteLine($"Chart {i + 1} saved to {chartPath}");
}
```

This pattern lets you **save Excel chart image** for every chart on the sheet, which is handy for reporting pipelines.

## Common pitfalls and how to avoid them

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| `ArgumentOutOfRangeException` on `Pictures[0]` | The worksheet has no chart or the chart is on a different sheet. | Verify the sheet index (`Worksheets[0]`) and ensure the chart exists. Use `Worksheets["SheetName"]` if needed. |
| Exported image is blurry | DPI set too low (default 96). | Increase `HorizontalResolution` and `VerticalResolution` in `ImageOrPrintOptions`. |
| PNG file is empty or corrupted | Missing license causing evaluation restrictions. | Apply a valid Aspose.Cells license before loading the workbook (`License license = new License(); license.SetLicense("Aspose.Total.lic");`). |
| File path errors (`FileNotFoundException`) | Incorrect `YOUR_DIRECTORY` placeholder. | Use absolute paths or `Path.Combine(Environment.CurrentDirectory, "pivot.xlsx")`. |

Addressing these issues ensures a smooth **save excel picture file** experience.

## Pro tip: Export directly to a memory stream

Sometimes you need the image in memory (e.g., to upload to a web API) instead of writing to disk:

```csharp
using (var ms = new MemoryStream())
{
    sheet.Pictures[0].RenderToImage(imageOptions, ms);
    // ms now contains the PNG bytes – you can send them over HTTP, store in DB, etc.
}
```

The same **set image format png** logic applies; you just replace the file path with a stream.
