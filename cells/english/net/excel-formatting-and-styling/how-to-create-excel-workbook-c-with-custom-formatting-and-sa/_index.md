# How to create Excel workbook C# with custom formatting and save as XLSX

If you need to **create Excel workbook C#** that imports data, applies a custom number format, and changes the cell font color, this tutorial shows you exactly how. You’ll get a ready‑to‑run example that produces a styled `StyleArrayImport.xlsx` file in seconds.

Working with Excel from C# often involves repetitive manual steps—defining formats, applying colors, and remembering to save the file correctly. By the end of this guide you’ll automate all of those tasks, so you can focus on the data instead of the UI.

You’ll learn how to:

* import a `DataTable` into a worksheet,
* use a `StyleArray` to **apply custom number format** and **change cell font color**,
* **save workbook as XLSX** with a single method call,
* and verify that the **format imported data excel** appears exactly as intended.

The only prerequisite is a reference to the **Aspose.Cells for .NET** library (or any compatible API that provides `Workbook`, `Worksheet`, and `StyleArray`). The code targets .NET 6+, but earlier versions work with minor adjustments.

## Step 1: Prepare the sample DataTable

First, create a `DataTable` that mimics the data you would normally retrieve from a database or another source. The table includes a **Name** column (string) and an **Amount** column (decimal) that we will format later.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Why this matters:** Using a `DataTable` lets you keep the import logic independent of the data source, which is a common pattern when generating reports from databases, CSV files, or APIs.

---

## Step 2: Define a StyleArray to **apply custom number format** and **change cell font color**

`StyleArray` lets you bundle formatting instructions that will be applied to every cell imported from the `DataTable`. In this example we:

* set `Number` to `#,##0.00` – a typical accounting format with thousands separators,
* set `FontColor` to `Color.Blue` – making the numbers stand out.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**Why use a StyleArray?** Applying a style at import time avoids a second pass over the worksheet, which improves performance for large data sets.

---

## Step 3: **Create Excel workbook C#** – instantiate Workbook and get the first Worksheet

Now we create an empty workbook and obtain a reference to the first worksheet (index 0). This worksheet becomes the destination for our imported data.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Explanation:** `Workbook` represents the entire Excel file, while `Worksheet` represents a single tab. The default workbook contains one sheet, which is sufficient for most simple reports.

---

## Step 4: Import the DataTable using the **StyleArray** to **format imported data excel**

The `ImportDataTable` method copies the table rows and columns into the worksheet, starting at cell `A1` (row 0, column 0). The `true` argument tells the method to include column headers. Because we pass `styleArray`, each imported cell receives the custom number format and font color.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**What happens under the hood:** Aspose.Cells iterates over each row, writes the value, and then applies the style defined in `styleArray`. Numbers appear with commas and two decimal places, and the text is rendered in blue.

---

## Step 5: **Save workbook as XLSX** – write the file to disk

Finally, persist the workbook to an `.xlsx` file. You can change the path to any writable directory on your machine.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Result verification:** Open the generated file in Excel. You should see the three rows of data, the **Amount** column formatted with commas, two decimal places, and displayed in blue font. This confirms that the **format imported data excel** step succeeded.

## Full Working Example

Copy the entire block below into a new console project and run it. No additional code is required.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Expected output in the console:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

Open the file and verify that the **Amount** column shows values like `1,234.56` in blue font.

## Common Questions & Edge Cases

| Question | Answer |
|----------|--------|
| *Can I apply different formats to individual columns?* | Yes. After importing, retrieve the column’s `Style` object (`worksheet.Cells.Columns[1].Style`) and set a different `Number` or `FontColor`. |
| *What if I need to format dates instead of numbers?* | Set `styleArray.Number = "mm-dd-yyyy"` and optionally `styleArray.FontColor` for date cells. |
| *Is the blue font visible on dark Excel themes?* | Blue can be hard to read on dark backgrounds. Use a lighter shade (`Color.LightBlue`) or a contrasting color (`Color.Black`). |
| *How do I import a very large DataTable (hundreds of thousands of rows)?* | Use `ImportDataTable` with the `ImportDataTableOptions` overload to stream data, or split the import into multiple worksheets to stay within Excel’s row limit (1,048,576 rows). |
| *Can I export to CSV instead of XLSX?* | Replace `SaveFormat.Xlsx` with `SaveFormat.Csv`. Note that formatting information (number format, font color) is lost in CSV because it’s a plain‑text format. |

## Tips for Production Use

* **Pro tip:** Cache the `Style` object if you need to apply the same formatting to many worksheets; creating a new `StyleArray` for each import adds overhead.
* **Watch out for culture differences:** The `Number` pattern `#,##0.00` follows the invariant culture. If you need locale‑specific separators, use `NumberFormatInfo` or let Excel handle it based on the user’s regional settings.
* **Error handling:** Wrap the `Save` call in a try‑catch block to handle I/O exceptions (e.g., insufficient permissions or locked files).
