# How to embed fonts in HTML when saving a workbook

If you need to **how to embed fonts in HTML** while exporting a spreadsheet, this tutorial shows you a complete, ready‑to‑run solution. Whether you are building a reporting portal or a client‑side analytics view, embedding fonts guarantees that the rendered HTML looks exactly like the original workbook, regardless of the viewer’s installed fonts.

You’ll also learn the best way to **save workbook as HTML** using Aspose.Cells, see common pitfalls, and get tips for handling large workbooks or custom font files. No external documentation is required—everything you need is in this guide.

## Prerequisites

Before you start, make sure you have:

- .NET 6.0 or later (the code also works with .NET Framework 4.7+)
- A valid Aspose.Cells for .NET license (or you can use the free evaluation mode)
- Basic C# knowledge and an IDE such as Visual Studio 2022
- The TrueType (.ttf) or OpenType (.otf) font files you want to embed (they must be accessible to the running process)

## Step 1: Set up the project and import Aspose.Cells

Create a new console application and add the Aspose.Cells NuGet package:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

Then open **Program.cs** and add the required `using` directives:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **Pro tip:** Place your custom fonts in a folder named `fonts` inside the project root. This keeps the solution portable and makes it easy to reference them later.

## Step 2: Create or load a workbook

For demonstration, we’ll create a simple workbook with a few styled cells:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **Why this matters:** If you skip the custom style, the exported HTML will fall back to the browser’s default fonts, defeating the purpose of **how to embed fonts in HTML**.

## Step 3: Configure `HtmlSaveOptions` to embed fonts

The core of **how to embed fonts in HTML** lies in the `HtmlSaveOptions` class. Setting `EmbedFonts = true` tells Aspose.Cells to embed any referenced TrueType/OpenType fonts directly into the generated HTML as Base64‑encoded data URIs.

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### How the embedding works

When `EmbedFonts` is `true`, Aspose.Cells scans the workbook’s style definitions, locates the corresponding font files on the system (or in the `fonts` folder you added), reads their binary data, and injects a `<style>` block similar to:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

Because the font data is encoded directly in the HTML, the page renders correctly even on machines that do not have the font installed.

## Step 4: Save the workbook as HTML

Now you can **save workbook as HTML** with the configured options. Choose a directory that the application can write to (e.g., `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

Running the program produces a single `report.html` file. Open it in any modern browser and you’ll see the “Quarterly Sales” header rendered with the **Pacifico** font, even if the font isn’t installed on your OS.

The `src:` attribute contains a long Base64 string—this is the embedded font data that enables **how to embed fonts in HTML**.

## Step 5: Verify font embedding and troubleshoot

1. **Open the HTML file in Chrome or Edge.** If the custom font appears, embedding succeeded.  
2. **Inspect the page source.** Look for the `@font-face` rule generated by Aspose.Cells.  
3. **Common issues:**  
   - *Missing font file:* Ensure the font file is reachable. You can explicitly add a folder to the search path:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *Large HTML size:* Embedding many fonts can bloat the file. Use `ExportToSingleFile = false` to keep fonts as separate `.ttf` files in a resources folder.

   - *Unsupported font format:* Aspose.Cells only embeds TrueType (`.ttf`) and OpenType (`.otf`). Convert other formats before embedding.

## Full working example

Below is the complete program you can copy, paste, and run without modifications (except for the optional license line).

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

Running this program creates `output/report.html`. Open the file, and you’ll see the **Pacifico** font rendered correctly—demonstrating **how to embed fonts in HTML** while **saving workbook as HTML**.

## Frequently asked questions

| Question | Answer |
|----------|--------|
| *Can I embed only specific fonts?* | Yes. Set `htmlOpt.EmbedAllFonts = false` (available in newer versions) and use `htmlOpt.FontsToEmbed` to list the exact font names. |
| *What if I need to embed fonts for multiple worksheets?* | Set `ExportActiveWorksheetOnly = false` so every worksheet is exported, and Aspose.Cells will embed fonts used across the whole workbook. |
| *Will embedded fonts work on mobile browsers?* | Modern mobile browsers support Base64‑encoded fonts, so the embedded fonts render correctly as long as the font format is supported (TTF or OTF). |
| *How large can the HTML file become?* | Embedding a 200 KB TrueType font adds roughly the same amount to the HTML size (Base64 adds ~33 % overhead). For many fonts, consider exporting to a folder (`ExportToSingleFile = false`) to keep the HTML lightweight. |
