# Cách xuất bảng tổng hợp (pivot) dưới dạng hình ảnh bằng Aspose.Cells trong C#

Nếu bạn cần **cách xuất pivot** dữ liệu thành một hình ảnh có thể di động, Aspose.Cells giúp quá trình này trở nên đơn giản. Hướng dẫn này chỉ cho bạn cách xuất bảng tổng hợp dưới dạng tệp PNG, để bạn có thể nhúng chúng vào báo cáo, email hoặc tài liệu mà không cần Excel trên máy đích.

Việc xuất pivot dưới dạng hình ảnh loại bỏ các vấn đề định dạng phụ thuộc vào phiên bản và cho phép các bên không chuyên kỹ thuật xem phân tích ngay lập tức. Chúng tôi sẽ bao phủ mọi thứ từ thiết lập dự án đến việc render hình ảnh **export pivot table image** cuối cùng, và cũng sẽ giải thích cách **save pivot as image** để tái sử dụng sau này.

## Cách xuất bảng tổng hợp dưới dạng hình ảnh với Aspose.Cells

Dưới đây là ví dụ hoàn chỉnh, có thể chạy được, tải một workbook, làm mới pivot, cấu hình tùy chọn hình ảnh và ghi tệp đầu ra. Mỗi bước đều có lời giải thích ngắn để bạn hiểu *tại sao* mã được viết như vậy, không chỉ *cái gì* nó làm.

### 1. Thiết lập môi trường Aspose.Cells

1. Cài đặt gói NuGet:

   ```bash
   dotnet add package Aspose.Cells
   ```

2. Thêm các chỉ thị `using` cần thiết ở đầu tệp C# của bạn:

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **Mẹo chuyên nghiệp:** Nhắm tới .NET 6 hoặc cao hơn để tận dụng các cải tiến hiệu năng mới nhất trong Aspose.Cells.

### 2. Tải workbook và xác định bảng tổng hợp

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*Lý do quan trọng:* Lớp `Workbook` phân tích tệp XLSX và cho bạn truy cập vào tất cả các worksheet. Việc chọn đúng worksheet là thiết yếu vì một workbook có thể chứa nhiều pivot.

### 3. Làm mới bảng tổng hợp để nắm bắt dữ liệu nguồn mới nhất

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

Làm mới đảm bảo rằng bất kỳ thay đổi nào đối với phạm vi nguồn sau khi tệp được lưu sẽ được phản ánh trong hình ảnh đã render. Bỏ qua bước này có thể tạo ra hình ảnh lỗi thời hoặc không chính xác.

### 4. Cấu hình tùy chọn xuất hình ảnh (export pivot table image)

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

Đối tượng `ImageOrPrintOptions` cho phép bạn kiểm soát định dạng, độ phân giải và các chi tiết render khác. PNG là lựa chọn phổ biến nhất cho đồ họa sắc nét, tương thích web, nhưng bạn cũng có thể chuyển sang `ImageFormat.Jpeg` nếu lo ngại về kích thước tệp.

### 5. Render và **save pivot as image**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

`RenderToImage` thực hiện phần công việc nặng: nó vẽ pivot chính xác như trong Excel và ghi dữ liệu PNG nhị phân ra đĩa. Phương thức trả về `void`, vì vậy bạn có thể yên tâm rằng tệp đã tồn tại sau khi gọi hoàn tất mà không cần kiểm tra thêm.

#### Kết quả mong đợi

Sau khi chương trình chạy, bạn sẽ thấy tệp `Pivot.png` trong thư mục đã chỉ định. Mở tệp sẽ hiển thị một ảnh chụp chính xác của bảng tổng hợp gốc, bao gồm tiêu đề cột, tổng dòng và bất kỳ định dạng nào đã áp dụng.

### 6. Các biến thể phổ biến và trường hợp đặc biệt

| Kịch bản | Điều chỉnh |
|----------|------------|
| **Pivot lớn** (nhiều hàng/cột) | Tăng `HorizontalResolution` và `VerticalResolution` lên 300 dpi để có đầu ra rõ nét hơn. |
| **Định dạng tùy chỉnh** (màu nền, phông chữ) | Đảm bảo các định nghĩa style của workbook được tải trước khi gọi `Refresh()`. |
| **Nhiều pivot** trong một sheet | Duyệt qua `worksheet.PivotTables` và gọi `RenderToImage` cho mỗi pivot, sử dụng tên tệp riêng. |
| **Xuất sang JPEG** thay vì PNG | Thay đổi `ImageFormat = ImageFormat.Jpeg` và tùy chọn đặt `Quality` trên đối tượng `JpegSaveOptions`. |

Các biến thể này cho phép bạn **export pivot table image** ở định dạng chính xác mà hệ thống downstream của bạn yêu cầu.

## Mã nguồn đầy đủ để sao chép nhanh

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

Chạy chương trình sẽ tạo ra tệp PNG như hình trên, hoàn thành quy trình **save pivot as image** trong chưa đầy một phút.

* **Áp dụng theme tùy chỉnh** – chỉnh sửa bộ sưu tập style của workbook trước khi render để phù hợp với thương hiệu công ty.
