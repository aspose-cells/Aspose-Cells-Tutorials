# Cách nhúng phông chữ vào HTML khi lưu một workbook

Nếu bạn cần **how to embed fonts in HTML** khi xuất một bảng tính, hướng dẫn này sẽ cho bạn một giải pháp hoàn chỉnh, sẵn sàng chạy. Dù bạn đang xây dựng một cổng báo cáo hay một giao diện phân tích phía khách hàng, việc nhúng phông chữ đảm bảo rằng HTML được hiển thị trông giống hệt workbook gốc, bất kể phông chữ đã cài đặt trên máy người xem.

Bạn cũng sẽ học cách tốt nhất để **save workbook as HTML** bằng Aspose.Cells, xem các lỗi thường gặp, và nhận các mẹo để xử lý workbook lớn hoặc các tệp phông chữ tùy chỉnh. Không cần tài liệu bên ngoài—tất cả những gì bạn cần đều có trong hướng dẫn này.

## Yêu cầu trước

- .NET 6.0 hoặc mới hơn (mã cũng hoạt động với .NET Framework 4.7+)
- Giấy phép Aspose.Cells for .NET hợp lệ (hoặc bạn có thể sử dụng chế độ đánh giá miễn phí)
- Kiến thức cơ bản về C# và một IDE như Visual Studio 2022
- Các tệp phông chữ TrueType (.ttf) hoặc OpenType (.otf) mà bạn muốn nhúng (phải có thể truy cập được bởi tiến trình đang chạy)

## Bước 1: Thiết lập dự án và nhập Aspose.Cells

Tạo một ứng dụng console mới và thêm gói NuGet Aspose.Cells:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

Sau đó mở **Program.cs** và thêm các chỉ thị `using` cần thiết:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **Mẹo chuyên nghiệp:** Đặt các phông chữ tùy chỉnh của bạn trong một thư mục có tên `fonts` ở trong thư mục gốc của dự án. Điều này giúp giải pháp di động và dễ dàng tham chiếu chúng sau này.

## Bước 2: Tạo hoặc tải workbook

Để minh họa, chúng ta sẽ tạo một workbook đơn giản với một vài ô đã được định dạng:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **Tại sao điều này quan trọng:** Nếu bạn bỏ qua kiểu tùy chỉnh, HTML xuất ra sẽ quay lại phông chữ mặc định của trình duyệt, làm mất mục đích của **how to embed fonts in HTML**.

## Bước 3: Cấu hình `HtmlSaveOptions` để nhúng phông chữ

Cốt lõi của **how to embed fonts in HTML** nằm trong lớp `HtmlSaveOptions`. Thiết lập `EmbedFonts = true` cho Aspose.Cells biết sẽ nhúng bất kỳ phông chữ TrueType/OpenType nào được tham chiếu trực tiếp vào HTML được tạo dưới dạng URI dữ liệu được mã hoá Base64.

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### Cách hoạt động của việc nhúng

Khi `EmbedFonts` là `true`, Aspose.Cells sẽ quét các định nghĩa kiểu của workbook, tìm các tệp phông chữ tương ứng trên hệ thống (hoặc trong thư mục `fonts` mà bạn đã thêm), đọc dữ liệu nhị phân của chúng, và chèn một khối `<style>` tương tự như:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

Vì dữ liệu phông chữ được mã hoá trực tiếp trong HTML, trang sẽ hiển thị đúng ngay cả trên các máy không cài đặt phông chữ đó.

## Bước 4: Lưu workbook dưới dạng HTML

Bây giờ bạn có thể **save workbook as HTML** với các tùy chọn đã cấu hình. Chọn một thư mục mà ứng dụng có thể ghi vào (ví dụ, `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

Chạy chương trình sẽ tạo ra một tệp `report.html` duy nhất. Mở nó trong bất kỳ trình duyệt hiện đại nào và bạn sẽ thấy tiêu đề “Quarterly Sales” được hiển thị với phông chữ **Pacifico**, ngay cả khi phông chữ không được cài đặt trên hệ điều hành của bạn.

### Kết quả mong đợi

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

Thuộc tính `src:` chứa một chuỗi Base64 dài—đây là dữ liệu phông chữ được nhúng cho phép **how to embed fonts in HTML**.

## Bước 5: Xác minh việc nhúng phông chữ và khắc phục sự cố

1. **Mở tệp HTML trong Chrome hoặc Edge.** Nếu phông chữ tùy chỉnh xuất hiện, việc nhúng đã thành công.  
2. **Kiểm tra mã nguồn trang.** Tìm quy tắc `@font-face` được Aspose.Cells tạo ra.  
3. **Các vấn đề thường gặp:**  
   - *Thiếu tệp phông chữ:* Đảm bảo tệp phông chữ có thể truy cập được. Bạn có thể thêm một thư mục vào đường dẫn tìm kiếm một cách rõ ràng:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *Kích thước HTML lớn:* Nhúng nhiều phông chữ có thể làm tăng kích thước tệp. Sử dụng `ExportToSingleFile = false` để giữ phông chữ dưới dạng các tệp `.ttf` riêng trong thư mục tài nguyên.

   - *Định dạng phông chữ không được hỗ trợ:* Aspose.Cells chỉ nhúng TrueType (`.ttf`) và OpenType (`.otf`). Chuyển đổi các định dạng khác trước khi nhúng.

## Ví dụ hoạt động đầy đủ

Dưới đây là chương trình hoàn chỉnh mà bạn có thể sao chép, dán và chạy mà không cần chỉnh sửa (ngoại trừ dòng giấy phép tùy chọn).

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

Chạy chương trình này sẽ tạo `output/report.html`. Mở tệp, và bạn sẽ thấy phông chữ **Pacifico** được hiển thị đúng—chứng minh **how to embed fonts in HTML** khi **save workbook as HTML**.

## Câu hỏi thường gặp

| Question | Answer |
|----------|--------|
| *Tôi có thể nhúng chỉ các phông chữ cụ thể không?* | Có. Đặt `htmlOpt.EmbedAllFonts = false` (có sẵn trong các phiên bản mới hơn) và sử dụng `htmlOpt.FontsToEmbed` để liệt kê các tên phông chữ chính xác. |
| *Nếu tôi cần nhúng phông chữ cho nhiều worksheet thì sao?* | Đặt `ExportActiveWorksheetOnly = false` để mọi worksheet đều được xuất, và Aspose.Cells sẽ nhúng các phông chữ được sử dụng trong toàn bộ workbook. |
| *Phông chữ được nhúng có hoạt động trên trình duyệt di động không?* | Các trình duyệt di động hiện đại hỗ trợ phông chữ được mã hoá Base64, vì vậy các phông chữ được nhúng sẽ hiển thị đúng miễn là định dạng phông chữ được hỗ trợ (TTF hoặc OTF). |
| *Kích thước tệp HTML có thể lớn đến mức nào?* | Nhúng một phông chữ TrueType 200 KB sẽ tăng kích thước HTML khoảng tương đương (Base64 thêm ~33 % overhead). Đối với nhiều phông chữ, hãy cân nhắc xuất ra một thư mục (`ExportToSingleFile = false`) để giữ HTML nhẹ. |
