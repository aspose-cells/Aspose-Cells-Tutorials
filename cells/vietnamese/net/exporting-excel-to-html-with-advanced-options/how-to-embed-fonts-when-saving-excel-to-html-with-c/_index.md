# Cách nhúng phông chữ khi lưu Excel sang HTML bằng C#

Cách nhúng phông chữ khi lưu một workbook Excel sang HTML là yêu cầu phổ biến để giữ nguyên giao diện của bảng tính trên các trình duyệt. Nếu bạn cần xuất Excel sang HTML đồng thời giữ nguyên các kiểu chữ gốc, hướng dẫn này sẽ cung cấp cho bạn một giải pháp hoàn chỉnh, sẵn sàng chạy.

Bạn sẽ học cách **xuất Excel sang HTML**, **chuyển đổi Excel sang HTML** với phông chữ được nhúng, và tránh vấn đề “phông chữ thiếu” thường gây lỗi bố cục trên máy khách. Không cần công cụ bên ngoài—chỉ cần thư viện Aspose.Cells và một vài dòng C#.

## Yêu cầu trước

Trước khi bắt đầu, hãy chắc chắn rằng bạn đã có:

* .NET 6.0 (hoặc mới hơn) đã được cài đặt.
* Bản sao có giấy phép của **Aspose.Cells for .NET** – bản dùng thử miễn phí cũng đủ để thử nghiệm.
* Một IDE như Visual Studio 2022 hoặc VS Code.

Nếu bạn đã có những thứ trên, có thể chuyển ngay sang phần code.

## Bước 1: Tạo workbook và thêm dữ liệu mẫu

Đầu tiên chúng ta tạo một workbook nhỏ để bạn có thể thấy hiệu ứng của phông chữ được nhúng. Đoạn code dưới đây tạo một worksheet, ghi một vài ô và áp dụng một phông chữ tùy chỉnh.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### Tại sao chúng ta thêm phông chữ tùy chỉnh

Nhúng phông chữ chỉ có ý nghĩa khi workbook sử dụng các phông chữ có thể không có trên thiết bị của khách hàng. Bằng cách đặt **Arial** (hoặc bất kỳ phông chữ nào khác) một cách rõ ràng, chúng ta có thể xác minh rằng đầu ra HTML thực sự chứa dữ liệu phông chữ.

## Bước 2: Cấu hình tùy chọn lưu HTML để nhúng phông chữ

Aspose.Cells cung cấp lớp `HtmlSaveOptions`. Đặt `EmbedFonts = true` sẽ yêu cầu thư viện nhúng các tệp phông chữ cần thiết trực tiếp vào HTML được tạo dưới dạng URI dữ liệu Base64.

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### “Nhúng phông chữ trong html” thực sự làm gì

Khi `EmbedFonts` được bật, Aspose.Cells sẽ trích xuất các tệp phông chữ từ hệ thống (hoặc từ bộ sưu tập phông chữ được nhúng trong workbook) và chuyển chúng thành chuỗi **Base64**. Những chuỗi này sau đó được chèn vào một khối `<style>` bằng cách sử dụng `@font-face`. HTML kết quả có thể được mở trên bất kỳ thiết bị nào mà không cần cài đặt phông chữ gốc.

## Bước 3: Lưu workbook dưới dạng HTML với phông chữ được nhúng

Bây giờ chúng ta ghi workbook ra đĩa. Tệp sẽ chứa dữ liệu phông chữ, vì vậy mở nó trong bất kỳ trình duyệt hiện đại nào sẽ hiển thị cùng một kiểu chữ như trong file Excel gốc.

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### Kết quả mong đợi

* `embedded.html` nằm trong thư mục `output`.
* Mở tệp trong Chrome, Edge hoặc Firefox sẽ hiển thị worksheet với văn bản **Arial**, ngay cả khi máy trình duyệt không có Arial.
* Kiểm tra nguồn HTML sẽ thấy một khối `<style>` chứa quy tắc `@font-face` với khai báo `src: url(data:font/ttf;base64,…)` dài – đó là phông chữ đã được nhúng.

## Bước 4: Xác minh HTML hoạt động trên máy khác (tùy chọn)

Để chắc chắn rằng việc nhúng đã thành công:

1. Sao chép `output/embedded.html` sang một máy tính khác (hoặc máy ảo) mà **không** có phông chữ tùy chỉnh được cài đặt.
2. Mở tệp trong trình duyệt.
3. Bố cục và kiểu chữ nên khớp với giao diện Excel gốc.

Nếu phông chữ chuyển sang một phông chữ chung, hãy kiểm tra lại rằng tệp phông chữ có thể truy cập được trên máy build và bạn có quyền đọc nó.

## Các câu hỏi thường gặp và trường hợp đặc biệt

### Nhúng phông chữ có làm tăng kích thước tệp không?

Có. Nhúng một phông chữ TrueType hoặc OpenType có thể thêm **vài chục kilobyte** vào tệp HTML. Đối với các workbook lớn có nhiều phông chữ độc đáo, hãy cân nhắc:

* Cắt giảm phông chữ (chỉ giữ lại các ký tự bạn sử dụng) – Aspose.Cells tự động thực hiện việc này cho hầu hết các phông chữ phổ biến.
* Sử dụng `ExportEmbeddedImages = false` nếu bạn không cần nhúng hình ảnh.

### Nếu tôi chỉ muốn nhúng một số phông chữ cụ thể thì sao?

`HtmlSaveOptions` không cung cấp danh sách trắng trực tiếp, nhưng bạn có thể kiểm soát phông chữ xuất hiện bằng cách **giới hạn các phông chữ được sử dụng trong workbook** trước khi gọi `Save`. Loại bỏ các gán phông chữ không cần thiết hoặc thay thế chúng bằng các phông chữ web‑safe tiêu chuẩn.

### Tôi có thể nhúng phông chữ khi chuyển đổi sang các định dạng khác (ví dụ, PDF) không?

Thuộc tính `EmbedFonts` cũng tồn tại trên `PdfSaveOptions`. Khái niệm tương tự: dữ liệu phông chữ được nhúng để PDF hiển thị đúng trên bất kỳ trình xem nào.

## Ví dụ đầy đủ, có thể chạy ngay

Dưới đây là chương trình hoàn chỉnh mà bạn có thể sao chép‑dán vào một dự án console mới.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

Chạy chương trình sẽ tạo ra một **tệp HTML chứa phông chữ Arial đã nhúng**, đảm bảo độ chính xác về hình ảnh ở bất kỳ nơi nào tệp được mở.

## Kết luận

Bây giờ bạn đã biết **cách nhúng phông chữ khi lưu Excel sang HTML** bằng C#. Bằng cách cấu hình `HtmlSaveOptions.EmbedFonts = true`, bạn có thể tin cậy **xuất Excel sang HTML** và **chuyển đổi Excel sang HTML** mà không lo lắng về phông chữ thiếu trên phía khách hàng. Kỹ thuật này rất cần thiết cho báo cáo dựa trên web, bảng điều khiển thân thiện email, hoặc bất kỳ kịch bản nào bạn chia sẻ nội dung xuất từ Excel dưới dạng HTML.

### Tiếp theo bạn nên làm gì?

* **Tùy chỉnh CSS** do Aspose.Cells tạo ra để phù hợp với hướng dẫn phong cách của site của bạn.  
* **Nhúng hình ảnh** một cách chọn lọc bằng cách bật/tắt `ExportEmbeddedImages`.  
* **Khám phá các định dạng xuất khác** như PDF hoặc SVG đồng thời vẫn nhúng phông chữ.  

Hãy thoải mái thử nghiệm với các phông chữ khác, worksheet lớn hơn, hoặc workbook đa sheet. Cờ `EmbedFonts` hoạt động đồng nhất trên tất cả các định dạng đầu ra được hỗ trợ, cho bạn kiểm soát nhất quán về việc nhúng phông chữ ở bất kỳ nơi nào cần thiết. Chúc bạn lập trình vui vẻ!
