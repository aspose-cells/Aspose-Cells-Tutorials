# Tạo file excel c# – định dạng ô và đặt định dạng tiền tệ

Nếu bạn cần **tạo file excel c#** trông chuyên nghiệp, hướng dẫn này sẽ chỉ cho bạn cách định dạng ô excel và đặt định dạng cột thành tiền tệ. Bạn sẽ thấy một ví dụ hoàn chỉnh, từ đầu đến cuối, nhập một `DataTable`, áp dụng tiêu đề in đậm, và đặt định dạng số `$#,##0.00` cho cột giá.

Bài hướng dẫn bao gồm mọi thứ bạn cần: các gói NuGet bắt buộc, mã nguồn đầy đủ, giải thích vì sao mỗi phần lại quan trọng, và mẹo xử lý các trường hợp đặc biệt như hàng rỗng hoặc các địa phương khác nhau. Khi kết thúc, bạn sẽ có thể tạo một file `.xlsx` với cột giá được định dạng đẹp mắt chỉ trong vài dòng C#.

## Yêu cầu trước

- .NET 6.0 trở lên (mã cũng hoạt động với .NET Framework 4.6+)
- Visual Studio 2022 hoặc bất kỳ trình soạn thảo C# nào bạn thích
- Thư viện **Aspose.Cells for .NET** hoặc **GemBox.Spreadsheet** (cả hai đều hỗ trợ `ImportTableOptions`). Ví dụ dưới đây sử dụng **Aspose.Cells** vì nó cung cấp thuộc tính `StyleArray` đơn giản.
- Kiến thức cơ bản về các collection trong C# và `DataTable`

> **Pro tip:** Nếu bạn muốn một giải pháp miễn phí, thay `Aspose.Cells` bằng `GemBox.Spreadsheet`. API để nhập một `DataTable` có style gần như giống hệt; chỉ cần thay đổi namespace và tên gói NuGet.

## Bước 1: Cài đặt thư viện Excel

Mở NuGet Package Manager và cài đặt thư viện:

```bash
dotnet add package Aspose.Cells
```

> **Tại sao cần bước này?** Thư viện cung cấp các lớp `Workbook`, `Worksheet`, `Style`, và `ImportTableOptions` được dùng ở các bước sau. Nếu không có chúng, bạn sẽ phải tự viết định dạng Office Open XML, điều này dễ gây lỗi.

## Bước 2: Tạo một DataTable với dữ liệu mẫu

`DataTable` là cách tiện lợi để giữ dữ liệu dạng bảng trước khi xuất ra Excel. Trong ví dụ này chúng ta có hai cột: *Product* và *Price*.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Giải thích:**  
> - `Columns.Add("Price", typeof(double))` báo cho bảng rằng các giá trị giá là số, cần thiết cho việc định dạng số sau này.  
> - Thêm một vài hàng để chúng ta có dữ liệu kiểm chứng bước **format column currency**.

## Bước 3: Định nghĩa các style bạn muốn áp dụng

Chúng ta sẽ tạo một mảng các đối tượng `Style` tương ứng với thứ tự các cột. Mục đầu tiên định dạng hàng tiêu đề, mục thứ hai để cột *Product* không thay đổi, và mục thứ ba áp dụng định dạng số tiền tệ.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### Tại sao lại dùng **style array**?

`ImportTableOptions.StyleArray` ánh xạ mỗi cột tới một `Style`. Đây là cách hiệu quả nhất để **add number format** và **style excel cells** trong một lần nhập duy nhất, tránh việc phải duyệt lại worksheet lần thứ hai.

## Bước 4: Cấu hình các tùy chọn nhập

Bây giờ chúng ta gắn mảng style vào thao tác nhập. Đối tượng `ImportTableOptions` cũng cho phép bạn kiểm soát việc hàng đầu tiên có được xem là tiêu đề hay không.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Lưu ý:** `IsFieldNameShown` mặc định là `true`, nhưng việc đặt rõ ràng giúp người đọc trong tương lai hiểu ý định hơn.

## Bước 5: Tạo workbook, nhập bảng và lưu

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### Kết quả mong đợi

Khi bạn mở `DataTableWithStyles.xlsx`:

- Hàng đầu tiên (tiêu đề) **in đậm**.
- Cột *Price* hiển thị giá trị dưới dạng **$1.20**, **$3.50**, **$0.75**.
- Cột *Product* giữ font mặc định.

Bạn đã **tạo file excel c#** thành công với cột tiền tệ được định dạng và tiêu đề được style.

## Bước 6: Xử lý các biến thể và trường hợp đặc biệt thường gặp

### a. Địa phương khác hoặc ký hiệu tiền tệ tùy chỉnh

Nếu bạn cần Euro hoặc tiền tệ khác, thay thế định dạng tích hợp `164` bằng chuỗi định dạng tùy chỉnh:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. Thêm nhiều cột sau này

Khi bạn thêm các cột bổ sung, mở rộng mảng `columnStyles` cho phù hợp. Dùng `null` cho các cột muốn giữ style mặc định.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. DataTable rỗng

Nếu `DataTable` không có hàng, Aspose.Cells vẫn tạo hàng tiêu đề. Tuy nhiên, workbook sẽ chỉ có một hàng. Để tránh file rỗng, kiểm tra số lượng hàng trước khi nhập:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Sử dụng `GemBox.Spreadsheet` thay vì Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

Logic vẫn giống hệt, chứng tỏ tutorial **format column currency** không phụ thuộc vào thư viện nền.

## Bước 7: Kiểm tra file bằng chương trình (tùy chọn)

Bạn có thể mở workbook đã tạo và xác nhận rằng định dạng số đã được áp dụng đúng—rất hữu ích cho các unit test.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```

## Kết luận

Bài hướng dẫn này đã chỉ cách **tạo file excel c#**, **style excel cells**, và **set currency format** cho một cột cụ thể bằng một ví dụ ngắn gọn, từ đầu đến cuối. Bạn đã học:

1. Cách xây dựng `DataTable` với dữ liệu số.  
2. Cách định nghĩa **style array** để in đậm tiêu đề và **add number format** cho cột giá.  
3. Cách nhập bảng với `ImportTableOptions` và lưu workbook.  
4. Cách điều chỉnh giải pháp cho các địa phương khác nhau, cột bổ sung, DataTable rỗng, và thư viện thay thế.

Từ đây bạn có thể khám phá các style nâng cao hơn—định dạng có điều kiện, viền ô, hoặc tự động điều chỉnh độ rộng cột. Thử nghiệm với đối tượng `Style` để thay đổi font, màu nền, hoặc căn chỉnh, và bạn sẽ có một giải pháp xuất Excel đầy đủ tính năng cho bất kỳ ứng dụng C# nào.

**Bước tiếp theo:**  

- Tìm hiểu cách **format column currency** dựa trên locale của người dùng (`CultureInfo`).  
- Thêm **data validation** (danh sách thả xuống) vào worksheet.  
- Sử dụng **Excel tables** (`ListObject`) để cải thiện khả năng lọc và sắp xếp trong file được tạo.  

Chúc bạn lập trình vui vẻ và tận hưởng việc tạo các báo cáo Excel chuyên nghiệp trực tiếp từ C#!
