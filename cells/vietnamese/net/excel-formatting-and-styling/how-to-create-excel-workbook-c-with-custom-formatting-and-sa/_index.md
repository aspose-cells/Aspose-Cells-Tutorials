# Cách tạo Excel workbook C# với định dạng tùy chỉnh và lưu dưới dạng XLSX

Nếu bạn cần **create Excel workbook C#** để nhập dữ liệu, áp dụng định dạng số tùy chỉnh và thay đổi màu phông chữ của ô, hướng dẫn này sẽ chỉ cho bạn cách thực hiện chính xác. Bạn sẽ có một ví dụ sẵn sàng chạy, tạo ra tệp `StyleArrayImport.xlsx` có định dạng trong vài giây.

Làm việc với Excel từ C# thường bao gồm các bước thủ công lặp đi lặp lại—định nghĩa định dạng, áp dụng màu sắc và nhớ lưu tệp đúng cách. Khi kết thúc hướng dẫn này, bạn sẽ tự động hoá tất cả các công việc đó, để có thể tập trung vào dữ liệu thay vì giao diện người dùng.

Bạn sẽ học cách:

* nhập một `DataTable` vào worksheet,
* sử dụng `StyleArray` để **apply custom number format** và **change cell font color**,
* lưu workbook dưới dạng XLSX bằng một lệnh gọi phương thức duy nhất,
* và xác minh rằng **format imported data excel** hiển thị đúng như mong muốn.

Yêu cầu duy nhất là tham chiếu tới thư viện **Aspose.Cells for .NET** (hoặc bất kỳ API tương thích nào cung cấp `Workbook`, `Worksheet` và `StyleArray`). Mã nguồn nhắm tới .NET 6+, nhưng các phiên bản trước cũng hoạt động với một số điều chỉnh nhỏ.

## Bước 1: Chuẩn bị DataTable mẫu

Đầu tiên, tạo một `DataTable` mô phỏng dữ liệu mà bạn thường lấy từ cơ sở dữ liệu hoặc nguồn khác. Bảng này bao gồm cột **Name** (chuỗi) và cột **Amount** (số thập phân) mà chúng ta sẽ định dạng sau.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Tại sao điều này quan trọng:** Sử dụng `DataTable` cho phép bạn giữ logic nhập dữ liệu độc lập với nguồn dữ liệu, đây là mẫu phổ biến khi tạo báo cáo từ cơ sở dữ liệu, tệp CSV hoặc API.

## Bước 2: Định nghĩa StyleArray để **apply custom number format** và **change cell font color**

`StyleArray` cho phép bạn gói các hướng dẫn định dạng sẽ được áp dụng cho mỗi ô được nhập từ `DataTable`. Trong ví dụ này chúng ta:

* đặt `Number` thành `#,##0.00` – định dạng kế toán tiêu chuẩn với dấu phân cách hàng nghìn,
* đặt `FontColor` thành `Color.Blue` – làm cho các số nổi bật.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**Tại sao lại dùng StyleArray?** Áp dụng kiểu khi nhập dữ liệu tránh việc phải duyệt lại worksheet lần thứ hai, giúp cải thiện hiệu năng cho các bộ dữ liệu lớn.

## Bước 3: **Create Excel workbook C#** – khởi tạo Workbook và lấy Worksheet đầu tiên

Bây giờ chúng ta tạo một workbook trống và lấy tham chiếu tới worksheet đầu tiên (chỉ mục 0). Worksheet này sẽ là nơi chứa dữ liệu đã nhập.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Giải thích:** `Workbook` đại diện cho toàn bộ tệp Excel, trong khi `Worksheet` đại diện cho một tab duy nhất. Workbook mặc định chứa một sheet, đủ cho hầu hết các báo cáo đơn giản.

## Bước 4: Nhập DataTable bằng **StyleArray** để **format imported data excel**

Phương thức `ImportDataTable` sao chép các hàng và cột của bảng vào worksheet, bắt đầu từ ô `A1` (hàng 0, cột 0). Tham số `true` chỉ thị phương thức bao gồm tiêu đề cột. Vì chúng ta truyền `styleArray`, mỗi ô được nhập sẽ nhận định dạng số tùy chỉnh và màu phông chữ.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**Điều gì xảy ra bên trong:** Aspose.Cells lặp qua mỗi hàng, ghi giá trị, sau đó áp dụng kiểu được định nghĩa trong `styleArray`. Các số hiển thị có dấu phẩy và hai chữ số thập phân, và văn bản được hiển thị màu xanh.

## Bước 5: **Save workbook as XLSX** – ghi tệp ra đĩa

Cuối cùng, lưu workbook vào tệp `.xlsx`. Bạn có thể thay đổi đường dẫn tới bất kỳ thư mục có thể ghi được nào trên máy của mình.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Xác minh kết quả:** Mở tệp đã tạo trong Excel. Bạn sẽ thấy ba hàng dữ liệu, cột **Amount** được định dạng có dấu phẩy, hai chữ số thập phân và hiển thị màu xanh. Điều này xác nhận bước **format imported data excel** đã thành công.

## Ví dụ Hoạt động Đầy đủ

Sao chép toàn bộ khối dưới đây vào một dự án console mới và chạy nó. Không cần mã bổ sung nào.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Kết quả mong đợi trong console:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

Mở tệp và xác minh rằng cột **Amount** hiển thị các giá trị như `1,234.56` với phông chữ màu xanh.

## Câu hỏi Thường gặp & Trường hợp Cạnh

| Câu hỏi | Câu trả lời |
|----------|--------|
| *Can I apply different formats to individual columns?* | Có. Sau khi nhập, lấy đối tượng `Style` của cột (`worksheet.Cells.Columns[1].Style`) và đặt `Number` hoặc `FontColor` khác. |
| *What if I need to format dates instead of numbers?* | Đặt `styleArray.Number = "mm-dd-yyyy"` và tùy chọn `styleArray.FontColor` cho các ô ngày. |
| *Is the blue font visible on dark Excel themes?* | Màu xanh có thể khó đọc trên nền tối. Sử dụng màu sáng hơn (`Color.LightBlue`) hoặc màu tương phản (`Color.Black`). |
| *How do I import a very large DataTable (hundreds of thousands of rows)?* | Sử dụng `ImportDataTable` với overload `ImportDataTableOptions` để truyền dữ liệu dạng stream, hoặc chia nhập thành nhiều worksheet để nằm trong giới hạn số hàng của Excel (1,048,576 hàng). |
| *Can I export to CSV instead of XLSX?* | Thay `SaveFormat.Xlsx` bằng `SaveFormat.Csv`. Lưu ý rằng thông tin định dạng (định dạng số, màu phông chữ) sẽ bị mất trong CSV vì nó là định dạng văn bản thuần. |

## Mẹo cho Sử dụng trong Sản xuất

* **Pro tip:** Lưu vào cache đối tượng `Style` nếu bạn cần áp dụng cùng một định dạng cho nhiều worksheet; việc tạo `StyleArray` mới cho mỗi lần nhập sẽ tăng chi phí.
* **Cẩn thận với sự khác biệt về văn hoá:** Mẫu `Number` `#,##0.00` tuân theo văn hoá không đổi. Nếu bạn cần dấu phân cách theo địa phương, hãy sử dụng `NumberFormatInfo` hoặc để Excel tự xử lý dựa trên cài đặt khu vực của người dùng.
* **Xử lý lỗi:** Bao bọc lệnh `Save` trong khối try‑catch để xử lý các ngoại lệ I/O (ví dụ: thiếu quyền hoặc tệp bị khóa).
