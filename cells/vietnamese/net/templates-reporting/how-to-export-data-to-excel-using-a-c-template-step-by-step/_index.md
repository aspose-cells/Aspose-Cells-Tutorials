# Cách xuất dữ liệu ra Excel bằng mẫu C# – hướng dẫn chi tiết

Nếu bạn cần **xuất dữ liệu ra Excel** từ một ứng dụng .NET, hướng dẫn này cung cấp giải pháp hoàn chỉnh chạy từ đầu tới cuối. Bằng cách tải một mẫu Excel đã chứa các thẻ Smart Marker, bạn có thể **tự động tạo Excel** và tạo ra một **báo cáo nhân viên Excel** chuyên nghiệp mà không cần viết mã cho từng ô.

Bạn sẽ thấy cách:

* Tải một mẫu Excel (`load excel template`) định nghĩa bố cục.
* Đưa danh sách các đối tượng employee vào mẫu.
* Tạo workbook cuối cùng và lưu dưới dạng `output.xlsx`.

Tất cả mã cần thiết đã được bao gồm, vì vậy bạn có thể sao chép, dán và chạy ngay lập tức.

## Yêu cầu trước

* .NET 6.0 hoặc mới hơn (mã cũng hoạt động với .NET Framework 4.7+).  
* Gói NuGet **Aspose.Cells for .NET** – cung cấp `Workbook`, `SmartMarkerProcessor` và hỗ trợ Smart Marker.  
* Một thư mục có tên `YOUR_DIRECTORY` chứa `template.xlsx`. Mẫu này cần có các thẻ Smart Marker như `&=EmployeeList.Name` trong các ô mà bạn muốn dữ liệu xuất hiện.

> **Mẹo chuyên nghiệp:** Giữ mẫu trong cùng thư mục dự án và đặt thuộc tính *Copy to Output Directory* thành *Copy always* để đường dẫn được giải quyết đúng khi gỡ lỗi.

## Toàn bộ mã nguồn

```csharp
using System;
using System.Collections.Generic;
using Aspose.Cells;

namespace ExcelExportDemo
{
    // Simple POCO that represents an employee record
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Step 1: Load the Excel template that contains Smart Marker tags
            string templatePath = @"YOUR_DIRECTORY\template.xlsx";
            Workbook wb = new Workbook(templatePath);

            // Step 2: Prepare a data source – a list of employee objects
            List<Employee> employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Step 3: Create a SmartMarkerProcessor instance
            SmartMarkerProcessor sp = new SmartMarkerProcessor();

            // Step 4: Apply the employee data to the workbook using the processor
            // The tag &amp;=EmployeeList.Name in the template will be replaced with each employee's name,
            // and &amp;=EmployeeList.Position will be replaced with the corresponding position.
            sp.Process(wb, employeeList);

            // Step 5: Save the populated workbook
            string outputPath = @"YOUR_DIRECTORY\output.xlsx";
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

### Những gì mã thực hiện

| Bước | Tại sao quan trọng | Dòng mã chính |
|------|-------------------|---------------|
| **Load Excel template** | Tái sử dụng bố cục đã thiết kế sẵn giúp tiết kiệm thời gian và đảm bảo phong cách nhất quán. | `Workbook wb = new Workbook(templatePath);` |
| **Prepare data source** | Smart Markers làm việc với bất kỳ collection `IEnumerable` nào; ở đây chúng ta dùng danh sách `Employee`. | `List<Employee> employeeList = …` |
| **Create processor** | `SmartMarkerProcessor` phân tích mẫu, tìm thẻ và chèn dữ liệu. | `SmartMarkerProcessor sp = new SmartMarkerProcessor();` |
| **Process data** | Bộ xử lý thay thế mỗi thẻ Smart Marker bằng giá trị thuộc tính tương ứng. | `sp.Process(wb, employeeList);` |
| **Save workbook** | Tệp cuối cùng có thể gửi cho người dùng, lưu trên máy chủ, hoặc đính kèm email. | `wb.Save(outputPath);` |

Kết quả là một tệp **báo cáo nhân viên Excel** trong đó mỗi hàng chứa tên và vị trí của một nhân viên, đúng tại các vị trí thẻ được đặt trong mẫu gốc.

## Tải một mẫu Excel

Khi bạn `load excel template` bằng `new Workbook(path)`, Aspose.Cells sẽ đọc toàn bộ workbook — bao gồm kiểu dáng, công thức và các placeholder Smart Marker. Cách này ưu việt hơn so với việc tạo workbook từ đầu vì:

* **Kiểm soát thiết kế** – Nhà thiết kế có thể định dạng tiêu đề, thêm logo công ty và đặt độ rộng cột mà không cần chạm vào mã.
* **Quản lý phiên bản** – Cập nhật mẫu không yêu cầu biên dịch lại ứng dụng.
* **Đa ngôn ngữ** – Bạn có thể giữ các tệp mẫu riêng cho các ngôn ngữ khác nhau.

Nếu bạn muốn một giải pháp thuần .NET mà không dùng thư viện bên thứ ba, có thể dùng **ClosedXML** hoặc **EPPlus**, nhưng chúng không có hỗ trợ Smart Marker tích hợp, nghĩa là bạn sẽ phải viết vòng lặp sao chép dữ liệu ô theo ô.

## Tự động tạo Excel với Smart Markers

Smart Markers là các placeholder có dạng `&=Collection.Property`. Khi bộ xử lý chạy:

* Nó lặp qua collection (`employeeList` trong ví dụ của chúng ta).
* Với mỗi mục, nó ghi giá trị thuộc tính vào ô tương ứng.
* Nó tự động mở rộng hàng hoặc cột khi cần.

Cơ chế này **tự động tạo Excel** và loại bỏ logic lặp thủ công. Mẫu này hoạt động với bất kỳ cấu trúc dữ liệu nào — đơn hàng, hoá đơn, danh sách tồn kho, v.v.

### Các biến thể phổ biến

| Biến thể | Cách thực hiện |
|----------|----------------|
| **Nhiều collection** | Thêm các danh sách khác (ví dụ `List<Department>`) và tham chiếu chúng bằng các thẻ khác như `&=DepartmentList.Name`. |
| **Collection lồng nhau** | Dùng ký hiệu chấm: `&=EmployeeList.Projects.ProjectName` trong đó `Projects` là một collection thuộc tính của `Employee`. |
| **Định dạng có điều kiện** | Đặt quy tắc định dạng có điều kiện trong mẫu; bộ xử lý sẽ giữ nguyên nó cho các hàng được tạo. |

## Tạo báo cáo nhân viên Excel

Thuật ngữ **báo cáo nhân viên Excel** chỉ một trường hợp sử dụng kinh doanh điển hình: một quản lý muốn danh sách nhân viên có thể in được. Bằng cách nhúng các thẻ Smart Marker trực tiếp vào mẫu, bạn sẽ có:

* Một hàng tiêu đề với phông chữ đậm và màu nền.
* Các cột tự động điều chỉnh độ rộng dựa trên dữ liệu.
* Các hàng tổng tùy chọn (ví dụ, đếm số nhân viên) có thể tính bằng công thức Excel tiêu chuẩn.

Nếu cần thêm hàng tổng, chỉ cần đặt công thức như `=COUNTA(A2:A100)` trong mẫu; bộ xử lý sẽ không làm thay đổi nó.

## Tạo mẫu Excel C# – các thực tiễn tốt nhất

Khi bạn **generate Excel template C#** code, hãy nhớ các hướng dẫn sau:

1. **Tách biệt trách nhiệm** – Giữ việc tải mẫu, chuẩn bị dữ liệu và xử lý trong các phương thức riêng. Điều này giúp việc kiểm thử đơn vị dễ dàng hơn.
2. **Xác thực đầu vào** – Đảm bảo tệp mẫu tồn tại và collection dữ liệu không null trước khi gọi `Process`.
3. **Giải phóng tài nguyên** – Mặc dù Aspose.Cells quản lý bộ nhớ, hãy bọc `Workbook` trong khối `using` nếu làm việc với tệp lớn.
4. **Xử lý ngoại lệ** – Bắt `Exception` quanh `sp.Process` để phát hiện các vấn đề như tên thẻ không khớp.

```csharp
static Workbook LoadTemplate(string path)
{
    if (!File.Exists(path))
        throw new FileNotFoundException($"Template not found: {path}");
    return new Workbook(path);
}
```

## Tóm tắt ví dụ hoàn chỉnh

Dưới đây là toàn bộ chương trình trong một khối để sao chép‑dán nhanh:

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Load the template
            string templatePath = Path.Combine("YOUR_DIRECTORY", "template.xlsx");
            Workbook wb = new Workbook(templatePath);

            // Prepare data
            var employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Process Smart Markers
            var sp = new SmartMarkerProcessor();
            sp.Process(wb, employeeList);

            // Save the result
            string outputPath = Path.Combine("YOUR_DIRECTORY", "output.xlsx");
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

Chạy chương trình này sẽ tạo một tệp **báo cáo nhân viên Excel** có thể gửi email, in ra hoặc tiếp tục xử lý.

* **Thêm biểu đồ** – Đặt placeholder biểu đồ trong mẫu; bộ xử lý sẽ giữ liên kết biểu đồ với dữ liệu đã tạo.
* **Xuất sang định dạng khác** – Aspose.Cells có thể lưu trực tiếp thành PDF, CSV, hoặc HTML (`wb.Save("report.pdf")`).
* **Tích hợp với ASP.NET Core** – Trả về workbook đã tạo dưới dạng tải xuống tệp trong một action controller.
