# Tạo các sheet chi tiết trong Java với smart markers của Aspose.Cells

Nếu bạn cần **tạo các sheet chi tiết** trong một ứng dụng Java, hướng dẫn này sẽ chỉ cho bạn cách thực hiện bằng smart markers của Aspose.Cells. Bạn sẽ thấy một ví dụ hoàn chỉnh, có thể chạy được mà **java create worksheets**, lấy **tên sheet từ trường**, và **xử lý nguồn dữ liệu** chỉ trong vài dòng code.

Hướng dẫn bao gồm mọi thứ từ thiết lập dự án đến lưu workbook cuối cùng, vì vậy bạn có thể sao chép‑dán giải pháp vào dự án của mình và ngay lập tức tùy chỉnh. Không cần tài liệu bên ngoài—mọi thứ bạn cần đã có ở đây.

## Bạn sẽ học được

* Cách **sử dụng smart markers** để sao chép một worksheet mẫu cho mỗi hàng trong bộ dữ liệu chính.  
* Cách đặt tên cho mỗi sheet mới một cách động dựa trên giá trị của một trường (ví dụ, `Order_123`).  
* Cách cung cấp một collection Java làm **nguồn dữ liệu xử lý** cho engine smart marker.  
* Các mẹo xử lý các trường hợp đặc biệt như dữ liệu rỗng, ký tự đặc biệt trong tên sheet, và cân nhắc hiệu năng cho các bộ dữ liệu lớn.

### Yêu cầu trước

| Yêu cầu | Lý do |
|-------------|--------|
| Java 8 hoặc cao hơn | Aspose.Cells for Java hỗ trợ Java 8+. |
| Hệ thống build Maven hoặc Gradle | Giúp việc thêm phụ thuộc Aspose.Cells trở nên đơn giản. |
| Kiến thức cơ bản về collection Java | Cần để xây dựng nguồn dữ liệu cho smart markers. |
| Một file Excel mẫu (`Template.xlsx`) với smart marker placeholder trong ô **A1** | Mẫu này điều khiển việc tạo các sheet chi tiết. |

> **Mẹo chuyên nghiệp:** Đặt workbook mẫu trong thư mục `resources` của dự án để nó được đóng gói cùng JAR của bạn.

## Bước 1: Thêm Aspose.Cells vào dự án (java create worksheets)

Nếu bạn dùng **Maven**, thêm phụ thuộc sau vào `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

Đối với **Gradle**, đặt dòng này trong `build.gradle`:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

Các dòng này sẽ làm cho các API **java create worksheets** khả dụng ở thời điểm biên dịch.

## Bước 2: Tải workbook mẫu

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*Lý do quan trọng:* Đối tượng `Workbook` là điểm vào cho mọi thao tác Excel. Việc tải mẫu đảm bảo bạn bắt đầu với bố cục và định dạng đã được định nghĩa sẵn.

## Bước 3: Chèn smart marker tạo sheet mới cho mỗi hàng master (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

Cú pháp `${Orders:DetailSheetNewName=Order_${OrderId}}` là lõi của **use smart markers**. Nó thực hiện ba việc:

1. Duyệt qua collection `Orders`.  
2. Tạo một **worksheet mới** cho mỗi phần tử.  
3. Đặt **tên sheet từ trường** `OrderId` (được tiền tố bằng `Order_`).

## Bước 4: Chuẩn bị nguồn dữ liệu (process data source)

Dưới đây là một ví dụ tối thiểu sử dụng `List<Map<String, Object>>`. Thay thế bằng nguồn dữ liệu thực của bạn—các hàng trong cơ sở dữ liệu, deserialization JSON, v.v.

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*Lý do quan trọng:* Bước **process data source** gắn collection Java của bạn vào engine smart marker. Khóa (`"Orders"`) phải khớp chính xác với tên smart marker.

## Bước 5: Xử lý smart markers (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

Khi `process` chạy, Aspose.Cells sẽ đọc collection `Orders`, sao chép worksheet mẫu cho mỗi mục, và đổi tên mỗi sheet theo trường `OrderId`. Đây là phần cốt lõi của việc sử dụng **process data source**.

## Bước 6: Lưu workbook với các sheet chi tiết đã được sao chép

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

Sau khi thực thi, bạn sẽ thấy file `DuplicatedDetailSheets.xlsx` chứa:

* `Sheet1` – mẫu gốc (không thay đổi).  
* `Order_101` – sheet chi tiết cho đơn hàng đầu tiên.  
* `Order_102` – sheet chi tiết cho đơn hàng thứ hai.

### Kết quả mong đợi (trích đoạn)

| Tên sheet | A1 (smart marker) | Nội dung kết quả |
|------------|-------------------|-------------------|
| Order_101  | `${Orders:...}`   | Được điền dữ liệu từ `order1` |
| Order_102  | `${Orders:...}`   | Được điền dữ liệu từ `order2` |

Mở file trong Excel để xác nhận mỗi sheet được đặt tên đúng và chứa các dòng dữ liệu.

## Xử lý các biến thể và trường hợp đặc biệt thường gặp

### Nguồn dữ liệu rỗng

Nếu `orders` rỗng, bộ xử lý smart marker sẽ **không tạo sheet mới** nào. Để tránh workbook trống, thêm một guard:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### Ký tự đặc biệt trong tên sheet

Tên sheet Excel không được chứa `\ / ? * [ ] :`. Hãy làm sạch trường trước khi sử dụng:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### Bộ dữ liệu lớn

Đối với hàng ngàn dòng, cân nhắc tăng heap JVM (`-Xmx2g`) và gọi `workbook.calculateFormula()` chỉ sau khi tất cả các sheet đã được tạo để cải thiện hiệu năng.
