# Cách tạo các worksheet trong Java bằng SmartMarkerProcessor

Nếu bạn cần **cách tạo các worksheet** trong một tệp Excel, hướng dẫn này sẽ cho bạn một giải pháp hoàn chỉnh, sẵn sàng chạy. Sau hai câu đầu tiên, bạn sẽ hiểu cách tạo các worksheet và các sheet Excel động từ một tập hợp các đối tượng, và sẽ có một mẫu mã hoạt động tự động tạo Excel chỉ bằng một lời gọi phương thức.

Việc tạo các worksheet riêng cho mỗi nhân viên, dự án, hoặc bất kỳ thực thể nào khác là một yêu cầu phổ biến khi bạn cần **điền dữ liệu vào workbook Excel** một cách lập trình. Bài tutorial này sẽ hướng dẫn từng bước — từ việc thiết lập mẫu đến xử lý danh sách và lưu tệp cuối cùng — để bạn có thể áp dụng ngay kỹ thuật này trong các ứng dụng Java của mình.

## Những gì bạn sẽ đạt được

* Tạo một worksheet chính liệt kê thông tin cấp cao.  
* Tạo **nhiều sheet từ danh sách** dữ liệu, mỗi sheet được đặt tên tự động.  
* **Tự động tạo Excel** mà không cần thêm hàng hoặc cột thủ công.  
* **Điền dữ liệu vào workbook Excel** với các cấu trúc dữ liệu phong phú (đối tượng, map, mảng).  

Điều kiện tiên quyết:

* Java 8 hoặc mới hơn đã được cài đặt.  
* Maven (hoặc công cụ xây dựng khác) để thêm thư viện Aspose.Cells for Java.  
* Kiến thức cơ bản về các collection trong Java.  

> **Mẹo chuyên nghiệp:** Cú pháp SmartMarker (`${EmployeeMaster}`) hoạt động với bất kỳ kiểu collection nào triển khai `java.util.Collection`. Sử dụng nó để giữ cho mẫu của bạn sạch sẽ và dễ bảo trì.

## Cách tạo các worksheet với SmartMarkerProcessor

Phần này chứa mã lõi giúp **cách tạo các worksheet** trở nên dễ dàng. Chúng tôi sẽ giải thích tại sao mỗi dòng mã quan trọng, không chỉ là những gì nó làm.

### Bước 1: Thêm phụ thuộc Aspose.Cells

Nếu bạn dùng Maven, thêm đoạn sau vào file `pom.xml` của bạn. Thư viện cung cấp lớp `SmartMarkerProcessor` được sử dụng xuyên suốt hướng dẫn này.

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **Tại sao:** Aspose.Cells xử lý I/O file Excel, phân tích Smart Marker và quản lý sheet nội bộ, cho phép bạn tập trung vào dữ liệu thay vì các thao tác file mức thấp.

### Bước 2: Chuẩn bị mẫu Excel

Tạo một tệp Excel có tên `EmployeeTemplate.xlsx` với một ô duy nhất chứa placeholder Smart Marker:

| A |
|---|
| `${EmployeeMaster}` |

Khi bộ xử lý chạy, nó sẽ thay thế placeholder này bằng một **sheet chi tiết** chứa một hàng cho mỗi nhân viên.

> **Tại sao:** Placeholder cho bộ xử lý biết nơi chèn dữ liệu. Sử dụng mẫu riêng giúp giữ nguyên định dạng (phông chữ, viền, độ rộng cột).

### Bước 3: Định nghĩa mô hình dữ liệu

Dưới đây là lớp `Employee` tối thiểu và một phương thức trợ giúp tạo danh sách nhân viên. Danh sách này sẽ được dùng để minh họa **nhiều sheet từ danh sách**.

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **Tại sao:** Một POJO (Plain Old Java Object) ánh xạ trực tiếp tới các trường Smart Marker (`firstName`, `lastName`, `department`). Điều này làm cho **điền dữ liệu vào workbook Excel** trở nên đơn giản và an toàn về kiểu dữ liệu.

### Bước 4: Thiết lập SmartMarkerProcessor

Bây giờ chúng ta kết nối mọi thứ lại. Bộ xử lý sẽ đọc mẫu, thay thế marker và tạo một sheet mới có tên `EmployeeDetail`.

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

**Giải thích các dòng quan trọng**

| Dòng | Lý do |
|------|-------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | Tải mẫu đã chứa placeholder Smart Marker. |
| `data.put("EmployeeMaster", employees);` | Gắn danh sách Java vào marker `${EmployeeMaster}`. |
| `processor.setDetailSheetNewName("EmployeeDetail");` | Đặt tên có ý nghĩa cho sheet được tạo thay vì `Sheet1` mặc định. |
| `processor.process(wb, data);` | **Cách tạo các worksheet** – bộ xử lý đọc marker, tạo sheet mới và điền các hàng cho mỗi `Employee`. |
| `wb.save("EmployeesReport.xlsx");` | Lưu **các sheet Excel động** ra đĩa. |

### Bước 5: Kiểm tra kết quả

Mở `EmployeesReport.xlsx`. Bạn sẽ thấy hai worksheet:

1. **Sheet1** – mẫu gốc (có thể ẩn hoặc xóa).  
2. **EmployeeDetail** – một **sheet Excel động** với các cột `firstName`, `lastName`, `department` và một hàng cho mỗi nhân viên.

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **Tại sao điều này quan trọng:** Tệp hiện chứa **nhiều sheet từ danh sách** mà không cần vòng lặp hay chỉ định ô thủ công. Engine Smart Marker tự động tạo hàng, chuyển đổi dữ liệu và kế thừa định dạng.

### Bước 6: Xử lý các trường hợp đặc biệt

#### Danh sách dữ liệu rỗng

Nếu `employees` rỗng, bộ xử lý vẫn tạo sheet `EmployeeDetail` nhưng để trống. Bạn có thể ngăn không tạo sheet bằng cách kiểm tra kích thước collection trước khi xử lý:

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### Danh sách rất lớn

Đối với hàng ngàn dòng, hãy cân nhắc tăng bộ nhớ cấp phát (`-Xmx2g`) hoặc sử dụng `processor.setAutoFitRows(false)` để tăng tốc xử lý.

#### Đặt tên sheet tùy chỉnh theo nhóm

Nếu bạn cần một sheet riêng cho mỗi phòng ban, có thể sử dụng **nhiều sheet chi tiết**:

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

Placeholder `${department}` được lấy từ mỗi đối tượng `Employee`, tạo ra các sheet như `Dept_Sales`, `Dept_Marketing`, v.v.
