# Nhập các đối tượng tùy chỉnh vào Excel với Aspose.Cells – Hướng dẫn Java

Nếu bạn cần **import custom objects** vào một worksheet Excel, hướng dẫn này sẽ đưa bạn qua toàn bộ quá trình sử dụng Aspose.Cells for Java. Bạn sẽ thấy cách **import data to Excel**, áp dụng kiểu tiêu đề in đậm, và tạo một tệp `.xlsx` sẵn sàng chia sẻ.

Xuất dữ liệu dạng bảng từ Java thường đòi hỏi việc ghi từng ô một một cách thủ công, điều này dễ gây lỗi và khó bảo trì. Bằng cách tận dụng API `importCustomObjects` bạn tránh được mã lặp lại, giữ nguyên mô hình dữ liệu của mình, và có được kiểm soát kiểu dáng chi tiết.

Trong tutorial này bạn sẽ:

* Xây dựng một danh sách các đối tượng Java `Map` mô phỏng một bảng dữ liệu tiêu chuẩn.
* Tạo một kiểu tiêu đề có thể tái sử dụng (phông chữ đậm) bằng Aspose.Cells.
* Nhập các đối tượng tùy chỉnh vào một worksheet đồng thời áp dụng mảng kiểu.
* Lưu workbook vào đĩa và xác minh kết quả.

Điều kiện tiên quyết duy nhất là môi trường phát triển Java (khuyến nghị JDK 8+) và thư viện Aspose.Cells for Java.

---

## Những gì bạn sẽ cần

| Yêu cầu | Lý do |
|-------------|--------|
| JDK 8 hoặc mới hơn | Cần thiết để biên dịch và chạy mã Java. |
| Aspose.Cells for Java (phiên bản mới nhất) | Cung cấp các API `Workbook`, `Worksheet`, và import. |
| IDE hoặc công cụ xây dựng (ví dụ: Maven, Gradle) | Đơn giản hoá việc quản lý phụ thuộc và thực thi. |
| Quyền ghi vào thư mục để lưu tệp đầu ra | Workbook sẽ được lưu dưới tên `ImportWithStyle.xlsx`. |

Thêm phụ thuộc Aspose.Cells vào `pom.xml` nếu bạn dùng Maven:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## Bước 1: Chuẩn bị các đối tượng tùy chỉnh để nhập

Bước đầu tiên là tạo một collection đại diện cho các hàng bạn muốn đặt vào Excel. Trong ví dụ này chúng ta sử dụng `List<Map<String,Object>>` trong đó mỗi map hoạt động như một hàng với tên cột làm khóa.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Tại sao điều này quan trọng:**  
`importCustomObjects` yêu cầu một mảng các đối tượng. Bằng cách sử dụng `Map`, bạn giữ lại tên cột, cho phép Aspose.Cells tự động ánh xạ chúng vào các ô. Cách tiếp cận này giống với một `DataTable` điển hình trong .NET hoặc một `ResultSet` từ JDBC, giúp mã có thể tái sử dụng trong nhiều dự án.

---

## Bước 2: Định nghĩa kiểu tiêu đề để áp dụng khi nhập

Một hàng tiêu đề rõ ràng giúp cải thiện khả năng đọc. Aspose.Cells cho phép bạn tạo một đối tượng `Style`, đặt phông chữ thành đậm, và truyền nó qua một mảng `ImportTableOptions`.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Tại sao điều này quan trọng:**  
Nếu bạn bỏ qua mảng kiểu, tiêu đề sẽ xuất hiện với phông chữ mặc định, có thể không nổi bật. Bằng cách chuẩn bị kiểu một lần, bạn tránh các lời gọi lặp lại cho mỗi hàng và giữ cho logic nhập dữ liệu sạch sẽ.

---

## Bước 3: Nhập các đối tượng tùy chỉnh cùng với mảng kiểu

Bây giờ bạn kết hợp dữ liệu và kiểu, sau đó gọi `importCustomObjects`. Phương thức sẽ đặt dữ liệu bắt đầu từ góc trên‑trái (hàng 0, cột 0) và tự động áp dụng kiểu tiêu đề.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Tại sao điều này quan trọng:**  
`importCustomObjects` phân tích mỗi map, tạo các cột dựa trên các khóa (`Name`, `Score`), và ghi các giá trị vào các ô tương ứng. Đối tượng `ImportTableOptions` thông báo cho Aspose.Cells sử dụng `styleArray` cho hàng đầu tiên, giúp bạn có tiêu đề đậm mà không cần viết thêm mã.

---

## Bước 4: Lưu workbook và xác minh đầu ra

Cuối cùng, ghi workbook vào một tệp. Tệp Excel được tạo ra chứa một hàng tiêu đề đã được định dạng, tiếp theo là các hàng dữ liệu.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Kết quả mong đợi:**  

| **Name** | **Score** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

Các ô tiêu đề (`Name`, `Score`) sẽ hiển thị ở phông chữ đậm, khớp với kiểu đã định nghĩa ở Bước 2.

## Các biến thể thường gặp và trường hợp đặc biệt

| Tình huống | Điều chỉnh đề xuất |
|-----------|------------------------|
| **Thứ tự cột khác** | Đảm bảo các khóa `Map` được chèn theo thứ tự mong muốn, hoặc sử dụng POJO tùy chỉnh với các trường được chú thích và một mảng `PropertyDescriptor`. |
| **Bộ dữ liệu lớn (>10 000 hàng)** | Tăng `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` để tránh `OutOfMemoryError`. |
| **Định dạng số tùy chỉnh** | Thêm một `Style` thứ hai trong `styleArray` cho các hàng dữ liệu, ví dụ đặt `NumberFormat` thành `"0"` cho các điểm số nguyên. |
| **Nhiều worksheet** | Gọi `importCustomObjects` trên mỗi worksheet mục tiêu, điều chỉnh hàng/cột bắt đầu theo nhu cầu. |
| **Văn bản tiêu đề theo locale** | Điền hàng tiêu đề thủ công trước khi nhập, sau đó áp dụng kiểu cho toàn bộ vùng bằng `Cells.applyStyle`. |

## Mẹo chuyên nghiệp để xuất Java sang Excel ổn định

* **Tái sử dụng workbook tạm thời** – Tạo một `Workbook` mới cho mỗi kiểu sẽ gây tốn tài nguyên. Giữ một instance duy nhất nếu bạn cần nhiều kiểu.  
* **Kiểm tra dữ liệu trước khi nhập** – Các giá trị null trong map sẽ trở thành ô trống; bạn có thể thay thế chúng bằng giá trị mặc định bằng cách tiền xử lý danh sách.  
* **Đóng tài nguyên** – Mặc dù Aspose.Cells quản lý bộ nhớ nội bộ, việc gọi `workbook.dispose()` một cách rõ ràng sau khi lưu sẽ giải phóng tài nguyên native kịp thời.  
* **Đặt `Workbook.setForceFullCalculation(true)`** nếu workbook của bạn chứa công thức cần được tính toán trước khi lưu.
