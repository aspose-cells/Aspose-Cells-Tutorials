# Cách tạo workbook Excel trong Java với dữ liệu JSON

Nếu bạn cần **create Excel workbook java**, các nhà phát triển thường gặp thách thức khi tải dữ liệu JSON vào bảng tính. Hướng dẫn này cho bạn cách **populate Excel from JSON**, bao gồm cách **convert JSON array excel** và **populate workbook from json** một cách sạch sẽ và có thể lặp lại.

Việc làm việc với JSON là phổ biến khi các dịch vụ cung cấp dữ liệu qua REST APIs, và Excel vẫn là định dạng ưu tiên cho báo cáo và phân tích. Khi kết thúc hướng dẫn này, bạn sẽ có một chương trình Java có thể chạy được mà:

* tạo một workbook Excel mới,
* đọc một mảng JSON (hoặc bất kỳ cấu trúc JSON nào) và ghi các giá trị của nó vào các ô,
* lưu tệp vào đĩa để sẵn sàng cho quá trình xử lý tiếp theo.

Không cần công cụ bên ngoài nào ngoài thư viện Aspose.Cells for Java, cung cấp `SmartMarkerProcessor` được sử dụng trong mã mẫu.

## Yêu cầu trước

Trước khi bắt đầu, hãy chắc chắn rằng bạn có:

| Prerequisite | Reason |
|--------------|--------|
| Java Development Kit (JDK) ≥ 8 | Cần thiết để biên dịch và chạy ví dụ |
| Maven or Gradle (optional) | Đơn giản hoá việc quản lý phụ thuộc |
| Aspose.Cells for Java (v23.10 or later) | Cung cấp các lớp `Workbook` và `SmartMarkerProcessor` |
| Basic knowledge of JSON and Java I/O | Giúp bạn hiểu luồng dữ liệu |

Nếu bạn không muốn sử dụng công cụ xây dựng, bạn có thể tải JAR Aspose.Cells từ [Aspose website](https://products.aspose.com/cells/java/) và thêm nó vào classpath của dự án một cách thủ công.

## Bước 1: Thiết lập dự án và thêm phụ thuộc Aspose.Cells

### Người dùng Maven

Thêm phụ thuộc sau vào tệp `pom.xml` của bạn:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Người dùng Gradle

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

Nếu bạn không sử dụng công cụ xây dựng, đặt JAR đã tải vào thư mục `libs/` và bao gồm nó trong classpath khi biên dịch:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## Bước 2: Tạo một workbook mới và cấu hình bộ xử lý SmartMarker

`SmartMarkerProcessor` đơn giản hoá việc ánh xạ các giá trị JSON vào các ô Excel. Bằng cách gọi `setArrayAsSingle(true)` chúng ta thông báo cho bộ xử lý coi toàn bộ mảng JSON như một giá trị duy nhất, hữu ích khi bạn muốn mỗi phần tử chiếm một ô riêng trong một hàng.

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**Tại sao điều này quan trọng:**  

Tạo workbook trước sẽ cho bạn một nền trắng sạch sẽ. Cấu hình `setArrayAsSingle(true)` ngăn bộ xử lý làm phẳng mảng thành một chuỗi duy nhất (ví dụ, `["A","B","C"]`) và thay vào đó cho phép bạn kiểm soát bố cục một cách thủ công.

## Bước 3: Định nghĩa dữ liệu JSON bạn muốn chèn

Trong hướng dẫn này, chúng ta sử dụng một mảng JSON đơn giản, nhưng cách tiếp cận tương tự hoạt động với các đối tượng, mảng lồng nhau hoặc cấu trúc phức tạp.

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**Mẹo:** Nếu JSON của bạn đến từ một tệp hoặc endpoint REST, hãy thay thế chuỗi nguyên thủy bằng một `String` đọc từ nguồn, ví dụ, `Files.readString(Paths.get("data.json"))`.

## Bước 4: Xử lý workbook với dữ liệu JSON

Bây giờ chúng ta để `SmartMarkerProcessor` ánh xạ mảng JSON lên worksheet đầu tiên. Hành vi mặc định ghi mỗi phần tử vào các ô liên tiếp bắt đầu từ `A1`.

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

Trong nền, Aspose.Cells phân tích JSON, tạo một bảng dữ liệu tạm thời và ghi các giá trị vào worksheet. Vì chúng ta đã đặt `ArrayAsSingle` thành `true`, các phần tử mảng được đặt ngang dọc theo hàng đầu tiên.

## Bước 5: Lưu workbook vào tệp

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

Khi bạn chạy chương trình, bạn sẽ thấy một tệp có tên **CreatedFromJson.xlsx** trong thư mục làm việc của mình. Mở nó bằng Excel (hoặc bất kỳ trình xem tương thích nào) sẽ hiển thị:

| A | B | C |
|---|---|---|
| A | B | C | *(các giá trị xuất hiện trong các ô A1, B1, C1)*

### Kết quả mong đợi

```
Workbook saved to CreatedFromJson.xlsx
```

Và sheet Excel trông như sau:

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## Bước 6: Xử lý các cấu trúc JSON phức tạp hơn (tùy chọn)

### 6.1 Đổ dữ liệu vào workbook từ một đối tượng JSON

Nếu JSON của bạn là một đối tượng thay vì một mảng, bạn vẫn có thể sử dụng `SmartMarkerProcessor`. Ví dụ:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

Bộ xử lý sẽ tạo các phạm vi có tên (`title`, `month`, `values`) mà bạn có thể tham chiếu trong mẫu Excel bằng các Smart Marker như `&=title` và `&=values`.

### 6.2 Chuyển đổi một mảng JSON lồng nhau thành danh sách dọc

Đôi khi bạn cần mảng điền vào một cột thay vì một hàng. Đặt ô bắt đầu thủ công trước khi xử lý:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

Bây giờ các giá trị **A**, **B**, **C** xuất hiện trong các ô A2, A3, A4 tương ứng.

## Những lỗi thường gặp và cách tránh chúng

| Issue | Cause | Fix |
|-------|-------|-----|
| **Mảng được ghi dưới dạng một chuỗi duy nhất** | `setArrayAsSingle(false)` (mặc định) | Call `processor.setArrayAsSingle(true)` |
| **Không tìm thấy tệp khi lưu** | Đường dẫn không hợp lệ hoặc thiếu quyền ghi | Use an absolute path or ensure the directory exists |
| **Lỗi phân tích JSON** | Chuỗi JSON không hợp lệ | Validate JSON with a tool or use a library like Jackson to generate the string |
| **Các ô bị ghi đè không mong muốn** | Xử lý cùng worksheet nhiều lần mà không đặt lại ô bắt đầu | Call `processor.setStartCell("A1")` before each `process` call |

## Mẹo chuyên nghiệp: tái sử dụng workbook như một mẫu

Thay vì bắt đầu từ một workbook trống mỗi lần, bạn có thể tải một mẫu đã được thiết kế sẵn có sẵn các tiêu đề, công thức hoặc kiểu dáng:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

Cách tiếp cận này kết hợp sự tinh tế về hình ảnh của một tệp Excel được tạo thủ công với việc tự động hoá của **populate workbook from json**.

## Kết luận

Bây giờ bạn đã biết cách tạo các chương trình **create Excel workbook java** để **populate Excel from JSON**, **convert JSON array excel**, và nói chung **populate workbook from json** bằng `SmartMarkerProcessor` của Aspose.Cells. Ví dụ đầy đủ bao gồm:

1. Thiết lập dự án với phụ thuộc Aspose.Cells,
2. Tạo workbook,
3. Định nghĩa JSON,
4. Xử lý bằng `SmartMarkerProcessor`,
5. Lưu kết quả,
6. Xử lý tùy chọn cho đối tượng, mảng dọc và mẫu.

Bạn có thể tự do thử nghiệm bằng cách:

* Tải JSON từ một dịch vụ web,
* Ánh xạ các đối tượng lồng nhau vào nhiều worksheet,
* Thêm kiểu dáng cho ô sau khi dữ liệu đã được ghi,
* Xuất ra các định dạng khác như CSV hoặc PDF.

Với những khối xây dựng này, bạn có thể tự động hoá bất kỳ quy trình báo cáo nào chuyển dữ liệu từ các API JSON trực tiếp vào bảng tính Excel—nhanh, đáng tin cậy và hoàn toàn dưới sự kiểm soát của mã của bạn.
