# Cómo generar hojas de cálculo en Java usando SmartMarkerProcessor

Si necesitas **cómo generar hojas de cálculo** en un archivo Excel, esta guía te muestra una solución completa y lista para ejecutar. Al final de las dos primeras frases comprenderás cómo generar hojas de cálculo y hojas de Excel dinámicas a partir de una colección de objetos, y tendrás un ejemplo de código funcional que automatiza la creación de Excel con una única llamada a método.

Crear hojas de cálculo separadas para cada empleado, proyecto o cualquier otra entidad es un requisito común cuando necesitas **poblar el libro de Excel** de forma programática. Este tutorial recorre cada paso—desde la configuración de la plantilla hasta el procesamiento de una lista y el guardado del archivo final—para que puedas aplicar la técnica al instante en tus propias aplicaciones Java.

## Lo que lograrás

* Generar una hoja maestra que enumere información de alto nivel.  
* Crear **múltiples hojas a partir de una lista** de datos, cada hoja nombrada automáticamente.  
* **Automatizar la creación de Excel** sin añadir filas o columnas manualmente.  
* **Poblar el libro de Excel** con estructuras de datos ricas (objetos, mapas, arrays).  

Requisitos previos:

* Java 8 o superior instalado.  
* Maven (u otra herramienta de compilación) para añadir la biblioteca Aspose.Cells for Java.  
* Una comprensión básica de las colecciones de Java.  

> **Consejo profesional:** La sintaxis de SmartMarker (`${EmployeeMaster}`) funciona con cualquier tipo de colección que implemente `java.util.Collection`. Úsala para mantener tus plantillas limpias y mantenibles.

## Cómo generar hojas de cálculo con SmartMarkerProcessor

Esta sección contiene el código central que hace que **cómo generar hojas de cálculo** sea sencillo. Explicaremos por qué cada línea es importante, no solo lo que hace.

### Paso 1: Añadir la dependencia Aspose.Cells

Si utilizas Maven, incluye lo siguiente en tu `pom.xml`. La biblioteca proporciona la clase `SmartMarkerProcessor` usada a lo largo de esta guía.

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **Por qué:** Aspose.Cells maneja la I/O de archivos Excel, el análisis de Smart Markers y la gestión de hojas internamente, permitiéndote centrarte en los datos en lugar de en operaciones de archivo de bajo nivel.

### Paso 2: Preparar la plantilla Excel

Crea un archivo Excel llamado `EmployeeTemplate.xlsx` con una única celda que contenga el marcador Smart Marker:

| A |
|---|
| `${EmployeeMaster}` |

Cuando el procesador se ejecute, reemplazará este marcador con una **hoja de detalle** que contiene una fila por empleado.

> **Por qué:** El marcador indica al procesador dónde inyectar los datos. Usar una plantilla separada mantiene tu formato (fuentes, bordes, anchura de columnas) intacto.

### Paso 3: Definir el modelo de datos

A continuación se muestra una clase mínima `Employee` y un método auxiliar que construye una lista de empleados. La lista se usará para demostrar **múltiples hojas a partir de una lista**.

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **Por qué:** Un objeto Java simple (POJO) se asigna directamente a los campos del Smart Marker (`firstName`, `lastName`, `department`). Esto hace que **poblar el libro de Excel** sea sencillo y tipado de forma segura.

### Paso 4: Configurar el SmartMarkerProcessor

Ahora conectamos todo. El procesador leerá la plantilla, reemplazará el marcador y creará una nueva hoja llamada `EmployeeDetail`.

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

**Explicación de las líneas clave**

| Línea | Razón |
|------|--------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | Carga la plantilla que ya contiene el marcador Smart Marker. |
| `data.put("EmployeeMaster", employees);` | Vincula la lista Java al marcador `${EmployeeMaster}`. |
| `processor.setDetailSheetNewName("EmployeeDetail");` | Asigna a la hoja generada un nombre significativo en lugar del predeterminado `Sheet1`. |
| `processor.process(wb, data);` | **Cómo generar hojas de cálculo** – el procesador lee el marcador, crea una nueva hoja y la llena con filas para cada `Employee`. |
| `wb.save("EmployeesReport.xlsx");` | Persiste las **hojas de Excel dinámicas** en disco. |

### Paso 5: Verificar la salida

Abre `EmployeesReport.xlsx`. Deberías ver dos hojas de cálculo:

1. **Sheet1** – la plantilla original (puede ocultarse o eliminarse).  
2. **EmployeeDetail** – una **hoja de Excel dinámica** con columnas `firstName`, `lastName`, `department` y una fila por empleado.

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **Por qué es importante:** El archivo ahora contiene **múltiples hojas a partir de una lista** sin ningún bucle manual ni direccionamiento de celdas. El motor de Smart Marker se encarga de crear filas, convertir datos y heredar el formato.

### Paso 6: Manejar casos límite

#### Lista de datos vacía

Si `employees` está vacío, el procesador aún crea la hoja `EmployeeDetail` pero la deja en blanco. Puedes evitar que se añada la hoja comprobando el tamaño de la colección antes del procesamiento:

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### Listas muy grandes

Para miles de filas, considera aumentar la asignación de memoria (`-Xmx2g`) o usar `processor.setAutoFitRows(false)` para acelerar el procesamiento.

#### Nomenclatura personalizada de hojas por grupo

Si necesitas una hoja separada para cada departamento, puedes usar **hojas de detalle múltiples**:

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

El marcador `${department}` se toma de cada objeto `Employee`, produciendo hojas como `Dept_Sales`, `Dept_Marketing`, etc.
