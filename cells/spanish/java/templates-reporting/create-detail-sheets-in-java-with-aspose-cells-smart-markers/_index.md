# Crear hojas de detalle en Java con marcadores inteligentes de Aspose.Cells

Si necesitas **crear hojas de detalle** en una aplicación Java, este tutorial te muestra cómo hacerlo con los marcadores inteligentes de Aspose.Cells. Verás un ejemplo completo y ejecutable que **java create worksheets**, deriva el **sheet name from field**, y **process data source** en solo unas pocas líneas de código.

La guía cubre todo, desde la configuración del proyecto hasta el guardado del libro final, para que puedas copiar‑pegar la solución en tu propio proyecto y adaptarla al instante. No se requiere documentación externa; todo lo que necesitas está aquí.

## Lo que aprenderás

* Cómo **use smart markers** para duplicar una hoja de plantilla por cada fila en un conjunto de datos maestro.  
* Cómo establecer dinámicamente el nombre de cada nueva hoja basado en el valor de un campo (p. ej., `Order_123`).  
* Cómo alimentar una colección Java como **process data source** para el motor de marcadores inteligentes.  
* Consejos para manejar casos límite como datos vacíos, caracteres especiales en nombres de hoja y consideraciones de rendimiento para conjuntos de datos grandes.

### Requisitos previos

| Requisito | Razón |
|-------------|--------|
| Java 8 o superior | Aspose.Cells for Java soporta Java 8+. |
| Sistema de compilación Maven o Gradle | Simplifica la inclusión de la dependencia Aspose.Cells. |
| Conocimientos básicos de colecciones Java | Necesarios para construir la fuente de datos para los marcadores inteligentes. |
| Un archivo Excel de plantilla (`Template.xlsx`) con un marcador inteligente de sustitución en la celda **A1** | La plantilla impulsa la generación de las hojas de detalle. |

> **Consejo profesional:** Mantén el libro de plantilla en la carpeta `resources` del proyecto para que se empaquete con tu JAR.

## Paso 1: Añadir Aspose.Cells a tu proyecto (java create worksheets)

Si usas **Maven**, agrega la siguiente dependencia a `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

Para **Gradle**, coloca esta línea en `build.gradle`:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

Estas líneas ponen a disposición las APIs **java create worksheets** en tiempo de compilación.

## Paso 2: Cargar el libro de plantilla

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*Por qué es importante:* El objeto `Workbook` es el punto de entrada para todas las operaciones de Excel. Cargar la plantilla garantiza que comiences con el diseño correcto y cualquier formato predefinido.

## Paso 3: Insertar un marcador inteligente que crea una nueva hoja por fila maestra (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

La sintaxis `${Orders:DetailSheetNewName=Order_${OrderId}}` es el núcleo de **use smart markers**. Hace tres cosas:

1. Itera sobre la colección `Orders`.  
2. Crea una **new worksheet** para cada elemento.  
3. Establece el **sheet name from field** `OrderId` (con el prefijo `Order_`).

## Paso 4: Preparar la fuente de datos (process data source)

A continuación se muestra un ejemplo mínimo usando un `List<Map<String, Object>>`. Reemplázalo con tu fuente de datos real: filas de base de datos, deserialización JSON, etc.

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*Por qué es importante:* El paso **process data source** enlaza tu colección Java con el motor de marcadores inteligentes. La clave (`"Orders"`) debe coincidir exactamente con el nombre del marcador inteligente.

## Paso 5: Procesar los marcadores inteligentes (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

Cuando se ejecuta `process`, Aspose.Cells lee la colección `Orders`, clona la hoja de plantilla para cada entrada y renombra cada hoja según el campo `OrderId`. Este es el corazón del uso de **process data source**.

## Paso 6: Guardar el libro con las hojas de detalle duplicadas

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

Tras la ejecución, encontrarás `DuplicatedDetailSheets.xlsx` con:

* `Sheet1` – la plantilla original (sin cambios).  
* `Order_101` – hoja de detalle para el primer pedido.  
* `Order_102` – hoja de detalle para el segundo pedido.

### Salida esperada (extracto)

| Nombre de hoja | A1 (smart marker) | Contenido resultante |
|----------------|-------------------|----------------------|
| Order_101      | `${Orders:...}`   | Pobladado con datos de `order1` |
| Order_102      | `${Orders:...}`   | Pobladado con datos de `order2` |

Abre el archivo en Excel para verificar que cada hoja tiene el nombre correcto y contiene las filas de datos.

## Manejo de variaciones comunes y casos límite

### Fuente de datos vacía

Si `orders` está vacío, el procesador de marcadores inteligentes **no crea nuevas worksheets**. Para evitar un libro vacío, añade una protección:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### Caracteres especiales en nombres de hoja

Los nombres de hoja de Excel no pueden contener `\ / ? * [ ] :`. Limpia el campo antes de usarlo:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### Conjuntos de datos grandes

Para miles de filas, considera aumentar el heap de la JVM (`-Xmx2g`) y llamar a `workbook.calculateFormula()` solo después de generar todas las hojas para mejorar el rendimiento.
