# Importar objetos personalizados a Excel con Aspose.Cells – Guía Java

Si necesita **importar objetos personalizados** a una hoja de cálculo de Excel, esta guía le muestra el proceso completo usando Aspose.Cells para Java. Verá cómo **importar datos a Excel**, aplicar un estilo de encabezado en negrita y generar un archivo `.xlsx` listo para compartir.

Exportar datos tabulares desde Java a menudo implica escrituras manuales celda por celda, lo que es propenso a errores y difícil de mantener. Al aprovechar la API `importCustomObjects` evitas código repetitivo, mantienes intacto tu modelo de datos y obtienes un control de estilo granular.

En este tutorial usted:

* Creará una lista de objetos Java `Map` que imita una tabla de datos típica.
* Creará un estilo de encabezado reutilizable (fuente en negrita) con Aspose.Cells.
* Importará los objetos personalizados a una hoja de cálculo mientras aplica la matriz de estilos.
* Guardará el libro de trabajo en disco y verificará el resultado.

El único requisito previo es un entorno de desarrollo Java (JDK 8+ recomendado) y la biblioteca Aspose.Cells para Java.

---

## Lo que necesitará

| Requisito | Razón |
|-----------|-------|
| JDK 8 o superior | Necesario para compilar y ejecutar el código Java. |
| Aspose.Cells para Java (última versión) | Proporciona las APIs `Workbook`, `Worksheet` y de importación. |
| IDE o herramienta de compilación (p. ej., Maven, Gradle) | Simplifica la gestión de dependencias y la ejecución. |
| Permiso de escritura en una carpeta para el archivo de salida | El libro de trabajo se guarda como `ImportWithStyle.xlsx`. |

Agregue la dependencia de Aspose.Cells a su `pom.xml` si usa Maven:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## Paso 1: Preparar los objetos personalizados para importar

El primer paso es crear una colección que represente las filas que desea colocar en Excel. En este ejemplo usamos un `List<Map<String,Object>>` donde cada mapa actúa como una fila con los nombres de columna como claves.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Por qué es importante:**  
`importCustomObjects` espera una matriz de objetos. Al usar un `Map`, conserva los nombres de columna, lo que permite a Aspose.Cells mapearlos automáticamente a celdas. Este enfoque refleja una típica `DataTable` en .NET o un `ResultSet` de JDBC, haciendo que el código sea reutilizable en distintos proyectos.

---

## Paso 2: Definir un estilo de encabezado para aplicar al importar

Una fila de encabezado clara mejora la legibilidad. Aspose.Cells le permite crear un objeto `Style`, establecer su fuente en negrita y pasarlo mediante una matriz `ImportTableOptions`.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Por qué es importante:**  
Si omite la matriz de estilos, el encabezado aparecerá con la fuente predeterminada, lo que puede pasar desapercibido. Al preparar el estilo una sola vez, evita llamadas repetitivas para cada fila y mantiene limpia la lógica de importación.

---

## Paso 3: Importar los objetos personalizados con la matriz de estilos

Ahora combina los datos y el estilo, y luego llama a `importCustomObjects`. El método coloca los datos comenzando en la esquina superior‑izquierda (fila 0, columna 0) y aplica automáticamente el estilo de encabezado.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Por qué es importante:**  
`importCustomObjects` analiza cada mapa, crea columnas basadas en las claves (`Name`, `Score`) y escribe los valores en las celdas correspondientes. El objeto `ImportTableOptions` indica a Aspose.Cells que use `styleArray` para la primera fila, proporcionando un encabezado en negrita sin código adicional.

---

## Paso 4: Guardar el libro de trabajo y verificar la salida

Finalmente, escriba el libro de trabajo en un archivo. El archivo Excel generado contiene una fila de encabezado con estilo seguida de las filas de datos.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Resultado esperado:**  

| **Nombre** | **Puntuación** |
|------------|----------------|
| Alice      | 95             |
| Bob        | 82             |

## Variaciones comunes y casos límite

| Situación | Ajuste recomendado |
|-----------|--------------------|
| **Orden de columnas diferente** | Asegúrese de que las claves del `Map` se inserten en el orden deseado, o use un POJO personalizado con campos anotados y una matriz `PropertyDescriptor`. |
| **Conjuntos de datos grandes (>10 000 filas)** | Aumente `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` para evitar `OutOfMemoryError`. |
| **Formatos numéricos personalizados** | Añada un segundo `Style` en `styleArray` para las filas de datos, por ejemplo, establezca `NumberFormat` a `"0"` para puntuaciones enteras. |
| **Múltiples hojas de cálculo** | Llame a `importCustomObjects` en cada hoja de destino, ajustando la fila/columna de inicio según sea necesario. |
| **Texto de encabezado específico por locale** | Complete la fila de encabezado manualmente antes de la importación, luego aplique el estilo a todo el rango usando `Cells.applyStyle`. |

---

## Consejos profesionales para una exportación Java a Excel robusta

* **Reutilizar el libro de trabajo temporal** – Crear un nuevo `Workbook` para cada estilo genera sobrecarga. Mantenga una única instancia si necesita varios estilos.  
* **Validar los datos antes de la importación** – Los valores nulos en un mapa se convierten en celdas vacías; puede reemplazarlos por valores predeterminados preprocesando la lista.  
* **Cerrar recursos** – Aunque Aspose.Cells gestiona la memoria internamente, llamar explícitamente a `workbook.dispose()` después de guardar libera los recursos nativos de inmediato.  
* **Establecer `Workbook.setForceFullCalculation(true)`** si su libro contiene fórmulas que deben evaluarse antes de guardarse.
