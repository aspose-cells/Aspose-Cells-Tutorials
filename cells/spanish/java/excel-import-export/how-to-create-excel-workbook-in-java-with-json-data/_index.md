# Cómo crear un libro de Excel en Java con datos JSON

Si necesitas **crear Excel workbook java** los desarrolladores a menudo se enfrentan al desafío de cargar datos JSON en una hoja de cálculo. Esta guía te muestra cómo **populate Excel from JSON**, incluyendo cómo **convert JSON array excel** y **populate workbook from json** de manera limpia y repetible.

Trabajar con JSON es común cuando los servicios exponen datos a través de APIs REST, y Excel sigue siendo el formato preferido para informes y análisis. Al final de este tutorial tendrás un programa Java ejecutable que:

* crea un nuevo libro de Excel,
* lee un array JSON (o cualquier estructura JSON) y escribe sus valores en celdas,
* guarda el archivo en disco listo para procesamiento posterior.

No se requieren herramientas externas más allá de la biblioteca Aspose.Cells for Java, que proporciona el `SmartMarkerProcessor` usado en el código de ejemplo.

## Prerrequisitos

Antes de comenzar, asegúrate de tener:

| Requisito | Razón |
|--------------|--------|
| Java Development Kit (JDK) ≥ 8 | Necesario para compilar y ejecutar el ejemplo |
| Maven o Gradle (opcional) | Simplifica la gestión de dependencias |
| Aspose.Cells for Java (v23.10 o posterior) | Proporciona las clases `Workbook` y `SmartMarkerProcessor` |
| Conocimientos básicos de JSON y Java I/O | Ayudan a comprender el flujo de datos |

Si prefieres no usar una herramienta de compilación, puedes descargar el JAR de Aspose.Cells desde el [Aspose website](https://products.aspose.com/cells/java/) y añadirlo manualmente al classpath de tu proyecto.

## Paso 1: Configura el proyecto y añade la dependencia de Aspose.Cells

### Usuarios de Maven

Añade la siguiente dependencia a tu `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Usuarios de Gradle

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

Si no utilizas una herramienta de compilación, coloca el JAR descargado en la carpeta `libs/` e inclúyelo en el classpath al compilar:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## Paso 2: Crea un nuevo libro y configura el procesador SmartMarker

El `SmartMarkerProcessor` simplifica el mapeo de valores JSON a celdas de Excel. Al llamar a `setArrayAsSingle(true)` indicamos al procesador que trate un array JSON completo como un solo valor, lo cual es útil cuando deseas que cada elemento ocupe su propia celda en una fila.

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**Por qué es importante:**  
Crear el libro de antemano te brinda un lienzo limpio. Configurar `setArrayAsSingle(true)` evita que el procesador aplane el array en una única cadena (p. ej., `["A","B","C"]`) y, en su lugar, te permite controlar el diseño manualmente.

## Paso 3: Define los datos JSON que deseas insertar

Para este tutorial usamos un array JSON sencillo, pero el mismo enfoque funciona con objetos, arrays anidados o estructuras complejas.

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**Consejo:** Si tu JSON proviene de un archivo o de un endpoint REST, reemplaza la cadena literal por un `String` leído de la fuente, por ejemplo, `Files.readString(Paths.get("data.json"))`.

## Paso 4: Procesa el libro con los datos JSON

Ahora dejamos que el `SmartMarkerProcessor` mapee el array JSON a la primera hoja de cálculo. El comportamiento predeterminado escribe cada elemento en celdas sucesivas a partir de `A1`.

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

Detrás de escena, Aspose.Cells analiza el JSON, crea una tabla de datos temporal y escribe los valores en la hoja. Como hemos establecido `ArrayAsSingle` en `true`, los elementos del array se colocan horizontalmente a lo largo de la primera fila.

## Paso 5: Guarda el libro en un archivo

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

Al ejecutar el programa, deberías ver un archivo llamado **CreatedFromJson.xlsx** en tu directorio de trabajo. Al abrirlo con Excel (o cualquier visor compatible) se mostrará:

| A | B | C |
|---|---|---|
| A | B | C | *(los valores aparecen en las celdas A1, B1, C1)*

### Salida esperada

```
Workbook saved to CreatedFromJson.xlsx
```

Y la hoja de Excel se ve así:

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## Paso 6: Manejo de estructuras JSON más complejas (opcional)

### 6.1 Poblar un libro a partir de un objeto JSON

Si tu JSON es un objeto en lugar de un array, aún puedes usar `SmartMarkerProcessor`. Por ejemplo:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

El procesador creará rangos con nombre (`title`, `month`, `values`) que puedes referenciar en tu plantilla de Excel usando Smart Markers como `&=title` y `&=values`.

### 6.2 Convertir un array JSON anidado a una lista vertical

A veces necesitas que el array llene una columna en vez de una fila. Establece la celda de inicio manualmente antes del procesamiento:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

Ahora los valores **A**, **B**, **C** aparecen en las celdas A2, A3, A4 respectivamente.

## Problemas comunes y cómo evitarlos

| Problema | Causa | Solución |
|-------|-------|-----|
| **Array escrito como una única cadena** | `setArrayAsSingle(false)` (valor predeterminado) | Llama a `processor.setArrayAsSingle(true)` |
| **Archivo no encontrado al guardar** | Ruta inválida o permisos de escritura insuficientes | Usa una ruta absoluta o asegura que el directorio exista |
| **Error de análisis JSON** | Cadena JSON malformada | Valida el JSON con una herramienta o usa una biblioteca como Jackson para generar la cadena |
| **Celdas sobrescritas sin intención** | Procesar la misma hoja varias veces sin reiniciar la celda de inicio | Llama a `processor.setStartCell("A1")` antes de cada llamada a `process` |

## Consejo profesional: reutilizar el libro de trabajo como plantilla

En lugar de comenzar con un libro en blanco cada vez, puedes cargar una plantilla pre‑diseñada que ya contenga encabezados, fórmulas o estilos:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

Este enfoque combina el acabado visual de un archivo Excel elaborado a mano con la automatización de **populate workbook from json**.
