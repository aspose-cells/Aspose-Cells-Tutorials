# Cómo crear un libro de Excel C# con formato personalizado y guardarlo como XLSX

Si necesitas **crear un libro de Excel C#** que importe datos, aplique un formato numérico personalizado y cambie el color de fuente de la celda, este tutorial te muestra exactamente cómo. Obtendrás un ejemplo listo‑para‑ejecutar que produce un archivo `StyleArrayImport.xlsx` con estilo en segundos.

Trabajar con Excel desde C# a menudo implica pasos manuales repetitivos—definir formatos, aplicar colores y recordar guardar el archivo correctamente. Al final de esta guía automatizarás todas esas tareas, de modo que puedas centrarte en los datos en lugar de la interfaz.

Aprenderás a:

* importar un `DataTable` a una hoja de cálculo,
* usar un `StyleArray` para **aplicar formato numérico personalizado** y **cambiar el color de fuente de la celda**,
* **guardar el libro como XLSX** con una única llamada a método,
* y verificar que el **formato de datos importados en Excel** aparece exactamente como se pretende.

El único requisito previo es una referencia a la biblioteca **Aspose.Cells for .NET** (o cualquier API compatible que proporcione `Workbook`, `Worksheet` y `StyleArray`). El código está dirigido a .NET 6+, pero versiones anteriores funcionan con ajustes menores.

---

## Prerequisitos

| Requisito | Razón |
|-----------|-------|
| .NET 6 SDK o posterior | Proporciona el runtime para la aplicación de consola C#. |
| Aspose.Cells for .NET (paquete NuGet `Aspose.Cells`) | Suministra las clases `Workbook`, `Worksheet` y `StyleArray` usadas en el ejemplo. |
| Visual Studio 2022 (o cualquier IDE de C#) | Facilita compilar y ejecutar la muestra. |
| Conocimientos básicos de manipulación de `DataTable` | Necesarios para generar el conjunto de datos de origen. |

Instala el paquete Aspose.Cells con el siguiente comando:

```bash
dotnet add package Aspose.Cells
```

## Paso 1: Preparar el DataTable de ejemplo

Primero, crea un `DataTable` que imite los datos que normalmente obtendrías de una base de datos u otra fuente. La tabla incluye una columna **Name** (cadena) y una columna **Amount** (decimal) que formatearemos más adelante.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Por qué esto es importante:** Usar un `DataTable` te permite mantener la lógica de importación independiente de la fuente de datos, lo cual es un patrón común al generar informes desde bases de datos, archivos CSV o APIs.

---

## Paso 2: Definir un StyleArray para **aplicar formato numérico personalizado** y **cambiar el color de fuente de la celda**

`StyleArray` te permite agrupar instrucciones de formato que se aplicarán a cada celda importada desde el `DataTable`. En este ejemplo:

* establecemos `Number` a `#,##0.00` – un formato contable típico con separadores de miles,
* establecemos `FontColor` a `Color.Blue` – haciendo que los números resalten.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**¿Por qué usar un StyleArray?** Aplicar un estilo en el momento de la importación evita una segunda pasada sobre la hoja, lo que mejora el rendimiento para conjuntos de datos grandes.

---

## Paso 3: **Crear libro de Excel C#** – instanciar Workbook y obtener la primera Worksheet

Ahora creamos un libro vacío y obtenemos una referencia a la primera hoja de cálculo (índice 0). Esta hoja será el destino de nuestros datos importados.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Explicación:** `Workbook` representa todo el archivo Excel, mientras que `Worksheet` representa una sola pestaña. El libro predeterminado contiene una hoja, lo cual es suficiente para la mayoría de los informes simples.

---

## Paso 4: Importar el DataTable usando el **StyleArray** para **formatear datos importados en Excel**

El método `ImportDataTable` copia las filas y columnas de la tabla a la hoja, comenzando en la celda `A1` (fila 0, columna 0). El argumento `true` indica que se incluyan los encabezados de columna. Como pasamos `styleArray`, cada celda importada recibe el formato numérico personalizado y el color de fuente.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**Qué ocurre bajo el capó:** Aspose.Cells itera sobre cada fila, escribe el valor y luego aplica el estilo definido en `styleArray`. Los números aparecen con comas y dos decimales, y el texto se muestra en azul.

---

## Paso 5: **Guardar el libro como XLSX** – escribir el archivo en disco

Finalmente, persiste el libro en un archivo `.xlsx`. Puedes cambiar la ruta a cualquier directorio escribible en tu máquina.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Verificación del resultado:** Abre el archivo generado en Excel. Deberías ver las tres filas de datos, la columna **Amount** formateada con comas, dos decimales y mostrada con fuente azul. Esto confirma que el paso **formatear datos importados en Excel** se completó con éxito.

## Ejemplo completo funcionando

Copia todo el bloque a continuación en un nuevo proyecto de consola y ejecútalo. No se requiere código adicional.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Salida esperada en la consola:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

Abre el archivo y verifica que la columna **Amount** muestre valores como `1,234.56` en fuente azul.

## Preguntas frecuentes y casos límite

| Pregunta | Respuesta |
|----------|-----------|
| *¿Puedo aplicar diferentes formatos a columnas individuales?* | Sí. Después de importar, obtén el objeto `Style` de la columna (`worksheet.Cells.Columns[1].Style`) y establece un `Number` o `FontColor` diferente. |
| *¿Qué pasa si necesito formatear fechas en lugar de números?* | Establece `styleArray.Number = "mm-dd-yyyy"` y, opcionalmente, `styleArray.FontColor` para las celdas de fecha. |
| *¿Es la fuente azul visible en temas oscuros de Excel?* | El azul puede ser difícil de leer sobre fondos oscuros. Usa un tono más claro (`Color.LightBlue`) o un color contrastante (`Color.Black`). |
| *¿Cómo importo un DataTable muy grande (cientos de miles de filas)?* | Usa `ImportDataTable` con la sobrecarga `ImportDataTableOptions` para transmitir datos, o divide la importación en varias hojas para permanecer dentro del límite de filas de Excel (1 048 576 filas). |
| *¿Puedo exportar a CSV en lugar de XLSX?* | Reemplaza `SaveFormat.Xlsx` por `SaveFormat.Csv`. Ten en cuenta que la información de formato (formato numérico, color de fuente) se pierde en CSV porque es un formato de texto plano. |

---

## Consejos para uso en producción

* **Pro tip:** Cachea el objeto `Style` si necesitas aplicar el mismo formato a muchas hojas; crear un nuevo `StyleArray` para cada importación añade sobrecarga.
* **Cuidado con las diferencias culturales:** El patrón `Number` `#,##0.00` sigue la cultura invariante. Si necesitas separadores específicos de locale, usa `NumberFormatInfo` o deja que Excel lo gestione según la configuración regional del usuario.
* **Manejo de errores:** Envuelve la llamada a `Save` en un bloque try‑catch para gestionar excepciones de I/O (p. ej., permisos insuficientes o archivos bloqueados).
