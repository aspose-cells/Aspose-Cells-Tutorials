# Crear archivo excel c# – estilo de celdas y establecer formato de moneda

Si necesitas **crear archivo excel c#** que tenga aspecto profesional, esta guía te muestra exactamente cómo aplicar estilo a las celdas de excel y formatear una columna como moneda. Verás un ejemplo completo, de extremo a extremo, que importa un `DataTable`, aplica un encabezado en negrita y establece un formato numérico `$#,##0.00` para la columna de precio.

El tutorial cubre todo lo que necesitas: paquetes NuGet requeridos, el código fuente completo, explicaciones de por qué cada parte es importante y consejos para manejar casos límite como filas vacías o diferentes configuraciones regionales. Al final podrás generar un archivo `.xlsx` con una columna de precios bien formateada en solo unas pocas líneas de C#.

## Requisitos previos

- .NET 6.0 o posterior (el código también funciona con .NET Framework 4.6+)
- Visual Studio 2022 o cualquier editor de C# que prefieras
- La biblioteca **Aspose.Cells for .NET** o **GemBox.Spreadsheet** (ambas soportan `ImportTableOptions`). El ejemplo a continuación usa **Aspose.Cells** porque proporciona una propiedad `StyleArray` simple.
- Conocimientos básicos de colecciones de C# y `DataTable`

> **Consejo profesional:** Si prefieres una alternativa gratuita, reemplaza `Aspose.Cells` por `GemBox.Spreadsheet`. La API para importar un `DataTable` con estilos es casi idéntica; solo cambia el espacio de nombres y el nombre del paquete NuGet.

## Paso 1: Instalar la biblioteca Excel

Abre el Administrador de paquetes NuGet e instala la biblioteca:

```bash
dotnet add package Aspose.Cells
```

> **¿Por qué este paso?** La biblioteca proporciona las clases `Workbook`, `Worksheet`, `Style` y `ImportTableOptions` que se usan más adelante. Sin ella, tendrías que escribir el formato Office Open XML manualmente, lo cual es propenso a errores.

## Paso 2: Crear un DataTable con datos de ejemplo

Un `DataTable` es una forma conveniente de mantener datos tabulares antes de exportarlos a Excel. En este ejemplo tenemos dos columnas: *Product* y *Price*.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Explicación:**  
> - `Columns.Add("Price", typeof(double))` indica a la tabla que trate los valores de precio como números, lo cual es necesario para el formateo numérico posterior.  
> - Añadir algunas filas nos brinda datos para verificar el paso de **format column currency**.

## Paso 3: Definir los estilos que deseas aplicar

Crearemos una matriz de objetos `Style` que coincida con el orden de las columnas. La primera entrada aplica estilo a la fila de encabezado, la segunda deja la columna *Product* sin cambios, y la tercera aplica un formato numérico de moneda.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### ¿Por qué usar una **style array**?

`ImportTableOptions.StyleArray` asigna cada columna a un `Style`. Esta es la forma más eficiente de **add number format** y **style excel cells** en una única operación de importación, evitando una segunda pasada sobre la hoja de cálculo.

## Paso 4: Configurar opciones de importación

Ahora vinculamos la style array a la operación de importación. El objeto `ImportTableOptions` también permite controlar si la primera fila se trata como encabezado.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Nota:** `IsFieldNameShown` tiene como valor predeterminado `true`, pero establecerlo explícitamente deja la intención clara para futuros lectores.

## Paso 5: Crear un libro de trabajo, importar la tabla y guardar

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### Resultado esperado

Al abrir `DataTableWithStyles.xlsx`:

- La primera fila (encabezado) está en **negrita**.
- La columna *Price* muestra los valores como **$1.20**, **$3.50**, **$0.75**.
- La columna *Product* conserva la fuente predeterminada.

Has creado con éxito **un archivo excel c#** con una columna de moneda formateada y celdas de encabezado con estilo.

## Paso 6: Manejo de variaciones comunes y casos límite

### a. Configuración regional diferente o símbolo de moneda personalizado

Si necesitas euros u otra moneda, reemplaza el formato incorporado `164` con una cadena de formato personalizada:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. Añadir más columnas más adelante

Cuando añadas columnas extra, amplía la matriz `columnStyles` en consecuencia. Usa `null` para las columnas que deben mantener el estilo predeterminado.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. DataTable vacío

Si el `DataTable` no tiene filas, Aspose.Cells aún crea la fila de encabezado. Sin embargo, el libro de trabajo contendrá solo una fila. Para evitar un archivo vacío, verifica el recuento de filas antes de importar:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Usar `GemBox.Spreadsheet` en lugar de Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

La lógica sigue siendo idéntica, demostrando que el tutorial es **format column currency** independiente de la biblioteca subyacente.

## Paso 7: Verificar el archivo programáticamente (opcional)

Puedes abrir el libro de trabajo generado y afirmar que el formato numérico se aplicó correctamente—útil para pruebas unitarias.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```
