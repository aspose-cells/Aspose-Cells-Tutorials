# Cómo incrustar fuentes al guardar Excel en HTML con C#

Incrustar fuentes al guardar un libro de trabajo de Excel en HTML es un requisito común para preservar el aspecto exacto de tus hojas de cálculo en todos los navegadores. Si necesitas exportar Excel a HTML manteniendo los tipos de letra originales, esta guía te muestra una solución completa y lista para ejecutar.

Aprenderás a **exportar Excel a HTML**, **convertir Excel a HTML** con fuentes incrustadas y a evitar el típico problema de “fuente faltante” que rompe el diseño en las máquinas cliente. No se requieren herramientas externas, solo la biblioteca Aspose.Cells y unas pocas líneas de C#.

## Requisitos previos

Antes de comenzar, asegúrate de tener:

* .NET 6.0 (o posterior) instalado.
* Una copia con licencia de **Aspose.Cells for .NET** – la versión de prueba gratuita sirve para pruebas.
* Un IDE como Visual Studio 2022 o VS Code.

Si ya los tienes, puedes pasar directamente al código.

## Paso 1: Crear un libro de trabajo y agregar datos de ejemplo

Primero generamos un libro de trabajo pequeño para que puedas ver el efecto de las fuentes incrustadas. El código a continuación crea una hoja de cálculo, escribe algunas celdas y aplica una fuente personalizada.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### Por qué agregamos una fuente personalizada

Incrustar fuentes solo importa cuando el libro de trabajo usa fuentes que podrían no estar presentes en el dispositivo cliente. Al establecer explícitamente **Arial** (o cualquier otra fuente) podemos verificar que la salida HTML realmente contiene los datos de la fuente.

## Paso 2: Configurar las opciones de guardado HTML para incrustar fuentes

Aspose.Cells proporciona la clase `HtmlSaveOptions`. Configurar `EmbedFonts = true` indica a la biblioteca que incruste los archivos de fuente necesarios directamente en el HTML generado como URIs de datos codificados en Base64.

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### Qué hace realmente “incrustar fuentes en html”

Cuando `EmbedFonts` es true, Aspose.Cells extrae los archivos de fuente del sistema (o de la colección de fuentes incrustadas del libro) y los convierte en cadenas **Base64**. esas cadenas se colocan dentro de un bloque `<style>` usando `@font-face`. El HTML resultante puede abrirse en cualquier dispositivo sin necesidad de que la fuente original esté instalada.

## Paso 3: Guardar el libro de trabajo como HTML con fuentes incrustadas

Ahora escribimos el libro de trabajo en disco. El archivo contendrá los datos de la fuente, de modo que abrirlo en cualquier navegador moderno muestra la tipografía exacta del archivo Excel original.

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### Resultado esperado

* `embedded.html` se encuentra en la carpeta `output`.
* Al abrir el archivo en Chrome, Edge o Firefox se muestra la hoja de cálculo con texto en **Arial**, incluso si la máquina del navegador no tiene Arial.
* Al inspeccionar el código fuente HTML se revela un bloque `<style>` que contiene una regla `@font-face` con una larga declaración `src: url(data:font/ttf;base64,…)` – esa es la fuente incrustada.

## Paso 4: Verificar que el HTML funciona en otra máquina (opcional)

Para estar absolutamente seguro de que la incrustación tuvo éxito:

1. Copia `output/embedded.html` a una computadora diferente (o una máquina virtual) que **no** tenga la fuente personalizada instalada.
2. Abre el archivo en un navegador.
3. El diseño y la tipografía deberían coincidir con la vista original de Excel.

Si la fuente recae en una genérica, verifica que el archivo de fuente sea accesible en la máquina de compilación y que tengas permiso para leerlo.

## Preguntas comunes y casos límite

### ¿Aumenta el tamaño del archivo al incrustar?

Sí. Incrustar una fuente TrueType u OpenType puede añadir **decenas de kilobytes** al archivo HTML. Para libros de trabajo grandes con muchas fuentes únicas, considera:

* Subconjuntar la fuente (solo los caracteres que usas) – Aspose.Cells lo hace automáticamente para la mayoría de fuentes comunes.
* Usar `ExportEmbeddedImages = false` si no necesitas imágenes incrustadas.

### ¿Qué pasa si solo necesito incrustar fuentes específicas?

`HtmlSaveOptions` no expone una lista blanca directa, pero puedes controlar qué fuentes aparecen **limitando las fuentes usadas en el libro de trabajo** antes de llamar a `Save`. Elimina asignaciones de fuentes innecesarias o reemplázalas por fuentes web‑seguras estándar.

### ¿Puedo incrustar fuentes al convertir a otros formatos (p.ej., PDF)?

La misma propiedad `EmbedFonts` existe en `PdfSaveOptions`. El concepto es idéntico: los datos de la fuente se incrustan para que el PDF se renderice correctamente en cualquier visor.

## Ejemplo completo y ejecutable

A continuación se muestra el programa completo que puedes copiar y pegar en un nuevo proyecto de consola.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

Ejecutar el programa genera un **archivo HTML que contiene la fuente Arial incrustada**, garantizando la fidelidad visual donde sea que se abra el archivo.

## Conclusión

Ahora sabes **cómo incrustar fuentes al guardar Excel en HTML** usando C#. Configurando `HtmlSaveOptions.EmbedFonts = true`, puedes exportar Excel a HTML y **convertir Excel a HTML** de forma fiable sin preocuparte por fuentes faltantes en el lado del cliente. Esta técnica es esencial para informes basados en web, paneles amigables para correo electrónico o cualquier escenario donde compartas contenido derivado de Excel como HTML.

### ¿Qué sigue?

* **Personaliza el CSS** generado por Aspose.Cells para que coincida con la guía de estilo de tu sitio.  
* **Incrusta imágenes** selectivamente activando o desactivando `ExportEmbeddedImages`.  
* **Explora otros formatos de exportación** como PDF o SVG mientras sigues incrustando fuentes.  

Siéntete libre de experimentar con diferentes fuentes, hojas de cálculo más grandes o libros de trabajo con varias hojas. La misma bandera `EmbedFonts` funciona en todos los formatos de salida compatibles, dándote un control consistente sobre la incrustación de fuentes donde lo necesites. ¡Feliz codificación!
