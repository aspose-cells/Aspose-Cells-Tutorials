# Cómo incrustar fuentes en HTML al guardar un libro de trabajo

Si necesitas **cómo incrustar fuentes en HTML** al exportar una hoja de cálculo, este tutorial te muestra una solución completa, lista para ejecutar. Ya sea que estés construyendo un portal de informes o una vista de análisis del lado del cliente, incrustar fuentes garantiza que el HTML renderizado se vea exactamente como el libro de trabajo original, sin importar las fuentes instaladas en el visor.

También aprenderás la mejor manera de **guardar libro de trabajo como HTML** usando Aspose.Cells, verás los problemas comunes y obtendrás consejos para manejar libros de trabajo grandes o archivos de fuentes personalizados. No se requiere documentación externa; todo lo que necesitas está en esta guía.

## Requisitos previos

- .NET 6.0 o posterior (el código también funciona con .NET Framework 4.7+)
- Una licencia válida de Aspose.Cells para .NET (o puedes usar el modo de evaluación gratuito)
- Conocimientos básicos de C# y un IDE como Visual Studio 2022
- Los archivos de fuentes TrueType (.ttf) u OpenType (.otf) que deseas incrustar (deben ser accesibles para el proceso en ejecución)

## Paso 1: Configurar el proyecto e importar Aspose.Cells

Crea una nueva aplicación de consola y agrega el paquete NuGet de Aspose.Cells:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

Luego abre **Program.cs** y agrega las directivas `using` requeridas:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **Consejo profesional:** Coloca tus fuentes personalizadas en una carpeta llamada `fonts` dentro de la raíz del proyecto. Esto mantiene la solución portátil y facilita referenciarlas más adelante.

## Paso 2: Crear o cargar un libro de trabajo

Para la demostración, crearemos un libro de trabajo simple con algunas celdas con estilo:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **Por qué es importante:** Si omites el estilo personalizado, el HTML exportado volverá a usar las fuentes predeterminadas del navegador, anulando el propósito de **cómo incrustar fuentes en HTML**.

## Paso 3: Configurar `HtmlSaveOptions` para incrustar fuentes

El núcleo de **cómo incrustar fuentes en HTML** se encuentra en la clase `HtmlSaveOptions`. Configurar `EmbedFonts = true` indica a Aspose.Cells que incruste cualquier fuente TrueType/OpenType referenciada directamente en el HTML generado como URIs de datos codificados en Base64.

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### Cómo funciona la incrustación

Cuando `EmbedFonts` es `true`, Aspose.Cells escanea las definiciones de estilo del libro de trabajo, localiza los archivos de fuentes correspondientes en el sistema (o en la carpeta `fonts` que agregaste), lee sus datos binarios e inserta un bloque `<style>` similar a:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

Dado que los datos de la fuente están codificados directamente en el HTML, la página se renderiza correctamente incluso en máquinas que no tienen la fuente instalada.

## Paso 4: Guardar el libro de trabajo como HTML

Ahora puedes **guardar el libro de trabajo como HTML** con las opciones configuradas. Elige un directorio al que la aplicación pueda escribir (p. ej., `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

Ejecutar el programa genera un único archivo `report.html`. Ábrelo en cualquier navegador moderno y verás el encabezado “Quarterly Sales” renderizado con la fuente **Pacifico**, incluso si la fuente no está instalada en tu sistema operativo.

### Resultado esperado

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

El atributo `src:` contiene una larga cadena Base64; estos son los datos de la fuente incrustada que permiten **cómo incrustar fuentes en HTML**.

## Paso 5: Verificar la incrustación de fuentes y solucionar problemas

1. **Abre el archivo HTML en Chrome o Edge.** Si la fuente personalizada aparece, la incrustación tuvo éxito.  
2. **Inspecciona el código fuente de la página.** Busca la regla `@font-face` generada por Aspose.Cells.  
3. **Problemas comunes:**  
   - *Archivo de fuente faltante:* Asegúrate de que el archivo de fuente sea accesible. Puedes agregar explícitamente una carpeta a la ruta de búsqueda:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *Tamaño grande del HTML:* Incrustar muchas fuentes puede inflar el archivo. Usa `ExportToSingleFile = false` para mantener las fuentes como archivos `.ttf` separados en una carpeta de recursos.

   - *Formato de fuente no compatible:* Aspose.Cells solo incrusta TrueType (`.ttf`) y OpenType (`.otf`). Convierte otros formatos antes de incrustar.

## Ejemplo completo en funcionamiento

A continuación se muestra el programa completo que puedes copiar, pegar y ejecutar sin modificaciones (excepto la línea de licencia opcional).

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

Ejecutar este programa crea `output/report.html`. Abre el archivo y verás la fuente **Pacifico** renderizada correctamente, demostrando **cómo incrustar fuentes en HTML** mientras **guardas el libro de trabajo como HTML**.

## Preguntas frecuentes

| Pregunta | Respuesta |
|----------|----------|
| *¿Puedo incrustar solo fuentes específicas?* | Sí. Configura `htmlOpt.EmbedAllFonts = false` (disponible en versiones más recientes) y usa `htmlOpt.FontsToEmbed` para enumerar los nombres exactos de las fuentes. |
| *¿Qué pasa si necesito incrustar fuentes para varias hojas de cálculo?* | Configura `ExportActiveWorksheetOnly = false` para que se exporten todas las hojas, y Aspose.Cells incrustará las fuentes usadas en todo el libro de trabajo. |
| *¿Las fuentes incrustadas funcionarán en navegadores móviles?* | Los navegadores móviles modernos soportan fuentes codificadas en Base64, por lo que las fuentes incrustadas se renderizan correctamente siempre que el formato de fuente sea compatible (TTF u OTF). |
| *¿Qué tan grande puede llegar a ser el archivo HTML?* | Incrustar una fuente TrueType de 200 KB agrega aproximadamente la misma cantidad al tamaño del HTML (Base64 añade ~33 % de sobrecarga). Para muchas fuentes, considera exportar a una carpeta (`ExportToSingleFile = false`) para mantener el HTML ligero. |
