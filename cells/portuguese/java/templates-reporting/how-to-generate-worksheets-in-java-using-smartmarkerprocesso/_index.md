# Como gerar planilhas em Java usando SmartMarkerProcessor

Se você precisa **gerar planilhas** em um arquivo Excel, este guia mostra uma solução completa e pronta‑para‑executar. Ao final das duas primeiras frases você entenderá como gerar planilhas e planilhas Excel dinâmicas a partir de uma coleção de objetos, e terá um exemplo de código funcional que automatiza a criação do Excel com uma única chamada de método.

Criar planilhas separadas para cada funcionário, projeto ou qualquer outra entidade é um requisito comum quando você precisa **preencher a pasta de trabalho Excel** programaticamente. Este tutorial percorre cada passo — desde a configuração do modelo até o processamento da lista e a gravação do arquivo final — para que você possa aplicar a técnica imediatamente em suas próprias aplicações Java.

## O que você vai alcançar

* Gerar uma planilha mestre que lista informações de alto nível.  
* Criar **várias planilhas a partir de lista** de dados, cada planilha nomeada automaticamente.  
* **Automatizar a criação do Excel** sem adicionar linhas ou colunas manualmente.  
* **Preencher a pasta de trabalho Excel** com estruturas de dados ricas (objetos, mapas, arrays).  

Pré‑requisitos:

* Java 8 ou superior instalado.  
* Maven (ou outra ferramenta de build) para adicionar a biblioteca Aspose.Cells for Java.  
* Noções básicas sobre coleções Java.  

> **Dica profissional:** A sintaxe do SmartMarker (`${EmployeeMaster}`) funciona com qualquer tipo de coleção que implemente `java.util.Collection`. Use-a para manter seus modelos limpos e fáceis de manter.

## Como gerar planilhas com SmartMarkerProcessor

Esta seção contém o código central que torna **gerar planilhas** simples. Explicaremos por que cada linha importa, não apenas o que ela faz.

### Etapa 1: Adicionar a dependência Aspose.Cells

Se você usa Maven, inclua o seguinte no seu `pom.xml`. A biblioteca fornece a classe `SmartMarkerProcessor` usada ao longo deste guia.

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **Por quê:** Aspose.Cells lida com I/O de arquivos Excel, análise de Smart Markers e gerenciamento de planilhas internamente, permitindo que você se concentre nos dados em vez de nas operações de arquivo de baixo nível.

### Etapa 2: Preparar o modelo Excel

Crie um arquivo Excel chamado `EmployeeTemplate.xlsx` com uma única célula que contém o placeholder do Smart Marker:

| A |
|---|
| `${EmployeeMaster}` |

Quando o processador for executado, ele substituirá esse placeholder por uma **planilha de detalhes** que contém uma linha por funcionário.

> **Por quê:** O placeholder indica ao processador onde injetar os dados. Usar um modelo separado mantém sua formatação (fontes, bordas, larguras de coluna) intacta.

### Etapa 3: Definir o modelo de dados

Abaixo está uma classe mínima `Employee` e um método auxiliar que cria uma lista de funcionários. A lista será usada para demonstrar **várias planilhas a partir de lista**.

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **Por quê:** Um objeto Java simples (POJO) mapeia diretamente para os campos do Smart Marker (`firstName`, `lastName`, `department`). Isso torna **preencher a pasta de trabalho Excel** simples e tipado.

### Etapa 4: Configurar o SmartMarkerProcessor

Agora conectamos tudo. O processador lerá o modelo, substituirá o marcador e criará uma nova planilha chamada `EmployeeDetail`.

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

**Explicação das linhas principais**

| Linha | Motivo |
|------|--------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | Carrega o modelo que já contém o placeholder do Smart Marker. |
| `data.put("EmployeeMaster", employees);` | Associa a lista Java ao marcador `${EmployeeMaster}`. |
| `processor.setDetailSheetNewName("EmployeeDetail");` | Dá à planilha gerada um nome significativo em vez do padrão `Sheet1`. |
| `processor.process(wb, data);` | **Como gerar planilhas** – o processador lê o marcador, cria uma nova planilha e preenche linhas para cada `Employee`. |
| `wb.save("EmployeesReport.xlsx");` | Persiste as **planilhas Excel dinâmicas** no disco. |

### Etapa 5: Verificar a saída

Abra `EmployeesReport.xlsx`. Você deverá ver duas planilhas:

1. **Sheet1** – o modelo original (pode ser ocultado ou removido).  
2. **EmployeeDetail** – uma **planilha Excel dinâmica** com colunas `firstName`, `lastName`, `department` e uma linha por funcionário.

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **Por que isso importa:** O arquivo agora contém **várias planilhas a partir de lista** sem nenhum loop manual ou endereçamento de células. O motor de Smart Marker cuida da criação de linhas, conversão de dados e herança de formatação.

### Etapa 6: Tratar casos especiais

#### Lista de dados vazia

Se `employees` estiver vazia, o processador ainda cria a planilha `EmployeeDetail`, mas a deixa em branco. Você pode impedir a criação da planilha verificando o tamanho da coleção antes do processamento:

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### Listas muito grandes

Para milhares de linhas, considere aumentar a alocação de memória (`-Xmx2g`) ou usar `processor.setAutoFitRows(false)` para acelerar o processamento.

#### Nomeação personalizada de planilhas por grupo

Se precisar de uma planilha separada para cada departamento, pode usar **várias planilhas de detalhe**:

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

O placeholder `${department}` é obtido de cada objeto `Employee`, produzindo planilhas como `Dept_Sales`, `Dept_Marketing`, etc.
