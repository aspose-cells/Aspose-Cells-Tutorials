# Criar planilhas detalhadas em Java com marcadores inteligentes do Aspose.Cells

Se você precisar **criar planilhas detalhadas** em uma aplicação Java, este tutorial mostra como fazer isso com marcadores inteligentes do Aspose.Cells. Você verá um exemplo completo e executável que **java create worksheets**, deriva o **sheet name from field**, e **process data source** em apenas algumas linhas de código.

O guia cobre tudo, desde a configuração do projeto até a gravação da pasta de trabalho final, para que você possa copiar‑colar a solução no seu próprio projeto e adaptá‑la instantaneamente. Nenhuma documentação externa é necessária—tudo o que você precisa está aqui.

## O que você aprenderá

* Como **usar marcadores inteligentes** para duplicar uma planilha modelo para cada linha em um conjunto de dados mestre.  
* Como definir o nome de cada nova planilha dinamicamente com base no valor de um campo (por exemplo, `Order_123`).  
* Como alimentar uma coleção Java como **process data source** para o mecanismo de marcadores inteligentes.  
* Dicas para lidar com casos extremos, como dados vazios, caracteres especiais em nomes de planilhas e considerações de desempenho para grandes conjuntos de dados.

### Pré-requisitos

| Requirement | Reason |
|-------------|--------|
| Java 8 ou superior | Aspose.Cells for Java suporta Java 8+. |
| Sistema de compilação Maven ou Gradle | Simplifica a adição da dependência Aspose.Cells. |
| Conhecimento básico de coleções Java | Necessário para construir a fonte de dados para os marcadores inteligentes. |
| Um arquivo Excel modelo (`Template.xlsx`) com um marcador inteligente de espaço reservado na célula **A1** | O modelo controla a geração da planilha detalhada. |

> **Dica profissional:** Mantenha a pasta de trabalho modelo na pasta `resources` do projeto para que ela seja empacotada com seu JAR.

## Etapa 1: Adicionar Aspose.Cells ao seu projeto (java create worksheets)

Se você usar **Maven**, adicione a seguinte dependência ao `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

Para **Gradle**, coloque esta linha em `build.gradle`:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

Essas linhas tornam as APIs **java create worksheets** disponíveis em tempo de compilação.

## Etapa 2: Carregar a pasta de trabalho modelo

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*Por que isso importa:* O objeto `Workbook` é o ponto de entrada para todas as operações do Excel. Carregar o modelo garante que você comece com o layout correto e qualquer formatação pré‑definida.

## Etapa 3: Inserir um marcador inteligente que cria uma nova planilha por linha mestre (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

A sintaxe `${Orders:DetailSheetNewName=Order_${OrderId}}` é o núcleo de **use smart markers**. Ela faz três coisas:

1. Itera sobre a coleção `Orders`.  
2. Cria uma **nova planilha** para cada elemento.  
3. Define o **nome da planilha a partir do campo** `OrderId` (com o prefixo `Order_`).

## Etapa 4: Preparar a fonte de dados (process data source)

Abaixo está um exemplo mínimo usando um `List<Map<String, Object>>`. Substitua‑o pela sua fonte de dados real—linhas de banco de dados, desserialização JSON, etc.

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*Por que isso importa:* A etapa **process data source** vincula sua coleção Java ao mecanismo de marcadores inteligentes. A chave (`"Orders"`) deve corresponder exatamente ao nome do marcador inteligente.

## Etapa 5: Processar os marcadores inteligentes (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

Quando `process` é executado, o Aspose.Cells lê a coleção `Orders`, clona a planilha modelo para cada entrada e renomeia cada planilha de acordo com o campo `OrderId`. Este é o núcleo do uso de **process data source**.

## Etapa 6: Salvar a pasta de trabalho com planilhas detalhadas duplicadas

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

Após a execução, você encontrará `DuplicatedDetailSheets.xlsx` contendo:

* `Sheet1` – o modelo original (inalterado).  
* `Order_101` – planilha detalhada do primeiro pedido.  
* `Order_102` – planilha detalhada do segundo pedido.

### Saída esperada (trecho)

| Nome da planilha | A1 (marcador inteligente) | Conteúdo resultante |
|------------------|---------------------------|----------------------|
| Order_101  | `${Orders:...}`   | Populated with data from `order1` |
| Order_102  | `${Orders:...}`   | Populated with data from `order2` |

Abra o arquivo no Excel para verificar se cada planilha está nomeada corretamente e contém as linhas de dados.

## Lidando com variações comuns e casos extremos

### Fonte de dados vazia

Se `orders` estiver vazio, o processador de marcadores inteligentes não cria **novas planilhas**. Para evitar uma pasta de trabalho vazia, adicione uma proteção:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### Caracteres especiais em nomes de planilhas

Nomes de planilhas do Excel não podem conter `\ / ? * [ ] :`. Limpe o campo antes de usá‑lo:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### Grandes conjuntos de dados

Para milhares de linhas, considere aumentar o heap da JVM (`-Xmx2g`) e chamar `workbook.calculateFormula()` somente após todas as planilhas serem geradas para melhorar o desempenho.
