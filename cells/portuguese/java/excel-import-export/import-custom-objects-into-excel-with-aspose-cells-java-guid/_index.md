# Importar objetos personalizados para o Excel com Aspose.Cells – Guia Java

Se você precisar **importar objetos personalizados** para uma planilha do Excel, este guia o conduzirá pelo processo completo usando Aspose.Cells para Java. Você verá como **importar dados para o Excel**, aplicar um estilo de cabeçalho em negrito e gerar um arquivo `.xlsx` pronto‑para‑compartilhar.

Exportar dados tabulares a partir do Java frequentemente envolve gravações manuais célula‑por‑célula, o que é propenso a erros e difícil de manter. Ao aproveitar a API `importCustomObjects` você evita código boilerplate, mantém seu modelo de dados intacto e obtém controle de estilo granular.

Neste tutorial você vai:

* Construir uma lista de objetos Java `Map` que imita uma tabela de dados típica.  
* Criar um estilo de cabeçalho reutilizável (fonte em negrito) com Aspose.Cells.  
* Importar os objetos personalizados para uma planilha enquanto aplica o array de estilos.  
* Salvar a pasta de trabalho em disco e verificar o resultado.

O único pré‑requisito é um ambiente de desenvolvimento Java (JDK 8+ recomendado) e a biblioteca Aspose.Cells para Java.

---

## O que você precisará

| Requisito | Motivo |
|-----------|--------|
| JDK 8 ou mais recente | Necessário para compilar e executar o código Java. |
| Aspose.Cells for Java (versão mais recente) | Fornece as APIs `Workbook`, `Worksheet` e de importação. |
| IDE ou ferramenta de build (ex.: Maven, Gradle) | Simplifica o gerenciamento de dependências e a execução. |
| Permissão de escrita em uma pasta para o arquivo de saída | A pasta de trabalho é salva como `ImportWithStyle.xlsx`. |

Adicione a dependência Aspose.Cells ao seu `pom.xml` se você usar Maven:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## Etapa 1: Preparar os objetos personalizados para importação

O primeiro passo é criar uma coleção que represente as linhas que você deseja colocar no Excel. Neste exemplo usamos um `List<Map<String,Object>>` onde cada mapa funciona como uma linha com os nomes das colunas como chaves.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Por que isso importa:**  
`importCustomObjects` espera um array de objetos. Ao usar um `Map`, você preserva os nomes das colunas, permitindo que o Aspose.Cells os mapeie automaticamente para as células. Essa abordagem reflete uma típica `DataTable` em .NET ou um `ResultSet` do JDBC, tornando o código reutilizável em diferentes projetos.

---

## Etapa 2: Definir um estilo de cabeçalho para aplicar na importação

Uma linha de cabeçalho clara melhora a legibilidade. O Aspose.Cells permite criar um objeto `Style`, definir sua fonte como negrito e passá‑lo via um array `ImportTableOptions`.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Por que isso importa:**  
Se você omitir o array de estilos, o cabeçalho aparecerá na fonte padrão, que pode não se destacar. Ao preparar o estilo uma única vez, você evita chamadas repetitivas para cada linha e mantém a lógica de importação limpa.

---

## Etapa 3: Importar os objetos personalizados com o array de estilos

Agora você combina os dados e o estilo, e então chama `importCustomObjects`. O método coloca os dados começando no canto superior‑esquerdo (linha 0, coluna 0) e aplica o estilo de cabeçalho automaticamente.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Por que isso importa:**  
`importCustomObjects` analisa cada mapa, cria colunas com base nas chaves (`Name`, `Score`) e grava os valores nas células correspondentes. O objeto `ImportTableOptions` indica ao Aspose.Cells para usar o `styleArray` na primeira linha, proporcionando um cabeçalho em negrito sem código extra.

---

## Etapa 4: Salvar a pasta de trabalho e verificar a saída

Por fim, grave a pasta de trabalho em um arquivo. O arquivo Excel gerado contém uma linha de cabeçalho estilizada seguida pelas linhas de dados.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Resultado esperado:**  

| **Name** | **Score** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

## Variações comuns e casos de borda

| Situação | Ajuste recomendado |
|----------|--------------------|
| **Ordem de colunas diferente** | Garanta que as chaves do `Map` sejam inseridas na ordem desejada, ou use um POJO personalizado com campos anotados e um array `PropertyDescriptor`. |
| **Conjuntos de dados grandes (>10 000 linhas)** | Aumente `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` para evitar `OutOfMemoryError`. |
| **Formatos numéricos personalizados** | Adicione um segundo `Style` em `styleArray` para as linhas de dados, por exemplo, defina `NumberFormat` como `"0"` para pontuações inteiras. |
| **Múltiplas planilhas** | Chame `importCustomObjects` em cada planilha de destino, ajustando a linha/coluna inicial conforme necessário. |
| **Texto de cabeçalho específico de localidade** | Preencha a linha de cabeçalho manualmente antes da importação e, em seguida, aplique o estilo a todo o intervalo usando `Cells.applyStyle`. |

---

## Dicas avançadas para uma exportação Java robusta para Excel

* **Reutilizar a pasta de trabalho temporária** – Criar um novo `Workbook` para cada estilo adiciona sobrecarga. Mantenha uma única instância se precisar de vários estilos.  
* **Validar os dados antes da importação** – Valores nulos em um mapa tornam‑se células vazias; você pode substituí‑los por valores padrão pré‑processando a lista.  
* **Fechar recursos** – Embora o Aspose.Cells gerencie a memória internamente, chamar explicitamente `workbook.dispose()` após salvar libera os recursos nativos prontamente.  
* **Definir `Workbook.setForceFullCalculation(true)`** se sua pasta de trabalho contiver fórmulas que precisam ser avaliadas antes de salvar.
