# Como criar uma pasta de trabalho Excel em Java com dados JSON

Se você precisa **criar uma pasta de trabalho Excel em Java**, os desenvolvedores frequentemente enfrentam o desafio de carregar dados JSON em uma planilha. Este guia mostra como **preencher Excel a partir de JSON**, incluindo como **convert JSON array excel** e **populate workbook from json** de forma limpa e repetível.

Trabalhar com JSON é comum quando serviços expõem dados via REST APIs, e o Excel continua sendo o formato preferido para relatórios e análises. Ao final deste tutorial você terá um programa Java executável que:

* cria uma nova pasta de trabalho Excel,
* lê um array JSON (ou qualquer estrutura JSON) e grava seus valores nas células,
* salva o arquivo no disco pronto para processamento posterior.

Nenhuma ferramenta externa é necessária além da biblioteca Aspose.Cells for Java, que fornece o `SmartMarkerProcessor` usado no código de exemplo.

## Pré-requisitos

Antes de começar, certifique‑se de que você tem:

| Pré‑requisito | Motivo |
|--------------|--------|
| Java Development Kit (JDK) ≥ 8 | Necessário para compilar e executar o exemplo |
| Maven ou Gradle (opcional) | Simplifica o gerenciamento de dependências |
| Aspose.Cells for Java (v23.10 ou posterior) | Fornece as classes `Workbook` e `SmartMarkerProcessor` |
| Conhecimento básico de JSON e Java I/O | Ajuda a entender o fluxo de dados |

Se preferir não usar uma ferramenta de build, você pode baixar o JAR do Aspose.Cells no [site da Aspose](https://products.aspose.com/cells/java/) e adicioná‑lo ao classpath do seu projeto manualmente.

## Etapa 1: Configurar o projeto e adicionar a dependência Aspose.Cells

### Usuários Maven

Adicione a seguinte dependência ao seu `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Usuários Gradle

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

Se você não estiver usando uma ferramenta de build, coloque o JAR baixado na pasta `libs/` e inclua‑lo no classpath ao compilar:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## Etapa 2: Criar uma nova pasta de trabalho e configurar o processador SmartMarker

O `SmartMarkerProcessor` simplifica o mapeamento de valores JSON para células do Excel. Ao chamar `setArrayAsSingle(true)` informamos ao processador que ele deve tratar um array JSON inteiro como um único valor, o que é útil quando você deseja que cada elemento ocupe sua própria célula em uma linha.

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**Por que isso importa:**  
Criar a pasta de trabalho antecipadamente fornece uma tela limpa. Configurar `setArrayAsSingle(true)` impede que o processador achate o array em uma única string (ex., `["A","B","C"]`) e, em vez disso, permite que você controle o layout manualmente.

## Etapa 3: Definir os dados JSON que você deseja inserir

Para este tutorial usamos um array JSON simples, mas a mesma abordagem funciona com objetos, arrays aninhados ou estruturas complexas.

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**Dica:** Se seu JSON vem de um arquivo ou de um endpoint REST, substitua a string literal por um `String` lido da fonte, por exemplo, `Files.readString(Paths.get("data.json"))`.

## Etapa 4: Processar a pasta de trabalho com os dados JSON

Agora deixamos o `SmartMarkerProcessor` mapear o array JSON para a primeira planilha. O comportamento padrão grava cada elemento em células sucessivas a partir de `A1`.

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

Nos bastidores, o Aspose.Cells analisa o JSON, cria uma tabela de dados temporária e grava os valores na planilha. Como definimos `ArrayAsSingle` como `true`, os elementos do array são colocados horizontalmente na primeira linha.

## Etapa 5: Salvar a pasta de trabalho em um arquivo

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

Ao executar o programa, você deverá ver um arquivo chamado **CreatedFromJson.xlsx** no seu diretório de trabalho. Abrindo‑o com o Excel (ou qualquer visualizador compatível) será exibido:

| A | B | C |
|---|---|---|
| A | B | C | *(valores aparecem nas células A1, B1, C1)*

### Saída esperada

```
Workbook saved to CreatedFromJson.xlsx
```

E a planilha Excel parece com:

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## Etapa 6: Manipulando estruturas JSON mais complexas (opcional)

### 6.1 Preenchendo uma pasta de trabalho a partir de um objeto JSON

Se seu JSON for um objeto em vez de um array, você ainda pode usar o `SmartMarkerProcessor`. Por exemplo:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

O processador criará intervalos nomeados (`title`, `month`, `values`) que você pode referenciar no seu modelo Excel usando Smart Markers como `&=title` e `&=values`.

### 6.2 Convertendo um array JSON aninhado para uma lista vertical

Às vezes você precisa que o array preencha uma coluna em vez de uma linha. Defina a célula inicial manualmente antes do processamento:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

Agora os valores **A**, **B**, **C** aparecem nas células A2, A3, A4 respectivamente.

## Armadilhas comuns e como evitá‑las

| Problema | Causa | Correção |
|----------|-------|----------|
| **Array escrito como uma única string** | `setArrayAsSingle(false)` (padrão) | Chame `processor.setArrayAsSingle(true)` |
| **Arquivo não encontrado ao salvar** | Caminho inválido ou permissões de gravação ausentes | Use um caminho absoluto ou garanta que o diretório exista |
| **Erro de análise JSON** | String JSON malformada | Valide o JSON com uma ferramenta ou use uma biblioteca como Jackson para gerar a string |
| **Células sobrescritas inadvertidamente** | Processamento da mesma planilha várias vezes sem redefinir a célula inicial | Chame `processor.setStartCell("A1")` antes de cada chamada `process` |

## Dica profissional: reutilizar a pasta de trabalho como modelo

Em vez de começar a partir de uma pasta de trabalho em branco a cada vez, você pode carregar um modelo pré‑projetado que já contém cabeçalhos, fórmulas ou estilos:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

Essa abordagem combina o acabamento visual de um arquivo Excel criado manualmente com a automação de **populate workbook from json**.
