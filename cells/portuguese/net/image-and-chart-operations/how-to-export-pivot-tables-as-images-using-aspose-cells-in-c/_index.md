# Como exportar tabelas dinâmicas como imagens usando Aspose.Cells em C#

Se você precisa **como exportar pivô** dados para uma imagem portátil, o Aspose.Cells torna o processo simples. Este tutorial mostra exatamente como exportar tabelas dinâmicas como arquivos PNG, para que você possa incorporá‑las em relatórios, e‑mails ou documentação sem precisar do Excel na máquina de destino.

Exportar um pivô como imagem elimina problemas de formatação específicos de versões e permite que partes interessadas não técnicas visualizem a análise instantaneamente. Vamos cobrir tudo, desde a configuração do projeto até a renderização da **imagem de exportação da tabela dinâmica**, e também explicaremos como **salvar pivô como imagem** para reutilização futura.

## Como exportar tabelas dinâmicas como imagens com Aspose.Cells

Abaixo está o exemplo completo e executável que carrega uma pasta de trabalho, atualiza o pivô, configura as opções de imagem e grava o arquivo de saída. Cada passo inclui uma breve justificativa para que você entenda *por que* o código foi escrito daquela forma, e não apenas *o que* ele faz.

### 1. Configurar o ambiente Aspose.Cells

1. Instale o pacote NuGet:

   ```bash
   dotnet add package Aspose.Cells
   ```

2. Adicione as diretivas `using` necessárias no topo do seu arquivo C#:

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **Dica profissional:** Alveje .NET 6 ou posterior para aproveitar as mais recentes melhorias de desempenho no Aspose.Cells.

### 2. Carregar a pasta de trabalho e localizar a tabela dinâmica

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*Por que isso importa:* A classe `Workbook` analisa o arquivo XLSX e fornece acesso a todas as planilhas. Selecionar a planilha correta é essencial porque uma pasta de trabalho pode conter múltiplas tabelas dinâmicas.

### 3. Atualizar a tabela dinâmica para capturar os dados de origem mais recentes

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

Atualizar garante que quaisquer alterações feitas na faixa de origem após o arquivo ser salvo sejam refletidas na imagem renderizada. Pular esta etapa pode gerar visualizações desatualizadas ou imprecisas.

### 4. Configurar opções de exportação de imagem (exportar imagem da tabela dinâmica)

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

O objeto `ImageOrPrintOptions` permite controlar o formato, a resolução e outros detalhes de renderização. PNG é a escolha mais comum para gráficos nítidos e compatíveis com a web, mas você pode mudar para `ImageFormat.Jpeg` se o tamanho do arquivo for uma preocupação.

### 5. Renderizar e **salvar pivô como imagem**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

`RenderToImage` realiza o trabalho pesado: ele desenha a tabela dinâmica exatamente como aparece no Excel e grava os dados binários PNG no disco. O método retorna `void`, portanto você pode assumir com segurança que o arquivo existe após a chamada ser concluída, sem necessidade de verificações adicionais.

#### Resultado esperado

Depois que o programa for executado, você encontrará `Pivot.png` na pasta especificada. Ao abrir o arquivo, deverá ser exibida uma cópia fiel da tabela dinâmica original, incluindo cabeçalhos de coluna, totais de linha e qualquer formatação aplicada.

### 6. Variações comuns e casos extremos

| Cenário | Ajuste |
|----------|------------|
| **Grandes pivôs** (muitas linhas/colunas) | Aumente `HorizontalResolution` e `VerticalResolution` para 300 dpi para uma saída mais nítida. |
| **Estilização personalizada** (cores de fundo, fontes) | Garanta que as definições de estilo da pasta de trabalho estejam carregadas antes de chamar `Refresh()`. |
| **Múltiplos pivôs** em uma planilha | Percorra `worksheet.PivotTables` e chame `RenderToImage` para cada um, usando nomes de arquivo distintos. |
| **Exportar para JPEG** em vez de PNG | Altere `ImageFormat = ImageFormat.Jpeg` e, opcionalmente, defina `Quality` em um objeto `JpegSaveOptions`. |

Essas variações permitem que você **exporte a imagem da tabela dinâmica** no formato exato que seu sistema downstream espera.

## Código-fonte completo para copiar‑colar rapidamente

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

Executar o programa gera o arquivo PNG mostrado acima, completando o fluxo de trabalho de **salvar pivô como imagem** em menos de um minuto.
