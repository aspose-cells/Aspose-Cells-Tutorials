# Criar excel file c# – estilizar células e definir formato de moeda

Se você precisa **create excel file c#** que pareça profissional, este guia mostra exatamente como estilizar células do Excel e formatar uma coluna como moeda. Você verá um exemplo completo, de ponta a ponta, que importa um `DataTable`, aplica um cabeçalho em negrito e define o formato numérico `$#,##0.00` para a coluna de preço.

O tutorial cobre tudo o que você precisa: pacotes NuGet necessários, o código‑fonte completo, explicações sobre por que cada parte é importante e dicas para lidar com casos de borda, como linhas vazias ou diferentes localidades. Ao final, você será capaz de gerar um arquivo `.xlsx` com uma coluna de preço bem formatada em apenas algumas linhas de C#.

## Pré-requisitos

- .NET 6.0 ou posterior (o código também funciona com .NET Framework 4.6+)
- Visual Studio 2022 ou qualquer editor C# de sua preferência
- A biblioteca **Aspose.Cells for .NET** ou **GemBox.Spreadsheet** (ambas suportam `ImportTableOptions`). O exemplo abaixo usa **Aspose.Cells** porque fornece uma propriedade `StyleArray` simples.
- Conhecimento básico de coleções C# e `DataTable`

> **Dica profissional:** Se você prefere uma alternativa gratuita, substitua `Aspose.Cells` por `GemBox.Spreadsheet`. A API para importar um `DataTable` com estilos é quase idêntica; basta mudar o namespace e o nome do pacote NuGet.

## Etapa 1: Instalar a biblioteca Excel

Abra o Gerenciador de Pacotes NuGet e instale a biblioteca:

```bash
dotnet add package Aspose.Cells
```

> **Por que esta etapa?** A biblioteca fornece as classes `Workbook`, `Worksheet`, `Style` e `ImportTableOptions` usadas posteriormente. Sem ela, você teria que escrever o formato Office Open XML manualmente, o que é propenso a erros.

## Etapa 2: Criar um DataTable com dados de exemplo

Um `DataTable` é uma maneira conveniente de armazenar dados tabulares antes de exportá‑los para o Excel. Neste exemplo, temos duas colunas: *Product* e *Price*.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Explicação:**  
> - `Columns.Add("Price", typeof(double))` indica à tabela que os valores de preço devem ser tratados como números, o que é necessário para a formatação numérica posteriormente.  
> - Adicionar algumas linhas nos fornece dados para verificar a etapa **format column currency**.

## Etapa 3: Definir os estilos que você deseja aplicar

Criaremos um array de objetos `Style` que corresponde à ordem das colunas. A primeira entrada estiliza a linha de cabeçalho, a segunda deixa a coluna *Product* sem alterações, e a terceira aplica um formato numérico de moeda.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### Por que usar um **style array**?

`ImportTableOptions.StyleArray` mapeia cada coluna para um `Style`. Esta é a maneira mais eficiente de **add number format** e **style excel cells** em uma única operação de importação, evitando uma segunda passagem pela planilha.

## Etapa 4: Configurar opções de importação

Agora vinculamos o array de estilos à operação de importação. O objeto `ImportTableOptions` também permite controlar se a primeira linha é tratada como cabeçalho.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Nota:** `IsFieldNameShown` tem o padrão `true`, mas defini‑lo explicitamente deixa a intenção clara para leitores futuros.

## Etapa 5: Criar uma workbook, importar a tabela e salvar

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### Resultado esperado

Ao abrir `DataTableWithStyles.xlsx`:

- A primeira linha (cabeçalho) está **bold**.
- A coluna *Price* exibe valores como **$1.20**, **$3.50**, **$0.75**.
- A coluna *Product* mantém a fonte padrão.

Você criou com sucesso **created an excel file c#** com uma coluna de moeda formatada e células de cabeçalho estilizadas.

## Etapa 6: Lidando com variações comuns e casos de borda

### a. Localidade diferente ou símbolo de moeda personalizado

If you need a Euro or another currency, replace the built‑in format `164` with a custom format string:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. Adicionando mais colunas posteriormente

When you add extra columns, extend the `columnStyles` array accordingly. Use `null` for columns that should keep the default style.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. DataTable vazio

If the `DataTable` has no rows, Aspose.Cells still creates the header row. However, the workbook will contain only one row. To avoid an empty file, check the row count before importing:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Usando `GemBox.Spreadsheet` em vez de Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

A lógica permanece idêntica, demonstrando que o tutorial é **format column currency** independente da biblioteca subjacente.

## Etapa 7: Verificar o arquivo programaticamente (opcional)

You can open the generated workbook and assert that the number format was applied correctly—useful for unit tests.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```
