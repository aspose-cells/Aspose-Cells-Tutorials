# Como criar uma pasta de trabalho Excel em C# com formatação personalizada e salvar como XLSX

Se você precisa **criar uma pasta de trabalho Excel C#** que importe dados, aplique um formato numérico personalizado e altere a cor da fonte da célula, este tutorial mostra exatamente como fazer. Você receberá um exemplo pronto‑para‑executar que produz um arquivo `StyleArrayImport.xlsx` estilizado em segundos.

Trabalhar com Excel a partir de C# costuma envolver etapas manuais repetitivas — definir formatos, aplicar cores e lembrar de salvar o arquivo corretamente. Ao final deste guia você automatizará todas essas tarefas, podendo focar nos dados em vez da interface.

Você aprenderá a:

* importar um `DataTable` para uma planilha,
* usar um `StyleArray` para **aplicar formato numérico personalizado** e **alterar a cor da fonte da célula**,
* **salvar a pasta de trabalho como XLSX** com uma única chamada de método,
* e verificar que o **formato dos dados importados no Excel** aparece exatamente como esperado.

O único pré‑requisito é uma referência à biblioteca **Aspose.Cells for .NET** (ou qualquer API compatível que forneça `Workbook`, `Worksheet` e `StyleArray`). O código tem como alvo .NET 6+, mas versões anteriores funcionam com pequenos ajustes.

## Pré‑requisitos

| Requisito | Motivo |
|-----------|--------|
| .NET 6 SDK ou posterior | Fornece o runtime para o aplicativo console C#. |

Instale o pacote Aspose.Cells com o seguinte comando:

```bash
dotnet add package Aspose.Cells
```

## Etapa 1: Preparar o DataTable de exemplo

Primeiro, crie um `DataTable` que imite os dados que você normalmente recuperaria de um banco de dados ou outra fonte. A tabela inclui uma coluna **Name** (string) e uma coluna **Amount** (decimal) que formataremos posteriormente.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Por que isso importa:** Usar um `DataTable` permite manter a lógica de importação independente da fonte de dados, o que é um padrão comum ao gerar relatórios a partir de bancos, arquivos CSV ou APIs.

## Etapa 2: Definir um StyleArray para **aplicar formato numérico personalizado** e **alterar a cor da fonte da célula**

`StyleArray` permite agrupar instruções de formatação que serão aplicadas a cada célula importada do `DataTable`. Neste exemplo nós:

* definimos `Number` como `#,##0.00` – um formato contábil típico com separador de milhares,
* definimos `FontColor` como `Color.Blue` – fazendo os números se destacarem.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**Por que usar um StyleArray?** Aplicar um estilo no momento da importação evita uma segunda passagem sobre a planilha, melhorando o desempenho para conjuntos de dados grandes.

---

## Etapa 3: **Criar pasta de trabalho Excel C#** – instanciar Workbook e obter a primeira Worksheet

Agora criamos uma pasta de trabalho vazia e obtemos uma referência à primeira planilha (índice 0). Essa planilha será o destino dos nossos dados importados.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Explicação:** `Workbook` representa o arquivo Excel completo, enquanto `Worksheet` representa uma única aba. O workbook padrão contém uma planilha, o que é suficiente para a maioria dos relatórios simples.

---

## Etapa 4: Importar o DataTable usando o **StyleArray** para **formatar os dados importados no Excel**

O método `ImportDataTable` copia as linhas e colunas da tabela para a planilha, começando na célula `A1` (linha 0, coluna 0). O argumento `true` indica que o método deve incluir os cabeçalhos das colunas. Como passamos `styleArray`, cada célula importada recebe o formato numérico personalizado e a cor da fonte.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**O que acontece nos bastidores:** Aspose.Cells itera sobre cada linha, grava o valor e, em seguida, aplica o estilo definido em `styleArray`. Os números aparecem com vírgulas e duas casas decimais, e o texto é renderizado em azul.

---

## Etapa 5: **Salvar a pasta de trabalho como XLSX** – gravar o arquivo no disco

Por fim, persista a pasta de trabalho em um arquivo `.xlsx`. Você pode alterar o caminho para qualquer diretório gravável na sua máquina.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Verificação do resultado:** Abra o arquivo gerado no Excel. Você deverá ver as três linhas de dados, a coluna **Amount** formatada com vírgulas, duas casas decimais e exibida em fonte azul. Isso confirma que a etapa **formatar os dados importados no Excel** foi bem‑sucedida.

## Exemplo Completo

Copie todo o bloco abaixo para um novo projeto console e execute-o. Nenhum código adicional é necessário.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Saída esperada no console:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

Abra o arquivo e verifique que a coluna **Amount** mostra valores como `1,234.56` em fonte azul.

## Perguntas Frequentes & Casos de Borda

| Pergunta | Resposta |
|----------|----------|
| *Posso aplicar formatos diferentes a colunas individuais?* | Sim. Após a importação, recupere o objeto `Style` da coluna (`worksheet.Cells.Columns[1].Style`) e defina um `Number` ou `FontColor` diferente. |
| *E se eu precisar formatar datas em vez de números?* | Defina `styleArray.Number = "mm-dd-yyyy"` e, opcionalmente, `styleArray.FontColor` para as células de data. |
| *A fonte azul fica visível em temas escuros do Excel?* | Azul pode ser difícil de ler em fundos escuros. Use um tom mais claro (`Color.LightBlue`) ou uma cor contrastante (`Color.Black`). |
| *Como importar um DataTable muito grande (centenas de milhares de linhas)?* | Use `ImportDataTable` com a sobrecarga `ImportDataTableOptions` para streaming, ou divida a importação em várias planilhas para permanecer dentro do limite de linhas do Excel (1.048.576 linhas). |
| *Posso exportar para CSV em vez de XLSX?* | Substitua `SaveFormat.Xlsx` por `SaveFormat.Csv`. Observe que informações de formatação (formato numérico, cor da fonte) são perdidas no CSV, pois é um formato de texto simples. |

---

## Dicas para Uso em Produção

* **Dica de especialista:** Cache o objeto `Style` se precisar aplicar a mesma formatação a muitas planilhas; criar um novo `StyleArray` para cada importação gera sobrecarga.
* **Fique atento às diferenças culturais:** O padrão `Number` `#,##0.00` segue a cultura invariável. Se precisar de separadores específicos de locale, use `NumberFormatInfo` ou deixe o Excel lidar com base nas configurações regionais do usuário.
* **Tratamento de erros:** Envolva a chamada `Save` em um bloco try‑catch para lidar com exceções de I/O (por exemplo, permissões insuficientes ou arquivos bloqueados).
