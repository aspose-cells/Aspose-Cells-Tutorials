# Como incorporar fontes ao salvar Excel em HTML com C#

Incorporar fontes ao salvar uma pasta de trabalho do Excel em HTML é uma necessidade comum para preservar a aparência exata das suas planilhas em diferentes navegadores. Se você precisa exportar Excel para HTML mantendo as tipografias originais, este guia mostra uma solução completa, pronta‑para‑executar.

Você aprenderá como **exportar Excel para HTML**, **converter Excel para HTML** com fontes incorporadas e evitar o típico problema de “fonte ausente” que quebra o layout nas máquinas dos clientes. Nenhuma ferramenta externa é necessária — apenas a biblioteca Aspose.Cells e algumas linhas de C#.

## Pré-requisitos

Antes de começar, certifique-se de que você tem:

* .NET 6.0 (ou superior) instalado.
* Uma cópia licenciada do **Aspose.Cells for .NET** – a versão de avaliação gratuita serve para testes.
* Uma IDE como Visual Studio 2022 ou VS Code.

Se você já possui esses itens, pode ir direto ao código.

## Etapa 1: Criar uma pasta de trabalho e adicionar dados de exemplo

Primeiro geramos uma pequena pasta de trabalho para que você possa ver o efeito das fontes incorporadas. O código abaixo cria uma planilha, escreve algumas células e aplica uma fonte personalizada.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### Por que adicionamos uma fonte personalizada

Incorporar fontes só é relevante quando a pasta de trabalho usa fontes que podem não estar presentes no dispositivo do cliente. Ao definir explicitamente **Arial** (ou qualquer outra fonte) podemos verificar que a saída HTML realmente contém os dados da fonte.

## Etapa 2: Configurar as opções de salvamento HTML para incorporar fontes

Aspose.Cells fornece a classe `HtmlSaveOptions`. Definir `EmbedFonts = true` indica à biblioteca que incorpore os arquivos de fonte necessários diretamente no HTML gerado como URIs de dados codificados em Base64.

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### O que realmente faz “incorporar fontes em html”

Quando `EmbedFonts` está true, Aspose.Cells extrai os arquivos de fonte do sistema (ou da coleção de fontes incorporadas da pasta de trabalho) e os converte em strings **Base64**. Essas strings são então inseridas dentro de um bloco `<style>` usando `@font-face`. O HTML resultante pode ser aberto em qualquer dispositivo sem precisar da fonte original instalada.

## Etapa 3: Salvar a pasta de trabalho como HTML com fontes incorporadas

Agora gravamos a pasta de trabalho no disco. O arquivo conterá os dados da fonte, de modo que abri‑lo em qualquer navegador moderno exiba a tipografia exatamente igual à do arquivo Excel original.

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### Resultado esperado

* `embedded.html` reside na pasta `output`.
* Abrir o arquivo no Chrome, Edge ou Firefox exibe a planilha com texto em **Arial**, mesmo que a máquina do navegador não possua Arial.
* Inspecionar o código‑fonte HTML revela um bloco `<style>` contendo uma regra `@font-face` com uma longa declaração `src: url(data:font/ttf;base64,…)` – essa é a fonte incorporada.

## Etapa 4: Verificar se o HTML funciona em outra máquina (opcional)

Para ter certeza absoluta de que a incorporação foi bem‑sucedida:

1. Copie `output/embedded.html` para outro computador (ou máquina virtual) que **não** tenha a fonte personalizada instalada.
2. Abra o arquivo em um navegador.
3. O layout e a tipografia devem corresponder à visualização original do Excel.

Se a fonte recair para uma genérica, verifique novamente se o arquivo de fonte está acessível na máquina de compilação e se você tem permissão para lê‑lo.

## Perguntas comuns e casos extremos

### Incorporar fontes aumenta o tamanho do arquivo?

Sim. Incorporar uma fonte TrueType ou OpenType pode acrescentar **dezenas de kilobytes** ao arquivo HTML. Para pastas de trabalho grandes com muitas fontes distintas, considere:

* Reduzir a fonte (apenas os caracteres que você usa) – o Aspose.Cells faz isso automaticamente para a maioria das fontes comuns.
* Usar `ExportEmbeddedImages = false` se você não precisar de imagens incorporadas.

### E se eu precisar incorporar apenas fontes específicas?

`HtmlSaveOptions` não oferece uma lista branca direta, mas você pode controlar quais fontes aparecem **limitando as fontes usadas na pasta de trabalho** antes de chamar `Save`. Remova atribuições de fonte desnecessárias ou substitua‑as por fontes web‑seguras padrão.

### Posso incorporar fontes ao converter para outros formatos (por exemplo, PDF)?

A mesma propriedade `EmbedFonts` existe em `PdfSaveOptions`. O conceito é idêntico: os dados da fonte são incorporados para que o PDF seja renderizado corretamente em qualquer visualizador.

## Exemplo completo e executável

Abaixo está o programa completo que você pode copiar‑colar em um novo projeto de console.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

Executar o programa gera um **arquivo HTML que contém a fonte Arial incorporada**, garantindo fidelidade visual onde quer que o arquivo seja aberto.

## Conclusão

Agora você sabe **como incorporar fontes ao salvar Excel em HTML** usando C#. Ao configurar `HtmlSaveOptions.EmbedFonts = true`, você pode de forma confiável **exportar Excel para HTML** e **converter Excel para HTML** sem se preocupar com fontes ausentes no lado do cliente. Essa técnica é essencial para relatórios baseados na web, dashboards compatíveis com e‑mail ou qualquer cenário em que você compartilhe conteúdo derivado do Excel como HTML.
