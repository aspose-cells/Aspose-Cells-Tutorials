# Como incorporar fontes em HTML ao salvar uma pasta de trabalho

Se você precisa **como incorporar fontes em HTML** ao exportar uma planilha, este tutorial mostra uma solução completa, pronta‑para‑executar. Seja construindo um portal de relatórios ou uma visualização de análise do lado do cliente, incorporar fontes garante que o HTML renderizado tenha exatamente a mesma aparência da pasta de trabalho original, independentemente das fontes instaladas no visualizador.

Você também aprenderá a melhor forma de **salvar pasta de trabalho como HTML** usando Aspose.Cells, verá armadilhas comuns e receberá dicas para lidar com pastas de trabalho grandes ou arquivos de fontes personalizados. Nenhuma documentação externa é necessária — tudo o que você precisa está neste guia.

## Pré-requisitos

- .NET 6.0 ou posterior (o código também funciona com .NET Framework 4.7+)
- Uma licença válida do Aspose.Cells para .NET (ou você pode usar o modo de avaliação gratuito)
- Conhecimento básico de C# e um IDE como o Visual Studio 2022
- Os arquivos de fonte TrueType (.ttf) ou OpenType (.otf) que você deseja incorporar (eles devem ser acessíveis ao processo em execução)

## Etapa 1: Configurar o projeto e importar Aspose.Cells

Crie uma nova aplicação console e adicione o pacote NuGet Aspose.Cells:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

Em seguida, abra **Program.cs** e adicione as diretivas `using` necessárias:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **Dica profissional:** coloque suas fontes personalizadas em uma pasta chamada `fonts` dentro da raiz do projeto. Isso mantém a solução portátil e facilita a referência a elas posteriormente.

## Etapa 2: Criar ou carregar uma pasta de trabalho

Para demonstração, criaremos uma pasta de trabalho simples com algumas células formatadas:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **Por que isso importa:** se você pular o estilo personalizado, o HTML exportado usará as fontes padrão do navegador, anulando o objetivo de **como incorporar fontes em HTML**.

## Etapa 3: Configurar `HtmlSaveOptions` para incorporar fontes

O núcleo de **como incorporar fontes em HTML** está na classe `HtmlSaveOptions`. Definir `EmbedFonts = true` indica ao Aspose.Cells que incorpore quaisquer fontes TrueType/OpenType referenciadas diretamente no HTML gerado como URIs de dados codificados em Base64.

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### Como a incorporação funciona

Quando `EmbedFonts` está `true`, o Aspose.Cells analisa as definições de estilo da pasta de trabalho, localiza os arquivos de fonte correspondentes no sistema (ou na pasta `fonts` que você adicionou), lê seus dados binários e injeta um bloco `<style>` semelhante a:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

Como os dados da fonte são codificados diretamente no HTML, a página é renderizada corretamente mesmo em máquinas que não têm a fonte instalada.

## Etapa 4: Salvar a pasta de trabalho como HTML

Agora você pode **salvar a pasta de trabalho como HTML** com as opções configuradas. Escolha um diretório onde a aplicação possa gravar (por exemplo, `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

Executar o programa gera um único arquivo `report.html`. Abra‑o em qualquer navegador moderno e você verá o cabeçalho “Quarterly Sales” renderizado com a fonte **Pacifico**, mesmo que a fonte não esteja instalada no seu sistema operacional.

### Saída esperada

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

O atributo `src:` contém uma longa string Base64 — isso é o dado da fonte incorporada que permite **como incorporar fontes em HTML**.

## Etapa 5: Verificar a incorporação de fontes e solucionar problemas

1. **Abra o arquivo HTML no Chrome ou Edge.** Se a fonte personalizada aparecer, a incorporação foi bem‑sucedida.  
2. **Inspecione o código‑fonte da página.** Procure a regra `@font-face` gerada pelo Aspose.Cells.  
3. **Problemas comuns:**  
   - *Arquivo de fonte ausente:* Certifique‑se de que o arquivo de fonte esteja acessível. Você pode adicionar explicitamente uma pasta ao caminho de pesquisa:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *Tamanho grande do HTML:* Incorporar muitas fontes pode inflar o arquivo. Use `ExportToSingleFile = false` para manter as fontes como arquivos `.ttf` separados em uma pasta de recursos.

   - *Formato de fonte não suportado:* O Aspose.Cells só incorpora TrueType (`.ttf`) e OpenType (`.otf`). Converta outros formatos antes de incorporar.

## Exemplo completo em funcionamento

Abaixo está o programa completo que você pode copiar, colar e executar sem modificações (exceto pela linha de licença opcional).

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

Executar este programa cria `output/report.html`. Abra o arquivo e você verá a fonte **Pacifico** renderizada corretamente — demonstrando **como incorporar fontes em HTML** ao **salvar a pasta de trabalho como HTML**.

## Perguntas frequentes

| Pergunta | Resposta |
|----------|----------|
| *Posso incorporar apenas fontes específicas?* | Sim. Defina `htmlOpt.EmbedAllFonts = false` (disponível em versões mais recentes) e use `htmlOpt.FontsToEmbed` para listar os nomes exatos das fontes. |
| *E se eu precisar incorporar fontes para várias planilhas?* | Defina `ExportActiveWorksheetOnly = false` para que todas as planilhas sejam exportadas, e o Aspose.Cells incorporará as fontes usadas em toda a pasta de trabalho. |
| *As fontes incorporadas funcionarão em navegadores móveis?* | Navegadores móveis modernos suportam fontes codificadas em Base64, portanto as fontes incorporadas são renderizadas corretamente, desde que o formato da fonte seja suportado (TTF ou OTF). |
| *Quão grande pode ficar o arquivo HTML?* | Incorporar uma fonte TrueType de 200 KB adiciona aproximadamente a mesma quantidade ao tamanho do HTML (Base64 adiciona ~33 % de sobrecarga). Para muitas fontes, considere exportar para uma pasta (`ExportToSingleFile = false`) para manter o HTML leve. |
