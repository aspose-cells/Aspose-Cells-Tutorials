# Πώς να δημιουργήσετε Excel workbook C# με προσαρμοσμένη μορφοποίηση και αποθήκευση ως XLSX

Αν χρειάζεστε **να δημιουργήσετε Excel workbook C#** που εισάγει δεδομένα, εφαρμόζει προσαρμοσμένη μορφή αριθμού και αλλάζει το χρώμα γραμματοσειράς του κελιού, αυτό το tutorial σας δείχνει ακριβώς πώς. Θα λάβετε ένα έτοιμο‑για‑εκτέλεση παράδειγμα που παράγει ένα μορφοποιημένο αρχείο `StyleArrayImport.xlsx` σε δευτερόλεπτα.

Η εργασία με το Excel από C# συχνά περιλαμβάνει επαναλαμβανόμενα χειροκίνητα βήματα—ορισμός μορφών, εφαρμογή χρωμάτων και αποθήκευση του αρχείου σωστά. Στο τέλος αυτού του οδηγού θα αυτοματοποιήσετε όλα αυτά τα καθήκοντα, ώστε να μπορείτε να εστιάσετε στα δεδομένα αντί για το UI.

Θα μάθετε πώς να:

* εισάγετε ένα `DataTable` σε ένα φύλλο εργασίας,
* χρησιμοποιείτε ένα `StyleArray` για **εφαρμογή προσαρμοσμένης μορφής αριθμού** και **αλλαγή χρώματος γραμματοσειράς κελιού**,
* **αποθηκεύετε το workbook ως XLSX** με μία κλήση μεθόδου,
* και επαληθεύετε ότι η **format imported data excel** εμφανίζεται ακριβώς όπως προβλέπεται.

Η μόνη προϋπόθεση είναι μια αναφορά στη βιβλιοθήκη **Aspose.Cells for .NET** (ή οποιοδήποτε συμβατό API που παρέχει `Workbook`, `Worksheet` και `StyleArray`). Ο κώδικας στοχεύει στο .NET 6+, αλλά παλαιότερες εκδόσεις λειτουργούν με μικρές προσαρμογές.

## Βήμα 1: Προετοιμασία του δείγματος DataTable

Πρώτα, δημιουργήστε ένα `DataTable` που προσομοιώνει τα δεδομένα που θα αντλούσατε κανονικά από μια βάση δεδομένων ή άλλη πηγή. Ο πίνακας περιλαμβάνει στήλη **Name** (string) και στήλη **Amount** (decimal) που θα μορφοποιήσουμε αργότερα.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Γιατί είναι σημαντικό:** Η χρήση `DataTable` σας επιτρέπει να διατηρήσετε τη λογική εισαγωγής ανεξάρτητη από την πηγή δεδομένων, κάτι που είναι κοινό μοτίβο όταν δημιουργείτε αναφορές από βάσεις, CSV ή APIs.

## Βήμα 2: Ορισμός StyleArray για **εφαρμογή προσαρμοσμένης μορφής αριθμού** και **αλλαγή χρώματος γραμματοσειράς κελιού**

Το `StyleArray` σας επιτρέπει να ομαδοποιήσετε οδηγίες μορφοποίησης που θα εφαρμοστούν σε κάθε κελί που εισάγεται από το `DataTable`. Σε αυτό το παράδειγμα:

* ορίζουμε `Number` σε `#,##0.00` – τυπική λογιστική μορφή με διαχωριστικά χιλιάδων,
* ορίζουμε `FontColor` σε `Color.Blue` – ώστε οι αριθμοί να ξεχωρίζουν.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**Γιατί να χρησιμοποιήσετε StyleArray;** Η εφαρμογή στυλ κατά τη στιγμή της εισαγωγής αποφεύγει ένα δεύτερο πέρασμα στο φύλλο εργασίας, βελτιώνοντας την απόδοση για μεγάλα σύνολα δεδομένων.

## Βήμα 3: **Create Excel workbook C#** – δημιουργία Workbook και λήψη του πρώτου Worksheet

Τώρα δημιουργούμε ένα κενό workbook και παίρνουμε μια αναφορά στο πρώτο φύλλο εργασίας (δείκτης 0). Αυτό το φύλλο γίνεται ο προορισμός για τα εισαχθέντα δεδομένα.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Εξήγηση:** Το `Workbook` αντιπροσωπεύει ολόκληρο το αρχείο Excel, ενώ το `Worksheet` αντιπροσωπεύει μια καρτέλα. Το προεπιλεγμένο workbook περιέχει ένα φύλλο, που είναι επαρκές για τις περισσότερες απλές αναφορές.

## Βήμα 4: Εισαγωγή του DataTable χρησιμοποιώντας το **StyleArray** για **format imported data excel**

Η μέθοδος `ImportDataTable` αντιγράφει τις γραμμές και στήλες του πίνακα στο φύλλο εργασίας, ξεκινώντας από το κελί `A1` (γραμμή 0, στήλη 0). Το όρισμα `true` υποδεικνύει ότι θα συμπεριληφθούν οι επικεφαλίδες των στηλών. Επειδή περνάμε το `styleArray`, κάθε εισαχθέν κελί λαμβάνει την προσαρμοσμένη μορφή αριθμού και το χρώμα γραμματοσειράς.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**Τι συμβαίνει στο παρασκήνιο:** Το Aspose.Cells διατρέχει κάθε γραμμή, γράφει την τιμή και στη συνέχεια εφαρμόζει το στυλ που ορίζεται στο `styleArray`. Οι αριθμοί εμφανίζονται με κόμματα και δύο δεκαδικά ψηφία, και το κείμενο εμφανίζεται σε μπλε χρώμα.

## Βήμα 5: **Save workbook as XLSX** – εγγραφή του αρχείου στο δίσκο

Τέλος, αποθηκεύουμε το workbook σε αρχείο `.xlsx`. Μπορείτε να αλλάξετε τη διαδρομή σε οποιονδήποτε εγγράψιμο φάκελο στο σύστημά σας.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Επαλήθευση αποτελέσματος:** Ανοίξτε το παραγόμενο αρχείο στο Excel. Θα πρέπει να δείτε τις τρεις γραμμές δεδομένων, τη στήλη **Amount** μορφοποιημένη με κόμματα, δύο δεκαδικά ψηφία και εμφανιζόμενη σε μπλε γραμματοσειρά. Αυτό επιβεβαιώνει ότι το βήμα **format imported data excel** ολοκληρώθηκε επιτυχώς.

## Πλήρες Παράδειγμα Λειτουργίας

Αντιγράψτε ολόκληρο το παρακάτω μπλοκ σε ένα νέο πρότζεκτ κονσόλας και τρέξτε το. Δεν απαιτείται επιπλέον κώδικας.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Αναμενόμενη έξοδος στην κονσόλα:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

Ανοίξτε το αρχείο και επαληθεύστε ότι η στήλη **Amount** εμφανίζει τιμές όπως `1,234.56` σε μπλε γραμματοσειρά.

## Συχνές Ερωτήσεις & Ακραίες Περιπτώσεις

| Question | Answer |
|----------|--------|
| *Can I apply different formats to individual columns?* | Ναι. Μετά την εισαγωγή, λάβετε το αντικείμενο `Style` της στήλης (`worksheet.Cells.Columns[1].Style`) και ορίστε διαφορετικό `Number` ή `FontColor`. |
| *What if I need to format dates instead of numbers?* | Ορίστε `styleArray.Number = "mm-dd-yyyy"` και προαιρετικά `styleArray.FontColor` για τα κελιά ημερομηνίας. |
| *Is the blue font visible on dark Excel themes?* | Το μπλε μπορεί να είναι δύσκολο στην ανάγνωση σε σκούρα θέματα. Χρησιμοποιήστε πιο ανοιχτό χρώμα (`Color.LightBlue`) ή αντίθετο χρώμα (`Color.Black`). |
| *How do I import a very large DataTable (hundreds of thousands of rows)?* | Χρησιμοποιήστε το overload `ImportDataTable` με `ImportDataTableOptions` για ροή δεδομένων, ή χωρίστε την εισαγωγή σε πολλαπλά φύλλα ώστε να παραμείνετε εντός του ορίου γραμμών του Excel (1.048.576 γραμμές). |
| *Can I export to CSV instead of XLSX?* | Αντικαταστήστε το `SaveFormat.Xlsx` με `SaveFormat.Csv`. Σημειώστε ότι οι πληροφορίες μορφοποίησης (μορφή αριθμού, χρώμα γραμματοσειράς) χάνονται σε CSV επειδή είναι απλό κείμενο. |

## Συμβουλές για Χρήση σε Παραγωγή

* **Pro tip:** Κρατήστε στην cache το αντικείμενο `Style` αν χρειάζεται να εφαρμόσετε την ίδια μορφοποίηση σε πολλά φύλλα εργασίας· η δημιουργία νέου `StyleArray` για κάθε εισαγωγή προσθέτει επιπλέον κόστος.  
* **Προσοχή στις πολιτισμικές διαφορές:** Το μοτίβο `Number` `#,##0.00` ακολουθεί την αμετάβλητη (invariant) πολιτισμική ρύθμιση. Αν χρειάζεστε διαχωριστικά ανά τοπική ρύθμιση, χρησιμοποιήστε `NumberFormatInfo` ή αφήστε το Excel να το διαχειριστεί βάσει των ρυθμίσεων του χρήστη.  
* **Διαχείριση σφαλμάτων:** Τυλίξτε την κλήση `Save` σε μπλοκ `try‑catch` για να αντιμετωπίσετε εξαιρέσεις I/O (π.χ. ανεπαρκή δικαιώματα ή κλειδωμένα αρχεία).
