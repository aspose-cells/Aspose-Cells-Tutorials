# Δημιουργία αρχείου Excel c# – μορφοποίηση κελιών και ορισμός μορφής νομίσματος

Αν χρειάζεστε **create excel file c#** που να φαίνεται επαγγελματικό, αυτός ο οδηγός σας δείχνει ακριβώς πώς να μορφοποιήσετε κελιά Excel και να ορίσετε μια στήλη ως νόμισμα. Θα δείτε ένα πλήρες, ολοκληρωμένο παράδειγμα που εισάγει ένα `DataTable`, εφαρμόζει έντονη κεφαλίδα και θέτει τη μορφή αριθμού `$#,##0.00` για τη στήλη τιμής.

Το tutorial καλύπτει όλα όσα χρειάζεστε: απαιτούμενα πακέτα NuGet, ο πλήρης κώδικας, εξηγήσεις για το γιατί κάθε κομμάτι είναι σημαντικό, και συμβουλές για την αντιμετώπιση ειδικών περιπτώσεων όπως κενές γραμμές ή διαφορετικές τοπικές ρυθμίσεις. Στο τέλος θα μπορείτε να δημιουργήσετε ένα αρχείο `.xlsx` με μια ωραία μορφοποιημένη στήλη τιμής σε λίγες μόνο γραμμές C#.

## Προαπαιτούμενα

- .NET 6.0 ή νεότερο (ο κώδικας λειτουργεί επίσης με .NET Framework 4.6+)
- Visual Studio 2022 ή οποιονδήποτε επεξεργαστή C# προτιμάτε
- Η βιβλιοθήκη **Aspose.Cells for .NET** ή **GemBox.Spreadsheet** (και οι δύο υποστηρίζουν `ImportTableOptions`). Το παρακάτω παράδειγμα χρησιμοποιεί **Aspose.Cells** επειδή παρέχει την απλή ιδιότητα `StyleArray`.
- Βασικές γνώσεις συλλογών C# και `DataTable`

> **Pro tip:** Αν προτιμάτε μια δωρεάν εναλλακτική, αντικαταστήστε το `Aspose.Cells` με το `GemBox.Spreadsheet`. Το API για την εισαγωγή ενός `DataTable` με στυλ είναι σχεδόν ταυτόσημο· απλώς αλλάξτε το namespace και το όνομα του πακέτου NuGet.

## Βήμα 1: Εγκατάσταση της βιβλιοθήκης Excel

Ανοίξτε το NuGet Package Manager και εγκαταστήστε τη βιβλιοθήκη:

```bash
dotnet add package Aspose.Cells
```

> **Why this step?** Η βιβλιοθήκη παρέχει τις κλάσεις `Workbook`, `Worksheet`, `Style` και `ImportTableOptions` που χρησιμοποιούνται αργότερα. Χωρίς αυτήν, θα έπρεπε να γράψετε το φορμά XML του Office Open XML χειροκίνητα, κάτι που είναι επιρρεπές σε σφάλματα.

## Βήμα 2: Δημιουργία DataTable με δείγμα δεδομένων

Ένα `DataTable` είναι ένας βολικός τρόπος για να κρατήσετε δομημένα δεδομένα πριν τα εξάγετε σε Excel. Σε αυτό το παράδειγμα έχουμε δύο στήλες: *Product* και *Price*.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Explanation:**  
> - `Columns.Add("Price", typeof(double))` λέει στον πίνακα να αντιμετωπίζει τις τιμές της στήλης τιμής ως αριθμούς, κάτι που απαιτείται για τη μορφοποίηση αριθμού αργότερα.  
> - Η προσθήκη μερικών γραμμών μας δίνει δεδομένα για να επαληθεύσουμε το βήμα **format column currency**.

## Βήμα 3: Ορισμός των στυλ που θέλετε να εφαρμόσετε

Θα δημιουργήσουμε έναν πίνακα αντικειμένων `Style` που ταιριάζει με τη σειρά των στηλών. Η πρώτη καταχώρηση μορφοποιεί τη γραμμή κεφαλίδας, η δεύτερη αφήνει τη στήλη *Product* αμετάβλητη, και η τρίτη εφαρμόζει μορφή νομίσματος.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### Γιατί να χρησιμοποιήσετε ένα **style array**;

`ImportTableOptions.StyleArray` αντιστοιχίζει κάθε στήλη σε ένα `Style`. Αυτός είναι ο πιο αποδοτικός τρόπος για **add number format** και **style excel cells** σε μια ενιαία λειτουργία εισαγωγής, αποφεύγοντας δεύτερο πέρασμα πάνω στο φύλλο εργασίας.

## Βήμα 4: Διαμόρφωση επιλογών εισαγωγής

Τώρα συνδέουμε τον πίνακα στυλ με τη λειτουργία εισαγωγής. Το αντικείμενο `ImportTableOptions` σας επιτρέπει επίσης να ελέγξετε αν η πρώτη γραμμή θα θεωρηθεί κεφαλίδα.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Note:** `IsFieldNameShown` έχει προεπιλογή `true`, αλλά ο καθορισμός του ρητά κάνει την πρόθεση σαφή για μελλοντικούς αναγνώστες.

## Βήμα 5: Δημιουργία βιβλίου εργασίας, εισαγωγή του πίνακα και αποθήκευση

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### Αναμενόμενο αποτέλεσμα

Όταν ανοίξετε το `DataTableWithStyles.xlsx`:

- Η πρώτη γραμμή (κεφαλίδα) είναι **έντονη**.
- Η στήλη *Price* εμφανίζει τιμές ως **$1.20**, **$3.50**, **$0.75**.
- Η στήλη *Product* διατηρεί τη προεπιλεγμένη γραμματοσειρά.

Έχετε δημιουργήσει επιτυχώς **create excel file c#** με μια μορφοποιημένη στήλη νομίσματος και μορφοποιημένα κελιά κεφαλίδας.

## Βήμα 6: Διαχείριση κοινών παραλλαγών και ειδικών περιπτώσεων

### α. Διαφορετική τοπική ρύθμιση ή προσαρμοσμένο σύμβολο νομίσματος

Αν χρειάζεστε ευρώ ή άλλο νόμισμα, αντικαταστήστε τη ενσωματωμένη μορφή `164` με μια προσαρμοσμένη συμβολοσειρά μορφής:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### β. Προσθήκη περισσότερων στηλών αργότερα

Όταν προσθέτετε επιπλέον στήλες, επεκτείνετε τον πίνακα `columnStyles` αναλόγως. Χρησιμοποιήστε `null` για στήλες που πρέπει να διατηρήσουν το προεπιλεγμένο στυλ.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### γ. Κενό DataTable

Αν το `DataTable` δεν έχει γραμμές, το Aspose.Cells δημιουργεί ακόμα τη γραμμή κεφαλίδας. Ωστόσο, το βιβλίο εργασίας θα περιέχει μόνο μία γραμμή. Για να αποφύγετε ένα κενό αρχείο, ελέγξτε τον αριθμό γραμμών πριν την εισαγωγή:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### δ. Χρήση `GemBox.Spreadsheet` αντί του Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

Η λογική παραμένει ταυτοτική, δείχνοντας ότι το tutorial είναι **format column currency** ανεξάρτητο από τη βιβλιοθήκη που χρησιμοποιείται.

## Βήμα 7: Επαλήθευση του αρχείου προγραμματιστικά (προαιρετικό)

Μπορείτε να ανοίξετε το παραγόμενο βιβλίο εργασίας και να ελέγξετε ότι η μορφή αριθμού εφαρμόστηκε σωστά—χρήσιμο για μονάδες ελέγχου.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```
