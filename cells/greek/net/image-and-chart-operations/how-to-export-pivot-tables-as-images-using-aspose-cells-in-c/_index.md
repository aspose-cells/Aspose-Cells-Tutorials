# Πώς να εξάγετε πίνακες Pivot ως εικόνες χρησιμοποιώντας το Aspose.Cells σε C#

Αν χρειάζεστε **πώς να εξάγετε pivot** δεδομένα σε μια φορητή εικόνα, το Aspose.Cells κάνει τη διαδικασία απλή. Αυτό το tutorial σας δείχνει ακριβώς πώς να εξάγετε πίνακες pivot ως αρχεία PNG, ώστε να μπορείτε να τα ενσωματώσετε σε αναφορές, email ή τεκμηρίωση χωρίς να απαιτείται το Excel στον προορισμό.

Η εξαγωγή ενός pivot ως εικόνα εξαλείφει προβλήματα μορφοποίησης που εξαρτώνται από την έκδοση και επιτρέπει σε μη‑τεχνικούς ενδιαφερόμενους να δουν την ανάλυση άμεσα. Θα καλύψουμε τα πάντα, από τη ρύθμιση του έργου μέχρι την απόδοση της τελικής **export pivot table image**, και θα εξηγήσουμε επίσης πώς να **save pivot as image** για μελλοντική επαναχρησιμοποίηση.

## Πώς να εξάγετε πίνακες pivot ως εικόνες με Aspose.Cells

Παρακάτω βρίσκεται το πλήρες, εκτελέσιμο παράδειγμα που φορτώνει ένα workbook, ανανεώνει το pivot, ρυθμίζει τις επιλογές εικόνας και γράφει το αρχείο εξόδου. Κάθε βήμα περιλαμβάνει μια σύντομη αιτιολόγηση ώστε να κατανοήσετε *γιατί* ο κώδικας είναι γραμμένος έτσι, όχι μόνο *τι* κάνει.

### 1. Ρυθμίστε το περιβάλλον Aspose.Cells

1. Εγκαταστήστε το πακέτο NuGet:

   ```bash
   dotnet add package Aspose.Cells
   ```

2. Προσθέστε τις απαιτούμενες οδηγίες `using` στην κορυφή του αρχείου C#:

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **Pro tip:** Στοχεύστε στο .NET 6 ή νεότερο για να επωφεληθείτε από τις τελευταίες βελτιώσεις απόδοσης στο Aspose.Cells.

### 2. Φορτώστε το workbook και εντοπίστε τον πίνακα pivot

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*Γιατί είναι σημαντικό:* Η κλάση `Workbook` αναλύει το αρχείο XLSX και σας δίνει πρόσβαση σε όλα τα φύλλα εργασίας. Η επιλογή του σωστού φύλλου είναι ουσιώδης επειδή ένα workbook μπορεί να περιέχει πολλαπλά pivots.

### 3. Ανανεώστε τον πίνακα pivot για να καταγράψετε τα πιο πρόσφατα δεδομένα πηγής

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

Η ανανέωση εγγυάται ότι τυχόν αλλαγές που έγιναν στην περιοχή πηγής μετά την αποθήκευση του αρχείου αντικατοπτρίζονται στην εικόνα που θα δημιουργηθεί. Η παράλειψη αυτού του βήματος μπορεί να παράγει παλιές ή ανακριβείς απεικονίσεις.

### 4. Ρυθμίστε τις επιλογές εξαγωγής εικόνας (export pivot table image)

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

Το αντικείμενο `ImageOrPrintOptions` σας επιτρέπει να ελέγξετε τη μορφή, την ανάλυση και άλλες λεπτομέρειες απόδοσης. Το PNG είναι η πιο κοινή επιλογή για καθαρά, συμβατά με το web γραφικά, αλλά μπορείτε να μεταβείτε σε `ImageFormat.Jpeg` αν το μέγεθος του αρχείου είναι πρόβλημα.

### 5. Απόδοση και **save pivot as image**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

Η μέθοδος `RenderToImage` εκτελεί το βαριά έργο: σχεδιάζει το pivot ακριβώς όπως εμφανίζεται στο Excel και γράφει τα δυαδικά δεδομένα PNG στο δίσκο. Η μέθοδος επιστρέφει `void`, οπότε μπορείτε να υποθέσετε με ασφάλεια ότι το αρχείο υπάρχει μετά την ολοκλήρωση της κλήσης χωρίς επιπλέον ελέγχους.

#### Αναμενόμενο αποτέλεσμα

Μετά την εκτέλεση του προγράμματος, θα βρείτε το `Pivot.png` στον καθορισμένο φάκελο. Το άνοιγμα του αρχείου θα πρέπει να εμφανίζει μια πιστή λήψη του αρχικού πίνακα pivot, συμπεριλαμβανομένων των κεφαλίδων στηλών, των συνολικών γραμμών και οποιασδήποτε εφαρμοσμένης μορφοποίησης.

### 6. Συνηθισμένες παραλλαγές και ειδικές περιπτώσεις

| Σενάριο | Προσαρμογή |
|----------|------------|
| **Large pivots** (πολλές γραμμές/στήλες) | Αυξήστε το `HorizontalResolution` και το `VerticalResolution` στα 300 dpi για πιο καθαρό αποτέλεσμα. |
| **Custom styling** (χρώματα φόντου, γραμματοσειρές) | Βεβαιωθείτε ότι οι ορισμοί στυλ του workbook έχουν φορτωθεί πριν καλέσετε `Refresh()`. |
| **Multiple pivots** σε ένα φύλλο | Κάντε βρόχο μέσω του `worksheet.PivotTables` και καλέστε `RenderToImage` για κάθε ένα, χρησιμοποιώντας διαφορετικά ονόματα αρχείων. |
| **Export to JPEG** αντί για PNG | Αλλάξτε `ImageFormat = ImageFormat.Jpeg` και προαιρετικά ορίστε `Quality` σε ένα αντικείμενο `JpegSaveOptions`. |

Αυτές οι παραλλαγές σας επιτρέπουν να **export pivot table image** στη μορφή που απαιτεί το σύστημα downstream.

## Πλήρης κώδικας για γρήγορη αντιγραφή‑επικόλληση

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

Η εκτέλεση του προγράμματος παράγει το αρχείο PNG που φαίνεται παραπάνω, ολοκληρώνοντας τη ροή εργασίας **save pivot as image** σε λιγότερο από ένα λεπτό.

## Συμπέρασμα

Τώρα γνωρίζετε **πώς να εξάγετε pivot** πίνακες σε αρχεία εικόνας χρησιμοποιώντας το Aspose.Cells σε C#. Ο οδηγός σας οδήγησε από τη ρύθμιση της βιβλιοθήκης, τη φόρτωση του workbook, την ανανέωση του pivot, τη διαμόρφωση επιλογών PNG και τέλος την απόδοση της **export pivot table image**, ενώ έδειξε επίσης πώς να **save pivot as image** για μελλοντική χρήση.

Επόμενα βήματα που μπορείτε να εξερευνήσετε:

* **Batch export** – επαναλάβετε τη διαδικασία για όλους τους πίνακες pivot σε ένα workbook και δημιουργήστε μια αναφορά PDF που ενσωματώνει κάθε PNG.
* **Apply custom themes** – τροποποιήστε τη συλλογή στυλ του workbook πριν την απόδοση ώστε να ταιριάζει με την εταιρική ταυτότητα.
* **Integrate with ASP.NET Core** – δημιουργήστε το PNG σε πραγματικό χρόνο και επιστρέψτε το ως απόκριση HTTP για πίνακες ελέγχου στο web.
