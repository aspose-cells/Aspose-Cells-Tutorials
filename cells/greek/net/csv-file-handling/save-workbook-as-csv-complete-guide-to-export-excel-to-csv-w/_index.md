# Αποθήκευση Βιβλίου Εργασίας ως CSV – Πλήρης Οδηγός για Εξαγωγή Excel σε CSV με Ελεγχόμενα Ψηφία

Έχετε αναρωτηθεί ποτέ **πώς να περιορίσετε την έξοδο CSV** όταν εξάγετε ένα βιβλίο εργασίας Excel; Ίσως έχετε προσπαθήσει να **γράψετε αριθμό σε κελί** και το παραγόμενο CSV φαίνεται ακατάστατο, με έναν τοίχο δεκαδικών ψηφίων που δεν χρειάζεστε. Τα καλά νέα είναι ότι με το Aspose.Cells μπορείτε να **αποθηκεύσετε το βιβλίο εργασίας ως CSV** ελέγχοντας με ακρίβεια τον αριθμό των σημαντικών ψηφίων. Σε αυτόν τον οδηγό θα περάσουμε από κάθε βήμα, από τη δημιουργία ενός βιβλίου εργασίας μέχρι τη ρύθμιση του `CsvSaveOptions` ώστε το αρχείο να περιέχει ακριβώς τα δεδομένα που θέλετε.

Θα καλύψουμε:

* Πώς να **εξάγετε Excel σε CSV** χρησιμοποιώντας Aspose.Cells σε C#  
* Την ιδιότητα που σας επιτρέπει να **ορίσετε σημαντικά ψηφία**  
* Ένα πλήρες, εκτελέσιμο παράδειγμα που **γράφει αριθμό σε κελί** και περιορίζει την έξοδο CSV  
* Συνηθισμένα προβλήματα και συμβουλές για έργα πραγματικού κόσμου  

Δεν απαιτείται προγενέστερη εμπειρία με το Aspose.Cells — μόνο μια βασική κατανόηση του C# και του Visual Studio.

## Προαπαιτούμενα

Πριν ξεκινήσουμε, βεβαιωθείτε ότι έχετε:

* **.NET 6.0** (ή νεότερη) εγκατεστημένη – η πιο πρόσφατη runtime λειτουργεί καλύτερα με το Aspose.Cells.  
* **Aspose.Cells for .NET** πακέτο NuGet – εγκαταστήστε το μέσω `dotnet add package Aspose.Cells`.  
* Ένα **επεξεργαστή κειμένου ή IDE** (Visual Studio, VS Code, Rider – όποιο σας βολεύει).  

Αυτό είναι όλο. Αν έχετε ήδη αυτά, είστε έτοιμοι να ξεκινήσετε.

## Βήμα 1: Δημιουργία Νέου Βιβλίου Εργασίας και Πρόσβαση στο Πρώτο Φύλλο

Το πρώτο πράγμα που πρέπει να κάνετε είναι να δημιουργήσετε ένα κενό βιβλίο εργασίας. Σκεφτείτε το βιβλίο εργασίας ως το δοχείο για όλα τα φύλλα σας, όπως ένα αρχείο Excel στο δίσκο.

```csharp
using Aspose.Cells;
using System;

class SignificantDigitsDemo
{
    static void Main()
    {
        // Step 1: Create a new workbook and get the first worksheet
        Workbook workbook = new Workbook();                 // new, blank workbook
        Worksheet sheet = workbook.Worksheets[0];           // first (default) worksheet
```

Γιατί να ξεκινήσετε με ένα φρέσκο βιβλίο εργασίας; Επειδή εγγυάται μια καθαρή βάση — χωρίς κρυφή μορφοποίηση ή υπολειπόμενα δεδομένα που θα μπορούσαν να επηρεάσουν το CSV αργότερα.  

> **Pro tip:** Αν έχετε ήδη ένα υπάρχον αρχείο Excel, απλώς αντικαταστήστε το `new Workbook()` με το `new Workbook("path/to/file.xlsx")`.

## Βήμα 2: Γράψτε Έναν Αριθμό στο Κελί A1 με Πολλά Δεκαδικά Ψηφία

Τώρα θα **γράψουμε αριθμό σε κελί** `A1`. Η τιμή που επιλέγουμε έχει περισσότερα ψηφία από όσα τελικά θέλουμε να διατηρήσουμε, κάτι που θα μας επιτρέψει να δείξουμε τη λειτουργία περιορισμού ψηφίων.

```csharp
        // Step 2: Write a number with many decimal places into cell A1
        sheet.Cells["A1"].PutValue(12345.6789012345);
```

Παρατηρήστε τη χρήση του `PutValue`. Ανιχνεύει αυτόματα τον τύπο δεδομένων (εδώ ένα `double`) και το αποθηκεύει σωστά. Αν δουλεύατε με ημερομηνίες, κείμενο ή τύπους, θα χρησιμοποιούσατε τις αντίστοιχες υπερφορτώσεις.

## Βήμα 3: Ρύθμιση Επιλογών Αποθήκευσης CSV – Ορισμός Σημαντικών Ψηφίων

Αυτή είναι η καρδιά του οδηγού: **ορισμός σημαντικών ψηφίων**. Το Aspose.Cells εκθέτει μια κλάση `CsvSaveOptions` όπου μπορείτε να καθορίσετε ακριβώς πόσα ψηφία θα διατηρηθούν όταν **αποθηκεύετε το βιβλίο εργασίας ως CSV**.

```csharp
        // Step 3: Configure CSV save options to limit the number of significant digits
        var csvOptions = new CsvSaveOptions
        {
            SignificantDigits = 6   // keep only 6 significant digits
        };
```

Γιατί έξι; Είναι ένας εύκολος αριθμός για παράδειγμα — το `12345.6789012345` γίνεται `12345.7` όταν στρογγυλοποιηθεί σε έξι σημαντικά ψηφία. Μπορείτε να προσαρμόσετε αυτήν την τιμή ώστε να ταιριάζει στις επιχειρηματικές σας απαιτήσεις (π.χ., οι οικονομικές αναφορές συχνά χρειάζονται δύο δεκαδικά ψηφία, ενώ τα επιστημονικά δεδομένα μπορεί να χρειάζονται περισσότερα).

## Βήμα 4: Αποθήκευση του Βιβλίου Εργασίας ως Αρχείο CSV Χρησιμοποιώντας τις Ρυθμισμένες Επιλογές

Τέλος, **εξάγουμε το Excel σε CSV** με τις επιλογές που μόλις ορίσαμε. Η μέθοδος `Save` δέχεται τρία ορίσματα: τη διαδρομή του αρχείου, το enum μορφής και το αντικείμενο επιλογών.

```csharp
        // Step 4: Save the workbook as a CSV file using the configured options
        workbook.Save("YOUR_DIRECTORY/LimitedDigits.csv", SaveFormat.Csv, csvOptions);
        Console.WriteLine("CSV saved with controlled significant digits.");
    }
}
```

Αντικαταστήστε το `YOUR_DIRECTORY` με έναν πραγματικό φάκελο στον υπολογιστή σας, ή χρησιμοποιήστε μια σχετική διαδρομή όπως `./LimitedDigits.csv`. Όταν εκτελέσετε το πρόγραμμα, θα δείτε ένα μήνυμα που επιβεβαιώνει την εξαγωγή.

### Αναμενόμενη Έξοδος CSV

Ανοίξτε το παραγόμενο `LimitedDigits.csv` σε έναν επεξεργαστή κειμένου (Notepad, VS Code κ.λπ.) και θα πρέπει να δείτε:

```
12345.7
```

Μόνο έξι σημαντικά ψηφία παραμένουν, αποδεικνύοντας ότι το **πώς να περιορίσετε την έξοδο CSV** είναι πλέον υπό τον έλεγχό σας.

## Προχωρημένο: Εξαγωγή Πολλαπλών Φύλλων και Προσαρμοσμένων Διαχωριστών

Σε πολλές πραγματικές περιπτώσεις θα έχετε περισσότερα από ένα φύλλο εργασίας, ή μπορεί να χρειάζεστε ελληνικά ερωτηματικά (;) αντί για κόμματα. Το ίδιο αντικείμενο `CsvSaveOptions` σας επιτρέπει να ρυθμίσετε αυτές τις επιλογές:

```csharp
var advancedCsvOptions = new CsvSaveOptions
{
    SignificantDigits = 8,
    Separator = ';',                    // use semicolon as delimiter
    ExportAllSheets = true              // include every worksheet in the CSV
};
workbook.Save("AllSheets.csv", SaveFormat.Csv, advancedCsvOptions);
```

> **Note:** Όταν το `ExportAllSheets` είναι `true`, κάθε φύλλο αποθηκεύεται σε ξεχωριστό αρχείο CSV με το όνομα του φύλλου προσαρτημένο στο όνομα του αρχείου.

## Συνηθισμένα Προβλήματα και Πώς να τα Αποφύγετε

| Προβλήμα | Γιατί Συμβαίνει | Διόρθωση |
|----------|----------------|----------|
| **Τα ψηφία δεν περικοπούν** | `SignificantDigits` προεπιλογή είναι `0`, που σημαίνει “χωρίς στρογγυλοποίηση”. | Πάντα ορίστε ρητά το `SignificantDigits`. |
| **Λάθος δεκαδικός διαχωριστής** | Η τοπική ρύθμιση του συστήματος χρησιμοποιεί κόμματα, αλλά το CSV αναμένει τελείες. | Ορίστε `CsvSaveOptions.DecimalSeparator = '.';` αν χρειάζεται. |
| **Αρχείο αντικαθίσταται σιωπηρά** | Η αποθήκευση σε υπάρχουσα διαδρομή αντικαθιστά το αρχείο χωρίς προειδοποίηση. | Ελέγξτε `File.Exists` πριν καλέσετε το `Save` ή χρησιμοποιήστε όνομα με χρονική σήμανση. |
| **Μεγάλο βιβλίο εργασίας επιβραδύνει** | Η εξαγωγή ενός τεράστιου βιβλίου εργασίας με πολλά φύλλα μπορεί να είναι αργή. | Εξάγετε μόνο το απαιτούμενο φύλλο (`ExportAllSheets = false`) και περιορίστε τις γραμμές/στήλες μέσω `CsvSaveOptions`. |

## Επαλήθευση του Αποτελέσματος Προγραμματιστικά

Αν χρειάζεται να επιβεβαιώσετε το περιεχόμενο του CSV μέσα από τον κώδικά σας (π.χ., σε μονάδες ελέγχου), μπορείτε να διαβάσετε ξανά το αρχείο και να ελέγξετε την αναμενόμενη συμβολοσειρά:

```csharp
string csvContent = System.IO.File.ReadAllText("YOUR_DIRECTORY/LimitedDigits.csv");
if (csvContent.Trim() == "12345.7")
{
    Console.WriteLine("Verification passed!");
}
else
{
    Console.WriteLine($"Unexpected CSV content: {csvContent}");
}
```

Αυτό το απόσπασμα δείχνει **πώς να περιορίσετε την έξοδο CSV** και επίσης αποδεικνύει ότι ο περιορισμός εφαρμόστηκε σωστά.

## Επόμενα Βήματα: Ενσωμάτωση σε Μεγαλύτερη Ροή Εργασίας

Τώρα που ξέρετε πώς να **αποθηκεύσετε το βιβλίο εργασίας ως CSV** με έλεγχο ψηφίων, σκεφτείτε αυτές τις επεκτάσεις:

* **Επεξεργασία παρτίδας** – επανάληψη σε φάκελο αρχείων Excel, εφαρμόζοντας το ίδιο `CsvSaveOptions`.  
* **Δυναμική επιλογή ψηφίων** – υπολογισμός του `SignificantDigits` βάσει μεταδεδομένων στήλης.  
* **Συμπίεση** – διοχέτευση του ρεύματος CSV απευθείας σε αρχείο ZIP για γρηγορότερες λήψεις.  

Όλα αυτά βασίζονται στις βασικές έννοιες που καλύψαμε και θα κάνουν τη διαδικασία εξαγωγής δεδομένων σας πιο αξιόπιστη και ευέλικτη.
