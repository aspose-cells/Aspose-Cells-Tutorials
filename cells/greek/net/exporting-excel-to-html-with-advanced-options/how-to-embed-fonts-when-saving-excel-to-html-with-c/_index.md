# Πώς να ενσωματώσετε γραμματοσειρές όταν αποθηκεύετε το Excel σε HTML με C#

Η ενσωμάτωση γραμματοσειρών κατά την αποθήκευση ενός βιβλίου εργασίας Excel σε HTML είναι μια συχνή απαίτηση για τη διατήρηση της ακριβούς εμφάνισης των λογιστικών φύλλων σας σε διαφορετικά προγράμματα περιήγησης. Αν χρειάζεστε εξαγωγή του Excel σε HTML διατηρώντας τις αρχικές γραμματοσειρές, αυτός ο οδηγός σας παρουσιάζει μια πλήρη, έτοιμη προς εκτέλεση λύση.

Θα μάθετε πώς να **εξάγετε το Excel σε HTML**, **μετατρέπετε το Excel σε HTML** με ενσωματωμένες γραμματοσειρές, και να αποφύγετε το συνηθισμένο πρόβλημα «λείπει η γραμματοσειρά» που διασπά τη διάταξη στα μηχανήματα των χρηστών. Δεν απαιτούνται εξωτερικά εργαλεία — μόνο η βιβλιοθήκη Aspose.Cells και μερικές γραμμές C#.

## Προαπαιτούμενα

Πριν ξεκινήσετε, βεβαιωθείτε ότι έχετε:

* .NET 6.0 (ή νεότερο) εγκατεστημένο.
* Αδειοδοτημένο αντίγραφο του **Aspose.Cells for .NET** – η δωρεάν δοκιμή λειτουργεί για δοκιμές.
* Ένα IDE όπως το Visual Studio 2022 ή το VS Code.

Αν έχετε ήδη όλα αυτά, μπορείτε να περάσετε κατευθείαν στον κώδικα.

## Βήμα 1: Δημιουργία βιβλίου εργασίας και προσθήκη δείγματος δεδομένων

Πρώτα δημιουργούμε ένα μικρό βιβλίο εργασίας ώστε να δείτε το αποτέλεσμα των ενσωματωμένων γραμματοσειρών. Ο παρακάτω κώδικας δημιουργεί ένα φύλλο εργασίας, γράφει μερικά κελιά και εφαρμόζει μια προσαρμοσμένη γραμματοσειρά.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### Γιατί προσθέτουμε προσαρμοσμένη γραμματοσειρά

Η ενσωμάτωση γραμματοσειρών έχει σημασία μόνο όταν το βιβλίο εργασίας χρησιμοποιεί γραμματοσειρές που μπορεί να μην υπάρχουν στη συσκευή του χρήστη. Ορίζοντας ρητά **Arial** (ή οποιαδήποτε άλλη γραμματοσειρά) μπορούμε να επαληθεύσουμε ότι η έξοδος HTML περιέχει πραγματικά τα δεδομένα της γραμματοσειράς.

## Βήμα 2: Διαμόρφωση επιλογών αποθήκευσης HTML για ενσωμάτωση γραμματοσειρών

Η Aspose.Cells παρέχει την κλάση `HtmlSaveOptions`. Ορίζοντας `EmbedFonts = true` λέτε στη βιβλιοθήκη να ενσωματώσει τα απαιτούμενα αρχεία γραμματοσειρών απευθείας στο παραγόμενο HTML ως κωδικοποιημένα Base64 URIs.

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### Τι κάνει πραγματικά η «ενσωμάτωση γραμματοσειρών σε html»

Όταν το `EmbedFonts` είναι true, η Aspose.Cells εξάγει τα αρχεία γραμματοσειρών από το σύστημα (ή από τη συλλογή ενσωματωμένων γραμματοσειρών του βιβλίου εργασίας) και τα μετατρέπει σε αλφαριθμητικά **Base64**. Αυτά τα αλφαριθμητικά τοποθετούνται μέσα σε ένα μπλοκ `<style>` χρησιμοποιώντας `@font-face`. Το παραγόμενο HTML μπορεί να ανοιχθεί σε οποιαδήποτε συσκευή χωρίς να απαιτείται η αρχική γραμματοσειρά να είναι εγκατεστημένη.

## Βήμα 3: Αποθήκευση του βιβλίου εργασίας ως HTML με ενσωματωμένες γραμματοσειρές

Τώρα γράφουμε το βιβλίο εργασίας στο δίσκο. Το αρχείο θα περιέχει τα δεδομένα της γραμματοσειράς, οπότε το άνοιγμα του σε οποιονδήποτε σύγχρονο περιηγητή θα εμφανίσει την ίδια τυπογραφία με το αρχικό αρχείο Excel.

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### Αναμενόμενο αποτέλεσμα

* Το `embedded.html` βρίσκεται στο φάκελο `output`.
* Το άνοιγμα του αρχείου σε Chrome, Edge ή Firefox εμφανίζει το φύλλο εργασίας με κείμενο **Arial**, ακόμη και αν η μηχανή του περιηγητή δεν διαθέτει Arial.
* Η εξέταση του πηγαίου κώδικα HTML αποκαλύπτει ένα μπλοκ `<style>` που περιέχει έναν κανόνα `@font-face` με μια μακριά δήλωση `src: url(data:font/ttf;base64,…)` – αυτή είναι η ενσωματωμένη γραμματοσειρά.

## Βήμα 4: Επαλήθευση ότι το HTML λειτουργεί σε άλλο μηχάνημα (προαιρετικό)

Για να είστε απολύτως σίγουροι ότι η ενσωμάτωση πέτυχε:

1. Αντιγράψτε το `output/embedded.html` σε έναν διαφορετικό υπολογιστή (ή εικονική μηχανή) που **δεν** έχει εγκατεστημένη τη συγκεκριμένη γραμματοσειρά.
2. Ανοίξτε το αρχείο σε έναν περιηγητή.
3. Η διάταξη και η τυπογραφία πρέπει να ταιριάζουν με την αρχική προβολή του Excel.

Αν η γραμματοσειρά υποκατασταθεί από μια γενική, ελέγξτε ξανά ότι το αρχείο γραμματοσειράς είναι προσβάσιμο στη μηχανή κατασκευής και ότι έχετε δικαίωμα ανάγνωσής του.

## Συχνές ερωτήσεις και ειδικές περιπτώσεις

### Η ενσωμάτωση αυξάνει το μέγεθος του αρχείου;

Ναι. Η ενσωμάτωση μιας γραμματοσειράς TrueType ή OpenType μπορεί να προσθέσει **δέκαδες kilobytes** στο αρχείο HTML. Για μεγάλα βιβλία εργασίας με πολλές μοναδικές γραμματοσειρές, σκεφτείτε:

* Υποσύνολο της γραμματοσειράς (μόνο οι χαρακτήρες που χρησιμοποιείτε) – η Aspose.Cells το κάνει αυτό αυτόματα για τις πιο κοινές γραμματοσειρές.
* Χρήση του `ExportEmbeddedImages = false` αν δεν χρειάζεστε ενσωματωμένες εικόνες.

### Τι γίνεται αν θέλω να ενσωματώσω μόνο συγκεκριμένες γραμματοσειρές;

Η `HtmlSaveOptions` δεν παρέχει άμεσο λευκό κατάλογο, αλλά μπορείτε να ελέγξετε ποιες γραμματοσειρές εμφανίζονται ** περιορίζοντας τις γραμματοσειρές που χρησιμοποιούνται στο βιβλίο εργασίας** πριν καλέσετε το `Save`. Αφαιρέστε περιττές αναθέσεις γραμματοσειρών ή αντικαταστήστε τες με τυπικές web‑safe γραμματοσειρές.

### Μπορώ να ενσωματώσω γραμματοσειρές όταν μετατρέπω σε άλλες μορφές (π.χ., PDF);

Η ίδια ιδιότητα `EmbedFonts` υπάρχει και στην `PdfSaveOptions`. Η έννοια είναι η ίδια: τα δεδομένα της γραμματοσειράς ενσωματώνονται ώστε το PDF να αποδίδει σωστά σε οποιονδήποτε προβολέα.

## Πλήρες, εκτελέσιμο παράδειγμα

Ακολουθεί το πλήρες πρόγραμμα που μπορείτε να αντιγράψετε‑επικολλήσετε σε ένα νέο έργο κονσόλας.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

Η εκτέλεση του προγράμματος παράγει ένα **αρχείο HTML που περιέχει την ενσωματωμένη γραμματοσειρά Arial**, εξασφαλίζοντας οπτική πιστότητα όπου και αν ανοίξει το αρχείο.
