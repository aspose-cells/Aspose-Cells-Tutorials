# Πώς να ενσωματώσετε γραμματοσειρές σε HTML κατά την αποθήκευση ενός βιβλίου εργασίας

Αν χρειάζεστε **πώς να ενσωματώσετε γραμματοσειρές σε HTML** κατά την εξαγωγή ενός υπολογιστικού φύλλου, αυτό το tutorial σας δείχνει μια πλήρη, έτοιμη προς εκτέλεση λύση. Είτε δημιουργείτε μια πύλη αναφορών είτε μια προβολή ανάλυσης στην πλευρά του πελάτη, η ενσωμάτωση γραμματοσειρών εγγυάται ότι το παραγόμενο HTML φαίνεται ακριβώς όπως το αρχικό βιβλίο εργασίας, ανεξάρτητα από τις εγκατεστημένες γραμματοσειρές του θεατή.

Θα μάθετε επίσης τον καλύτερο τρόπο για **αποθήκευση βιβλίου εργασίας ως HTML** χρησιμοποιώντας το Aspose.Cells, θα δείτε κοινά προβλήματα και θα λάβετε συμβουλές για τη διαχείριση μεγάλων βιβλίων εργασίας ή προσαρμοσμένων αρχείων γραμματοσειρών. Δεν απαιτείται εξωτερική τεκμηρίωση — όλα όσα χρειάζεστε είναι σε αυτόν τον οδηγό.

## Προαπαιτούμενα

- .NET 6.0 ή νεότερο (ο κώδικας λειτουργεί επίσης με .NET Framework 4.7+)
- Ένα έγκυρο άδεια Aspose.Cells για .NET (ή μπορείτε να χρησιμοποιήσετε τη δωρεάν λειτουργία αξιολόγησης)
- Βασικές γνώσεις C# και ένα IDE όπως το Visual Studio 2022
- Τα αρχεία γραμματοσειρών TrueType (.ttf) ή OpenType (.otf) που θέλετε να ενσωματώσετε (πρέπει να είναι προσβάσιμα από τη διεργασία που εκτελείται)

## Βήμα 1: Ρύθμιση του έργου και εισαγωγή του Aspose.Cells

Δημιουργήστε μια νέα εφαρμογή κονσόλας και προσθέστε το πακέτο NuGet του Aspose.Cells:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

Στη συνέχεια, ανοίξτε το **Program.cs** και προσθέστε τις απαιτούμενες οδηγίες `using`:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **Συμβουλή επαγγελματία:** Τοποθετήστε τις προσαρμοσμένες γραμματοσειρές σας σε έναν φάκελο με όνομα `fonts` μέσα στη ρίζα του έργου. Αυτό διατηρεί τη λύση φορητή και καθιστά εύκολη την αναφορά σε αυτές αργότερα.

## Βήμα 2: Δημιουργία ή φόρτωση βιβλίου εργασίας

Για επίδειξη, θα δημιουργήσουμε ένα απλό βιβλίο εργασίας με μερικά μορφοποιημένα κελιά:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **Γιατί είναι σημαντικό:** Εάν παραλείψετε το προσαρμοσμένο στυλ, το εξαγόμενο HTML θα επιστρέψει στις προεπιλεγμένες γραμματοσειρές του προγράμματος περιήγησης, αντιστρέφοντας τον σκοπό του **πώς να ενσωματώσετε γραμματοσειρές σε HTML**.

## Βήμα 3: Διαμόρφωση του `HtmlSaveOptions` για ενσωμάτωση γραμματοσειρών

Ο πυρήνας του **πώς να ενσωματώσετε γραμματοσειρές σε HTML** βρίσκεται στην κλάση `HtmlSaveOptions`. Ορίζοντας `EmbedFonts = true` λέτε στο Aspose.Cells να ενσωματώσει οποιεσδήποτε αναφερόμενες γραμματοσειρές TrueType/OpenType απευθείας στο παραγόμενο HTML ως κωδικοποιημένα Base64 δεδομένα URI.

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### Πώς λειτουργεί η ενσωμάτωση

Όταν το `EmbedFonts` είναι `true`, το Aspose.Cells σαρώει τις ορισμούς στυλ του βιβλίου εργασίας, εντοπίζει τα αντίστοιχα αρχεία γραμματοσειρών στο σύστημα (ή στον φάκελο `fonts` που προσθέσατε), διαβάζει τα δυαδικά τους δεδομένα και ενσωματώνει ένα μπλοκ `<style>` παρόμοιο με:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

Επειδή τα δεδομένα της γραμματοσειράς κωδικοποιούνται απευθείας στο HTML, η σελίδα αποδίδεται σωστά ακόμη και σε μηχανές που δεν έχουν εγκατεστημένη τη γραμματοσειρά.

## Βήμα 4: Αποθήκευση του βιβλίου εργασίας ως HTML

Τώρα μπορείτε να **αποθηκεύσετε το βιβλίο εργασίας ως HTML** με τις διαμορφωμένες επιλογές. Επιλέξτε έναν φάκελο στον οποίο η εφαρμογή μπορεί να γράψει (π.χ., `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

Η εκτέλεση του προγράμματος παράγει ένα μόνο αρχείο `report.html`. Ανοίξτε το σε οποιονδήποτε σύγχρονο πρόγραμμα περιήγησης και θα δείτε την κεφαλίδα «Quarterly Sales» να αποδίδεται με τη γραμματοσειρά **Pacifico**, ακόμη και αν η γραμματοσειρά δεν είναι εγκατεστημένη στο λειτουργικό σας σύστημα.

### Αναμενόμενο αποτέλεσμα

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

Το χαρακτηριστικό `src:` περιέχει μια μακριά συμβολοσειρά Base64 — αυτά είναι τα ενσωματωμένα δεδομένα γραμματοσειράς που επιτρέπουν το **πώς να ενσωματώσετε γραμματοσειρές σε HTML**.

## Βήμα 5: Επαλήθευση ενσωμάτωσης γραμματοσειρών και αντιμετώπιση προβλημάτων

1. **Ανοίξτε το αρχείο HTML σε Chrome ή Edge.** Εάν εμφανιστεί η προσαρμοσμένη γραμματοσειρά, η ενσωμάτωση πέτυχε.  
2. **Εξετάστε τον πηγαίο κώδικα της σελίδας.** Αναζητήστε τον κανόνα `@font-face` που δημιουργήθηκε από το Aspose.Cells.  
3. **Κοινά προβλήματα:**  
   - *Απουσία αρχείου γραμματοσειράς:* Βεβαιωθείτε ότι το αρχείο γραμματοσειράς είναι προσβάσιμο. Μπορείτε να προσθέσετε ρητά έναν φάκελο στη διαδρομή αναζήτησης:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *Μεγάλο μέγεθος HTML:* Η ενσωμάτωση πολλών γραμματοσειρών μπορεί να αυξήσει το μέγεθος του αρχείου. Χρησιμοποιήστε `ExportToSingleFile = false` για να διατηρήσετε τις γραμματοσειρές ως ξεχωριστά αρχεία `.ttf` σε φάκελο πόρων.

   - *Μη υποστηριζόμενη μορφή γραμματοσειράς:* Το Aspose.Cells ενσωματώνει μόνο TrueType (`.ttf`) και OpenType (`.otf`). Μετατρέψτε άλλες μορφές πριν την ενσωμάτωση.

## Πλήρες λειτουργικό παράδειγμα

Παρακάτω βρίσκεται το πλήρες πρόγραμμα που μπορείτε να αντιγράψετε, επικολλήσετε και εκτελέσετε χωρίς τροποποιήσεις (εκτός από τη γραμμή άδειας, αν χρειάζεται).

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

Η εκτέλεση αυτού του προγράμματος δημιουργεί το `output/report.html`. Ανοίξτε το αρχείο και θα δείτε τη γραμματοσειρά **Pacifico** να αποδίδεται σωστά — επιδεικνύοντας **πώς να ενσωματώσετε γραμματοσειρές σε HTML** ενώ **αποθηκεύετε το βιβλίο εργασίας ως HTML**.

## Συχνές ερωτήσεις

| Ερώτηση | Απάντηση |
|----------|--------|
| *Μπορώ να ενσωματώσω μόνο συγκεκριμένες γραμματοσειρές;* | Ναι. Ορίστε `htmlOpt.EmbedAllFonts = false` (διαθέσιμο σε νεότερες εκδόσεις) και χρησιμοποιήστε `htmlOpt.FontsToEmbed` για να καταγράψετε τα ακριβή ονόματα των γραμματοσειρών. |
| *Τι γίνεται αν χρειαστεί να ενσωματώσω γραμματοσειρές για πολλαπλά φύλλα εργασίας;* | Ορίστε `ExportActiveWorksheetOnly = false` ώστε κάθε φύλλο εργασίας να εξαχθεί, και το Aspose.Cells θα ενσωματώσει τις γραμματοσειρές που χρησιμοποιούνται σε όλο το βιβλίο εργασίας. |
| *Θα λειτουργούν οι ενσωματωμένες γραμματοσειρές σε κινητά προγράμματα περιήγησης;* | Τα σύγχρονα κινητά προγράμματα περιήγησης υποστηρίζουν γραμματοσειρές κωδικοποιημένες σε Base64, έτσι οι ενσωματωμένες γραμματοσειρές αποδίδονται σωστά εφόσον η μορφή της γραμματοσειράς υποστηρίζεται (TTF ή OTF). |
| *Πόσο μεγάλο μπορεί να γίνει το αρχείο HTML;* | Η ενσωμάτωση μιας γραμματοσειράς TrueType 200 KB προσθέτει περίπου το ίδιο μέγεθος στο HTML (Base64 προσθέτει ~33 % επιπλέον). Για πολλές γραμματοσειρές, σκεφτείτε την εξαγωγή σε φάκελο (`ExportToSingleFile = false`) ώστε το HTML να παραμείνει ελαφρύ. |
