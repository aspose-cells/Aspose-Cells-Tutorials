# Πώς να εξάγετε δεδομένα σε Excel χρησιμοποιώντας ένα πρότυπο C# – οδηγός βήμα‑βήμα

Αν χρειάζεστε **εξαγωγή δεδομένων σε Excel** από μια εφαρμογή .NET, αυτός ο οδηγός παρουσιάζει μια πλήρη λύση που εκτελείται από άκρη σε άκρη. Φορτώνοντας ένα πρότυπο Excel που ήδη περιέχει ετικέτες Smart Marker, μπορείτε να **αυτοματοποιήσετε τη δημιουργία Excel** και να παραγάγετε ένα επαγγελματικό **employee report Excel** χωρίς να γράψετε κώδικα κελί‑με‑κελί.

Θα δείτε πώς να:

* Φορτώσετε ένα πρότυπο Excel (`load excel template`) που ορίζει τη διάταξη.
* Εισάγετε μια λίστα αντικειμένων employee στο πρότυπο.
* Δημιουργήσετε το τελικό βιβλίο εργασίας και αποθηκεύσετε το ως `output.xlsx`.

Όλος ο απαιτούμενος κώδικας περιλαμβάνεται, ώστε να μπορείτε να τον αντιγράψετε, επικολλήσετε και να τον εκτελέσετε αμέσως.

## Προαπαιτούμενα

* .NET 6.0 ή νεότερο (ο κώδικας λειτουργεί επίσης με .NET Framework 4.7+).  
* Το πακέτο NuGet **Aspose.Cells for .NET** – παρέχει `Workbook`, `SmartMarkerProcessor` και υποστήριξη Smart Marker.  
* Ένας φάκελος με όνομα `YOUR_DIRECTORY` που περιέχει το `template.xlsx`. Το πρότυπο πρέπει να έχει ετικέτες Smart Marker όπως `&=EmployeeList.Name` στα κελιά όπου θέλετε να εμφανιστούν τα δεδομένα.

> **Pro tip:** Κρατήστε το πρότυπο στον ίδιο φάκελο του έργου και ορίστε την ιδιότητα *Copy to Output Directory* σε *Copy always* ώστε η διαδρομή να επιλύεται σωστά κατά το debugging.

## Πλήρης κώδικας πηγής

```csharp
using System;
using System.Collections.Generic;
using Aspose.Cells;

namespace ExcelExportDemo
{
    // Simple POCO that represents an employee record
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Step 1: Load the Excel template that contains Smart Marker tags
            string templatePath = @"YOUR_DIRECTORY\template.xlsx";
            Workbook wb = new Workbook(templatePath);

            // Step 2: Prepare a data source – a list of employee objects
            List<Employee> employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Step 3: Create a SmartMarkerProcessor instance
            SmartMarkerProcessor sp = new SmartMarkerProcessor();

            // Step 4: Apply the employee data to the workbook using the processor
            // The tag &amp;=EmployeeList.Name in the template will be replaced with each employee's name,
            // and &amp;=EmployeeList.Position will be replaced with the corresponding position.
            sp.Process(wb, employeeList);

            // Step 5: Save the populated workbook
            string outputPath = @"YOUR_DIRECTORY\output.xlsx";
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

### Τι κάνει ο κώδικας

| Βήμα | Γιατί είναι σημαντικό | Κύρια γραμμή(-ες) |
|------|-----------------------|-------------------|
| **Load Excel template** | Η επαναχρησιμοποίηση μιας προ‑σχεδιασμένης διάταξης εξοικονομεί χρόνο και εγγυάται συνεπή στυλ. | `Workbook wb = new Workbook(templatePath);` |
| **Prepare data source** | Τα Smart Markers λειτουργούν με οποιαδήποτε συλλογή `IEnumerable`; εδώ χρησιμοποιούμε μια λίστα `Employee`. | `List<Employee> employeeList = …` |
| **Create processor** | `SmartMarkerProcessor` αναλύει το πρότυπο, βρίσκει τις ετικέτες και ενσωματώνει τα δεδομένα. | `SmartMarkerProcessor sp = new SmartMarkerProcessor();` |
| **Process data** | Ο επεξεργαστής αντικαθιστά κάθε ετικέτα Smart Marker με την αντίστοιχη τιμή ιδιότητας. | `sp.Process(wb, employeeList);` |
| **Save workbook** | Το τελικό αρχείο μπορεί να σταλεί στον χρήστη, να αποθηκευτεί σε διακομιστή ή να επισυναφθεί σε email. | `wb.Save(outputPath);` |

Το αποτέλεσμα είναι ένα αρχείο **employee report Excel** όπου κάθε γραμμή περιέχει το όνομα και τη θέση ενός υπαλλήλου, ακριβώς στα σημεία όπου τοποθετήθηκαν οι ετικέτες στο αρχικό πρότυπο.

## Φόρτωση προτύπου Excel

Όταν `load excel template` με `new Workbook(path)`, το Aspose.Cells διαβάζει ολόκληρο το βιβλίο εργασίας—συμπεριλαμβανομένων των στυλ, των τύπων και των placeholders Smart Marker. Αυτή η προσέγγιση είναι προτιμότερη από τη δημιουργία βιβλίου εργασίας από το μηδέν επειδή:

* **Design control** – Οι σχεδιαστές μπορούν να μορφοποιήσουν τις κεφαλίδες, να προσθέσουν λογότυπα εταιρείας και να ορίσουν το πλάτος των στηλών χωρίς να επεμβαίνουν στον κώδικα.
* **Versioning** – Η ενημέρωση του προτύπου δεν απαιτεί επαναμεταγλώττιση της εφαρμογής.
* **Localization** – Μπορείτε να διατηρείτε ξεχωριστά αρχεία προτύπου για διαφορετικές γλώσσες.

Αν προτιμάτε μια καθαρή λύση .NET χωρίς βιβλιοθήκες τρίτων, μπορείτε να χρησιμοποιήσετε **ClosedXML** ή **EPPlus**, αλλά δεν διαθέτουν ενσωματωμένη υποστήριξη Smart Marker, πράγμα που σημαίνει ότι θα πρέπει να γράψετε βρόχους που αντιγράφουν τα δεδομένα κελί‑με‑κελί.

## Αυτοματοποίηση δημιουργίας Excel με Smart Markers

Τα Smart Markers είναι placeholders που μοιάζουν με `&=Collection.Property`. Όταν εκτελείται ο επεξεργαστής:

* Διατρέχει τη συλλογή (`employeeList` στο παράδειγμά μας).
* Για κάθε στοιχείο, γράφει την τιμή της ιδιότητας στο αντίστοιχο κελί.
* Αυτοματοποιεί την επέκταση γραμμών ή στηλών όπως απαιτείται.

Αυτός ο μηχανισμός **αυτοματοποιεί τη δημιουργία Excel** και εξαλείφει τη λογική χειροκίνητης επανάληψης. Το ίδιο μοτίβο λειτουργεί για οποιοδήποτε σχήμα δεδομένων—παραγγελίες, τιμολόγια, λίστες αποθεμάτων κ.λπ.

### Συνηθισμένες παραλλαγές

| Παραλλαγή | Πώς να υλοποιηθεί |
|-----------|-------------------|
| **Πολλαπλές συλλογές** | Προσθέστε περισσότερες λίστες (π.χ., `List<Department>`) και αναφερθείτε σε αυτές με διαφορετικές ετικέτες όπως `&=DepartmentList.Name`. |
| **Φωλιασμένες συλλογές** | Χρησιμοποιήστε σημειογραφία με τελεία: `&=EmployeeList.Projects.ProjectName` όπου το `Projects` είναι μια ιδιότητα συλλογής μέσα στο `Employee`. |
| **Conditional formatting** | Τοποθετήστε έναν κανόνα conditional formatting του Excel στο πρότυπο· ο επεξεργαστής τον διατηρεί για τις παραγόμενες γραμμές. |

## Δημιουργία employee report Excel

Ο όρος **employee report Excel** υποδεικνύει μια τυπική επιχειρηματική περίπτωση χρήσης: ένας διευθυντής θέλει μια εκτυπώσιμη λίστα προσωπικού. Ενσωματώνοντας τις ετικέτες Smart Marker απευθείας στο πρότυπο, λαμβάνετε:

* Μια γραμμή κεφαλίδας με έντονη γραμματοσειρά και χρώμα φόντου.
* Στήλες αυτόματου μεγέθους βάσει των δεδομένων.
* Προαιρετικές γραμμές συνολικού (π.χ., αριθμός υπαλλήλων) που μπορείτε να υπολογίσετε με τυπικούς τύπους του Excel.

Αν χρειάζεται να προσθέσετε μια γραμμή συνολικού, απλώς τοποθετήστε έναν τύπο όπως `=COUNTA(A2:A100)` στο πρότυπο· ο επεξεργαστής δεν θα τον διαταράξει.

## Δημιουργία προτύπου Excel C# – βέλτιστες πρακτικές

Όταν γράφετε κώδικα **generate Excel template C#**, κρατήστε αυτές τις οδηγίες στο μυαλό:

1. **Separate concerns** – Διατηρήστε τη φόρτωση του προτύπου, την προετοιμασία των δεδομένων και την επεξεργασία σε ξεχωριστές μεθόδους. Αυτό κάνει τις μονάδες δοκιμών πιο εύκολες.
2. **Validate input** – Βεβαιωθείτε ότι το αρχείο προτύπου υπάρχει και ότι η συλλογή δεδομένων δεν είναι null πριν καλέσετε το `Process`.
3. **Dispose resources** – Παρόλο που το Aspose.Cells διαχειρίζεται τη μνήμη, τυλίξτε το `Workbook` σε ένα μπλοκ `using` αν εργάζεστε με μεγάλα αρχεία.
4. **Handle exceptions** – Πιάστε (`catch`) το `Exception` γύρω από το `sp.Process` για να εμφανίσετε προβλήματα όπως μη ταιριαστά ονόματα ετικετών.

```csharp
static Workbook LoadTemplate(string path)
{
    if (!File.Exists(path))
        throw new FileNotFoundException($"Template not found: {path}");
    return new Workbook(path);
}
```

| Όνομα | Θέση |

| Jane Smith | Manager |

Όλη η μορφοποίηση από το `template.xlsx`—όπως το χρώμα φόντου της κεφαλίδας, το πλάτος των στηλών και τυχόν εικόνα λογότυπου—παραμένει αμετάβλητη.

## Επίλυση κοινών προβλημάτων

| Συμπτωμα | Πιθανή αιτία | Διόρθωση |
|----------|--------------|----------|
| Δεν εμφανίζονται δεδομένα μετά την επεξεργασία | Οι ετικέτες Smart Marker είναι γραμμένες λανθασμένα ή τοποθετημένες σε συγχωνευμένα κελιά. | Επαληθεύστε ότι οι ετικέτες ακολουθούν ακριβώς τη σύνταξη `&=Collection.Property` και δεν βρίσκονται μέσα σε συγχωνευμένες περιοχές. |
| Το αρχείο εξόδου είναι κενό ή κατεστραμμένο | Το βιβλίο εργασίας αποθηκεύτηκε πριν ολοκληρωθεί η επεξεργασία. | Βεβαιωθείτε ότι το `sp.Process` εκτελείται **πριν** το `wb.Save`. |
| Μεγάλη λίστα υπαλλήλων επιβραδύνει τη δημιουργία | Η χρήση της δωρεάν έκδοσης του Aspose.Cells μπορεί να έχει περιορισμούς απόδοσης. | Αναβαθμίστε στην έκδοση με άδεια ή επεξεργαστείτε τα δεδομένα σε παρτίδες. |
| Η διαδρομή του προτύπου είναι λανθασμένη | Η σχετική διαδρομή επιλύεται σε διαφορετικό φάκελο κατά την εκτέλεση. | Χρησιμοποιήστε `Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "template.xlsx")` ή ορίστε την ιδιότητα `Copy to Output Directory` του αρχείου. |

## Συνοπτική επανάληψη πλήρους παραδείγματος

Παρακάτω βρίσκεται ολόκληρο το πρόγραμμα σε ένα μπλοκ για γρήγορη αντιγραφή‑επικόλληση:

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Load the template
            string templatePath = Path.Combine("YOUR_DIRECTORY", "template.xlsx");
            Workbook wb = new Workbook(templatePath);

            // Prepare data
            var employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Process Smart Markers
            var sp = new SmartMarkerProcessor();
            sp.Process(wb, employeeList);

            // Save the result
            string outputPath = Path.Combine("YOUR_DIRECTORY", "output.xlsx");
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

Η εκτέλεση αυτού του προγράμματος δημιουργεί ένα αρχείο **employee report Excel** που μπορεί να σταλεί μέσω email, να εκτυπωθεί ή να υποστεί περαιτέρω επεξεργασία.
