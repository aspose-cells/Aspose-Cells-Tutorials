# Εισαγωγή προσαρμοσμένων αντικειμένων στο Excel με Aspose.Cells – Οδηγός Java

Αν χρειάζεται να **εισάγετε προσαρμοσμένα αντικείμενα** σε ένα φύλλο εργασίας Excel, αυτός ο οδηγός σας καθοδηγεί βήμα‑βήμα στη διαδικασία χρησιμοποιώντας το Aspose.Cells for Java. Θα δείτε πώς να **εισάγετε δεδομένα στο Excel**, να εφαρμόσετε έντονο στυλ κεφαλίδας και να δημιουργήσετε ένα έτοιμο‑για‑κοινή χρήση αρχείο `.xlsx`.

Η εξαγωγή πινάκων δεδομένων από Java συχνά απαιτεί χειροκίνητες εγγραφές κελιού‑με‑κελί, κάτι που είναι επιρρεπές σε σφάλματα και δύσκολο στη συντήρηση. Εκμεταλλευόμενοι το API `importCustomObjects` αποφεύγετε τον επαναλαμβανόμενο κώδικα, διατηρείτε το μοντέλο δεδομένων σας αμετάβλητο και αποκτάτε ακριβή έλεγχο του στυλ.

Σε αυτό το tutorial θα:

* Δημιουργήσετε μια λίστα Java `Map` αντικειμένων που προσομοιώνει έναν τυπικό πίνακα δεδομένων.
* Δημιουργήσετε ένα επαναχρησιμοποιήσιμο στυλ κεφαλίδας (έντονη γραμματοσειρά) με το Aspose.Cells.
* Εισάγετε τα προσαρμοσμένα αντικείμενα σε ένα φύλλο εργασίας εφαρμόζοντας τον πίνακα στυλ.
* Αποθηκεύσετε το βιβλίο εργασίας στο δίσκο και επαληθεύσετε το αποτέλεσμα.

Η μόνη προαπαιτούμενη προϋπόθεση είναι ένα περιβάλλον ανάπτυξης Java (συνιστάται JDK 8+ ) και η βιβλιοθήκη Aspose.Cells for Java.

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## Βήμα 1: Προετοιμασία των προσαρμοσμένων αντικειμένων για εισαγωγή

Το πρώτο βήμα είναι η δημιουργία μιας συλλογής που αντιπροσωπεύει τις γραμμές που θέλετε να τοποθετήσετε στο Excel. Σε αυτό το παράδειγμα χρησιμοποιούμε ένα `List<Map<String,Object>>` όπου κάθε χάρτης λειτουργεί ως γραμμή με τα ονόματα των στηλών ως κλειδιά.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Γιατί είναι σημαντικό:**  
Το `importCustomObjects` αναμένει έναν πίνακα αντικειμένων. Χρησιμοποιώντας ένα `Map`, διατηρείτε τα ονόματα των στηλών, επιτρέποντας στο Aspose.Cells να τα αντιστοιχίσει αυτόματα στα κελιά. Αυτή η προσέγγιση αντικατοπτρίζει έναν τυπικό `DataTable` σε .NET ή ένα `ResultSet` από JDBC, κάνοντας τον κώδικα επαναχρησιμοποιήσιμο σε πολλά έργα.

---

## Βήμα 2: Ορισμός στυλ κεφαλίδας για εφαρμογή κατά την εισαγωγή

Μια σαφής γραμμή κεφαλίδας βελτιώνει την αναγνωσιμότητα. Το Aspose.Cells σας επιτρέπει να δημιουργήσετε ένα αντικείμενο `Style`, να ορίσετε τη γραμματοσειρά του σε έντονη και να το περάσετε μέσω ενός πίνακα `ImportTableOptions`.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Γιατί είναι σημαντικό:**  
Αν παραλείψετε τον πίνακα στυλ, η κεφαλίδα εμφανίζεται με την προεπιλεγμένη γραμματοσειρά, η οποία μπορεί να μην ξεχωρίζει. Ετοιμάζοντας το στυλ μία φορά, αποφεύγετε επαναλαμβανόμενες κλήσεις για κάθε γραμμή και διατηρείτε τον κώδικα εισαγωγής καθαρό.

---

## Βήμα 3: Εισαγωγή των προσαρμοσμένων αντικειμένων με τον πίνακα στυλ

Τώρα συνδυάζετε τα δεδομένα και το στυλ, και καλείτε το `importCustomObjects`. Η μέθοδος τοποθετεί τα δεδομένα ξεκινώντας από την πάνω‑αριστερή γωνία (γραμμή 0, στήλη 0) και εφαρμόζει αυτόματα το στυλ κεφαλίδας.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Γιατί είναι σημαντικό:**  
Το `importCustomObjects` αναλύει κάθε χάρτη, δημιουργεί στήλες βάσει των κλειδιών (`Name`, `Score`) και γράφει τις τιμές στα αντίστοιχα κελιά. Το αντικείμενο `ImportTableOptions` λέει στο Aspose.Cells να χρησιμοποιήσει το `styleArray` για την πρώτη γραμμή, δίνοντάς σας μια έντονη κεφαλίδα χωρίς επιπλέον κώδικα.

---

## Βήμα 4: Αποθήκευση του βιβλίου εργασίας και επαλήθευση του αποτελέσματος

Τέλος, γράψτε το βιβλίο εργασίας σε αρχείο. Το παραγόμενο αρχείο Excel περιέχει μια μορφοποιημένη γραμμή κεφαλίδας ακολουθούμενη από τις γραμμές δεδομένων.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Αναμενόμενο αποτέλεσμα:**  

| **Name** | **Score** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

Τα κελιά της κεφαλίδας (`Name`, `Score`) εμφανίζονται με έντονη γραμματοσειρά, όπως ορίστηκε στο Βήμα 2.

## Συνηθισμένες παραλλαγές και ειδικές περιπτώσεις

| Κατάσταση | Προτεινόμενη προσαρμογή |
|-----------|------------------------|
| **Διαφορετική σειρά στηλών** | Βεβαιωθείτε ότι τα κλειδιά του `Map` εισάγονται με τη ζητούμενη σειρά, ή χρησιμοποιήστε ένα προσαρμοσμένο POJO με επισημασμένα πεδία και έναν πίνακα `PropertyDescriptor`. |
| **Μεγάλα σύνολα δεδομένων (>10 000 γραμμές)** | Αυξήστε το `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` για να αποφύγετε `OutOfMemoryError`. |
| **Προσαρμοσμένες μορφές αριθμών** | Προσθέστε ένα δεύτερο `Style` στο `styleArray` για τις γραμμές δεδομένων, π.χ., ορίστε `NumberFormat` σε `"0"` για ακέραιους βαθμούς. |
| **Πολλαπλά φύλλα εργασίας** | Καλέστε `importCustomObjects` σε κάθε στοχευόμενο φύλλο, προσαρμόζοντας τη γραμμή/στήλη εκκίνησης όπως απαιτείται. |
| **Κείμενο κεφαλίδας ειδικό για τοπική ρύθμιση** | Συμπληρώστε τη γραμμή κεφαλίδας χειροκίνητα πριν την εισαγωγή, έπειτα εφαρμόστε το στυλ σε όλο το εύρος με `Cells.applyStyle`. |

## Pro tips για αξιόπιστη εξαγωγή Java σε Excel

* **Επαναχρησιμοποίηση του προσωρινού βιβλίου εργασίας** – Η δημιουργία νέου `Workbook` για κάθε στυλ προσθέτει επιβάρυνση. Διατηρήστε μια μόνο παρουσία εάν χρειάζεστε πολλαπλά στυλ.  
* **Επικύρωση δεδομένων πριν την εισαγωγή** – Οι τιμές `null` σε έναν χάρτη γίνονται κενά κελιά· μπορείτε να τις αντικαταστήσετε με προεπιλογές προεπεξεργάζοντας τη λίστα.  
* **Κλείσιμο πόρων** – Παρόλο που το Aspose.Cells διαχειρίζεται τη μνήμη εσωτερικά, η ρητή κλήση `workbook.dispose()` μετά την αποθήκευση απελευθερώνει άμεσα τους εγγενείς πόρους.  
* **Ορίστε `Workbook.setForceFullCalculation(true)`** εάν το βιβλίο εργασίας περιέχει τύπους που πρέπει να υπολογιστούν πριν την αποθήκευση.
