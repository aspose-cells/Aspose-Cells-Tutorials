# Πώς να δημιουργήσετε βιβλίο εργασίας Excel σε Java με δεδομένα JSON

Αν χρειάζεστε **create Excel workbook java** οι προγραμματιστές συχνά αντιμετωπίζουν την πρόκληση της φόρτωσης δεδομένων JSON σε ένα φύλλο εργασίας. Αυτός ο οδηγός σας δείχνει πώς να **populate Excel from JSON**, συμπεριλαμβανομένου του πώς να **convert JSON array excel** και **populate workbook from json** με καθαρό, επαναλαμβανόμενο τρόπο.

Η εργασία με JSON είναι συνηθισμένη όταν οι υπηρεσίες εκθέτουν δεδομένα μέσω REST APIs, και το Excel παραμένει η προτιμώμενη μορφή για αναφορές και ανάλυση. Στο τέλος αυτού του tutorial θα έχετε ένα εκτελέσιμο πρόγραμμα Java που:

* δημιουργεί ένα νέο βιβλίο εργασίας Excel,
* διαβάζει έναν πίνακα JSON (ή οποιαδήποτε δομή JSON) και γράφει τις τιμές του σε κελιά,
* αποθηκεύει το αρχείο στο δίσκο έτοιμο για επεξεργασία downstream.

Δεν απαιτούνται εξωτερικά εργαλεία πέρα από τη βιβλιοθήκη Aspose.Cells for Java, η οποία παρέχει τον `SmartMarkerProcessor` που χρησιμοποιείται στο δείγμα κώδικα.

## Προαπαιτούμενα

Πριν ξεκινήσετε, βεβαιωθείτε ότι έχετε:

| Προαπαιτούμενο | Αιτία |
|----------------|-------|
| Java Development Kit (JDK) ≥ 8 | Απαιτείται για τη μεταγλώττιση και εκτέλεση του παραδείγματος |
| Maven ή Gradle (προαιρετικό) | Απλοποιεί τη διαχείριση εξαρτήσεων |
| Aspose.Cells for Java (v23.10 ή νεότερο) | Παρέχει τις κλάσεις `Workbook` και `SmartMarkerProcessor` |
| Βασικές γνώσεις JSON και Java I/O | Σας βοηθά να κατανοήσετε τη ροή των δεδομένων |

Αν προτιμάτε να μην χρησιμοποιήσετε εργαλείο κατασκευής, μπορείτε να κατεβάσετε το JAR του Aspose.Cells από την [Aspose website](https://products.aspose.com/cells/java/) και να το προσθέσετε χειροκίνητα στο classpath του έργου σας.

## Βήμα 1: Ρύθμιση του έργου και προσθήκη της εξάρτησης Aspose.Cells

### Χρήστες Maven

Προσθέστε την ακόλουθη εξάρτηση στο `pom.xml` σας:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Χρήστες Gradle

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

Αν δεν χρησιμοποιείτε εργαλείο κατασκευής, τοποθετήστε το ληφθέν JAR στον φάκελο `libs/` και συμπεριλάβτε το στο classpath κατά τη μεταγλώττιση:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## Βήμα 2: Δημιουργία νέου βιβλίου εργασίας και διαμόρφωση του SmartMarker processor

Ο `SmartMarkerProcessor` απλοποιεί τη χαρτογράφηση των τιμών JSON σε κελιά Excel. Καλώντας `setArrayAsSingle(true)` λέμε στον επεξεργαστή να αντιμετωπίζει έναν ολόκληρο πίνακα JSON ως μία ενιαία τιμή, κάτι που είναι χρήσιμο όταν θέλετε κάθε στοιχείο να καταλαμβάνει το δικό του κελί σε μια σειρά.

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**Γιατί αυτό είναι σημαντικό:**  
Η δημιουργία του βιβλίου εργασίας εκ των προτέρων σας παρέχει έναν καθαρό καμβά. Η ρύθμιση `setArrayAsSingle(true)` αποτρέπει τον επεξεργαστή από το να «συμπιέσει» τον πίνακα σε μία συμβολοσειρά (π.χ., `["A","B","C"]`) και επιτρέπει τον χειροκίνητο έλεγχο της διάταξης.

## Βήμα 3: Ορισμός των δεδομένων JSON που θέλετε να εισάγετε

Για αυτό το tutorial χρησιμοποιούμε έναν απλό πίνακα JSON, αλλά η ίδια προσέγγιση λειτουργεί με αντικείμενα, ενσωματωμένους πίνακες ή πολύπλοκες δομές.

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**Συμβουλή:** Αν το JSON προέρχεται από αρχείο ή από ένα REST endpoint, αντικαταστήστε τη λεκτική συμβολοσειρά με ένα `String` που διαβάζεται από την πηγή, π.χ., `Files.readString(Paths.get("data.json"))`.

## Βήμα 4: Επεξεργασία του βιβλίου εργασίας με τα δεδομένα JSON

Τώρα αφήνουμε τον `SmartMarkerProcessor` να χαρτογραφήσει τον πίνακα JSON στο πρώτο φύλλο εργασίας. Η προεπιλεγμένη συμπεριφορά γράφει κάθε στοιχείο σε διαδοχικά κελιά ξεκινώντας από το `A1`.

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

Στο παρασκήνιο, το Aspose.Cells αναλύει το JSON, δημιουργεί έναν προσωρινό πίνακα δεδομένων και γράφει τις τιμές στο φύλλο εργασίας. Επειδή ορίσαμε `ArrayAsSingle` σε `true`, τα στοιχεία του πίνακα τοποθετούνται οριζόντια στην πρώτη σειρά.

## Βήμα 5: Αποθήκευση του βιβλίου εργασίας σε αρχείο

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

Όταν εκτελέσετε το πρόγραμμα, θα δείτε ένα αρχείο με όνομα **CreatedFromJson.xlsx** στον τρέχοντα φάκελο εργασίας σας. Ανοίγοντάς το με το Excel (ή οποιονδήποτε συμβατό προβολέα) θα εμφανιστεί:

| A | B | C |
|---|---|---|
| A | B | C | *(τιμές εμφανίζονται στα κελιά A1, B1, C1)*

## Βήμα 6: Διαχείριση πιο σύνθετων δομών JSON (προαιρετικό)

### 6.1 Συμπλήρωση βιβλίου εργασίας από αντικείμενο JSON

Αν το JSON σας είναι ένα αντικείμενο αντί για πίνακα, μπορείτε ακόμη να χρησιμοποιήσετε τον `SmartMarkerProcessor`. Για παράδειγμα:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

Ο επεξεργαστής θα δημιουργήσει ονομαστικές περιοχές (`title`, `month`, `values`) που μπορείτε να αναφέρετε στο πρότυπο Excel σας χρησιμοποιώντας Smart Markers όπως `&=title` και `&=values`.

### 6.2 Μετατροπή ενσωματωμένου πίνακα JSON σε κατακόρυφη λίστα

Μερικές φορές χρειάζεται ο πίνακας να γεμίσει μια στήλη αντί για μια σειρά. Ορίστε το αρχικό κελί χειροκίνητα πριν την επεξεργασία:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

Τώρα οι τιμές **A**, **B**, **C** εμφανίζονται στα κελιά A2, A3, A4 αντίστοιχα.

## Συνηθισμένα προβλήματα και πώς να τα αποφύγετε

| Πρόβλημα | Αιτία | Διόρθωση |
|----------|-------|----------|
| **Array written as a single string** | `setArrayAsSingle(false)` (default) | Call `processor.setArrayAsSingle(true)` |
| **File not found when saving** | Μη έγκυρη διαδρομή ή έλλειψη δικαιωμάτων εγγραφής | Χρησιμοποιήστε απόλυτη διαδρομή ή βεβαιωθείτε ότι ο φάκελος υπάρχει |
| **JSON parsing error** | Κακοδιατυπωμένη συμβολοσειρά JSON | Επικυρώστε το JSON με εργαλείο ή χρησιμοποιήστε βιβλιοθήκη όπως το Jackson για τη δημιουργία της συμβολοσειράς |
| **Cells overwritten unintentionally** | Επεξεργασία του ίδιου φύλλου εργασίας πολλές φορές χωρίς επαναφορά του αρχικού κελιού | Call `processor.setStartCell("A1")` before each `process` call |

## Pro tip: επαναχρησιμοποίηση του βιβλίου εργασίας ως πρότυπο

Αντί να ξεκινάτε από ένα κενό βιβλίο εργασίας κάθε φορά, μπορείτε να φορτώσετε ένα προ‑σχεδιασμένο πρότυπο που περιέχει ήδη κεφαλίδες, τύπους ή στυλ:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

Αυτή η προσέγγιση συνδυάζει την οπτική πολυτέλεια ενός χειροποίητου αρχείου Excel με την αυτοματοποίηση του **populate workbook from json**.
