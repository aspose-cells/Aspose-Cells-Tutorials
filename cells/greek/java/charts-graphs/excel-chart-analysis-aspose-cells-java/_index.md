# Πώς να δημιουργήσετε αναφορά γραφήματος Excel με Aspose.Cells για Java

## Εισαγωγή

Αν χρειάζεστε να **create excel chart report** αυτόματα από μια εφαρμογή Java, το Aspose.Cells for Java σας παρέχει ένα πλήρες API που λειτουργεί χωρίς το Microsoft Office. Μπορείτε να φορτώσετε οποιοδήποτε βιβλίο εργασίας, να διαβάσετε τα γραφήματά του και να εξάγετε τα δεδομένα των σειρών για περαιτέρω επεξεργασία ή οπτικοποίηση. Αυτός ο οδηγός σας καθοδηγεί μέσα από ολόκληρη τη ροή εργασίας — ρύθμιση, φόρτωση βιβλίου εργασίας, πρόσβαση σε φύλλα εργασίας και γραφήματα, και επανάληψη μέσω σημείων σειράς — ώστε να μπορείτε να δημιουργήσετε αξιόπιστες pipelines αναφοράς.

## Γρήγορες απαντήσεις
- **What library handles Excel charts in Java?** Aspose.Cells for Java.  
- **Can I work without Microsoft Office installed?** **Ναι**, το API είναι εντελώς ανεξάρτητο.  
- **Which Java version is required?** JDK 8 or higher.  
- **How many chart types are supported?** **Πάνω από 50** native chart types.  
- **Is a license mandatory for production?** **Μια έγκυρη άδεια** αφαιρεί τα όρια αξιολόγησης.

## Τι είναι το create excel chart report;

`create excel chart report` αναφέρεται στη προγραμματιστική δημιουργία ενός πλήρους εγγράφου ανάλυσης που εξάγει δεδομένα γραφήματος, υπολογίζει μετρικές και προαιρετικά ενσωματώνει τα αποτελέσματα πίσω σε αρχείο Excel ή σε άλλη μορφή αναφοράς. Αυτοματοποιώντας αυτή τη διαδικασία μπορείτε να παράγετε συνεπείς, επαναλαμβανόμενες αναφορές που ενσωματώνονται σε downstream συστήματα όπως πίνακες ελέγχου BI ή αποθήκες δεδομένων.

## Γιατί να δημιουργήσετε create excel chart report με Aspose.Cells;

Το Aspose.Cells επεξεργάζεται βιβλία εργασίας έως **200 MB** σε μέγεθος, διατηρώντας τη χρήση μνήμης κάτω από **100 MB** μέσω ροής δεδομένων κατά απαίτηση. Υποστηρίζει **50+ τύπους γραφημάτων**, μπορεί να αποδίδει γραφήματα σε PNG/JPEG και εκτελεί υπολογισμούς 3× πιο γρήγορα από πολλές ανοιχτές εναλλακτικές. Αυτά τα ποσοτικοποιημένα οφέλη το καθιστούν την προτιμώμενη επιλογή για αναφορές επιχειρησιακού επιπέδου.

## Πώς να φορτώσετε και να αποκτήσετε πρόσβαση σε ένα βιβλίο εργασίας Excel;

Φορτώστε το αρχείο βιβλίου εργασίας στη μνήμη, ώστε να μπορείτε να ερωτήσετε τη δομή του, τα φύλλα εργασίας και τα γραφήματα. Η φόρτωση γίνεται δημιουργώντας μια νέα παρουσία `Workbook` και περνώντας τη διαδρομή του αρχείου. Αυτή η μοναδική γραμμή διαβάζει ολόκληρη τη δομή του αρχείου χωρίς να εκκινήσει το Excel και επικυρώνει τη μορφή του αρχείου πριν από οποιαδήποτε περαιτέρω επεξεργασία.

Το αντικείμενο `Workbook` εκθέτει επίσης επιλογές για φόρτωση μόνο συγκεκριμένων φύλλων εργασίας, κάτι που μπορεί να μειώσει την κατανάλωση μνήμης για μεγάλα αρχεία.

```java
Workbook workbook = new Workbook("C:/Data/PieBars.xlsx");
```  

## Πώς να αποκτήσετε πρόσβαση σε φύλλο εργασίας και γράφημα;

Μόλις φορτωθεί το βιβλίο εργασίας, ανακτήστε το στοχευόμενο φύλλο εργασίας και στη συνέχεια το γράφημα που θέλετε να αναλύσετε. Λαμβάνετε το πρώτο φύλλο εργασίας μέσω `workbook.getWorksheets().get(0)`. Από αυτό το φύλλο, καλέστε `getCharts().get(0)` για να πάρετε το πρώτο αντικείμενο γραφήματος.

Η κλάση `Worksheet` αντιπροσωπεύει ένα μοναδικό φύλλο μέσα στο βιβλίο εργασίας, παρέχοντας πρόσβαση σε γραμμές, στήλες και ενσωματωμένα αντικείμενα όπως γραφήματα. Η κλάση `Chart` περιλαμβάνει όλα τα δεδομένα που αφορούν το γράφημα, συμπεριλαμβανομένων των σειρών, αξόνων και επιλογών μορφοποίησης.  

```java

Chart chart = sheet.getCharts().get(0);
```  

## Πώς να επαναλάβετε τις σειρές γραφήματος και τα σημεία δεδομένων;

Οι σειρές γραφήματος περιέχουν τις πραγματικές σειρές δεδομένων που απεικονίζονται στο γράφημα. Η επανάληψη σε αυτές σας επιτρέπει να εξάγετε τις τιμές X και Y για προσαρμοσμένους υπολογισμούς. Ξεκινάτε καλώντας `chart.getNSeries().get(0)` για να πάρετε την πρώτη σειρά, στη συνέχεια επαναλαμβάνετε τα σημεία δεδομένων της με έναν βρόχο `for`, ελέγχοντας το `YValue` κάθε σημείου και αν ανήκει σε δευτερεύον άξονα.

Η κλάση `ChartSeries` ομαδοποιεί σχετιζόμενα σημεία, και κάθε `ChartPoint` σας δίνει άμεση πρόσβαση στις αριθμητικές τιμές που καθορίζουν την οπτική αναπαράσταση. Επαναλαμβάνοντας τα αντικείμενα `ChartPoint` μπορείτε να δημιουργήσετε προσαρμοσμένα σύνολα, να εξάγετε δεδομένα σε άλλες μορφές ή να τροποποιήσετε τις σειρές προγραμματιστικά.  

```java
ChartSeries series = chart.getNSeries().get(0);
for (int i = 0; i < series.getPoints().size(); i++) {
    ChartPoint point = series.getPoints().get(i);
    if (point.getYValue() == null) continue;
    boolean isSecondary = point.getIsSecondaryValue();
    // Process point as needed
}
```

## Κοινά προβλήματα και συμβουλές αντιμετώπισης

- **File not found** – ελέγξτε ξανά την απόλυτη ή σχετική διαδρομή που περνάτε στο `Workbook`. Χρησιμοποιήστε `Paths.get(...)` για διαδρομές ανεξάρτητες από την πλατφόρμα.  
- **Null values** – πάντα επαληθεύετε το `point.getYValue()` πριν το χρησιμοποιήσετε· ελλιπείς τιμές διαφορετικά θα προκαλέσουν `NullPointerException`.  
- **License issues** – εάν δείτε υδατογράφημα δοκιμής ή λάβετε εξαίρεση άδειας, βεβαιωθείτε ότι το αρχείο άδειας φορτώνεται σωστά με `License license = new License(); license.setLicense("Aspose.Cells.lic");`.

## Παραμέτρους απόδοσης (H2)

### Βελτιστοποίηση απόδοσης

- **Selective loading** – χρησιμοποιήστε κατασκευαστές `Workbook` που δέχονται `LoadOptions` για να φορτώσετε μόνο τα απαιτούμενα φύλλα εργασίας, μειώνοντας το αποτύπωμα μνήμης για μεγάλα αρχεία.  
- **Streaming** – το Aspose.Cells μπορεί να μεταδίδει μεγάλα φύλλα εργασίας, επιτρέποντάς σας να εργάζεστε με αρχεία άνω των 500 MB χωρίς να εξαντλείται η μνήμη heap.

### Καλές πρακτικές

- Αποδεσμεύστε τα αντικείμενα `Workbook` μετά τη χρήση (`workbook.dispose()`) για να ελευθερώσετε τους εγγενείς πόρους.  
- Εκμεταλλευτείτε τις ενσωματωμένες μηχανές υπολογισμού (`workbook.calculateFormula()`) αντί για χειροκίνητους βρόχους για αξιολόγηση τύπων.
