# Πώς να αλλάξετε την κατεύθυνση των σημείων του διαγράμματος σε Java χρησιμοποιώντας το Aspose.Cells

## Εισαγωγή

Η αλλαγή της κατεύθυνσης των σημείων του διαγράμματος είναι ένας συνηθισμένος τρόπος βελτίωσης της αναγνωσιμότητας των διαγραμμάτων Excel, ειδικά όταν αντιμετωπίζετε μακριές ονομασίες κατηγοριών ή πυκνά σύνολα δεδομένων. Σε αυτόν τον οδηγό θα μάθετε **πώς να αλλάξετε την κατεύθυνση των σημείων του διαγράμματος** με το Aspose.Cells για Java, από την εγκατάσταση της βιβλιοθήκης μέχρι την αποθήκευση του τελικού workbook. Θα καλύψουμε επίσης γιατί η σωστή περιστροφή των ετικετών είναι σημαντική για οικονομικές αναφορές, επιστημονικές απεικονίσεις και επιχειρηματικούς πίνακες ελέγχου.

## Σύντομες απαντήσεις
- **Ποια βιβλιοθήκη διαχειρίζεται την περιστροφή ετικετών διαγράμματος;** Aspose.Cells for Java.
- **Ποιο Maven artifact προσθέτει τη λειτουργικότητα;** `com.aspose:aspose-cells`.
- **Μπορώ να ορίσω τη γωνία της ετικέτας κατακόρυφα;** Ναι, χρησιμοποιήστε `ChartTextDirectionType.VERTICAL`.
- **Χρειάζομαι άδεια για χρήση σε παραγωγή;** Απαιτείται μόνιμη άδεια· μια προσωρινή άδεια λειτουργεί για αξιολόγηση.
- **Είναι το API συμβατό με Java 8 και νεότερες εκδόσεις;** Ναι, υποστηρίζει Java 8‑21.

## Τι είναι η αλλαγή της κατεύθυνσης των σημείων του διαγράμματος;
**Αλλαγή της κατεύθυνσης των σημείων του διαγράμματος** αναφέρεται στην προσαρμογή του προσανατολισμού των ετικετών του άξονα κατηγορίας (π.χ. οριζόντια, κάθετη ή περιστραμμένη) ώστε να ταιριάζουν καλύτερα στο χώρο του διαγράμματος. Η λειτουργία αυτή εκτελείται μέσω της μεθόδου `setTickLabelDirection` του αντικειμένου `ChartAxis` στο Aspose.Cells.

## Γιατί να χρησιμοποιήσετε το Aspose.Cells για Java για την περιστροφή των ετικετών σημείων;
Το Aspose.Cells επεξεργάζεται **πάνω από 150 μορφές αρχείων**, μπορεί να διαχειριστεί workbooks με **500+ φύλλα** χωρίς να φορτώνει ολόκληρο το αρχείο στη μνήμη, και εκτελεί περιστροφές ετικετών σε **λιγότερο από 0,2 δευτερόλεπτα** για τυπικά μεγέθη διαγραμμάτων. Αυτές οι ποσοτικοποιημένες δυνατότητες το καθιστούν αξιόπιστη επιλογή για επιχειρησιακό επίπεδο αυτοματοποίησης Excel.

## Προαπαιτούμενα
- **Aspose.Cells for Java** έκδοση 25.3 ή νεότερη.
- Ένα Java 8+ development kit και το προτιμώμενο IDE σας (IntelliJ IDEA, Eclipse, κ.λπ.).
- Maven ή Gradle για διαχείριση εξαρτήσεων.
- Μια προσωρινή ή μόνιμη άδεια Aspose.Cells (δείτε την ενότητα άδειας παρακάτω).

Για να ξεκινήσετε, προσθέστε την εξάρτηση Aspose.Cells στο αρχείο κατασκευής σας.

```xml

    <artifactId>aspose-cells</artifactId>
    <version>25.3</version>
    <classifier>jdk17</classifier>
</dependency>
```


## Πώς να αλλάξετε την κατεύθυνση των σημείων του διαγράμματος σε Java;
Για να τροποποιήσετε τον προσανατολισμό των ετικετών σημείων, πρέπει να φορτώσετε το στοχευόμενο workbook, να ανακτήσετε το συγκεκριμένο διάγραμμα, να έχετε πρόσβαση στον άξονα κατηγορίας και να καλέσετε τη μέθοδο `setTickLabelDirection` με το επιθυμητό `ChartTextDirectionType`. Αυτή η ακολουθία μπορεί να εκτελεστεί σε λίγες γραμμές κώδικα Java, καθιστώντας το εύκολο να ενσωματωθεί σε υπάρχουσες ροές αυτοματοποίησης.

1. Φορτώστε το workbook που περιέχει το διάγραμμα που θέλετε να τροποποιήσετε.  
2. Ανακτήστε το φύλλο εργασίας και το αντικείμενο διαγράμματος με βάση το δείκτη του.  
3. Πρόσβαση στον άξονα κατηγορίας (`getCategoryAxis()`) και κλήση της `setTickLabelDirection` με το επιθυμητό `ChartTextDirectionType`.  
4. Αποθηκεύστε το workbook σε νέο αρχείο.

## Οδηγός υλοποίησης

### Φόρτωση του workbook και του διαγράμματος
Η κλάση `Workbook` αντιπροσωπεύει ολόκληρο το αρχείο Excel στη μνήμη. Η κλάση `Worksheet` παρέχει πρόσβαση σε μεμονωμένα φύλλα, και η κλάση `Chart` αντιπροσωπεύει ένα συγκεκριμένο διάγραμμα.

```java
Workbook workbook = new Workbook("input.xlsx");               // 1️⃣ Load file
Worksheet sheet = workbook.getWorksheets().get(0);            // 2️⃣ First sheet
Chart chart = sheet.getCharts().get(0);                       // 3️⃣ First chart on the sheet
```

### Αλλαγή κατεύθυνσης ετικέτας σημείου
`ChartAxis` ελέγχει όλες τις ιδιότητες που σχετίζονται με τους άξονες. `ChartTextDirectionType` είναι μια απαρίθμηση που ορίζει τον προσανατολισμό.

```java
ChartAxis categoryAxis = chart.getCategoryAxis();            // Access category axis
categoryAxis.setTickLabelDirection(ChartTextDirectionType.HORIZONTAL); // 4️⃣ Set direction
```

- `ChartTextDirectionType.HORIZONTAL` → ετικέτες διαβάζονται από αριστερά προς δεξιά.  
- `ChartTextDirectionType.VERTICAL` → ετικέτες διαβάζονται από πάνω προς τα κάτω.  
- `ChartTextDirectionType.ROTATED_45` → ετικέτες περιστραμμένες 45° (διαθέσιμες σε νεότερες εκδόσεις).

### Αποθήκευση του workbook
Μετά την προσαρμογή του άξονα, αποθηκεύστε τις αλλαγές:

```java
workbook.save("output.xlsx", SaveFormat.XLSX);
```

## Συνηθισμένα προβλήματα και λύσεις
- **Λάθος δείκτης διαγράμματος** – Επαληθεύστε ότι το διάγραμμα υπάρχει ελέγχοντας το `sheet.getCharts().getCount()`.  
- **Άδεια δεν εφαρμόστηκε** – Εάν βλέπετε υδατογράφημα, βεβαιωθείτε ότι το αρχείο άδειας φορτώνεται πριν από οποιαδήποτε λειτουργία workbook.  
- **Μη υποστηριζόμενη κατεύθυνση** – Ορισμένοι παλαιότεροι τύποι διαγραμμάτων υποστηρίζουν μόνο οριζόντιες ετικέτες· αναβαθμίστε στην πιο πρόσφατη έκδοση του Aspose.Cells για πρόσβαση σε όλες τις τιμές της απαρίθμησης.

## Πρακτικές εφαρμογές
Η αλλαγή της κατεύθυνσης των ετικετών σημείων ξεχωρίζει σε σενάρια όπου ο χώρος είναι περιορισμένος:

1. **Οικονομικά χρονοδιαγράμματα** – Οι οριζόντιες ετικέτες διατηρούν τις ημερομηνίες αναγνώσιμες σε πυκνά διαγράμματα χρονοσειρών.  
2. **Επιστημονικά διαγράμματα** – Οι κάθετες ετικέτες ελευθερώνουν οριζόντιο χώρο για μακρύτερα ονόματα μεταβλητών.  
3. **Επιχειρηματικά dashboards** – Οι περιστρεφόμενες ετικέτες αποτρέπουν την επικάλυψη κειμένου σε διαγράμματα ράβδων πολλαπλών κατηγοριών.

## Σκέψεις για την απόδοση
Κατά την επεξεργασία workbook με **εκατοντάδες διαγράμματα**, ακολουθήστε τις καλύτερες πρακτικές:

- Φορτώστε το workbook μία φορά και επαναχρησιμοποιήστε την ίδια παρουσία `Workbook`.  
- Εφαρμόστε τις αλλαγές ετικετών σε βρόχο, στη συνέχεια καλέστε `workbook.save` μία φορά για ελαχιστοποίηση I/O.  
- Χρησιμοποιήστε τη σημαία `setCalculateFormula` μόνο όταν χρειάζεται να επανυπολογίσετε τύπους μετά τις τροποποιήσεις.

**Ε: Λειτουργεί το API με αρχεία Excel προστατευμένα με κωδικό;**  
Α: Ναι. Φορτώστε το workbook με `new Workbook("file.xlsx", new LoadOptions(LoadFormat.XLSX) {{ setPassword("pwd"); }})`.
