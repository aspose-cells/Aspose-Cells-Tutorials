# Δημιουργία φύλλων λεπτομερειών σε Java με τα smart markers του Aspose.Cells

Αν χρειάζεστε **δημιουργία φύλλων λεπτομερειών** σε μια εφαρμογή Java, αυτό το tutorial σας δείχνει πώς να το κάνετε με τα smart markers του Aspose.Cells. Θα δείτε ένα πλήρες, εκτελέσιμο παράδειγμα που **java create worksheets**, αντλεί το **sheet name from field** και **process data source** σε λίγες μόνο γραμμές κώδικα.

Ο οδηγός καλύπτει τα πάντα, από τη ρύθμιση του έργου μέχρι την αποθήκευση του τελικού βιβλίου εργασίας, ώστε να μπορείτε να αντιγράψετε‑επικολλήσετε τη λύση στο δικό σας έργο και να την προσαρμόσετε αμέσως. Δεν απαιτείται εξωτερική τεκμηρίωση — όλα όσα χρειάζεστε είναι εδώ.

## Τι θα μάθετε

* Πώς να **use smart markers** για την αντιγραφή ενός φύλλου προτύπου για κάθε γραμμή σε ένα κύριο σύνολο δεδομένων.  
* Πώς να ορίσετε το όνομα κάθε νέου φύλλου δυναμικά με βάση την τιμή ενός πεδίου (π.χ., `Order_123`).  
* Πώς να τροφοδοτήσετε μια συλλογή Java ως **process data source** για τη μηχανή smart marker.  
* Συμβουλές για τη διαχείριση ειδικών περιπτώσεων όπως κενά δεδομένα, ειδικοί χαρακτήρες στα ονόματα φύλλων και ζητήματα απόδοσης για μεγάλα σύνολα δεδομένων.

### Προαπαιτούμενα

| Απαίτηση | Αιτία |
|-------------|--------|
| Java 8 or higher | Aspose.Cells for Java supports Java 8+. |
| Maven or Gradle build system | Simplifies adding the Aspose.Cells dependency. |
| Basic knowledge of Java collections | Needed to build the data source for the smart markers. |
| A template Excel file (`Template.xlsx`) with a placeholder smart marker in cell **A1** | The template drives the detail‑sheet generation. |

> **Pro tip:** Κρατήστε το πρότυπο βιβλίο εργασίας στο φάκελο `resources` του έργου ώστε να συσκευάζεται με το JAR σας.

## Βήμα 1: Προσθέστε το Aspose.Cells στο έργο σας (java create worksheets)

Αν χρησιμοποιείτε **Maven**, προσθέστε την παρακάτω εξάρτηση στο `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

Για **Gradle**, τοποθετήστε αυτή τη γραμμή στο `build.gradle`:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

Αυτές οι γραμμές καθιστούν τα APIs **java create worksheets** διαθέσιμα κατά τη μεταγλώττιση.

## Βήμα 2: Φορτώστε το πρότυπο βιβλίο εργασίας

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*Γιατί είναι σημαντικό:* Το αντικείμενο `Workbook` είναι το σημείο εισόδου για όλες τις λειτουργίες του Excel. Η φόρτωση του προτύπου εξασφαλίζει ότι ξεκινάτε με τη σωστή διάταξη και τυχόν προ‑ορισμένη μορφοποίηση.

## Βήμα 3: Εισαγάγετε ένα smart marker που δημιουργεί νέο φύλλο ανά γραμμή κύριου συνόλου (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

Η σύνταξη `${Orders:DetailSheetNewName=Order_${OrderId}}` είναι ο πυρήνας του **use smart markers**. Κάνει τρία πράγματα:

1. Διασχίζει τη συλλογή `Orders`.  
2. Δημιουργεί ένα **new worksheet** για κάθε στοιχείο.  
3. Ορίζει το **sheet name from field** `OrderId` (με πρόθεμα `Order_`).

## Βήμα 4: Προετοιμάστε την πηγή δεδομένων (process data source)

Παρακάτω υπάρχει ένα ελάχιστο παράδειγμα που χρησιμοποιεί ένα `List<Map<String, Object>>`. Αντικαταστήστε το με την πραγματική πηγή δεδομένων σας — γραμμές βάσης δεδομένων, αποσυσκευασία JSON κ.λπ.

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*Γιατί είναι σημαντικό:* Το βήμα **process data source** συνδέει τη συλλογή Java σας με τη μηχανή smart marker. Το κλειδί (`"Orders"`) πρέπει να ταιριάζει ακριβώς με το όνομα του smart marker.

## Βήμα 5: Επεξεργαστείτε τα smart markers (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

Όταν εκτελείται το `process`, το Aspose.Cells διαβάζει τη συλλογή `Orders`, κλωνοποιεί το πρότυπο φύλλο εργασίας για κάθε καταχώρηση και μετονομάζει κάθε φύλλο σύμφωνα με το πεδίο `OrderId`. Αυτό είναι η καρδιά της χρήσης του **process data source**.

## Βήμα 6: Αποθηκεύστε το βιβλίο εργασίας με τα διπλασιασμένα φύλλα λεπτομερειών

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

Μετά την εκτέλεση, θα βρείτε το `DuplicatedDetailSheets.xlsx` που περιέχει:

* `Sheet1` – το αρχικό πρότυπο (αμετάβλητο).  
* `Order_101` – φύλλο λεπτομερειών για την πρώτη παραγγελία.  
* `Order_102` – φύλλο λεπτομερειών για τη δεύτερη παραγγελία.

### Αναμενόμενη έξοδος (απόσπασμα)

| Όνομα φύλλου | A1 (smart marker) | Περιεχόμενο |
|--------------|-------------------|------------|
| Order_101    | `${Orders:...}`   | Συμπληρώνεται με δεδομένα από `order1` |
| Order_102    | `${Orders:...}`   | Συμπληρώνεται με δεδομένα από `order2` |

Ανοίξτε το αρχείο στο Excel για να επαληθεύσετε ότι κάθε φύλλο έχει το σωστό όνομα και περιέχει τις σειρές δεδομένων.

## Διαχείριση κοινών παραλλαγών και ειδικών περιπτώσεων

### Κενή πηγή δεδομένων

Αν το `orders` είναι κενό, ο επεξεργαστής smart marker δεν δημιουργεί **νέα worksheets**. Για να αποφύγετε ένα κενό βιβλίο εργασίας, προσθέστε έναν έλεγχο:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### Ειδικοί χαρακτήρες στα ονόματα φύλλων

Τα ονόματα φύλλων του Excel δεν μπορούν να περιέχουν `\ / ? * [ ] :`. Καθαρίστε το πεδίο πριν το χρησιμοποιήσετε:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### Μεγάλα σύνολα δεδομένων

Για χιλιάδες γραμμές, σκεφτείτε να αυξήσετε τη μνήμη heap της JVM (`-Xmx2g`) και να καλέσετε το `workbook.calculateFormula()` μόνο μετά τη δημιουργία όλων των φύλλων για να βελτιώσετε την απόδοση.
