# Πώς να δημιουργήσετε φύλλα εργασίας σε Java χρησιμοποιώντας SmartMarkerProcessor

Αν χρειάζεστε **πώς να δημιουργήσετε φύλλα εργασίας** σε ένα αρχείο Excel, αυτός ο οδηγός σας παρουσιάζει μια πλήρη, έτοιμη προς εκτέλεση λύση. Μέχρι το τέλος των πρώτων δύο προτάσεων θα καταλάβετε πώς να δημιουργήσετε φύλλα εργασίας και δυναμικά φύλλα Excel από μια συλλογή αντικειμένων, και θα έχετε ένα λειτουργικό δείγμα κώδικα που αυτοματοποιεί τη δημιουργία Excel με μία κλήση μεθόδου.

Η δημιουργία ξεχωριστών φύλλων εργασίας για κάθε υπάλληλο, έργο ή οποιαδήποτε άλλη οντότητα είναι μια συχνή απαίτηση όταν χρειάζεται να **populate excel workbook** δεδομένα προγραμματιστικά. Αυτός ο οδηγός περνάει από κάθε βήμα — από τη ρύθμιση του προτύπου μέχρι την επεξεργασία μιας λίστας και την αποθήκευση του τελικού αρχείου — ώστε να μπορείτε άμεσα να εφαρμόσετε την τεχνική στις δικές σας εφαρμογές Java.

## Τι θα πετύχετε

* Δημιουργήστε ένα κύριο φύλλο εργασίας που καταγράφει πληροφορίες υψηλού επιπέδου.  
* Δημιουργήστε **multiple sheets from list** δεδομένα, κάθε φύλλο ονομάζεται αυτόματα.  
* **Automate excel creation** χωρίς να προσθέτετε χειροκίνητα γραμμές ή στήλες.  
* **Populate excel workbook** με πλούσιες δομές δεδομένων (objects, maps, arrays).  

Απαιτούμενα:

* Java 8 ή νεότερη εγκατεστημένη.  
* Maven (ή άλλο εργαλείο κατασκευής) για την προσθήκη της βιβλιοθήκης Aspose.Cells for Java.  
* Βασική κατανόηση των συλλογών Java.  

> **Συμβουλή επαγγελματία:** Η σύνταξη SmartMarker (`${EmployeeMaster}`) λειτουργεί με οποιονδήποτε τύπο συλλογής που υλοποιεί το `java.util.Collection`. Χρησιμοποιήστε την για να διατηρείτε τα πρότυπά σας καθαρά και εύκολα στη συντήρηση.

## Πώς να δημιουργήσετε φύλλα εργασίας με SmartMarkerProcessor

Αυτή η ενότητα περιέχει τον βασικό κώδικα που κάνει το **πώς να δημιουργήσετε φύλλα εργασίας** απλό. Θα εξηγήσουμε γιατί κάθε γραμμή είναι σημαντική, όχι μόνο τι κάνει.

### Βήμα 1: Προσθέστε την εξάρτηση Aspose.Cells

Αν χρησιμοποιείτε Maven, συμπεριλάβετε τα παρακάτω στο `pom.xml` σας. Η βιβλιοθήκη παρέχει την κλάση `SmartMarkerProcessor` που χρησιμοποιείται σε όλο τον οδηγό.

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **Γιατί:** Η Aspose.Cells διαχειρίζεται το I/O αρχείων Excel, την ανάλυση Smart Marker και τη διαχείριση φύλλων εσωτερικά, επιτρέποντάς σας να εστιάσετε στα δεδομένα αντί για λειτουργίες αρχείων χαμηλού επιπέδου.

### Βήμα 2: Προετοιμάστε το πρότυπο Excel

Δημιουργήστε ένα αρχείο Excel με όνομα `EmployeeTemplate.xlsx` που περιέχει ένα μόνο κελί με τον placeholder Smart Marker:

| A |
|---|
| `${EmployeeMaster}` |

Όταν εκτελεστεί ο επεξεργαστής, θα αντικαταστήσει αυτόν τον placeholder με ένα **detail sheet** που περιέχει μία γραμμή ανά υπάλληλο.

> **Γιατί:** Ο placeholder ενημερώνει τον επεξεργαστή πού να ενσωματώσει τα δεδομένα. Η χρήση ξεχωριστού προτύπου διατηρεί τη μορφοποίηση (γραμματοσειρές, περιγράμματα, πλάτη στηλών) ανέπαφη.

### Βήμα 3: Ορίστε το μοντέλο δεδομένων

Παρακάτω υπάρχει μια ελάχιστη κλάση `Employee` και μια βοηθητική μέθοδος που δημιουργεί μια λίστα υπαλλήλων. Η λίστα θα χρησιμοποιηθεί για να επιδείξει **multiple sheets from list**.

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **Γιατί:** Ένα απλό αντικείμενο Java (POJO) αντιστοιχεί άμεσα σε πεδία Smart Marker (`firstName`, `lastName`, `department`). Αυτό κάνει το **populate excel workbook** απλό και ασφαλές ως προς τον τύπο.

### Βήμα 4: Ρυθμίστε τον SmartMarkerProcessor

Τώρα ενώνουμε όλα μαζί. Ο επεξεργαστής θα διαβάσει το πρότυπο, θα αντικαταστήσει το marker και θα δημιουργήσει ένα νέο φύλλο με όνομα `EmployeeDetail`.

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

**Επεξήγηση βασικών γραμμών**

| Line | Reason |
|------|--------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | Φορτώνει το πρότυπο που ήδη περιέχει το placeholder Smart Marker. |
| `data.put("EmployeeMaster", employees);` | Συνδέει τη λίστα Java με το marker `${EmployeeMaster}`. |
| `processor.setDetailSheetNewName("EmployeeDetail");` | Δίνει στο παραγόμενο φύλλο ένα περιγραφικό όνομα αντί του προεπιλεγμένου `Sheet1`. |
| `processor.process(wb, data);` | **Πώς να δημιουργήσετε φύλλα εργασίας** – ο επεξεργαστής διαβάζει το marker, δημιουργεί νέο φύλλο και το γεμίζει με γραμμές για κάθε `Employee`. |
| `wb.save("EmployeesReport.xlsx");` | Αποθηκεύει τα **dynamic excel sheets** στο δίσκο. |

### Βήμα 5: Επαληθεύστε το αποτέλεσμα

Ανοίξτε το `EmployeesReport.xlsx`. Θα πρέπει να δείτε δύο φύλλα εργασίας:

1. **Sheet1** – το αρχικό πρότυπο (μπορεί να κρυφτεί ή να αφαιρεθεί).  
2. **EmployeeDetail** – ένα **dynamic excel sheet** με στήλες `firstName`, `lastName`, `department` και μία γραμμή ανά υπάλληλο.

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **Γιατί είναι σημαντικό:** Το αρχείο τώρα περιέχει **multiple sheets from list** χωρίς καμία χειροκίνητη επανάληψη ή διεύθυνση κελιών. Η μηχανή Smart Marker φροντίζει για τη δημιουργία γραμμών, τη μετατροπή δεδομένων και την κληρονομιά μορφοποίησης.

### Βήμα 6: Διαχειριστείτε ειδικές περιπτώσεις

#### Κενή λίστα δεδομένων

Αν η λίστα `employees` είναι κενή, ο επεξεργαστής δημιουργεί ακόμη το φύλλο `EmployeeDetail` αλλά το αφήνει κενό. Μπορείτε να αποτρέψετε την προσθήκη του φύλλου ελέγχοντας το μέγεθος της συλλογής πριν την επεξεργασία:

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### Πολύ μεγάλες λίστες

Για χιλιάδες γραμμές, σκεφτείτε να αυξήσετε την κατανομή μνήμης (`-Xmx2g`) ή να χρησιμοποιήσετε το `processor.setAutoFitRows(false)` για να επιταχύνετε την επεξεργασία.

#### Προσαρμοσμένη ονομασία φύλλων ανά ομάδα

Αν χρειάζεστε ξεχωριστό φύλλο για κάθε τμήμα, μπορείτε να χρησιμοποιήσετε **multiple detail sheets**:

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

Ο placeholder `${department}` λαμβάνεται από κάθε αντικείμενο `Employee`, δημιουργώντας φύλλα όπως `Dept_Sales`, `Dept_Marketing`, κ.λπ.
