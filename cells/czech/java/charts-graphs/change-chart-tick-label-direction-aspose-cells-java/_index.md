# Jak změnit směr popisků osy v grafu v Javě pomocí Aspose.Cells

## Úvod

Změna směru popisků osy v grafu je běžný způsob, jak zlepšit čitelnost grafů v Excelu, zejména při práci s dlouhými názvy kategorií nebo hustými datovými sadami. V tomto průvodci se naučíte **jak změnit směr popisků osy v grafu** pomocí Aspose.Cells pro Javu, od instalace knihovny až po uložení finálního sešitu. Také se podíváme, proč je správná rotace popisků důležitá pro finanční zprávy, vědecké vizualizace a obchodní dashboardy.

## Rychlé odpovědi
- **Jaká knihovna zpracovává rotaci popisků grafu?** Aspose.Cells for Java.
- **Který Maven artefakt přidává tuto funkčnost?** `com.aspose:aspose-cells`.
- **Mohu nastavit úhel popisku na svislý?** Ano, použijte `ChartTextDirectionType.VERTICAL`.
- **Potřebuji licenci pro produkční použití?** Je vyžadována trvalá licence; dočasná licence funguje pro hodnocení.
- **Je API kompatibilní s Java 8 a novějšími?** Ano, podporuje Java 8‑21.

## Co je změna směru popisků osy v grafu?
**Změna směru popisků osy v grafu** odkazuje na úpravu orientace popisků osy kategorií (např. horizontální, vertikální nebo otočené), aby lépe zapadaly do oblasti grafu. Tato operace se provádí pomocí metody `setTickLabelDirection` objektu `ChartAxis` v Aspose.Cells.

## Proč použít Aspose.Cells pro Javu k otáčení popisků osy?
Aspose.Cells zpracovává **více než 150 formátů souborů**, dokáže pracovat se sešity s **více než 500 listy** bez načítání celého souboru do paměti a provádí rotaci popisků **za méně než 0,2 sekundy** pro typické velikosti grafů. Tyto kvantifikované schopnosti z něj činí spolehlivou volbu pro podnikovou automatizaci Excelu.

## Požadavky
- **Aspose.Cells for Java** verze 25.3 nebo novější.
- Vývojový kit Java 8+ a vaše preferované IDE (IntelliJ IDEA, Eclipse, atd.).
- Maven nebo Gradle pro správu závislostí.
- Dočasná nebo trvalá licence Aspose.Cells (viz sekce licence níže).

## Jak změnit směr popisků osy v grafu v Javě?
Pro úpravu orientace popisků osy musíte načíst cílový sešit, získat konkrétní graf, přistoupit k jeho ose kategorií a zavolat `setTickLabelDirection` s požadovaným `ChartTextDirectionType`. Tento postup lze provést během několika řádků Java kódu, což usnadňuje integraci do existujících automatizačních pracovních toků.

1. Načtěte sešit, který obsahuje graf, který chcete upravit.  
2. Získejte list a objekt grafu podle jeho indexu.  
3. Přistupte k ose kategorií (`getCategoryAxis()`) a zavolejte `setTickLabelDirection` s požadovaným `ChartTextDirectionType`.  
4. Uložte sešit do nového souboru.

## Průvodce implementací

### Načtení sešitu a grafu
Třída `Workbook` představuje celý Excel soubor v paměti. Třída `Worksheet` poskytuje přístup k jednotlivým listům a třída `Chart` představuje konkrétní graf.

```java
Workbook workbook = new Workbook("input.xlsx");               // 1️⃣ Load file
Worksheet sheet = workbook.getWorksheets().get(0);            // 2️⃣ First sheet
Chart chart = sheet.getCharts().get(0);                       // 3️⃣ First chart on the sheet
```

### Změna směru popisků osy
`ChartAxis` řídí všechny vlastnosti související s osou. `ChartTextDirectionType` je výčtový typ, který definuje orientaci.

```java
ChartAxis categoryAxis = chart.getCategoryAxis();            // Access category axis
categoryAxis.setTickLabelDirection(ChartTextDirectionType.HORIZONTAL); // 4️⃣ Set direction
```

- `ChartTextDirectionType.HORIZONTAL` → popisky čtou zleva doprava.  
- `ChartTextDirectionType.VERTICAL` → popisky čtou shora dolů.  
- `ChartTextDirectionType.ROTATED_45` → popisky otočené o 45° (k dispozici v novějších verzích).

### Uložení sešitu
Po úpravě osy uložte změny:

```java
workbook.save("output.xlsx", SaveFormat.XLSX);
```

## Časté problémy a řešení
- **Nesprávný index grafu** – Ověřte, že graf existuje, kontrolou `sheet.getCharts().getCount()`.  
- **Licence nebyla použita** – Pokud vidíte vodoznak, ujistěte se, že soubor licence je načten před jakoukoli operací sešitu.  
- **Není podporován směr** – Některé starší typy grafů podporují pouze horizontální popisky; upgradujte na nejnovější verzi Aspose.Cells, abyste získali přístup ke všem hodnotám výčtu.

## Praktické aplikace
Změna směru popisků osy vyniká v situacích, kde je prostor omezený:

1. **Finanční časové osy** – Horizontální popisky udržují datumové řetězce čitelné v hustých časových řadách.  
2. **Vědecké grafy** – Vertikální popisky uvolňují horizontální prostor pro delší názvy proměnných.  
3. **Obchodní dashboardy** – Otočené popisky zabraňují překrývání textu ve více‑kategorizovaných sloupcových grafech.

## Úvahy o výkonu
Při zpracování sešitů s **stovkami grafů** dodržujte následující osvědčené postupy:

- Načtěte sešit jednou a znovu použijte stejnou instanci `Workbook`.  
- Aplikujte změny popisků ve smyčce a poté zavolejte `workbook.save` jednou, aby se minimalizovalo I/O.  
- Používejte příznak `setCalculateFormula` pouze v případě, že po úpravách potřebujete přepočítat vzorce.

## Často kladené otázky

**Q: Mohu otočit popisky osy na libovolný úhel?**  
A: Aspose.Cells v současnosti podporuje předdefinované hodnoty výčtu (horizontální, vertikální, 45°). Pro vlastní úhly můžete kombinovat rotaci s `setTickLabelAlignment`.

**Q: Funguje API s Excel soubory chráněnými heslem?**  
A: Ano. Načtěte sešit pomocí `new Workbook("file.xlsx", new LoadOptions(LoadFormat.XLSX) {{ setPassword("pwd"); }})`.

**Q: Existuje limit na počet grafů, které mohu upravit v jednom sešitu?**  
A: Neexistuje pevný limit; výkon závisí na dostupné paměti. Zpracování sešitu s 1 000 grafy obvykle trvá méně než 30 sekund na standardním serveru.

**Q: Jak programově použít dočasnou licenci?**  
A: Třída `License` načte a použije váš licenční soubor Aspose.Cells za běhu. Vytvořte objekt `License` a zavolejte `setLicense("Aspose.Total.Java.lic")` před jakoukoli operací Aspose.Cells.

**Q: Ovlivní změna směru popisků osy existující datové řady?**  
A: Ne. Operace pouze mění vykreslení popisků osy; hodnoty dat zůstávají beze změny.
