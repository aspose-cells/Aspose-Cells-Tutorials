# Jak vytvořit Excel sešit v Javě s JSON daty

Pokud potřebujete **create Excel workbook java** vývojáři často čelí výzvě načíst JSON data do tabulky. Tento průvodce vám ukáže, jak **populate Excel from JSON**, včetně toho, jak **convert JSON array excel** a **populate workbook from json** čistým, opakovatelným způsobem.

Práce s JSON je běžná, když služby poskytují data přes REST API, a Excel zůstává preferovaným formátem pro reportování a analýzu. Na konci tohoto tutoriálu budete mít spustitelný Java program, který:

* vytvoří nový Excel sešit,
* načte JSON pole (nebo jakoukoli JSON strukturu) a zapíše jeho hodnoty do buněk,
* uloží soubor na disk připravený pro další zpracování.

K žádným externím nástrojům není potřeba kromě knihovny Aspose.Cells pro Java, která poskytuje `SmartMarkerProcessor` použité ve vzorovém kódu.

## Požadavky

Před začátkem se ujistěte, že máte:

| Požadavek | Důvod |
|--------------|--------|
| Java Development Kit (JDK) ≥ 8 | Vyžadováno pro kompilaci a spuštění příkladu |
| Maven nebo Gradle (volitelné) | Zjednodušuje správu závislostí |
| Aspose.Cells for Java (v23.10 or later) | Poskytuje třídy `Workbook` a `SmartMarkerProcessor` |
| Základní znalost JSON a Java I/O | Pomáhá pochopit tok dat |

Pokud raději nepoužíváte nástroj pro sestavení, můžete stáhnout Aspose.Cells JAR z [Aspose website](https://products.aspose.com/cells/java/) a přidat jej ručně do classpath vašeho projektu.

## Krok 1: Nastavte projekt a přidejte závislost Aspose.Cells

### Uživatelé Maven

Add the following dependency to your `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Uživatelé Gradle

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

Pokud nepoužíváte nástroj pro sestavení, umístěte stažený JAR do složky `libs/` a zahrňte jej do classpath při kompilaci:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## Krok 2: Vytvořte nový sešit a nakonfigurujte procesor SmartMarker

`SmartMarkerProcessor` zjednodušuje mapování JSON hodnot do Excel buněk. Voláním `setArrayAsSingle(true)` říkáme procesoru, aby celou JSON pole považoval za jedinou hodnotu, což je užitečné, když chcete, aby každý prvek obsadil vlastní buňku v řádku.

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**Why this matters:**  
Vytvoření sešitu předem vám poskytne čisté plátno. Nastavení `setArrayAsSingle(true)` zabraňuje procesoru v rozbalení pole do jediného řetězce (např. `["A","B","C"]`) a místo toho vám umožní ručně řídit rozložení.

## Krok 3: Definujte JSON data, která chcete vložit

Pro tento tutoriál používáme jednoduché JSON pole, ale stejný přístup funguje s objekty, vnořenými poli nebo složitými strukturami.

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**Tip:** Pokud váš JSON pochází ze souboru nebo REST endpointu, nahraďte doslovný řetězec `String` načteným obsahem ze zdroje, např. `Files.readString(Paths.get("data.json"))`.

## Krok 4: Zpracujte sešit s JSON daty

Nyní necháme `SmartMarkerProcessor` mapovat JSON pole na první list. Výchozí chování zapisuje každý prvek do po sobě jdoucích buněk počínaje `A1`.

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

Za scénou Aspose.Cells parsuje JSON, vytvoří dočasnou datovou tabulku a zapíše hodnoty do listu. Protože jsme nastavili `ArrayAsSingle` na `true`, prvky pole jsou umístěny horizontálně napříč prvním řádkem.

## Krok 5: Uložte sešit do souboru

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

Když spustíte program, měli byste v pracovním adresáři vidět soubor pojmenovaný **CreatedFromJson.xlsx**. Otevřením v Excelu (nebo jakémkoli kompatibilním prohlížeči) se zobrazí:

| A | B | C |
|---|---|---|
| A | B | C | *(hodnoty se zobrazí v buňkách A1, B1, C1)*

### Očekávaný výstup

```
Workbook saved to CreatedFromJson.xlsx
```

A Excel list vypadá takto:

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## Krok 6: Práce s komplexnějšími JSON strukturami (volitelné)

### 6.1 Naplnění sešitu z JSON objektu

Pokud je váš JSON objektem místo pole, můžete stále použít `SmartMarkerProcessor`. Například:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

Procesor vytvoří pojmenované oblasti (`title`, `month`, `values`), na které můžete odkazovat ve vaší Excel šabloně pomocí Smart Markerů jako `&=title` a `&=values`.

### 6.2 Převod vnořeného JSON pole na vertikální seznam

Někdy potřebujete, aby pole vyplnilo sloupec místo řádku. Nastavte počáteční buňku ručně před zpracováním:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

Nyní se hodnoty **A**, **B**, **C** objeví v buňkách A2, A3, A4.

## Běžné úskalí a jak se jim vyhnout

| Problém | Příčina | Řešení |
|-------|-------|-----|
| **Array written as a single string** | `setArrayAsSingle(false)` (default) | Call `processor.setArrayAsSingle(true)` |
| **File not found when saving** | Invalid path or missing write permissions | Use an absolute path or ensure the directory exists |
| **JSON parsing error** | Malformed JSON string | Validate JSON with a tool or use a library like Jackson to generate the string |
| **Cells overwritten unintentionally** | Processing the same worksheet multiple times without resetting the start cell | Call `processor.setStartCell("A1")` before each `process` call |

## Pro tip: znovu použijte sešit jako šablonu

Místo toho, abyste pokaždé začínali s prázdným sešitem, můžete načíst předem navrženou šablonu, která již obsahuje hlavičky, vzorce nebo stylování:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

Tento přístup kombinuje vizuální úpravu ručně vytvořeného Excel souboru s automatizací **populate workbook from json**.
