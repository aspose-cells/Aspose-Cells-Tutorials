# Import vlastních objektů do Excelu pomocí Aspose.Cells – průvodce pro Java

Pokud potřebujete **importovat vlastní objekty** do listu Excelu, tento průvodce vás provede kompletním procesem pomocí Aspose.Cells pro Java. Uvidíte, jak **importovat data do Excelu**, použít tučný styl záhlaví a vygenerovat připravený k sdílení soubor `.xlsx`.

Export tabulkových dat z Javy často zahrnuje ruční zápisy buňka po buňce, což je náchylné k chybám a těžko udržovatelné. Využitím API `importCustomObjects` se vyhnete boilerplate kódu, zachováte svůj datový model a získáte detailní kontrolu nad formátováním.

V tomto tutoriálu:

* Vytvoříte seznam Java `Map` objektů, který napodobuje typickou datovou tabulku.
* Vytvoříte opakovaně použitelný styl záhlaví (tučné písmo) pomocí Aspose.Cells.
* Naimportujete vlastní objekty do listu a aplikujete pole stylů.
* Uložíte sešit na disk a ověříte výsledek.

Jedinou podmínkou je vývojové prostředí Java (doporučeno JDK 8+) a knihovna Aspose.Cells pro Java.

---

## Co budete potřebovat

| Požadavek | Důvod |
|-----------|-------|
| JDK 8 nebo novější | Nutné pro kompilaci a spuštění Java kódu. |
| Aspose.Cells pro Java (nejnovější verze) | Poskytuje třídy `Workbook`, `Worksheet` a importní API. |
| IDE nebo nástroj pro sestavení (např. Maven, Gradle) | Zjednodušuje správu závislostí a spouštění. |

```xml

    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## Krok 1: Připravte vlastní objekty k importu

Prvním krokem je vytvořit kolekci, která představuje řádky, jež chcete umístit do Excelu. V tomto příkladu používáme `List<Map<String,Object>>`, kde každý map funguje jako řádek s názvy sloupců jako klíči.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Proč je to důležité:**  
`importCustomObjects` očekává pole objektů. Použitím `Map` zachováte názvy sloupců, což umožní Aspose.Cells automaticky je namapovat do buněk. Tento přístup připomíná typický `DataTable` v .NET nebo `ResultSet` z JDBC, což činí kód znovupoužitelným napříč projekty.

---

## Krok 2: Definujte styl záhlaví, který se použije při importu

Přehledný řádek záhlaví zlepšuje čitelnost. Aspose.Cells vám umožní vytvořit objekt `Style`, nastavit jeho písmo na tučné a předat jej v poli `ImportTableOptions`.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Proč je to důležité:**  
Pokud vynecháte pole stylů, zobrazí se záhlaví výchozím písmem, které nemusí vynikat. Připravením stylu jednou se vyhnete opakovaným voláním pro každý řádek a udržíte logiku importu čistou.

---

## Krok 3: Importujte vlastní objekty s polem stylů

Nyní spojíte data a styl a zavoláte `importCustomObjects`. Metoda umístí data od levého horního rohu (řádek 0, sloupec 0) a automaticky použije styl záhlaví.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Proč je to důležité:**  
`importCustomObjects` analyzuje každou mapu, vytvoří sloupce na základě klíčů (`Name`, `Score`) a zapíše hodnoty do odpovídajících buněk. Objekt `ImportTableOptions` říká Aspose.Cells, aby použil `styleArray` pro první řádek, čímž získáte tučné záhlaví bez dalšího kódu.

---

## Krok 4: Uložte sešit a ověřte výstup

Nakonec zapíšete sešit do souboru. Vygenerovaný Excel obsahuje stylovaný řádek záhlaví následovaný datovými řádky.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Očekávaný výsledek:**  

| **Jméno** | **Skóre** |
|-----------|-----------|
| Alice     | 95        |
| Bob       | 82        |

Buňky záhlaví (`Jméno`, `Skóre`) jsou zobrazeny tučným písmem, odpovídajícím stylu definovanému v kroku 2.

## Běžné varianty a okrajové případy

| Situace | Doporučené úpravy |
|---------|-------------------|
| **Různé pořadí sloupců** | Ujistěte se, že klíče v `Map` jsou vloženy v požadovaném pořadí, nebo použijte vlastní POJO s anotovanými poli a pole `PropertyDescriptor`. |
| **Velké datové sady (>10 000 řádků)** | Zvyšte nastavení `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)`, aby se předešlo `OutOfMemoryError`. |
| **Vlastní formáty čísel** | Přidejte druhý `Style` do `styleArray` pro datové řádky, např. nastavte `NumberFormat` na `"0"` pro celočíselná skóre. |
| **Více listů** | Zavolejte `importCustomObjects` na každý cílový list, přičemž upravíte počáteční řádek/sloupec podle potřeby. |
| **Locale‑specifický text záhlaví** | Naplňte řádek záhlaví ručně před importem a poté aplikujte styl na celý rozsah pomocí `Cells.applyStyle`. |

## Profesionální tipy pro robustní export Java do Excelu

* **Znovu použijte dočasný sešit** – Vytváření nového `Workbook` pro každý styl přidává režii. Uchovávejte jednu instanci, pokud potřebujete více stylů.  
* **Validujte data před importem** – Null hodnoty v mapě se stanou prázdnými buňkami; můžete je nahradit výchozími hodnotami předzpracováním seznamu.  
* **Uzavřete zdroje** – I když Aspose.Cells spravuje paměť interně, explicitní volání `workbook.dispose()` po uložení okamžitě uvolní nativní zdroje.  
* **Nastavte `Workbook.setForceFullCalculation(true)`**, pokud váš sešit obsahuje vzorce, které je nutné vyhodnotit před uložením.
