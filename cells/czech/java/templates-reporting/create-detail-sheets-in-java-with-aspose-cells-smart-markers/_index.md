# Vytváření detailních listů v Javě pomocí Aspose.Cells smart markers

Pokud potřebujete **vytvořit detailní listy** v Java aplikaci, tento tutoriál vám ukáže, jak na to pomocí Aspose.Cells smart markers. Uvidíte kompletní, spustitelný příklad, který **java create worksheets**, odvozuje **název listu z pole** a **zpracovává zdroj dat** během několika řádků kódu.

Průvodce pokrývá vše od nastavení projektu až po uložení finální sešitu, takže můžete řešení zkopírovat‑vložit do svého projektu a okamžitě jej přizpůsobit. Žádná externí dokumentace není potřeba — vše, co potřebujete, je zde.

## Co se naučíte

* Jak **použít smart markers** k duplikaci šablonového listu pro každý řádek v hlavním datovém souboru.  
* Jak dynamicky nastavit název každého nového listu na základě hodnoty pole (např. `Order_123`).  
* Jak předat Java kolekci jako **process data source** pro engine smart markerů.  
* Tipy pro řešení okrajových případů, jako jsou prázdná data, speciální znaky v názvech listů a úvahy o výkonu u velkých datových souborů.

### Požadavky

| Požadavek | Důvod |
|-------------|--------|
| Java 8 nebo vyšší | Aspose.Cells for Java podporuje Java 8+. |
| Maven nebo Gradle build systém | Zjednodušuje přidání závislosti Aspose.Cells. |
| Základní znalost Java kolekcí | Potřebné pro vytvoření zdroje dat pro smart markery. |
| Šablonový Excel soubor (`Template.xlsx`) s placeholder smart markerem v buňce **A1** | Šablona řídí generování detailních listů. |

> **Pro tip:** Uložte šablonový sešit do složky projektu `resources`, aby byl zahrnut do vašeho JAR souboru.

## Krok 1: Přidejte Aspose.Cells do svého projektu (java create worksheets)

Pokud používáte **Maven**, přidejte následující závislost do `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

Pro **Gradle** vložte tento řádek do `build.gradle`:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

Tyto řádky zpřístupní **java create worksheets** API během kompilace.

## Krok 2: Načtěte šablonový sešit

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*Proč je to důležité:* Objekt `Workbook` je vstupním bodem pro všechny operace s Excelem. Načtení šablony zajistí, že začnete se správným rozvržením a předdefinovaným formátováním.

## Krok 3: Vložte smart marker, který vytvoří nový list pro každý řádek hlavního souboru (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

Syntaxe `${Orders:DetailSheetNewName=Order_${OrderId}}` je jádrem **use smart markers**. Dělá tři věci:

1. Prochází kolekci `Orders`.  
2. Vytvoří **nový list** pro každý prvek.  
3. Nastaví **název listu z pole** `OrderId` (s předponou `Order_`).

## Krok 4: Připravte zdroj dat (process data source)

Níže je minimální příklad používající `List<Map<String, Object>>`. Nahraďte jej svým skutečným zdrojem dat — řádky z databáze, deserializace JSON atd.

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*Proč je to důležité:* Krok **process data source** propojí vaši Java kolekci s engine smart markerů. Klíč (`"Orders"`) musí přesně odpovídat názvu smart markeru.

## Krok 5: Zpracujte smart markery (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

Když se spustí `process`, Aspose.Cells načte kolekci `Orders`, klonuje šablonový list pro každý záznam a přejmenuje každý list podle pole `OrderId`. Toto je jádro použití **process data source**.

## Krok 6: Uložte sešit s duplikovanými detailními listy

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

Po spuštění najdete soubor `DuplicatedDetailSheets.xlsx`, který obsahuje:

* `Sheet1` – původní šablona (beze změny).  
* `Order_101` – detailní list pro první objednávku.  
* `Order_102` – detailní list pro druhou objednávku.

### Očekávaný výstup (úryvek)

| Název listu | A1 (smart marker) | Výsledný obsah |
|------------|-------------------|-------------------|
| Order_101  | `${Orders:...}`   | Vyplněno daty z `order1` |
| Order_102  | `${Orders:...}`   | Vyplněno daty z `order2` |

Otevřete soubor v Excelu a ověřte, že každý list má správný název a obsahuje požadované řádky dat.

## Řešení běžných variant a okrajových případů

### Prázdný zdroj dat

Pokud je `orders` prázdný, procesor smart markerů nevytvoří **žádné nové listy**. Aby se předešlo prázdnému sešitu, přidejte ochranu:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### Speciální znaky v názvech listů

Názvy listů v Excelu nesmí obsahovat `\ / ? * [ ] :`. Před použitím očistěte pole:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### Velké datové soubory

U tisíců řádků zvažte zvýšení haldy JVM (`-Xmx2g`) a volání `workbook.calculateFormula()` až po vygenerování všech listů, aby se zlepšil výkon.
