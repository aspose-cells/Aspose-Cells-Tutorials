# Jak vložit písma při ukládání Excelu do HTML pomocí C#

Jak vložit písma při ukládání sešitu Excel do HTML je častý požadavek pro zachování přesného vzhledu vašich tabulek napříč prohlížeči. Pokud potřebujete exportovat Excel do HTML a zachovat původní typ písma, tento návod vám ukáže kompletní, připravené řešení.

Dozvíte se, jak **exportovat Excel do HTML**, **převést Excel do HTML** s vloženými písmy a vyhnout se typickému problému „chybějícího písma“, který rozbije rozvržení na klientských počítačích. Nejsou potřeba žádné externí nástroje — stačí knihovna Aspose.Cells a několik řádků C#.

## Požadavky

Než začnete, ujistěte se, že máte:

* .NET 6.0 (nebo novější) nainstalovaný.
* Licencovanou kopii **Aspose.Cells for .NET** — zkušební verze stačí pro testování.
* IDE, například Visual Studio 2022 nebo VS Code.

Pokud už máte vše připravené, můžete rovnou přejít k kódu.

## Krok 1: Vytvořte sešit a přidejte ukázková data

Nejprve vygenerujeme malý sešit, abyste mohli vidět efekt vložených písem. Níže uvedený kód vytvoří list, zapíše několik buněk a použije vlastní písmo.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### Proč přidáváme vlastní písmo

Vkládání písem má smysl jen tehdy, když sešit používá písma, která nemusí být na klientském zařízení přítomna. Explicitním nastavením **Arial** (nebo jiného písma) můžeme ověřit, že výstupní HTML skutečně obsahuje data písma.

## Krok 2: Nastavte možnosti uložení HTML pro vložení písem

Aspose.Cells poskytuje třídu `HtmlSaveOptions`. Nastavením `EmbedFonts = true` řeknete knihovně, aby vložila požadované soubory písem přímo do generovaného HTML jako Base64‑kódované data URI.

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### Co vlastně „embed fonts in html“ dělá

Když je `EmbedFonts` nastaveno na true, Aspose.Cells získá soubory písem ze systému (nebo z vložené kolekce písem v sešitu) a převede je na řetězce **Base64**. Tyto řetězce jsou následně umístěny do bloku `<style>` pomocí `@font-face`. Výsledné HTML lze otevřít na libovolném zařízení, aniž by bylo nutné mít původní písmo nainstalováno.

## Krok 3: Uložte sešit jako HTML s vloženými písmy

Nyní zapíšeme sešit na disk. Soubor bude obsahovat data písma, takže jeho otevření v libovolném moderním prohlížeči zobrazí přesně stejnou typografii jako originální Excel soubor.

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### Očekávaný výsledek

* `embedded.html` se nachází ve složce `output`.
* Otevřením souboru v Chrome, Edge nebo Firefoxu se zobrazí list s textem **Arial**, i když na počítači prohlížeče Arial není nainstalován.
* Prohlížením zdroje HTML uvidíte blok `<style>` obsahující pravidlo `@font-face` s dlouhým `src: url(data:font/ttf;base64,…)` — to je vložené písmo.

## Krok 4: Ověřte, že HTML funguje na jiném počítači (volitelné)

Abyste se ujistili, že vložení proběhlo úspěšně:

1. Zkopírujte `output/embedded.html` na jiný počítač (nebo virtuální stroj), který **nemá** vlastní písmo nainstalováno.
2. Otevřete soubor v prohlížeči.
3. Rozvržení a typografie by měly odpovídat původnímu zobrazení v Excelu.

Pokud se písmo přepne na generické, zkontrolujte, že soubor písma je přístupný na stroji, kde se sestavuje, a že máte oprávnění jej číst.

## Často kladené otázky a okrajové případy

### Zvyšuje vložení písma velikost souboru?

Ano. Vložení TrueType nebo OpenType písma může přidat **desítky kilobajtů** k HTML souboru. U velkých sešitů s mnoha unikátními písmy zvažte:

* Ořezání písma (pouze použité znaky) — Aspose.Cells to provádí automaticky pro většinu běžných písem.
* Použití `ExportEmbeddedImages = false`, pokud nepotřebujete vkládat obrázky.

### Co když potřebuji vložit jen konkrétní písma?

`HtmlSaveOptions` nepodporuje přímý whitelist, ale můžete ovlivnit, která písma se objeví, **omezením písem použitých v sešitu** před voláním `Save`. Odstraňte zbytečná přiřazení písem nebo je nahraďte standardními web‑safe písmy.

### Můžu vložit písma při převodu do jiných formátů (např. PDF)?

Stejná vlastnost `EmbedFonts` existuje i v `PdfSaveOptions`. Princip je identický: data písma jsou vložena, takže PDF se vykreslí správně v libovolném prohlížeči.

## Kompletní, spustitelný příklad

Níže je kompletní program, který můžete zkopírovat a vložit do nového konzolového projektu.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

Spuštěním programu vznikne **HTML soubor, který obsahuje vložené písmo Arial**, což zaručuje vizuální shodu kdekoliv, kde je soubor otevřen.

## Závěr

Nyní víte, **jak vložit písma při ukládání Excelu do HTML** pomocí C#. Nastavením `HtmlSaveOptions.EmbedFonts = true` můžete spolehlivě **exportovat Excel do HTML** a **převést Excel do HTML** bez obav z chybějících písem na straně klienta. Tato technika je nezbytná pro webové reportování, dashboardy přátelské k e‑mailům nebo jakýkoli scénář, kde sdílíte obsah odvozený z Excelu jako HTML.

Nebojte se experimentovat s různými písmy, většími listy nebo sešity s více listy. Stejný příznak `EmbedFonts` funguje ve všech podporovaných výstupních formátech a dává vám jednotnou kontrolu nad vkládáním písem kdekoliv to potřebujete. Šťastné programování!
