# Jak vytvořit Excel sešit v C# s vlastním formátováním a uložit jako XLSX

Pokud potřebujete **vytvořit Excel sešit v C#**, který importuje data, použije vlastní číselný formát a změní barvu písma buňky, tento tutoriál vám přesně ukáže, jak na to. Získáte připravený příklad, který během několika sekund vytvoří stylovaný soubor `StyleArrayImport.xlsx`.

Práce s Excelem z C# často zahrnuje opakující se ruční kroky — definování formátů, aplikaci barev a zapamatování si správného uložení souboru. Na konci tohoto průvodce automatizujete všechny tyto úkoly, takže se můžete soustředit na data místo na uživatelské rozhraní.

Naučíte se:

* importovat `DataTable` do listu,
* použít `StyleArray` k **aplikaci vlastního číselného formátu** a **změně barvy písma buňky**,
* **uložit sešit jako XLSX** jedním voláním metody,
* a ověřit, že **formát importovaných dat v Excelu** vypadá přesně podle očekávání.

Jedinou podmínkou je reference na knihovnu **Aspose.Cells for .NET** (nebo jakékoli kompatibilní API, které poskytuje `Workbook`, `Worksheet` a `StyleArray`). Kód cílí na .NET 6+, ale starší verze fungují s menšími úpravami.

## Krok 1: Připravte ukázkový DataTable

Nejprve vytvořte `DataTable`, který napodobuje data, jež byste normálně získali z databáze nebo jiného zdroje. Tabulka obsahuje sloupec **Name** (string) a sloupec **Amount** (decimal), který později naformátujeme.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Proč je to důležité:** Použití `DataTable` vám umožní udržet logiku importu nezávislou na zdroji dat, což je běžný vzor při generování reportů z databází, CSV souborů nebo API.

---

## Krok 2: Definujte StyleArray pro **aplikaci vlastního číselného formátu** a **změnu barvy písma buňky**

`StyleArray` vám umožní seskupit instrukce formátování, které budou aplikovány na každou buňku importovanou z `DataTable`. V tomto příkladu:

* nastavíme `Number` na `#,##0.00` — typický účetní formát s oddělovači tisíců,
* nastavíme `FontColor` na `Color.Blue` — čísla tak budou výraznější.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**Proč použít StyleArray?** Aplikace stylu během importu eliminuje potřebu druhého průchodu listem, což zvyšuje výkon u velkých datových sad.

---

## Krok 3: **Vytvořit Excel sešit v C#** — instanciujte Workbook a získejte první Worksheet

Nyní vytvoříme prázdný sešit a získáme odkaz na první list (index 0). Tento list bude cílem pro naše importovaná data.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Vysvětlení:** `Workbook` představuje celý Excel soubor, zatímco `Worksheet` představuje jeden list. Výchozí sešit obsahuje jeden list, což stačí pro většinu jednoduchých reportů.

---

## Krok 4: Importujte DataTable pomocí **StyleArray** k **formátování importovaných dat v Excelu**

Metoda `ImportDataTable` zkopíruje řádky a sloupce tabulky do listu, počínaje buňkou `A1` (řádek 0, sloupec 0). Argument `true` říká metodě, aby zahrnula záhlaví sloupců. Protože předáváme `styleArray`, každá importovaná buňka získá vlastní číselný formát a barvu písma.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**Co se děje pod kapotou:** Aspose.Cells iteruje přes každý řádek, zapíše hodnotu a následně aplikuje styl definovaný v `styleArray`. Čísla se zobrazí s čárkami a dvěma desetinnými místy a text bude modrý.

---

## Krok 5: **Uložit sešit jako XLSX** — zapište soubor na disk

Nakonec uložíme sešit do souboru s příponou `.xlsx`. Cestu můžete změnit na libovolný zapisovatelný adresář ve vašem počítači.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Ověření výsledku:** Otevřete vygenerovaný soubor v Excelu. Měli byste vidět tři řádky dat, sloupec **Amount** naformátovaný s čárkami, dvěma desetinnými místy a zobrazený modrým písmem. To potvrzuje, že krok **formát importovaných dat v Excelu** byl úspěšný.

## Kompletní funkční příklad

Zkopírujte celý blok níže do nového konzolového projektu a spusťte jej. Další kód není potřeba.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Očekávaný výstup v konzoli:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

Otevřete soubor a ověřte, že sloupec **Amount** zobrazuje hodnoty jako `1,234.56` modrým písmem.

## Často kladené otázky a okrajové případy

| Otázka | Odpověď |
|----------|--------|
| *Mohu aplikovat různé formáty na jednotlivé sloupce?* | Ano. Po importu získáte objekt `Style` sloupce (`worksheet.Cells.Columns[1].Style`) a nastavíte jiný `Number` nebo `FontColor`. |
| *Co když potřebuji formátovat datum místo čísel?* | Nastavte `styleArray.Number = "mm-dd-yyyy"` a případně `styleArray.FontColor` pro buňky s daty. |
| *Je modré písmo viditelné na tmavých tématech Excelu?* | Modrá může být na tmavém pozadí těžko čitelná. Použijte světlejší odstín (`Color.LightBlue`) nebo kontrastní barvu (`Color.Black`). |
| *Jak importovat velmi velký DataTable (stovky tisíc řádků)?* | Použijte přetížení `ImportDataTable` s parametrem `ImportDataTableOptions` pro streamování dat, nebo rozdělte import do více listů, aby byl zachován limit řádků v Excelu (1 048 576 řádků). |
| *Mohu exportovat do CSV místo XLSX?* | Nahraďte `SaveFormat.Xlsx` za `SaveFormat.Csv`. Všimněte si, že informace o formátování (číslicový formát, barva písma) se v CSV ztratí, protože jde o čistý textový formát. |

## Tipy pro produkční nasazení

* **Pro tip:** Ukládejte objekt `Style` do cache, pokud potřebujete stejný formát aplikovat na mnoho listů; vytváření nového `StyleArray` pro každý import zvyšuje režii.
* **Dávejte pozor na kulturní rozdíly:** Vzor `Number` `#,##0.00` používá invariantní kulturu. Pokud potřebujete lokální oddělovače, použijte `NumberFormatInfo` nebo nechte Excel, aby formát přizpůsobil podle regionálního nastavení uživatele.
* **Zpracování chyb:** Obalte volání `Save` do bloku try‑catch, abyste zachytili I/O výjimky (např. nedostatečná oprávnění nebo zamčené soubory).
