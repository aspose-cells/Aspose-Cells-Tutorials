# Vytvoření excel souboru c# – stylování buněk a nastavení formátu měny

Pokud potřebujete **vytvořit excel soubor c#**, který vypadá profesionálně, tento návod vám ukáže přesně, jak stylovat excel buňky a nastavit sloupec jako měnu. Uvidíte kompletní, end‑to‑end příklad, který importuje `DataTable`, použije tučný záhlaví a nastaví formát čísla `$#,##0.00` pro sloupec s cenou.

Návod pokrývá vše, co potřebujete: požadované NuGet balíčky, celý zdrojový kód, vysvětlení, proč je každá část důležitá, a tipy pro řešení okrajových případů, jako jsou prázdné řádky nebo různé locale. Na konci budete schopni vygenerovat soubor `.xlsx` s pěkně naformátovaným sloupcem ceny během několika řádků C#.

## Požadavky

- .NET 6.0 nebo novější (kód funguje také s .NET Framework 4.6+)
- Visual Studio 2022 nebo jakýkoli C# editor, který preferujete
- Knihovna **Aspose.Cells for .NET** nebo **GemBox.Spreadsheet** (obě podporují `ImportTableOptions`). Níže uvedený příklad používá **Aspose.Cells**, protože poskytuje jednoduchou vlastnost `StyleArray`.
- Základní znalost C# kolekcí a `DataTable`

> **Pro tip:** Pokud preferujete bezplatnou alternativu, nahraďte `Aspose.Cells` knihovnou `GemBox.Spreadsheet`. API pro import `DataTable` se styly je téměř identické; stačí změnit jmenný prostor a název NuGet balíčku.

## Krok 1: Instalace Excel knihovny

Otevřete NuGet Package Manager a nainstalujte knihovnu:

```bash
dotnet add package Aspose.Cells
```

> **Proč tento krok?** Knihovna poskytuje třídy `Workbook`, `Worksheet`, `Style` a `ImportTableOptions`, které jsou později použity. Bez ní byste museli ručně psát formát Office Open XML, což je náchylné k chybám.

## Krok 2: Vytvoření DataTable se vzorovými daty

`DataTable` je pohodlný způsob, jak držet tabulková data před jejich exportem do Excelu. V tomto příkladu máme dva sloupce: *Product* a *Price*.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Vysvětlení:**  
> - `Columns.Add("Price", typeof(double))` říká tabulce, aby hodnoty ceny považovala za čísla, což je potřeba pro formátování čísel později.  
> - Přidání několika řádků nám dává data pro ověření kroku **format column currency**.

## Krok 3: Definování stylů, které chcete použít

Vytvoříme pole objektů `Style`, které odpovídá pořadí sloupců. První položka styluje řádek záhlaví, druhá nechává sloupec *Product* nedotčený a třetí aplikuje formát měny.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### Proč použít **style array**?

`ImportTableOptions.StyleArray` mapuje každý sloupec na `Style`. Toto je nejefektivnější způsob, jak **add number format** a **style excel cells** v jedné importní operaci, aniž byste museli provádět druhý průchod přes list.

## Krok 4: Konfigurace možností importu

Nyní svážeme pole stylů s operací importu. Objekt `ImportTableOptions` vám také umožní nastavit, zda se první řádek má považovat za záhlaví.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Poznámka:** `IsFieldNameShown` má výchozí hodnotu `true`, ale nastavení explicitně dělá záměr jasným pro budoucí čtenáře.

## Krok 5: Vytvoření sešitu, import tabulky a uložení

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### Očekávaný výsledek

Po otevření `DataTableWithStyles.xlsx`:

- První řádek (záhlaví) je **tučný**.
- Sloupec *Price* zobrazuje hodnoty jako **$1.20**, **$3.50**, **$0.75**.
- Sloupec *Product* si zachovává výchozí písmo.

Úspěšně jste **vytvořili excel soubor c#** s formátovaným sloupcem měny a stylovanými buňkami záhlaví.

## Krok 6: Řešení běžných variant a okrajových případů

### a. Jiný locale nebo vlastní symbol měny

Pokud potřebujete euro nebo jinou měnu, nahraďte vestavěný formát `164` vlastním řetězcem formátu:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. Přidání dalších sloupců později

Když přidáte další sloupce, rozšiřte pole `columnStyles` odpovídajícím způsobem. Pro sloupce, které mají zachovat výchozí styl, použijte `null`.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. Prázdný DataTable

Pokud `DataTable` neobsahuje žádné řádky, Aspose.Cells stále vytvoří řádek záhlaví. Nicméně sešit bude obsahovat jen jeden řádek. Aby se předešlo prázdnému souboru, zkontrolujte počet řádků před importem:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Použití `GemBox.Spreadsheet` místo Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

Logika zůstává identická, což dokazuje, že návod je **format column currency** nezávislý na použité knihovně.

## Krok 7: Ověření souboru programově (volitelné)

Můžete otevřít vygenerovaný sešit a ověřit, že formát čísla byl aplikován správně – užitečné pro jednotkové testy.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```
