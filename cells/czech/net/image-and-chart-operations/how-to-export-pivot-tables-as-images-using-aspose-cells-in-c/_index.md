# Jak exportovat kontingenční tabulky jako obrázky pomocí Aspose.Cells v C#

Pokud potřebujete **exportovat kontingenční** data do přenosného obrázku, Aspose.Cells proces zjednodušuje. Tento tutoriál vám ukáže, jak přesně exportovat kontingenční tabulky jako soubory PNG, takže je můžete vložit do zpráv, e‑mailů nebo dokumentace, aniž byste potřebovali Excel na cílovém počítači.

Export kontingenční tabulky jako obrázku eliminuje problémy s formátováním specifickým pro verzi a umožní netechnickým uživatelům okamžitě zobrazit analýzu. Probereme vše od nastavení projektu po vykreslení finálního **exportu obrázku kontingenční tabulky** a také vysvětlíme, jak **uložit kontingenční tabulku jako obrázek** pro budoucí použití.

## Jak exportovat kontingenční tabulky jako obrázky s Aspose.Cells

Níže je kompletní, spustitelný příklad, který načte sešit, obnoví kontingenční tabulku, nastaví možnosti obrázku a zapíše výstupní soubor. Každý krok obsahuje stručné odůvodnění, abyste pochopili *proč* je kód napsán tak, jak je, a ne jen *co* dělá.

### 1. Nastavení prostředí Aspose.Cells

1. Nainstalujte NuGet balíček:

   ```bash
   dotnet add package Aspose.Cells
   ```

2. Přidejte požadované `using` direktivy na začátek vašeho C# souboru:

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **Tip:** Cílová platforma .NET 6 nebo novější vám poskytne nejnovější vylepšení výkonu v Aspose.Cells.

### 2. Načtení sešitu a vyhledání kontingenční tabulky

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*Proč je to důležité:* Třída `Workbook` parsuje soubor XLSX a poskytuje přístup ke všem listům. Výběr správného listu je zásadní, protože sešit může obsahovat více kontingenčních tabulek.

### 3. Obnovení kontingenční tabulky pro zachycení nejnovějších zdrojových dat

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

Obnovení zajišťuje, že všechny změny provedené ve zdrojovém rozsahu po uložení souboru se projeví ve vykresleném obrázku. Přeskočení tohoto kroku může vést k zastaralým nebo nepřesným vizuálům.

### 4. Nastavení možností exportu obrázku (export kontingenční tabulky jako obrázku)

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

Objekt `ImageOrPrintOptions` vám umožňuje řídit formát, rozlišení a další podrobnosti vykreslování. PNG je nejčastější volbou pro ostrou, web‑kompatibilní grafiku, ale můžete přepnout na `ImageFormat.Jpeg`, pokud je velikost souboru kritická.

### 5. Vykreslení a **uložení kontingenční tabulky jako obrázku**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

`RenderToImage` provádí těžkou práci: vykreslí kontingenční tabulku přesně tak, jak vypadá v Excelu, a zapíše binární data PNG na disk. Metoda vrací `void`, takže můžete bezpečně předpokládat, že soubor existuje po dokončení volání, aniž byste potřebovali další kontroly.

#### Očekávaný výsledek

Po spuštění programu najdete `Pivot.png` ve specifikovaném adresáři. Otevření souboru by mělo zobrazit věrný snímek původní kontingenční tabulky, včetně záhlaví sloupců, součtů řádků a veškerého použitého formátování.

### 6. Běžné varianty a okrajové případy

| Scénář | Úprava |
|----------|------------|
| **Velké kontingenční tabulky** (mnoho řádků/sloupců) | Zvyšte `HorizontalResolution` a `VerticalResolution` na 300 dpi pro ostřejší výstup. |
| **Vlastní stylování** (barvy pozadí, písma) | Ujistěte se, že jsou načteny definice stylů sešitu před voláním `Refresh()`. |
| **Více kontingenčních tabulek** v jednom listu | Procházejte `worksheet.PivotTables` a pro každou zavolejte `RenderToImage` s odlišnými názvy souborů. |
| **Export do JPEG** místo PNG | Změňte `ImageFormat = ImageFormat.Jpeg` a volitelně nastavte `Quality` na objektu `JpegSaveOptions`. |

Tyto varianty vám umožní **exportovat obrázek kontingenční tabulky** ve formátu, který váš downstream systém očekává.

## Kompletní zdrojový kód pro rychlé zkopírování

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

Spuštěním programu se vytvoří PNG soubor zobrazený výše, čímž se dokončí workflow **uložit kontingenční tabulku jako obrázek** během méně než jedné minuty.
