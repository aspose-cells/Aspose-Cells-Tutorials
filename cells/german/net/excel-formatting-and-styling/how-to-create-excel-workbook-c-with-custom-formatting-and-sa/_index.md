# Wie man ein Excel-Arbeitsbuch C# mit benutzerdefinierter Formatierung erstellt und als XLSX speichert

Wenn Sie ein **Excel-Arbeitsbuch C#** erstellen müssen, das Daten importiert, ein benutzerdefiniertes Zahlenformat anwendet und die Schriftfarbe der Zelle ändert, zeigt Ihnen dieses Tutorial genau, wie es geht. Sie erhalten ein sofort ausführbares Beispiel, das in Sekunden eine formatierte `StyleArrayImport.xlsx`‑Datei erzeugt.

Die Arbeit mit Excel aus C# heraus beinhaltet oft wiederholende manuelle Schritte — Formate definieren, Farben anwenden und daran denken, die Datei korrekt zu speichern. Am Ende dieses Leitfadens automatisieren Sie all diese Aufgaben, sodass Sie sich auf die Daten statt auf die Benutzeroberfläche konzentrieren können.

Sie lernen, wie Sie:

* ein `DataTable` in ein Arbeitsblatt importieren,
* ein `StyleArray` verwenden, um **ein benutzerdefiniertes Zahlenformat anzuwenden** und **die Schriftfarbe der Zelle zu ändern**,
* **das Arbeitsbuch als XLSX speichern** mit einem einzigen Methodenaufruf,
* und überprüfen, dass die **format imported data excel** exakt wie beabsichtigt aussieht.

Die einzige Voraussetzung ist ein Verweis auf die **Aspose.Cells for .NET**‑Bibliothek (oder jede kompatible API, die `Workbook`, `Worksheet` und `StyleArray` bereitstellt). Der Code zielt auf .NET 6+ ab, frühere Versionen funktionieren mit geringfügigen Anpassungen.

---

## Voraussetzungen

| Anforderung | Grund |
|-------------|-------|

Installieren Sie das Aspose.Cells‑Paket mit folgendem Befehl:

```bash
dotnet add package Aspose.Cells
```

## Schritt 1: Beispiel‑DataTable vorbereiten

Erstellen Sie zunächst ein `DataTable`, das die Daten simuliert, die Sie normalerweise aus einer Datenbank oder einer anderen Quelle abrufen würden. Die Tabelle enthält eine **Name**‑Spalte (String) und eine **Amount**‑Spalte (Decimal), die wir später formatieren.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Warum das wichtig ist:** Die Verwendung eines `DataTable` ermöglicht es, die Import‑Logik unabhängig von der Datenquelle zu halten – ein gängiges Muster beim Erstellen von Berichten aus Datenbanken, CSV‑Dateien oder APIs.

## Schritt 2: Definieren Sie ein StyleArray, um **benutzerdefiniertes Zahlenformat anzuwenden** und **die Schriftfarbe der Zelle zu ändern**

`StyleArray` lässt Sie Formatierungsanweisungen bündeln, die auf jede aus dem `DataTable` importierte Zelle angewendet werden. In diesem Beispiel:

* setzen wir `Number` auf `#,##0.00` — ein typisches Buchhaltungsformat mit Tausendertrennzeichen,
* setzen `FontColor` auf `Color.Blue` — damit die Zahlen hervorstechen.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**Warum ein StyleArray verwenden?** Das Anwenden eines Stils zur Importzeit vermeidet einen zweiten Durchlauf über das Arbeitsblatt, was die Leistung bei großen Datensätzen verbessert.

---

## Schritt 3: **Excel-Arbeitsbuch C# erstellen** – Workbook instanziieren und das erste Worksheet erhalten

Jetzt erstellen wir ein leeres Arbeitsbuch und erhalten eine Referenz auf das erste Arbeitsblatt (Index 0). Dieses Arbeitsblatt wird zum Ziel für unsere importierten Daten.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Erläuterung:** `Workbook` repräsentiert die gesamte Excel‑Datei, während `Worksheet` ein einzelnes Tab darstellt. Das Standard‑Workbook enthält ein Blatt, was für die meisten einfachen Berichte ausreicht.

---

## Schritt 4: Importieren Sie das DataTable mit dem **StyleArray**, um **importierte Daten in Excel zu formatieren**

Die Methode `ImportDataTable` kopiert die Zeilen und Spalten der Tabelle in das Arbeitsblatt, beginnend bei Zelle `A1` (Zeile 0, Spalte 0). Das Argument `true` bewirkt, dass Spaltenüberschriften mit übernommen werden. Da wir `styleArray` übergeben, erhält jede importierte Zelle das benutzerdefinierte Zahlenformat und die Schriftfarbe.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**Was im Hintergrund passiert:** Aspose.Cells iteriert über jede Zeile, schreibt den Wert und wendet anschließend den im `styleArray` definierten Stil an. Zahlen erscheinen mit Kommas und zwei Dezimalstellen, und der Text wird in Blau dargestellt.

---

## Schritt 5: **Arbeitsbuch als XLSX speichern** – Datei auf die Festplatte schreiben

Zum Schluss speichern wir das Arbeitsbuch in einer `.xlsx`‑Datei. Sie können den Pfad nach Belieben an ein beschreibbares Verzeichnis auf Ihrem Rechner anpassen.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Ergebnisüberprüfung:** Öffnen Sie die erzeugte Datei in Excel. Sie sollten die drei Datenzeilen sehen, wobei die **Amount**‑Spalte mit Kommas, zwei Dezimalstellen und blauer Schrift formatiert ist. Das bestätigt, dass der Schritt **format imported data excel** erfolgreich war.

## Vollständiges funktionierendes Beispiel

Kopieren Sie den gesamten Block unten in ein neues Konsolenprojekt und führen Sie ihn aus. Weiterer Code ist nicht nötig.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Erwartete Ausgabe in der Konsole:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

Öffnen Sie die Datei und prüfen Sie, dass die **Amount**‑Spalte Werte wie `1,234.56` in blauer Schrift zeigt.

## Häufige Fragen & Sonderfälle

| Frage | Antwort |
|-------|----------|
| *Kann ich unterschiedliche Formate auf einzelne Spalten anwenden?* | Ja. Nach dem Importieren rufen Sie das `Style`‑Objekt der Spalte ab (`worksheet.Cells.Columns[1].Style`) und setzen ein anderes `Number`‑ oder `FontColor`‑Attribut. |
| *Was, wenn ich statt Zahlen Daten formatieren muss?* | Setzen Sie `styleArray.Number = "mm-dd-yyyy"` und optional `styleArray.FontColor` für Datumszellen. |
| *Ist die blaue Schrift auf dunklen Excel‑Themen sichtbar?* | Blau kann auf dunklen Hintergründen schwer lesbar sein. Verwenden Sie einen helleren Farbton (`Color.LightBlue`) oder eine kontrastierende Farbe (`Color.Black`). |
| *Wie importiere ich ein sehr großes DataTable (Hunderttausende von Zeilen)?* | Verwenden Sie `ImportDataTable` mit der Überladung `ImportDataTableOptions`, um Daten zu streamen, oder teilen Sie den Import in mehrere Worksheets auf, um innerhalb des Zeilenlimits von Excel (1.048.576 Zeilen) zu bleiben. |
| *Kann ich stattdessen nach CSV exportieren?* | Ersetzen Sie `SaveFormat.Xlsx` durch `SaveFormat.Csv`. Beachten Sie, dass Formatierungsinformationen (Zahlenformat, Schriftfarbe) in CSV verloren gehen, da es ein Nur‑Text‑Format ist. |

---

## Tipps für den Produktionseinsatz

* **Pro‑Tipp:** Cachen Sie das `Style`‑Objekt, wenn Sie dieselbe Formatierung auf viele Arbeitsblätter anwenden müssen; das Erzeugen eines neuen `StyleArray` für jeden Import verursacht zusätzlichen Aufwand.
* **Achten Sie auf Kulturunterschiede:** Das Muster `#,##0.00` folgt der invariant culture. Wenn Sie länderspezifische Trennzeichen benötigen, verwenden Sie `NumberFormatInfo` oder lassen Sie Excel das Format basierend auf den regionalen Einstellungen des Benutzers übernehmen.
* **Fehlerbehandlung:** Wickeln Sie den `Save`‑Aufruf in einen try‑catch‑Block, um I/O‑Ausnahmen (z. B. unzureichende Berechtigungen oder gesperrte Dateien) zu behandeln.
