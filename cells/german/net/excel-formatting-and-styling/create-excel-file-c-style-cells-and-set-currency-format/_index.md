# Excel-Datei mit C# erstellen – Zellen formatieren und Währungsformat setzen

Wenn Sie **eine Excel-Datei mit C#** erstellen möchten, die professionell aussieht, zeigt Ihnen diese Anleitung genau, wie Sie Excel‑Zellen formatieren und eine Spalte als Währung formatieren. Sie sehen ein vollständiges End‑zu‑Ende‑Beispiel, das eine `DataTable` importiert, eine fette Kopfzeile anwendet und das Zahlenformat `$#,##0.00` für die Preisspalte setzt.

Das Tutorial deckt alles ab, was Sie benötigen: erforderliche NuGet‑Pakete, den vollständigen Quellcode, Erklärungen, warum jedes Element wichtig ist, und Tipps zum Umgang mit Sonderfällen wie leeren Zeilen oder verschiedenen Locale‑Einstellungen. Am Ende können Sie mit nur wenigen Zeilen C# eine `.xlsx`‑Datei mit einer schön formatierten Preisspalte erzeugen.

## Voraussetzungen

- .NET 6.0 oder höher (der Code funktioniert auch mit .NET Framework 4.6+)
- Visual Studio 2022 oder ein beliebiger C#‑Editor Ihrer Wahl
- Die Bibliothek **Aspose.Cells for .NET** oder **GemBox.Spreadsheet** (beide unterstützen `ImportTableOptions`). Das nachfolgende Beispiel verwendet **Aspose.Cells**, weil es eine einfache `StyleArray`‑Eigenschaft bereitstellt.
- Grundkenntnisse zu C#‑Collections und `DataTable`

> **Pro‑Tipp:** Wenn Sie eine kostenlose Alternative bevorzugen, ersetzen Sie `Aspose.Cells` durch `GemBox.Spreadsheet`. Die API zum Importieren einer `DataTable` mit Styles ist fast identisch; ändern Sie lediglich den Namespace und den NuGet‑Paketnamen.

## Schritt 1: Excel‑Bibliothek installieren

Öffnen Sie den NuGet‑Package‑Manager und installieren Sie die Bibliothek:

```bash
dotnet add package Aspose.Cells
```

> **Warum dieser Schritt?** Die Bibliothek liefert die Klassen `Workbook`, `Worksheet`, `Style` und `ImportTableOptions`, die später verwendet werden. Ohne sie müssten Sie das Office‑Open‑XML‑Format manuell schreiben, was fehleranfällig ist.

## Schritt 2: DataTable mit Beispieldaten erstellen

Eine `DataTable` ist ein praktischer Weg, tabellarische Daten zu halten, bevor sie nach Excel exportiert werden. In diesem Beispiel haben wir zwei Spalten: *Product* und *Price*.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Erklärung:**  
> - `Columns.Add("Price", typeof(double))` weist die Tabelle an, die Preiswerte als Zahlen zu behandeln, was für die spätere Zahlenformatierung erforderlich ist.  
> - Das Hinzufügen einiger Zeilen liefert Daten, um den Schritt **Spalte als Währung formatieren** zu überprüfen.

## Schritt 3: Die zu verwendenden Styles definieren

Wir erstellen ein Array von `Style`‑Objekten, das der Spaltenreihenfolge entspricht. Der erste Eintrag formatiert die Kopfzeile, der zweite lässt die *Product*‑Spalte unverändert, und der dritte wendet ein Währungs‑Zahlenformat an.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### Warum ein **Style‑Array** verwenden?

`ImportTableOptions.StyleArray` ordnet jeder Spalte ein `Style` zu. Das ist der effizienteste Weg, **Zahlenformat** und **Excel‑Zellen formatieren** in einem einzigen Importvorgang hinzuzufügen und so einen zweiten Durchlauf über das Arbeitsblatt zu vermeiden.

## Schritt 4: Import‑Optionen konfigurieren

Jetzt binden wir das Style‑Array an den Importvorgang. Das Objekt `ImportTableOptions` ermöglicht zudem die Kontrolle, ob die erste Zeile als Kopfzeile behandelt wird.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Hinweis:** `IsFieldNameShown` ist standardmäßig `true`, aber die explizite Einstellung macht die Absicht für zukünftige Leser klar.

## Schritt 5: Arbeitsmappe erstellen, Tabelle importieren und speichern

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### Erwartetes Ergebnis

Wenn Sie `DataTableWithStyles.xlsx` öffnen:

- Die erste Zeile (Kopfzeile) ist **fett**.
- Die *Price*‑Spalte zeigt Werte als **$1.20**, **$3.50**, **$0.75**.
- Die *Product*‑Spalte behält die Standardschriftart bei.

Sie haben erfolgreich **eine Excel‑Datei mit C#** erstellt, die eine formatierte Währungsspalte und formatierte Kopfzeilenzellen enthält.

## Schritt 6: Häufige Variationen und Sonderfälle behandeln

### a. Andere Locale oder benutzerdefiniertes Währungssymbol

Wenn Sie Euro oder eine andere Währung benötigen, ersetzen Sie das integrierte Format `164` durch einen benutzerdefinierten Format‑String:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. Später weitere Spalten hinzufügen

Wenn Sie zusätzliche Spalten hinzufügen, erweitern Sie das `columnStyles`‑Array entsprechend. Verwenden Sie `null` für Spalten, die den Standard‑Style behalten sollen.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. Leere DataTable

Hat die `DataTable` keine Zeilen, erzeugt Aspose.Cells trotzdem die Kopfzeile. Die Arbeitsmappe enthält dann nur eine Zeile. Um eine leere Datei zu vermeiden, prüfen Sie die Zeilenanzahl vor dem Import:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Verwendung von `GemBox.Spreadsheet` statt Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

Die Logik bleibt identisch, was zeigt, dass das Tutorial **Spalte als Währung formatieren** unabhängig von der zugrunde liegenden Bibliothek ist.

## Schritt 7: Datei programmgesteuert verifizieren (optional)

Sie können die erzeugte Arbeitsmappe öffnen und prüfen, ob das Zahlenformat korrekt angewendet wurde – nützlich für Unit‑Tests.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```
