# Wie man Pivot-Tabellen als Bilder mit Aspose.Cells in C# exportiert

Wenn Sie **Pivot exportieren** Daten in ein tragbares Bild exportieren müssen, macht Aspose.Cells den Prozess unkompliziert. Dieses Tutorial zeigt Ihnen genau, wie Sie Pivot-Tabellen als PNG‑Dateien exportieren, sodass Sie sie in Berichte, E‑Mails oder Dokumentationen einbetten können, ohne dass Excel auf dem Zielrechner erforderlich ist.

Das Exportieren einer Pivot‑Tabelle als Bild eliminiert versionsspezifische Formatierungsprobleme und ermöglicht es nicht‑technischen Stakeholdern, die Analyse sofort zu sehen. Wir behandeln alles von der Projektkonfiguration bis zur Darstellung des endgültigen **export pivot table image**, und wir erklären außerdem, wie man **save pivot as image** für die zukünftige Wiederverwendung speichert.

## Wie man Pivot-Tabellen als Bilder mit Aspose.Cells exportiert

Unten finden Sie das vollständige, ausführbare Beispiel, das eine Arbeitsmappe lädt, die Pivot‑Tabelle aktualisiert, Bildoptionen konfiguriert und die Ausgabedatei schreibt. Jeder Schritt enthält eine kurze Begründung, damit Sie verstehen, *warum* der Code so geschrieben ist und nicht nur, *was* er tut.

### 1. Einrichten der Aspose.Cells‑Umgebung

1. Installieren Sie das NuGet‑Paket:

   ```bash
   dotnet add package Aspose.Cells
   ```

2. Fügen Sie die erforderlichen `using`‑Direktiven am Anfang Ihrer C#‑Datei hinzu:

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **Pro‑Tipp:** Zielgerichtet .NET 6 oder höher, um von den neuesten Leistungsverbesserungen in Aspose.Cells zu profitieren.

### 2. Laden der Arbeitsmappe und Auffinden der Pivot‑Tabelle

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*Warum das wichtig ist:* Die Klasse `Workbook` analysiert die XLSX‑Datei und gibt Ihnen Zugriff auf alle Arbeitsblätter. Die Auswahl des richtigen Arbeitsblatts ist entscheidend, da eine Arbeitsmappe mehrere Pivot‑Tabellen enthalten kann.

### 3. Aktualisieren der Pivot‑Tabelle, um die neuesten Quelldaten zu erfassen

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

Durch das Aktualisieren wird sichergestellt, dass alle Änderungen am Quellbereich, die nach dem Speichern der Datei vorgenommen wurden, im gerenderten Bild wiedergegeben werden. Das Überspringen dieses Schritts kann veraltete oder ungenaue Darstellungen erzeugen.

### 4. Konfigurieren der Bild‑Exportoptionen (export pivot table image)

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

Das Objekt `ImageOrPrintOptions` ermöglicht die Steuerung von Format, Auflösung und anderen Render‑Details. PNG ist die gängigste Wahl für scharfe, web‑kompatible Grafiken, aber Sie können zu `ImageFormat.Jpeg` wechseln, wenn die Dateigröße ein Problem darstellt.

### 5. Rendern und **save pivot as image**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

`RenderToImage` übernimmt die schwere Arbeit: Es zeichnet die Pivot‑Tabelle exakt so, wie sie in Excel erscheint, und schreibt die binären PNG‑Daten auf die Festplatte. Die Methode gibt `void` zurück, sodass Sie sicher davon ausgehen können, dass die Datei nach Abschluss des Aufrufs existiert, ohne zusätzliche Prüfungen durchführen zu müssen.

#### Erwartetes Ergebnis

Nach dem Ausführen des Programms finden Sie `Pivot.png` im angegebenen Ordner. Das Öffnen der Datei sollte einen getreuen Schnappschuss der ursprünglichen Pivot‑Tabelle anzeigen, einschließlich Spaltenüberschriften, Zeilensummen und aller angewendeten Formatierungen.

### 6. Häufige Variationen und Randfälle

| Szenario | Anpassung |
|----------|------------|
| **Große Pivot‑Tabellen** (viele Zeilen/Spalten) | Erhöhen Sie `HorizontalResolution` und `VerticalResolution` auf 300 dpi für klarere Ausgabe. |
| **Benutzerdefiniertes Styling** (Hintergrundfarben, Schriften) | Stellen Sie sicher, dass die Stildefinitionen der Arbeitsmappe geladen sind, bevor `Refresh()` aufgerufen wird. |
| **Mehrere Pivot‑Tabellen** in einem Blatt | Durchlaufen Sie `worksheet.PivotTables` und rufen Sie `RenderToImage` für jede auf, wobei Sie unterschiedliche Dateinamen verwenden. |
| **Export nach JPEG** statt PNG | Ändern Sie `ImageFormat = ImageFormat.Jpeg` und setzen Sie optional `Quality` in einem `JpegSaveOptions`‑Objekt. |

Diese Variationen ermöglichen es Ihnen, **export pivot table image** im genauen Format zu exportieren, das Ihr nachgelagertes System erwartet.

## Vollständiger Quellcode für schnelles Kopieren‑Einfügen

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

Das Ausführen des Programms erzeugt die oben gezeigte PNG‑Datei und schließt den **save pivot as image**‑Arbeitsablauf in weniger als einer Minute ab.
