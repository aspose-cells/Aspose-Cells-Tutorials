# Wie man Schriftarten in HTML einbettet, wenn ein Arbeitsbuch gespeichert wird

Wenn Sie **wie man Schriftarten in HTML einbettet** beim Exportieren einer Tabelle, zeigt Ihnen dieses Tutorial eine komplette, sofort einsatzbereite Lösung. Egal, ob Sie ein Reporting‑Portal oder eine clientseitige Analyse‑Ansicht bauen, das Einbetten von Schriftarten stellt sicher, dass das gerenderte HTML exakt wie das ursprüngliche Arbeitsbuch aussieht, unabhängig von den auf dem Rechner des Betrachters installierten Schriftarten.

Sie erfahren außerdem den besten Weg, **Arbeitsbuch als HTML zu speichern** mit Aspose.Cells, sehen häufige Stolperfallen und erhalten Tipps zum Umgang mit großen Arbeitsbüchern oder benutzerdefinierten Schriftdateien. Keine externe Dokumentation nötig – alles, was Sie brauchen, finden Sie in diesem Leitfaden.

## Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie Folgendes haben:

- .NET 6.0 oder höher (der Code funktioniert auch mit .NET Framework 4.7+)
- Eine gültige Aspose.Cells for .NET Lizenz (oder Sie nutzen den kostenlosen Evaluierungsmodus)
- Grundkenntnisse in C# und eine IDE wie Visual Studio 2022
- Die TrueType‑(.ttf) oder OpenType‑(.otf) Schriftdateien, die Sie einbetten möchten (sie müssen für den laufenden Prozess zugänglich sein)

## Schritt 1: Projekt einrichten und Aspose.Cells importieren

Erstellen Sie eine neue Konsolenanwendung und fügen Sie das Aspose.Cells NuGet‑Paket hinzu:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

Öffnen Sie dann **Program.cs** und fügen Sie die erforderlichen `using`‑Direktiven hinzu:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **Pro‑Tipp:** Legen Sie Ihre benutzerdefinierten Schriftarten in einem Ordner namens `fonts` im Projekt‑Root ab. Das macht die Lösung portabel und erleichtert das spätere Referenzieren.

## Schritt 2: Ein Arbeitsbuch erstellen oder laden

Zur Demonstration erstellen wir ein einfaches Arbeitsbuch mit ein paar formatierten Zellen:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **Warum das wichtig ist:** Wenn Sie den benutzerdefinierten Stil weglassen, fällt das exportierte HTML auf die Standardschriftarten des Browsers zurück, was den Zweck von **wie man Schriftarten in HTML einbettet** zunichte macht.

## Schritt 3: `HtmlSaveOptions` konfigurieren, um Schriftarten einzubetten

Der Kern von **wie man Schriftarten in HTML einbettet** liegt in der Klasse `HtmlSaveOptions`. Das Setzen von `EmbedFonts = true` weist Aspose.Cells an, alle referenzierten TrueType/OpenType‑Schriftarten direkt in das erzeugte HTML als Base64‑kodierte Data‑URIs einzubetten.

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### Wie das Einbetten funktioniert

Wenn `EmbedFonts` auf `true` gesetzt ist, durchsucht Aspose.Cells die Stildefinitionen des Arbeitsbuchs, findet die entsprechenden Schriftdateien im System (oder im von Ihnen hinzugefügten `fonts`‑Ordner), liest deren Binärdaten und fügt einen `<style>`‑Block ähnlich dem folgenden ein:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

Da die Schriftartdaten direkt im HTML kodiert sind, wird die Seite korrekt dargestellt, selbst auf Rechnern, auf denen die Schriftart nicht installiert ist.

## Schritt 4: Das Arbeitsbuch als HTML speichern

Jetzt können Sie **Arbeitsbuch als HTML speichern** mit den konfigurierten Optionen. Wählen Sie ein Verzeichnis, in das die Anwendung schreiben darf (z. B. `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

Beim Ausführen des Programms entsteht eine einzelne Datei `report.html`. Öffnen Sie sie in einem modernen Browser und Sie sehen die Überschrift „Quarterly Sales“ mit der **Pacifico**‑Schrift, selbst wenn diese Schrift nicht auf Ihrem Betriebssystem installiert ist.

### Erwartete Ausgabe

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

Das `src:`‑Attribut enthält einen langen Base64‑String – das ist die eingebettete Schriftart, die **wie man Schriftarten in HTML einbettet** ermöglicht.

## Schritt 5: Einbettung prüfen und Fehler beheben

1. **Öffnen Sie die HTML‑Datei in Chrome oder Edge.** Wenn die benutzerdefinierte Schrift erscheint, war das Einbetten erfolgreich.  
2. **Untersuchen Sie den Seitenquelltext.** Suchen Sie nach der von Aspose.Cells erzeugten `@font-face`‑Regel.  
3. **Häufige Probleme:**  
   - *Fehlende Schriftdatei:* Stellen Sie sicher, dass die Schriftdatei erreichbar ist. Sie können explizit einen Ordner zum Suchpfad hinzufügen:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *Große HTML‑Datei:* Das Einbetten vieler Schriftarten kann die Datei aufblähen. Verwenden Sie `ExportToSingleFile = false`, um Schriftarten als separate `.ttf`‑Dateien in einem Ressourcen‑Ordner zu speichern.

   - *Nicht unterstütztes Schriftformat:* Aspose.Cells bettet nur TrueType (`.ttf`) und OpenType (`.otf`) ein. Konvertieren Sie andere Formate vor dem Einbetten.

## Vollständiges funktionierendes Beispiel

Unten finden Sie das komplette Programm, das Sie kopieren, einfügen und ohne Änderungen ausführen können (abgesehen von der optionalen Lizenzzeile).

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

Durch das Ausführen dieses Programms wird `output/report.html` erstellt. Öffnen Sie die Datei und Sie sehen die **Pacifico**‑Schrift korrekt gerendert – das demonstriert **wie man Schriftarten in HTML einbettet**, während man **Arbeitsbuch als HTML speichert**.

## Häufig gestellte Fragen

| Frage | Antwort |
|-------|----------|
| *Kann ich nur bestimmte Schriftarten einbetten?* | Ja. Setzen Sie `htmlOpt.EmbedAllFonts = false` (verfügbar in neueren Versionen) und verwenden Sie `htmlOpt.FontsToEmbed`, um die genauen Schriftartnamen anzugeben. |
| *Was, wenn ich Schriftarten für mehrere Arbeitsblätter einbetten muss?* | Setzen Sie `ExportActiveWorksheetOnly = false`, sodass jedes Arbeitsblatt exportiert wird, und Aspose.Cells bettet die in der gesamten Arbeitsmappe verwendeten Schriftarten ein. |
| *Werden eingebettete Schriftarten in mobilen Browsern funktionieren?* | Moderne mobile Browser unterstützen Base64‑kodierte Schriftarten, sodass die eingebetteten Schriftarten korrekt gerendert werden, solange das Schriftformat unterstützt wird (TTF oder OTF). |
| *Wie groß kann die HTML‑Datei werden?* | Das Einbetten einer 200 KB TrueType‑Schrift fügt etwa die gleiche Menge zur HTML‑Größe hinzu (Base64 erzeugt ca. 33 % Overhead). Bei vielen Schriftarten sollten Sie den Export in einen Ordner (`ExportToSingleFile = false`) erwägen, um das HTML leichtgewichtig zu halten. |
