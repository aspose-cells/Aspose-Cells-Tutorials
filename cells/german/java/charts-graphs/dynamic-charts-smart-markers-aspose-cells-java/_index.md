# Dynamische Diagramme in Java mit der Aspose.Cells-Bibliothek erstellen

## Einleitung
Das Erstellen dynamischer, datengetriebener Diagramme in Excel kann ohne die richtigen Werkzeuge komplex sein. **Aspose.Cells for Java** vereinfacht diesen Prozess mithilfe von Smart Markern – Platzhaltern, die die Datenbindung und Diagrammerstellung automatisieren. In diesem Leitfaden lernen Sie, wie man **dynamische Diagramme in Java erstellt**, Daten mit Smart Markern bindet, Zeichenkettenwerte in numerische Werte umwandelt und programmgesteuert ein Excel-Diagramm erzeugt.

## Schnelle Antworten
- **Was ist der schnellste Weg, ein Diagramm in Java zu erzeugen?** Verwenden Sie Aspose.Cells Smart Marker und die integrierte Diagramm-API.  
- **Benötige ich eine Lizenz für den Produktionseinsatz?** Ja – eine Aspose.Cells-Lizenz entfernt die Evaluationsbeschränkungen.  
- **Kann ich Text automatisch in Zahlen umwandeln?** Rufen Sie `convertStringToNumericValue()` auf der Zellen‑Sammlung des Arbeitsblatts auf.  
- **Welche Diagrammtypen werden unterstützt?** Über 40 Typen, darunter Säulen-, Linien-, Kreis-, Radar- und Börsendiagramme.  
- **Welche Java-Version wird benötigt?** Java 8 oder höher; die Bibliothek ist kompatibel mit Java 11, 17 und neueren Versionen.

## Was ist ein Smart Marker in Aspose.Cells?
Ein Smart Marker ist ein Platzhalter‑Token, das Aspose.Cells während der Verarbeitung durch tatsächliche Daten ersetzt. Er ermöglicht es Ihnen, Vorlagen einmal zu entwerfen und mit jeder Datenquelle wiederzuverwenden, wodurch manuelles Schreiben Zelle für Zelle entfällt. Smart Marker können für Zeilen, Spalten und Diagramme verwendet werden und erweitern Bereiche automatisch basierend auf der Größe der Datenquelle.

## Warum Smart Marker für die Diagrammerstellung verwenden?
Smart Marker reduzieren den Codeumfang um bis zu 80 % und gewährleisten, dass Datenbereiche mit dem Diagramm synchron bleiben. Aspose.Cells verarbeitet Arbeitsblätter mit 100 000 Zeilen in weniger als 30 Sekunden auf einem typischen Server, was es ideal für groß angelegte Berichte macht. Außerdem werden dynamische Bereichsanpassungen automatisch durchgeführt, sodass Diagramme stets die neuesten Daten widerspiegeln, ohne manuelle Aktualisierungen.

### Wie erstellt man dynamische Diagramme in Java mit Aspose.Cells?
Laden Sie eine Arbeitsmappe, fügen Sie Smart Marker ein, verarbeiten Sie die Daten, konvertieren Sie Zeichenketten in Zahlen und fügen Sie schließlich ein Diagramm hinzu. Dieser End‑zu‑End‑Ablauf ermöglicht es Ihnen, vollständig gefüllte Diagramme mit nur wenigen Codezeilen zu erzeugen.

## Arbeitsblatt erstellen und benennen
#### Übersicht
Die Klasse `Workbook` ist das oberste Objekt von Aspose.Cells, das eine Excel‑Datei im Speicher repräsentiert. Sie erstellen eine neue Arbeitsmappe, greifen auf das erste Blatt zu und benennen es zur besseren Übersicht um.

**Implementierungsschritte:**  
1. **Workbook erstellen und auf das erste Blatt zugreifen** –  
   ```java
   import com.aspose.cells.Workbook;
   import com.aspose.cells.Worksheet;

   String dataDir = "YOUR_DATA_DIRECTORY"; // Specify the directory path
   Workbook book = new Workbook();
   Worksheet dataSheet = book.getWorksheets().get(0);
   ```  
2. **Arbeitsblatt zur besseren Übersicht umbenennen** –  
   ```java
   dataSheet.setName("ChartData");
   ```

## Smart Marker in Zellen platzieren
#### Übersicht
Smart Marker fungieren als Platzhalter, die beim Verarbeiten dynamisch durch tatsächliche Daten ersetzt werden.

**Implementierungsschritte:**  
1. **Auf die Zellen‑Sammlung der Arbeitsmappe zugreifen** –  
   ```java
   import com.aspose.cells.Cells;

   Cells cells = dataSheet.getCells();
   ```  
2. **Smart Marker an gewünschten Positionen einfügen** –  
   ```java
   cells.get("A1").putValue("&=$Headers(horizontal)");
   cells.get("A2").putValue("&=$Year2000(horizontal)");
   // Continue for other years as needed
   ```

## Datenquellen für Smart Marker festlegen
#### Übersicht
Definieren Sie Datenquellen, die den Smart Markern entsprechen und während der Verarbeitung verwendet werden.

**Implementierungsschritte:**  
1. **WorkbookDesigner initialisieren** – Die Klasse `WorkbookDesigner` verarbeitet Smart Marker und bindet Datenquellen an die Arbeitsmappe.  
   ```java
   import com.aspose.cells.WorkbookDesigner;

   WorkbookDesigner designer = new WorkbookDesigner();
   designer.setWorkbook(book);
   ```  
2. **Datenquellen für Smart Marker festlegen** –  
   ```java
   String[] headers = { "", "Item 1", "Item 2", "Item 3" /*...*/ };
   String[] year2000 = { "2000", "310", "0", "110" /*...*/ };
   
   designer.setDataSource("Headers", headers);
   designer.setDataSource("Year2000", year2000);
   // Set additional data sources similarly
   ```

## Smart Marker verarbeiten

Nachdem Sie Smart Marker und die zugehörigen Datenquellen eingerichtet haben, verarbeiten Sie sie, um das Arbeitsblatt zu füllen.

**Implementierungsschritte:**  
1. **Smart Marker verarbeiten** –  
   ```java
   designer.process();
   ```

## Zeichenkettenwerte im Arbeitsblatt in numerische Werte umwandeln
#### Übersicht
Bevor Sie Diagramme auf Basis von Zeichenkettenwerten erstellen, konvertieren Sie diese Zeichenketten in numerische Werte für eine genaue Diagrammdarstellung.

**Implementierungsschritte:**  
1. **Zeichenkettenwerte in numerische Werte umwandeln** – `convertStringToNumericValue()` konvertiert Textdarstellungen von Zahlen in Zellen in tatsächliche numerische Werte, wodurch genaue Diagrammberechnungen ermöglicht werden.  
   ```java
   dataSheet.getCells().convertStringToNumericValue();
   ```

## Diagramm hinzufügen und konfigurieren
#### Übersicht
Fügen Sie Ihrer Arbeitsmappe ein neues Diagrammblatt hinzu, konfigurieren Sie dessen Typ, legen Sie den Datenbereich fest und passen Sie das Erscheinungsbild an.

**Implementierungsschritte:**  
1. **Diagrammblatt erstellen und benennen** –  
   ```java
   import com.aspose.cells.SheetType;

   int chartSheetIdx = book.getWorksheets().add(SheetType.CHART);
   Worksheet chartSheet = book.getWorksheets().get(chartSheetIdx);
   chartSheet.setName("Chart");
   ```  
2. **Diagramm hinzufügen und konfigurieren** –  
   ```java
   import com.aspose.cells.Chart;
   import com.aspose.cells.ChartType;
   import com.aspose.cells.Range;

   int chartIdx = chartSheet.getCharts().add(ChartType.COLUMN_STACKED, 0, 0,
       dataSheet.getCells().getMaxDataRow() + 1, dataSheet.getCells().getMaxDataColumn() + 1);
   
   Chart chart = chartSheet.getCharts().get(chartIdx);
   Range dataRange = dataSheet.getCells().createRange(0, 1, 
       dataSheet.getCells().getMaxDataRow() + 1, dataSheet.getCells().getMaxDataColumn());
   chart.setChartDataRange(dataRange.getRefersTo(), false);
   chart.getTitle().setText("Sales Summary");
   
   book.save("GCByPSmartMarkers.xlsx");
   ```
