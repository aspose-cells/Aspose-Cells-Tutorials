# Wie man ein Excel-Arbeitsbuch in Java mit JSON-Daten erstellt

Wenn Sie **create Excel workbook java** benötigen, stehen Entwickler oft vor der Herausforderung, JSON-Daten in ein Tabellenblatt zu laden. Dieser Leitfaden zeigt Ihnen, wie Sie **populate Excel from JSON** durchführen, einschließlich wie Sie **convert JSON array excel** und **populate workbook from json** auf saubere, wiederholbare Weise.

Die Arbeit mit JSON ist üblich, wenn Dienste Daten über REST‑APIs bereitstellen, und Excel bleibt das bevorzugte Format für Berichte und Analysen. Am Ende dieses Tutorials haben Sie ein ausführbares Java‑Programm, das:

* ein neues Excel-Arbeitsbuch erstellt,
* ein JSON-Array (oder jede JSON-Struktur) liest und dessen Werte in Zellen schreibt,
* die Datei auf dem Datenträger speichert, bereit für die Weiterverarbeitung.

Keine externen Werkzeuge sind erforderlich, außer der Aspose.Cells for Java‑Bibliothek, die den im Beispielcode verwendeten `SmartMarkerProcessor` bereitstellt.

## Voraussetzungen

Stellen Sie vor dem Start sicher, dass Sie Folgendes haben:

| Prerequisite | Reason |
|--------------|--------|
| Java Development Kit (JDK) ≥ 8 | Erforderlich, um das Beispiel zu kompilieren und auszuführen |
| Maven or Gradle (optional) | Vereinfacht die Verwaltung von Abhängigkeiten |
| Aspose.Cells for Java (v23.10 or later) | Stellt die Klassen `Workbook` und `SmartMarkerProcessor` bereit |
| Basic knowledge of JSON and Java I/O | Hilft Ihnen, den Datenfluss zu verstehen |

Wenn Sie kein Build‑Tool verwenden möchten, können Sie das Aspose.Cells‑JAR von der [Aspose-Website](https://products.aspose.com/cells/java/) herunterladen und manuell zum Klassenpfad Ihres Projekts hinzufügen.

## Schritt 1: Projekt einrichten und die Aspose.Cells‑Abhängigkeit hinzufügen

### Maven‑Benutzer

Fügen Sie die folgende Abhängigkeit zu Ihrer `pom.xml` hinzu:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Gradle‑Benutzer

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

Wenn Sie kein Build‑Tool verwenden, legen Sie das heruntergeladene JAR im Ordner `libs/` ab und fügen Sie es beim Kompilieren dem Klassenpfad hinzu:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## Schritt 2: Neues Arbeitsbuch erstellen und den SmartMarker‑Prozessor konfigurieren

Der `SmartMarkerProcessor` vereinfacht das Zuordnen von JSON‑Werten zu Excel‑Zellen. Durch Aufruf von `setArrayAsSingle(true)` teilen wir dem Prozessor mit, ein gesamtes JSON‑Array als einzelnen Wert zu behandeln, was nützlich ist, wenn jedes Element seine eigene Zelle in einer Zeile einnehmen soll.

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**Warum das wichtig ist:**  
Das vorherige Erstellen des Arbeitsbuchs gibt Ihnen eine leere Leinwand. Durch Konfiguration von `setArrayAsSingle(true)` wird verhindert, dass der Prozessor das Array zu einem einzelnen String (z. B. `["A","B","C"]`) zusammenfasst und ermöglicht stattdessen die manuelle Steuerung des Layouts.

## Schritt 3: Definieren Sie die JSON‑Daten, die Sie einfügen möchten

Für dieses Tutorial verwenden wir ein einfaches JSON‑Array, aber derselbe Ansatz funktioniert mit Objekten, verschachtelten Arrays oder komplexen Strukturen.

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**Tipp:** Wenn Ihr JSON aus einer Datei oder einem REST‑Endpunkt stammt, ersetzen Sie den Literal‑String durch einen `String`, der aus der Quelle gelesen wird, z. B. `Files.readString(Paths.get("data.json"))`.

## Schritt 4: Das Arbeitsbuch mit den JSON‑Daten verarbeiten

Jetzt lassen wir den `SmartMarkerProcessor` das JSON‑Array auf das erste Arbeitsblatt abbilden. Das Standardverhalten schreibt jedes Element in aufeinanderfolgende Zellen beginnend bei `A1`.

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

Im Hintergrund analysiert Aspose.Cells das JSON, erstellt eine temporäre Datentabelle und schreibt die Werte in das Arbeitsblatt. Da wir `ArrayAsSingle` auf `true` gesetzt haben, werden die Array‑Elemente horizontal über die erste Zeile verteilt.

## Schritt 5: Das Arbeitsbuch in einer Datei speichern

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

Wenn Sie das Programm ausführen, sollten Sie eine Datei namens **CreatedFromJson.xlsx** in Ihrem Arbeitsverzeichnis sehen. Öffnen Sie sie mit Excel (oder einem kompatiblen Viewer), wird angezeigt:

| A | B | C |
|---|---|---|
| A | B | C | *(Werte erscheinen in den Zellen A1, B1, C1)*

### Erwartete Ausgabe

```
Workbook saved to CreatedFromJson.xlsx
```

Und das Excel‑Blatt sieht folgendermaßen aus:

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## Schritt 6: Umgang mit komplexeren JSON‑Strukturen (optional)

### 6.1 Ein Arbeitsbuch aus einem JSON‑Objekt befüllen

Wenn Ihr JSON ein Objekt statt eines Arrays ist, können Sie weiterhin `SmartMarkerProcessor` verwenden. Zum Beispiel:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

Der Prozessor erstellt benannte Bereiche (`title`, `month`, `values`), die Sie in Ihrer Excel‑Vorlage mithilfe von Smart Markern wie `&=title` und `&=values` referenzieren können.

### 6.2 Konvertieren eines verschachtelten JSON‑Arrays in eine vertikale Liste

Manchmal muss das Array eine Spalte statt einer Zeile füllen. Setzen Sie die Startzelle vor der Verarbeitung manuell:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

Jetzt erscheinen die Werte **A**, **B**, **C** in den Zellen A2, A3, A4.

## Häufige Fallstricke und wie man sie vermeidet

| Issue | Cause | Fix |
|-------|-------|-----|
| **Array als einzelner String geschrieben** | `setArrayAsSingle(false)` (default) | Call `processor.setArrayAsSingle(true)` |
| **Datei beim Speichern nicht gefunden** | Ungültiger Pfad oder fehlende Schreibberechtigungen | Verwenden Sie einen absoluten Pfad oder stellen Sie sicher, dass das Verzeichnis existiert |
| **JSON‑Parsing‑Fehler** | Fehlerhafter JSON‑String | Validieren Sie JSON mit einem Tool oder verwenden Sie eine Bibliothek wie Jackson, um den String zu erzeugen |
| **Zellen unbeabsichtigt überschrieben** | Verarbeitung desselben Arbeitsblatts mehrmals ohne Zurücksetzen der Startzelle | Rufen Sie `processor.setStartCell("A1")` vor jedem `process`‑Aufruf auf |

## Profi‑Tipp: Arbeitsbuch als Vorlage wiederverwenden

Anstatt jedes Mal ein leeres Arbeitsbuch zu beginnen, können Sie eine vorgefertigte Vorlage laden, die bereits Kopfzeilen, Formeln oder Formatierungen enthält:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

Dieser Ansatz kombiniert die optische Qualität einer handgefertigten Excel‑Datei mit der Automatisierung von **populate workbook from json**.
