# Benutzerdefinierte Objekte in Excel importieren mit Aspose.Cells – Java‑Leitfaden

Wenn Sie **benutzerdefinierte Objekte** in ein Excel‑Arbeitsblatt importieren müssen, führt Sie diese Anleitung durch den gesamten Prozess mit Aspose.Cells für Java. Sie sehen, wie Sie **Daten nach Excel importieren**, einen fetten Kopfzeilenstil anwenden und eine sofort teilbare `.xlsx`‑Datei erzeugen.

Das Exportieren tabellarischer Daten aus Java erfordert häufig manuelle Zell‑für‑Zell‑Schreibvorgänge, was fehleranfällig und schwer zu warten ist. Durch die Nutzung der `importCustomObjects`‑API vermeiden Sie Boilerplate‑Code, behalten Ihr Datenmodell unverändert bei und erhalten eine feinkörnige Steuerung der Formatierung.

In diesem Tutorial werden Sie:

* Eine Liste von Java `Map`‑Objekten erstellen, die einer typischen Datentabelle ähnelt.
* Einen wiederverwendbaren Kopfzeilenstil (fette Schrift) mit Aspose.Cells erstellen.
* Die benutzerdefinierten Objekte in ein Arbeitsblatt importieren und dabei das Stil‑Array anwenden.
* Die Arbeitsmappe auf die Festplatte speichern und das Ergebnis überprüfen.

Die einzige Voraussetzung ist eine Java‑Entwicklungsumgebung (empfohlen JDK 8 +) und die Aspose.Cells‑Bibliothek für Java.

---

## Was Sie benötigen

| Anforderung | Grund |
|-------------|-------|
| JDK 8 oder neuer | Erforderlich, um den Java‑Code zu kompilieren und auszuführen. |
| Aspose.Cells für Java (neueste Version) | Stellt die `Workbook`-, `Worksheet`- und Import‑APIs bereit. |
| IDE oder Build‑Tool (z. B. Maven, Gradle) | Vereinfacht die Verwaltung von Abhängigkeiten und die Ausführung. |
| Schreibberechtigung für einen Ordner für die Ausgabedatei | Die Arbeitsmappe wird als `ImportWithStyle.xlsx` gespeichert. |

Fügen Sie die Aspose.Cells‑Abhängigkeit zu Ihrer `pom.xml` hinzu, wenn Sie Maven verwenden:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## Schritt 1: Die zu importierenden benutzerdefinierten Objekte vorbereiten

Der erste Schritt besteht darin, eine Sammlung zu erstellen, die die Zeilen repräsentiert, die Sie in Excel platzieren möchten. In diesem Beispiel verwenden wir ein `List<Map<String,Object>>`, wobei jede Map wie eine Zeile mit Spaltennamen als Schlüssel fungiert.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Warum das wichtig ist:**  
`importCustomObjects` erwartet ein Array von Objekten. Durch die Verwendung einer `Map` behalten Sie die Spaltennamen bei, sodass Aspose.Cells sie automatisch den Zellen zuordnen kann. Dieser Ansatz spiegelt eine typische `DataTable` in .NET oder ein `ResultSet` aus JDBC wider und macht den Code projektübergreifend wiederverwendbar.

---

## Schritt 2: Einen Kopfzeilenstil für den Import definieren

Eine klare Kopfzeile verbessert die Lesbarkeit. Aspose.Cells ermöglicht das Erstellen eines `Style`‑Objekts, das Setzen einer fetten Schrift und das Übergeben über ein `ImportTableOptions`‑Array.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Warum das wichtig ist:**  
Wenn Sie das Stil‑Array weglassen, erscheint die Kopfzeile in der Standardschrift, die möglicherweise nicht hervorsticht. Durch die einmalige Vorbereitung des Stils vermeiden Sie wiederholte Aufrufe für jede Zeile und halten die Import‑Logik sauber.

---

## Schritt 3: Die benutzerdefinierten Objekte mit dem Stil‑Array importieren

Jetzt kombinieren Sie die Daten und den Stil und rufen `importCustomObjects` auf. Die Methode platziert die Daten beginnend in der oberen linken Ecke (Zeile 0, Spalte 0) und wendet den Kopfzeilenstil automatisch an.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Warum das wichtig ist:**  
`importCustomObjects` analysiert jede Map, erstellt Spalten basierend auf den Schlüsseln (`Name`, `Score`) und schreibt die Werte in die entsprechenden Zellen. Das `ImportTableOptions`‑Objekt weist Aspose.Cells an, das `styleArray` für die erste Zeile zu verwenden, sodass Sie eine fette Kopfzeile ohne zusätzlichen Code erhalten.

---

## Schritt 4: Die Arbeitsmappe speichern und die Ausgabe überprüfen

Abschließend schreiben Sie die Arbeitsmappe in eine Datei. Die erzeugte Excel‑Datei enthält eine formatierte Kopfzeile, gefolgt von den Datenzeilen.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Erwartetes Ergebnis:**  

| **Name** | **Score** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

Die Kopfzeilenzellen (`Name`, `Score`) erscheinen in fetter Schrift, entsprechend dem in Schritt 2 definierten Stil.

## Häufige Variationen und Sonderfälle

| Situation | Empfohlene Anpassung |
|-----------|----------------------|
| **Andere Spaltenreihenfolge** | Stellen Sie sicher, dass die `Map`‑Schlüssel in der gewünschten Reihenfolge eingefügt werden, oder verwenden Sie ein benutzerdefiniertes POJO mit annotierten Feldern und einem `PropertyDescriptor`‑Array. |
| **Große Datenmengen (>10 000 Zeilen)** | Erhöhen Sie `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)`, um `OutOfMemoryError` zu vermeiden. |
| **Benutzerdefinierte Zahlenformate** | Fügen Sie ein zweites `Style` im `styleArray` für die Datenzeilen hinzu, z. B. `NumberFormat` auf `"0"` setzen für ganzzahlige Werte. |
| **Mehrere Arbeitsblätter** | Rufen Sie `importCustomObjects` für jedes Ziel‑Worksheet auf und passen Sie die Start‑Zeile/Spalte nach Bedarf an. |
| **Lokalspezifischer Kopfzeilentext** | Befüllen Sie die Kopfzeile manuell vor dem Import und wenden Sie dann den Stil auf den gesamten Bereich mit `Cells.applyStyle` an. |

---

## Profi‑Tipps für einen robusten Java‑Export nach Excel

* **Temporäre Arbeitsmappe wiederverwenden** – Das Erstellen einer neuen `Workbook`‑Instanz für jeden Stil verursacht zusätzlichen Aufwand. Behalten Sie eine einzelne Instanz, wenn Sie mehrere Stile benötigen.  
* **Daten vor dem Import validieren** – Null‑Werte in einer Map werden zu leeren Zellen; Sie können sie durch Vorgabewerte ersetzen, indem Sie die Liste vorher verarbeiten.  
* **Ressourcen schließen** – Obwohl Aspose.Cells den Speicher intern verwaltet, sollte `workbook.dispose()` nach dem Speichern explizit aufgerufen werden, um native Ressourcen sofort freizugeben.  
* **`Workbook.setForceFullCalculation(true)` setzen** – Falls Ihre Arbeitsmappe Formeln enthält, die vor dem Speichern ausgewertet werden müssen.
