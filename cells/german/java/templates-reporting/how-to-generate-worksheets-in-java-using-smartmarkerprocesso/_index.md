# Wie man Arbeitsblätter in Java mit SmartMarkerProcessor erzeugt

Wenn Sie **wie man Arbeitsblätter erzeugt** in einer Excel-Datei benötigen, zeigt Ihnen dieser Leitfaden eine komplette, sofort einsatzbereite Lösung. Am Ende der ersten beiden Sätze verstehen Sie, wie man Arbeitsblätter und dynamische Excel‑Sheets aus einer Sammlung von Objekten erzeugt, und Sie haben ein funktionierendes Code‑Beispiel, das die Excel‑Erstellung mit einem einzigen Methodenaufruf automatisiert.

Das Erstellen separater Arbeitsblätter für jeden Mitarbeiter, jedes Projekt oder jede andere Entität ist eine häufige Anforderung, wenn Sie **populate excel workbook** Daten programmgesteuert befüllen müssen. Dieses Tutorial führt Sie durch jeden Schritt – vom Einrichten der Vorlage über die Verarbeitung einer Liste bis zum Speichern der endgültigen Datei – sodass Sie die Technik sofort in Ihren eigenen Java‑Anwendungen anwenden können.

## Was Sie erreichen werden

* Erzeugen Sie ein Master‑Arbeitsblatt, das hochrangige Informationen auflistet.  
* Erstellen Sie **multiple sheets from list** Daten, wobei jedes Blatt automatisch benannt wird.  
* **Automate excel creation** ohne manuelles Hinzufügen von Zeilen oder Spalten.  
* **Populate excel workbook** mit reichhaltigen Datenstrukturen (Objekte, Maps, Arrays).  

Voraussetzungen:

* Java 8 oder neuer installiert.  
* Maven (oder ein anderes Build‑Tool), um die Aspose.Cells for Java‑Bibliothek hinzuzufügen.  
* Grundlegendes Verständnis von Java‑Collections.  

> **Profi‑Tipp:** Die SmartMarker‑Syntax (`${EmployeeMaster}`) funktioniert mit jedem Collection‑Typ, der `java.util.Collection` implementiert. Verwenden Sie sie, um Ihre Vorlagen sauber und wartbar zu halten.

## Wie man Arbeitsblätter mit SmartMarkerProcessor erzeugt

Dieser Abschnitt enthält den Kerncode, der **wie man Arbeitsblätter erzeugt** mühelos macht. Wir erklären, warum jede Zeile wichtig ist, nicht nur was sie tut.

### Schritt 1: Aspose.Cells‑Abhängigkeit hinzufügen

Wenn Sie Maven verwenden, fügen Sie das Folgende in Ihre `pom.xml` ein. Die Bibliothek stellt die `SmartMarkerProcessor`‑Klasse bereit, die in diesem Leitfaden durchgehend verwendet wird.

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **Warum:** Aspose.Cells übernimmt Excel‑Datei‑I/O, Smart‑Marker‑Parsing und Blattverwaltung intern, sodass Sie sich auf Daten statt auf low‑level Dateioperationen konzentrieren können.

### Schritt 2: Die Excel‑Vorlage vorbereiten

Erstellen Sie eine Excel‑Datei namens `EmployeeTemplate.xlsx` mit einer einzigen Zelle, die den Smart‑Marker‑Platzhalter enthält:

| A |
|---|
| `${EmployeeMaster}` |

Wenn der Prozessor ausgeführt wird, ersetzt er diesen Platzhalter durch ein **detail sheet**, das eine Zeile pro Mitarbeiter enthält.

> **Warum:** Der Platzhalter sagt dem Prozessor, wo die Daten eingefügt werden sollen. Die Verwendung einer separaten Vorlage bewahrt Ihre Formatierung (Schriftarten, Rahmen, Spaltenbreiten).

### Schritt 3: Das Datenmodell definieren

Unten finden Sie eine minimale `Employee`‑Klasse und eine Hilfsmethode, die eine Liste von Mitarbeitern erstellt. Die Liste wird verwendet, um **multiple sheets from list** zu demonstrieren.

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **Warum:** Ein einfaches Java‑Objekt (POJO) wird direkt den Smart‑Marker‑Feldern (`firstName`, `lastName`, `department`) zugeordnet. Das macht **populate excel workbook** unkompliziert und typensicher.

### Schritt 4: Den SmartMarkerProcessor einrichten

Jetzt verbinden wir alles. Der Prozessor liest die Vorlage, ersetzt den Marker und erstellt ein neues Blatt namens `EmployeeDetail`.

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

**Erklärung der wichtigsten Zeilen**

| Zeile | Grund |
|------|--------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | Lädt die Vorlage, die bereits den Smart‑Marker‑Platzhalter enthält. |
| `data.put("EmployeeMaster", employees);` | Bindet die Java‑Liste an den Marker `${EmployeeMaster}`. |
| `processor.setDetailSheetNewName("EmployeeDetail");` | Gibt dem erzeugten Blatt einen aussagekräftigen Namen anstelle des Standard‑`Sheet1`. |
| `processor.process(wb, data);` | **How to generate worksheets** – der Prozessor liest den Marker, erstellt ein neues Blatt und füllt es mit Zeilen für jeden `Employee`. |
| `wb.save("EmployeesReport.xlsx");` | Speichert die **dynamic excel sheets** auf die Festplatte. |

### Schritt 5: Die Ausgabe überprüfen

Öffnen Sie `EmployeesReport.xlsx`. Sie sollten zwei Arbeitsblätter sehen:

1. **Sheet1** – die ursprüngliche Vorlage (kann ausgeblendet oder entfernt werden).  
2. **EmployeeDetail** – ein **dynamic excel sheet** mit den Spalten `firstName`, `lastName`, `department` und einer Zeile pro Mitarbeiter.

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **Warum das wichtig ist:** Die Datei enthält jetzt **multiple sheets from list** ohne manuelles Durchlaufen oder Zelladressierung. Die Smart‑Marker‑Engine übernimmt die Zeilenerstellung, Datenkonvertierung und Vererbung der Formatierung.

### Schritt 6: Randfälle behandeln

#### Leere Datenliste

Wenn `employees` leer ist, erstellt der Prozessor weiterhin das Blatt `EmployeeDetail`, lässt es jedoch leer. Sie können das Hinzufügen des Blatts verhindern, indem Sie die Größe der Collection vor der Verarbeitung prüfen:

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### Sehr große Listen

Für tausende Zeilen sollten Sie die Speicherzuweisung (`-Xmx2g`) erhöhen oder `processor.setAutoFitRows(false)` verwenden, um die Verarbeitung zu beschleunigen.

#### Benutzerdefinierte Blattnamen pro Gruppe

Wenn Sie ein separates Blatt für jede Abteilung benötigen, können Sie **multiple detail sheets** verwenden:

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

Der Platzhalter `${department}` wird aus jedem `Employee`‑Objekt entnommen und erzeugt Blätter wie `Dept_Sales`, `Dept_Marketing` usw.
