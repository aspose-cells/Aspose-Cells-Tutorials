# Detailblätter in Java mit Aspose.Cells Smart Markers erstellen

Wenn Sie **Detailblätter** in einer Java-Anwendung erstellen müssen, zeigt Ihnen dieses Tutorial, wie Sie dies mit Aspose.Cells Smart Markers tun. Sie sehen ein vollständiges, ausführbares Beispiel, das **java create worksheets**, den **sheet name from field** ableitet und **process data source** in nur wenigen Codezeilen verarbeitet.

Der Leitfaden deckt alles von der Projektkonfiguration bis zum Speichern der finalen Arbeitsmappe ab, sodass Sie die Lösung einfach per Kopieren‑Einfügen in Ihr eigenes Projekt übernehmen und sofort anpassen können. Keine externe Dokumentation ist erforderlich – alles, was Sie benötigen, finden Sie hier.

## Was Sie lernen werden

* Wie man **smart markers verwendet**, um ein Vorlagen‑Arbeitsblatt für jede Zeile eines Master‑Datensatzes zu duplizieren.  
* Wie man den Namen jedes neuen Blatts dynamisch basierend auf einem Feldwert festlegt (z. B. `Order_123`).  
* Wie man eine Java‑Collection als **process data source** für die Smart‑Marker‑Engine bereitstellt.  
* Tipps zum Umgang mit Sonderfällen wie leeren Daten, Sonderzeichen in Blattnamen und Leistungsüberlegungen bei großen Datensätzen.

### Voraussetzungen

| Anforderung | Grund |
|-------------|--------|
| Java 8 oder höher | Aspose.Cells für Java unterstützt Java 8+. |
| Maven- oder Gradle-Buildsystem | Vereinfacht das Hinzufügen der Aspose.Cells‑Abhängigkeit. |
| Grundkenntnisse von Java‑Collections | Erforderlich, um die Datenquelle für die Smart Markers zu erstellen. |
| Eine Excel‑Vorlagendatei (`Template.xlsx`) mit einem Platzhalter‑Smart‑Marker in Zelle **A1** | Die Vorlage steuert die Erstellung der Detailblätter. |

> **Pro Tipp:** Bewahren Sie die Vorlagen‑Arbeitsmappe im `resources`‑Ordner des Projekts auf, damit sie mit Ihrem JAR gepackt wird.

## Schritt 1: Aspose.Cells zu Ihrem Projekt hinzufügen (java create worksheets)

Wenn Sie **Maven** verwenden, fügen Sie die folgende Abhängigkeit zu `pom.xml` hinzu:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

Für **Gradle** fügen Sie diese Zeile in `build.gradle` ein:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

Diese Zeilen stellen die **java create worksheets** APIs zur Compile‑Zeit bereit.

## Schritt 2: Die Vorlagen‑Arbeitsmappe laden

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*Warum das wichtig ist:* Das `Workbook`‑Objekt ist der Einstiegspunkt für alle Excel‑Operationen. Das Laden der Vorlage stellt sicher, dass Sie mit dem korrekten Layout und allen vordefinierten Formatierungen beginnen.

## Schritt 3: Einen Smart Marker einfügen, der pro Master‑Zeile ein neues Blatt erstellt (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

Die Syntax `${Orders:DetailSheetNewName=Order_${OrderId}}` ist das Kernstück von **use smart markers**. Sie erledigt drei Dinge:

1. Durchläuft die `Orders`‑Collection.  
2. Erstellt für jedes Element ein **new worksheet**.  
3. Setzt den **sheet name from field** `OrderId` (vorangestellt mit `Order_`).

## Schritt 4: Die Datenquelle vorbereiten (process data source)

Unten finden Sie ein minimales Beispiel, das eine `List<Map<String, Object>>` verwendet. Ersetzen Sie es durch Ihre reale Datenquelle – Datenbankzeilen, JSON‑Deserialisierung usw.

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*Warum das wichtig ist:* Der **process data source**‑Schritt bindet Ihre Java‑Collection an die Smart‑Marker‑Engine. Der Schlüssel (`"Orders"`) muss exakt dem Namen des Smart Markers entsprechen.

## Schritt 5: Die Smart Marker verarbeiten (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

Wenn `process` ausgeführt wird, liest Aspose.Cells die `Orders`‑Collection, klont das Vorlagen‑Arbeitsblatt für jeden Eintrag und benennt jedes Blatt gemäß dem Feld `OrderId` um. Das ist das Kernstück der Nutzung von **process data source**.

## Schritt 6: Die Arbeitsmappe mit duplizierten Detailblättern speichern

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

Nach der Ausführung finden Sie `DuplicatedDetailSheets.xlsx` mit folgendem Inhalt:

* `Sheet1` – die ursprüngliche Vorlage (unverändert).  
* `Order_101` – Detailblatt für die erste Bestellung.  
* `Order_102` – Detailblatt für die zweite Bestellung.

### Erwartete Ausgabe (Auszug)

| Blattname | A1 (smart marker) | Ergebnisinhalt |
|------------|-------------------|-------------------|
| Order_101  | `${Orders:...}`   | Mit Daten aus `order1` gefüllt |
| Order_102  | `${Orders:...}`   | Mit Daten aus `order2` gefüllt |

Öffnen Sie die Datei in Excel, um zu überprüfen, dass jedes Blatt korrekt benannt ist und die Datenzeilen enthält.

## Umgang mit gängigen Variationen und Sonderfällen

### Leere Datenquelle

Wenn `orders` leer ist, erzeugt der Smart‑Marker‑Prozessor **keine neuen Arbeitsblätter**. Um eine leere Arbeitsmappe zu vermeiden, fügen Sie eine Prüfung hinzu:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### Sonderzeichen in Blattnamen

Excel‑Blattnamen dürfen `\ / ? * [ ] :` nicht enthalten. Bereinigen Sie das Feld, bevor Sie es verwenden:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### Große Datensätze

Bei tausenden Zeilen sollten Sie den JVM‑Heap erhöhen (`-Xmx2g`) und `workbook.calculateFormula()` erst aufrufen, nachdem alle Blätter erzeugt wurden, um die Leistung zu verbessern.
