# C#로 Excel을 HTML로 저장할 때 글꼴을 포함하는 방법

Excel 워크북을 HTML로 저장할 때 글꼴을 포함하는 것은 브라우저 간에 스프레드시트의 정확한 모양을 유지하기 위한 일반적인 요구 사항입니다. 원본 서체를 유지하면서 Excel을 HTML로 내보내야 한다면, 이 가이드는 완전하고 바로 실행할 수 있는 솔루션을 보여줍니다.

여러분은 **export Excel to HTML**, **convert Excel to HTML** 를 글꼴 포함으로 수행하는 방법과 클라이언트 머신에서 레이아웃을 깨뜨리는 일반적인 “missing‑font” 문제를 피하는 방법을 배우게 됩니다. 외부 도구는 필요 없으며, Aspose.Cells 라이브러리와 몇 줄의 C# 코드만 있으면 됩니다.

## 사전 요구 사항

* .NET 6.0 (또는 이후 버전) 설치.
* **Aspose.Cells for .NET** 라이선스 사본 – 무료 체험판으로 테스트 가능.
* Visual Studio 2022 또는 VS Code와 같은 IDE.

이미 준비되어 있다면 바로 코드로 넘어갈 수 있습니다.

## 단계 1: 워크북 생성 및 샘플 데이터 추가

먼저 작은 워크북을 생성하여 글꼴 포함 효과를 확인할 수 있도록 합니다. 아래 코드는 워크시트를 만들고, 몇 개의 셀에 값을 쓰며, 사용자 정의 글꼴을 적용합니다.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### 사용자 정의 글꼴을 추가하는 이유

글꼴을 포함하는 것은 워크북이 클라이언트 장치에 없을 수 있는 글꼴을 사용할 때만 의미가 있습니다. **Arial**(또는 다른 글꼴)을 명시적으로 설정함으로써 HTML 출력에 실제로 글꼴 데이터가 포함되었는지 확인할 수 있습니다.

## 단계 2: HTML 저장 옵션을 구성하여 글꼴 포함

Aspose.Cells는 `HtmlSaveOptions` 클래스를 제공합니다. `EmbedFonts = true` 로 설정하면 라이브러리가 필요한 글꼴 파일을 Base64‑인코딩된 데이터 URI 형태로 직접 생성된 HTML에 포함하도록 지시합니다.

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### “embed fonts in html”이 실제로 하는 일

`EmbedFonts`가 true이면 Aspose.Cells는 시스템(또는 워크북에 포함된 글꼴 컬렉션)에서 글꼴 파일을 추출하여 **Base64** 문자열로 변환합니다. 그런 문자열은 `@font-face`를 사용하여 `<style>` 블록 안에 삽입됩니다. 결과 HTML은 원본 글꼴이 설치되지 않은 장치에서도 열 수 있습니다.

## 단계 3: 워크북을 글꼴 포함 HTML로 저장

이제 워크북을 디스크에 저장합니다. 파일에 글꼴 데이터가 포함되므로 최신 브라우저에서 열면 원본 Excel 파일과 동일한 타이포그래피가 표시됩니다.

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### 예상 결과

* `embedded.html` 파일이 `output` 폴더에 위치합니다.
* Chrome, Edge, Firefox 중 하나로 파일을 열면 브라우저 머신에 Arial이 없더라도 워크시트가 **Arial** 텍스트로 표시됩니다.
* HTML 소스를 검사하면 긴 `src: url(data:font/ttf;base64,…)` 선언을 포함한 `@font-face` 규칙이 들어 있는 `<style>` 블록을 확인할 수 있습니다 – 이것이 포함된 글꼴입니다.

## 단계 4: 다른 머신에서 HTML 작동 확인 (선택 사항)

글꼴 포함이 성공했는지 확실히 확인하려면:

1. `output/embedded.html` 파일을 사용자 정의 글꼴이 설치되지 않은 다른 컴퓨터(또는 가상 머신)로 복사합니다.
2. 브라우저에서 파일을 엽니다.
3. 레이아웃과 타이포그래피가 원본 Excel 화면과 일치해야 합니다.

글꼴이 일반 글꼴로 대체된다면, 빌드 머신에서 글꼴 파일에 접근 가능하고 읽을 권한이 있는지 다시 확인하십시오.

## 일반적인 질문 및 엣지 케이스

### 포함으로 파일 크기가 증가하나요?

예. TrueType 또는 OpenType 글꼴을 포함하면 HTML 파일에 **수십 킬로바이트** 정도가 추가될 수 있습니다. 많은 고유 글꼴을 사용하는 대형 워크북의 경우 다음을 고려하십시오:

* 글꼴 서브셋팅(사용하는 문자만 포함) – Aspose.Cells는 대부분의 일반 글꼴에 대해 자동으로 수행합니다.
* 이미지를 포함할 필요가 없으면 `ExportEmbeddedImages = false` 를 사용합니다.

### 특정 글꼴만 포함해야 하면 어떻게 하나요?

`HtmlSaveOptions`는 직접적인 화이트리스트를 제공하지 않지만, `Save` 호출 전에 **워크북에서 사용되는 글꼴을 제한**함으로써 포함되는 글꼴을 제어할 수 있습니다. 불필요한 글꼴 할당을 제거하거나 표준 웹 안전 글꼴로 교체하십시오.

### 다른 형식(예: PDF)으로 변환할 때도 글꼴을 포함할 수 있나요?

`PdfSaveOptions`에도 동일한 `EmbedFonts` 속성이 있습니다. 개념은 동일하며, 글꼴 데이터가 포함되어 PDF가 어떤 뷰어에서도 올바르게 렌더링됩니다.

## 전체 실행 가능한 예제

아래는 새 콘솔 프로젝트에 복사‑붙여넣기 할 수 있는 전체 프로그램입니다.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

프로그램을 실행하면 **Arial 글꼴이 포함된 HTML 파일**이 생성되어 파일이 열리는 모든 곳에서 시각적 일관성을 보장합니다.

## 결론

이제 C#를 사용하여 Excel을 HTML로 저장할 때 **글꼴을 포함하는 방법**을 알게 되었습니다. `HtmlSaveOptions.EmbedFonts = true` 를 설정하면 클라이언트 측에서 글꼴이 누락되는 문제 없이 **export Excel to HTML** 및 **convert Excel to HTML** 를 안정적으로 수행할 수 있습니다. 이 기술은 웹 기반 보고서, 이메일 친화적인 대시보드, 또는 Excel에서 파생된 콘텐츠를 HTML로 공유하는 모든 시나리오에 필수적입니다.
