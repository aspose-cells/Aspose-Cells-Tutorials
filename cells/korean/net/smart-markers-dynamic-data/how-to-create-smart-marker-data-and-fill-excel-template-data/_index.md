# 스마트 마커 데이터를 생성하고 Excel 템플릿 데이터를 채우는 방법

Excel 워크북에 **스마트 마커 데이터**를 생성해야 한다면, Aspose.Cells 스마트 마커를 사용하면 손쉽게 할 수 있습니다. 이 튜토리얼에서는 몇 줄의 C# 코드로 **Excel 템플릿 데이터를 채우는** 방법을 보여줍니다.

템플릿에 Smart Marker 태그를 삽입하고, 데이터 소스를 제공하며, 프로세서를 실행하고, 채워진 파일을 저장하는 방법을 배웁니다. 외부 도구는 필요 없으며, Aspose.Cells for .NET과 기본 C# 프로젝트만 있으면 됩니다.

## 필요 사항

- .NET 6.0 이상 (코드는 .NET Framework 4.7+에서도 작동합니다)
- Aspose.Cells for .NET (NuGet 패키지 `Aspose.Cells`)
- `${Comment:fieldName}`와 같은 Smart Marker 태그가 포함된 Excel 워크북
- C# IDE (Visual Studio, Rider, 또는 VS Code)

> **프로 팁:** 파일을 찾을 수 없음 오류를 방지하려면 워크북을 프로젝트와 같은 폴더에 두거나 절대 경로를 사용하세요.

## Aspose.Cells를 사용하여 스마트 마커 데이터 생성하기

솔루션의 핵심은 `SmartMarkerProcessor`입니다. 이 프로세서는 워크시트에서 태그를 스캔하고, 데이터 소스에서 일치하는 값을 가져와 시트에 다시 씁니다.

```csharp
using Aspose.Cells;
using System;

// 1️⃣ Load the workbook that contains Smart Marker tags.
Workbook workbook = new Workbook("Template.xlsx");

// 2️⃣ Get the worksheet where the tags reside.
Worksheet ws = workbook.Worksheets[0];

// 3️⃣ Prepare the data source that supplies values for the markers.
var dataSource = new[]
{
    new { fieldName = "Sample comment text generated by C#." }
};

// 4️⃣ Create a SmartMarkerProcessor instance.
SmartMarkerProcessor processor = new SmartMarkerProcessor();

// 5️⃣ Process the worksheet, replacing Smart Marker tags with data from the source.
processor.Process(ws, dataSource);

// 6️⃣ Save the populated workbook.
workbook.Save("Result.xlsx");
```

### 각 라인이 중요한 이유

1. **워크북 로드**는 프로세서가 작업할 구체적인 파일을 제공합니다.  
2. **워크시트 선택**은 프로세서가 올바른 시트를 스캔하도록 보장합니다; 인덱스나 이름으로 원하는 시트를 지정할 수 있습니다.  
3. **데이터 소스**는 익명 객체 배열입니다. 각 속성 이름(`fieldName`)은 `${Comment:fieldName}` 내부의 마커 이름과 일치해야 합니다.  
4. `SmartMarkerProcessor`는 태그를 구문 분석하고 교체를 수행하는 엔진입니다.  
5. `Process`는 핵심 작업을 수행합니다: 모든 `${...}` 태그를 읽고, 데이터 소스에서 일치하는 속성을 찾아 셀에 값을 씁니다.  
6. **워크북 저장**은 업데이트된 파일을 디스크에 저장하여 이후 사용을 준비합니다.

## **Excel 템플릿 데이터를 채우기** 위해 Excel 템플릿 준비하기

1. 새 Excel 워크북을 엽니다.  
2. 동적 콘텐츠를 넣고 싶은 셀에 Smart Marker 태그를 입력합니다. 예시:  

   ```
   ${Comment:fieldName}
   ```

3. `Template.xlsx` 파일로 저장합니다.  

태그 구문은 `${<CollectionName>:<PropertyName>}` 패턴을 따릅니다. 이 간단한 예시에서는 컬렉션 이름을 생략하고 기본 컬렉션( `Process`에 전달되는 데이터 소스)을 사용합니다.

> **에지 케이스:** 태그가 데이터 소스에 존재하지 않는 속성을 참조하면 Aspose.Cells는 셀을 그대로 두고 변경하지 않습니다. 속성 이름이 정확히 일치하는지(대소문자 구분 포함) 항상 확인하세요.

## **Aspose.Cells 스마트 마커** 사용을 위한 데이터 소스 구축

배열, `List<T>`, `DataTable` 또는 사용자 정의 객체와 같은 모든 열거 가능한 컬렉션을 제공할 수 있습니다. 테이블 스타일 마커를 사용할 때 프로세서는 컬렉션을 순회하며 각 항목에 대해 행을 반복합니다.

```csharp
// Example with a List<T>
var comments = new List<Comment>
{
    new Comment { fieldName = "First comment." },
    new Comment { fieldName = "Second comment." }
};

processor.Process(ws, comments);
```

```csharp
public class Comment
{
    public string fieldName { get; set; }
}
```

여러 행을 제공하면 Aspose.Cells가 템플릿 영역을 자동으로 확장하여 모든 항목을 포함시킵니다. 이는 보고서, 청구서 또는 데이터 기반 테이블을 생성할 때 유용합니다.

## **Aspose.Cells 스마트 마커**를 사용하여 워크시트 처리하기

`Process` 메서드는 선택적 설정을 받을 수 있습니다, 예를 들어:

- `SmartMarkerOptions`는 빈 셀 처리 방식을 제어합니다.
- `DataSourceOptions`는 다른 컬렉션 이름을 지정합니다.

```csharp
SmartMarkerOptions options = new SmartMarkerOptions
{
    // Preserve empty cells as blanks instead of removing them.
    PreserveEmptyCells = true
};

processor.Process(ws, dataSource, options);
```

이 옵션들을 사용하면 **Excel 템플릿 데이터를 채우는** 작업을 세밀하게 제어할 수 있어 출력이 원하는 서식 요구사항에 맞게 됩니다.

## 결과 저장 및 출력 확인

처리 후에는 Aspose.Cells가 지원하는 모든 형식(XLSX, CSV, PDF 등)으로 워크북을 저장할 수 있습니다.

```csharp
workbook.Save("Result.pdf", SaveFormat.Pdf);
```

`Result.xlsx`(또는 `Result.pdf`)를 열어 `${Comment:fieldName}` 자리표시자가 **C#으로 생성된 샘플 코멘트 텍스트**로 교체되었는지 확인합니다. 셀에 여전히 원래 태그가 표시된다면 데이터 소스의 속성 이름을 다시 확인하세요.

## 흔히 발생하는 문제와 해결 방법

| 문제 | 원인 | 해결 방법 |
|------|------|----------|
| 태그가 교체되지 않음 | 속성 이름 불일치 (예: `fieldname` vs `fieldName`) | 대소문자를 구분한 정확한 일치 확인 |
| 행이 복제되지 않음 | 데이터 소스에 하나의 객체만 있어 템플릿이 테이블을 기대함 | 여러 항목을 포함하는 컬렉션 제공 |
| 저장 시 워크북 충돌 | 구버전 Aspose.Cells 사용 | 최신 NuGet 패키지로 업그레이드 |
| 서식 손실 | 프로세서가 셀 스타일을 덮어씀 | `SmartMarkerOptions.PreserveCellFormatting = true` 로 스타일 보존 |

## 전체 작업 예제

아래는 복사·붙여넣기·실행할 수 있는 독립형 프로그램 예시입니다.

```csharp
using Aspose.Cells;
using System;
using System.Collections.Generic;

namespace SmartMarkerDemo
{
    class Program
    {
        static void Main()
        {
            // Load the template that contains the Smart Marker tag ${Comment:fieldName}
            Workbook workbook = new Workbook("Template.xlsx");
            Worksheet ws = workbook.Worksheets[0];

            // Create a list of data objects – each object maps to the marker property.
            var data = new List<Comment>
            {
                new Comment { fieldName = "First generated comment." },
                new Comment { fieldName = "Second generated comment." },
                new Comment { fieldName = "Third generated comment." }
            };

            // Initialise the processor and run it.
            SmartMarkerProcessor processor = new SmartMarkerProcessor();
            processor.Process(ws, data);

            // Save the populated workbook.
            workbook.Save("Result.xlsx");
            Console.WriteLine("Smart marker processing complete. Check Result.xlsx.");
        }
    }

    public class Comment
    {
        public string fieldName { get; set; }
    }
}
```

**예상 결과:** `Result.xlsx`에서 원래 `${Comment:fieldName}`가 있던 셀이 세 행으로 확장되며, 각각 `data` 리스트의 해당 코멘트 텍스트가 채워집니다.
