# C# 템플릿을 사용하여 Excel로 데이터 내보내기 – 단계별 가이드

.NET 애플리케이션에서 **Excel로 데이터를 내보내야** 할 때, 이 가이드는 처음부터 끝까지 실행되는 완전한 솔루션을 보여줍니다. Smart Marker 태그가 이미 포함된 Excel 템플릿을 로드하면 **Excel 생성 자동화**가 가능해지며, 셀‑별 코드를 작성하지 않고도 깔끔한 **직원 보고서 Excel**을 만들 수 있습니다.

다음 내용을 확인할 수 있습니다:

* 레이아웃을 정의한 Excel 템플릿(`load excel template`)을 로드하기
* 직원 객체 리스트를 템플릿에 전달하기
* 최종 워크북을 생성하고 `output.xlsx`로 저장하기

필요한 모든 코드는 포함되어 있으니 바로 복사·붙여넣기·실행하면 됩니다.

## 사전 요구 사항

* .NET 6.0 이상 (코드는 .NET Framework 4.7+에서도 동작합니다).  
* **Aspose.Cells for .NET** NuGet 패키지 – `Workbook`, `SmartMarkerProcessor`, Smart Marker 지원을 제공합니다.  
* `template.xlsx` 파일이 들어 있는 `YOUR_DIRECTORY` 폴더. 템플릿에는 데이터가 표시될 셀에 `&=EmployeeList.Name` 같은 Smart Marker 태그가 포함되어 있어야 합니다.

> **Pro tip:** 템플릿을 프로젝트 폴더에 두고 *Copy to Output Directory* 속성을 *Copy always* 로 설정하면 디버깅 중 경로가 올바르게 해석됩니다.

## 전체 소스 코드

```csharp
using System;
using System.Collections.Generic;
using Aspose.Cells;

namespace ExcelExportDemo
{
    // Simple POCO that represents an employee record
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Step 1: Load the Excel template that contains Smart Marker tags
            string templatePath = @"YOUR_DIRECTORY\template.xlsx";
            Workbook wb = new Workbook(templatePath);

            // Step 2: Prepare a data source – a list of employee objects
            List<Employee> employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Step 3: Create a SmartMarkerProcessor instance
            SmartMarkerProcessor sp = new SmartMarkerProcessor();

            // Step 4: Apply the employee data to the workbook using the processor
            // The tag &amp;=EmployeeList.Name in the template will be replaced with each employee's name,
            // and &amp;=EmployeeList.Position will be replaced with the corresponding position.
            sp.Process(wb, employeeList);

            // Step 5: Save the populated workbook
            string outputPath = @"YOUR_DIRECTORY\output.xlsx";
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

### 코드가 수행하는 작업

| 단계 | 왜 중요한가 | 핵심 코드 |
|------|------------|-----------|
| **Excel 템플릿 로드** | 미리 디자인된 레이아웃을 재사용하면 시간 절약과 일관된 스타일 보장이 가능합니다. | `Workbook wb = new Workbook(templatePath);` |
| **데이터 소스 준비** | Smart Marker는 모든 `IEnumerable` 컬렉션과 함께 사용할 수 있습니다; 여기서는 `Employee` 리스트를 사용합니다. | `List<Employee> employeeList = …` |
| **프로세서 생성** | `SmartMarkerProcessor`가 템플릿을 분석하고 태그를 찾아 데이터를 삽입합니다. | `SmartMarkerProcessor sp = new SmartMarkerProcessor();` |
| **데이터 처리** | 프로세서는 각 Smart Marker 태그를 해당 속성 값으로 교체합니다. | `sp.Process(wb, employeeList);` |
| **워크북 저장** | 최종 파일을 사용자에게 전송하거나 서버에 저장하거나 이메일에 첨부할 수 있습니다. | `wb.Save(outputPath);` |

그 결과는 **직원 보고서 Excel** 파일이며, 각 행에 직원의 이름과 직책이 원본 템플릿에 태그를 배치한 위치에 정확히 들어갑니다.

## Excel 템플릿 로드

`new Workbook(path)` 로 `load excel template` 하면 Aspose.Cells가 전체 워크북(스타일, 수식, Smart Marker 자리표시자 포함)을 읽어들입니다. 이 방식이 워크북을 처음부터 만드는 것보다 선호되는 이유는 다음과 같습니다:

* **디자인 제어** – 디자이너가 헤더 서식, 회사 로고, 열 너비 등을 코드 없이 지정할 수 있습니다.
* **버전 관리** – 템플릿을 업데이트해도 애플리케이션을 다시 컴파일할 필요가 없습니다.
* **현지화** – 언어별로 별도 템플릿 파일을 유지할 수 있습니다.

서드파티 라이브러리를 사용하지 않고 순수 .NET 솔루션을 원한다면 **ClosedXML**이나 **EPPlus**를 사용할 수 있지만, 이들에는 Smart Marker 지원이 내장되어 있지 않아 셀‑별 복사 루프를 직접 작성해야 합니다.

## Smart Marker 로 Excel 생성 자동화

Smart Marker는 `&=Collection.Property` 형태의 자리표시자입니다. 프로세서가 실행될 때:

* 컬렉션(`employeeList`)을 순회합니다.
* 각 항목에 대해 해당 속성 값을 지정 셀에 씁니다.
* 필요에 따라 행이나 열을 자동으로 확장합니다.

이 메커니즘은 **Excel 생성 자동화**를 가능하게 하며 수동 반복 로직을 없애줍니다. 동일한 패턴을 주문, 청구서, 재고 목록 등 모든 데이터 형태에 적용할 수 있습니다.

### 흔히 쓰이는 변형

| 변형 | 구현 방법 |
|------|-----------|
| **다중 컬렉션** | `List<Department>` 같은 리스트를 추가하고 `&=DepartmentList.Name` 과 같이 다른 태그로 참조합니다. |
| **중첩 컬렉션** | 점 표기법 사용: `&=EmployeeList.Projects.ProjectName` (여기서 `Projects`는 `Employee` 내부 컬렉션 속성). |
| **조건부 서식** | 템플릿에 Excel 조건부 서식 규칙을 배치하면 프로세서가 생성된 행에도 이를 유지합니다. |

## 직원 보고서 Excel 만들기

**직원 보고서 Excel**이라는 용어는 전형적인 비즈니스 시나리오를 의미합니다: 관리자가 인쇄 가능한 직원 명단을 원할 때. Smart Marker 태그를 템플릿에 직접 삽입하면 다음을 얻을 수 있습니다:

* 굵은 글꼴과 배경색이 적용된 헤더 행
* 데이터에 따라 자동으로 크기가 조정되는 열
* 표준 Excel 수식으로 계산할 수 있는 선택적 총계 행(예: 직원 수)

총계 행을 추가하려면 템플릿에 `=COUNTA(A2:A100)` 같은 수식을 배치하면 프로세서가 이를 건드리지 않습니다.

## Excel 템플릿 C# 생성 – 모범 사례

**generate Excel template C#** 코드를 작성할 때 다음 가이드를 기억하세요:

1. **관심사 분리** – 템플릿 로드, 데이터 준비, 처리 로직을 별도 메서드로 분리하면 단위 테스트가 쉬워집니다.
2. **입력 검증** – `Process` 호출 전에 템플릿 파일 존재 여부와 데이터 컬렉션이 null이 아닌지 확인합니다.
3. **리소스 해제** – Aspose.Cells가 메모리를 관리하지만, 대용량 파일을 다룰 경우 `Workbook`을 `using` 블록으로 감싸세요.
4. **예외 처리** – `sp.Process` 주변에 `Exception`을 잡아 태그 이름 불일치와 같은 문제를 명확히 알립니다.

```csharp
static Workbook LoadTemplate(string path)
{
    if (!File.Exists(path))
        throw new FileNotFoundException($"Template not found: {path}");
    return new Workbook(path);
}
```

## 흔히 발생하는 문제 해결

| 증상 | 가능한 원인 | 해결 방법 |
|------|------------|-----------|
| 처리 후 데이터가 표시되지 않음 | Smart Marker 태그가 오타이거나 병합 셀 안에 있음 | 태그가 정확히 `&=Collection.Property` 형식인지, 병합 영역 안에 있지 않은지 확인 |
| 출력 파일이 비어 있거나 손상됨 | 워크북이 처리 완료 전에 저장됨 | `sp.Process`가 **wb.Save** 전에 실행되는지 확인 |
| 직원 리스트가 커서 생성 속도가 느려짐 | Aspose.Cells 무료 버전에는 성능 제한이 있음 | 라이선스 버전으로 업그레이드하거나 배치 처리 적용 |
| 템플릿 경로 오류 | 실행 시 상대 경로가 다른 폴더를 가리킴 | `Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "template.xlsx")` 사용하거나 파일의 *Copy to Output Directory* 속성을 설정 |

## 전체 예제 요약

아래는 한 번에 복사·붙여넣기 할 수 있도록 전체 프로그램을 하나의 블록으로 정리한 것입니다:

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Load the template
            string templatePath = Path.Combine("YOUR_DIRECTORY", "template.xlsx");
            Workbook wb = new Workbook(templatePath);

            // Prepare data
            var employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Process Smart Markers
            var sp = new SmartMarkerProcessor();
            sp.Process(wb, employeeList);

            // Save the result
            string outputPath = Path.Combine("YOUR_DIRECTORY", "output.xlsx");
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

이 프로그램을 실행하면 **직원 보고서 Excel** 파일이 생성되며, 이메일 전송, 인쇄, 혹은 추가 처리에 바로 활용할 수 있습니다.
