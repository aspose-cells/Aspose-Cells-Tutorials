# C#에서 사용자 지정 서식으로 Excel 워크북을 만들고 XLSX로 저장하는 방법

데이터를 가져오고, 사용자 지정 숫자 형식을 적용하며, 셀 글꼴 색상을 변경하는 **create Excel workbook C#**이 필요하다면, 이 튜토리얼이 정확히 어떻게 하는지 보여줍니다. 몇 초 만에 스타일이 적용된 `StyleArrayImport.xlsx` 파일을 생성하는 실행 가능한 예제를 얻을 수 있습니다.

C#에서 Excel을 다루다 보면 형식을 정의하고, 색상을 적용하고, 파일을 올바르게 저장하는 반복적인 수작업이 필요합니다. 이 가이드를 끝까지 따라 하면 이러한 작업을 모두 자동화하여 UI 대신 데이터에 집중할 수 있습니다.

다음과 같은 내용을 배웁니다:

* `DataTable`을 워크시트에 **import**하는 방법,
* `StyleArray`를 사용해 **custom number format**을 적용하고 **cell font color**를 변경하는 방법,
* 한 줄의 메서드 호출로 **workbook을 XLSX로 저장**하는 방법,
* **format imported data excel**이 정확히 적용되었는지 확인하는 방법.

필요한 전제 조건은 **Aspose.Cells for .NET** 라이브러리(또는 `Workbook`, `Worksheet`, `StyleArray`를 제공하는 호환 API)에 대한 참조뿐입니다. 코드는 .NET 6+를 대상으로 하지만, 약간의 수정으로 이전 버전에서도 동작합니다.

## Step 1: Prepare the sample DataTable

먼저, 일반적으로 데이터베이스나 다른 소스에서 가져올 데이터를 흉내 내는 `DataTable`을 생성합니다. 테이블에는 **Name** 열(string)과 나중에 서식을 적용할 **Amount** 열(decimal)이 포함됩니다.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**왜 중요한가:** `DataTable`을 사용하면 가져오기 로직을 데이터 소스와 독립적으로 유지할 수 있어, 데이터베이스, CSV 파일 또는 API에서 보고서를 생성할 때 일반적인 패턴입니다.

## Step 2: Define a StyleArray to **apply custom number format** and **change cell font color**

`StyleArray`를 사용하면 `DataTable`에서 가져온 모든 셀에 적용될 서식 지시자를 한 번에 묶을 수 있습니다. 이 예제에서는:

* `Number`를 `#,##0.00`으로 설정 – 천 단위 구분 기호가 있는 전형적인 회계 형식,
* `FontColor`를 `Color.Blue`로 설정 – 숫자를 돋보이게 함.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**StyleArray를 사용하는 이유:** 가져오기 시점에 스타일을 적용하면 워크시트를 두 번 순회할 필요가 없어 대용량 데이터 세트에서 성능이 향상됩니다.

## Step 3: **Create Excel workbook C#** – instantiate Workbook and get the first Worksheet

이제 빈 워크북을 만들고 첫 번째 워크시트(인덱스 0)에 대한 참조를 얻습니다. 이 워크시트가 가져온 데이터의 대상이 됩니다.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**설명:** `Workbook`은 전체 Excel 파일을 나타내고, `Worksheet`는 단일 탭을 나타냅니다. 기본 워크북에는 하나의 시트만 포함되어 있어 대부분의 간단한 보고서에 충분합니다.

---

## Step 4: Import the DataTable using the **StyleArray** to **format imported data excel**

`ImportDataTable` 메서드는 테이블의 행과 열을 워크시트에 복사하며, 시작 셀은 `A1`(행 0, 열 0)입니다. `true` 인자는 열 머리글을 포함하도록 지정합니다. `styleArray`를 전달하면 각 가져온 셀에 사용자 지정 숫자 형식과 글꼴 색상이 적용됩니다.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**내부 동작:** Aspose.Cells는 각 행을 순회하면서 값을 기록하고, `styleArray`에 정의된 스타일을 적용합니다. 숫자는 쉼표와 두 자리 소수점이 표시되고, 텍스트는 파란색으로 렌더링됩니다.

---

## Step 5: **Save workbook as XLSX** – write the file to disk

마지막으로 워크북을 `.xlsx` 파일로 저장합니다. 경로는 머신의 쓰기 가능한 디렉터리로 자유롭게 변경할 수 있습니다.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**결과 확인:** Excel에서 생성된 파일을 열면 세 개의 데이터 행과 **Amount** 열이 쉼표와 두 자리 소수점이 적용된 파란색 글꼴로 표시됩니다. 이는 **format imported data excel** 단계가 성공했음을 확인하는 것입니다.

## Full Working Example

아래 전체 블록을 새 콘솔 프로젝트에 복사하고 실행하십시오. 추가 코드가 필요하지 않습니다.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**콘솔에 예상되는 출력:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

파일을 열어 **Amount** 열에 `1,234.56`과 같이 파란색 글꼴로 값이 표시되는지 확인하세요.

## Common Questions & Edge Cases

| 질문 | 답변 |
|----------|--------|
| *개별 열에 서로 다른 형식을 적용할 수 있나요?* | 가능합니다. 가져온 후 해당 열의 `Style` 객체(`worksheet.Cells.Columns[1].Style`)를 가져와 다른 `Number` 또는 `FontColor`를 설정하면 됩니다. |
| *숫자 대신 날짜를 서식 지정해야 하면 어떻게 하나요?* | `styleArray.Number = "mm-dd-yyyy"` 로 설정하고 필요에 따라 날짜 셀의 `FontColor`도 지정합니다. |
| *다크 테마 Excel에서 파란색 글꼴이 잘 보이나요?* | 다크 배경에서는 파란색이 읽기 어려울 수 있습니다. 더 밝은 색(`Color.LightBlue`)이나 대비가 좋은 색(`Color.Black`)을 사용하세요. |
| *수십만 행의 매우 큰 DataTable을 가져와야 하면?* | `ImportDataTable`의 `ImportDataTableOptions` 오버로드를 사용해 데이터를 스트리밍하거나, Excel 행 제한(1,048,576행)을 고려해 여러 워크시트로 나누어 가져오세요. |
| *XLSX 대신 CSV로 내보낼 수 있나요?* | `SaveFormat.Xlsx`를 `SaveFormat.Csv`로 교체하면 됩니다. 다만 CSV는 순수 텍스트 형식이므로 서식 정보(숫자 형식, 글꼴 색상)는 손실됩니다. |

## Tips for Production Use

* **Pro tip:** 여러 워크시트에 동일한 서식을 적용해야 할 경우 `Style` 객체를 캐시하세요. 각 가져오기마다 새로운 `StyleArray`를 만들면 오버헤드가 발생합니다.
* **문화권 차이 주의:** `Number` 패턴 `#,##0.00`은 불변 문화권을 따릅니다. 로케일별 구분 기호가 필요하면 `NumberFormatInfo`를 사용하거나 사용자의 지역 설정에 따라 Excel이 자동으로 처리하도록 하세요.
* **예외 처리:** `Save` 호출을 try‑catch 블록으로 감싸 파일 권한 부족이나 파일 잠금 등 I/O 예외를 처리합니다.
