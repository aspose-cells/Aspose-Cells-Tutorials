# C#로 Excel 파일 만들기 – 셀 스타일 지정 및 통화 형식 설정

If you need to **create excel file c#** that looks professional, this guide shows you exactly how to style excel cells and format a column as currency. You’ll see a complete, end‑to‑end example that imports a `DataTable`, applies a bold header, and sets a `$#,##0.00` number format for the price column.

전문적인 **create excel file c#**이(가) 필요하다면, 이 가이드는 엑셀 셀을 스타일링하고 열을 통화 형식으로 지정하는 방법을 정확히 보여줍니다. `DataTable`을 가져와서 굵은 헤더를 적용하고 가격 열에 `$#,##0.00` 숫자 형식을 설정하는 완전한 엔드‑투‑엔드 예제를 확인할 수 있습니다.

The tutorial covers everything you need: required NuGet packages, the full source code, explanations of why each piece matters, and tips for handling edge cases such as empty rows or different locales. By the end you’ll be able to generate an `.xlsx` file with a nicely formatted price column in just a few lines of C#.

이 튜토리얼은 필요한 모든 내용을 다룹니다: 필수 NuGet 패키지, 전체 소스 코드, 각 요소가 중요한 이유에 대한 설명, 빈 행이나 다른 로케일과 같은 엣지 케이스를 처리하기 위한 팁. 끝까지 진행하면 몇 줄의 C# 코드만으로 깔끔하게 포맷된 가격 열이 포함된 `.xlsx` 파일을 생성할 수 있습니다.

## 전제 조건

- .NET 6.0 또는 이후 버전 (코드는 .NET Framework 4.6+에서도 작동합니다)
- Visual Studio 2022 또는 선호하는 C# 편집기
- **Aspose.Cells for .NET** 또는 **GemBox.Spreadsheet** 라이브러리 (`ImportTableOptions`를 모두 지원). 아래 예제는 간단한 `StyleArray` 속성을 제공하기 때문에 **Aspose.Cells**를 사용합니다.
- C# 컬렉션 및 `DataTable`에 대한 기본 지식

> **Pro tip:** 무료 대안을 선호한다면 `Aspose.Cells`를 `GemBox.Spreadsheet`로 교체하세요. 스타일이 적용된 `DataTable`을 가져오는 API는 거의 동일하며, 네임스페이스와 NuGet 패키지 이름만 변경하면 됩니다.

## 1단계: Excel 라이브러리 설치

Open the NuGet Package Manager and install the library:

```bash
dotnet add package Aspose.Cells
```

> **Why this step?** 이 라이브러리는 이후에 사용되는 `Workbook`, `Worksheet`, `Style`, `ImportTableOptions` 클래스를 제공합니다. 이를 사용하지 않으면 Office Open XML 형식을 직접 작성해야 하는데, 이는 오류가 발생하기 쉽습니다.

## 2단계: 샘플 데이터로 DataTable 생성

A `DataTable`은 Excel로 내보내기 전에 표 형식 데이터를 보관하기에 편리한 방법입니다. 이 예제에서는 두 개의 열, *Product*와 *Price*가 있습니다.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **설명:**  
> - `Columns.Add("Price", typeof(double))`는 가격 값을 숫자로 처리하도록 테이블에 알려주며, 이는 이후 숫자 형식 지정에 필요합니다.  
> - 몇 개의 행을 추가하면 **format column currency** 단계를 검증할 데이터가 생깁니다.

## 3단계: 적용할 스타일 정의

We’ll create an array of `Style` objects that matches the column order. The first entry styles the header row, the second leaves the *Product* column untouched, and the third applies a currency number format.

`Style` 객체 배열을 만들어 열 순서와 일치시킵니다. 첫 번째 항목은 헤더 행에 스타일을 적용하고, 두 번째는 *Product* 열을 그대로 두며, 세 번째는 통화 숫자 형식을 적용합니다.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### 왜 **style array**를 사용하나요?

`ImportTableOptions.StyleArray`는 각 열을 `Style`에 매핑합니다. 이는 단일 가져오기 작업에서 **add number format**와 **style excel cells**를 수행하는 가장 효율적인 방법으로, 워크시트를 두 번 순회할 필요가 없습니다.

## 4단계: 가져오기 옵션 구성

Now we bind the style array to the import operation. The `ImportTableOptions` object also lets you control whether the first row is treated as a header.

이제 스타일 배열을 가져오기 작업에 바인딩합니다. `ImportTableOptions` 객체를 사용하면 첫 번째 행을 헤더로 처리할지 여부도 제어할 수 있습니다.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Note:** `IsFieldNameShown`는 기본값이 `true`이지만, 명시적으로 설정하면 향후 독자에게 의도가 명확해집니다.

## 5단계: 워크북 생성, 테이블 가져오기 및 저장

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### 예상 결과

When you open `DataTableWithStyles.xlsx`:

- 첫 번째 행(헤더)은 **bold**입니다.
- *Price* 열은 **$1.20**, **$3.50**, **$0.75**와 같이 표시됩니다.
- *Product* 열은 기본 폰트를 유지합니다.

형식이 지정된 통화 열과 스타일이 적용된 헤더 셀을 포함한 **created an excel file c#**를 성공적으로 만들었습니다.

## 6단계: 일반적인 변형 및 엣지 케이스 처리

### a. 다른 로케일 또는 사용자 정의 통화 기호

If you need a Euro or another currency, replace the built‑in format `164` with a custom format string:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. 나중에 열 추가

When you add extra columns, extend the `columnStyles` array accordingly. Use `null` for columns that should keep the default style.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. 빈 DataTable

If the `DataTable` has no rows, Aspose.Cells still creates the header row. However, the workbook will contain only one row. To avoid an empty file, check the row count before importing:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Aspose.Cells 대신 `GemBox.Spreadsheet` 사용

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

The logic remains identical, demonstrating that the tutorial is **format column currency**에 대해 기반 라이브러리와 무관함을 보여줍니다.

## 7단계: 파일을 프로그래밍 방식으로 검증 (선택 사항)

You can open the generated workbook and assert that the number format was applied correctly—useful for unit tests.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```
