# Java와 JSON 데이터를 사용하여 Excel 워크북 만들기

Excel 워크북을 **create Excel workbook java** 해야 하는 경우, 개발자들은 종종 JSON 데이터를 스프레드시트에 로드하는 어려움에 직면합니다. 이 가이드는 **populate Excel from JSON** 방법을 보여주며, **convert JSON array excel** 및 **populate workbook from json**을 깔끔하고 반복 가능한 방식으로 수행하는 방법을 포함합니다.

서비스가 REST API를 통해 데이터를 제공할 때 JSON을 다루는 것은 일반적이며, Excel은 보고 및 분석을 위한 기본 포맷으로 남아 있습니다. 이 튜토리얼이 끝날 때쯤에는 실행 가능한 Java 프로그램을 갖게 됩니다:

* 새 Excel 워크북을 생성합니다,
* JSON 배열(또는 모든 JSON 구조)을 읽어 셀에 값을 씁니다,
* 파일을 디스크에 저장하여 후속 처리에 사용할 수 있게 합니다.

샘플 코드에 사용된 `SmartMarkerProcessor`를 제공하는 Aspose.Cells for Java 라이브러리를 제외하고는 외부 도구가 필요하지 않습니다.

## 필수 조건

시작하기 전에 다음을 확인하십시오:

| Prerequisite | Reason |
|--------------|--------|
| Java Development Kit (JDK) ≥ 8 | 예제를 컴파일하고 실행하는 데 필요합니다 |
| Maven or Gradle (optional) | 의존성 관리를 간소화합니다 |
| Aspose.Cells for Java (v23.10 or later) | `Workbook` 및 `SmartMarkerProcessor` 클래스를 제공합니다 |
| Basic knowledge of JSON and Java I/O | 데이터 흐름을 이해하는 데 도움이 됩니다 |

빌드 도구를 사용하고 싶지 않은 경우, [Aspose website](https://products.aspose.com/cells/java/)에서 Aspose.Cells JAR를 다운로드하고 프로젝트의 클래스패스에 수동으로 추가할 수 있습니다.

## 1단계: 프로젝트 설정 및 Aspose.Cells 의존성 추가

### Maven 사용자

Add the following dependency to your `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Gradle 사용자

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

빌드 도구를 사용하지 않는 경우, 다운로드한 JAR를 `libs/` 폴더에 넣고 컴파일 시 클래스패스에 포함하십시오:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## 2단계: 새 워크북을 만들고 SmartMarker 프로세서를 구성하기

`SmartMarkerProcessor`는 JSON 값을 Excel 셀에 매핑하는 작업을 단순화합니다. `setArrayAsSingle(true)`를 호출하면 프로세서가 전체 JSON 배열을 단일 값으로 취급하도록 하며, 이는 각 요소를 행의 개별 셀에 배치하려는 경우에 유용합니다.

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**왜 중요한가:**  
워크북을 미리 생성하면 깨끗한 캔버스를 얻을 수 있습니다. `setArrayAsSingle(true)`를 구성하면 프로세서가 배열을 단일 문자열(예: `["A","B","C"]`)로 평탄화하는 것을 방지하고 대신 레이아웃을 수동으로 제어할 수 있습니다.

## 3단계: 삽입할 JSON 데이터 정의하기

이 튜토리얼에서는 간단한 JSON 배열을 사용하지만, 동일한 접근 방식은 객체, 중첩 배열 또는 복잡한 구조에도 적용됩니다.

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**팁:** JSON이 파일이나 REST 엔드포인트에서 오는 경우, 리터럴 문자열을 소스에서 읽은 `String`(예: `Files.readString(Paths.get("data.json"))`)으로 교체하십시오.

## 4단계: JSON 데이터를 사용해 워크북 처리하기

이제 `SmartMarkerProcessor`가 JSON 배열을 첫 번째 워크시트에 매핑하도록 합니다. 기본 동작은 각 요소를 `A1`부터 시작하는 연속 셀에 씁니다.

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

내부적으로 Aspose.Cells는 JSON을 파싱하고 임시 데이터 테이블을 생성한 뒤 값을 워크시트에 씁니다. `ArrayAsSingle`을 `true`로 설정했기 때문에 배열 요소가 첫 번째 행에 가로로 배치됩니다.

## 5단계: 워크북을 파일로 저장하기

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

프로그램을 실행하면 작업 디렉터리에 **CreatedFromJson.xlsx**라는 파일이 생성됩니다. Excel(또는 호환 뷰어)으로 열면 다음과 같이 표시됩니다:

| A | B | C |
|---|---|---|
| A | B | C | *(값은 셀 A1, B1, C1에 표시됩니다)*

### 예상 출력

```
Workbook saved to CreatedFromJson.xlsx
```

Excel 시트는 다음과 같이 보입니다:

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## 6단계: 더 복잡한 JSON 구조 처리하기 (선택 사항)

### 6.1 JSON 객체에서 워크북 채우기

JSON이 배열이 아니라 객체인 경우에도 `SmartMarkerProcessor`를 사용할 수 있습니다. 예를 들어:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

프로세서는 (`title`, `month`, `values`)와 같은 명명된 범위를 생성하며, Excel 템플릿에서 `&=title`, `&=values`와 같은 Smart Marker를 사용해 참조할 수 있습니다.

### 6.2 중첩 JSON 배열을 세로 목록으로 변환하기

때때로 배열을 행이 아니라 열에 채워야 할 때가 있습니다. 처리하기 전에 시작 셀을 수동으로 설정하십시오:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

이제 값 **A**, **B**, **C**가 각각 셀 A2, A3, A4에 표시됩니다.

## 자주 발생하는 문제와 해결 방법

| **배열이 단일 문자열로 기록됨** | `setArrayAsSingle(false)` (default) | `processor.setArrayAsSingle(true)` 호출 |
| **파일 저장 시 찾을 수 없음** | 잘못된 경로나 쓰기 권한 부족 | 절대 경로를 사용하거나 디렉터리가 존재하는지 확인 |
| **JSON 파싱 오류** | 잘못된 형식의 JSON 문자열 | 도구로 JSON을 검증하거나 Jackson과 같은 라이브러리를 사용해 문자열을 생성 |
| **셀을 의도치 않게 덮어씀** | 시작 셀을 재설정하지 않고 동일 워크시트를 여러 번 처리 | 각 `process` 호출 전에 `processor.setStartCell("A1")` 호출 |

## 전문가 팁: 워크북을 템플릿으로 재사용하기

매번 빈 워크북에서 시작하는 대신, 헤더, 수식 또는 스타일이 이미 포함된 사전 설계된 템플릿을 로드할 수 있습니다:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

이 접근 방식은 수작업으로 만든 Excel 파일의 시각적 완성도와 **populate workbook from json** 자동화를 결합합니다.
