# Aspose.Cells를 사용한 Excel에 사용자 정의 객체 가져오기 – Java 가이드

Excel 워크시트에 **사용자 정의 객체**를 가져와야 하는 경우, 이 가이드는 Aspose.Cells for Java를 사용한 전체 과정을 안내합니다. **Excel에 데이터 가져오기**, 굵은 헤더 스타일 적용, 그리고 공유 준비가 된 `.xlsx` 파일 생성 방법을 확인할 수 있습니다.

Java에서 표 형식 데이터를 내보내는 경우 수동으로 셀을 하나씩 쓰는 작업이 필요할 때가 많으며, 이는 오류가 발생하기 쉽고 유지 관리가 어렵습니다. `importCustomObjects` API를 활용하면 보일러플레이트 코드를 피하고 데이터 모델을 그대로 유지하면서 세밀한 스타일 제어를 할 수 있습니다.

이 튜토리얼에서 수행할 내용:

* Java `Map` 객체 목록을 만들어 일반적인 데이터 테이블을 모방합니다.
* Aspose.Cells를 사용해 재사용 가능한 헤더 스타일(굵은 글꼴)을 생성합니다.
* 스타일 배열을 적용하면서 사용자 정의 객체를 워크시트에 가져옵니다.
* 워크북을 디스크에 저장하고 결과를 확인합니다.

필수 조건은 Java 개발 환경(JDK 8+ 권장)과 Aspose.Cells for Java 라이브러리뿐입니다.

## 필요 사항

| 요구 사항 | 이유 |
|-------------|--------|
| JDK 8 이상 | Java 코드를 컴파일하고 실행하는 데 필요합니다. |
| Aspose.Cells for Java (최신 버전) | `Workbook`, `Worksheet` 및 import API를 제공합니다. |
| IDE 또는 빌드 도구 (예: Maven, Gradle) | 의존성 관리와 실행을 단순화합니다. |
| 출력 파일을 저장할 폴더에 대한 쓰기 권한 | 워크북이 `ImportWithStyle.xlsx` 로 저장됩니다. |

Maven을 사용하는 경우 `pom.xml`에 Aspose.Cells 의존성을 추가합니다:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## Step 1: Prepare the custom objects to import

1단계: 가져올 사용자 정의 객체 준비

첫 번째 단계는 Excel에 배치하려는 행을 나타내는 컬렉션을 만드는 것입니다. 이 예제에서는 각 맵이 열 이름을 키로 하는 행처럼 동작하는 `List<Map<String,Object>>` 를 사용합니다.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Why this matters:**  
`importCustomObjects`는 객체 배열을 기대합니다. `Map`을 사용하면 열 이름을 보존할 수 있어 Aspose.Cells가 자동으로 셀에 매핑합니다. 이 접근 방식은 .NET의 일반적인 `DataTable`이나 JDBC의 `ResultSet`을 닮아 있어 프로젝트 전반에 걸쳐 코드를 재사용할 수 있습니다.

---

## Step 2: Define a header style to apply on import

2단계: 가져오기 시 적용할 헤더 스타일 정의

명확한 헤더 행은 가독성을 높입니다. Aspose.Cells를 사용하면 `Style` 객체를 생성하고 글꼴을 굵게 설정한 뒤 `ImportTableOptions` 배열을 통해 전달할 수 있습니다.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Why this matters:**  
스타일 배열을 생략하면 헤더가 기본 글꼴로 표시되어 눈에 잘 띄지 않을 수 있습니다. 스타일을 한 번만 준비하면 각 행마다 반복 호출을 피하고 가져오기 로직을 깔끔하게 유지할 수 있습니다.

---

## Step 3: Import the custom objects with the style array

3단계: 스타일 배열을 사용해 사용자 정의 객체 가져오기

이제 데이터를 스타일과 결합하고 `importCustomObjects`를 호출합니다. 이 메서드는 데이터를 왼쪽 상단 모서리(행 0, 열 0)부터 배치하고 헤더 스타일을 자동으로 적용합니다.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Why this matters:**  
`importCustomObjects`는 각 맵을 파싱해 키(`Name`, `Score`)를 기반으로 열을 생성하고 값을 해당 셀에 씁니다. `ImportTableOptions` 객체는 첫 번째 행에 `styleArray`를 사용하도록 Aspose.Cells에 알려 주어 추가 코드 없이 굵은 헤더를 얻을 수 있습니다.

---

## Step 4: Save the workbook and verify the output

4단계: 워크북 저장 및 출력 확인

마지막으로 워크북을 파일에 기록합니다. 생성된 Excel 파일에는 스타일이 적용된 헤더 행과 데이터 행이 포함됩니다.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Expected result:**  

| **이름** | **점수** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

헤더 셀(`이름`, `점수`)은 굵은 글꼴로 표시되어 2단계에서 정의한 스타일과 일치합니다.

## Common variations and edge cases

일반적인 변형 및 엣지 케이스

| 상황 | 권장 조정 |
|-----------|------------------------|
| **다른 열 순서** | `Map` 키가 원하는 순서대로 삽입되었는지 확인하거나, 주석이 달린 필드와 `PropertyDescriptor` 배열을 가진 사용자 정의 POJO를 사용하십시오. |
| **대용량 데이터 세트 (>10 000 행)** | `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)`를 늘려 `OutOfMemoryError`를 방지하십시오. |
| **사용자 정의 숫자 형식** | 데이터 행에 대한 두 번째 `Style`을 `styleArray`에 추가하고, 예를 들어 정수 점수를 위해 `NumberFormat`을 `"0"`으로 설정합니다. |
| **여러 워크시트** | 각 대상 워크시트에서 `importCustomObjects`를 호출하고, 필요에 따라 시작 행/열을 조정하십시오. |
| **지역별 헤더 텍스트** | 가져오기 전에 헤더 행을 수동으로 채운 다음 `Cells.applyStyle`을 사용해 전체 범위에 스타일을 적용하십시오. |

## Pro tips for a robust Java export to Excel

Excel로 Java 내보내기 강화를 위한 전문가 팁

* **임시 워크북 재사용** – 각 스타일마다 새로운 `Workbook`을 생성하면 오버헤드가 증가합니다. 여러 스타일이 필요하면 단일 인스턴스를 유지하십시오.  
* **가져오기 전 데이터 검증** – 맵의 null 값은 빈 셀로 변환됩니다; 리스트를 사전 처리해 기본값으로 교체할 수 있습니다.  
* **리소스 닫기** – Aspose.Cells가 내부적으로 메모리를 관리하지만, 저장 후 `workbook.dispose()`를 명시적으로 호출하면 네이티브 리소스를 즉시 해제할 수 있습니다.  
* 워크북에 저장 전에 수식이 평가되어야 하는 경우 `Workbook.setForceFullCalculation(true)`를 설정하십시오.
