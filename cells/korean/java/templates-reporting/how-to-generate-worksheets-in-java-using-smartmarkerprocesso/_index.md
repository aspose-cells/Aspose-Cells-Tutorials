# Java와 SmartMarkerProcessor를 사용하여 워크시트 생성하기

Excel 파일에 **워크시트를 생성하는 방법**이 필요하다면, 이 가이드는 완전하고 바로 실행 가능한 솔루션을 제공합니다. 처음 두 문장을 읽고 나면 객체 컬렉션에서 워크시트와 동적 Excel 시트를 생성하는 방법을 이해하게 되며, 단일 메서드 호출만으로 Excel 생성을 자동화하는 작동 예제를 얻게 됩니다.

각 직원, 프로젝트 또는 기타 엔터티별로 별도의 워크시트를 만드는 것은 **Excel 워크북을 프로그래밍 방식으로 채우는** 일반적인 요구사항입니다. 이 튜토리얼은 템플릿 설정부터 리스트 처리 및 최종 파일 저장까지 모든 단계를 단계별로 안내하므로, 바로 자신의 Java 애플리케이션에 적용할 수 있습니다.

## 달성할 수 있는 목표

* 고수준 정보를 나열하는 마스터 워크시트 생성.  
* **리스트에서 여러 시트**를 자동으로 이름을 지정하여 생성.  
* **Excel 생성 자동화** – 행이나 열을 수동으로 추가할 필요 없음.  
* **Excel 워크북을** 객체, 맵, 배열 등 풍부한 데이터 구조로 **채우기**.  

전제 조건:

* Java 8 이상 설치.  
* Aspose.Cells for Java 라이브러리를 추가할 Maven(또는 다른 빌드 도구).  
* Java 컬렉션에 대한 기본 이해.  

> **Pro tip:** SmartMarker 구문(`\${EmployeeMaster}`)은 `java.util.Collection`을 구현하는 모든 컬렉션 타입에서 동작합니다. 템플릿을 깔끔하고 유지보수하기 쉽게 만들 때 활용하세요.

## SmartMarkerProcessor로 워크시트 생성하기

이 섹션에서는 **워크시트를 생성하는 방법**을 손쉽게 만들 핵심 코드를 제공합니다. 각 라인이 왜 중요한지, 단순히 무엇을 하는지 설명합니다.

### Step 1: Aspose.Cells 의존성 추가

Maven을 사용한다면 `pom.xml`에 다음을 포함하세요. 라이브러리는 이 가이드 전반에 걸쳐 사용되는 `SmartMarkerProcessor` 클래스를 제공합니다.

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **Why:** Aspose.Cells는 Excel 파일 I/O, Smart Marker 파싱, 시트 관리를 내부적으로 처리하므로, 저수준 파일 작업에 신경 쓰지 않고 데이터에 집중할 수 있습니다.

### Step 2: Excel 템플릿 준비

`EmployeeTemplate.xlsx`라는 이름의 Excel 파일을 만들고, 단일 셀에 Smart Marker 자리표시자를 넣습니다:

| A |
|---|
| `\${EmployeeMaster}` |

프로세서가 실행되면 이 자리표시자는 **세부 시트**로 교체되며, 직원당 한 행이 생성됩니다.

> **Why:** 자리표시자는 프로세서에게 데이터를 삽입할 위치를 알려줍니다. 별도 템플릿을 사용하면 서식(글꼴, 테두리, 열 너비)을 그대로 유지할 수 있습니다.

### Step 3: 데이터 모델 정의

아래는 최소한의 `Employee` 클래스와 직원 리스트를 생성하는 헬퍼 메서드입니다. 이 리스트는 **리스트에서 여러 시트**를 시연하는 데 사용됩니다.

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **Why:** 일반 Java 객체(POJO)는 Smart Marker 필드(`firstName`, `lastName`, `department`)와 직접 매핑됩니다. 이를 통해 **Excel 워크북을 채우는** 작업이 직관적이고 타입 안전하게 이루어집니다.

### Step 4: SmartMarkerProcessor 설정

이제 모든 것을 연결합니다. 프로세서는 템플릿을 읽고, 마커를 교체하며, `EmployeeDetail`이라는 새 시트를 생성합니다.

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

**핵심 라인 설명**

| Line | Reason |
|------|--------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | Smart Marker 자리표시자가 이미 포함된 템플릿을 로드합니다. |
| `data.put("EmployeeMaster", employees);` | Java 리스트를 마커 `\${EmployeeMaster}`에 바인딩합니다. |
| `processor.setDetailSheetNewName("EmployeeDetail");` | 생성된 시트에 기본 `Sheet1` 대신 의미 있는 이름을 지정합니다. |
| `processor.process(wb, data);` | **워크시트를 생성하는 방법** – 마커를 읽고 새 시트를 만들며 각 `Employee`에 대해 행을 채웁니다. |
| `wb.save("EmployeesReport.xlsx");` | **동적 Excel 시트**를 디스크에 저장합니다. |

### Step 5: 출력 확인

`EmployeesReport.xlsx`를 열어보세요. 두 개의 워크시트가 표시됩니다:

1. **Sheet1** – 원본 템플릿(숨기거나 삭제 가능).  
2. **EmployeeDetail** – `firstName`, `lastName`, `department` 열과 직원당 한 행을 가진 **동적 Excel 시트**.

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **Why this matters:** 이제 파일에 **리스트에서 여러 시트**가 자동으로 포함되며, 수동 루프나 셀 주소 지정이 전혀 필요 없습니다. Smart Marker 엔진이 행 생성, 데이터 변환, 서식 상속을 모두 처리합니다.

### Step 6: 엣지 케이스 처리

#### 빈 데이터 리스트

`employees`가 비어 있으면 프로세서는 여전히 `EmployeeDetail` 시트를 만들지만 빈 상태로 남깁니다. 처리 전에 컬렉션 크기를 확인하여 시트 생성을 방지할 수 있습니다:

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### 매우 큰 리스트

수천 행이 될 경우 메모리 할당(`-Xmx2g`)을 늘리거나 `processor.setAutoFitRows(false)`를 사용해 처리 속도를 높이세요.

#### 그룹별 맞춤 시트 이름 지정

부서별로 별도 시트가 필요하면 **다중 세부 시트**를 활용할 수 있습니다:

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

자리표시자 `\${department}`는 각 `Employee` 객체에서 가져와 `Dept_Sales`, `Dept_Marketing` 등과 같은 시트를 생성합니다.
