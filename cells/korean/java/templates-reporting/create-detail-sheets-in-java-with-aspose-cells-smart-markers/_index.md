# Java와 Aspose.Cells 스마트 마커를 사용하여 상세 시트 만들기

Java 애플리케이션에서 **detail sheets**를 생성해야 한다면, 이 튜토리얼에서는 Aspose.Cells 스마트 마커를 사용하여 이를 수행하는 방법을 보여줍니다. **java create worksheets**를 포함하고, **sheet name from field**를 파생시키며, **process data source**를 몇 줄의 코드만으로 구현하는 완전하고 실행 가능한 예제를 확인할 수 있습니다.

이 가이드는 프로젝트 설정부터 최종 워크북 저장까지 모든 과정을 다루므로, 솔루션을 복사‑붙여넣기만 하면 바로 자신의 프로젝트에 적용하고 즉시 활용할 수 있습니다. 외부 문서는 전혀 필요하지 않으며, 필요한 모든 내용이 여기 있습니다.

## 배울 내용

* **스마트 마커**를 사용하여 마스터 데이터 집합의 각 행마다 템플릿 워크시트를 복제하는 방법.  
* 각 새 시트의 이름을 필드 값(예: `Order_123`)을 기반으로 동적으로 설정하는 방법.  
* Java 컬렉션을 **process data source**로 스마트 마커 엔진에 전달하는 방법.  
* 빈 데이터, 시트 이름의 특수 문자, 대용량 데이터 세트에 대한 성능 고려 사항 등 엣지 케이스 처리 팁.

### 사전 요구 사항

| 요구 사항 | 이유 |
|-------------|--------|
| Java 8 이상 | Aspose.Cells for Java는 Java 8+를 지원합니다. |
| Maven 또는 Gradle 빌드 시스템 | Aspose.Cells 의존성을 추가하는 작업을 단순화합니다. |
| Java 컬렉션에 대한 기본 지식 | 스마트 마커용 데이터 소스를 구축하는 데 필요합니다. |
| 셀 **A1**에 플레이스홀더 스마트 마커가 포함된 템플릿 Excel 파일 (`Template.xlsx`) | 템플릿이 상세‑시트 생성을 주도합니다. |

> **Pro tip:** 템플릿 워크북을 프로젝트의 `resources` 폴더에 보관하면 JAR에 패키징됩니다.

## 1단계: 프로젝트에 Aspose.Cells 추가 (java create worksheets)

**Maven**을 사용하는 경우 `pom.xml`에 다음 의존성을 추가합니다:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

**Gradle**을 사용하는 경우 `build.gradle`에 다음 줄을 넣습니다:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

이 줄들은 **java create worksheets** API를 컴파일 시점에 사용할 수 있게 합니다.

## 2단계: 템플릿 워크북 로드

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*Why this matters:* `Workbook` 객체는 모든 Excel 작업의 진입점입니다. 템플릿을 로드하면 올바른 레이아웃과 사전 정의된 서식을 가진 상태에서 시작할 수 있습니다.

## 3단계: 마스터 행당 새 시트를 생성하는 스마트 마커 삽입 (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

`${Orders:DetailSheetNewName=Order_${OrderId}}` 구문은 **use smart markers**의 핵심입니다. 다음 세 가지 작업을 수행합니다:

1. `Orders` 컬렉션을 반복합니다.  
2. 각 요소마다 **새 워크시트**를 생성합니다.  
3. `OrderId` 필드(앞에 `Order_` 접두사)를 사용해 **sheet name from field**를 설정합니다.

## 4단계: 데이터 소스 준비 (process data source)

아래는 `List<Map<String, Object>>`를 이용한 최소 예제입니다. 실제 데이터 소스(데이터베이스 행, JSON 역직렬화 등)로 교체하세요.

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*Why this matters:* **process data source** 단계는 Java 컬렉션을 스마트 마커 엔진에 바인딩합니다. 키(`"Orders"`)는 스마트 마커 이름과 정확히 일치해야 합니다.

## 5단계: 스마트 마커 처리 (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

`process`가 실행되면 Aspose.Cells는 `Orders` 컬렉션을 읽고, 템플릿 워크시트를 각 항목마다 복제한 뒤, `OrderId` 필드에 따라 시트 이름을 바꿉니다. 이것이 **process data source** 사용의 핵심입니다.

## 6단계: 복제된 상세 시트와 함께 워크북 저장

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

실행 후 `DuplicatedDetailSheets.xlsx` 파일에는 다음이 포함됩니다:

* `Sheet1` – 원본 템플릿(변경되지 않음).  
* `Order_101` – 첫 번째 주문에 대한 상세 시트.  
* `Order_102` – 두 번째 주문에 대한 상세 시트.

### 예상 출력 (발췌)

| Sheet name | A1 (smart marker) | Resulting content |
|------------|-------------------|-------------------|
| Order_101  | `${Orders:...}`   | `order1` 데이터로 채워짐 |
| Order_102  | `${Orders:...}`   | `order2` 데이터로 채워짐 |

Excel에서 파일을 열어 각 시트가 올바르게 이름이 지정되고 데이터 행을 포함하고 있는지 확인하세요.

## 일반적인 변형 및 엣지 케이스 처리

### 빈 데이터 소스

`orders`가 비어 있으면 스마트 마커 프로세서는 **새 워크시트를 전혀 생성하지** 않습니다. 빈 워크북을 방지하려면 방어 코드를 추가하세요:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### 시트 이름에 특수 문자 포함

Excel 시트 이름에는 `\ / ? * [ ] :`를 포함할 수 없습니다. 사용하기 전에 필드를 정리하세요:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### 대용량 데이터 세트

수천 개의 행을 처리할 경우 JVM 힙(`-Xmx2g`)을 늘리고, 모든 시트가 생성된 후에만 `workbook.calculateFormula()`를 호출하여 성능을 향상시키세요.
