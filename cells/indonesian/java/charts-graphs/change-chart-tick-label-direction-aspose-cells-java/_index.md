# Cara mengubah arah tick diagram di Java menggunakan Aspose.Cells

## Pendahuluan

Mengubah arah tick diagram adalah cara umum untuk meningkatkan keterbacaan diagram Excel, terutama ketika berhadapan dengan nama kategori yang panjang atau kumpulan data yang padat. Dalam panduan ini Anda akan belajar **cara mengubah arah tick diagram** dengan Aspose.Cells untuk Java, mulai dari pemasangan pustaka hingga menyimpan workbook akhir. Kami juga akan membahas mengapa rotasi label yang tepat penting untuk laporan keuangan, visualisasi ilmiah, dan dasbor bisnis.

## Jawaban singkat
- **Pustaka apa yang menangani rotasi label diagram?** Aspose.Cells untuk Java.  
- **Artefak Maven mana yang menambahkan fungsionalitas ini?** `com.aspose:aspose-cells`.  
- **Bisakah saya mengatur sudut label menjadi vertikal?** Ya, gunakan `ChartTextDirectionType.VERTICAL`.  
- **Apakah saya memerlukan lisensi untuk penggunaan produksi?** Lisensi permanen diperlukan; lisensi sementara dapat digunakan untuk evaluasi.  
- **Apakah API kompatibel dengan Java 8 dan yang lebih baru?** Ya, mendukung Java 8‑21.

## Apa itu mengubah arah tick diagram?
**Mengubah arah tick diagram** mengacu pada penyesuaian orientasi label tick sumbu kategori (misalnya, horizontal, vertikal, atau diputar) sehingga mereka lebih cocok dalam area diagram. Operasi ini dilakukan melalui metode `setTickLabelDirection` pada objek `ChartAxis` di Aspose.Cells.

## Mengapa menggunakan Aspose.Cells untuk Java untuk memutar label tick?
Aspose.Cells memproses **lebih dari 150 format file**, dapat menangani workbook dengan **lebih dari 500 lembar kerja** tanpa memuat seluruh file ke memori, dan melakukan rotasi label dalam **kurang dari 0,2 detik** untuk ukuran diagram tipikal. Kemampuan terkuantifikasi ini menjadikannya pilihan andal untuk otomatisasi Excel tingkat perusahaan.

## Prasyarat
- **Aspose.Cells untuk Java** versi 25.3 atau yang lebih baru.  
- Kit pengembangan Java 8+ dan IDE pilihan Anda (IntelliJ IDEA, Eclipse, dll.).  
- Maven atau Gradle untuk manajemen dependensi.  
- Lisensi Aspose.Cells sementara atau permanen (lihat bagian lisensi di bawah).

## Menyiapkan Aspose.Cells untuk Java
Untuk memulai, tambahkan dependensi Aspose.Cells ke file build Anda.

**Maven**  
```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>25.3</version>
    <classifier>jdk17</classifier>
</dependency>
```

**Gradle**  
```gradle
implementation 'com.aspose:aspose-cells:25.3:jdk17'
```

## Bagaimana cara mengubah arah tick diagram di Java?
Untuk memodifikasi orientasi label tick, Anda harus memuat workbook target, mengambil diagram tertentu, mengakses sumbu kategori, dan memanggil `setTickLabelDirection` dengan `ChartTextDirectionType` yang diinginkan. Urutan ini dapat dilakukan dalam beberapa baris kode Java, sehingga mudah diintegrasikan ke dalam alur kerja otomatisasi yang ada.

1. Muat workbook yang berisi diagram yang ingin Anda ubah.  
2. Ambil lembar kerja dan objek diagram berdasarkan indeksnya.  
3. Akses sumbu kategori (`getCategoryAxis()`) dan panggil `setTickLabelDirection` dengan `ChartTextDirectionType` yang diinginkan.  
4. Simpan workbook ke file baru.

## Panduan implementasi

### Memuat workbook dan diagram
Kelas `Workbook` mewakili seluruh file Excel dalam memori. Kelas `Worksheet` memberi Anda akses ke lembar individual, dan kelas `Chart` mewakili diagram tertentu.

```java
Workbook workbook = new Workbook("input.xlsx");               // 1️⃣ Load file
Worksheet sheet = workbook.getWorksheets().get(0);            // 2️⃣ First sheet
Chart chart = sheet.getCharts().get(0);                       // 3️⃣ First chart on the sheet
```

### Mengubah arah label tick
`ChartAxis` mengontrol semua properti yang terkait sumbu. `ChartTextDirectionType` adalah enumerasi yang menentukan orientasi.

```java
ChartAxis categoryAxis = chart.getCategoryAxis();            // Access category axis
categoryAxis.setTickLabelDirection(ChartTextDirectionType.HORIZONTAL); // 4️⃣ Set direction
```

- `ChartTextDirectionType.HORIZONTAL` → label dibaca dari kiri ke kanan.  
- `ChartTextDirectionType.VERTICAL` → label dibaca dari atas ke bawah.  
- `ChartTextDirectionType.ROTATED_45` → label diputar 45° (tersedia pada versi yang lebih baru).

### Menyimpan workbook
Setelah menyesuaikan sumbu, persisten perubahan:

```java
workbook.save("output.xlsx", SaveFormat.XLSX);
```

## Masalah umum dan solusinya
- **Indeks diagram tidak tepat** – Verifikasi diagram ada dengan memeriksa `sheet.getCharts().getCount()`.  
- **Lisensi tidak diterapkan** – Jika Anda melihat watermark, pastikan file lisensi dimuat sebelum operasi workbook apa pun.  
- **Arah tidak didukung** – Beberapa tipe diagram lama hanya mendukung label horizontal; tingkatkan ke versi Aspose.Cells terbaru untuk mengakses semua nilai enum.

## Aplikasi praktis
Mengubah arah label tick sangat berguna dalam skenario dengan ruang terbatas:

1. **Garis waktu keuangan** – Label horizontal menjaga string tanggal tetap terbaca pada diagram deret waktu yang padat.  
2. **Plot ilmiah** – Label vertikal membebaskan ruang horizontal untuk nama variabel yang lebih panjang.  
3. **Dasbor bisnis** – Label diputar mencegah tumpang tindih teks pada diagram batang multi‑kategori.

## Pertimbangan kinerja
Saat memproses workbook dengan **ratusan diagram**, ikuti praktik terbaik berikut:

- Muat workbook sekali dan gunakan kembali instance `Workbook` yang sama.  
- Terapkan perubahan label dalam loop, kemudian panggil `workbook.save` satu kali untuk meminimalkan I/O.  
- Gunakan flag `setCalculateFormula` hanya ketika Anda perlu menghitung ulang rumus setelah modifikasi.

## Pertanyaan yang sering diajukan

**T: Bisakah saya memutar label tick ke sudut arbitrer?**  
J: Aspose.Cells saat ini mendukung nilai enum yang telah ditentukan (horizontal, vertikal, 45°). Untuk sudut khusus Anda dapat menggabungkan rotasi dengan `setTickLabelAlignment`.

**T: Apakah API bekerja dengan file Excel yang dilindungi kata sandi?**  
J: Ya. Muat workbook dengan `new Workbook("file.xlsx", new LoadOptions(LoadFormat.XLSX) {{ setPassword("pwd"); }})`.

**T: Apakah ada batasan jumlah diagram yang dapat saya ubah dalam satu workbook?**  
J: Tidak ada batas keras; kinerja bergantung pada memori yang tersedia. Memproses workbook dengan 1.000 diagram biasanya selesai dalam kurang dari 30 detik pada server standar.

**T: Bagaimana cara menerapkan lisensi sementara secara programatik?**  
J: Kelas `License` memuat dan menerapkan file lisensi Aspose.Cells Anda pada runtime. Buat objek `License` dan panggil `setLicense("Aspose.Total.Java.lic")` sebelum operasi Aspose.Cells apa pun.

**T: Apakah mengubah arah tick memengaruhi seri data yang ada?**  
J: Tidak. Operasi ini hanya memodifikasi rendering label sumbu; nilai data tetap tidak berubah.

import com.aspose.cells.*;

public class ChangeTickLabelDirection {
    public static void main(String[] args) throws Exception {
        // Set up directories for source and output files
        String sourceDir = Utils.Get_SourceDirectory();
        String outputDir = Utils.Get_OutputDirectory();

        // Load the workbook from a file
        Workbook workbook = new Workbook(sourceDir + "SampleChangeTickLabelDirection.xlsx");
        
        // Get the first worksheet in the workbook

        Chart chart = worksheet.getCharts().get(0);
    }
}

// Change tick label orientation to horizontal
