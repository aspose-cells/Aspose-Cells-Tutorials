# Buat lembar detail di Java dengan smart markers Aspose.Cells

Jika Anda perlu **membuat lembar detail** dalam aplikasi Java, tutorial ini menunjukkan cara melakukannya dengan smart markers Aspose.Cells. Anda akan melihat contoh lengkap yang dapat dijalankan yang **java create worksheets**, menurunkan **sheet name from field**, dan **process data source** dalam hanya beberapa baris kode.

Panduan ini mencakup semua hal mulai dari penyiapan proyek hingga menyimpan workbook akhir, sehingga Anda dapat menyalin‑tempel solusi ke dalam proyek Anda sendiri dan langsung menyesuaikannya. Tidak diperlukan dokumentasi eksternal—semua yang Anda butuhkan ada di sini.

## Apa yang akan Anda pelajari

* Cara **use smart markers** untuk menduplikasi lembar kerja templat untuk setiap baris dalam kumpulan data master.  
* Cara mengatur nama setiap lembar baru secara dinamis berdasarkan nilai bidang (misalnya, `Order_123`).  
* Cara memberi koleksi Java sebagai **process data source** untuk mesin smart marker.  
* Tips menangani kasus tepi seperti data kosong, karakter khusus dalam nama lembar, dan pertimbangan kinerja untuk kumpulan data besar.

### Prasyarat

| Persyaratan | Alasan |
|-------------|--------|
| Java 8 or higher | Aspose.Cells for Java mendukung Java 8+. |
| Maven atau sistem build Gradle | Mempermudah menambahkan dependensi Aspose.Cells. |
| Pengetahuan dasar tentang koleksi Java | Diperlukan untuk membangun sumber data bagi smart markers. |
| File Excel templat (`Template.xlsx`) dengan smart marker placeholder di sel **A1** | Templat menggerakkan pembuatan lembar detail. |

> **Pro tip:** Simpan workbook templat di folder `resources` proyek sehingga terpaket bersama JAR Anda.

## Langkah 1: Tambahkan Aspose.Cells ke proyek Anda (java create worksheets)

Jika Anda menggunakan **Maven**, tambahkan dependensi berikut ke `pom.xml`:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.9</version> <!-- Use the latest stable version -->
</dependency>
```

Untuk **Gradle**, letakkan baris ini di `build.gradle`:

```gradle
implementation 'com.aspose:aspose-cells:24.9'
```

Baris‑baris ini membuat API **java create worksheets** tersedia pada saat kompilasi.

## Langkah 2: Muat workbook templat

```java
import com.aspose.cells.*;

public class DuplicateDetailSheets {
    public static void main(String[] args) throws Exception {
        // Load the template workbook located in the resources folder
        Workbook workbook = new Workbook(
            DuplicateDetailSheets.class.getResource("/Template.xlsx").getPath()
        );
```

*Mengapa ini penting:* Objek `Workbook` adalah titik masuk untuk semua operasi Excel. Memuat templat memastikan Anda memulai dengan tata letak yang benar dan format yang telah ditentukan sebelumnya.

## Langkah 3: Sisipkan smart marker yang membuat lembar baru per baris master (use smart markers)

```java
        // Get the first worksheet (index 0) where the smart marker will be placed
        Worksheet worksheet = workbook.getWorksheets().get(0);

        // Insert a smart marker that tells Aspose.Cells to create a new detail sheet
        // for each row in the "Orders" collection. The new sheet name is based on
        // the OrderId field, e.g., "Order_123".
        worksheet.getCells().putValue(
            "A1",
            "${Orders:DetailSheetNewName=Order_${OrderId}}"
        );
```

Sintaks `${Orders:DetailSheetNewName=Order_${OrderId}}` adalah inti dari **use smart markers**. Sintaks ini melakukan tiga hal:

1. Mengiterasi koleksi `Orders`.  
2. Membuat **worksheet baru** untuk setiap elemen.  
3. Menetapkan **sheet name from field** `OrderId` (dengan awalan `Order_`).

## Langkah 4: Siapkan sumber data (process data source)

Di bawah ini contoh minimal menggunakan `List<Map<String, Object>>`. Ganti dengan sumber data nyata Anda—baris basis data, deserialisasi JSON, dll.

```java
        // Simulated data source: a list of orders, each represented as a map
        List<Map<String, Object>> orders = new ArrayList<>();

        Map<String, Object> order1 = new HashMap<>();
        order1.put("OrderId", 101);
        order1.put("Customer", "Acme Corp");
        order1.put("Amount", 2500.75);
        orders.add(order1);

        Map<String, Object> order2 = new HashMap<>();
        order2.put("OrderId", 102);
        order2.put("Customer", "Beta Ltd");
        order2.put("Amount", 1800.00);
        orders.add(order2);

        // Wrap the list in a data source object that Aspose.Cells can consume
        // The key "Orders" matches the smart marker name used in Step 3.
        HashMap<String, Object> dataSource = new HashMap<>();
        dataSource.put("Orders", orders);
```

*Mengapa ini penting:* Langkah **process data source** mengikat koleksi Java Anda ke mesin smart marker. Kunci (`"Orders"`) harus persis sama dengan nama smart marker.

## Langkah 5: Proses smart markers (process data source)

```java
        // Execute the smart marker processor – this creates the detail sheets
        worksheet.getSmartMarkerProcessor().process(dataSource);
```

Saat `process` dijalankan, Aspose.Cells membaca koleksi `Orders`, menggandakan worksheet templat untuk setiap entri, dan mengganti nama setiap lembar sesuai bidang `OrderId`. Inilah inti penggunaan **process data source**.

## Langkah 6: Simpan workbook dengan lembar detail yang digandakan

```java
        // Save the workbook to the output directory
        workbook.save("DuplicatedDetailSheets.xlsx");
        System.out.println("Workbook saved successfully with " + orders.size() + " detail sheets.");
    }
}
```

Setelah eksekusi, Anda akan menemukan `DuplicatedDetailSheets.xlsx` yang berisi:

* `Sheet1` – templat asli (tidak berubah).  
* `Order_101` – lembar detail untuk pesanan pertama.  
* `Order_102` – lembar detail untuk pesanan kedua.

### Output yang diharapkan (kutipan)

| Nama lembar | A1 (smart marker) | Konten hasil |
|------------|-------------------|--------------|
| Order_101  | `${Orders:...}`   | Terisi dengan data dari `order1` |
| Order_102  | `${Orders:...}`   | Terisi dengan data dari `order2` |

Buka file di Excel untuk memverifikasi bahwa setiap lembar dinamai dengan benar dan berisi baris data.

## Menangani variasi umum dan kasus tepi

### Sumber data kosong

Jika `orders` kosong, pemroses smart marker tidak membuat **new worksheets**. Untuk menghindari workbook kosong, tambahkan penjagaan:

```java
if (orders.isEmpty()) {
    System.out.println("No orders to process – workbook will contain only the template.");
} else {
    worksheet.getSmartMarkerProcessor().process(dataSource);
}
```

### Karakter khusus dalam nama lembar

Nama lembar Excel tidak boleh mengandung `\ / ? * [ ] :`. Bersihkan bidang sebelum menggunakannya:

```java
String safeName = ("Order_" + orderId).replaceAll("[\\\\/:*?\\[\\]]", "_");
```

### Kumpulan data besar

Untuk ribuan baris, pertimbangkan meningkatkan heap JVM (`-Xmx2g`) dan memanggil `workbook.calculateFormula()` hanya setelah semua lembar dihasilkan untuk meningkatkan kinerja.
