# Cara menghasilkan lembar kerja di Java menggunakan SmartMarkerProcessor

Jika Anda perlu **cara menghasilkan lembar kerja** dalam file Excel, panduan ini menunjukkan solusi lengkap yang siap dijalankan. Pada akhir dua kalimat pertama Anda akan memahami cara menghasilkan lembar kerja dan lembar Excel dinamis dari kumpulan objek, dan Anda akan memiliki contoh kode yang berfungsi yang mengotomatiskan pembuatan Excel dengan satu panggilan metode.

Membuat lembar kerja terpisah untuk setiap karyawan, proyek, atau entitas lain merupakan kebutuhan umum ketika Anda perlu **populate excel workbook** data secara programatis. Tutorial ini membahas setiap langkah—dari menyiapkan templat hingga memproses daftar dan menyimpan file akhir—sehingga Anda dapat langsung menerapkan teknik ini dalam aplikasi Java Anda.

## Apa yang akan Anda capai

* Hasilkan lembar kerja master yang menampilkan informasi tingkat tinggi.  
* Buat data **multiple sheets from list**, setiap lembar secara otomatis diberi nama.  
* **Automate excel creation** tanpa menambahkan baris atau kolom secara manual.  
* **Populate excel workbook** dengan struktur data yang kaya (objek, peta, array).  

Prasyarat:

* Java 8 atau lebih baru terpasang.  
* Maven (atau alat build lain) untuk menambahkan pustaka Aspose.Cells for Java.  
* Pemahaman dasar tentang koleksi Java.  

> **Pro tip:** Sintaks SmartMarker (`${EmployeeMaster}`) bekerja dengan tipe koleksi apa pun yang mengimplementasikan `java.util.Collection`. Gunakan untuk menjaga templat Anda tetap bersih dan mudah dipelihara.

## Cara menghasilkan lembar kerja dengan SmartMarkerProcessor

Bagian ini berisi kode inti yang membuat **cara menghasilkan lembar kerja** menjadi mudah. Kami akan menjelaskan mengapa setiap baris penting, bukan hanya apa yang dilakukannya.

### Langkah 1: Tambahkan dependensi Aspose.Cells

Jika Anda menggunakan Maven, sertakan berikut ini dalam `pom.xml` Anda. Pustaka ini menyediakan kelas `SmartMarkerProcessor` yang digunakan di seluruh panduan ini.

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>24.10</version> <!-- latest stable version as of 2026 -->
</dependency>
```

> **Why:** Aspose.Cells menangani I/O file Excel, parsing Smart Marker, dan manajemen lembar secara internal, memungkinkan Anda fokus pada data daripada operasi file tingkat rendah.

### Langkah 2: Siapkan templat Excel

Buat file Excel bernama `EmployeeTemplate.xlsx` dengan satu sel yang berisi placeholder Smart Marker:

| A |
|---|
| `${EmployeeMaster}` |

Saat processor dijalankan, ia akan menggantikan placeholder ini dengan **detail sheet** yang berisi satu baris per karyawan.

> **Why:** Placeholder memberi tahu processor di mana menyuntikkan data. Menggunakan templat terpisah menjaga format Anda (font, batas, lebar kolom) tetap utuh.

### Langkah 3: Definisikan model data

Berikut adalah kelas `Employee` minimal dan metode pembantu yang membangun daftar karyawan. Daftar ini akan digunakan untuk mendemonstrasikan **multiple sheets from list**.

```java
import java.util.*;

public class Employee {
    public String firstName;
    public String lastName;
    public String department;

    public Employee(String firstName, String lastName, String department) {
        this.firstName   = firstName;
        this.lastName    = lastName;
        this.department  = department;
    }
}
```

```java
// Helper to generate sample data
private static List<Employee> getSampleEmployees() {
    return Arrays.asList(
        new Employee("John", "Doe", "Sales"),
        new Employee("Jane", "Smith", "Marketing"),
        new Employee("Bob", "Johnson", "Engineering")
    );
}
```

> **Why:** Objek Java sederhana (POJO) langsung dipetakan ke bidang Smart Marker (`firstName`, `lastName`, `department`). Ini membuat **populate excel workbook** menjadi sederhana dan aman tipe.

### Langkah 4: Siapkan SmartMarkerProcessor

Sekarang kami menghubungkan semuanya. Processor akan membaca templat, mengganti marker, dan membuat lembar baru bernama `EmployeeDetail`.

```java
import com.aspose.cells.*;

public class GenerateWorksheetsExample {
    public static void main(String[] args) throws Exception {
        // Load the template workbook
        Workbook wb = new Workbook("EmployeeTemplate.xlsx");

        // Build the data source
        List<Employee> employees = getSampleEmployees();
        HashMap<String, Object> data = new HashMap<>();
        data.put("EmployeeMaster", employees); // <-- Smart Marker key

        // Initialize SmartMarkerProcessor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Rename the automatically generated detail sheet
        processor.setDetailSheetNewName("EmployeeDetail");

        // Process the workbook – this is where **how to generate worksheets** happens
        processor.process(wb, data);

        // Save the result
        wb.save("EmployeesReport.xlsx");
        System.out.println("Workbook generated successfully.");
    }

    // (Insert the Employee class and getSampleEmployees() method here)
}
```

**Penjelasan baris kunci**

| Baris | Alasan |
|------|--------|
| `Workbook wb = new Workbook("EmployeeTemplate.xlsx");` | Memuat templat yang sudah berisi placeholder Smart Marker. |
| `data.put("EmployeeMaster", employees);` | Mengikat daftar Java ke marker `${EmployeeMaster}`. |
| `processor.setDetailSheetNewName("EmployeeDetail");` | Memberi nama yang bermakna pada lembar yang dihasilkan alih-alih `Sheet1` default. |
| `processor.process(wb, data);` | **Cara menghasilkan lembar kerja** – processor membaca marker, membuat lembar baru, dan mengisinya dengan baris untuk setiap `Employee`. |
| `wb.save("EmployeesReport.xlsx");` | Menyimpan **dynamic excel sheets** ke disk. |

### Langkah 5: Verifikasi output

Buka `EmployeesReport.xlsx`. Anda harus melihat dua lembar kerja:

1. **Sheet1** – templat asli (bisa disembunyikan atau dihapus).  
2. **EmployeeDetail** – **dynamic excel sheet** dengan kolom `firstName`, `lastName`, `department` dan satu baris per karyawan.

```
| firstName | lastName | department |
|-----------|----------|------------|
| John      | Doe      | Sales      |
| Jane      | Smith    | Marketing  |
| Bob       | Johnson  | Engineering|
```

> **Why this matters:** File kini berisi **multiple sheets from list** tanpa looping manual atau penunjukan sel. Mesin Smart Marker menangani pembuatan baris, konversi data, dan pewarisan format.

### Langkah 6: Tangani kasus tepi

#### Daftar data kosong

Jika `employees` kosong, processor tetap membuat lembar `EmployeeDetail` tetapi membiarkannya kosong. Anda dapat mencegah lembar ditambahkan dengan memeriksa ukuran koleksi sebelum memproses:

```java
if (!employees.isEmpty()) {
    processor.process(wb, data);
}
```

#### Daftar sangat besar

Untuk ribuan baris, pertimbangkan meningkatkan alokasi memori (`-Xmx2g`) atau menggunakan `processor.setAutoFitRows(false)` untuk mempercepat pemrosesan.

#### Penamaan lembar khusus per grup

Jika Anda memerlukan lembar terpisah untuk setiap departemen, Anda dapat menggunakan **multiple detail sheets**:

```java
processor.setDetailSheetNewName("Dept_${department}");
processor.setDetailSheetNewNameIsPattern(true); // enables pattern replacement
```

Placeholder `${department}` diambil dari setiap objek `Employee`, menghasilkan lembar seperti `Dept_Sales`, `Dept_Marketing`, dll.
