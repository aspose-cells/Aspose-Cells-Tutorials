# Cara Membuat Workbook Excel di Java dengan Data JSON

Jika Anda perlu **create Excel workbook java** pengembang sering menghadapi tantangan memuat data JSON ke dalam spreadsheet. Panduan ini menunjukkan cara **populate Excel from JSON**, termasuk cara **convert JSON array excel** dan **populate workbook from json** secara bersih dan dapat diulang.

Bekerja dengan JSON umum ketika layanan menyediakan data melalui REST API, dan Excel tetap format pilihan untuk pelaporan serta analisis. Pada akhir tutorial ini Anda akan memiliki program Java yang dapat dijalankan dan:

* membuat workbook Excel baru,
* membaca sebuah array JSON (atau struktur JSON apa pun) dan menulis nilainya ke sel,
* menyimpan file ke disk siap untuk proses lanjutan.

Tidak diperlukan alat eksternal selain pustaka Aspose.Cells for Java, yang menyediakan `SmartMarkerProcessor` yang digunakan dalam contoh kode.

## Prasyarat

Sebelum memulai, pastikan Anda memiliki:

| Prasyarat | Alasan |
|--------------|--------|
| Java Development Kit (JDK) ≥ 8 | Diperlukan untuk mengompilasi dan menjalankan contoh |
| Maven atau Gradle (opsional) | Mempermudah manajemen dependensi |
| Aspose.Cells for Java (v23.10 atau lebih baru) | Menyediakan kelas `Workbook` dan `SmartMarkerProcessor` |
| Pengetahuan dasar tentang JSON dan Java I/O | Membantu Anda memahami alur data |

Jika Anda lebih memilih tidak menggunakan alat build, Anda dapat mengunduh JAR Aspose.Cells dari [Aspose website](https://products.aspose.com/cells/java/) dan menambahkannya ke classpath proyek Anda secara manual.

## Langkah 1: Siapkan proyek dan tambahkan dependensi Aspose.Cells

### Pengguna Maven

Tambahkan dependensi berikut ke `pom.xml` Anda:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.10</version>
    <classifier>jdk17</classifier> <!-- adjust for your JDK version -->
</dependency>
```

### Pengguna Gradle

```gradle
implementation 'com.aspose:aspose-cells:23.10:jdk17'
```

Jika Anda tidak menggunakan alat build, letakkan JAR yang diunduh di folder `libs/` dan sertakan pada classpath saat kompilasi:

```bash
javac -cp "libs/aspose-cells-23.10.jar" CreateWorkbookFromJson.java
```

## Langkah 2: Buat workbook baru dan konfigurasikan SmartMarker processor

`SmartMarkerProcessor` menyederhanakan pemetaan nilai JSON ke sel Excel. Dengan memanggil `setArrayAsSingle(true)` kami memberi tahu processor untuk memperlakukan seluruh array JSON sebagai satu nilai, yang berguna ketika Anda ingin setiap elemen menempati selnya masing‑masing dalam satu baris.

```java
import com.aspose.cells.*;

public class CreateWorkbookFromJson {

    public static void main(String[] args) throws Exception {
        // Step 2.1: Create a fresh workbook (empty Excel file)
        Workbook workbook = new Workbook();

        // Step 2.2: Initialise the SmartMarker processor
        SmartMarkerProcessor processor = new SmartMarkerProcessor();

        // Treat the whole array as a single value so we can write each element into separate cells
        processor.setArrayAsSingle(true);
```

**Mengapa ini penting:**  
Membuat workbook terlebih dahulu memberi Anda kanvas yang bersih. Mengkonfigurasi `setArrayAsSingle(true)` mencegah processor mengubah array menjadi satu string (misalnya `["A","B","C"]`) dan sebaliknya memungkinkan Anda mengatur tata letak secara manual.

## Langkah 3: Definisikan data JSON yang ingin dimasukkan

Untuk tutorial ini kami menggunakan array JSON sederhana, tetapi pendekatan yang sama berlaku untuk objek, array bersarang, atau struktur kompleks.

```java
        // Step 3: Define JSON data – a simple array of strings
        String jsonData = "[\"A\",\"B\",\"C\"]";
```

**Tip:** Jika JSON Anda berasal dari file atau endpoint REST, ganti string literal dengan `String` yang dibaca dari sumber, misalnya `Files.readString(Paths.get("data.json"))`.

## Langkah 4: Proses workbook dengan data JSON

Sekarang kami biarkan `SmartMarkerProcessor` memetakan array JSON ke lembar kerja pertama. Perilaku default menulis setiap elemen ke sel berurutan mulai dari `A1`.

```java
        // Step 4: Apply the JSON data to the workbook
        processor.process(workbook, jsonData);
```

Di balik layar, Aspose.Cells mem-parsing JSON, membuat tabel data sementara, dan menulis nilai ke lembar kerja. Karena kami mengatur `ArrayAsSingle` menjadi `true`, elemen array ditempatkan secara horizontal pada baris pertama.

## Langkah 5: Simpan workbook ke file

```java
        // Step 5: Save the populated workbook
        String outputPath = "CreatedFromJson.xlsx";
        workbook.save(outputPath, SaveFormat.XLSX);
        System.out.println("Workbook saved to " + outputPath);
    }
}
```

Saat Anda menjalankan program, Anda akan melihat file bernama **CreatedFromJson.xlsx** di direktori kerja Anda. Membukanya dengan Excel (atau penampil kompatibel lainnya) akan menampilkan:

| A | B | C |
|---|---|---|
| A | B | C | *(nilai muncul di sel A1, B1, C1)*

### Output yang diharapkan

```
Workbook saved to CreatedFromJson.xlsx
```

Dan lembar Excel terlihat seperti:

```
+---+---+---+
| A | B | C |
+---+---+---+
```

## Langkah 6: Menangani struktur JSON yang lebih kompleks (opsional)

### 6.1 Mengisi workbook dari objek JSON

Jika JSON Anda berupa objek bukan array, Anda tetap dapat menggunakan `SmartMarkerProcessor`. Contohnya:

```json
{
  "title": "Sales Report",
  "month": "July",
  "values": [1200, 1500, 1300]
}
```

```java
String jsonObject = "{\"title\":\"Sales Report\",\"month\":\"July\",\"values\":[1200,1500,1300]}";
processor.process(workbook, jsonObject);
```

Processor akan membuat named range (`title`, `month`, `values`) yang dapat Anda referensikan dalam template Excel menggunakan Smart Markers seperti `&=title` dan `&=values`.

### 6.2 Mengonversi array JSON bersarang menjadi daftar vertikal

Kadang‑kadang Anda memerlukan array mengisi kolom alih‑alih baris. Atur sel mulai secara manual sebelum memproses:

```java
Worksheet ws = workbook.getWorksheets().get(0);
Cell startCell = ws.getCells().get("A2"); // start at A2
processor.setStartCell(startCell.getName()); // tells SmartMarker where to begin
processor.process(workbook, jsonData);
```

Sekarang nilai **A**, **B**, **C** muncul di sel A2, A3, A4 masing‑masing.

## Kesalahan umum dan cara menghindarinya

| Masalah | Penyebab | Solusi |
|-------|-------|-----|
| **Array ditulis sebagai satu string** | `setArrayAsSingle(false)` (default) | Panggil `processor.setArrayAsSingle(true)` |
| **File tidak ditemukan saat menyimpan** | Path tidak valid atau izin menulis tidak ada | Gunakan path absolut atau pastikan direktori ada |
| **Kesalahan parsing JSON** | String JSON tidak valid | Validasi JSON dengan alat atau gunakan library seperti Jackson untuk menghasilkan string |
| **Sel tertimpa secara tidak sengaja** | Memproses lembar kerja yang sama berulang kali tanpa mereset sel mulai | Panggil `processor.setStartCell("A1")` sebelum setiap panggilan `process` |

## Pro tip: gunakan kembali workbook sebagai template

Alih‑alih memulai dari workbook kosong setiap kali, Anda dapat memuat template yang telah dirancang sebelumnya yang sudah berisi header, rumus, atau styling:

```java
Workbook template = new Workbook("ReportTemplate.xlsx");
SmartMarkerProcessor tmplProcessor = new SmartMarkerProcessor();
tmplProcessor.setArrayAsSingle(true);
tmplProcessor.process(template, jsonData);
template.save("ReportFromTemplate.xlsx", SaveFormat.XLSX);
```

Pendekatan ini menggabungkan kehalusan visual file Excel buatan tangan dengan otomatisasi **populate workbook from json**.
