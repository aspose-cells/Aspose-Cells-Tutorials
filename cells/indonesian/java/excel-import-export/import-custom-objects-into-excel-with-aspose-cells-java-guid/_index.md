# Impor objek khusus ke Excel dengan Aspose.Cells – Panduan Java

Jika Anda perlu **mengimpor objek khusus** ke lembar kerja Excel, panduan ini akan memandu Anda melalui proses lengkap menggunakan Aspose.Cells untuk Java. Anda akan melihat cara **mengimpor data ke Excel**, menerapkan gaya header tebal, dan menghasilkan file `.xlsx` yang siap dibagikan.

Mengekspor data tabular dari Java sering melibatkan penulisan sel per sel secara manual, yang rawan kesalahan dan sulit dipelihara. Dengan memanfaatkan API `importCustomObjects` Anda menghindari kode boilerplate, menjaga model data tetap utuh, dan memperoleh kontrol styling yang halus.

Dalam tutorial ini Anda akan:

* Membuat daftar objek Java `Map` yang meniru tabel data tipikal.
* Membuat gaya header yang dapat digunakan kembali (font tebal) dengan Aspose.Cells.
* Mengimpor objek khusus ke lembar kerja sambil menerapkan array gaya.
* Menyimpan workbook ke disk dan memverifikasi hasilnya.

Satu-satunya prasyarat adalah lingkungan pengembangan Java (JDK 8+ disarankan) dan pustaka Aspose.Cells untuk Java.

---

## Apa yang Anda perlukan

| Persyaratan | Alasan |
|-------------|--------|
| JDK 8 atau lebih baru | Diperlukan untuk mengompilasi dan menjalankan kode Java. |
| Aspose.Cells untuk Java (versi terbaru) | Menyediakan `Workbook`, `Worksheet`, dan API impor. |
| IDE atau alat build (mis., Maven, Gradle) | Menyederhanakan manajemen dependensi dan eksekusi. |
| Izin menulis ke folder untuk file output | Workbook disimpan sebagai `ImportWithStyle.xlsx`. |

Tambahkan dependensi Aspose.Cells ke `pom.xml` Anda jika menggunakan Maven:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-cells</artifactId>
    <version>23.12</version> <!-- Use the latest stable version -->
</dependency>
```

## Langkah 1: Siapkan objek khusus untuk diimpor

Langkah pertama adalah membuat koleksi yang mewakili baris‑baris yang ingin Anda tempatkan di Excel. Pada contoh ini kami menggunakan `List<Map<String,Object>>` di mana setiap map berfungsi seperti satu baris dengan nama kolom sebagai kunci.

```java
// Step 1 – Simulate a DataTable with a list of maps
List<Map<String, Object>> dataRows = new ArrayList<>();
dataRows.add(Map.of("Name", "Alice", "Score", 95));
dataRows.add(Map.of("Name", "Bob",   "Score", 82));
```

**Mengapa ini penting:**  
`importCustomObjects` mengharapkan array objek. Dengan menggunakan `Map`, Anda mempertahankan nama kolom, memungkinkan Aspose.Cells memetakan secara otomatis ke sel. Pendekatan ini mencerminkan `DataTable` tipikal di .NET atau `ResultSet` dari JDBC, sehingga kode dapat digunakan kembali di berbagai proyek.

---

## Langkah 2: Definisikan gaya header untuk diterapkan saat impor

Baris header yang jelas meningkatkan keterbacaan. Aspose.Cells memungkinkan Anda membuat objek `Style`, mengatur font menjadi tebal, dan melewatkannya melalui array `ImportTableOptions`.

```java
// Step 2 – Create a bold font style for the header row
Workbook tempWb = new Workbook(); // temporary workbook to obtain a style instance
Style headerStyle = tempWb.getWorksheets().get(0).getCells().get("A1").getStyle();
headerStyle.getFont().setBold(true);

// The ImportTableOptions API expects an array of styles; one entry per row.
// Here we provide a single style for the first row (the header).
Style[] styleArray = new Style[] { headerStyle };
```

**Mengapa ini penting:**  
Jika Anda mengabaikan array gaya, header akan muncul dengan font default, yang mungkin tidak menonjol. Dengan menyiapkan gaya sekali saja, Anda menghindari pemanggilan berulang untuk setiap baris dan menjaga logika impor tetap bersih.

---

## Langkah 3: Impor objek khusus dengan array gaya

Sekarang Anda menggabungkan data dan gaya, lalu memanggil `importCustomObjects`. Metode ini menempatkan data mulai dari sudut kiri‑atas (baris 0, kolom 0) dan secara otomatis menerapkan gaya header.

```java
// Step 3 – Import the custom objects into the target workbook
Workbook workbook = new Workbook();                     // target workbook
Worksheet sheet = workbook.getWorksheets().get(0);     // first worksheet

sheet.getCells().importCustomObjects(
        dataRows.toArray(),    // array of objects to import
        0,                     // start row (0‑based)
        0,                     // start column (0‑based)
        new ImportTableOptions().setStyleArray(styleArray));
```

**Mengapa ini penting:**  
`importCustomObjects` mengurai setiap map, membuat kolom berdasarkan kunci (`Name`, `Score`), dan menulis nilai ke sel yang sesuai. Objek `ImportTableOptions` memberi tahu Aspose.Cells untuk menggunakan `styleArray` pada baris pertama, sehingga Anda mendapatkan header tebal tanpa kode tambahan.

---

## Langkah 4: Simpan workbook dan verifikasi output

Akhirnya, tulis workbook ke file. File Excel yang dihasilkan berisi baris header yang bergaya diikuti oleh baris data.

```java
// Step 4 – Save the workbook as an .xlsx file
String outputPath = "YOUR_DIRECTORY/ImportWithStyle.xlsx";
workbook.save(outputPath);
System.out.println("Workbook saved to: " + outputPath);
```

**Hasil yang diharapkan:**  

| **Name** | **Score** |
|----------|----------|
| Alice    | 95       |
| Bob      | 82       |

Sel header (`Name`, `Score`) muncul dengan font tebal, sesuai gaya yang didefinisikan pada Langkah 2.

## Variasi umum dan kasus tepi

| Situasi | Penyesuaian yang disarankan |
|-----------|------------------------|
| **Urutan kolom yang berbeda** | Pastikan kunci `Map` dimasukkan dalam urutan yang diinginkan, atau gunakan POJO khusus dengan bidang beranotasi dan array `PropertyDescriptor`. |
| **Set data besar (>10 000 baris)** | Tingkatkan `ImportTableOptions.setMemorySetting(MemorySetting.MEMORY_PREFERENCE)` untuk menghindari `OutOfMemoryError`. |
| **Format angka khusus** | Tambahkan `Style` kedua dalam `styleArray` untuk baris data, misalnya set `NumberFormat` ke `"0"` untuk skor integer. |
| **Beberapa lembar kerja** | Panggil `importCustomObjects` pada setiap lembar kerja target, sesuaikan baris/kolom mulai sesuai kebutuhan. |
| **Teks header spesifik lokal** | Isi baris header secara manual sebelum impor, lalu terapkan gaya ke seluruh rentang menggunakan `Cells.applyStyle`. |

---

## Tips profesional untuk ekspor Java ke Excel yang kuat

* **Gunakan kembali workbook sementara** – Membuat `Workbook` baru untuk setiap gaya menambah beban. Simpan satu instance jika Anda memerlukan beberapa gaya.  
* **Validasi data sebelum impor** – Nilai null dalam map menjadi sel kosong; Anda dapat menggantinya dengan nilai default dengan memproses daftar terlebih dahulu.  
* **Tutup sumber daya** – Meskipun Aspose.Cells mengelola memori secara internal, memanggil `workbook.dispose()` secara eksplisit setelah menyimpan akan melepaskan sumber daya native dengan cepat.  
* **Setel `Workbook.setForceFullCalculation(true)`** jika workbook Anda berisi formula yang harus dihitung sebelum disimpan.
