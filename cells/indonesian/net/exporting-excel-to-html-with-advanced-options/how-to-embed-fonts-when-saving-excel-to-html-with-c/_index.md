# Cara menyematkan font saat menyimpan Excel ke HTML dengan C#

Menyematkan font saat menyimpan workbook Excel ke HTML adalah kebutuhan umum untuk mempertahankan tampilan persis spreadsheet Anda di berbagai browser. Jika Anda perlu mengekspor Excel ke HTML sambil menjaga jenis huruf aslinya, panduan ini menunjukkan solusi lengkap yang siap dijalankan.

Anda akan belajar cara **mengekspor Excel ke HTML**, **mengonversi Excel ke HTML** dengan font yang disematkan, dan menghindari masalah “font hilang” yang biasanya merusak tata letak pada mesin klien. Tidak diperlukan alat eksternal—hanya pustaka Aspose.Cells dan beberapa baris kode C#.

## Prasyarat

Sebelum memulai, pastikan Anda memiliki:

* .NET 6.0 (atau lebih baru) terpasang.
* Salinan berlisensi **Aspose.Cells for .NET** – versi percobaan gratis cukup untuk pengujian.
* IDE seperti Visual Studio 2022 atau VS Code.

Jika semua sudah tersedia, Anda dapat langsung melompat ke kode.

## Langkah 1: Buat workbook dan tambahkan data contoh

Pertama kami membuat workbook kecil sehingga Anda dapat melihat efek font yang disematkan. Kode di bawah ini membuat lembar kerja, menulis beberapa sel, dan menerapkan font khusus.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // 1️⃣ Initialize a new workbook
        Workbook wb = new Workbook();

        // 2️⃣ Access the first worksheet
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // 3️⃣ Populate some cells with data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");

        // 4️⃣ Apply a custom font (e.g., Arial Bold) to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;

        // Apply the style to the header cells
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);
```

### Mengapa kami menambahkan font khusus

Menyematkan font hanya penting ketika workbook menggunakan font yang mungkin tidak ada di perangkat klien. Dengan secara eksplisit menetapkan **Arial** (atau font lain) kami dapat memverifikasi bahwa output HTML benar‑benar berisi data font.

## Langkah 2: Konfigurasikan opsi penyimpanan HTML untuk menyematkan font

Aspose.Cells menyediakan kelas `HtmlSaveOptions`. Menetapkan `EmbedFonts = true` memberi tahu pustaka untuk menyematkan file font yang diperlukan langsung ke dalam HTML yang dihasilkan sebagai URI data Base64.

```csharp
        // 5️⃣ Configure HTML save options
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            // ✅ Embed all referenced fonts into the HTML file
            EmbedFonts = true,

            // Optional: make the HTML file self‑contained (no external CSS)
            ExportEmbeddedImages = true,

            // Optional: keep the original sheet name in the file name
            SheetName = sheet.Name
        };
```

### Apa yang sebenarnya dilakukan “embed fonts in html”

Ketika `EmbedFonts` bernilai true, Aspose.Cells mengekstrak file font dari sistem (atau dari koleksi font yang disematkan dalam workbook) dan mengonversinya menjadi string **Base64**. String‑string tersebut kemudian ditempatkan di dalam blok `<style>` menggunakan `@font-face`. HTML yang dihasilkan dapat dibuka di perangkat apa pun tanpa harus menginstal font asli.

## Langkah 3: Simpan workbook sebagai HTML dengan font yang disematkan

Sekarang kami menulis workbook ke disk. File akan berisi data font, sehingga membukanya di browser modern mana pun menampilkan tipografi yang persis sama dengan file Excel asli.

```csharp
        // 6️⃣ Save the workbook as HTML with embedded fonts
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

### Hasil yang diharapkan

* `embedded.html` berada di folder `output`.
* Membuka file tersebut di Chrome, Edge, atau Firefox menampilkan lembar kerja dengan teks **Arial**, bahkan jika mesin browser tidak memiliki Arial.
* Memeriksa sumber HTML memperlihatkan blok `<style>` yang berisi aturan `@font-face` dengan deklarasi panjang `src: url(data:font/ttf;base64,…)` – itulah font yang disematkan.

## Langkah 4: Verifikasi HTML berfungsi di mesin lain (opsional)

Untuk memastikan penyematan berhasil:

1. Salin `output/embedded.html` ke komputer lain (atau mesin virtual) yang **tidak** memiliki font khusus terinstal.
2. Buka file tersebut di browser.
3. Tata letak dan tipografi harus cocok dengan tampilan Excel asli.

Jika font beralih ke font generik, periksa kembali bahwa file font dapat diakses pada mesin build dan Anda memiliki izin untuk membacanya.

## Pertanyaan umum dan kasus tepi

### Apakah penyematan meningkatkan ukuran file?

Ya. Menyematkan font TrueType atau OpenType dapat menambah **puluhan kilobyte** ke file HTML. Untuk workbook besar dengan banyak font unik, pertimbangkan:

* Membatasi subset font (hanya karakter yang Anda gunakan) – Aspose.Cells melakukannya secara otomatis untuk sebagian besar font umum.
* Menggunakan `ExportEmbeddedImages = false` jika Anda tidak memerlukan gambar yang disematkan.

### Bagaimana jika saya hanya perlu menyematkan font tertentu?

`HtmlSaveOptions` tidak menyediakan daftar putih langsung, tetapi Anda dapat mengontrol font yang muncul dengan **membatasi font yang digunakan dalam workbook** sebelum memanggil `Save`. Hapus penetapan font yang tidak diperlukan atau ganti dengan font web‑safe standar.

### Bisakah saya menyematkan font saat mengonversi ke format lain (mis., PDF)?

Properti `EmbedFonts` yang sama ada pada `PdfSaveOptions`. Konsepnya identik: data font disematkan sehingga PDF ditampilkan dengan benar pada viewer mana pun.

## Contoh lengkap yang dapat dijalankan

Berikut adalah program lengkap yang dapat Anda salin‑tempel ke proyek konsol baru.

```csharp
using System;
using Aspose.Cells;

class Program
{
    static void Main()
    {
        // Create a new workbook
        Workbook wb = new Workbook();

        // Access the first worksheet and give it a name
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        // Fill cells with sample data
        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Revenue");
        sheet.Cells["A3"].PutValue("North America");
        sheet.Cells["B3"].PutValue(1250000);
        sheet.Cells["A4"].PutValue("Europe");
        sheet.Cells["B4"].PutValue(980000);

        // Apply a custom font to the header row
        Style headerStyle = wb.CreateStyle();
        Font headerFont = headerStyle.Font;
        headerFont.Name = "Arial";
        headerFont.IsBold = true;
        headerFont.Size = 12;
        sheet.Cells["A1"].SetStyle(headerStyle);
        sheet.Cells["A2"].SetStyle(headerStyle);
        sheet.Cells["B2"].SetStyle(headerStyle);

        // Configure HTML save options to embed fonts
        HtmlSaveOptions saveOptions = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportEmbeddedImages = true,
            SheetName = sheet.Name
        };

        // Save as HTML
        string outputPath = "output/embedded.html";
        wb.Save(outputPath, saveOptions);

        Console.WriteLine($"HTML file with embedded fonts created at: {outputPath}");
    }
}
```

Menjalankan program menghasilkan **file HTML yang berisi font Arial yang disematkan**, menjamin kesetiaan visual di mana pun file tersebut dibuka.

## Kesimpulan

Anda kini tahu **cara menyematkan font saat menyimpan Excel ke HTML** menggunakan C#. Dengan mengatur `HtmlSaveOptions.EmbedFonts = true`, Anda dapat dengan andal **mengekspor Excel ke HTML** dan **mengonversi Excel ke HTML** tanpa khawatir tentang font yang hilang di sisi klien. Teknik ini penting untuk pelaporan berbasis web, dasbor yang ramah email, atau skenario apa pun di mana Anda membagikan konten turunan Excel sebagai HTML.

### Apa selanjutnya?

* **Sesuaikan CSS** yang dihasilkan oleh Aspose.Cells agar sesuai dengan panduan gaya situs Anda.  
* **Sematkan gambar** secara selektif dengan mengaktifkan atau menonaktifkan `ExportEmbeddedImages`.  
* **Jelajahi format ekspor lain** seperti PDF atau SVG sambil tetap menyematkan font.  

Silakan bereksperimen dengan font yang berbeda, lembar kerja yang lebih besar, atau workbook multi‑sheet. Flag `EmbedFonts` yang sama bekerja di semua format output yang didukung, memberi Anda kontrol konsisten atas penyematan font di mana pun Anda membutuhkannya. Selamat coding!
