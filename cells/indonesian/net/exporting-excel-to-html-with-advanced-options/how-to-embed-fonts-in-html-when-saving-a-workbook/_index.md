# Cara menyematkan font dalam HTML saat menyimpan workbook

Jika Anda perlu **cara menyematkan font dalam HTML** saat mengekspor spreadsheet, tutorial ini menunjukkan solusi lengkap yang siap dijalankan. Baik Anda sedang membangun portal pelaporan atau tampilan analitik sisi‑klien, menyematkan font menjamin bahwa HTML yang dihasilkan tampak persis seperti workbook asli, terlepas dari font yang terpasang pada perangkat penampil.

Anda juga akan mempelajari cara **menyimpan workbook sebagai HTML** menggunakan Aspose.Cells, melihat jebakan umum, dan mendapatkan tip untuk menangani workbook besar atau file font khusus. Tidak diperlukan dokumentasi eksternal—semua yang Anda butuhkan ada dalam panduan ini.

## Prasyarat

Sebelum memulai, pastikan Anda memiliki:

- .NET 6.0 atau lebih baru (kode juga berfungsi dengan .NET Framework 4.7+)
- Lisensi Aspose.Cells for .NET yang valid (atau Anda dapat menggunakan mode evaluasi gratis)
- Pengetahuan dasar C# dan IDE seperti Visual Studio 2022
- File font TrueType (.ttf) atau OpenType (.otf) yang ingin Anda sematkan (harus dapat diakses oleh proses yang berjalan)

## Langkah 1: Siapkan proyek dan impor Aspose.Cells

Buat aplikasi console baru dan tambahkan paket NuGet Aspose.Cells:

```bash
dotnet new console -n WorkbookHtmlExport
cd WorkbookHtmlExport
dotnet add package Aspose.Cells
```

Kemudian buka **Program.cs** dan tambahkan direktif `using` yang diperlukan:

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;   // needed for HtmlSaveOptions
```

> **Pro tip:** Letakkan font khusus Anda dalam folder bernama `fonts` di dalam root proyek. Ini membuat solusi lebih portabel dan memudahkan referensi di kemudian hari.

## Langkah 2: Buat atau muat workbook

Untuk demonstrasi, kita akan membuat workbook sederhana dengan beberapa sel yang bergaya:

```csharp
// Step 2: Create a workbook and add data
Workbook wb = new Workbook();
Worksheet sheet = wb.Worksheets[0];
sheet.Name = "Report";

// Populate some cells
sheet.Cells["A1"].PutValue("Quarterly Sales");
sheet.Cells["A2"].PutValue("Region");
sheet.Cells["B2"].PutValue("Amount");

// Apply a custom style that uses a non‑system font
Style style = wb.CreateStyle();
style.Font.Name = "Pacifico";          // a font not guaranteed to exist on the client
style.Font.Size = 14;
style.Font.IsBold = true;

// Assign the style to the header row
sheet.Cells["A1"].SetStyle(style);
sheet.Cells["A2"].SetStyle(style);
sheet.Cells["B2"].SetStyle(style);
```

> **Mengapa ini penting:** Jika Anda melewatkan gaya khusus, HTML yang diekspor akan kembali ke font default browser, sehingga tujuan **cara menyematkan font dalam HTML** tidak tercapai.

## Langkah 3: Konfigurasikan `HtmlSaveOptions` untuk menyematkan font

Inti dari **cara menyematkan font dalam HTML** terletak pada kelas `HtmlSaveOptions`. Menetapkan `EmbedFonts = true` memberi tahu Aspose.Cells untuk menyematkan semua font TrueType/OpenType yang direferensikan langsung ke dalam HTML yang dihasilkan sebagai data URI yang di‑encode Base64.

```csharp
// Step 3: Create HTML save options with font embedding enabled
HtmlSaveOptions htmlOpt = new HtmlSaveOptions
{
    // Embeds all fonts used in the workbook into the HTML output
    EmbedFonts = true,

    // Optional: place the HTML file in a subfolder for better organization
    ExportToSingleFile = true,   // bundles CSS, images, and fonts into one .html file
    ExportActiveWorksheetOnly = true, // only the active sheet is exported
    // Set a custom folder for temporary resources (if ExportToSingleFile = false)
    // ResourcesFolder = "HtmlResources"
};
```

### Cara kerja penyematan

Saat `EmbedFonts` bernilai `true`, Aspose.Cells memindai definisi gaya workbook, menemukan file font yang bersesuaian di sistem (atau di folder `fonts` yang Anda tambahkan), membaca data biner mereka, dan menyuntikkan blok `<style>` serupa dengan:

```html
@font-face {
    font-family: 'Pacifico';
    src: url('data:font/ttf;base64,AAEAAAALAIAAAwAwT1MvMg8S...') format('truetype');
}
```

Karena data font di‑encode langsung dalam HTML, halaman akan dirender dengan benar bahkan pada mesin yang tidak memiliki font tersebut terpasang.

## Langkah 4: Simpan workbook sebagai HTML

Sekarang Anda dapat **menyimpan workbook sebagai HTML** dengan opsi yang telah dikonfigurasi. Pilih direktori yang dapat ditulisi oleh aplikasi (misalnya `output`).

```csharp
// Step 4: Ensure the output directory exists
string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
Directory.CreateDirectory(outputDir);

// Save the workbook as an HTML file using the options from Step 3
string htmlPath = Path.Combine(outputDir, "report.html");
wb.Save(htmlPath, htmlOpt);

Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
```

Menjalankan program menghasilkan satu file `report.html`. Buka file tersebut di browser modern apa pun dan Anda akan melihat header “Quarterly Sales” dirender dengan font **Pacifico**, meskipun font tersebut tidak terpasang di OS Anda.

### Output yang diharapkan

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8"/>
<title>Report</title>
<style>
@font-face{
    font-family:'Pacifico';
    src:url('data:font/ttf;base64,AAEAAA...') format('truetype');
}
...
</style>
</head>
<body>
<table>
<tr><td style="font-family:'Pacifico';font-size:14pt;font-weight:bold;">Quarterly Sales</td></tr>
...
</table>
</body>
</html>
```

Atribut `src:` berisi string Base64 yang panjang—ini adalah data font yang disematkan yang memungkinkan **cara menyematkan font dalam HTML**.

## Langkah 5: Verifikasi penyematan font dan pemecahan masalah

1. **Buka file HTML di Chrome atau Edge.** Jika font khusus muncul, penyematan berhasil.  
2. **Periksa sumber halaman.** Cari aturan `@font-face` yang dihasilkan oleh Aspose.Cells.  
3. **Masalah umum:**  
   - *File font tidak ditemukan:* Pastikan file font dapat dijangkau. Anda dapat secara eksplisit menambahkan folder ke jalur pencarian:

     ```csharp
     // Add custom font folder to Aspose.Cells FontSettings
     FontSettings fontSettings = new FontSettings();
     fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
     wb.FontSettings = fontSettings;
     ```

   - *Ukuran HTML besar:* Menyematkan banyak font dapat memperbesar file. Gunakan `ExportToSingleFile = false` untuk menyimpan font sebagai file `.ttf` terpisah di folder sumber daya.  

   - *Format font tidak didukung:* Aspose.Cells hanya menyematkan TrueType (`.ttf`) dan OpenType (`.otf`). Konversi format lain sebelum menyematkan.

## Contoh lengkap yang dapat dijalankan

Berikut adalah program lengkap yang dapat Anda salin, tempel, dan jalankan tanpa modifikasi (kecuali baris lisensi opsional).

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Rendering;

class Program
{
    static void Main()
    {
        // Optional: set your Aspose.Cells license to remove evaluation watermark
        // var license = new License();
        // license.SetLicense("Aspose.Cells.lic");

        // Step 2: Create workbook and style
        Workbook wb = new Workbook();
        Worksheet sheet = wb.Worksheets[0];
        sheet.Name = "Report";

        sheet.Cells["A1"].PutValue("Quarterly Sales");
        sheet.Cells["A2"].PutValue("Region");
        sheet.Cells["B2"].PutValue("Amount");

        Style style = wb.CreateStyle();
        style.Font.Name = "Pacifico"; // custom font
        style.Font.Size = 14;
        style.Font.IsBold = true;

        sheet.Cells["A1"].SetStyle(style);
        sheet.Cells["A2"].SetStyle(style);
        sheet.Cells["B2"].SetStyle(style);

        // Step 3: Configure HTML options with font embedding
        HtmlSaveOptions htmlOpt = new HtmlSaveOptions
        {
            EmbedFonts = true,
            ExportToSingleFile = true,
            ExportActiveWorksheetOnly = true
        };

        // Optional: point to a folder that contains custom fonts
        FontSettings fontSettings = new FontSettings();
        fontSettings.SetFontsFolder(Path.Combine(Directory.GetCurrentDirectory(), "fonts"), true);
        wb.FontSettings = fontSettings;

        // Step 4: Save as HTML
        string outputDir = Path.Combine(Directory.GetCurrentDirectory(), "output");
        Directory.CreateDirectory(outputDir);
        string htmlPath = Path.Combine(outputDir, "report.html");
        wb.Save(htmlPath, htmlOpt);

        Console.WriteLine($"Workbook successfully saved as HTML at: {htmlPath}");
    }
}
```

Menjalankan program ini membuat `output/report.html`. Buka file tersebut, dan Anda akan melihat font **Pacifico** dirender dengan benar—menunjukkan **cara menyematkan font dalam HTML** saat **menyimpan workbook sebagai HTML**.

## Pertanyaan yang sering diajukan

| Pertanyaan | Jawaban |
|------------|---------|
| *Apakah saya dapat menyematkan hanya font tertentu?* | Ya. Setel `htmlOpt.EmbedAllFonts = false` (tersedia pada versi terbaru) dan gunakan `htmlOpt.FontsToEmbed` untuk mencantumkan nama font yang tepat. |
| *Bagaimana jika saya perlu menyematkan font untuk beberapa lembar kerja?* | Setel `ExportActiveWorksheetOnly = false` sehingga setiap lembar kerja diekspor, dan Aspose.Cells akan menyematkan font yang digunakan di seluruh workbook. |
| *Apakah font yang disematkan akan berfungsi di browser seluler?* | Browser seluler modern mendukung font yang di‑encode Base64, sehingga font yang disematkan akan dirender dengan benar selama format font didukung (TTF atau OTF). |
| *Seberapa besar file HTML dapat menjadi?* | Menyematkan font TrueType berukuran 200 KB menambah kira‑kira ukuran yang sama ke HTML (Base64 menambah overhead ~33 %). Untuk banyak font, pertimbangkan mengekspor ke folder (`ExportToSingleFile = false`) agar HTML tetap ringan. |
