# Buat file excel c# – gaya sel dan atur format mata uang

Jika Anda perlu **create excel file c#** yang terlihat profesional, panduan ini menunjukkan secara tepat cara menata sel excel dan memformat sebuah kolom sebagai mata uang. Anda akan melihat contoh lengkap, end‑to‑end yang mengimpor `DataTable`, menerapkan header tebal, dan mengatur format angka `$#,##0.00` untuk kolom harga.

Tutorial ini mencakup semua yang Anda butuhkan: paket NuGet yang diperlukan, kode sumber lengkap, penjelasan mengapa setiap bagian penting, dan tip untuk menangani kasus tepi seperti baris kosong atau locale yang berbeda. Pada akhir tutorial Anda akan dapat menghasilkan file `.xlsx` dengan kolom harga yang diformat dengan rapi hanya dalam beberapa baris kode C#.

## Prasyarat

- .NET 6.0 atau lebih baru (kode juga berfungsi dengan .NET Framework 4.6+)
- Visual Studio 2022 atau editor C# apa pun yang Anda sukai
- Perpustakaan **Aspose.Cells for .NET** atau **GemBox.Spreadsheet** (keduanya mendukung `ImportTableOptions`). Contoh di bawah menggunakan **Aspose.Cells** karena menyediakan properti `StyleArray` yang sederhana.
- Pengetahuan dasar tentang koleksi C# dan `DataTable`

> **Pro tip:** Jika Anda lebih suka alternatif gratis, ganti `Aspose.Cells` dengan `GemBox.Spreadsheet`. API untuk mengimpor `DataTable` dengan gaya hampir identik; cukup ubah namespace dan nama paket NuGet.

## Langkah 1: Instal perpustakaan Excel

Buka NuGet Package Manager dan instal perpustakaan:

```bash
dotnet add package Aspose.Cells
```

> **Mengapa langkah ini?** Perpustakaan menyediakan kelas `Workbook`, `Worksheet`, `Style`, dan `ImportTableOptions` yang akan digunakan nanti. Tanpanya, Anda harus menulis format Office Open XML secara manual, yang rawan kesalahan.

## Langkah 2: Buat DataTable dengan data contoh

`DataTable` adalah cara yang nyaman untuk menyimpan data tabular sebelum mengekspornya ke Excel. Pada contoh ini kami memiliki dua kolom: *Product* dan *Price*.

```csharp
using System;
using System.Data;
using Aspose.Cells;

DataTable productTable = new DataTable();
productTable.Columns.Add("Product");
productTable.Columns.Add("Price", typeof(double));

productTable.Rows.Add("Pen", 1.2);
productTable.Rows.Add("Notebook", 3.5);
productTable.Rows.Add("Eraser", 0.75);
```

> **Penjelasan:**  
> - `Columns.Add("Price", typeof(double))` memberi tahu tabel untuk memperlakukan nilai harga sebagai angka, yang diperlukan untuk pemformatan angka nanti.  
> - Menambahkan beberapa baris memberi kami data untuk memverifikasi langkah **format column currency**.

## Langkah 3: Tentukan gaya yang ingin Anda terapkan

Kami akan membuat array objek `Style` yang sesuai dengan urutan kolom. Entri pertama menata baris header, yang kedua membiarkan kolom *Product* tidak berubah, dan yang ketiga menerapkan format angka mata uang.

```csharp
// Header style – bold font
Style headerStyle = new Style
{
    Font = new Font { Bold = true }
};

// Currency style – "$#,##0.00"
Style priceStyle = new Style
{
    Number = 164 // Built‑in number format for "$#,##0.00"
};

// Build the style array (header, product, price)
Style[] columnStyles = new[]
{
    headerStyle, // column 0 – header
    null,       // column 1 – Product (default)
    priceStyle  // column 2 – Price (currency)
};
```

### Mengapa menggunakan **style array**?

`ImportTableOptions.StyleArray` memetakan setiap kolom ke sebuah `Style`. Ini adalah cara paling efisien untuk **add number format** dan **style excel cells** dalam satu operasi impor, menghindari proses kedua pada lembar kerja.

## Langkah 4: Konfigurasikan opsi impor

Sekarang kami mengikat array gaya ke operasi impor. Objek `ImportTableOptions` juga memungkinkan Anda mengontrol apakah baris pertama diperlakukan sebagai header.

```csharp
ImportTableOptions importOptions = new ImportTableOptions
{
    StyleArray = columnStyles,
    // The first row of the DataTable will become the Excel header
    // (Aspose.Cells automatically writes the column names)
    IsFieldNameShown = true
};
```

> **Catatan:** `IsFieldNameShown` defaultnya `true`, tetapi mengaturnya secara eksplisit membuat niatnya jelas bagi pembaca di masa depan.

## Langkah 5: Buat workbook, impor tabel, dan simpan

```csharp
// Create a new workbook and get the first worksheet
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];

// Import the DataTable with the configured styles
worksheet.Cells.ImportDataTable(productTable, true, importOptions);

// Save the workbook to disk
string outputPath = @"C:\Temp\DataTableWithStyles.xlsx";
workbook.Save(outputPath);
Console.WriteLine($"Workbook saved to {outputPath}");
```

### Hasil yang diharapkan

Ketika Anda membuka `DataTableWithStyles.xlsx`:

- Baris pertama (header) **tebal**.
- Kolom *Price* menampilkan nilai sebagai **$1.20**, **$3.50**, **$0.75**.
- Kolom *Product* mempertahankan font default.

Anda telah berhasil **create excel file c#** dengan kolom mata uang yang diformat dan sel header yang ditata.

## Langkah 6: Menangani variasi umum dan kasus tepi

### a. Locale berbeda atau simbol mata uang khusus

Jika Anda membutuhkan Euro atau mata uang lain, ganti format bawaan `164` dengan string format khusus:

```csharp
priceStyle.Custom = "€#,##0.00";
```

### b. Menambahkan lebih banyak kolom nanti

Ketika Anda menambahkan kolom tambahan, perpanjang array `columnStyles` sesuai. Gunakan `null` untuk kolom yang harus mempertahankan gaya default.

```csharp
Style[] extendedStyles = new[]
{
    headerStyle,   // Header
    null,          // Product
    priceStyle,    // Price
    null           // New column – default
};
importOptions.StyleArray = extendedStyles;
```

### c. DataTable kosong

Jika `DataTable` tidak memiliki baris, Aspose.Cells tetap membuat baris header. Namun, workbook hanya akan berisi satu baris. Untuk menghindari file kosong, periksa jumlah baris sebelum mengimpor:

```csharp
if (productTable.Rows.Count > 0)
{
    worksheet.Cells.ImportDataTable(productTable, true, importOptions);
}
else
{
    Console.WriteLine("No data to export.");
}
```

### d. Menggunakan `GemBox.Spreadsheet` alih-alih Aspose.Cells

```csharp
using GemBox.Spreadsheet;

// License (free version limits rows/columns)
SpreadsheetInfo.SetLicense("FREE-LIMITED-KEY");

// Create a new workbook
var workbook = new ExcelFile();
var worksheet = workbook.Worksheets.Add("Products");

// Import with styles (GemBox uses a similar approach)
worksheet.InsertDataTable(productTable, new InsertDataTableOptions
{
    ColumnHeaders = true,
    Style = new ExcelStyle
    {
        Font = new ExcelFont { Bold = true } // Header style
    }
});

// Apply currency format to the third column (index 2)
worksheet.Columns[2].Style.NumberFormat = "$#,##0.00";

workbook.Save("DataTableWithStyles.xlsx");
```

Logika tetap identik, menunjukkan bahwa tutorial ini **format column currency** tidak bergantung pada perpustakaan yang mendasarinya.

## Langkah 7: Verifikasi file secara programatik (opsional)

Anda dapat membuka workbook yang dihasilkan dan memastikan bahwa format angka telah diterapkan dengan benar—berguna untuk unit test.

```csharp
Workbook verifyWb = new Workbook(outputPath);
Worksheet verifyWs = verifyWb.Worksheets[0];
Style verifyStyle = verifyWs.Cells["C2"].GetStyle();

bool isCurrency = verifyStyle.Number == 164; // true if "$#,##0.00"
Console.WriteLine(isCurrency ? "Currency format applied." : "Currency format missing.");
```

## Kesimpulan

Tutorial ini menunjukkan cara **create excel file c#**, **style excel cells**, dan **set currency format** untuk kolom tertentu menggunakan contoh singkat, end‑to‑end. Anda mempelajari:

1. Cara membangun `DataTable` dengan data numerik.  
2. Cara mendefinisikan **style array** yang menebalkan header dan **add number format** untuk kolom harga.  
3. Cara mengimpor tabel dengan `ImportTableOptions` dan menyimpan workbook.  
4. Cara menyesuaikan solusi untuk locale yang berbeda, kolom tambahan, data kosong, dan perpustakaan alternatif.

Dari sini Anda dapat menjelajahi styling yang lebih maju—conditional formatting, batas sel, atau auto‑sizing kolom. Bereksperimenlah dengan objek `Style` untuk mengubah font, warna latar, atau perataan, dan Anda akan memiliki solusi ekspor Excel lengkap untuk aplikasi C# apa pun.
