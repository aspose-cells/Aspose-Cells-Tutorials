# Cara membuat workbook Excel C# dengan format khusus dan menyimpannya sebagai XLSX

Jika Anda perlu **create Excel workbook C#** yang mengimpor data, menerapkan format angka khusus, dan mengubah warna font sel, tutorial ini menunjukkan cara melakukannya secara tepat. Anda akan mendapatkan contoh siap‑jalankan yang menghasilkan file `StyleArrayImport.xlsx` yang bergaya dalam hitungan detik.

Bekerja dengan Excel dari C# sering melibatkan langkah manual yang berulang—mendefinisikan format, menerapkan warna, dan mengingat untuk menyimpan file dengan benar. Pada akhir panduan ini Anda akan mengotomatisasi semua tugas tersebut, sehingga dapat fokus pada data bukan pada UI.

Anda akan belajar cara:

* mengimpor `DataTable` ke dalam worksheet,
* menggunakan `StyleArray` untuk **apply custom number format** dan **change cell font color**,
* **save workbook as XLSX** dengan satu pemanggilan metode,
* dan memverifikasi bahwa **format imported data excel** muncul persis seperti yang dimaksud.

Satu-satunya prasyarat adalah referensi ke perpustakaan **Aspose.Cells for .NET** (atau API kompatibel lain yang menyediakan `Workbook`, `Worksheet`, dan `StyleArray`). Kode ini menargetkan .NET 6+, tetapi versi sebelumnya juga dapat bekerja dengan penyesuaian kecil.

## Prerequisites

| Persyaratan | Alasan |
|-------------|--------|
| .NET 6 SDK or later | Menyediakan runtime untuk aplikasi konsol C#. |
| Aspose.Cells for .NET (NuGet package `Aspose.Cells`) | Menyediakan kelas `Workbook`, `Worksheet`, dan `StyleArray` yang digunakan dalam contoh. |
| Visual Studio 2022 (or any C# IDE) | Memudahkan kompilasi dan menjalankan contoh. |
| Basic knowledge of `DataTable` manipulation | Diperlukan untuk menghasilkan set data sumber. |

Install the Aspose.Cells package with the following command:

```bash
dotnet add package Aspose.Cells
```

## Langkah 1: Siapkan DataTable contoh

Pertama, buat `DataTable` yang meniru data yang biasanya Anda ambil dari basis data atau sumber lain. Tabel ini mencakup kolom **Name** (string) dan kolom **Amount** (decimal) yang akan kita format nanti.

```csharp
using System;
using System.Data;
using System.Drawing;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Create a DataTable with sample data
            DataTable dataTable = GetSampleTable();

            // The rest of the workflow follows...
        }

        /// <summary>
        /// Generates a DataTable with two columns: Name (string) and Amount (decimal).
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Mengapa ini penting:** Menggunakan `DataTable` memungkinkan Anda menjaga logika impor tetap terpisah dari sumber data, yang merupakan pola umum saat menghasilkan laporan dari basis data, file CSV, atau API.

## Langkah 2: Definisikan StyleArray untuk **apply custom number format** dan **change cell font color**

`StyleArray` memungkinkan Anda menggabungkan instruksi pemformatan yang akan diterapkan pada setiap sel yang diimpor dari `DataTable`. Dalam contoh ini kami:

* mengatur `Number` menjadi `#,##0.00` – format akuntansi umum dengan pemisah ribuan,
* mengatur `FontColor` menjadi `Color.Blue` – membuat angka lebih menonjol.

```csharp
// Inside Main(), after obtaining dataTable
StyleArray styleArray = new StyleArray
{
    // Custom number format: thousands separator and two decimal places
    Number = "#,##0.00",
    // Font color: blue for better visibility
    FontColor = Color.Blue
};
```

**Mengapa menggunakan StyleArray?** Menerapkan gaya saat impor menghindari proses kedua pada worksheet, yang meningkatkan kinerja untuk set data besar.

## Langkah 3: **Create Excel workbook C#** – buat instance Workbook dan dapatkan Worksheet pertama

Sekarang kami membuat workbook kosong dan memperoleh referensi ke worksheet pertama (indeks 0). Worksheet ini menjadi tujuan untuk data yang kami impor.

```csharp
// Create a new workbook
Workbook workbook = new Workbook();

// Get the first worksheet (default sheet is named "Sheet1")
Worksheet worksheet = workbook.Worksheets[0];
```

**Penjelasan:** `Workbook` mewakili seluruh file Excel, sedangkan `Worksheet` mewakili satu tab. Workbook default berisi satu lembar, yang cukup untuk kebanyakan laporan sederhana.

## Langkah 4: Impor DataTable menggunakan **StyleArray** untuk **format imported data excel**

Metode `ImportDataTable` menyalin baris dan kolom tabel ke dalam worksheet, dimulai dari sel `A1` (baris 0, kolom 0). Argumen `true` memberi tahu metode untuk menyertakan header kolom. Karena kami melewatkan `styleArray`, setiap sel yang diimpor menerima format angka khusus dan warna font.

```csharp
// Import the DataTable into the worksheet with the style applied
worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);
```

**Apa yang terjadi di balik layar:** Aspose.Cells mengiterasi setiap baris, menulis nilai, lalu menerapkan gaya yang didefinisikan dalam `styleArray`. Angka muncul dengan koma dan dua tempat desimal, dan teks ditampilkan berwarna biru.

## Langkah 5: **Save workbook as XLSX** – tulis file ke disk

Akhirnya, simpan workbook ke file `.xlsx`. Anda dapat mengubah path ke direktori yang dapat ditulisi pada mesin Anda.

```csharp
// Define the output path (adjust as needed)
string outputPath = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
    "StyleArrayImport.xlsx");

// Save the workbook in XLSX format
workbook.Save(outputPath, SaveFormat.Xlsx);

Console.WriteLine($"Workbook saved successfully to: {outputPath}");
```

**Verifikasi hasil:** Buka file yang dihasilkan di Excel. Anda akan melihat tiga baris data, kolom **Amount** diformat dengan koma, dua tempat desimal, dan ditampilkan dengan font biru. Ini mengonfirmasi bahwa langkah **format imported data excel** berhasil.

## Contoh Kerja Lengkap

Salin seluruh blok di bawah ini ke dalam proyek konsol baru dan jalankan. Tidak diperlukan kode tambahan.

```csharp
using System;
using System.Data;
using System.Drawing;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Obtain a sample DataTable (columns: Name, Amount)
            DataTable dataTable = GetSampleTable();

            // Step 2: Create a StyleArray to define number format and font color
            StyleArray styleArray = new StyleArray
            {
                Number = "#,##0.00",   // Apply custom number format
                FontColor = Color.Blue // Change cell font color
            };

            // Step 3: Create a new workbook and get the first worksheet
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Step 4: Import the DataTable into the worksheet using the style array
            worksheet.Cells.ImportDataTable(dataTable, true, 0, 0, styleArray);

            // Step 5: Save the workbook as XLSX
            string outputPath = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.Desktop),
                "StyleArrayImport.xlsx");
            workbook.Save(outputPath, SaveFormat.Xlsx);

            Console.WriteLine($"Workbook saved successfully to: {outputPath}");
        }

        /// <summary>
        /// Generates a simple DataTable with sample rows.
        /// </summary>
        private static DataTable GetSampleTable()
        {
            DataTable table = new DataTable();
            table.Columns.Add("Name", typeof(string));
            table.Columns.Add("Amount", typeof(decimal));

            table.Rows.Add("Alice", 1234.56m);
            table.Rows.Add("Bob", 7890.12m);
            table.Rows.Add("Charlie", 345.67m);

            return table;
        }
    }
}
```

**Output yang diharapkan di konsol:**

```
Workbook saved successfully to: C:\Users\<YourUser>\Desktop\StyleArrayImport.xlsx
```

Buka file dan verifikasi bahwa kolom **Amount** menampilkan nilai seperti `1,234.56` dengan font biru.

## Pertanyaan Umum & Kasus Tepi

| Pertanyaan | Jawaban |
|----------|--------|
| *Bisakah saya menerapkan format berbeda pada kolom individual?* | Ya. Setelah mengimpor, ambil objek `Style` kolom (`worksheet.Cells.Columns[1].Style`) dan atur `Number` atau `FontColor` yang berbeda. |
| *Bagaimana jika saya perlu memformat tanggal alih-alih angka?* | Set `styleArray.Number = "mm-dd-yyyy"` dan opsional `styleArray.FontColor` untuk sel tanggal. |
| *Apakah font biru terlihat pada tema Excel gelap?* | Biru dapat sulit dibaca pada latar belakang gelap. Gunakan nuansa lebih terang (`Color.LightBlue`) atau warna kontras (`Color.Black`). |
| *Bagaimana cara mengimpor DataTable yang sangat besar (ratusan ribu baris)?* | Gunakan `ImportDataTable` dengan overload `ImportDataTableOptions` untuk streaming data, atau bagi impor ke beberapa worksheet agar tetap dalam batas baris Excel (1,048,576 baris). |
| *Bisakah saya mengekspor ke CSV alih-alih XLSX?* | Ganti `SaveFormat.Xlsx` dengan `SaveFormat.Csv`. Perhatikan bahwa informasi pemformatan (format angka, warna font) hilang pada CSV karena merupakan format teks biasa. |

## Tips untuk Penggunaan Produksi

* **Pro tip:** Cache objek `Style` jika Anda perlu menerapkan pemformatan yang sama ke banyak worksheet; membuat `StyleArray` baru untuk setiap impor menambah beban.
* **Watch out for culture differences:** Pola `Number` `#,##0.00` mengikuti budaya invarian. Jika Anda memerlukan pemisah khusus locale, gunakan `NumberFormatInfo` atau biarkan Excel menanganinya berdasarkan pengaturan regional pengguna.
* **Error handling:** Bungkus pemanggilan `Save` dalam blok try‑catch untuk menangani pengecualian I/O (mis., izin tidak cukup atau file terkunci).
