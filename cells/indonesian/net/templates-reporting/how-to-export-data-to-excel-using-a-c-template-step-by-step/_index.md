# Cara mengekspor data ke Excel menggunakan template C# – panduan langkah‑demi‑langkah

Jika Anda perlu **mengekspor data ke Excel** dari aplikasi .NET, panduan ini menunjukkan solusi lengkap yang berjalan end‑to‑end. Dengan memuat template Excel yang sudah berisi tag Smart Marker, Anda dapat **mengotomatisasi pembuatan Excel** dan menghasilkan **laporan karyawan Excel** yang rapi tanpa menulis kode sel‑per‑sel.

Anda akan melihat cara:

* Memuat template Excel (`load excel template`) yang mendefinisikan tata letak.
* Mengisi daftar objek karyawan ke dalam template.
* Menghasilkan workbook akhir dan menyimpannya sebagai `output.xlsx`.

Semua kode yang diperlukan disertakan, sehingga Anda dapat menyalin, menempel, dan menjalankannya segera.

## Prasyarat

* .NET 6.0 atau lebih baru (kode juga berfungsi dengan .NET Framework 4.7+).  
* Paket NuGet **Aspose.Cells for .NET** – menyediakan `Workbook`, `SmartMarkerProcessor`, dan dukungan Smart Marker.  
* Folder bernama `YOUR_DIRECTORY` yang berisi `template.xlsx`. Template harus memiliki tag Smart Marker seperti `&=EmployeeList.Name` di sel tempat Anda ingin data muncul.

> **Pro tip:** Simpan template di folder proyek yang sama dan atur properti *Copy to Output Directory* menjadi *Copy always* sehingga jalur terresolusi dengan benar saat debugging.

## Kode sumber lengkap

```csharp
using System;
using System.Collections.Generic;
using Aspose.Cells;

namespace ExcelExportDemo
{
    // Simple POCO that represents an employee record
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Step 1: Load the Excel template that contains Smart Marker tags
            string templatePath = @"YOUR_DIRECTORY\template.xlsx";
            Workbook wb = new Workbook(templatePath);

            // Step 2: Prepare a data source – a list of employee objects
            List<Employee> employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Step 3: Create a SmartMarkerProcessor instance
            SmartMarkerProcessor sp = new SmartMarkerProcessor();

            // Step 4: Apply the employee data to the workbook using the processor
            // The tag &amp;=EmployeeList.Name in the template will be replaced with each employee's name,
            // and &amp;=EmployeeList.Position will be replaced with the corresponding position.
            sp.Process(wb, employeeList);

            // Step 5: Save the populated workbook
            string outputPath = @"YOUR_DIRECTORY\output.xlsx";
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

### Apa yang dilakukan kode

| Langkah | Mengapa penting | Baris kunci |
|---------|----------------|-------------|
| **Load Excel template** | Menggunakan kembali tata letak yang telah dirancang sebelumnya menghemat waktu dan menjamin konsistensi gaya. | `Workbook wb = new Workbook(templatePath);` |
| **Prepare data source** | Smart Markers bekerja dengan koleksi `IEnumerable` apa pun; di sini kami menggunakan daftar `Employee`. | `List<Employee> employeeList = …` |
| **Create processor** | `SmartMarkerProcessor` mem-parsing template, menemukan tag, dan menyuntikkan data. | `SmartMarkerProcessor sp = new SmartMarkerProcessor();` |
| **Process data** | Processor menggantikan setiap tag Smart Marker dengan nilai properti yang sesuai. | `sp.Process(wb, employeeList);` |
| **Save workbook** | File akhir dapat dikirim ke pengguna, disimpan di server, atau dilampirkan pada email. | `wb.Save(outputPath);` |

Hasilnya adalah file **employee report Excel** di mana setiap baris berisi nama dan jabatan seorang karyawan, tepat di tempat tag ditempatkan dalam template asli.

## Memuat template Excel

Ketika Anda `load excel template` dengan `new Workbook(path)`, Aspose.Cells membaca seluruh workbook—termasuk gaya, rumus, dan placeholder Smart Marker. Pendekatan ini lebih disukai dibandingkan membuat workbook dari awal karena:

* **Kontrol desain** – Desainer dapat memformat header, menambahkan logo perusahaan, dan mengatur lebar kolom tanpa menyentuh kode.
* **Versi** – Memperbarui template tidak memerlukan kompilasi ulang aplikasi.
* **Lokalisasi** – Anda dapat menyimpan file template terpisah untuk bahasa yang berbeda.

Jika Anda lebih suka solusi .NET murni tanpa perpustakaan pihak ketiga, Anda dapat menggunakan **ClosedXML** atau **EPPlus**, tetapi keduanya tidak memiliki dukungan Smart Marker bawaan, yang berarti Anda harus menulis loop yang menyalin data sel per sel.

## Mengotomatisasi pembuatan Excel dengan Smart Markers

Smart Markers adalah placeholder yang terlihat seperti `&=Collection.Property`. Ketika processor dijalankan:

* Ia mengiterasi koleksi (`employeeList` dalam contoh kami).
* Untuk setiap item, ia menulis nilai properti ke sel yang sesuai.
* Ia secara otomatis memperluas baris atau kolom sesuai kebutuhan.

Mekanisme ini **mengotomatisasi pembuatan Excel** dan menghilangkan logika iterasi manual. Pola yang sama bekerja untuk bentuk data apa pun—pesanan, faktur, daftar inventaris, dll.

### Variasi umum

| Variasi | Cara mengimplementasikan |
|---------|--------------------------|
| **Multiple collections** | Tambahkan lebih banyak daftar (mis., `List<Department>`) dan referensikan mereka dengan tag berbeda seperti `&=DepartmentList.Name`. |
| **Nested collections** | Gunakan notasi titik: `&=EmployeeList.Projects.ProjectName` dimana `Projects` adalah properti koleksi di dalam `Employee`. |
| **Conditional formatting** | Tempatkan aturan format bersyarat Excel di template; processor akan mempertahankannya untuk baris yang dihasilkan. |

## Membuat laporan karyawan Excel

Istilah **employee report Excel** menandakan kasus penggunaan bisnis yang umum: seorang manajer menginginkan daftar staf yang dapat dicetak. Dengan menyematkan tag Smart Marker langsung ke dalam template, Anda mendapatkan:

* Baris header dengan huruf tebal dan warna latar belakang.
* Kolom berukuran otomatis berdasarkan data.
* Baris total opsional (mis., jumlah karyawan) yang dapat Anda hitung dengan rumus Excel standar.

Jika Anda perlu menambahkan baris total, cukup letakkan rumus seperti `=COUNTA(A2:A100)` di template; processor tidak akan mengganggunya.

## Membuat template Excel C# – praktik terbaik

Saat Anda **generate Excel template C#** kode, perhatikan pedoman berikut:

1. **Pisahkan kepedulian** – Simpan pemuatan template, persiapan data, dan pemrosesan dalam metode terpisah. Ini memudahkan pengujian unit.
2. **Validasi input** – Pastikan file template ada dan koleksi data tidak null sebelum memanggil `Process`.
3. **Bebaskan sumber daya** – Meskipun Aspose.Cells mengelola memori, bungkus `Workbook` dalam blok `using` jika Anda bekerja dengan file besar.
4. **Tangani pengecualian** – Tangkap `Exception` di sekitar `sp.Process` untuk menampilkan masalah seperti nama tag yang tidak cocok.

```csharp
static Workbook LoadTemplate(string path)
{
    if (!File.Exists(path))
        throw new FileNotFoundException($"Template not found: {path}");
    return new Workbook(path);
}
```

## Output yang diharapkan

Setelah menjalankan program, buka `output.xlsx`. Anda akan melihat lembar yang terlihat seperti ini (tampilan sederhana):

| Nama      | Jabatan   |
|-----------|-----------|
| John Doe  | Developer |
| Jane Smith| Manager   |

Semua format dari `template.xlsx`—seperti warna latar belakang header, lebar kolom, dan gambar logo apa pun—tetap utuh.

## Memecahkan masalah umum

| Gejala | Penyebab kemungkinan | Perbaikan |
|--------|----------------------|-----------|
| Tidak ada data yang muncul setelah pemrosesan | Tag Smart Marker salah eja atau ditempatkan di sel yang digabung. | Verifikasi tag mengikuti sintaks tepat `&=Collection.Property` dan tidak berada di dalam wilayah yang digabung. |
| File output kosong atau rusak | Workbook disimpan sebelum pemrosesan selesai. | Pastikan `sp.Process` dijalankan **sebelum** `wb.Save`. |
| Daftar karyawan besar memperlambat pembuatan | Menggunakan versi gratis Aspose.Cells mungkin memiliki batas kinerja. | Upgrade ke versi berlisensi atau proses data dalam batch. |
| Jalur template salah | Jalur relatif terresolusi ke folder yang berbeda saat runtime. | Gunakan `Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "template.xlsx")` atau atur properti `Copy to Output Directory` file. |

## Ringkasan contoh lengkap

Berikut adalah seluruh program dalam satu blok untuk penyalinan cepat:

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using Aspose.Cells;

namespace ExcelExportDemo
{
    public class Employee
    {
        public string Name { get; set; }
        public string Position { get; set; }
    }

    class Program
    {
        static void Main()
        {
            // Load the template
            string templatePath = Path.Combine("YOUR_DIRECTORY", "template.xlsx");
            Workbook wb = new Workbook(templatePath);

            // Prepare data
            var employeeList = new List<Employee>
            {
                new Employee { Name = "John Doe", Position = "Developer" },
                new Employee { Name = "Jane Smith", Position = "Manager" }
            };

            // Process Smart Markers
            var sp = new SmartMarkerProcessor();
            sp.Process(wb, employeeList);

            // Save the result
            string outputPath = Path.Combine("YOUR_DIRECTORY", "output.xlsx");
            wb.Save(outputPath);

            Console.WriteLine($"Excel file generated at: {outputPath}");
        }
    }
}
```

Menjalankan program ini membuat file **employee report Excel** yang dapat dikirim via email, dicetak, atau diproses lebih lanjut.

* **Integrasikan dengan ASP.NET Core** – Kembalikan workbook yang dihasilkan sebagai unduhan file dalam aksi controller.
