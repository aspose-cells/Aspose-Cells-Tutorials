# Cara mengekspor tabel pivot sebagai gambar menggunakan Aspose.Cells di C#

Jika Anda perlu **mengekspor pivot** data ke dalam gambar yang dapat dipindahkan, Aspose.Cells membuat prosesnya menjadi sederhana. Tutorial ini menunjukkan secara tepat cara mengekspor tabel pivot sebagai file PNG, sehingga Anda dapat menyematkannya dalam laporan, email, atau dokumentasi tanpa memerlukan Excel di mesin target.

Mengekspor pivot sebagai gambar menghilangkan masalah format yang spesifik versi dan memungkinkan pemangku kepentingan non‑teknis melihat analisis secara langsung. Kami akan membahas semuanya mulai dari penyiapan proyek hingga merender gambar **ekspor tabel pivot**, dan kami juga akan menjelaskan cara **menyimpan pivot sebagai gambar** untuk penggunaan kembali di masa mendatang.

## Cara mengekspor tabel pivot sebagai gambar dengan Aspose.Cells

Berikut adalah contoh lengkap yang dapat dijalankan yang memuat workbook, menyegarkan pivot, mengonfigurasi opsi gambar, dan menulis file output. Setiap langkah menyertakan alasan singkat sehingga Anda memahami *mengapa* kode ditulis seperti itu, bukan hanya *apa* yang dilakukannya.

### 1. Siapkan lingkungan Aspose.Cells

1. Instal paket NuGet:

   ```bash
   dotnet add package Aspose.Cells
   ```

2. Tambahkan direktif `using` yang diperlukan di bagian atas file C# Anda:

   ```csharp
   using Aspose.Cells;
   using System.Drawing.Imaging;   // Provides ImageFormat enum
   ```

> **Tip profesional:** Targetkan .NET 6 atau yang lebih baru untuk memanfaatkan peningkatan kinerja terbaru di Aspose.Cells.

### 2. Muat workbook dan temukan tabel pivot

```csharp
// Step 1: Load the workbook that contains the pivot table
var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

// Step 2: Retrieve the first worksheet (where the pivot resides)
Worksheet worksheet = workbook.Worksheets[0];
```

*Mengapa ini penting:* Kelas `Workbook` mem-parsing file XLSX dan memberi Anda akses ke semua lembar kerja. Memilih lembar kerja yang tepat sangat penting karena sebuah workbook dapat berisi banyak pivot.

### 3. Segarkan tabel pivot untuk menangkap data sumber terbaru

```csharp
// Step 3: Ensure the pivot reflects the most recent data
worksheet.PivotTables[0].Refresh();
```

Menyegarkan menjamin bahwa setiap perubahan yang dibuat pada rentang sumber setelah file disimpan tercermin dalam gambar yang dirender. Melewatkan langkah ini dapat menghasilkan visual yang usang atau tidak akurat.

### 4. Konfigurasikan opsi ekspor gambar (ekspor gambar tabel pivot)

```csharp
// Step 4: Define how the image should be rendered
var imageOptions = new ImageOrPrintOptions
{
    ImageFormat = ImageFormat.Png,   // PNG preserves lossless quality
    // Optional: set resolution for high‑DPI output
    // HorizontalResolution = 300,
    // VerticalResolution   = 300
};
```

Objek `ImageOrPrintOptions` memungkinkan Anda mengontrol format, resolusi, dan detail rendering lainnya. PNG adalah pilihan paling umum untuk grafik tajam yang kompatibel dengan web, tetapi Anda dapat beralih ke `ImageFormat.Jpeg` jika ukuran file menjadi perhatian.

### 5. Render dan **simpan pivot sebagai gambar**

```csharp
// Step 5: Export the pivot table to a PNG file
string outputPath = "YOUR_DIRECTORY/Pivot.png";
worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);
```

`RenderToImage` melakukan pekerjaan berat: ia menggambar pivot persis seperti yang muncul di Excel dan menulis data PNG biner ke disk. Metode ini mengembalikan `void`, sehingga Anda dapat dengan aman mengasumsikan file ada setelah pemanggilan selesai tanpa memerlukan pemeriksaan tambahan.

#### Hasil yang diharapkan

Setelah program dijalankan, Anda akan menemukan `Pivot.png` di folder yang ditentukan. Membuka file tersebut harus menampilkan snapshot yang setia dari tabel pivot asli, termasuk header kolom, total baris, dan semua format yang diterapkan.

### 6. Variasi umum dan kasus tepi

| Skenario | Penyesuaian |
|----------|------------|
| **Pivot besar** (banyak baris/kolom) | Tingkatkan `HorizontalResolution` dan `VerticalResolution` menjadi 300 dpi untuk output yang lebih jelas. |
| **Styling khusus** (warna latar, font) | Pastikan definisi style workbook dimuat sebelum memanggil `Refresh()`. |
| **Beberapa pivot** dalam satu lembar | Loop melalui `worksheet.PivotTables` dan panggil `RenderToImage` untuk masing‑masing, menggunakan nama file yang berbeda. |
| **Ekspor ke JPEG** alih‑alih PNG | Ubah `ImageFormat = ImageFormat.Jpeg` dan opsional atur `Quality` pada objek `JpegSaveOptions`. |

Variasi ini memungkinkan Anda **mengekspor gambar tabel pivot** dalam format yang tepat sesuai kebutuhan sistem hilir Anda.

## Kode sumber lengkap untuk salin‑tempel cepat

```csharp
using Aspose.Cells;
using System.Drawing.Imaging;

class PivotExportDemo
{
    static void Main()
    {
        // Load workbook containing the pivot table
        var workbook = new Workbook("YOUR_DIRECTORY/Pivot.xlsx");

        // Access the first worksheet (index 0)
        Worksheet worksheet = workbook.Worksheets[0];

        // Refresh the pivot to include the latest source data
        worksheet.PivotTables[0].Refresh();

        // Define PNG export options
        var imageOptions = new ImageOrPrintOptions
        {
            ImageFormat = ImageFormat.Png
        };

        // Export the pivot as an image file
        string outputPath = "YOUR_DIRECTORY/Pivot.png";
        worksheet.PivotTables[0].RenderToImage(outputPath, imageOptions);

        // Inform the user
        System.Console.WriteLine($"Pivot table exported successfully to {outputPath}");
    }
}
```

Menjalankan program menghasilkan file PNG yang ditunjukkan di atas, menyelesaikan alur kerja **simpan pivot sebagai gambar** dalam waktu kurang dari satu menit.
